# Andon

**Andon — a one-person software factory.** AI coding agents take issues from a ledger through implementation, review and merge, and the human is called only for the decisions that only they can make.

A one-person software factory. Agents carry issues from the kanban through implementation, review, and merge, and the owner is called only when a decision that only they can make is needed. The kanban is a set of files holding each project's issues, questions, routines, and history, and it is read and written with the `kanban` command.
