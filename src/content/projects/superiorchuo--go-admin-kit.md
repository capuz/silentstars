  <strong>✨ Enterprise-level microservices backend scaffolding · Contains only infrastructure · Ready to use ✨</strong><br/>

---

## ✨ Why Choose Go Admin Kit Scaffolding

| Highlights | Description |
|:-----|:-----|
| 🧩 **Pure Scaffolding** | Contains only platform-agnostic infrastructure services (authentication/RBAC/system/logs/files/monitoring), without business coupling, a clean starting point. |
| ⚛️ **Unified Frontend** | React + Ant Design deep space/light color dual theme, a set of visual language (gradient card wall + drawer). |
| 🐳 **Ready to Use** | Docker Compose one-click to start dependencies, gateway/services and frontend; built-in RBAC, logs, monitoring, migration. |
| 🏗️ **Complete Engineering** | CI, OpenAPI, health checks, Prometheus, optional tracing and object storage. |
| 🛠️ **Easily Extendable** | Add business capabilities = add a microservice + gateway tag, does not pollute the base. |
