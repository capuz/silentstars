## Get started

Choose an installation channel on the [website](https://www.floe-agent.com/#download). Check [current status](https://github.com/JiangNanGenius/floe-agent/blob/HEAD/docs/CURRENT_STATUS.md) and the installation page for each channel’s version, region and eligibility.

```text
https://raw.githubusercontent.com/JiangNanGenius/floe-agent/main/feather.json
```

| Channel | Before you install |
| --- | --- |
| iOS / iPadOS · TestFlight | Requires valid beta access. Available builds and expiry appear in TestFlight. |
| iOS / iPadOS · Feather / AltStore | Install the corresponding app, use a button above to add the source, then sign with your own setup. |
| iOS / iPadOS · GitHub IPA | Download the IPA and checksum from Releases. The IPA is unsigned and requires your own signing. |
| Android alpha | Android 9+ (ARM64). Download the signed APK and checksum from the [Android release](https://github.com/JiangNanGenius/floe-agent/releases/tag/android/v0.1.0-alpha.1) and install it manually;…
