# CS2 Coach Agent

**From match recordings to traceable event analysis, player profiles, and training recommendations**

[English](https://github.com/Zzz0zzZ0/CS2-coach-agent/blob/HEAD/README_EN.md) · [Case study](https://github.com/Zzz0zzZ0/CS2-coach-agent/blob/HEAD/docs/portfolio/CASE_STUDY.md) · [Three-minute demo](https://github.com/Zzz0zzZ0/CS2-coach-agent/blob/HEAD/docs/portfolio/DEMO_SCRIPT.md) · [Full-flow validation](https://github.com/Zzz0zzZ0/CS2-coach-agent/blob/HEAD/docs/FULL_FLOW_VALIDATION_V3.md)

CS2 Coach Agent is an engineering project for CS2 match review: it parses real `.dem` recordings, links round events with historical retrieval evidence, generates verifiable match reports, and supports player comparison, source drill-down, and read-only follow-up questions after saving.

The system uses LangGraph to orchestrate analysis nodes. Metrics, report facts, and citations are generated by code; the model selects training themes within a whitelist. The project focuses on the complete data pipeline, explainable retrieval boundaries, fault handling, and reproducible evaluation.
