# Chompyy

> **It learns your taste, suggests the tasks you'd want done, and runs them while you're away, so tokens that would reset unused become work waiting for you when you're back.**

The home of Chompyy, spun out of [BranchWork](https://github.com/BranchWork-HQ/branchwork). For now it holds the research behind it: how to get more done per token with coding agents such as Claude Code, what exists, what actually works when measured, and where there's room left.

> **Status: early test version.** A CLI ([cli/](https://github.com/BranchWork-HQ/Chompyy/blob/HEAD/cli/README.md)) and a Mac menu bar app ([mac/](https://github.com/BranchWork-HQ/Chompyy/blob/HEAD/mac/README.md)): live quota, board, picture-first blueprints, away runs, review and rating. Taste learning and suggested tasks are next.

**Try it:** `npm install -g chompyy && chompyy status && chompyy app` (macOS 14+, Claude Code on a Pro/Max/Ultra plan, Node 20+). The tester guide is **[TRY.md](https://github.com/BranchWork-HQ/Chompyy/blob/HEAD/TRY.md)**.
