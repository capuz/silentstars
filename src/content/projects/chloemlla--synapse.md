A feature-rich full-stack web application platform centered on text-to-speech (TTS) and speech transcription, integrating dozens of functional modules including multi-factor authentication with account risk grading, multi-layer security protection, a resource store and CDK, batch Markdown → Word conversion, a GeoGebra collaboration workspace, a Pixel task workspace, legal hold and forensic audit, data analysis, utility tools, entertainment games, and an admin backend. The backend is built on Node.js + Express 5 + MongoDB (Mongoose 9), the frontend on React 19 + Vite 8 + Tailwind CSS 4, and it supports one-click deployment with Docker.
