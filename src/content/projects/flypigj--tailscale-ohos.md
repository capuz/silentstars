# MeshArc

A Tailscale community client built for HarmonyOS NEXT, connecting devices, transferring files, and accessing remote storage and media services.

---

After going out, access the NAS at home, send files from your phone to your computer, or open a remote media library. MeshArc brings these common operations into the HarmonyOS native interface, allowing your HarmonyOS device to join an existing Tailscale network (tailnet).

**MeshArc is an independent community project and not an official Tailscale client.** This repository retains the `Tailscale-OHOS` name, with the app name being MeshArc.

## One Connection, Endless Possibilities

| What You Want to Do | Capabilities MeshArc Provides |
| --- | --- |
| **Access Your Own Devices** | Log in to Tailscale, view device online status, connection paths and latency, and access remote services via Tailscale IP. |
| **Use Home or Remote Networks** | Select available exit nodes, receive approved subnet routes, and configure local network access when using exit nodes. |
