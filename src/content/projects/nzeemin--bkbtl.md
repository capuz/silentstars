# bkbtl - BKBTL emulator, Win32 version

## In Russian

**BKBTL** — **BK Back to Life!** — is a project to emulate the Soviet domestic computer [БК-0010/БК-0011](http://ru.wikipedia.org/wiki/БК), built on a 16-bit К1801ВМ1 processor, compatible in instruction set with the PDP-11 family. The project started on November 14, 2009. Based on the code of the [UKNCBTL](https://github.com/nzeemin/ukncbtl) project.

The BKBTL project includes repositories:
* **bkbtl** — Windows version. Written for Win32 and requires Unicode support, so the set of Windows versions is 2000/2003/2008/XP/Vista/7.
* [**bkbtl-qt**](https://github.com/nzeemin/bkbtl-qt) — Qt version. Works on Windows, Linux and Mac OS X. The Qt version has no sound support, no memory map window, no external joystick support; otherwise the capabilities are the same.
* [**bkbtl-testbench**](https://github.com/nzeemin/bkbtl-testbench) — test bench for regression testing.
* [**bkbtl-doc**](https://github.com/nzeemin/bkbtl-doc) — documentation and screenshots.
