# Netbox Routing

A plugin for tracking all kinds of routing information

## Features

### Current features

* Static routing
* Dynamic routing
  * EIGRP
  * BGP
    * Templates/Group inheritance
    * IPv4/IPv46 AF VRF support
    * VPNv4 support
  * OSPF

### Under development

### Roadmapped

* Dynamic Routing
  * IS-IS

# Requirements

* Netbox 4.5+
* Python 3.12+
