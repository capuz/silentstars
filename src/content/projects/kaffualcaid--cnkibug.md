# CNKIBug

CNKIBug helps you batch-find literature on research topics on China National Knowledge Infrastructure (CNKI). It combines results from multiple keyword groups or search criteria, filters them, and exports them as a spreadsheet or imports them into Zotero.

**[Download Windows version](https://github.com/KaffuAlcaid/CNKIBug/releases/latest/download/CNKIBug-GUI.exe)** · [Download Linux version](https://github.com/KaffuAlcaid/CNKIBug/releases/latest/download/CNKIBug-GUI-x86_64.AppImage) · [Usage guide](https://github.com/KaffuAlcaid/CNKIBug/blob/HEAD/docs/usage.md)

Quick navigation: [Main features](#主要功能) · [Getting started](#开始使用) · [Interface and export](#界面与导出) · [Documentation and feedback](#文档与反馈) · [License and acknowledgments](#许可与致谢)

## Main features

- **Batch literature search**: Enter multiple keyword groups or import a TXT list, or combine advanced search criteria; set the search scope, sort order, and language
- **Save profiles and resume tasks**: Save commonly used search criteria; if a task is interrupted, you can resume from the most recently completed page
- **View and filter results**: Combine results from multiple searches, merge duplicate literature,…
