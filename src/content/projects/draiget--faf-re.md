# faf-re

**The *Supreme Commander: Forged Alliance* engine, rebuilt as C++20**

[Build](#build) · [Retail parity](#retail-parity) · [Performance](#performance) · [Contributing](https://github.com/Draiget/faf-re/blob/HEAD/CONTRIBUTING.md)

The Moho engine behind *Supreme Commander: Forged Alliance* (2007), rebuilt as readable, buildable C++20 so it can be maintained instead of staying frozen in a binary. It builds for x86 and x64, plays real games bit for bit like the retail `ForgedAlliance.exe`, and the x64 build plays replays about a quarter faster.

> An independent preservation and interoperability effort, inspired by and indebted to the [Forged Alliance Forever](https://faforever.com) community. Not affiliated with, endorsed by, or supported by the original publisher or developer. See [LEGAL.md](https://github.com/Draiget/faf-re/blob/HEAD/LEGAL.md).
