### Mod Overview

**yiyiaddon** is an automation mod for Minecraft Java Edition, based on Fabric, that consolidates common automation operations into a Chinese-language interface.

- **Core gameplay**: Stardew farm, Stardew fishing, fully automatic map art
- **Daily tasks**: auto mining, auto enchanting, supply replenishment, sorted unloading
- **Task management**: task notifications, run statistics, per-server saved configuration

**Supported systems**: Windows x64 · Mac ARM64

- **Mac**: Uses native ARM64 Java. Downloadable platforms and installer status are as marked in the download section.
- **Server compatibility**: The Stardew features target farming and fishing gameplay on Minecraft servers, and need to be configured according to the server's resource pack and menu settings.
