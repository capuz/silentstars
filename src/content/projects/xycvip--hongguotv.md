# Hongguo TV

A Hongguo short drama client project built with native Android technology. Supports Android 8.0 (API 26) and above on ARM64 (arm64-v8a) and ARMv7 (armeabi-v7a) Android devices. There is no separate package per architecture; the APK is about 2 MB.
  Feature requests and questions are welcome.
