# Hongguo TV

An Android-native client for the Hongguo short-drama service. It supports Android 8.0 (API 26) and later on ARM64 (arm64-v8a) and ARMv7 (armeabi-v7a) devices. There is a single package for all of these, and the install package is about 2 MB.
  Feature requests and questions are welcome.
