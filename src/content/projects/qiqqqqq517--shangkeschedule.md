# ShangKe · ShangKeSchedule

> An open-source course schedule app for Chinese universities (Kotlin Multiplatform + Compose Multiplatform).
> One app solves: **Course schedule, agenda and to-do lists, multiple daily routine options, couple's course schedules, academic system one-click import, desktop widgets, course reminders and cloud backup**.
> Android is the official version (Android 8.0+), Desktop and iOS are in development.

**Official Website** <https://shangke.asia> ｜ **Download** <https://shangke.asia/download> ｜ **Changelog** <https://shangke.asia/changelog> ｜ **Issue Feedback** [GitHub Issues](https://github.com/qiqqqqq517/shangkeschedule/issues)
