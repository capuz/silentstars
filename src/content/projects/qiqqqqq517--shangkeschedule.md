# 上课 (ShangKe) · ShangKeSchedule

> An open-source timetable app for Chinese university settings (Kotlin Multiplatform + Compose Multiplatform).
> One app covering: **timetable, agenda and to-dos, multiple bell-schedule plans, couple timetable, one-tap academic system import, grades and GPA, certification score lookup, desktop widgets, class reminders and cloud backup**.
> The Android version is the official release (Android 8.0+); Desktop and iOS are in development.

**Official site** <https://shangke.asia> | **Download** <https://shangke.asia/download> | **Changelog** <https://shangke.asia/changelog> | **Issue tracker** [GitHub Issues](https://github.com/qiqqqqq517/shangkeschedule/issues)
