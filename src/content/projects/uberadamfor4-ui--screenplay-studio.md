# Screenplay Studio / 剧本工坊

Cross-platform desktop screenplay writing software. The project uses Electron, React, TypeScript, and Vite, with a simplified Chinese interface as the default experience, while also supporting English, traditional Chinese, and other screenplay text workflows.

> Current version: 0.4.1
> License: MIT  
> Developer: This software is independently developed by 郭之然 of 1037 Film
> Design boundaries: Refer to the general workflow of professional screenplay writing tools, but do not copy Final Draft's proprietary interface, code, materials, trademarks, or protected expressions.

## Implemented

- Application icon: SVG source files, PNG multi-size bitmaps, Windows `.ico`, and integrated window icons, web favicons, installation package, and shortcut icons.
- Cross-platform packaging: Windows NSIS installation package; macOS DMG/ZIP, capable of building Intel x64 and Apple Silicon arm64 separately.
- Writing UI: Retains a focused writing layout, top command bar, element formatting bar, centered Letter paper, and bottom status bar.
