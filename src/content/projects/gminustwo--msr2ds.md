# msr2ds (Metroid Samus Returns 2DS)

> **Important**
>
> **Bug reports:**
> 
> Use the **Bug report** form on [Issues](https://github.com/gminustwo/msr2ds/issues/new/choose) and attach the log of the play session where the problem happened. Each play session writes its own, in `user/logs/`, named by the date and time it started (the newest 10 are kept). [Reporting a problem](#reporting-a-problem) says where to find it on each platform.
>
> **Android users:**
>
> Android support is difficult. We don't have an Android device to physically test on. Building an Android image is easy, but testing it on real hardware is a different story.
> Android support can only continue with a back and forth from the community unless someone wants to put in a pull request to fix whatever is the performance issues being seen there.
> 
> **No game files are included.**
