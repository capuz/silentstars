The official Douyin app doesn't adapt to the inner screen of foldable phones or to iPad, and the web version keeps redirecting to the App, which is why this project exists. The UI and playback are fully native (SwiftUI + AVPlayer, with VLC as a fallback).

## Features

**Watching videos**
- Recommended / Following / Live, full-page vertical swiping; **instant start** (plays the last cached video first) plus background **pre-caching** of several upcoming videos
- Four UI modes, switchable via More → Settings → UI mode: **Default / Simple / Minimal** (Minimal shows only the video, with progress drawn on the outer ring of the round entry on the right), plus the **Classic** layout available on iPhone Duo (iOS 27.1+, [notes](https://github.com/81199000/DouDuo/blob/HEAD/docs/classic-duo-layout.md)). All four modes share the same interactions; maintenance rules are in [docs/ui-modes.md](https://github.com/81199000/DouDuo/blob/HEAD/docs/ui-modes.md)
- Horizontal swipe to seek forward and back (with preview), double-tap to like, long-press to speed up, playback speed presets, auto-play next, background playback and lock-screen controls
