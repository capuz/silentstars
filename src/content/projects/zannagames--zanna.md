<h1 align="center">Zanna</h1>

</p>

**Zanna** is a from-scratch, IL-first compiler toolchain and virtual machine for building platform-native applications and games. Source languages lower to a typed intermediate language, **[Zanna IL](https://github.com/zannagames/zanna/blob/HEAD/docs/il/il-guide.md)**, which can run on the [VM](https://github.com/zannagames/zanna/blob/HEAD/docs/internals/vm.md), feed the optimizer, or compile to native code through the built-in backends.

**[Zia](https://github.com/zannagames/zanna/blob/HEAD/docs/languages/zia-reference.md)** is the flagship language: a modern, statically typed language with classes, generics, enums, lambdas, modules, pattern matching, and direct access to the Zanna runtime. A **[BASIC](https://github.com/zannagames/zanna/blob/HEAD/docs/languages/basic-reference.md)** frontend is included for education, compatibility experiments, and quick prototypes.

> **Status:** Pre-alpha, active development. The current source tree is `v0.3.1-snapshot`; the IL reference is `0.3.0`. APIs, diagnostics, IL rules, and tooling are still evolving.
