# Spreado - All-in-One Content Publishing Tool

A powerful automation tool that supports simultaneous video publishing to multiple Chinese social media platforms, including Douyin, Xiaohongshu, Kuaishou, and Tencent Video Account.

## 🚀 Features

- **Multi-platform Support**: One-click upload to Douyin, Xiaohongshu, Kuaishou, and Tencent Video Account
- **Smart Authentication**: Automatically handles login and cookie management, supports full process QR code scanning login
- **Flexible Scheduling**: Supports scheduled publishing and draft saving
- **Rich Configuration**: Complete settings for title, description, tags, cover, location, etc.
- **Command Line Interface**: Easy-to-use CLI tool
- **Program Interface**: Supports Python API integration
- **Plugin Architecture**: New platforms can be automatically discovered by placing them in the `plugins/` directory without modifying core code
