# Ad-set-hosts

## 1. Introduction

- This project aggregates multiple ad-blocking `hosts` and removes duplicates
- This project implements automatic updates via GitHub Actions, updating once every hour
- For learning, exchange, and personal use only. Do not use commercially. If it infringes any rights, please contact us and it will be removed
- Discussion group: **[Click to join the 小贝塔 tutorial resource group](https://jq.qq.com/?_wv=1027&k=Ju2X65DC)**

## 2. Usage and Version Information

- On Android, directly replace `/system/etc/hosts`, or flash it using a `Magisk` module
- Do not use on computers; large `hosts` files can cause computers to lag
- `AdGuard` version (simply adds the original hosts to the filter list)
- `Github version`: the file address is on GitHub; the mirror version is for easier access within mainland China
