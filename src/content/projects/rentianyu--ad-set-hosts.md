## 1. Introduction

- This project collects multiple ad-blocking `hosts` and deduplicates them.
- This project has implemented GitHub Actions for automatic updates, updating every hour.
- For learning and personal use only, please do not use for commercial purposes. If there is any infringement, please contact for removal.
- Group chat: **[Click to join the Xiao Bei Ta tutorial resource group](https://jq.qq.com/?_wv=1027&k=Ju2X65DC)**

## 2. Usage and Version Introduction

- For Android, directly replace `/system/etc/hosts`, or use `Magisk` module to flash.
- Do not use on computers, as the `hosts` file being too large can cause the computer to lag.
- `AdGuard` version (just adds the original hosts to the filter list).
- `Github version` file address is from GitHub, the mirror version is convenient for access in China.
