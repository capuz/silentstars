# Vermes 🚀

> Your AI, ready to go — out-of-the-box Chinese AI Agent

Vermes is based on the official [Hermes Agent](https://github.com/NousResearch/hermes-agent) engine, integrating the [QClaw](https://skillhub.cn) skill ecosystem to provide an out-of-the-box AI Agent experience for Chinese users.

## ✨ Features

- 🧠 **Self-evolving Agent** — Learns from experience, creates and improves skills
- 🛠 **30+ Built-in Skills** — Documents, search, email, weather, code...
- 🏪 **Skill Store** — Expand capabilities anytime through Skillhub
- 🌐 **Multi-model Support** — DeepSeek, Qwen, OpenAI, Ollama...
- 💻 **Cross-platform** — macOS / Windows / Linux
- 🇨🇳 **Chinese First** — Default Chinese interaction, pre-configured domestic models

## 📦 Installation

### macOS / Linux
```bash
curl -fsSL https://install.vbit.top | bash
```

### pip
```bash
pip install vermes
vermes setup
vermes
```

## 🚀 Quick Start

1. `vermes setup` — Choose model and provider (recommended DeepSeek)
2. `vermes` — Start the conversation!

## 🏪 Skill Store

```bash
vermes skills search 天气   # Search for skills
vermes skills install weather  # Install skills
```
