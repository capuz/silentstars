# Motion Studio

Motion Studio is an open-source motion graphics editor for desktop. It organizes the creative workflow with layers, keyframes, curves, nodes, and GPU compositing, aiming to let motion design, compositing effects, and real-time preview work together in the same project.

The project is in ongoing development. Current development and automated verification focus on Windows, Linux, and macOS desktop. The desktop version already provides usable layer editing, timeline, curve, and node effect workflows. The Android version is no longer maintained. Its historical source code and manual build tools are retained, but automatic builds, device testing, and APK releases have been disabled.

## Current Capabilities

| Area | Provided | Still being improved |
| --- | --- | --- |
| Layers & timeline | Layer hierarchy, clip moving, trimming, splitting, parent-child relationships, blend modes, track masks | More complete media management and advanced timeline workflows |
| Animation & curves | Keyframes for position, anchor, scale, rotation, opacity, and effect parameters; value curves and speed curves | More curve editing handles, expression references, and complex easing |
