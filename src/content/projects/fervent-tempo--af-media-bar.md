## Introduction

AF Media Bar is a portable media controller for Windows 10/11. It reads the Windows Global System Media Transport Controls (GSMTC), displaying album covers, titles, artists, and real-time lyrics in the taskbar, while providing previous track, play/pause, next track, and source switching. Audio devices, application volume, spatial audio, and system metrics can all be managed in the same interface.

The program runs as an independent process, mounting the WPF media bar as a taskbar child window without modifying or injecting code into `explorer.exe`. Applications such as NetEase Cloud Music, QQ Music, Spotify, and web browsers can be discovered and controlled as long as they publish media sessions to Windows.
