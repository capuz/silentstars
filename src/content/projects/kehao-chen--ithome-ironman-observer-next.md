# 鐵人觀察家 Next

A daily observation dashboard for the 2026 iThome Ironman Contest. It is a static site: GitHub Actions scrapes the data on a schedule, and Cloudflare Pages hosts it for free.

🔗 Live site: https://ithome-ironman-observer.happyhacking.ninja/

The site has four pages:

- **[Contest Observatory (賽事觀察台)](https://ithome-ironman-observer.happyhacking.ninja/)** (home): one card per participating series, showing progress and popularity
- **[Team Scoreboard](https://ithome-ironman-observer.happyhacking.ninja/teams/)**: treats teams as participating units, showing total views, average views per member, average progress, today's posts, and lag warnings
- **[Hall of Fame](https://ithome-ironman-observer.happyhacking.ninja/hall-of-fame/)**: lists participating authors with public recognition (such as 高見龍), with a one-line introduction, verifiable source links, and their series articles
- **[Insights](https://ithome-ironman-observer.happyhacking.ninja/insights/)**: analysis of the entire contest, with charts for posting times, popularity distribution, categories, title text, and more
