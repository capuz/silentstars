**INPX Library Server** — self-hosted web server for electronic libraries based on INPX/FB2. Catalog, search, in-browser reading, OPDS for KOReader, and sending books to Kindle/Kobo by email — on a NAS, Raspberry Pi, or an ordinary PC.

---

## Features

| | |
|---|---|
| **Catalog** | Full-text search, authors / series / genres, filters, book card with cover and similar books |
| **Formats** | FB2, EPUB, MOBI, AZW3 · ZIP/7z archives · multiple sources at once |
| **Reader** | HTML5 for FB2/EPUB, themes, fonts, bookmarks, position, TTS, «Continue» |
| **Personal** | Favorites (books, authors, series), shelves, recommendations |
| **Delivery** | Download and batch ZIP · conversion via [fb2cng](https://github.com/rupor-github/fb2cng) · email to e-reader |
| **OPDS** | `/opds` for KOReader, Moon+, Librera, FBReader · Basic Auth · OpenSearch |
| **Sidecar** | Flibusta/FLibrary covers (incl. JXL), reviews, biographies, portraits |
| **Admin** | Sources, users, SMTP, Telegram bot, OIDC/SSO, duplicates, logs, backup, update from ZIP |
| **Security** | Sessions, CSRF, rate limit, SMTP password encryption, configurable anonymous access |
