# Open Fixture Library<br><a href="https://open-fixture-library.org/">open-fixture-library.org</a>

[<img alt="OFL logo" src="https://cdn.rawgit.com/OpenLightingProject/open-fixture-library/master/ui/static/ofl-logo.svg" width="250" />](https://github.com/OpenLightingProject/open-fixture-library/blob/HEAD/ui/static/ofl-logo.svg)

To use lighting control software like [QLC+](https://www.qlcplus.org/), [DMXControl](https://www.dmxcontrol.org/) or [e:cue](https://www.osram.de/ecue/), you need fixture definition files that describe your lighting hardware. Since one software can usually only understand its own fixture definition format, switching between different programs can be difficult.

The *Open Fixture Library* tries to solve this problem by collecting fixture definitions and making them downloadable in various formats. Internally, it uses a [JSON format](https://github.com/OpenLightingProject/open-fixture-library/blob/HEAD/docs/fixture-format.md) that tries to bundle as much information as possible for all the different output formats.
