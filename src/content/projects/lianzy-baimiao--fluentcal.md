# FluentCal Desktop Calendar

[Simplified Chinese](https://github.com/Lianzy-Baimiao/FluentCal/blob/HEAD/README.md) · [Traditional Chinese](https://github.com/Lianzy-Baimiao/FluentCal/blob/HEAD/README.zh-TW.md) · [English](https://github.com/Lianzy-Baimiao/FluentCal/blob/HEAD/README.en.md)

FluentCal is a native Windows desktop calendar and Gantt chart. Tasks, calendars, and project plans share one dataset. It works offline, requires no account, and has no ads.

[Microsoft Store](https://apps.microsoft.com/store/detail/9NTT06453DG5?cid=DevShareMCLPCB) · [Windows installer](https://github.com/Lianzy-Baimiao/FluentCal/releases/latest) · [Android client](https://github.com/Lianzy-Baimiao/FluentCal/releases/tag/android-latest)
