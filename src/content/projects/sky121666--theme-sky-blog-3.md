# Sky Blog 3

Sky Blog 3 is a macOS desktop style blog theme for Halo 2.x. The theme organizes content such as articles, archives, galleries, moments, friend links, tracking, Douban, Steam, equipment, and Docsme into independent apps, with the desktop, Dock, top bar, window system, and desktop widgets as the core interaction model.

- Repository: [sky121666/theme-sky-blog-3](https://github.com/sky121666/theme-sky-blog-3)
- Current version: `v0.9.42`
- Halo requirement: `>= 2.25.0`
- Package manager: `pnpm`

> Halo compatibility note: `theme.yaml` only declares the minimum requirement of `>=2.25.0`; actual adaptation and running verification are based on the latest stable version of Halo `2.25.4`. My local `2.25.4` has been verified with `pnpm run verify:reload` and `SMOKE_BASE_URL=http://localhost:8090 pnpm run smoke:playwright`.
