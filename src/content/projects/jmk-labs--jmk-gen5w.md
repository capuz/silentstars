# JMK Gen5W — Korean-market Gen5W head unit package

A NEMESIS package for installing on Korean-market **Hyundai·Kia Gen5W AVNT head units** (NEMESIS rooted). It was built around the Ioniq 5, and features for other models will be enabled as they are confirmed ([Supported vehicles](#지원-차종)).

| Package | Version | What it does |
|---|---|---|
| **jmk-map-menu** | 2.3.49 | Hold the MAP button for 1.5 seconds → JMK launcher menu: Wi-Fi, Active Ambient, car camping mode, custom heated window, lab, NEMESIS, USB mode, reboot |
| **jmk-ambient-sound** | 2.5.24 | Moves the interior ambient light in sync with music and calls (AI DJ / mood / beat / solid color / custom). Bluetooth·USB·Android Auto·Apple CarPlay |
