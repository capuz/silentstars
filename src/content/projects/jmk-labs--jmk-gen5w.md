# JMK Gen5W — Domestic Gen5W head unit package

A NEMESIS package to install on the domestic **Hyundai·Kia Gen5W AVNT head unit** (NEMESIS rooted). It was built around the IONIQ 5, and features for other models will be enabled as they are confirmed ([Supported vehicles](#지원-차종)).

| Package | Version | What it does |
|---|---|---|
| **jmk-map-menu** | 2.3.40 | Hold the MAP button for 1.5 seconds → JMK launcher menu: Wi-Fi, Active Ambient, camping mode, custom heated window, lab, NEMESIS, USB mode, reboot |
| **jmk-ambient-sound** | 2.5.21 | Moves the interior ambient lighting in sync with music and calls (AI DJ / mood / beat / solid color / custom). Bluetooth·USB·Android Auto·Apple CarPlay |
| **jmk-wifi** | 1.4.16 | Makes a USB Wi-Fi dongle work **like a factory Wi-Fi module**. Wireless Android Auto·CarPlay via the factory hotspot, while simultaneously connecting to a phone hotspot |
| **jmk-autoplay** | 0.3.6 | **Wireless AutoPlay**: Wireless CarPlay · Android Auto |
