M3U and Xtream Codes, program guide (EPG), archive, profiles — controlled only with the remote, no ads and no accounts.</p>

## Features

**Sources**
- M3U / M3U8 by link or from a file, Xtream Codes, Stalker/Ministra; multiple playlists at the same time.
- Provider groups (`group-title`, `#EXTGRP`), favorites, recently watched, hiding and renaming categories.
- Adding a playlist from a phone by QR code over the local network — no need to enter the address with the remote.

**Program guide and archive**
- XMLTV (`url-tvg`, `.xml`, `.xml.gz`), automatic matching of programs by channel name, even without `tvg-id`.
- Program grid across all channels, description and "what's next" right in the channel list.
- Archive (catch-up) and rewinding of live broadcasts where the provider supports it.
