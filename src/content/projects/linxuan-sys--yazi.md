# Yazi Localized Enhanced Configuration

> A **Chinese-enhanced configuration** based on [Yazi](https://github.com/sxyazi/yazi): all interface prompts are localized into Chinese, with 16 practical built-in plugins, ready to use out of the box.

- Applicable version: **Yazi 26.9.1**
- Target audience: Chinese-speaking users
- Features: fully Chinese keybinding descriptions, a complete plugin set, and fixes for keybinding conflicts in the default configuration

---

## 1. Plugins and Features

| Plugin | Function | Keybinding / Notes |
| :--- | :--- | :--- |
| `mediainfo` | Thumbnail and media info preview for audio, video, and images | Preview on cursor hover; depends on `ffmpeg`, `mediainfo` |
| `duckdb` | Preview CSV / TSV / JSON / Parquet / XLSX / DB table data | Preview on cursor hover; depends on `duckdb` |
| `docx-preview` | Converts `.docx` documents to plain-text preview (Chinese supported) | Depends on `pandoc` |
| `preview-typst` | Preview for `.typ` typesetting documents | Depends on `typst` |
| `gvfs` | Mount MTP / SMB / SFTP / WebDAV devices and remote storage | `M` series, `G m`; depends on `gvfs`, `glib` |
| `mount` | Mount / unmount / eject local disk partitions |…
