# OpenFeature Go Contributions

This repository is intended for OpenFeature contributions which are not included in the [OpenFeature SDK](https://github.com/open-feature/go-sdk).

The project includes:

- [Providers](https://github.com/open-feature/go-sdk-contrib/blob/HEAD/providers)
- [Hooks](https://github.com/open-feature/go-sdk-contrib/blob/HEAD/hooks)
- [Tests](https://github.com/open-feature/go-sdk-contrib/blob/HEAD/tests)

## Contributing

Interested in contributing? Great, we'd love your help! To get started, take a look at the [CONTRIBUTING](https://github.com/open-feature/go-sdk-contrib/blob/HEAD/CONTRIBUTING.md) guide.
