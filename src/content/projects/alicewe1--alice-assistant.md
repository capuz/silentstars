## What is this

Alice Assistant is a portable desktop tool for Windows designed to manage **prompts** and **skill libraries** for AI coding Agents.

It decouples prompts, skill libraries, and clients: any prompt can be paired with any skill library and deployed to any client. To switch to a different combination, just click in the interface—no need to manually navigate directories or copy-paste files.

**It doesn't restrict clients.** It comes with presets for common Agents, while also allowing you to specify custom paths—select a prompt file, a skill folder, and a target folder to integrate a new client.

The entire runtime (including the built-in portable Codex) is distributed with the package and can be used directly on any Windows machine: no registry writes, no system environment pollution, uninstall by simply deleting the folder.
