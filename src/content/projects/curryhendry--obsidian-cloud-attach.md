# obsidian-cloud-attach

> An Obsidian plugin that connects to services such as OpenList via WebDAV, and to object storage (S3), so you can insert cloud files directly into notes. Frees up local space.

---

## Project Background

- A committed Obsidian vault user who keeps 0 attachments locally
- Heavy OpenList user
- Former e-commerce professional with zero coding background
- All work done with 🦞 Lobster

---

## Features

- 🌐 **WebDAV protocol** — Compatible with OpenList; in theory supports all WebDAV services such as Alist / Synology / QNAP
- 🌐 **S3 object storage** — Compatible with Cloudflare R2; in theory supports most object storage services such as AWS
- 📂 **Sidebar browsing** — Browse cloud directories directly in the Obsidian sidebar
- 📝 **One-click insert** — Single-click inserts a Markdown link; supports inserting one or multiple selections at once
- ⬆️ **Upload attachments** — Upload local attachments to the server and update references, saving local space
- 🔗 **Signed links** — Automatically generates URLs with a sign signature
