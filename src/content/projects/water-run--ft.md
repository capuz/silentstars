# f(t)

**Free software, free video.** f(t) uses large language models to help produce science-popularization and project-introduction videos that explain one thing clearly. For each film, it publishes the factual basis, script, review records, animation source code, and production tools, all released under GPL-3.0-or-later. Anyone can watch, study, modify, or remake them.

The name comes from the images themselves: every frame is a pure function of time t, f(t). Finished videos are 1920×1080 at 60 frames per second and are published on [哔哩哔哩](https://space.bilibili.com/68328330) and [YouTube](https://www.youtube.com/@waterrun1978). All works, production status, and release records are listed in the **[catalog](https://github.com/Water-Run/ft/blob/HEAD/videos/README.md)**.

## Purpose

Knowledge is a wealth jointly created by humanity, and videos that explain knowledge should be as free as free software. Each film is released together with its complete source code, giving users four freedoms:

| Freedom | Meaning in f(t) |
|---|---|
| Run | Anyone can watch, screen, and use these videos for any purpose |
