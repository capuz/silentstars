# Magic 视界社区版

Windows 桌面社区项目，提供统一桌面网格、虚拟大文件夹、Windows 文件操作与通用拖放、顶栏弹窗，以及声明式卡片入口和管理。

Windows 桌面宿主由独立 Win32/.NET 程序实现。仓库中的桌面 Widget 使用 `@seelen-ui/lib` 2.8.4，并复用部分上游样式；它们及仓库保留的其他上游内容继续适用各自许可证，详见 [`NOTICE.md`](https://github.com/littletaro97-arch/honor-magic-visual-community/blob/HEAD/NOTICE.md) 和 [`THIRD-PARTY-NOTICES.md`](https://github.com/littletaro97-arch/honor-magic-visual-community/blob/HEAD/THIRD-PARTY-NOTICES.md)。

项目优先级是**低占用、低延迟、低续航影响**。当前仍为预览阶段；自动检查与真实 Windows 桌面验收分开记录。
