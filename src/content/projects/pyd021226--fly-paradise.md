# Fly Paradise

Windows desktop fruit fly. Repository: [pyd021226/fly-paradise](https://github.com/pyd021226/fly-paradise)

**Two installation packages, different modes.** Download: [Releases](https://github.com/pyd021226/fly-paradise/releases/tag/v0.3.6)

| File | For whom |
|---|
| **fly-paradise-setup-0.3.6.exe** | Fly Paradise. Raise them yourself, maximum 12 adult flies, complete level with 12 all green. Auto-start on boot is disabled by default. |
| **fly-paradise-welfare-setup-0.3.6.exe** | Fly Paradise Welfare Edition. Suitable for installing on a friend's computer. Auto-start on boot by default. More egg-laying, no upper limit on quantity. |

## Running from source

```
npm install
npm start
```

Welfare Edition preview: `npm run start:annoy`

## Packaging

```
npm run dist
npm run dist:annoy
```
