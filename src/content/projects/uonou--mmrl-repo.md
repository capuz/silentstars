# Misaki-Modules Repo

A module repository based on MMRL (Magisk Module Repository Loader)

## 📱 Introduction

Misaki-Modules Repo is a repository focused on providing high-quality Magisk modules. We are committed to giving users a convenient module download and management experience.

### ✨ Features

- 🔄 Automatically syncs module updates every 6 hours
- 🧹 Automatically cleans up old versions to keep the repository tidy
- 📦 Supports Magisk/KernelSU/APatch
- 🔍 Full module search
- 📱 Mobile-friendly interface

## 🗂️ Repository Structure

```
📦 mmrl-repo
 ┣ 📂 assets            # Repository media assets
 ┃ ┗ 📜 cover.webp      # Repository cover (1024x500)
 ┣ 📂 json              # Configuration files
 ┃ ┣ 📜 config.json     # Global repository settings
 ┃ ┗ 📜 modules.json    # Module list and metadata
 ┗ 📂 modules           # Magisk module storage
```

## 🚀 Quick Start

1. Use a Magisk manager that supports [MMRL](https://github.com/MMRLApp/MMRL)
2. Add the repository URL: `https://misak10.github.io/mmrl-repo/`
3. Refresh and browse the available modules
4. Select and install the modules you need

### 📱 Supported Managers
- [MMRL](https://github.com/MMRLApp/MMRL)
