# Nightcord

A real-time chat application with a modern, modular architecture.

## ✨ Features

- 🎯 **Highly decoupled** - UI, business logic, and network communication are fully separated
- 📡 **Event-driven** - Uses a publish-subscribe pattern for communication between components
- 🔄 **Auto-reconnect** - WebSocket automatically reconnects after disconnection
- 🧩 **Extensible** - Easily add new features through a plugin system
- 📦 **Modular** - ES6 modules, each class is a separate file
- 🧪 **Easy to test** - Single responsibility, easy to unit test
- 📝 **Complete documentation** - API docs, architecture docs, example docs
- 🤖 **AI integration** - Built-in Nako AI assistant with streaming conversation support
- 🔐 **SSO authentication** - Integrates SEKAI Pass single sign-on
- 📊 **Data reporting** - Automatically reports user activity to SEKAI Platform

### @ Mentions

Type `@` in the input box or click the `@` button to select a member, `everyone`, or AI.
Member mentions are bound to user ID. Users with the same name are listed separately, and mentions still work after a rename. Click a member mention in a message to view their profile.
