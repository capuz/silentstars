# cfipv4db

Get the best IP addresses from China Mobile, China Telecom, and China Unicom every 30 minutes!

Data source: https://github.com/gacjie/cf2dns

Main function: When using cFvless, quickly generate 15 preferred nodes at once. No need to manually enter them one by one each time you log in. Combined with subscriptions, you can get multiple preferred IPs at once!

For convenience, you can directly use the files cfip.txt and cf.txt!

CNchina.txt: this is a program I run with local code, suited to China Telecom broadband. If you need it, you can call it yourself.

2026 latest update file: https://raw.githubusercontent.com/yuanxiawan/cfipv4db/refs/heads/main/high_score_ips.txt

Clean IPs, scanned by my own server and by US-region VPSes, so most of the IPs are from there. The planned update frequency is every 15 minutes (only top-ranked, particularly high-quality IPs by weight get included)!
