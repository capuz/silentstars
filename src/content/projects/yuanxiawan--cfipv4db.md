# cfipv4db

Get the best IP addresses from China Mobile, China Telecom, and China Unicom every 30 minutes!

Data source: https://github.com/gacjie/cf2dns

Main function: When using cFvless, quickly generate 15 preferred nodes at once. No need to manually enter them one by one each time you log in. Combined with subscriptions, you can get multiple preferred IPs at once!

For convenience, you can directly use the files cfip.txt and cf.txt!

The latest updated file in 2026 is high_score_ips.txt. It contains clean IPs, selected from our own server scans, specifically VPS in South Korea, so most of the IPs are from there. The speed is quite good, making it a top-tier IP option! The planned update frequency is once every 15 minutes (provided exceptionally high-quality IPs are found)!

Call for contributions: If you have spare Hong Kong hosts, please contact me. I can place the testing script on the Hong Kong host. It must be able to run PY!
