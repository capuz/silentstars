# cfipv4db

Get the best IP routes for China Mobile, China Telecom, and China Unicom, with an interval of 30 minutes!

Data source: https://github.com/gacjie/cf2dns

Main function: When using cFvless, quickly generate 15 preferred nodes at once. There is no need to log in and enter them one by one each time. Combined with subscriptions, you can get multiple preferred IPs in one go!

For convenience, you can directly use the files cfip.txt and cf.txt!

The latest file updated in 2026: https://raw.githubusercontent.com/yuanxiawan/cfipv4db/refs/heads/main/high_score_ips.txt

These are clean IPs selected from scans run on our own server, mainly US-region VPS scans, so most of the IPs are from that region. The planned update frequency is every 15 minutes (provided that exceptionally high-quality IPs, ranking near the top by weight, are found and included)!…
