<h1 align="center">Pentect</h1>

</p>

</p>

Pentect is a local security boundary between supported AI clients and their
providers. Start with the [documentation](https://pentect.dev/).

## Repository guides

- [Compatibility](https://github.com/EdamAme-x/pentect/blob/HEAD/COMPATIBILITY.md)
- [Plugins](https://github.com/EdamAme-x/pentect/blob/HEAD/PLUGINS.md)
- [Security](https://github.com/EdamAme-x/pentect/blob/HEAD/SECURITY.md)
- [Contributing](https://github.com/EdamAme-x/pentect/blob/HEAD/CONTRIBUTING.md)
- [Third-party notices](https://github.com/EdamAme-x/pentect/blob/HEAD/THIRD_PARTY_LICENSES.txt)

> **Security scope:** Pentect does not protect a compromised operating system
> from malware with administrator privileges or an attacker that can read local
> process memory. It reduces unintended disclosure of sensitive data to AI
> providers.
