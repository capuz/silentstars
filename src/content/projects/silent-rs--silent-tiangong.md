# Silent-Tiangong

> A desktop-level AI automation hub for personal workflows: dialogue, planning, execution, memory, tool invocation, embedded browser, and multi-agent collaboration.

Tiangong is a personal intelligent terminal built on Rust, Tauri, and silent. It can be used as a desktop AI assistant or accessed via CLI and Server API for scripts, services, or external messaging channels. The core goal is not just to answer questions, but to enable the Agent to read materials, break down tasks, invoke tools, execute commands, save long-term memories, and dynamically create Sub Agents for collaborative work in complex tasks around a real workspace. Tiangong has a built-in embedded browser, allowing the Agent to autonomously open web pages, read page content, click elements, and fill out forms, while also perceiving user actions in the browser to achieve human-machine collaborative browsing. The project is fully compatible with DeepSeek's context caching mechanism, allowing historical messages in multi-turn dialogues to be efficiently cached, significantly reducing transmission costs and improving response speed.
