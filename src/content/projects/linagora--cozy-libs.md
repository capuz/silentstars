# Cozy libs

> Sharing Helpers for Cozy Application Development

## Libraries

- [Cozy Device Helper](https://github.com/linagora/cozy-libs/blob/HEAD/packages/cozy-device-helper): To know more information about the device platform
- [Cozy Doctypes](https://github.com/linagora/cozy-libs/blob/HEAD/packages/cozy-doctypes): Tools for working with shared doctypes
- [Cozy Flags](https://github.com/linagora/cozy-libs/blob/HEAD/packages/cozy-flags): Client side feature flags
- [Cozy Interapp](https://github.com/linagora/cozy-libs/blob/HEAD/packages/cozy-interapp): Allows applications to interact with each other
- [Cozy Realtime](https://github.com/linagora/cozy-libs/blob/HEAD/packages/cozy-realtime): Be notified via websocket when something happens on the Cozy
