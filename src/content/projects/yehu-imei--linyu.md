# 🚿 Shower (LinYu)

**⬇️ [Download linyu-v3.1.1](https://github.com/yehu-imei/linyu/releases/tag/v3.1.1)**

> Android supports Android 8.0+, arm64-v8a; the iOS main app requires iOS 16+, and the desktop widget requires iOS 17+
>
> **Slow downloads in China? Use the Gitee mirror** → [https://gitee.com/yehu-imei/linyu/releases](https://gitee.com/yehu-imei/linyu/releases) In-app update downloads also use the mirror by default

Third-party Android client for Quzhi Campus, used to control campus water heaters. Compared with the official app, it offers a cleaner interface and smoother operation

iOS standalone client: [GitHub repository](https://github.com/yehu-imei/linyu-ios) · [Gitee mirror](https://gitee.com/yehu-imei/linyu-ios) · [IPA releases](https://github.com/yehu-imei/linyu-ios/releases/tag/v3.1.1)

iOS packages must be self-signed to install. See the [installation tutorial](https://github.com/yehu-imei/Guides/blob/main/Tutorial/.ipa%E7%9A%84%E5%AE%89%E8%A3%85.md). To use the desktop widget, the app must be installed separately, and the widget extension and shared permissions must be kept
