## 📖 Project Introduction

**NanoAiCanvas_workflow** is a Workflow task workflow system built on an infinite canvas, focused on a visual, process-oriented node editing experience. The project draws inspiration from Figma's design philosophy, uses the Base Nova dark theme, supports full internationalization, and integrates powerful AI workflow features.

### Core Positioning

**🎯 Workflow task workflow system**
- Visual workflow design and execution
- 9 built-in node types (input, AI generation, decision, output)
- 4 preset workflow templates (storyboard, character design, scene design)
- Smart layout algorithm and topological sorting
- Real-time execution status tracking

**🎨 Infinite canvas editor**
- Professional node editor based on React Flow
- Smooth zoom, pan, and minimap navigation
- Smart snapping and alignment guides
- Custom node and connection line styles
