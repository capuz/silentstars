# TodayWaifu

> For the detailed configuration and usage guide, see: [TodayWaifu 完整使用指南与配置手册](https://blog.xlinxc.cn/posts/botplugin/todaywaifu-plugin-intro) (TodayWaifu Complete Usage Guide and Configuration Manual)

## 丨Installation Notice

> This plugin is an extension of [早柚核心 (gsuid_core)](https://github.com/Genshin-bots/gsuid_core) and requires the GsCore framework to be deployed first. After the first installation, GsCore must be restarted before the plugin takes full effect.

> [!NOTE]
> The plugin is still under continuous development. If you run into problems or have suggestions for improvement, feel free to submit an [Issue](https://github.com/MimoKit/TodayWaifu/issues), or join the discussion group **798949533**.

## 丨Installation Steps

- Prerequisite: [gsuid_core](https://github.com/Genshin-bots/gsuid_core) is already deployed.
- Clone this repository into the GsCore plugin directory, then restart:

```bash
cd gsuid_core/gsuid_core/plugins
git clone https://github.com/MimoKit/TodayWaifu
```

You can also send the following message to the bot:

```text
core安装插件TodayWaifu
```
