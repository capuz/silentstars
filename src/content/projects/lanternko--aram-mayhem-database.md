# arammeta

**League of Legends ARAM Mayhem（大亂鬥）data tool**

[Open arammeta](https://arammeta.com/) · [English](https://arammeta.com/en/) · [Simplified Chinese](https://arammeta.com/zh-cn/)

arammeta organizes real match data into hero, augment, and composition data to help players compare options. The site shows historical statistics for a specific patch and sample range, not guarantees of individual match outcomes.

## Windows Desktop Recommender Tool

[Download latest EXE](https://github.com/Lanternko/ARAM-Mayhem-Database/releases/latest/download/ARAMRecommender.exe) · [Download ZIP](https://github.com/Lanternko/ARAM-Mayhem-Database/releases/latest/download/ARAMRecommender-windows.zip) · [Versions and SHA-256](https://github.com/Lanternko/ARAM-Mayhem-Database/releases/latest)

Windows 10/11 x64; no Python installation required. Open the EXE directly, or extract the ZIP first and then run the EXE inside it. Each launch downloads the latest published program and data over the internet; if the download fails, the last complete dataset is kept. The program displays the data version, scope, and cutoff time.
