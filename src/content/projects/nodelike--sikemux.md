# Sikemux

**Own your software factory.**

`Open-source agentic infrastructure · MIT`

English · [简体中文](https://github.com/nodelike/sikemux/blob/HEAD/README.zh-CN.md) · [日本語](https://github.com/nodelike/sikemux/blob/HEAD/README.ja.md)

**Agents build and ship. You make the calls.** A project chief staffs and routes Claude Code, Codex and more across your laptops, servers and phone, with shared rules, peer review, real browser testing and release gates.

Native Rust app on the GPU, about 30 MB, using the plans you already pay for. Free and MIT for Apple Silicon Macs, Windows and Linux.

[sikemux.com](https://sikemux.com/?utm_source=github&utm_medium=readme) · [Docs](https://docs.sikemux.com) · [Discord](https://discord.gg/UKfmHpF9kX) · [X (@sikemux)](https://x.com/sikemux) · [App Store](https://apps.apple.com/app/sikemux/id6819588876)

## Install

```bash
curl -fsSL https://sikemux.com/install | sh
```

Or on a Mac with Homebrew:

```bash
brew install --cask nodelike/tap/sikemux
```

On Windows with [Scoop](https://scoop.sh):

```powershell
scoop bucket add sikemux https://github.com/nodelike/scoop-bucket
scoop install sikemux/sikemux
```
