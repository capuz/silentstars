# 磊毛TV（LEIMAOTV）

> An all-in-one **IPTV live + on-demand movies/TV** player for Android TV: one remote, one interface, so you don't need to install two apps for live TV and films.
> **Playback starts as soon as you open it** (it resumes the last channel directly), and search in the live section **only matches six content types** (live channels, movies, anime, TV series, sports, variety shows).

This project is written by one person in their spare time. Details on TV such as focus, key handling, and startup have to be polished one at a time. If you feel it saves you time, you can buy me a drink:
