# 🧩 OC Manager

> OpenCode All-in-One Workbench — Making AI Programming More Elegant

**OC Manager** is a carefully crafted [OpenCode](https://github.com/anomalyco/opencode) visualization management desktop application. Say goodbye to the command line and operate AI intuitively.

---

## ✨ Overview

### 🎯 All-in-One Workbench
Start services, manage sessions, browse project trees — **everything in one window**. Project tree on the left, conversation area in the middle, information panel on the right — classic three-column layout with perfectly balanced information density.

### 🎨 Elegant Chat Experience
User messages are right-aligned blue bubbles, AI replies are left-aligned cards. Reasoning processes, tool calls, and file operations are **intelligently collapsed**, expanding on demand. Full Markdown rendering with syntax highlighting for code blocks. **Desktop supports multiple conversation tabs in parallel**, with zero-lag switching and independent scrolling and rendering for each session.
