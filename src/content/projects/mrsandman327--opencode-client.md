# OC Manager

> OpenCode all-in-one workbench: making AI programming more elegant

**OC Manager** brings OpenCode's command-line operations into a handy desktop window: start services, manage sessions, browse projects, and edit configuration, all in one place. Supports OpenCode **v1 and v2**.

---

## What it can do

### One window, a clear workflow

- Left project tree, center conversation area, and right info panel: a three-column layout that is easy to follow
- Start services, switch sessions, and browse projects and files, all in the same window
- Multi-session tabs run in parallel on desktop. The top tab bar stays visible, each tab scrolls and renders independently, switching is smooth, and closing a tab releases its resources

### Clean conversations, key points stand out

- User and AI messages are laid out in separate columns
- Reasoning, tool calls, and file operations are collapsed by default; expand them when you want to see them
- Full Markdown rendering with syntax highlighting for code blocks
- Subtasks and to-do items are automatically extracted from sessions and presented in one place
- The command palette opens with the `/` key
