# MiniWorld-API-Desc

MiniWorld UGC Lua development API declaration library, code completion plugin, and auxiliary toolset.

> **It is no longer recommended to use declaration files for declarations; it is recommended to use the declaration plugin.**  
After installing this extension, execute the corresponding command by pressing `Ctrl+Shift+P` to automatically configure the declaration path without manual operation.
