# DSH Codex Style

A Codex desktop-style dark theme for **DeepSeek Harness (DSH)**.

Current version **0.2.1**, adapted for **Windows DSH 0.2.1-rc.2 / rc.3 / rc.4 / rc.5**.

## Features

This version additionally adapts to DSH 0.2.1-rc.4. Starting from 0.2.0, a DSH self-update button was added and rc.5 is supported. The installer can find DSH installed in other directories, and the Codex-style work guidelines now use the new prompt. The default switch for each optional submodule is unchanged, and upgrades keep existing selections.

- **Themed interface (main module)**: Codex-style navigation, a collapsible sidebar, and an input area. Supports project/session search and management, model and permission selection, a thinking-intensity slider with a MAX animation, session running/completed notifications, and this plugin's update check, automatic download, download progress, and confirmed installation. When a new DSH version is available, a blue update button appears above the gear icon in the lower-left corner. Hovering over it shows download progress.
