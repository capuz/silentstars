# DSH Codex Style

Provides Codex desktop-style light and dark themes for **DeepSeek Harness (DSH)**. Select light or dark in DSH's appearance settings to switch. When set to follow the system, the theme also follows system changes.

This package version **0.2.8** optimizes streaming display performance for body text, improves the progressive display of bold text, links, and inline code, and restores live reasoning expansion. The original copy and arrow interactions are retained. **Official DSH 0.2.2-rc.3 is recommended and has been verified.** The plugin does not refuse to install or load because the DSH version number is outside that range. UI compatibility with other versions depends on actual use.

The 0.2.7 stable release passed **242 automated checks** against the official DSH **0.2.2-rc.3** host resources, and verified navigation pin management, workspace layout, and browser-isolated interaction of the recent list. Beyond the recommended version, hands-on retesting has not been done for each release. Allowing loading means version-number gating does not apply.
