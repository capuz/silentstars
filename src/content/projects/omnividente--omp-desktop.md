# OMP Desktop

Independent desktop workspace for [Oh My Pi](https://github.com/can1357/oh-my-pi) — projects, sessions, and OMP terminals on Windows and Linux.

**[Русский](#русский) · [English](#english)**

## Русский

**OMP Desktop** is an independent open-source graphical client for [Oh My Pi](https://github.com/can1357/oh-my-pi). It brings project and session management, conversation history, and live OMP terminals together in one native application for Windows and Linux.

For people who want graphical access to projects and settings while keeping the familiar OMP workflow: live conversation runs through OMP's built-in terminal interface (TUI), not a separate graphical chat. This is a local desktop application, not a web client or a cloud-hosted service. OMP is installed separately.

**[Установка](#установка) · [Latest stable release](https://github.com/Omnividente/omp-desktop/releases/latest)**

> **Independent client:** the project is not part of the official OMP distribution. Desktop support is maintained in this repository; publication upstream does not imply endorsement by OMP. [Integration discussion →](https://github.com/can1357/oh-my-pi/issues/12456)
