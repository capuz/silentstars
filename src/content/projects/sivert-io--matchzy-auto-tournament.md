## ⚡ Quick Start (5 minutes)

### 1. Install Platform

```bash
# Clone and start
git clone https://github.com/sivert-io/matchzy-auto-tournament.git
cd matchzy-auto-tournament
cp example.env .env
docker compose up -d

# Open http://localhost:3069
```
