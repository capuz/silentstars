# Pixel VoLTE/5G Helper (Shizuku)

No root required. Uses [Shizuku](https://shizuku.rikka.app/zh-hans/) to enable carrier capabilities such as **VoLTE / VoNR / 5G (NSA+SA) / VoWiFi** on Google Pixel devices (including **Pixel 9 Pro XL**).

Intended for cases where Google has not certified 5G/VoLTE for the local carrier (for example, an international-version Pixel with a mainland China SIM has no VoLTE/5G toggle).
