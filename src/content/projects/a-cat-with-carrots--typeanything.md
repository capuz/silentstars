# TypeAnything

> **Type pinyin, land in any language, any circle, any style.**
> Type Chinese pinyin → press Enter → AI rewrites it as English / code-mixed Chinese-English for overseas students / financial-speak / academic prose / Hong Kong gangster-film dialogue / Klingon. Anything you can describe.

---

## This isn't just a translation input method. It's a **style input method**.

You type Chinese:

```
我们最近的项目数据不太好看，老板让我下周给个明确的方案
```

Switch the target and you get a **completely different tone**:

| Target | Result |
|---|---|
| `English` | Our recent project metrics aren't looking great. The boss wants a clear plan from me by next week. |
| `Overseas-student style` | Our recent project data is kinda ugly, and my boss wants a clear plan from me next week. |
| `Financial-speak` | The KPIs on this deal have underperformed recently, and management requires an actionable strategy memo to be delivered before next week. |
| `Internet buzzword-speak` | This project's data has been under some pressure lately. We need to align on an empowered, closed-loop playbook with clear levers before next week. |
| `Academic-grandiose English` | The project's recent metrics exhibit suboptimal…
