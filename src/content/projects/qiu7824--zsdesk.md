# ZSDesk

A Windows multi-tab file manager and desktop fences. Browse multiple folders in one window, organize files with dual panes, or group and store desktop files.

[Download and install](https://github.com/qiu7824/zsdesk/releases/latest) · [User guide](https://github.com/qiu7824/zsdesk/blob/HEAD/docs/user-guide.md) · [Changelog](https://github.com/qiu7824/zsdesk/blob/HEAD/CHANGELOG.md) · [Issue feedback](https://github.com/qiu7824/zsdesk/issues)

Applies to Windows 10 / 11, 64-bit. The current stable release is **0.3.15**; pending improvements on the main branch are listed under “Unreleased” in the changelog.

## Choosing a Version

| Edition | Best for |
|---|---|
| **Full edition** | Use when unsure; includes file management, network access, and desktop fences |
| Standard edition | File management, search, and preview only |
| Network edition | Standard edition plus FTP, SFTP/SSH, and network drives |
| Desktop edition | Standard edition plus desktop fences |
| Theme edition | Full features, adds Mica, acrylic, and light/dark materials; separate configuration |
| Standalone desktop box edition | Desktop organization only; excludes the file manager window and search |
