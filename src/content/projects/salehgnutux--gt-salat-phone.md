Phone version of the [GT-SALAT](https://github.com/SalehGNUTUX/GT-SALAT) desktop project, natively rebuilt in **Kotlin** with a **Jetpack Compose + Material 3 (Material You)** interface by **SalehGNUTUX**.

> The name inside the app remains **GT-SALAT**; the `PHONE` suffix in the repository name is only to distinguish it from the desktop version.

---

## ⬇️ Download

Latest package from the releases page:
**[Releases](https://github.com/SalehGNUTUX/GT-SALAT-PHONE/releases)**

The stable release is **`v2.1`** (the `foss` flavor). To install: enable "Install from unknown sources", then install the APK file. To ensure adhan notifications arrive, enable **battery exemption** from the reliability card in Settings.

**Two distribution paths:** the free `foss` build is downloaded **directly** from Releases and is available on **F-Droid** (with an in-app self-updater). The Google `full` build (more precise location) is distributed **exclusively** via **Google Play** (updates are handled through the store). Do not switch between the two paths without uninstalling and reinstalling (signature mismatch).
