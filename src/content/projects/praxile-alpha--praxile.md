## What is Praxile?

**Praxile** is an evaluation and evolution control plane for Agent Harnesses.

> **V2 boundary:** External Base Agents own planning, tools, and execution. Praxile owns normalized trace, evaluation, diagnosis, governed assets, policy candidates, promotion, and rollback. The P0 reference path is runnable and publicly documented; it is an engineering acceptance result, not a broad benchmark claim. See the [V2 P0 public result](https://github.com/Praxile-Alpha/Praxile/blob/HEAD/docs/V2_P0_PUBLIC_RESULT.md) and [frozen boundary](https://github.com/Praxile-Alpha/Praxile/blob/HEAD/docs/V2_P0_FROZEN_BOUNDARY.md).

The measured V2 reference system is **mini-SWE-agent as the Base Agent + Praxile as the Control Plane + SWE-bench as the evaluator**. Results belong to that…
