# Awesome Pi [](https://awesome.re)

[Browse the website](https://piindex.dev/zh/) · Search resources by category, read introductions, and copy installation commands.

> A curated list of community-maintained [Pi Coding Agent](https://pi.dev) packages. Pi is a terminal AI coding assistant developed by earendil-works, with a rich package ecosystem. The extensions, skills, and themes listed here are mainly published by community authors. Inclusion does not mean they are officially released or endorsed by Pi.

[Pi Coding Agent](https://pi.dev) is an AI Coding Harness framework whose package mechanism supports Extensions, Skills, Themes, and Prompt Templates. This list curates community packages to help developers build efficient AI-assisted coding environments.

```
# Install the Pi core CLI
curl -fsSL https://pi.dev/install.sh | sh

# Install a community package (example)
pi install npm:context-mode

# List installed Pi packages
pi list
```
