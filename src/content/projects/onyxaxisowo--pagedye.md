# PageDye

Official website: [pagedye.pages.dev](https://pagedye.pages.dev)

Set custom backgrounds for any website—solid colors, gradients, images, or dynamic effect wallpapers, saved independently by site, completely local, no tracking, no network requests.

Supports **Chrome / Edge / Brave** and other Chromium-based browsers, as well as **Firefox** (including Firefox for Android). Mobile/tablet users can use the streamlined **PageDye Lite** user script (Edge/Firefox on Android, Safari on iOS/iPadOS).

## Features

- **Multiple background types**: solid colors, linear/radial gradients, images (local files or URLs), or 16 types of dynamic effect wallpapers (Matrix rain, particles, aurora, snowflakes, typewriter effects, etc.)
- **Custom animation API** (v0.6, extended version only): Write your own Canvas animations in the settings page, preview in real-time, share the same density/speed/color controls as built-in effects, supports export/import sharing of individual animations, see [Custom Animation API Documentation](https://pagedye.pages.dev/custom-effects.html)
- **Frosted glass**: Add a frosted glass background to specified card/container elements, revealing the wallpaper…
