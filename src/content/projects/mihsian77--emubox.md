# EmuBox

> Download manager for drivers, components, and runtime libraries for Android and Windows emulation environments. Full Chinese interface, domestic download acceleration, and automatic device matching.

EmuBox is derived from [Rodrig02005/EmuHub-APP](https://github.com/Rodrig02005/EmuHub-APP) (MIT license, author Rodrigo Castro). On that base it redesigns the interface, resource directory, and download pipeline, targeting users of domestic (China) emulation environments such as Winlator / Eden / GameHub.

---

> Is GitHub rate-limiting APK downloads, or do you not want to install the app right now? You can use the [web version fallback](https://mihsian77.github.io/EmuHub/) (EmuHub navigation site, separate repository, archived and read-only) to download common drivers and components directly in your browser. The web version has limited features; for the full experience, use the app.

---

## Features

- **Driver section**: Turnip (Qualcomm Adreno), PanVK (ARM Mali), and Samsung Xclipse GPU drivers. Includes 48 built-in driver source records, categorized by GPU architecture, model, target platform, and maturity.
- **Component section**: Wine / Proton, Box64 / FEXCore /…
