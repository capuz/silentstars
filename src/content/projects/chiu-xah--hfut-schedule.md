# Juzai Gongda (HFUT-Schedule)

## Download
### Stable Release

> Versions distributed via F-Droid are re-signed (so they cannot be installed over versions from other channels as an update), and releases are slower, so not recommended;
> 
> GitHub releases include three APKs, for arm64, x86_64, and universal builds. Choose as needed (usually arm64);
> 
> Gitee releases only include arm64, and only the arm64 version supports incremental updates.

### [Development Build (Dev)](https://github.com/Chiu-xaH/HFUT-Schedule/releases/tag/Devevlop)
> For trying out features still in development. The APK is updated with every code push and does not represent the final stable release.

### Resource Packs (Optional)
- Image captcha recognition model (downloaded within the app, located under [Options - Preferences & Configuration - Automatic Image Captcha Filling])
> To reduce the APK size, the captcha recognition model (about 11MB) is split out and available as an optional download;
- Guest experience data pack (downloaded within the app, located under [Options - Preferences & Configuration - Backup & Restore])
> So that other developers can also try the app, a guest data pack is provided.…
