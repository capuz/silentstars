<h1 align="center">🚀 AirSend </h1>

<h2 align="center">🤔 What is this?</h2>

AirSend is a cross-platform interconnection tool designed specifically for **Mac + Android** users, with the core goal of: **making file transfer and clipboard synchronization as convenient as AirDrop, without needing two Apple devices.**

It consists of two parts:
- **macOS side**: a menu bar application developed natively in Swift, with a memory usage of about 20MB, no main window, drag and drop to send.
- **Android side**: optional selection - you can use the official LocalSend directly, or install the AirSend custom app for system-level deep integration.

> **Network requirements**: Both devices must be on the same Wi-Fi local area network, and the router must not have AP isolation enabled. By default, HTTPS is still preferred; if you are on a "network that can be discovered but hardly transmits" such as a campus/dormitory network, please refer to the `HTTP compatibility mode` below.
