# YikaiCMS v2.2.0

> **A lightweight PHP CMS for business and export websites** · Open source and free for commercial use

**[Live demo](https://demo.yikaicms.com)** · **[Download the latest version](https://github.com/bluesailor/yikaicms/releases/latest)** · **[Tutorial](https://www.yikaicms.com/tutorial.php)** · [Official site](https://www.yikaicms.com) · [Changelog](https://www.yikaicms.com/changelog.html)

**Simplified Chinese** · YikaiCMS (易开CMS) is a lightweight, multilingual, visual website builder for enterprises. It runs on native PHP and supports either MySQL or SQLite. Columns, products, news, cases, inquiry forms, and SEO, which most corporate websites need, are built in, so you don't have to install a pile of plugins. The frontend supports 18 languages (Simplified and Traditional Chinese, English, Japanese, Korean, Spanish, French, German, Russian, Arabic, and more; Arabic and Persian are laid out right-to-left). The admin interface is available in 18 languages (Simplified Chinese, English, and Japanese ship with the package; the others are downloaded on demand as signed language packs).
