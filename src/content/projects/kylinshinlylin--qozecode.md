## Project Introduction

QozeCode is a professional-level command line AI Agent built on the **LangGraph** architecture, achieving automated execution of complex development tasks through the **ReAct** (Reasoning and Acting) paradigm.

As a smart co-pilot for developers, QozeCode not only provides code generation and review capabilities but also directly interacts with the system Shell to perform file operations, system management, and web retrieval, with all operations presented in real-time in a modern TUI (Terminal User Interface).

### Core Highlights

- 🧠 **Intelligent Decision Engine**: ReAct reasoning framework based on LangGraph state diagrams, supporting Prompt Caching optimization
- 📋 **Plan Mode**: The `/plan` command generates structured execution plans with one click, automatically tracking task progress
- 🚀 **Subagent Parallel Scheduling**: Subagents execute independent tasks in parallel, with context isolation and automatic parallel scheduling by LangGraph
