# 🧵 RecallLoom

**Let the project remember itself.**

RecallLoom is a documented project memory layer for AI collaboration: it saves background, progress, key decisions, and next steps in Markdown / JSON files next to or within the project, without the need for a database, RAG, or backend services. Switching sessions, models, or tools makes it easier for the next AI collaboration to pick up the current state.

[English](https://github.com/Frappucc1no/recall-loom/blob/HEAD/README.en.md) · **Simplified Chinese**

> [!TIP]
> If you have been tormented by the "restart tax" of having to explain the project again after a while, RecallLoom's goal is straightforward: to keep the project status, key decisions, and next steps within the project, allowing the next AI collaboration to pick up where it left off.
