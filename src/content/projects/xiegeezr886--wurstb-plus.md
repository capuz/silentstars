**WurstB+ Plus** is a Minecraft client (utility mod) based on [Wurst](https://github.com/Wurst-Imperium/Wurst7) code structure. The same set of features is ported to **Forge / NeoForge / Fabric** three loaders and **22 Minecraft versions**, and is maintained with 64 independent Gradle projects.
