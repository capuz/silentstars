**WurstB+ Plus** is a Minecraft client (utility mod) that extends the code structure of [Wurst](https://github.com/Wurst-Imperium/Wurst7).
The same feature set is ported to the **Forge / NeoForge / Fabric** loaders across **23 Minecraft versions**, and is maintained as 67 independent Gradle projects.
