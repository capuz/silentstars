<h1 align="center">NewCatroid</h1>

  An extended version of <a href="https://github.com/Catrobat/Catroid">Catrobat/Catroid</a> — with support for 3D, AI, Qemu, Python, and more.

**Main improvements:**
*   **Extended 3D:** Support for 3D scenes, physics, post-processing, PBR, and a built-in 3D editor with ECS and hierarchy.
*   **Extended 2D:** Extension of Fast 2D, implementing work with 2D scenes with ECS and allowing the creation of hundreds and thousands of objects.
*   **AI Integration:** Ability to use neural network models (import `.onnx`), access to the Gemini API, and a custom framework for working with tensors called PockeTensor.
*   **Networking Features:** Ready-made tools for working with Firebase, local servers, and the internet in general.
*   **Git Integration:** Ability to develop projects together using Git.
*   **Libraries:** Creation of custom blocks and formulas in the LunoScript language.
*   **Plugins:** Customization of the main interface.
*   **Qemu:** Emulation of x86_64 directly through blocks. (ARM64)
*   **Python 3.12:** Full Python 3.12, ability to install libraries via pip (ARM64)
