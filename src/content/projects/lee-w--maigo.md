# Maigo

Docs: https://lee-w.github.io/maigo/

> "Even if you get lost" — it's okay to become lost.
>
> — "BanG Dream! It's MyGO!!!!!"

Maigo is a multi-agent general development workflow (Claude Code / Codex plugin) based on the five members of **MyGO!!!!!**.

Engineers often feel lost — stuck in debugging, unable to find entry points during refactoring, unsure how to break down a PR. Maigo maps the personality traits of the five members to development roles, allowing you to be guided back on track even when you feel lost.

## Role Mapping

| Member | Personality | Development Role | Main Responsibility |
|--------|-------------|------------------|---------------------|
| **Raana** | Mysterious, seemingly spaced out but highly observant | Explorer | Explore codebase, find clues |
| **Tomori** | Poet, structures chaos into narrative | Planner | Design strategies, write implementation plans |
| **Anon** | Lively promoter, never gives up | Implementer | Write code, implement features |
| **Soyo** | Perfectionist, obsessed with details | Reviewer | Code review, auditing |
| **Taki** | Sharp-tongued, direct, action-oriented | Verifier | Run tests, validate results |
