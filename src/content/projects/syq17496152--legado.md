# Legado（阅读M）

[English](https://github.com/syq17496152/legado/blob/HEAD/English.md) | Chinese

**Open-source Android e-book reader**

Custom source rule engine | Five parsing methods: CSS / JSONPath / XPath / Regex / JS

**All-in-one content reader**: read text, comics, image feeds, and videos in one app — no account, no ads, and data stays only on your device.

---

## Main Features

- **Custom sources** — Set your own rules to scrape web data. The rules are simple and easy to understand, and the app includes built-in rule documentation
- **Bookshelf management** — Freely switch between list and grid bookshelves
- **Search & discovery** — Source rules support search and discovery; finding and reading books is fully customizable
- **Feeds** — Subscribe to any content you want, via RSS or web pages, with a built-in video player
- **Replacement & cleanup** — Remove ads and replace content with one-tap cleanup
- **Highlight rules** — Automatically highlight regex/literal matches in 9 styles; supports manual underline annotations
- **Local reading** — Supports TXT and EPUB, with manual browsing plus smart scanning
- **Deep customization** — Font, color, background, line spacing,…
