# aureliendupaysdexemple.com

> NOTE: My personal website is my breakable place where I test patterns and technologies. Some part of the code may not work at some point.

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **UI**: [shadcn/ui](https://ui.shadcn.com/)
- **UI VFX**: Inspiration from [ Aceternity UI](https://ui.aceternity.com/) & [Magic UI](https://magicui.design/)
- **MDX and Markdown**: Inspiration from [Vercel Blog Example](https://github.com/vercel/examples/tree/main/solutions/blog)
- **Deployment**: [Vercel](https://vercel.com)

## Running locally

This project has been implemented with Node.js v21.7+ and pnpm v11.10+

```bash
git clone https://github.com/SugarDarius/aureliendupaysdexemple.git
pnpm install
pnpm dev
```
