# olua

> [English](https://github.com/WebCoderT/olua/blob/HEAD/README.en.md) | Simplified Chinese

> **A learning project written entirely by AI (Vibe Coding)**: every line of code in this repository was written by AI. Humans only supply requirements and review the results.
> **Not a game ready for live operation.** It is a project where a few developers and AI practitioners came together to learn and research.

A 2D character progression and equipment gameplay prototype built on Cocos Creator 3.8.7, with a companion NestJS server and React admin dashboard. The three parts together run login, account creation, progression, equipment, map exploration, and combat.

**Free and open source. Anyone can deploy their own copy.** Publicly accessible live instances:

| Address | What it is |
| --- | --- |
| <http://yimw.cn> | Official website (project overview / data flow / engineering management / design approach / deployment) |
| <http://game.yimw.cn> | Game client (web version, playable right away) |
| <http://admin.yimw.cn> | Operations admin dashboard |
