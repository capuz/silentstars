# olua

> [English](https://github.com/WebCoderT/olua/blob/HEAD/README.en.md) | Simplified Chinese

> **A purely AI-written learning project (Vibe Coding)**: every line of code in this repository was written by AI. Humans only provide requirements and check the results.
> **Not a game ready for live operation.** It is a project where a few developers and AI enthusiasts came together to learn and research.

A 2D character growth and equipment gameplay prototype built on Cocos Creator 3.8.7, with a companion NestJS server and React admin backend. The three ends together run login, account creation, growth, equipment, map exploration, and combat.

**Free and open source. Anyone can deploy their own copy.** There are publicly accessible live instances:

| --- | --- |

| <http://game.yimw.cn> | Game client (Web version, playable right away) |
| <http://admin.yimw.cn> | Operations admin backend |
