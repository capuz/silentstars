## Overview

NTUST Freshman Survival Pack is a freshman guide jointly maintained by students.

It gathers the issues freshmen most often run into, such as course selection, housing, and daily life. It is maintained as open source, so anyone can contribute.

### **Contents**
- **Course Selection**: from understanding the terminology to practical application
- **Campus Life**: housing, meals, transportation, clubs
- **Information**: campus accounts, tuition payment, useful tools, communities
- **Other**: common freshman questions, NTUST trivia

### **Features**
- **Department-specific content**: shows advice from direct upperclassmen in each department
- **Academic calendar**: taken from [NTUST calendar](https://www.academic.ntust.edu.tw/p/404-1048-78935.php)
- **Anyone can edit**: articles are plain Markdown text files that can be corrected directly on the GitHub web interface
