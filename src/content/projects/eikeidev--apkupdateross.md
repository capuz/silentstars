# APKUpdater OSS

**Open-source update manager for Android apps from independent stores and git repositories**

---

**APKUpdater OSS** helps you find, download, and install updates for Android apps without being tied to a single store. The app polls selected sources in parallel, groups identical updates into a single card, and lets you precisely control where and which versions are installed.

The project is a heavily reworked fork of the original [APKUpdater](https://github.com/rumboalla/apkupdater) by [rumboalla](https://github.com/rumboalla). The app uses the package identifier `com.apkupdateross`, so it can be installed alongside the original version. Smartphones, tablets, and Android TV devices are supported.
