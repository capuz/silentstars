# TG Challenge Bot

**AI anti-spam bot for Telegram — challenges with topic generation on Cloudflare Workers, free serverless.**

## ✨ Features

- 🏘️ **Multi-community**: one bot serves up to 10 groups
- 📅 **Three challenge types**: daily, weekly, monthly
- 🗳️ **Topic voting**: AI generates options, participants choose
- 🎨 **Easy participation**: just send a picture in the challenge topic
- 🔗 **Link previews**: optionally accepts links as entries
- ⭐ **Reaction counting**: automatic counting (🌚 is not counted)
- 🏆 **Leaderboard**: ranking of winners (separate for each group)
- 🚫 **Anti-plagiarism**: forwarded images are not accepted
- 🧠 **Smart AI**: does not repeat topics (remembers the last 50)
- 💡 **Topic suggestions**: participants can suggest their own topics
- 🎭 **Content modes**: vanilla / medium / nsfw
- ☁️ **Serverless**: runs on Cloudflare Workers (free!)
- 🎛️ **Web admin panel** (optional, in [`admin/`](https://github.com/timoncool/tg-challenge-bot/blob/HEAD/admin/)) — manage AI/schedule/texts without redeploying code
