## Download and Installation

Please download the latest stable version from [GitHub Releases](https://github.com/LYOfficial/USTBL/releases). The current official distribution targets Windows 10/11. The release page provides installer and portable versions for each architecture:

| Package type     | Use case                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| `*_setup.exe`    | Recommended for most users. Installation and uninstallation are handled by the installer.                 |
| `*_portable.exe` | No installation required. Suitable for portable storage devices or when you don't want to write to the install directory. |

Choose the build that matches your system architecture (common PCs use `x86_64`; for Windows on ARM, choose `aarch64`). After downloading, double-click to run. If Windows reports that WebView2 is missing, first install [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) and then restart the launcher.
