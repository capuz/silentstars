## Download and Installation

Please download the latest stable version from [GitHub Releases](https://github.com/LYOfficial/USTBL/releases). Current official distribution targets Windows 10/11, and the release page provides installer and portable versions by architecture:

| Package Type     | Use Case                                                   |
| ---------------- | ---------------------------------------------------------- |
| `*_setup.exe`    | Recommended for most users; installation and uninstallation completed by the installer. |
| `*_portable.exe` | No installation required; suitable for portable storage devices or scenarios where you don't want to write to the installation directory. |

Please select the build corresponding to your system architecture (common computers use `x86_64`; for Windows on ARM, select `aarch64`). After downloading, simply double-click to run. If Windows indicates WebView2 is missing, first install [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) and restart the launcher.
