# Eventiva

Eventiva is an open-source platform for event planning and production logistics. After the full reset in [EVE-242](https://linear.app/resnovas/issue/EVE-242), the repository holds the fresh application foundation from [EVE-244](https://linear.app/resnovas/issue/EVE-244): a PNPM and Nx workspace with an Effect backend shell, an Expo client and the `@eventiva/contracts`, `@eventiva/schema` and `@eventiva/runtime` packages, with tests and smoke runs. **It has no product features yet.** Read [the foundation guide](https://github.com/Resnovas/Eventiva/blob/HEAD/docs/foundation.md). House governance, security and synchronization workflows are enrolled under [EVE-243](https://linear.app/resnovas/issue/EVE-243); release workflows remain inert without a release configuration.

The sections from here to [Rebuild order](#rebuild-order) restore the project introduction and mission from the [historical README](https://github.com/Resnovas/Eventiva/blob/HEAD/examples/eventiva-before-amp/README.adoc). They describe what Eventiva sets out to become. **None of the features they name is implemented in this repository today.**
