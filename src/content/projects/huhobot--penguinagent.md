# HuHoBotPenguin

Integrate QQ group bot into Minecraft server: bidirectional game chat and QQ group forwarding, whitelist management, online queries, command execution, sensitive word review, **AI Agent intelligent management** and **WebUI graphical configuration**.

The most aggressive and fast-updated, feature-complete branch of [HuHoBot-Penguin](https://github.com/HuHoBot/PenguinClient)

Based on [qqpd-bot-java](https://github.com/Kloping/qqpd-bot-java) (HuHoBot fork, introduced as git submodule).

---

## Feature Overview

| Feature | Description |
|---------|-------------|
| Bidirectional Chat Forwarding | Game ↔ QQ group messages in real-time synchronization, supports format templates and prefix filtering |
| QQ Group Command System | 30+ built-in commands, supports permission levels, command toggles, and dynamic help |
| Whitelist Management | Maps to native server commands, supports custom templates |
| Sensitive Word Review | Local regex word library + optional OpenAI-compatible interface AI secondary review |
| MOTD Server Status | `/motd` query server status, returns image + Markdown card |
| Custom Commands | Placeholder substitution, supports permission levels…
