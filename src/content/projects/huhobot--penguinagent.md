# HuHoBotPenguin

Connects QQ group bots to Minecraft servers: bidirectional forwarding between in-game chat and QQ groups, whitelist management, online player lists, command execution, sensitive-word moderation, **AI Agent intelligent management**, and **WebUI graphical configuration**.

[HuHoBot-Penguin](https://github.com/HuHoBot/PenguinClient) is the most aggressively and rapidly updated fork, with the most complete feature set.

Built on [qqpd-bot-java](https://github.com/Kloping/qqpd-bot-java) (HuHoBot fork, included as a git submodule).

---

## Feature Overview

| Feature | Description |
|------|------|
| Bidirectional chat forwarding | Real-time message exchange between game and QQ groups, with format templates and prefix filtering |
| **MiniMessage colors** | Group-to-game messages support `<gold>`, `<#FFAA00>`, `<bold>`, `<gradient>`, and are also compatible with `&6` / `§6` |
| **Server status notifications** | Push reminders to QQ groups on shutdown / restart / unexpected closure; messages can be customized |
| QQ group command system | 30+ built-in commands, with permission levels, command toggles, and dynamic help |
