# WKAppBot — Computer Use, App Use, AppBot

> ▶ **[전체 영상 보기 →](https://kiexpert.github.io/wkappbot-sdk/)**  ·  Sudo 라이선스로 이런 봇을 만들 수 있습니다

**Windows + Android UI automation for Claude, GPT, Gemini, Copilot, and any AI agent.**
Focusless. Self-healing. AI-native. The open-source bridge between LLMs and the apps humans already use.

> 🧠 **NEW — [Wisdom Kernel AppBot Code (`wkappbot-code`) →](https://github.com/kiexpert/wkappbot-sdk/blob/HEAD/docs/wkappbot-code/README.md)**
> **An AI coding agent built on the Wisdom Kernel (= Wisdom Reflex Driver), wired to an a11y-linked harness and A11Y QA.**
> Reflex guards refuse a bad tool call before it runs, and every refusal names the skill that fixes it. A11Y QA clicks and reads the real app through its accessibility tree, so a passing test means the screen works.
>
> ```sh
> npm i -g wkappbot-code
> ```
>
> The first `wkappbot-code` run finishes the setup once (the health check and the selftest run in the background) and prints the result; the package ships no npm install script. Then set a model with `wkappbot-code config`.
