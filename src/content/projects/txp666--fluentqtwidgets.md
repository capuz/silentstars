FluentQtWidgets is a Fluent Design-style control library for C++/Qt Widgets. It includes reusable controls, standalone examples, and a complete Gallery application.

This project is the **C++/Qt Widgets port** of the Python [PyQt-Fluent-Widgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets). The original Python version is the behavioral and visual baseline for this repository. Control states, spacing, QSS constants, example content, resource paths, Gallery page structure, and translations are aligned with the upstream implementation wherever possible. Necessary adjustments are kept only where Qt/C++ platform behavior differs.
