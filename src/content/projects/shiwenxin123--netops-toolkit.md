# NetOps Toolkit v4.0 - Network Operations Toolkit

A powerful **multi-vendor network device configuration generator** with a modern interface, supporting **Huawei/H3C/Ruijie/Maipu/ZTE switches**, **ZTE ROSNG**, **ZTE OLT**, **DPtech FW1000 firewalls**, and **H3C SecPath load balancers**, with **11+ built-in network tools**, developed with Python + PyQt5.

## What's New in v4.0

### 🎨 Tech-Inspired UI Design
- **Dark gradient theme** - purple-blue gradient background, cyberpunk style
- **Glowing border effect** - neon blue highlights, very high-tech feel
- **Adaptive window** - automatically adapts to different screen sizes
- **Modern controls** - gradient buttons, glassmorphism cards

### 🔄 Multi-Vendor Device Support
- **Huawei** - 248 commands + 8 configuration examples
- **H3C** - 239 commands + 9 configuration examples
- **Ruijie** - 284 commands + 10 configuration examples
- **Maipu** - 229 commands + 8 configuration examples
- **ZTE** - ZXR10 5200/5900/8900 classic ZXROS configuration generation (basic, VLAN, routing, ACL, aggregation)
- **ZTE ROSNG** - ZXR10 5960/9900 next-generation ROSNG configuration generation (VLAN, Access/Trunk, SSH, smartgroup, static routing)
