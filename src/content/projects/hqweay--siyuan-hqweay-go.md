# Dinosaur Toolbox

> This is a dinosaur, and passersby must praise its cuteness.🦖
>
> Dinosaur Toolbox is an enhancement plugin for Siyuan Note, utilizing a modular **Sub-Plugin automatic registration mechanism** to highly integrate various independent practical functions.

---

## 🛠️ Core Features Overview

Currently, Dinosaur Toolbox includes **22** independent sub-plugin functions, covering various scenarios such as daily editing, multi-device synchronization, layout optimization, reading annotations, and view conversion.

### 🌟 Key Core Features

#### 1. 📂 Enhanced Backlink Panel ([lets-syplugin-backlink-panel](https://github.com/hqweay/siyuan-hqweay-go/blob/HEAD/src/lets-syplugin-backlink-panel))
*Enhanced based on `Misuzu2027/syplugin-backlink-panel`*
- **Custom SQL Display**: Supports custom SQL query results display in the backlink panel.
- **Tab Persistence**: Remembers the last opened tab in the document and automatically opens it the next time you enter that document.
- **Document Flow Optimization**: Enhances the user experience of browsing document flow.
