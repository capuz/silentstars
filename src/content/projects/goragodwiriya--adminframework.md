# Now.js Admin Framework

**Base project for building admin back-office systems**, not a library to install on top of an existing project. It is a working system that is ready to use as soon as it is installed. Copy the whole project as the start of a new job, then write only the "modules" for that job. The parts every system needs, namely members, permissions, settings, language, and security, are already included.

Version 7.0.3 · PHP 7.4+ · MIT License

> **English** — A ready-to-run admin base built on [Now.js](https://nowjs.net)
> (HTML-first front-end) and [Kotchasan](https://www.kotchasan.com) (PHP back-end).
> Copy the whole project to start a new system, then write only your own modules:
> authentication, users, permissions, settings, i18n, PWA and the UI toolkit are
> already in place. Documentation is in Thai.

## Why it is a "base" and not a library

Every back-office system needs the same set of things: signing in, resetting forgotten passwords, user permissions, website settings, sending email, multiple languages, tables that can be searched, sorted, and paginated, and forms that validate values for you.
