# Now.js Admin Framework

**A base project for building back-office systems**, not a library to install on top of something else.
It is a system that works in practice as soon as installation is finished. Copy the whole project as a new job,
then write only the "modules" for that job. The parts every system needs in common (members, permissions,
settings, language, security) are already included.

Version 7.0.3 · PHP 7.4+ · MIT License

> **English** — A ready-to-run admin base built on [Now.js](https://nowjs.net)
> (HTML-first front-end) and [Kotchasan](https://www.kotchasan.com) (PHP back-end).
> Copy the whole project to start a new system, then write only your own modules:
> authentication, users, permissions, settings, i18n, PWA and the UI toolkit are
> already in place. Documentation is in Thai.

## Why it is a "base" and not a library

Every back-office system always needs the same things: signing in, resetting forgotten passwords, user permissions,
website settings, sending email, multiple languages, tables that can be searched, sorted and paginated, and forms that check values for you.
If you start from scratch every time, you lose time rebuilding these existing…
