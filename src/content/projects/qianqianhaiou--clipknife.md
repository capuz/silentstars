# ClipKnife (素刀)

> Find every frame of inspiration scattered across your hard drives with a single sentence
>
> Chinese | [English](https://github.com/qianqianhaiou/ClipKnife/blob/HEAD/README.en.md)

ClipKnife is a natural-language asset management and search tool for Windows, built for creators. Add assets spread across folders, drives, and external hard drives to the asset library. After local indexing is complete, you can search for images or video clips by describing the visuals, then return to the original files to verify, organize, and use them.

**This repository is used for the official website, user manual, changelog, and issue feedback. It does not contain the desktop app's source code.** To use the software, download it from the official website. You do not need to clone this repository or set up a development environment.
