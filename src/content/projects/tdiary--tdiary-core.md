## tDiary, a Web diary system that allows TSUKKOMI

tDiary is open-source software that enables a web diary (commonly known as a blog). It is a tool for those who want to operate their own web diary instead of renting a blog service.

tDiary has the following features:

### You can keep a diary for a long time

A diary is an important personal history. To ensure that you can safely continue writing your diary for a long time, tDiary aims to maintain the project for at least 25 years. As of 2016, it is the 15th anniversary, so you can continue writing your diary with tDiary for another 10 years.

### User-friendly for rental server users

All you need is Ruby (compatible with 3.1 and later). It operates as a standalone CGI and does not require a database or additional libraries for basic functionality.

### Can be extended with plugins

You can add various features with a rich set of plugins. Most of the necessary features for a blogging tool are available as plugins.
