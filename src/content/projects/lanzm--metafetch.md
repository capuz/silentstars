# 🚀 MetaFetch Proxy Aggregator

MetaFetch is a high-performance automated proxy node aggregation tool. It can automatically crawl, clean, and classify nodes from global public channels, providing out-of-the-box advanced diversion configuration files for Clash (Mihomo).

> [!IMPORTANT]
> **Statement:** This project is modified from [peasoft/NoMoreWalls](https://github.com/peasoft/NoMoreWalls) and has been deeply customized based on it, enhancing asynchronous crawling, YAML configuration management, and regional automatic grouping logic.
