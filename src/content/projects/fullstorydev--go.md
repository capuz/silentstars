# go
General purpose utility libraries for Go.  Low dependency.
- [eventstream](https://github.com/fullstorydev/go/blob/HEAD/eventstream) is a fast, efficient way to publish and subscribe to events within a Go process.
- [errgroup](https://github.com/fullstorydev/go/blob/HEAD/errgroup) is a safer alternative to the official [golang.org/x/sync/errgroup](https://pkg.go.dev/golang.org/x/sync/errgroup) package.
