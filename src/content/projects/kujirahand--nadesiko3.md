# Japanese Programming Language "Nadesiko 3"

## What is "Nadesiko 3"

"Nadesiko 3" is a Japanese programming language. It is developed with the motto "Easy programming for everyone." Japanese programming languages are characterized by being easy to read and understand, and you can enjoy learning to program even if it's your first time. For Japanese speakers, it is also ideal for programming education in their native language! Also, Nadesiko was originally developed as a tool for business improvement, so it is also good at easily writing routine processing and batch processing. It can be used for games, tools, and various purposes.

- [Nadesiko Website](https://nadesi.com/)
- [Manual](https://nadesi.com/v3/doc/)

For those trying Nadesiko for the first time, we recommend starting with the following tutorial. You can easily understand the atmosphere of Japanese programming language.
