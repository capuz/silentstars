# Japanese Programming Language "Nadesiko 3"

## What is "Nadesiko 3"

"Nadesiko 3" is a Japanese programming language. It is developed under the slogan "Easy programming for everyone."
Japanese programming languages are known for being easy to read and understand, so even first-time learners can enjoy learning to program.
For Japanese speakers, it is also ideal for programming education in their native language!
Also, Nadesiko was originally developed as a tool for business process improvement, so it excels at easily writing routine and batch processing tasks. It can be used for games, tools, and many other purposes.

- [Nadesiko Website](https://nadesi.com/)
- [Manual](https://nadesi.com/v3/doc/)

If you are trying Nadesiko for the first time, we recommend starting with the following tutorial. You can easily get a feel for the Japanese programming language.
