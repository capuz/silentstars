# Ruoyi-Scan — RuoYi-specific vulnerability scanning tool

[中文](https://github.com/xiabai2008/ruoyi-scan/blob/HEAD/README.md) | [English](https://github.com/xiabai2008/ruoyi-scan/blob/HEAD/README_EN.md)

> A **RuoYi (RuoYi) dedicated vulnerability scanner** for legally authorized use, with a plugin-based architecture and three-state verdicts (CONFIRMED / SAFE / UNKNOWN).
> Supports batch scanning, multi-format reports, WAF bypass (including an adversarial transport layer), exploit chains, Web API and other enterprise-grade features.
> **The desktop app is now available** — a single exe, double-click to run, with no Python / Docker / environment setup needed.
