# VK Cloud Documentation

This repository stores the [public VK Cloud documentation](https://cloud.vk.ru/docs). You can suggest edits or make them yourself.

## Suggest changes

If you notice a typo or error in the documentation, or want to expand a section, you can suggest changes in two ways:

- Open an Issue and write your comments and suggestions. We will consider implementing them and let you know the decision.
- Open a Pull Request and propose your additions and corrections yourself (more details in the file [how-to-contribute.md](https://github.com/vk-cs/docs-public/blob/HEAD/guides/how-to-contribute.md))

To suggest changes, you must read the “Contributor License Agreement” and confirm your consent to its terms. Detailed information on how to do this, and links to the text of the Agreement, are given in the file [CONTRIBUTING.md](https://github.com/vk-cs/docs-public/blob/HEAD/CONTRIBUTING.md).
