# multiverse

The sites of Griko Nibras and the Sanity CMS that feeds them.

- **[nibras.co](https://nibras.co)**: the blog, work, resume and photos, with Markdown and MCP access for AI tools.
- **archive.nibras.co**: every past version of the site, rebuilt in its original design.
- **nbr.st**: short links.
- **`npx grikomsn`**: the home page as a card in a terminal.

This repository held each earlier version of the site from 2018 on. The archive app now rebuilds all of them in one place. [docs/legacy](https://github.com/grikomsn/multiverse/blob/HEAD/docs/legacy/README.md) tells the history of each version. The `legacy/*` tags keep the source of each old version: `legacy/v2` to `legacy/v9`.
