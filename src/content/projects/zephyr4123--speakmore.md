Open-source, free voice input and translation tool for macOS and Windows.<br>
  Voice input, voice translation, and selection translation, each triggered by its own hotkey and available in any app.<br>
  Compatible with mainstream large models. Voice input can also run entirely on your machine.<br>

## Three Features

All three features start with the right ⌥ (on Windows, the right Alt): a single press is voice input, adding Space is voice translation, and adding Enter is selection translation.

| Feature | Purpose | macOS | Windows |
| --- | --- | --- | --- |
| 🎙️ **[Voice Input](#️-语音输入)** | Dictate, and get fluent text written at the cursor | Right ⌥ | Right Alt |
| 🌐 **[Voice Translation](#-语音翻译)** | Speak one language and write out another | Right ⌥ + Space | Right Alt + Space |
| 📖 **[Selection Translation](#-划词翻译)** | Select any text, and the translation appears below the selection | Right ⌥ + Enter | Right Alt + Enter |

### 🎙️ Voice Input

- Press the hotkey to start dictating, press it again to stop, and the text is written at the current cursor position.
- Automatically removes filler words, repetitions, and self-corrections (direct output and mixed modes).
