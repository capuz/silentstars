# Resolution Support
Script development resolution is 720 * 1280. Both landscape and portrait orientations at this resolution are compatible. For the compatibility principles of other resolutions, see the anchor point color comparison and multi-point color finding mentioned in the README at <https://gitee.com/yiszza/ScriptLib>. Coordinate points obtained from the development resolution will be scaled and shifted once on the runtime resolution, but other resolutions have not been tested. Since most real devices currently have notch screens, Onmyoji has special optimization for notch screens, which causes almost all notch screens to not support anchor point color comparison for Onmyoji's multi-resolution compatibility. It is recommended to use with a virtual machine or cloud phone.
