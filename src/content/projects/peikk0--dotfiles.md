# Dotfiles

This repository contains my dotfiles, or my `~/.config/` directory to be exact.

They can be installed using [yadm](https://yadm.io/):

```sh
yadm clone https://gitlab.com/peikk0/dotfiles.git -w ~/.config --bootstrap
```
