# 鳩bot - 愛嬌のあるBot

You can mainly do the following with 鳩bot.

- Rain cloud information ... Displays rain cloud information as an image for the place name or address [text] specified with `amesh [text]`.
- Latest earthquake information ... Displays the 3 most recent earthquake reports with `eq`.
- Registering and displaying power words ... Displays power words registered with `text`.
- Formatting in a "sudden death" speech bubble ... Formats the string [text] in a "sudden death" speech bubble with `>< [text]`.

## Running 鳩bot

鳩botは自分のPC上で動かすことができます。
