> **Deeptask 9.3.6** History commands are collapsed by default: only the current last command is auto-expanded, and history lines use `txt` to skip Shiki. Diff highlighting uses the same skip gate and no longer builds a token tree per hunk. A second parallel conversation no longer pushes the first one out of the main repo. Live command buttons for isolated parallel conversations: `commandExecutionStatus` no longer bypasses the focus gate to overlay Continue/Terminate on top of the foreground Cancel (fail-closed when `taskId` is missing). The chat body is one continuous Virtuoso list holding the full history and covering all saved rows; scroll position carries over, and it no longer pages with a 64-line sliding window. History rows keep a 120-character preview, the latest 64 rows are truncated at 8k, and up to 4 images are shown; disk and model I/O are still full text. In-place `messageUpdated` replacement also re-projects the transcript.
