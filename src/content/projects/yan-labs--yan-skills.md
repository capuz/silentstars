# yan-skills

Agent Skills for people doing SEO and indie development. **Building sites, picking keywords, getting backlinks, checking data, and reviewing and iterating**. The whole pipeline lives in this repo, and it runs as soon as you install it.

By [Yan](https://github.com/yan-labs). Polished for personal use and tested in practice. Compatible with Claude Code, Codex CLI, Cursor, and any platform that reads `SKILL.md`. MIT license, so take it and use it freely.

```bash
npx skills add yan-labs/yan-skills -g --all
```

---

## What problem this solves

A person running a standalone site typically spends a day like this:

In the morning they want to start a new direction, so they first check whether the keyword has search volume and how hard it is to rank for. Tool websites charge two hundred dollars a month, which is too expensive, so they open a dozen tabs and compare by hand. At noon they settle on a keyword and start building the site: scaffolding, Cloudflare, domain, GA, GSC. The whole process takes two days, and next time they build a site they go through it again and hit the same pitfalls. In the afternoon they need backlinks, so they dig up a "500 free backlink sites"…
