# yan-skills

Agent Skills for SEO and indie developers. **Building sites, choosing keywords, getting backlinks, checking data, and reviewing and iterating.** The whole pipeline is in this repo, and it's ready to run once installed.

By [Yan](https://github.com/yan-labs). Battle-tested for personal use and verified to work. Compatible with Claude Code, Codex CLI, Cursor, and any platform that reads `SKILL.md`. MIT licensed, so use it freely.

```bash
npx skills add yan-labs/yan-skills -g --all
```
