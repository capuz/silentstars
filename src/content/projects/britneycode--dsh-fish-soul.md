# dsh-fish-soul

Gives a QQ alt account one consistent person behind it: a fixed persona, memory kept per person, its own daily rhythm, and it initiates conversations. The same 'her' appears on QQ, Bilibili, and Douyin.

DSH plugin (single character `feiyu`). Version **0.18.21**.
