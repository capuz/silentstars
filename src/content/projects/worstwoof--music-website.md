# 🎵 星乐 (Space Music) - Immersive Music World

Welcome to “星乐”, a feature-rich, visually stunning modern music web application.

This project is a complete, immersive music experience from onboarding to playback. It consists of three core parts:

1.  **Start screen (`start.html`)**: a product onboarding page featuring full-screen scrolling and rich animations (meteors, butterflies, blooming flowers).
2.  **Feature homepage (`index.html`)**: a modern music discovery homepage integrating WebGL, GSAP animations, and the View Transitions API.
3.  **Music player (`music-player.html`)**: a fully featured user center and an immersive player with dual audio/video (MV) core synchronization.
