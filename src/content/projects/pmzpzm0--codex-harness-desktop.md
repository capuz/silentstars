# Codex Harness Desktop

A standalone desktop workbench that packages the OpenAI Codex engine into a true desktop application: multi-session task management, visual diff review, built-in automation tools, a plugin/skill/connector ecosystem, and expert team collaboration. It works out of the box and does not require using the command line.

## ☁️ Codex Harness Cloud (Cloud Edition)

The **cloud form** of the same desktop experience. Open [ppz123.asia](https://ppz123.asia) in a browser and log in. Together with a local assistant, you can access **the assistant on your computer** from any device. Sessions and data stay local; the cloud only handles account and interface distribution.

- **Web version**: no installation required, open and use in any browser
- **Desktop client**: [Cloud assistant client download](https://github.com/PMZPZM0/codex-harness-cloud-src/releases/latest) (Windows installer + macOS for both architectures). Double-click to use; it stays resident and starts with the system
- **Real-time push**: messages and events are all delivered via SSE push, not polling
