# Codex Harness Desktop

A standalone desktop workbench that packages the OpenAI Codex engine into a true desktop application: multi-session task management, visual diff review, built-in automation tools, a plugin/skill/connector ecosystem, and expert team collaboration. It works out of the box without touching the command line.

## ☁️ Codex Harness Cloud

The **cloud edition** of the same desktop experience. Open [ppz123.asia](https://ppz123.asia) in a browser and log in. Together with a local assistant, you can access **the assistant on your own computer** from any device. Sessions and data stay local; the cloud only handles account management and interface distribution.

- **Web version**: no installation required. Open it in any browser and start using it right away.
- **Desktop app client**: [cloud-v0.0.1 download](https://github.com/PMZPZM0/codex-harness-desktop/blob/HEAD/../../releases/tag/cloud-v0.0.1) (Windows installer + macOS for both architectures). Double-click to use it; it stays resident across startups.
- **Real-time push**: messages and events are all delivered via SSE push, not polling.
