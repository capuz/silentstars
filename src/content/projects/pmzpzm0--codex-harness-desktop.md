# Codex Harness Desktop

A standalone desktop workbench that packages the OpenAI Codex engine into a real desktop app: multi-session task management, visual diff review, built-in automation tools, a plugin/skill/connector ecosystem, and expert team collaboration. It works out of the box, with no command line required.

## ☁️ Codex Harness Cloud

The **cloud edition** of the same desktop experience: open [ppz123.asia](https://ppz123.asia) in a browser and sign in. Together with the local assistant, you can access the assistant **on your computer** from any device. Sessions and data stay local; the cloud only handles accounts and interface delivery.

- **Web version**: no installation, open and use in any browser
- **App client**: [cloud-v0.0.1 download](https://github.com/PMZPZM0/codex-harness-desktop/blob/HEAD/../../releases/tag/cloud-v0.0.1) (Windows installer + macOS, both architectures). Double-click to use; runs resident at startup
- **Real-time push**: messages and events are all delivered via SSE push, not polling
