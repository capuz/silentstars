# Codex Harness Desktop

Independent desktop workbench that integrates the OpenAI Codex engine into a true desktop application: multi-session task management, visual diff review, built-in automation tools, plugin/skill/connector ecosystem, expert team collaboration, out-of-the-box, no command line required.

## 🆕 Latest Update v0.0.29

- **Component Library**: Built-in 3800+ ready-made HTML/CSS components from Uiverse, browse/copy and use directly, Codex automatically checks the library when writing frontend
- **Desktop Pets**: Desktop floating window pets compatible with Codex's official pet.json format, status follows the tasks
- **Pixel Office**: Expert team members real-time mapped to a virtual office (workstations, typing animations, rest activities)
- **Thinking Level Auto Transmission**: Laya local model 33ms automatically selects Low/Medium/High/Ultra-high, manual selection immediately overrides
- **Plugin Marketplace**: Switch to Gitee official mirror (48 compatible plugins), names and descriptions all in Chinese
- **First Launch Guide 2.0**: Only shows "Developer Tools" guide, tool installation uses domestic mirror acceleration, progress/speed/parallel queue
