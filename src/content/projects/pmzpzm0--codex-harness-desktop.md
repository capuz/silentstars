# Codex Harness Desktop

A standalone desktop workbench that packages the OpenAI Codex engine into a true desktop application: multi-session task management, visual diff review, built-in automation tools, a plugin/skill/connector ecosystem, and expert team collaboration. It works out of the box and does not require the command line.

## ☁️ Codex Harness Cloud

The **cloud version** of the same desktop experience: open [ppz123.asia](https://ppz123.asia) in a browser and log in. Together with a local assistant, you can access **the assistant on your own computer** from any device. Sessions and data remain local; the cloud only handles account management and interface delivery.

- **Web version**: no installation needed, open and use in any browser
- **Desktop app client**: [Cloud assistant client download](https://github.com/PMZPZM0/codex-harness-cloud-src/releases/latest) (Windows installer + macOS for both architectures). Double-click to use; it runs resident at startup
- **Real-time push**: messages and events are all delivered via SSE push, not polling
