# Codex Harness Desktop

A standalone desktop workbench that packs the OpenAI Codex engine into a real desktop app: multi-session task management, visual diff review, built-in automation tools, a plugin/skill/connector ecosystem, and expert team collaboration. It works out of the box, so you don't need to touch the command line.

## ☁️ Codex Harness Cloud (cloud edition)

The **cloud form** of the same desktop experience. Open [ppz123.asia](https://ppz123.asia) in a browser and sign in. Together with a local helper, you can access the assistant **on your own computer** from any device. Sessions and data stay local; the cloud only handles accounts and interface delivery.

- **Web version**: no installation required, open and use in any browser
- **Desktop client**: [Cloud assistant client download](https://github.com/PMZPZM0/codex-harness-cloud-src/releases/latest) (Windows installer + macOS for both architectures). Double-click to use; it stays resident and starts with the computer.
- **Real-time push**: messages and events are all delivered via SSE push, not polling
