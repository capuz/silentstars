# Codex Harness Desktop

An independent desktop workbench that packages the OpenAI Codex engine into a real desktop application: multi-session task management, visual diff review, built-in automation tools, a plugin/skill/connector ecosystem, and expert team collaboration. It works out of the box without touching the command line.

## ☁️ Codex Harness Cloud (Cloud Edition)

The **cloud form** of the same desktop experience: open [ppz123.asia](https://ppz123.asia) in a browser and log in. Together with a local assistant, you can access **the assistant on your own computer** from any device (sessions and data still stay local; the cloud only handles accounts and interface distribution).

- **Web version**: no installation required, open and use in any browser
- **App client**: [Cloud assistant client download](https://github.com/PMZPZM0/codex-harness-cloud-src/releases/latest) (Windows installer + macOS for both architectures), double-click to use, stays resident on startup
- **Real-time push**: messages and events are all delivered via SSE push, not polling
