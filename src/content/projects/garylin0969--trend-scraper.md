# 🔥 Hot Now Crawler Project

This is a crawler project that provides data for the [Hot Now](https://hotnow.garylin.dev) website, responsible for collecting the latest information on various trending content.

## 🌟 Project Overview

Hot Now is an information aggregation website that integrates trending content from major platforms, allowing users to browse various trending topics in one place.

- **Website**: [https://hotnow.garylin.dev](https://hotnow.garylin.dev)
- **Main Project**: [https://github.com/garylin0969/hot-now](https://github.com/garylin0969/hot-now)
- **Chrome Extension**: [Hot Now | Grab All Trending Topics](https://chromewebstore.google.com/detail/hot-now%EF%BD%9C%E7%86%B1%E9%96%80%E8%A9%B1%E9%A1%8C%E4%B8%80%E6%8A%8A%E6%8A%93/pcgkeopgenagbemoagdogljeapjhapch)

## 🎯 Chrome Extension

Hot Now provides a Chrome extension that allows you to stay up-to-date with the most popular trending topics every time you open a new tab.

### Features

- Browse trending topics by opening a new tab
- Does not collect personal identification information
- Only uses Google Analytics for anonymous usage behavior analysis
