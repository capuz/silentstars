# 🔥 Hot Now Web Crawler Project

This is the crawler project that provides data for the [Hot Now](https://hotnow.garylin.dev) website, responsible for collecting the latest information on various trending content.

## 🌟 Project Overview

Hot Now is an information aggregation website that brings together trending content from major platforms, letting users browse a wide range of hot topics in one place.

- **Website**: [https://hotnow.garylin.dev](https://hotnow.garylin.dev)
- **Main project**: [https://github.com/garylin0969/hot-now](https://github.com/garylin0969/hot-now)
- **Chrome extension**: [Hot Now ｜熱門話題一把抓](https://chromewebstore.google.com/detail/hot-now%EF%BD%9C%E7%86%B1%E9%96%80%E8%A9%B1%E9%A1%8C%E4%B8%80%E6%8A%8A%E6%8A%93/pcgkeopgenagbemoagdogljeapjhapch)

## 🎯 Chrome Extension

Hot Now offers a Chrome extension that lets you keep up with the most popular online discussion topics every time you open a new tab.

### Features

- Browse trending topics as soon as you open a new tab
- Does not collect personally identifiable information
- Uses only Google Analytics for anonymous usage behavior analysis
