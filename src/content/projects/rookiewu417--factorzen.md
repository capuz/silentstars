# FactorZen

**A multi-market quantitative research platform centered on factor library access**

Factor mining → overfitting guardrails → **incremental access to the library** → risk and portfolio → simulation and forward execution → unattended operation → results display.<br>
Each step falls into `manifest.json`, which is auditable and reproducible.

## What is this

Most factor platforms answer the question "**Is this factor good?**" FactorZen answers a more difficult and useful question:

> **Does this factor provide any incremental value to my existing factor library?**
