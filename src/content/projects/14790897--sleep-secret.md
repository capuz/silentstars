# Sleep Recording Analysis

Record overnight, split sounds into categories such as snoring, breathing, coughing, and sleep talk, all locally on your phone, and get a timeline and statistics in the morning.

**By default, audio never leaves the device.** There is no account and no server, so you can install and use it right away. All analysis happens on the phone.

The only exception is if **you yourself** set up 坚果云 (Jianguoyun) / WebDAV on the Export Data page. After that, each night's recording is uploaded to a cloud drive **under your own name**. This project has no server of its own, and never will.

**Documentation site**: <https://mygithub.sixiangjia.de/sleep-secret/> ([Usage Guide](https://mygithub.sixiangjia.de/sleep-secret/guide/) · [Understanding the Report](https://mygithub.sixiangjia.de/sleep-secret/report/) · [Data & Privacy](https://mygithub.sixiangjia.de/sleep-secret/privacy/))
