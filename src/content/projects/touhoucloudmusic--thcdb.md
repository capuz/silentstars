# Touhou Cloud DB（THCDB）

Touhou Cloud DB（THCDB）is a database project for Touhou doujin music.

The project's positioning and functions are referenced from platforms such as Rate Your Music, VocaDB, and Discogs.

## Current Status

The project is still under construction.
