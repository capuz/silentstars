# SAP on AWS Automation Scripts

Collection of scripts, that can be used primarily with **AWS Launch Wizard for SAP** to automate the following tasks:

| Feature  | Description |
| ------------- | ------------- |
| **[SAP Software Download](https://github.com/awslabs/aws-sap-automation/blob/HEAD/software_download/)**  | Makes all [required SAP software](https://docs.aws.amazon.com/launchwizard/latest/userguide/launch-wizard-sap-software-install-details.html) available to AWS Launch Wizard for SAP deployments |
| **[SSM for SAP](https://github.com/awslabs/aws-sap-automation/blob/HEAD/ssm_sap/) (RETIRED)** | Performs [AWS Systems Manager for SAP](https://docs.aws.amazon.com/ssm-sap/latest/userguide/get-started.html) registration for AWS Launch Wizard for SAP deployments |
| **[Custom Tags](https://github.com/awslabs/aws-sap-automation/blob/HEAD/tagging/)** | Adds a set of predefined custom tags to all AWS Launch Wizard for SAP deployment resources |
| **[AWS SDK for SAP ABAP installer](https://github.com/awslabs/aws-sap-automation/blob/HEAD/abapsdk/)** | Downloads latest version and (optional) runs import @ AWS Launch Wizard for SAP deployments |
