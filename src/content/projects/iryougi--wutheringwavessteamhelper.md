# WutheringWavesSteamHelper

Wuthering Waves Steam Helper - Used to add the Wuthering Waves game to the Steam library, enabling Steam launcher management. This description may not be updated in a timely manner; for detailed documentation, please visit [Wuthering Waves Steam Helper Documentation](https://www.iryougi.com/index.php/wutheringwavessteamhelper/)

## Introduction

WutheringWavesSteamHelper is a tool that allows players to launch and manage the domestic version of Wuthering Waves through the Steam client by generating the necessary configuration files.

Since version 2.2.0, the application also supports a "Custom Manifest" page, allowing users to customize AppID / DepotID / BuildID / Manifest fields for any Steam game, generate the corresponding ACF configuration, and copy the launch command.
