# MoArt

An anime pre-production tool: key animation (原画), storyboard (絵コンテ), exposure
sheet, audio timing, and video output — in a single self-contained HTML file.
No installation required. Runs in a browser on desktop and iPad.

## Use

Open `index.html` in a browser, or use the hosted build.
