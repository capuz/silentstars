# 🧟 Project Zomboid Mod Conflict Checker — Build 42 Mod Scanner

**Project Zomboid Mod Conflict Checker** is a Windows desktop diagnostic concept for players with large local or Steam Workshop mod collections.

It complements Project Zomboid's **Build 42 Mod Manager** by giving you a single pre-launch report for missing dependencies, duplicate identifiers, declared incompatibilities, load-order warnings, Build 41/42 mismatches, and possible local file overlaps.

> **Important:** Always back up important saves before changing a heavily modded setup. Changing an established mod list or load order can affect an existing save.
