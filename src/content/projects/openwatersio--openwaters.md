# Open Waters App

An experiment in building modern marine charts. Currently alpha and not to be use for navigation.

## Features

- [**Tracks**](https://github.com/openwatersio/OpenWaters/blob/HEAD/docs/tracks.md) — Record the vessel's path in the background with smart sampling, display tracks on the chart, and export as GPX.
- [**Markers**](https://github.com/openwatersio/OpenWaters/blob/HEAD/docs/markers.md) — Drop pins on the chart, name and color-code them, and navigate with live bearing and distance.
- [**Routes**](https://github.com/openwatersio/OpenWaters/blob/HEAD/docs/routes.md) — Create multi-leg routes with drag-and-drop waypoints, then navigate with automatic waypoint advancement and ETA.
- [**Charts**](https://github.com/openwatersio/OpenWaters/blob/HEAD/docs/charts/) — Browse and install nautical charts from a curated catalog, add custom tile sources, or import MBTiles for offline use.
- [**Instruments**](https://github.com/openwatersio/OpenWaters/blob/HEAD/docs/instruments.md) — Connect to onboard instruments via Signal K or NMEA 0183 over WiFi to display depth, wind, heading, and AIS targets.
