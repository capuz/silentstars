# rRanker

rRanker is a multi-rhythm game data management application. You can view player data, best scores, complete scores, song library and song details for different games and accounts in one application, and use practical tools provided for each game.

## Main Features

- **Data Query**: View player overview, best scores, complete scores, song library and song details, and search, filter and sort according to conditions supported by each game.
- **Account Management**: Bind multiple accounts according to data sources supported by each game, and quickly switch between different games, accounts, and osu! modes.
- **Personal Library**: Collect songs, mark practice charts, and add local tags to songs and charts.
- **Score Images**: Generate and export preset or custom score images for Maimai DX, Chunithm, and Phigros.
- **Chart Features**: View chart confirmations for Maimai DX, Majdata Net, Phigros, Phira, osu!, and Rizline; download chart files for Maimai DX, Majdata Net, Phigros, Phira, and osu!.
- **Game Tools**: Provide game-specific tools including random song selection, nearby arcade location finder, Rating calculation, score advancement calculation, strength analysis,…
