# rRanker

rRanker is a multi-rhythm-game data management app. In one app, you can view player data, best scores, full score records, song libraries, and song details for different games and accounts, and use practical tools built for each game.

## Key Features

- **Data queries**: View player overviews, best scores, full score records, song libraries, and song details, with search, filtering, and sorting based on what each game supports.
- **Account management**: Bind multiple accounts using the data sources each game supports, and quickly switch between games, accounts, and osu! modes.
- **Personal library**: Favorite songs, mark charts for practice, and add local tags to songs and charts.
- **Score images**: Generate and export preset or custom score images for maimai DX, CHUNITHM, and Phigros.
- **Chart features**: View chart confirmations for maimai DX, Majdata Net, Phigros, Phira, osu!, and Rizline; download chart files for maimai DX, Majdata Net, Phigros, Phira, and osu!.
- **Game tools**: Random song picker, a rhythm game map with location selection and cross-city arcade and venue search, plus game-specific tools such as Rating calculation, push-score calculation,…
