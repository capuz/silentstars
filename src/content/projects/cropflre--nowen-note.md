<h1>Nowen Note</h1>
  <p><strong>An open-source, self-hosted knowledge base and task workspace for individuals and small teams</strong></p>
  <p>
    Rich text and Markdown dual editor · Real-time collaboration · AI knowledge Q&A · To-do and mind mapping · Multi-end clients

  </p>

> The goal of Nowen Note is not just to be an editor, but to provide a personal knowledge infrastructure that is data-controllable, can run long-term on NAS/servers, and can be accessed through desktop and mobile clients.

## Core Capabilities

| Module | Current Capabilities |
| --- | --- |
| **Notes and Editor** | Tiptap 3 rich text, CodeMirror 6 Markdown, real-time preview and split screen, tables, code blocks, KaTeX, Mermaid, images and attachments, comments, version history |
| **Knowledge Organization** | Unlimited levels of notebooks, colored tags, favorites, recycle bin, full-text search, bidirectional links, block references, backlinks, and knowledge graphs |
| **Task Management** | Tree tasks, lists, Kanban, calendar, Gantt chart/timeline, task dependencies, repeat rules, reminders, templates, and AI breakdown |
| **AI Capabilities** | OpenAI compatible interface,…
