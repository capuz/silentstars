# Long解压

**A local archive and media compression workspace for Windows**

Package files · Extract archives · Browse contents · Manage passwords · Compress images, videos and PDFs

### [⬇ Download the latest version](https://github.com/Longyuyeee/long_Decompress/releases/latest)

[Features](#features) · [Screenshots](#screenshots) · [Quick Start](#quick-start) · [Formats](#formats) · [FAQ](#faq) · [Changelog](#updates)

---

Long解压 brings everyday file handling into one convenient workspace. Received a batch of archives? Extract them together. Only want to find one file inside? Browse directly. Need to share materials? Package, encrypt, and split them into volumes. Image, video, and PDF size optimization each have their own separate entry points.

## ✨ Less effort from the start

**Tool Center:** Document comparison, the workflow center, the archive library, and file integrity checks are gathered into one entry point. When you switch categories at the top, your current inputs, selections, and results are kept; original shortcuts and history entries still go directly to their destinations.

**More everyday touches:** Common directories and bookmarks, Explorer right-click…
