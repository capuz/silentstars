## 📖 Project Introduction

EndlessPixel is the official website of a **Java Edition** Minecraft server, built with Next.js 16 App Router.

It is not a simple showcase page, but a **service-oriented site** designed around real player needs:

- Newcomers want to know how to join the server -- answered directly by an AI assistant, not by reading documentation;
- Players want to see their own skin -- 3D preview, no need to download the client;
- Find launchers and modpacks -- 80+ resources with one-stop high-speed downloads;
- Whether the server is online -- real-time status at a glance;
- Manage information after login -- unified management of account info and skins.

> ⚠️ **Version Notice**: This server only supports **Java Edition** (including mobile Java Edition launcher) to join, **does not support** Bedrock Edition and web version.
