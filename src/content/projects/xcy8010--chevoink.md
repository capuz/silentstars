## Chevoink Agent 3.5

Custom model support connects to a relay station on this machine, LM Studio, and Ollama through a local connector. The computer running the model service must stay on; works and tools are still processed in the cloud. For connection, key storage, and capability verification, see the [Local Models guide](https://github.com/Xcy8010/Chevoink/blob/HEAD/docs/LOCAL-MODELS.md). Developers can use the [cloud development and delivery entry](https://github.com/Xcy8010/Chevoink/blob/HEAD/docs/CLOUD-DEVELOPMENT.md). Android signing and production deployment require a protected environment to be configured first, and existing workflows do not automatically grant release permissions.
