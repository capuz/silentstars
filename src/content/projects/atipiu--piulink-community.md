# PiuLink

PiuLink lets you connect to your own computer from a phone, tablet, TV, or another computer to use the desktop and apps remotely, and you can also play games with a controller. The host side is based on Sunshine, and the client is compatible with Moonlight. Resolution, aspect ratio, and frame rate depend on the display, encoding hardware, and network conditions.

[Watch the short film (1:03)](https://atipiu.github.io/PiuLink-Community/#film) · [Go to the official website to download](https://atipiu.github.io/PiuLink-Community/#downloads)

## PiuLink Rust New Mainline

PiuLink Rust is a completely new development version. Starting with this release, all future optimizations, fixes, and feature iterations will be based on the new main branch. Old forks, old commits, and PRs based on the old mainline will not be accepted for merging. Developers who want to keep contributing should create a new fork or branch from the new main, reimplement the changes they need, and submit a new PR.
