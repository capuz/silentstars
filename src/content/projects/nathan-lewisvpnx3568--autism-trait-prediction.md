## Overview

Autism Prediction is an interactive web quiz for exploring autism spectrum traits through a short screening process. After the user responds to the questions, a machine learning model generates an informational result that can be viewed directly in the browser.

Because the app runs on the web, it offers a lightweight alternative to installing desktop software. The project also illustrates how a Random Forest model may be connected to an HTML-based application for health-related screening purposes.

- A concise, interactive question flow
