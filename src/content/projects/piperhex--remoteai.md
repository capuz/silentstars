On first launch, systems set to Chinese display Chinese by default, and systems set to other languages display English by default.
You can choose Chinese, English, or Русский in the settings, and the app will remember your choice.

Remote AI is a desktop workbench built on Codex CLI that combines a graphical programming assistant with multi-account management.
You can chat with Codex directly in the app to understand code, implement features, and troubleshoot issues, and check execution progress and file changes at any time.
It also provides account login and switching, usage viewing, third-party providers, a local hot-switching proxy, token analysis, a Skills marketplace, and one-click theme switching.
