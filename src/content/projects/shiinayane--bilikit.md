<h1>BiliKit</h1>
</div>

> A set of Tampermonkey scripts for Bilibili that are friendly to **macOS Safari**. No browser extensions, zero external dependencies, just a script manager is needed.

> [!WARNING]
> **In development · Rapid iteration**: BiliKit is still under active development, with frequent version updates and features that may change at any time. Occasional instability is normal. A change in the Bilibili API may also cause temporary failures. If you encounter issues or have suggestions, feel free to submit an [Issue](https://github.com/shiinayane/BiliKit/issues).

Is watching Bilibili overseas like a slideshow? Want recommendations that understand you like a mobile app? Want to see comments by region, watch videos without screen sleep, and have themes follow the system?
BiliKit solves it all at once with **two scripts**—core enhancements + homepage recommendation flow.

## Two Main Components

| Script | One-liner |
|---|---|
| 🧩 **BiliKit Core** | A core enhancement that installs all at once: **CDN optimization** (rescue overseas lag) · **Watch comments/dynamics/1080p without logging in** · **Theme** follows the system · Comments show **gender/IP region** · **No…
