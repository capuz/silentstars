## 架构设计

## 能力

| 能力 | 说明 |
| --- | --- |
| 📄 办公文件处理 | Read, create, and edit DOCX, PPTX, XLSX, and plain text files; |
| 🧠 本地知识库 | Supports indexing large numbers of files, retrieving content, and citing sources |
| 🌐 网页与浏览器 | Web search, operating the built-in browser |
| ✍️ 改动审核 | View change history, review change diffs, roll back supported file changes |
| ⏰ 定时任务 | Run tasks on a schedule, reusing the partner's materials and model configuration |

Feature demos and real task examples are available on the [official website](https://www.guanzhangai.cn/zh).

## 快速开始

1. Download and install the Windows or macOS version.
2. Choose an available model, or configure your own service address and API Key.
3. Create a partner, add a working directory, and start assigning tasks. To use the knowledge base, first download the embedding model and build the index.
