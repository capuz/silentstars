# MATR — Automation Assistant for Touken Ranbu

<br>
    <br/>
</p>
<br>

An automation tool for the PC version of Touken Ranbu, running the game through ADB connection with an emulator, powered by MaaFramework! It is recommended to use MuMu Emulator 12 with a resolution of 1280×720. Other ADB-supported emulators and resolutions can also run.

> To maintain consistency with the naming style of the MaaFramework ecosystem, this project has been renamed from **AATL** to MATR. The old repository address will automatically redirect to this repository.
