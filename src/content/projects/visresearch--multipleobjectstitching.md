## Multiple Object Stitching for Unsupervised Representation Learning

This repository is the official implementation of "Multiple Object Stitching for Unsupervised Representation Learning".

[[Paper](https://arxiv.org/abs/2506.07364)]    [[BibTex](#Citation)]    [[ model weights]](https://huggingface.co/visresearch/MOS/tree/main)

### 1. Introduction

Contrastive learning for single object centric images has achieved remarkable progress on unsupervised representation, but suffering inferior performance on the widespread images with multiple objects. In this paper, we propose a simple but effective method, Multiple Object Stitching (MOS), to refine the unsupervised representation for multi-object images. Specifically, we construct the multi-object images by stitching the single object centric ones, where the objects in the synthesized multi-object images are predetermined. Hence, compared to the existing contrastive methods, our method provides additional object correspondences between multi-object images without human annotations.
