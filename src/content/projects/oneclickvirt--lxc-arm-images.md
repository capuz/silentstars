# lxc_arm_images

## Description

Images in Releases (daily pulling of images for automatic patching and updating):

Pre-installed: wget curl openssh-server sshpass sudo cron(cronie) lsof iptables dos2unix

SSH login is pre-enabled, SSH preset to listen on port 22 of IPV4 and IPV6, password authentication login is enabled

All images are enabled to allow SSH login for root users

Default username: ```root```

Default password unchanged, consistent with official repository
