# Xinyi Network Sandbox · Huawei VRP Command Training (single-file offline edition)

**One HTML file. Double-click it to practice Huawei switch and router commands. No need to install eNSP or GNS3, and it works without an internet connection.**

> The image above shows what it looks like after opening: drag in two switches, connect two cables, click 「实训实验」(Lab Exercises) to load the exercises, then type `system-view` and `port link-type trunk` below. The same rules apply as on real equipment.

---

## Up and running in 30 seconds

| Step | What to do |
|---|---|
| **1** | **[Open it online here](https://liuyimr.github.io/NE_HWSIM/NE_HWSIM.html)** (recommended, nothing to download)<br>or download the single file `NE_HWSIM.html` |
| **2** | **Double-click it.** Open it with Chrome, Edge, or Firefox |
| **3** | A VLAN lab topology is already set up automatically. Click **「开始配置」(Start Configuring)** to start working hands-on |

That's just these three steps, with no fourth step. Send it to students by WeChat, QQ, USB drive, or class group chat, whichever works.
