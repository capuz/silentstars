# Codex Remote Bridge/Use Codex on your phone as easily as Doubao

Optional voice read-aloud for the web interface: completed reasoning summaries and final replies can call Volcano TTS on demand. Voice is off by default. During installation, you can optionally enter an API Key, voice ID, and resource ID. Keys are stored only on your main computer. Voice clips that have already been synthesized play on click; clips that have not yet been synthesized are generated on click. Local voice files are cleaned up only when capacity runs low. The public temporary cache is kept for up to 72 hours and has a 5 GB limit.
