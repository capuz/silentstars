# Arclight

**A multi-agent creation project for AI comic-drama and visual storytelling.**

Make story creation a reviewable, traceable, and recoverable production process, rather than a set of independent model calls.

Arclight is aimed at individual creators, small comic-drama studios, and AI content production teams. Its goal is to connect story, script, storyboard, visual assets, and the final cut. Creators handle direction and key decisions, specialized agents handle concrete creative tasks, and the server handles state, versions, review, and execution.

> **Current stage: a usable story-text creation product.**
> The project has implemented a cute-style canvas frontend, accounts and project collaboration, and a two-person manual review workflow for story → script → storyboard. Image, voice-over, and final-cut production are still in development.
