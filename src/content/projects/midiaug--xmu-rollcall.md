# XMU Rollcall (厦大签到)

**TronClass client for Xiamen University · Android / Windows**

XMU Rollcall (xmu-rollcall) is a third-party open-source client built with Flutter for Xiamen University's TronClass (畅课). It provides number, radar, and QR code check-in, assignment viewing, timetable management, and multi-identity assistance. This is not an official app of the university.
