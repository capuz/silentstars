## What is OrcaBox

OrcaBox is built for video editors, designers, motion graphics artists, photographers, and creative teams. After you add existing asset folders, OrcaBox builds a local index without changing the original directory structure, and brings previews, search, tags, collections, ratings, color filtering, and AI-assisted organization together in a single desktop workflow.

| Core Principle | Description |
| --- | --- |
| Local first | Indexes, databases, and main analysis workflows stay on your machine, suitable for private assets and large project libraries. |
| Zero-copy management | Links directly to original files, without duplicating them to build the library or consuming extra disk space. |
| Multi-format preview | Browse images, videos, audio, Lottie, 3D, fonts, documents, and project files in one place. |
