秋笺 is an open-source desktop Markdown editor. Paste screenshots or draw Excalidraw hand-drawn diagrams, and the content is stored by default directly in the same `.md` file, with no image host to set up. When writing tutorials or technical notes, you can use multiple tabs to switch between steps, collapsible blocks to hide supplementary notes, centered filenames on code blocks, line highlighting, and draggable preview heights. All of this is based on **standard Markdown syntax that degrades gracefully**, so readers using other editors won't see garbled text or lost content.
