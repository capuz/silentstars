Aggregates usage from multiple AI coding tools, including Claude Code, Codex, Cursor, and Gemini CLI, so you can view trends, models, and project distribution in one dashboard. Supports macOS / Windows desktop clients, and can also open a local browser dashboard via the CLI on macOS / Windows / Linux.

## ⚡ Quick Start

### 🖥️ Client Usage

Quotern provides macOS / Windows desktop clients that are ready to use after installation, with no extra configuration required.

#### Download and Install

Go to the [Releases](https://github.com/yuhengqin/Quotern/releases) page to download the installer for your operating system and architecture:

| System / Chip | Installer | Other Downloads |
| --- | --- | --- |
| macOS Apple Silicon | `Quotern-<version>-mac-arm64.dmg` | Same-named `.zip` |
| macOS Intel | `Quotern-<version>-mac-x64.dmg` | Same-named `.zip` |
| Windows x64 | `Quotern-<version>-win-x64-setup.exe` | `*-win-x64-portable.exe` portable version |
| Windows ARM64 | `Quotern-<version>-win-arm64-setup.exe` | `*-win-arm64-portable.exe` portable version |
