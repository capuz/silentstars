## Requests

To request a new source or bug fix, [create an issue](https://github.com/marbou92/MHExtensions/issues/new/choose).

prohibitively difficult to maintain.

If you would like to see a request fulfilled and have the necessary skills to do so, consider
contributing! Issues are up-for-grabs for any developer if there is no assigned user already.
