# HestiaCP Useful Tools Collection

A curated collection of production-grade scripts, optimization guides, and **platform-agnostic AI prompt blueprints** for HestiaCP + Debian/Ubuntu servers.

Built and battle-tested for real production environments. A contribution to the HestiaCP community — thank you to the team for your continuous work!

## 📂 Repository Structure

### 1. 📖 Guides & Optimizations

Step-by-step guides to optimize your server infrastructure:

- **[PHP-FPM Optimization Guide](https://github.com/webxtekstudio/hestiacp-useful-tools/blob/HEAD/php_optimize/php_optimization_guide.md):** Calculate RAM limits and choose between `ondemand`, `dynamic`, and `static` PHP modes based on server size and traffic.
- **[MariaDB Optimization Guide](https://github.com/webxtekstudio/hestiacp-useful-tools/blob/HEAD/mariadb_optimize/mariadb_optimization_guide.md):** Configure `innodb_buffer_pool_size`, `innodb_log_file_size`, and `table_open_cache` for MariaDB 10.11 / 11.8 LTS to dramatically improve database performance and reduce CPU load.
