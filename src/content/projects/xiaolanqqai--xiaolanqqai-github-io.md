## Website Introduction

### Website Overview
Xiaolan is an efficient navigation page system designed to provide quick search and website access functionality. This project is developed using a modern front-end technology stack, focusing on user experience and performance optimization.

### Core Features
- **Intelligent Search**: Supports AJAX instant search suggestions, providing a fast search experience.
- **Categorical Navigation**: Organizes and displays various website links through tabs, supporting custom sorting.
- **Four Major Management Systems**: Navigation management, version management, and other systems built by TRAE, achieving data visualization management.
- **Theme Switching**: Supports automatic switching between light/dark themes, with state saving and automatic button creation features.
- **Performance Monitoring**: Real-time monitoring of page loading performance, providing performance data analysis.
- **Poetry Display**: Integrates a daily poetry API to showcase beautiful verses.
