# Strava Panel

> Strava cycling data panel — credential management, automatic token refresh, riding stats visualization
>
> Strava cycling panel — credential management, auto token refresh, riding stats visualization

Zero-dependency pure Node.js backend (ESM, Node ≥22.13, node:sqlite), one codebase deployed across multiple platforms: **Feiniu NAS (fnOS) / Docker / Windows·macOS·Linux desktop tray / npm CLI**.

## Features / Features

- 🧭 **Top tab panel**: Cycling data (home) / Recent rides / Training suggestions / FIT tools / Trip planning / Dashboard / Settings. Day/night theme adapts automatically to the system, bilingual in Chinese and English, official Strava logo + linear SVG icons
- 📊 **Stat cards double as chart switchers**: click any of "Total distance / Ride count / Total duration / Total elevation gain" to switch the trend chart's metric; each card has a "vs. previous period" percentage change badge
