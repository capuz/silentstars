# Quadro Builder

A browser-based designer for QUADRO climbing frames, made by Xiaomaifang. Open the web page and build on the official grid: edit in the browser, publish your models, record your household parts in inventory, list surplus accessories for sale, and export assembly manuals when you're done. `.qdf` files can be opened in both this tool and the original manufacturer's software. AI design is not yet available.

Online: [xiaomaifang.com/builder](https://xiaomaifang.com/builder/)

QUADRO is the original manufacturer's trademark. This is an unofficial community tool.

## Features

1. **Online editing**: Build in the browser with no software to install. Connectable positions light up.
2. **Model community**: Models in the plaza can be opened, edited, and published.
3. **Inventory management**: Record what you have at home. After building, compare to see what you're still missing.
4. **Accessory trading**: List surplus parts for sale, or post wanted requests for missing ones. Contact each other directly. The platform does not inspect goods or handle transactions.
5. **Assembly manual**: Build up layer by layer. The parts used in each step are shown alongside.
