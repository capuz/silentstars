# DDD Project Template Based on the Wow Framework

A DDD project template for rapidly building projects based on the [Wow framework](https://github.com/Ahoo-Wang/Wow).

> **Warning**
>
> This template is based on **Wow 10.0.0-beta.18** (pre-release): the API, configuration, storage, and wire formats may still change before the 10.0.0 GA. No compatibility is promised, and it is not recommended for production use.
> For the stable 9.x template, see the Wow 9.9.0 version in the Git history; for migrating from 9.x, refer to the Wow documentation "Migrating from 9.x" and the `wow-migrate` Skill.
