# Wow Service Template

A DDD + Event Sourcing + CQRS service template organized according to the [Wow](https://github.com/Ahoo-Wang/Wow) 10 best practices. Get it running, test it, and deploy it, then replace the sample domain with your own.

> **Warning**
>
> This template is based on **Wow 10.0.0-beta.22** (a pre-release version): the API, configuration, storage, and wire formats may still change before the 10.0.0 GA, no compatibility is promised, and it is not recommended for production use.
