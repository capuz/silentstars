# MongoDB Atlas AWS CloudFormation Resources

Use [AWS CloudFormation](https://aws.amazon.com/cloudformation/) to manage [MongoDB Atlas](https://www.mongodb.com/cloud/atlas). See our [documentation](https://www.mongodb.com/products/integrations/aws-cloudformation) for quick starts and common questions. For a list of supported resources, see [here](https://github.com/mongodb/mongodbatlas-cloudformation-resources/blob/HEAD/cfn-resources/README.md).

## Getting Started
### MongoDB Atlas CloudFormation

See the [`cfn` examples](https://github.com/mongodb/mongodbatlas-cloudformation-resources/blob/HEAD/examples/README.md) to setup prerequisites and get started with your first cluster using our sample CloudFormation Stack templates. Follow the steps in [Activate the MongoDB Atlas CloudFormation public extensions](https://github.com/mongodb/mongodbatlas-cloudformation-resources/blob/HEAD/examples/README.md#activate-the-mongodb-atlas-cloudformation-public-extensions) for each AWS Account and Region where you want to deploy your MongoDB Atlas resources.
