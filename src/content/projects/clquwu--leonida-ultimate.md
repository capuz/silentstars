**Leonida Ultimate** is a native Windows/Vulkan static recompilation port of Grand Theft Auto VI (Xbox Series), built **on your PC from your own copy**. The Xbox Series CPU is x86-64 like a PC, so the game's code runs natively while console system software is reimplemented; precompiled RDNA2 GPU programs are translated to SPIR-V for Vulkan; and models, textures, and audio are read directly from your local package.

This tree unifies active community runtime, shader-translator, and native Rust improvements into a single working, booting baseline so **human contributors and AI coding agents** can jump straight into rendering, audio, ray tracing, shader performance, and asset tooling instead of re-solving early boot.

> **Important**
>
> This repository **does not contain the game, keys, shaders, assets, or an executable**, and does not explain how to obtain them. Nothing here decrypts or bypasses any protection. Every commit is checked by `scripts/check_no_game_data.py`. Everything built from your own copy stays strictly on your PC. Never share generated files.
