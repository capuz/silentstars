# zjiet-work

`zjiet-work` is a legacy Java 8 security and web demonstration project that is being restored to active maintenance. It contains browser authentication pages, QQ/WeChat social-login adapters, sample user and product APIs, file transfer examples, and an asynchronous order example.

The current maintenance goal is to establish a reproducible baseline, fix deterministic defects, improve security and tests, and provide Chinese and English user-facing messages without changing the original module layout.

## AI assistant

After logging in, open `/ai-assistant.html` for prompt generation and customer-service chat.
Model credentials stay on the server and are configured with environment variables:

| Variable | Default | Description |
| --- | --- | --- |
| `AI_ENABLED` | `false` | Enables model calls |
| `AI_PROVIDER` | `openai` | `openai` or `deepseek` |
| `AI_API_KEY` | empty | Provider secret; never sent to the browser |
| `AI_BASE_URL` | `https://api.openai.com/v1` | DeepSeek: `https://api.deepseek.com/v1` |
| `AI_MODEL` | `gpt-4o-mini` | Provider model name |
| `AI_TEMPERATURE` | `0.3` | Sampling temperature |
| `AI_MAX_TOKENS` | `800` | Maximum generated tokens |
