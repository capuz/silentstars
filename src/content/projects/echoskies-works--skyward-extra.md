# Skyward-Extra

English | [简体中文](https://github.com/echoskies-works/skyward-extra/blob/HEAD/README.zh-CN.md)

Skyward-Extra is an extension built on Skyward, a from-scratch Rust Android recovery, with extra features and experiments.
It includes all of Skyward's features, plus some additional extensions.

### Installing

Install scripts get `7za` and `zstd`, which ROMs with a super image compressed by
zstd use to flash it, and an `unzip` whose `-p` streams the image as it reads it.
They also get `avbctl` and `resetprop`, to turn off verified boot's checks and to
read and set properties.
