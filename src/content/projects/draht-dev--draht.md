# draht Monorepo

> **Looking for the draht coding agent?** See **[packages/coding-agent](https://github.com/draht-dev/draht/blob/HEAD/packages/coding-agent)** for installation and usage.

The supported Draht product is a local agent stack for building and running AI
agents, with selected public extensions and deployment tools. Private workspaces
and examples in this monorepo are not hosted-service or release claims. See the
[product and package support map](https://github.com/draht-dev/draht/blob/HEAD/.planning/PRODUCT-MAP.md) for the authoritative
scope and evidence gates.
