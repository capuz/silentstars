  Unofficial compatibility maintenance edition of TSF Launcher 3D Shell for modern Android.<br>
  While retaining the original 3D desktop interaction experience as much as possible, it focuses on fixing compatibility issues with launching, permissions, components, wallpapers, and widgets on modern Android systems.

> [!IMPORTANT]
> The original app **TSF Launcher 3D Shell** was developed by **TSFUI**. The original in-app About page, string resources, and site links retain information such as `tsfui.com` and `service@tsfui.com`. This repository is an independent, unofficial compatibility maintenance project with no official affiliation with the original author. It is mainly intended for personal study, compatibility analysis, and non-commercial research.
