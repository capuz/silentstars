# nwd-reader

An independent C++20 Navisworks file parsing library for model import, format conversion, and engineering data processing. It provides read interfaces for **geometry, properties, materials, textures, structure tree, saved viewpoints, selection sets, animation, and construction tasks**.

It supports reading embedded models in NWD and NWC files, as well as model files referenced by NWF files. No Navisworks installation is required, and it does not depend on the Autodesk SDK or runtime.

## Features

- **Geometry**: Reads triangle strips, polylines, points, text, and parametric geometry such as circles and cylinders, preserving coordinate indices, normals, colors, and UVs.
- **Instances and transforms**: Shared geometry is referenced through instances. Transforms, units, and object associations are preserved, avoiding per-instance vertex duplication.
- **Properties and structure tree**: Reads partitions, model hierarchy, property groups, and typed property values, and provides child node and instance query indexes.
- **Shared field definitions**: Reads typed fields, GUIDs, and bounding boxes from the common schema, partition references, and external geometry…
