# getnote-mcp

MCP (Model Context Protocol) server for [得到大脑（Get笔记）](https://biji.com) Open API.

得到大脑（Get笔记）is a personal note-management tool. With this MCP Server, AI models can help users manage their notes.

> 🔑 **Get an API Key**: https://www.biji.com/openapi
>
> **Free accounts can also be used**: Complete authorization to start calling the API. Members get higher default quotas. Use `get_quota` to check your current actual quota. Dedicated quotas and enterprise delegated authorization are determined by the server. When your quota runs out, wait until the reset time returned in the response.
>
> **Upgrade membership as needed**: [Go to the 得到大脑 membership purchase page](https://www.biji.com/checkout?product_alias=9Ab36BB3ZD&spm=openapi_mcp)

## Installation

Requires Node.js 20 or later.

```bash
# Run directly (recommended, no cloning needed)
npx @getnote/mcp

# Or install globally
npm install -g @getnote/mcp
```
