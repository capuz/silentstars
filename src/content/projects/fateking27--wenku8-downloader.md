## Features

This tool can be used to download novel content from [Light Novel Library](https://www.wenku8.net/index.php), supporting the following features:

- ✅ Generate **EPUB** format e-books (supports custom cover)
- ✅ Generate **TXT** format e-books
- ✅ Download only novel illustrations
- ✅ Download **removed novels**
- ✅ **Full volume download** or **custom volume download**
- ✅ Configure **proxy** to add multiple proxies

## 🚀 Quick Start

### Method 1: Direct Use (Recommended)
[Download](https://github.com/fateking27/wenku8-downloader/releases/download/v0.2.1/v0.2.1.zip) the latest version, unzip it and double-click to run `wenku8-downloader.exe` to use.

### Method 2: Run from Source
You need to install the [Bun](https://bun.sh/) runtime environment first.

```bash
# Clone the project
git clone https://github.com/fateking27/wenku8-downloader.git
cd wenku8-downloader

# Install dependencies
bun install

# Run the program
bun start
```
