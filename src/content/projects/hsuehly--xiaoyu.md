# 小遇 Xiaoyu

A digital companion app built with Flutter that supports customizing avatars, personas, and voices, with real-time voice and video interaction.

Supports **iOS / Android** · current version `0.1.0+1` · **in beta** · integrates Vidu S2-Avatar real-time version

## Interface Preview

A dark background with a light purple accent color, including a branded splash screen, a floating dual-tab navigation, a horizontal character list, a full-screen call, and a text/action input panel.
