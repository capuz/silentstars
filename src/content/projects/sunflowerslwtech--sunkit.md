# sunkit

SunflowersLwtech's toolbox — Claude Code skills, agents, commands, and MCP servers,
packaged as a plugin marketplace.

## Install

```
/plugin marketplace add SunflowersLwtech/sunkit
/plugin install polanyi-design@sunkit
```
