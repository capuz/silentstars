# Studio Next

Studio Next is a runtime framework for AI Agent organizations.

It models "a company" as a version-controlled company directory, with a resident daemon responsible for scheduling, dispatching, executing, acceptance, and bookkeeping. Execution bodies (DSH, Claude Code, Codex, Kimi, etc.) are replaceable, while organization, processes, and records are persistent assets.

> Current status: The V2 specification was finalized on 2026-10-30 (tag `v2-final`). The core framework has entered the productization wrap-up stage. The V2 finalized baseline is 106 test files and 1583 test cases, all passing. Real-world runtime validation, security hardening, and platform adaptation are still in progress.
