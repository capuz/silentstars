# OJ Insight

**Organize training records scattered across multiple Online Judges into a single trustworthy, clear, and long-term trackable personal profile.**

OJ Insight is a cross-platform training data dashboard for algorithmic competition participants. Currently supports Codeforces, AtCoder, Luogu, Niuke, QOJ, and LeetCode, and provides an independent ICPC / CCPC Tracker. All data is saved locally, and the application clearly distinguishes between per-problem AC records, publicly available summaries, and missing data, avoiding assembling incomparable statistics that look "complete".
