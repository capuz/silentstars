# sawyer-plugins

Sawyer Hood's [BB](https://getbb.app) plugins, in one repository. Every plugin lives under `plugins/<id>/` as an ordinary plugin package with its own `package.json`, and `.bb/plugins.json` indexes them as a collection.

| Plugin | Directory | What it does |
| --- | --- | --- |
| Better Notes | [`plugins/better-notes`](https://github.com/SawyerHood/sawyer-plugins/blob/HEAD/plugins/better-notes) | An editable fork of BB’s built-in document and notes library. |
| Cascade | [`plugins/cascade`](https://github.com/SawyerHood/sawyer-plugins/blob/HEAD/plugins/cascade) | A scrollable, tiled layout for active BB threads. |
| Compact Nav | [`plugins/compact-nav`](https://github.com/SawyerHood/sawyer-plugins/blob/HEAD/plugins/compact-nav) | Borderless sidebar icon buttons with native ordering and visibility controls. |
| CoW copy | [`plugins/btrfs-cow`](https://github.com/SawyerHood/sawyer-plugins/blob/HEAD/plugins/btrfs-cow) | An environment provider that uses copy-on-write reflink copies instead of git worktrees (Btrfs/XFS). |
