# Prettier Apex Monorepo

Monorepo for the Prettier Apex project, including:

- [prettier-plugin-apex](https://github.com/dangmai/prettier-plugin-apex/blob/HEAD/packages/prettier-plugin-apex/README.md)
- [apex-ast-serializer](https://github.com/dangmai/prettier-plugin-apex/blob/HEAD/packages/apex-ast-serializer/README.md)
- [playground](https://github.com/dangmai/prettier-plugin-apex/blob/HEAD/packages/playground/README.md)

The monorepo uses [pnpm](https://pnpm.io/) as package manager, and
[nx](https://nx.dev/) for running monorepo operational tasks.

If you are simply using Prettier Apex, please refer to the
[prettier-plugin-apex](https://github.com/dangmai/prettier-plugin-apex/blob/HEAD/packages/prettier-plugin-apex/README.md) documentation.

If you are interested in contributing to this project, please refer to
[this document](https://github.com/dangmai/prettier-plugin-apex/blob/HEAD/CONTRIBUTING.md) to get started.
