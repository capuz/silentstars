# dvclient
new client for working with dimonvideo.ru

Features:
- retrieving information about materials from all site sections.
- search across all sections.
- logging in to the site, registering on the site, viewing your own profile
- endless downloading (all files from before 2004).
- forum (reading, replies, bookmarks, thanks, quoting).
- search by topics or by replies.
- private messages (all folders, deleting, reading, replies, push notifications).
- friends list (and sending them messages).
- files (download, screenshot preview, online video playback, rating a file, reading and writing comments, uploading files).
- many settings.
- no background services, the program does not run in the background.
- caching, low traffic consumption.
- adjustable font size.
- export and import of settings.
- choice of main section.
- integration with DVGet / ADM.
- site support (via built-in purchases)
