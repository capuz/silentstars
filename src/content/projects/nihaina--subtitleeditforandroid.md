# SubtitleEdit for Android

When translating voice and subtitles, it's inconvenient to use a computer. I found there's no suitable software on mobile.

So I created one with the help of AI. The features are referenced from Subtitle Edit, and the operation logic is mainly based on personal usage habits.

Currently mainly perfecting basic subtitle editing features, adding new features while optimizing operation logic and fixing bugs at the same time.

You can quickly sync subtitles based on waveform and spectrogram.

## Main Features

### Subtitle Editing

- **Multi-format Support**: Supports SRT, LRC, WebVTT, TXT formats
- **Visual Editing**: Click to edit timeline and subtitle text
- **Time Offset**: Supports batch time adjustment at millisecond/second/minute/hour level
- **Multi-select Operations**: Supports batch selection, copy, paste, delete
- **Source View Mode**: Directly view and edit raw text content
- **Format Conversion**: Supports batch conversion between SRT, LRC, WebVTT subtitle formats, supports video format conversion
- **Audio Reference**: Can open audio and quickly adjust subtitle timeline based on waveform, supports mp3, wav, flac and other formats
