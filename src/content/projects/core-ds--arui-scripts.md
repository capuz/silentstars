[Пользовательская документация](https://github.com/core-ds/arui-scripts/blob/HEAD/packages/arui-scripts/README.md)

## Разработка

Быстрый старт:
```bash
yarn install --immutable
yarn build
yarn test
yarn lint
```

Подробнее тут: [CONTRIBUTING.md](https://github.com/core-ds/arui-scripts/blob/HEAD/CONTRIBUTING.md)

Проект является монорепозиторием, в котором находятся следующие пакеты:

- [arui-scripts](https://github.com/core-ds/arui-scripts/blob/HEAD/packages/arui-scripts/) - Код конфигураций сборщиков
- [alpine-node-nginx](https://github.com/core-ds/arui-scripts/blob/HEAD/packages/alpine-node-nginx/) - Базовый образ docker контейнера, на котором будут основываться контейнеры проектов
- [@alfalab/scripts-server](https://github.com/core-ds/arui-scripts/blob/HEAD/packages/arui-scripts-server) - Утилиты для использования на сервере
- [@alfalab/scripts-modules](https://github.com/core-ds/arui-scripts/blob/HEAD/packages/arui-scripts-modules) - Библиотека для работы с модулями приложений
- [@alfalab/client-event-bus](https://github.com/core-ds/arui-scripts/blob/HEAD/packages/client-event-bus/) - Библиотека для работы c Event Bus
