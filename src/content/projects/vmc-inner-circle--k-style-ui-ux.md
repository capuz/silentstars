# k-style-ui-ux

A Claude Code, Codex, and Cursor plugin that takes one PRD (planning document) and outputs a **Korean app-style mobile screen draft** as HTML in about 15 minutes. It is an open-source project developed together with [VIBE MAFIA CLUB 이너서클](https://www.vibemafiaclub.com/inner-circle).

## Who this is for

- **People building an early app without a designer**: you can see the screen flow and a first draft before outsourcing the work.
- **Developers who need to handle planning and design themselves, such as for internal tools**
- **Designers**: you can get a first draft of the same work quickly and use it as a base for refinement.

This is not a tool that builds the finished product for you. It removes bottlenecks by producing drafts quickly. Details, aesthetics, and copy still need to be handled by people.

## What makes it different

- **UX first**: rather than flashy screens, it first checks whether core features can be reached without confusion. For every target that users create or apply for, it builds the start → view → edit → end (result) screens without omission.
