# 🤖 tailclaude - Run Claude Code on Tailscale Easily

Welcome to tailclaude, a simple way to use Claude Code within your Tailscale tailnet. This tool runs with the iii engine to give you smart code sessions right at home or work. This guide will walk you through how to get tailclaude running on your Windows computer without any coding skills.

---

## 🔍 What is tailclaude?

tailclaude connects the Claude AI code model to your private Tailscale network. This means you can run AI code sessions securely on your own devices. It uses the iii engine to process your commands and create code quickly.

This app is designed for people who want to use AI code tools on their personal network without complicated setups. It works on Windows and requires no special software knowledge.

---
