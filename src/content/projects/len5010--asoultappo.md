AsoulTappo is an open-source online desktop pet app made for Zhijiang (枝江).

## Download

Download the file for your platform from the [Releases](https://github.com/LEN5010/AsoulTappo/releases/latest) page. If you can't access GitHub, you can download the same files from [len5010.top/download](https://len5010.top/download?app=tappo).

| Platform | File | Notes |
| --- | --- | --- |
| Windows (x64) | `_x64-setup.exe` | NSIS installer, not signed by Microsoft; if SmartScreen blocks it, choose to run anyway |
| macOS 10.15+ | `_universal.dmg` | Universal build, supports Apple silicon and Intel; not notarized by Apple |

If macOS says the app is damaged or the developer can't be verified on first launch, drag the app into the Applications folder, then run this in Terminal:

```sh
xattr -dr com.apple.quarantine /Applications/AsoulTappo.app
```

Keyboard and mouse input requires allowing AsoulTappo under System Settings → Privacy & Security → Input Monitoring or Accessibility. You only need to allow it in one of them. After allowing it, restart the desktop pet. If the toggle is on but the pet still doesn't respond, remove AsoulTappo from the list with the minus button and add it again.…
