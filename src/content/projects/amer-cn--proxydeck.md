#### Turn your AI subscriptions into a local OpenAI-compatible API that any client can use

---

Do you have subscriptions to CommandCode, Codely (团结), or WorkBuddy (Tencent CodeBuddy) but can only use them inside their own clients? **ProxyDeck converts these subscriptions into a single local OpenAI-compatible API** (`http://127.0.0.1:55990/v1`). Codex, Cursor, and any agent that supports a custom Base URL can connect directly. One exe, double-click to use, zero installation and zero configuration.

The interface is a **mechanical control panel**: a cream-colored body, traffic lights at the top, a black dot-matrix screen, and an ignition lever. Starting the proxy isn't a button press. You pull the lever from left to right, accompanied by a self-check light ceremony and a real ratchet sound effect.

## 🚀 Quick Start

1. **Download**: Download `ProxyDeck.exe` from [Releases](https://github.com/Amer-CN/proxydeck/releases) (single file, about 24MB, no installation needed)
2. **Ignite**: Double-click to open, and pull the red lever on the COMMAND deck all the way to the right
3. **Connect**: Enter the following in your AI client:

```
Base URL:  http://127.0.0.1:55990/v1
API Key:…
