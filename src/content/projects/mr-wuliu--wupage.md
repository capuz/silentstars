## Installation

### Microsoft Edge

1. Open the [WuPage Translator store page](https://microsoftedge.microsoft.com/addons/detail/wupage-translator/ophhojnppohaklhcdaheplkodopmplfg).
2. Click 'Get' and follow the prompts to complete the installation.
3. In the browser extensions menu, pin WuPage to the toolbar.

### Manual installation (Chrome / Edge)

1. Download the package for your browser from [Releases](https://github.com/mr-wuliu/wupage/releases/latest): for Chrome, use `wupage-<version>-chrome.zip`; for Edge, use `wupage-<version>-edge.zip`.
2. Extract the release package and keep the extracted directory.
3. Open the extensions management page: for Chrome, use `chrome://extensions`; for Edge, use `edge://extensions`.
