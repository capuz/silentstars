# 🍔 Maimai Savings Ordering Assistant · mcd-savings-assistant

> A McDonald's ordering expert that does the math: one-click coupon claiming · automatic best-coupon application · smart pairing · **Savings Leaderboard** · visualized calories · **Checkout Cabin** · **Delivery to home (address set within the conversation)** · **Maimai Shake-Shake Lottery** · nearby store navigation · DIY free combos · one-click ordering

An interactive, visual Skill built on the capabilities of the **McDonald's China MCP** (`https://mcp.mcd.cn`).
It is more than a chatbot: it renders the real menu, coupon, nutrition and store data returned by MCP into an HTML ordering assistant where you can **click, tick, and see prices and calories update in real time**.
