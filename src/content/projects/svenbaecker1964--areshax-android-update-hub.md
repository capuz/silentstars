## What AresHax Provides

AresHax is an Android-centered game script utility built around packaging and distributing releases. Its purpose is to provide one clear location for the current build, allowing users to find the latest release package without checking several different sources.

The repository is also arranged for simple maintenance over time. Updated builds can be substituted as they become available, making the project suitable for distributing game script packages, cheat builds, and other release files intended for Android while keeping the distribution process compact.

- Packages game-related releases with Android use in mind
