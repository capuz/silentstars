# MoviePilot-App (v2 Fully Native iOS Client)

The official fully native SwiftUI iOS client for MoviePilot (`v2` branch). It connects directly to the MoviePilot V3 backend API and provides a unified dark purple-rose gradient glass visual system, iOS 26+ Liquid Glass navigation, and a native local playback experience. [View the full screenshot gallery (60 images)](https://github.com/jxxghp/MoviePilot-App/blob/HEAD/screenshots/README.md).

## Core Capabilities

- **4+1 Liquid Glass bottom navigation**: `发现`, `探索`, `我的` (a dashboard without a large title, with seamless plugin charts), and `设置` (a settings hub with multi-level cards and lists). The right-side `+1` button dynamically switches between the primary action of the current page and the default global search. Repeatedly tapping a bottom-bar main icon opens a minimal 8-item quick menu (`订阅`, `日历`, `资源`, `下载`, `文件`, `历史`, `工作流`, `插件`).
