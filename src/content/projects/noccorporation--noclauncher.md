## ✨ Current features

- Java + Bedrock in one launcher
- Java profiles: Vanilla / Forge / OptiFine
- Offline-first mode
- Library of mods/resources/shaders
- Bedrock Hub (mini dock) with quick switches
- External FPS monitor NocFpsCounter (manual launch)
- Additional Bedrock settings (presets + options.txt)
- MS Fix / Xbox Fixer / Deep Fix
- Launch check and diagnostics
- Experiments and utilities

- Splash reduced by about 40% for a neater fit on the screen
- Significantly reduced splash background dimming (about 60%)
