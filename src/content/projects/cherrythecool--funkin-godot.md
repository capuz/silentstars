# Funkin' Godot

[Friday Night Funkin'](https://github.com/FunkinCrew/Funkin) modding framework / engine / whatever, made
in the [Godot Game Engine](https://godotengine.org) to make the process of creating mods
or similar fan projects easier. It comes with a set of tools and scenes in its `core`
to provide the more essential building blocks for most mods, with the `funkin` module
as an example of how you can use those things.

To get a feel for the gameplay as-is, try out one of the [precompiled releases](https://github.com/cherrythecool/funkin_godot/releases/latest)
with content from the [original game](https://www.newgrounds.com/portal/view/770371) (the `funkin` module).

To make a mod just download [Godot](https://godotengine.org/download) (no .NET required) and the source from
this repository. Then, import the source as a project in Godot and get started! Documentation is
currently scarce, but will be worked on in the future (and until then, you can always submit issues on this
repository to ask questions).

Godot itself has [well put together documentation](https://docs.godotengine.org/en/stable/) that can help
if you're stuck or want to add something but don't know how, so…
