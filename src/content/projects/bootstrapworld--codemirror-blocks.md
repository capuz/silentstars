# codemirror-blocks

codemirror-blocks is a project to make programming languages editable using visual blocks.

## About this repository

This repository contains the code for all the packages maintained by the codemirror-blocks team, including the core codemirror-blocks library, and various language modules that implement block
editors for individual languages using the core library. Documentation for individual packages
can be found in their respective directories:

- [codemirror-blocks](https://github.com/bootstrapworld/codemirror-blocks/blob/HEAD/packages/codemirror-blocks/) - the core library used to make block editors. Start here if you'd like to implement a new block editor for a programming language of your choice.
- [wescheme-blocks](https://github.com/bootstrapworld/codemirror-blocks/blob/HEAD/packages/wescheme-blocks/) - a block editor for the wescheme programming language.
