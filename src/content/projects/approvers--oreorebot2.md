# OreOreBot2 (New Haracho)

---

The representative BOT of the Gengai Development Server, [Haracho](https://github.com/approvers/OreOreBot), has been rebuilt using TypeScript and discord.js.

It is an OreOre BOT. It does not engage in scams or anything like that.

## What is Haracho?

**It is a BOT that aims to support the activities of the Gengai Development Server members.**

- Haracho is a BOT that connected to the Gengai Development Server on 2020/03/03.
  - It is probably the first BOT to connect to the Gengai Development Server.
  - It was built using Python and discord.py, initially developed by [Isso](https://github.com/isso0424), [Colk](https://github.com/Colk-tech), and [Fly-san](https://github.com/loxygenK), later joined by [Kawaemon](https://github.com/kawaemon), [Soshi](https://github.com/soshiharami), and [Ko](https://github.com/ko50) (honorifics omitted).
- Haracho has a very troublesome mechanism, and after entering 2021, no further development was conducted (there were small updates, etc.).
- A reimplementation in Go was planned, but it was never completed and was permanently frozen.
