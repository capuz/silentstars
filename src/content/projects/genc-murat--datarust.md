# datarust workspace

This repository is a **Cargo workspace** hosting the datarust ecosystem: a
collection of independent, separately-versioned crates for classical
data-science and machine-learning workloads in Rust.

## Crates

| Crate | Path | Description |
|---|---|---|
| **[datarust]** | [`crates/datarust/`](https://github.com/genc-murat/datarust/blob/HEAD/crates/datarust) | Scikit-learn-style preprocessing and classical ML in Rust. Standard/minmax/robust scalers, encoders, imputers, PCA, linear models, clustering, pipelines — zero external dependencies by default. |
| **[datarust-profile]** | [`crates/datarust-profile/`](https://github.com/genc-murat/datarust/blob/HEAD/crates/datarust-profile) | One-call data profiling and data-quality reports. Column statistics, type inference, duplicate detection, quality findings, HTML/JSON output. |

Each crate has its own `README.md`, `CHANGELOG.md`, version, and release track,
and is published independently to crates.io.
