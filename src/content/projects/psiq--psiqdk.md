# PsiQuantum Development Kit (PsiQDK)

Welcome to the **PsiQuantum Development Kit** - an integrated set of Python packages for designing, simulating, and analyzing quantum programs targeted at fault-tolerant quantum computers.

PsiQDK bundles the core components you need to write a quantum program, simulate it, estimate the cost of running it on fault-tolerant hardware, and visualize the results.

## What's in PsiQDK?

| Component | Purpose |
| --- | --- |
| **[Workbench](https://github.com/PsiQ/psiqdk/blob/HEAD/workbench)** | A Python framework with an optimized C++ backend for writing and simulating quantum programs and perform resource estimation. |
| **[Algorithms](https://github.com/PsiQ/psiqdk/blob/HEAD/algorithms)** | A growing library of reusable quantum algorithm primitives - state preparation, arithmetic, phase estimation, data loading, Hamiltonian simulation, and more. |
| **[Visualize](https://github.com/PsiQ/psiqdk/blob/HEAD/visualize)** | Jupyter widgets and editor integrations for inspecting circuits and resource-estimation reports. |
