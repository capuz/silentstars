# Fubon NeoAPI Skill

A hands-on guide to the Fubon Neo Python SDK for AI coding agents.

[English](https://github.com/phenomenoner/neoapi-skill/blob/HEAD/README.en.md) · [Installation Guide](https://github.com/phenomenoner/neoapi-skill/blob/HEAD/skills/neoapi-python/INSTALL.md) · [Changelog](https://github.com/phenomenoner/neoapi-skill/blob/HEAD/CHANGELOG.md) · [Official Documentation](https://www.fbs.com.tw/TradeAPI/)

> [!IMPORTANT]
> This is a community-maintained AI skill, not the official Fubon SDK. Before putting any trading program into production, treat the official documentation, the test environment, and broker confirmations as the final authority.

## What does this skill solve?

It organizes NeoAPI knowledge scattered across official documentation, test-environment experience, and real-world projects into workflows that AI can reliably follow.

| :--- | :--- |
| Trading flow | Login, account selection, placing orders, modifying orders, canceling orders, execution reports, and reconciliation |
