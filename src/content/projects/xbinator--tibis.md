# Tibis

Tibis is a **Markdown desktop editor** that saves data on your computer and deeply integrates AI conversations with document editing.

It is suitable for writing, knowledge organization, technical document drafts, and AI-assisted content production.

## Core Highlights

- **Dual View Editor** — Seamless switching between rich text (TipTap) and source code (CodeMirror), WYSIWYG + precise control
- **AI Chat Sidebar** — Streaming conversations, tool calls, context compression, models assist writing at any time
- **Multi AI Service Provider Support** — OpenAI / Anthropic / Google / DeepSeek, freely switch and configure
- **MCP Tool Integration** — Supports Model Context Protocol, AI can operate files, execute commands, read and write editor content
- **Skill System** — Custom skills can be registered to extend AI's writing and editing capabilities
- **Prompt Editor** — Slash commands `/`, file references `@`, quickly build complex prompts
- **Voice Input** — Local whisper.cpp speech-to-text, no internet required
- **Local First** — SQLite persistence + encrypted storage, your data belongs to you
