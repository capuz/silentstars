# Remote Buddy (Windows)

Remote Buddy（遥控搭子）Windows edition turns a Bluetooth TV remote into a global voice input and quick-control tool for Windows 10 / 11. Pick up the remote and speak, then release to finish. The speech goes directly into input tools such as 微信输入法, 豆包输入法, the Windows system dictation feature, or Typeless. It also supports custom regular-key shortcuts, media control, and commonly used text.
