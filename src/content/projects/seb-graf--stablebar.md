# StableBar

A native, configurable menu bar for macOS and an alternative to SketchyBar. Built with Swift, AppKit and SwiftUI.

[**Download for Mac**](https://github.com/Seb-GRAF/StableBar/releases/latest) · [Website](https://stablebar.app/) · [User guide](https://github.com/Seb-GRAF/StableBar/blob/HEAD/docs/README.md) · [Widget store](https://github.com/Seb-GRAF/stablebar-packages)

## Install

Download [StableBar.dmg](https://github.com/Seb-GRAF/StableBar/releases/latest), drag it to Applications and open it. Setup walks you through a preset, a theme and a placement.

Or install with [Homebrew](https://brew.sh):

```sh
brew install --cask seb-graf/tap/stablebar
```

**macOS 14+ · Apple silicon · Free and open source.** Releases update themselves. See [Getting started](https://github.com/Seb-GRAF/StableBar/blob/HEAD/docs/getting-started.md) for permissions, beta updates and uninstalling.
