## 📖 Introduction

This project is modified from [osuv2](https://github.com/Yuri-YuzuChaN/osuv2), adapted for nonebot2, and has modified the command response logic and fixed some bugs to make it easier to use.

The speed change feature relies on ffmpeg, and you need to [install ffmpeg yourself](https://docs.go-cqhttp.org/guide/quick_start.html#%E5%AE%89%E8%A3%85-ffmpeg) for it to work properly.

## 💿 Installation

<details>
<summary>Install using nb-cli (recommended)</summary>
Open the command line in the root directory of the nonebot2 project and enter the following command to install:

    nb plugin install nonebot-plugin-osubot

</details>

<details>
<summary>Install using package manager</summary>
In the plugin directory of the nonebot2 project, open the command line and enter the corresponding installation command based on the package manager you are using:

<details>
<summary>pip</summary>

    pip install nonebot-plugin-osubot
</details>
