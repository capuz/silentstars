# pi-plugins

Focused plugins for everyday work in [pi](https://github.com/earendil-works/pi).

Search the web, fetch pages, delegate tasks, restore files as you navigate session
history, and keep an eye on speed and usage. Each package adds a specific capability.
Install only the pieces you need.

## Plugins

| Package                            | What it does                                             | Entry point                             |
| ---------------------------------- | -------------------------------------------------------- | --------------------------------------- |
| [`checkpoint`](https://github.com/k3dom/pi-plugins/blob/HEAD/plugins/checkpoint) | Restore files when navigating session history.           | `/tree`, `/checkpoint-cleanup`          |
| [`claude-cli`](https://github.com/k3dom/pi-plugins/blob/HEAD/plugins/claude-cli) | Use a Claude subscription through the Claude Code CLI.   | `claude-cli` models                     |
| [`elapsed`](https://github.com/k3dom/pi-plugins/blob/HEAD/plugins/elapsed)       | Show a live timer in the working indicator.              | Automatic                               |
