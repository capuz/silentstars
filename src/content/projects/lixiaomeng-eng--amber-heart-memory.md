# Amber Heart · 琥珀之心

[Simplified Chinese](https://github.com/lixiaomeng-eng/amber-heart-memory/blob/HEAD/README.md) | [English](https://github.com/lixiaomeng-eng/amber-heart-memory/blob/HEAD/README.en.md)

> Give AI companions a memory that grows.
> Fixed memory stabilizes personality, short-term memory catches the present moment, and long-term memory settles the relationship.

Amber Heart is a long-term memory system designed for AI companions. It was born in my own AI companion project and has been used and refined through daily real-life interaction since February 2026.

The goal of this system is not simply to save chat logs, but to let the AI gradually develop a continuous sense of relationship over long-term interaction:

- It knows who it is, and it knows who you are;
- It remembers the important experiences, agreements, preferences, and boundaries between you;
- It can associate a single sentence with related past events;
- It can tell recent states apart from long-term facts;
- Its memories settle and get organized, and they also quietly fade away.
