# agent-skills-lab

> A beginner-friendly **playground + toolkit**: small runnable code
> experiments, and a categorized, tagged collection of reusable
> [skills](https://github.com/Franky100-pig/agent-skills-lab/blob/HEAD/reflect/skills/) for working with LLMs / coding agents.

Originally, this is a repo for my daily commits. Now, it is becoming a tool any
beginner developer can browse, copy from, and contribute to:

- **[Skills](https://github.com/Franky100-pig/agent-skills-lab/blob/HEAD/reflect/skills/README.md)** — organized by category
  (🎮 game-dev · 🧠 llm-context · 🖥️ macos · 🎵 music-creation · ✍️ writing), tagged for filtering,
  each ending with a "try it as an experiment" pointer.
- **[Experiments](https://github.com/Franky100-pig/agent-skills-lab/blob/HEAD/INDEX.md)** — small runnable programs (zero/few
  dependencies), tagged, all verified by CI on every push.
- **[Journal](https://github.com/Franky100-pig/agent-skills-lab/blob/HEAD/reflect/README.md)** — LLM-usage notes with real evidence:
  screenshots, transcripts, data — not vibes.
- **[Pitfalls](https://github.com/Franky100-pig/agent-skills-lab/blob/HEAD/pitfalls/README.md)** — traps already stepped on, filed…
