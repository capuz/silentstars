# dsh-seeker-os

**A complete system engineering project built on top of DeepSeek Harness**

Turn DSH into a personal AI operating system: execution dashboard · interactive cards · Bot team / group chat / voice · memory · profiles · skills · sync · end-side encrypted roaming

## What is this

DeepSeek Harness is the foundation, and dsh-seeker-os is a complete system engineering suite built on top of it. It consolidates the host's conversations, tools, memory, profiles, skills, connectors, sync, and multi-Bot orchestration into one coherent personal AI operating system. **It doesn't just show you what the AI is actually doing.** It also gathers scattered capabilities like memory, profiles, and skills into a set of workbenches, and lets Bots collaborate, report, and do scheduled work like colleagues.

| What you care about | After installing |
|---|---|
| You want to know what the AI did, but don't want to see a screen full of tool logs | A right-column dual-pane execution dashboard, with tool calls rendered in plain language |
