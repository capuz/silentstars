# ⚡ x-hub — Local Personal Productivity Workbench

A desktop productivity tool built with **Tauri 2 + Vue 3 + TypeScript**, featuring a Bento-style interface.
**All data is stored locally by default and is not uploaded to the cloud.**

## ✨ Features

### 🕐 Workbench
**Freely arranged Bento grid**: clock (**large clock / today's lunar-solar calendar / minimal time**, three display modes; quotes pulled from the online hitokoto service, falling back to a local corpus when offline), **weather card** (compact and detailed modes, real-time temperature / feels-like / humidity / wind speed from Open-Meteo, plus city/IP location), system resource monitor (CPU/memory, 2s polling), sticky notes ×2 (600ms debounced auto-save), **diary** (Enter saves to quick notes), **overview cards** for quick notes / to-dos / quick launch, prompt treasure box, to-do list, **to-do calendar** (monthly calendar marking to-do distribution and overdue items), countdown list, **custom quick launch ×4** (pin frequently used resources into groups for one-click launch), and a full-width recent-use strip.
