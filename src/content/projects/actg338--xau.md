# XAU Quant

XAU Quant is an MT5 automated trading EA and XAUUSD strategy information site for gold traders. The main site address is <https://03xau.com>.

This repository mainly hosts the static pages of 03xau.com, multilingual entry points, the free EA download page, installation tutorials, backtest screenshot pages, strategy description documents, and search engine crawling configuration. Website content is used to explain the features of the MT5 Expert Advisor, installation methods, backtesting materials, risk boundaries, and developer contact information.
