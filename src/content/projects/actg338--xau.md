# XAU Quant

XAU Quant is an MT5 automated trading EA and XAUUSD strategy information site for gold traders. The main site is <https://03xau.com>.

This repository mainly hosts the static pages of 03xau.com, multi-language entry points, the free EA download page, installation tutorials, backtest screenshot pages, strategy documentation, and search engine crawling configuration. The website content explains the features of the MT5 Expert Advisor, installation methods, backtest materials, risk boundaries, and developer contact information.
