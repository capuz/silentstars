# xiaohu-video-translate

> One sentence turns a foreign-language video into a **Chinese-subtitled video + a clean transcript**. Download → transcribe → translate → polish → burn-in, end to end, all local, zero transcription API cost.

This is a set of **Skills** for AI coding command-line tools. Essentially it is "scripts + a manual" and is **not tied to any single vendor**: [Claude Code](https://claude.com/claude-code), OpenClaw (小龙虾), Gemini CLI, and Codex can all use it. Once installed, you don't need to memorize any commands. Just say something like "translate this link into a Chinese-subtitled video," and it handles the rest automatically.
