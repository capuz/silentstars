# Map Editor (CK3 / EU4 / HOI4 / Victoria 3 / EU5)

> Author: **永夜廿九** (same name on Bilibili)

A small tool in the browser for coloring game maps, changing colors, and exporting. Click any region you want to modify, and when done you can export to an image or save the coloring to a file to continue next time.

Supports 5 games, 7 maps:

- **Crusader Kings 3** (CK3)
- **Europa Universalis IV** (EU4)
- **Hearts of Iron IV** (HOI4) — Vanilla + Modified Borders
- **Victoria 3** (Victoria 3)
- **Europa Universalis V** (EU5) — Vanilla + Original Size (Chunked Loading)

---

## 1. Getting Started

**This tool is a single file**: `pdx-map-editor.html` (approximately 35 MB, with data for all 7 maps baked in). Get it, **double-click** it, and open it in a browser (Chrome / Edge / Firefox all work). The first screen lets you **select a map** and click to enter.
