# Spec-Driven Development Tools Comparison

Independent research comparing **24 spec-driven development (SDD) tools** for AI-assisted coding — 8 with full workflow treatment, 16 emerging — plus the surrounding agent-orchestration and execution layer. Feature matrices, use-case scoring, git-worktree analysis, decision frameworks, and an interactive comparison site, all derived from the research docs in this repo.

> A considered opinion, not a benchmark. This project is independent and unaffiliated with every vendor tracked, except that the [RPAC](https://github.com/cameronsjo/spec-compare/blob/HEAD/docs/gaps.md#rpac-eai-orgagent-toolkit) entry was added by an agent-toolkit contributor; where a vendor initiated contact ([Memex](https://github.com/cameronsjo/spec-compare/blob/HEAD/docs/memex-review.md)), the review says so up front.
