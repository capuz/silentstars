# JetChat

JetChat is an instant messaging sample project built with Swift 5. It includes one-on-one chat, group chat, an emoji keyboard, image and video messages, local message caching, Moments, theme switching, and a Widget.

## Features

- One-on-one chat, group chat, conversation list, and unread badges
- Text, emoji, image, and video messages
- `ZLPhotoBrowser` album selection, with image caching, video export, and cover generation
- `JXPhotoBrowser` image preview and system video playback
- Moments, likes, comments, and nine-grid images
- SQLite/WCDB local message and conversation caching
- Light, dark, and follow-system themes
- Chinese/English language switching
- Widget showing recent chats
- Adaptive collapsed, half-expanded, and expanded states on iPhone and iPhone Duo

## Tech Stack

| Module | Technology |
| --- | --- |
| UI | UIKit, MVVM, SnapKit |
| Reactive state | RxSwift, RxCocoa |
| Networking | Moya, Alamofire |
| Local storage | WCDB.swift |
| List layout | IGListKit |
| Image loading | Kingfisher |
| Image browsing | JXPhotoBrowser |
| Album selection | ZLPhotoBrowser |
| Theming | SwiftTheme |
| Dependency management | CocoaPods |
