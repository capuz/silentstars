# Baby Records & Toolbox

A local-first mini-program built with uni-app + Vue 3 + Vite: baby tracking plus everyday calculation tools. All data and calculations are done on the device, with no backend dependency.

## Features

### Baby (Tab)

- Baby profile: nickname, date of birth, gender, and age in months
- Daily records: feeding, sleep, and diaper changes, with today's statistics
- Growth chart: height and weight records with canvas line charts
- Vaccine reference: Category 1 / Category 2 reference lists, vaccination checkmarks, custom vaccines
- Growth journal: milestones, daily mood, parenting notes
- Data management: JSON export / restore / clear

### Tools (Tab)

- VAT calculator: bidirectional conversion between tax-inclusive and tax-exclusive amounts, with common and custom tax rates
- Unit conversion: length, weight, temperature, storage, area
- Text processing: line-based deduplication, case conversion
- Base conversion: bases 2–36, supports negative numbers and very large integers

The floating button in the lower-right corner of the Tools page opens the "All Tools" drawer, which shows VAT by default.
