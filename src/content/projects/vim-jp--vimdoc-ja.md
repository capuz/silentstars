# vimdoc-ja

This is a project for distributing the Vim help files bundled with Vim, translated into Japanese.

For detailed usage instructions, see the [wiki](https://github.com/vim-jp/vimdoc-ja/wiki).

The HTML version can be viewed at <https://vim-jp.org/vimdoc-ja/>.
Also, you can ask an AI questions about the contents of this help at <https://deepwiki.com/vim-jp/vimdoc-ja>.

If you find any errors, please let us know via the issue tracker or the mailing list.

- Issue tracker <https://github.com/vim-jp/vimdoc-ja-working/issues>
- Mailing list <https://groups.google.com/group/vimdoc-ja>

If you would like to help with the translation work, please see <https://github.com/vim-jp/vimdoc-ja-working>.
