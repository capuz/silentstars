# ZenTao (禅道) MCP Server

A project management toolset service for ZenTao built on the Model Context Protocol (MCP). It uses a domain-layered modular architecture and lets AI assistants (such as Antigravity, Claude, etc.) call the ZenTao API directly through the standard protocol.

---

## Quick Start

This service is launched with `npx`, pulling from GitHub. Before use, you need **Node.js (≥ 18)** and **Git** installed locally. Installing these two pieces of software, as well as cloning this public repository, **does not require a GitHub account or login**.

### 1. Install Node.js

1. Open [https://nodejs.org/](https://nodejs.org/) and download the LTS installer (choose `.msi` on Windows).
2. Click through the installation, keeping **Add to PATH** checked.
3. After installation, **reopen** your terminal or MCP client and run:

```bash
node -v
npx -v
```

If version numbers appear, you're set (Node must be ≥ 18).
