# WeChat Anti-Recall for macOS

> [!TIP]
> **🖼️ Recommended Project: WallpaperMachine**
>
> Website: **[wallpapermachine.app](https://www.wallpapermachine.app/)** · GitHub: **[WallpaperMachine/WallpaperMachine](https://github.com/WallpaperMachine/WallpaperMachine)**

A macOS WeChat 4 tool for regular users: retain recalled messages, also supports custom notifications, multiple WeChat instances, block automatic updates, and one-click restore.

**[Download Latest Version](https://github.com/fzlzjerry/wechat-antirecall/releases)** · [Troubleshooting](#遇到问题) · [Advanced Usage](#进阶用户命令行)

> **Read Before Use**
>
> - Currently only supports **Apple Silicon (M-series) Mac**.
> - Please **completely quit WeChat** before installing.
> - The tool modifies the WeChat App, but automatically keeps a backup each time, which can be restored anytime.
> - If anti-recall disappears after WeChat upgrades, usually re-detecting and installing once is sufficient.
> - Supports **WeChat 4.1.15.20 (270100)** and **4.1.15.10 (270090)**. 270090 has been confirmed to support anti-recall and auto red packet collection; 270100 has completed static address verification.
