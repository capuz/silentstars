# Nighthawk Wallet (DarkFi Edition) — iOS

Privacy-preserving wallet (work-in-progress) by [Nighthawk Apps](https://nighthawkapps.com). This tree ships as a **native iOS app** on the DarkFi network (DRK). The app integrates a native DarkFi wallet API via **UniFFI** (`rust/darkfi-mobile-ffi` → generated Swift + `DarkfiWalletHandle`) for chain sync, broadcast, and chat.

**3.01.06.** Cyberpunk is the default theme on a light or dark system. The Void wallpaper stays anchored at the top left and continues under the status bar and the tab bar. Body text uses DejaVu Sans Mono. Light and Paper use graphite and grey instead of teal. Titles are Outfit, body text is Source Sans 3, Paper titles are Source Serif 4, and keys are IBM Plex Mono. The sync light is green only while lightwalletd is connected; it is orange while connecting or disconnected. Default sync is padded trial decryption over lightwalletd proto 2.1.0. Experimental UnifOMR is off unless you turn it on under Advanced settings. Embedded Tor is Arti 0.48. Nym is the default network for the wallet, DarkIRC, and node traffic.
