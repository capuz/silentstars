Desktop player for Yandex Music, YouTube and SoundCloud:<br>
  one search, one library, offline mode and video wallpapers that play together with the track.

## Features

Also: full-screen "Now Playing" mode, favorites and custom playlists,
power-saving mode while the window is in the background (for example, during gaming),
and a notification about a new version.

## Themes

Switch them in **Settings → Theme**.

| Theme | Character |
|------|----------|
| **Aurora** | Cyan + magenta with glow, default theme |
| **Glass** | Glass over wallpaper, background turns on automatically |
| **Transparent** | Interface with almost no backing panels: background visible through panels |
| **Editorial** | Georgia + monospace font, emphasis on the "Now Playing" panel |
| **Classic** | Calm dark steel-blue |
| **Light** | Muted light mode |
| **Dark Yellow** | Warm amber accent |
| **Midnight** | Deep blue, cool icy accent |

Custom theme — a single file in `src/quantis/ui/themes/`, see [docs/themes.md](https://github.com/Really-Fun/Quantis/blob/HEAD/docs/themes.md).
