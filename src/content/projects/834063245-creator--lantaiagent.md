The main interface is not a chat window, but an ever-growing sheet: user input, AI output, thought annotations, tool footnotes, and code excerpts.

## What is this

**Lantai is a Windows desktop Agent workbench** (Tauri 2 shell + TypeScript / React 19 frontend): a complete multi-agent runtime.

| | |
|---|---|
| **Canvas, not message flow** | A conversation is a space: multiple volumes laid out on the same sheet, content can be pinned, dragged, and compared; zooming changes information granularity |
| **Multi-Agent runtime** | Domain tools · Sub-Agent pool (git worktree isolation) · Plan / Goal · Memory and skills · Multi-vendor Providers · Token governance |
| **Everything is a plugin** | Panels / Commands / Tools / Renderers / Prompt segments / Hooks / Capabilities / Swappable backends - all contribution channels assembled, shipped with zero privileges enabled by default |
| **Guardrails at the shell layer, not in prompts** | Permission engine · Dangerous command interception · Three-layer sandbox · Encrypted credentials · Permission gate audit logs |
