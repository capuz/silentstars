# AviUtl2 Community Translation

Maintainer: [@sevenc-nanashi](https://github.com/sevenc-nanashi)

[English README](https://github.com/aviutl2/aviutl2_community_translation/blob/HEAD/README.en.md)

AviUtl2's unofficial multilingual translation project. This repository manages:

- Translation files for AviUtl2 and its accompanying effects
- A plugin that automatically updates the translated files

## How to Use

### Automatic

Please install the [AviUtl2 Community Translation Companion](https://aviutl2-catalog-badge.sevenc7c.workers.dev/package/aviutl2-community.aviutl2_community_translation_companion) from the AviUtl2 catalog. Alternatively, download `aviutl2-community.aviutl2_community_translation_companion-v*.au2pkg.zip` from [Releases](https://github.com/aviutl2/aviutl2-community-translation/releases) and drop it into the preview window of AviUtl2 to install.

### Manual

Open the `.aul2` in the `./locales/` folder and download the translation files from the download button in the upper right.
