## v0.3.1 Update

- Redesigned the "Release Desktop Pet" area to clearly distinguish between current platform products and cross-platform build packages.
- Fixed issues with desktop pets being cut off, fixed in corners, unable to drag or scale under high DPI.
- Desktop pets support 70%–140% scaling, bottom dragging, hover toolbars, and tray size menus.
- Retained taskbar entry after minimizing Studio, exiting the process directly when closing the window.
- Added lightweight cross-platform build packages, native CI build matrix, and Docker Web Studio.
- Studio and online version support switching between Chinese and English; the online version completes animation preview and the full three-step process.
- The relay package adds one-click entry for Windows, macOS, Linux, and bilingual offline guidance.
