# Awesome DSH Plugins

[简体中文](https://github.com/white0dew/awesome-dsh-plugins/blob/HEAD/README.zh-CN.md)

An independent directory of DeepSeek Harness (DSH) plugins and related tools, with direct links to each original GitHub repository and its primary action.

- **Live site:** https://dsh.reshub.vip
- **Repository:** https://github.com/white0dew/awesome-dsh-plugins

## Browse and use

Browse the [full directory](https://github.com/white0dew/awesome-dsh-plugins/blob/HEAD/docs/plugins/index.md), choose a category, then review a repository before installing a plugin or downloading a related tool.

```bash
dsh plugin --profile web add github:OWNER/REPOSITORY
```
