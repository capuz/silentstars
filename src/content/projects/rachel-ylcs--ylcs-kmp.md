# Rachel Rapid Development Framework

`Rachel` is a cross-platform rapid development framework built on `Kotlin Multiplatform` and `Compose Multiplatform`, integrating logic, services, and UI. It was developed by the Yinlin Tea House project team.

It covers cross-platform entry points, shared UI, dependent service startup, the client-server interaction engine, free screen navigation, platform-native components, custom themes, responsive layout, MDI configuration consistency, paginated loading, server-side routing, and more.

It supports `Android`, `iOS`, `Windows`, `Linux`, `macOS`, and `Web(Wasm)` clients, plus the `Server` backend.

## Features

- **Cross-platform**: Based on `KMP` / `CMP`, supports six platform clients and the server, with consistency across platforms.
- **Native performance**: Generates platform-native binaries with no bridging or additional libraries.
- **Single language**: Only the `kotlin` language is needed to complete most task requirements and development.
- **Fast**: You can build your own cross-platform application within three minutes.
