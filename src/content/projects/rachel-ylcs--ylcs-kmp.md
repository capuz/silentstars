# Rachel Rapid Development Framework

`Rachel` is a cross-platform rapid development framework built on `Kotlin Multiplatform` and `Compose Multiplatform`, integrating logic, services, and UI. It was developed by the Yinlin Teahouse project team.

It covers areas including cross-platform entry points, shared UI, dependent service startup, client and server interaction engine, free screen navigation, platform-native components, custom themes, responsive layout, MDI configuration consistency, paginated loading, server-side routing, and more.
