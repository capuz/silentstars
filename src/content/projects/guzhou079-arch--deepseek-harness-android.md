**Chinese** | [English](https://github.com/guzhou079-arch/deepseek-harness-android/blob/HEAD/README.en.md)

Packages **DeepSeek Harness** (DeepSeek's AI Agent) as an Android app that you can use by **installing a single APK**.

**What sets it apart: it can build its own APK on the phone.** After you change the code, you run `javac → dex → package → sign → release` right on the phone, with no computer needed. **No Termux, no root, and no environment setup are required.** The terminal, file access and command execution all run inside the app, and 21 skills are bundled and ready to use out of the box.
