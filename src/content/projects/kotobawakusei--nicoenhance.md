# NicoEnhance

An LSPosed-based enhancement module for the niconico Android client.

## Features

- **UI localization** — Translates niconico's Japanese UI sentences as whole sentences into Simplified Chinese (2290+ resource keys / 1560+ full-sentence texts; no word-by-word substitution)
- **Ad removal** — Removes in-app ads, banner ads, and video ads
- **WebView translation** — Translates content on the copyright page and contributor renderer
- **Premium membership unlock** — Unlocks niconico premium membership features
- **Compose text translation** — Translates dynamic text in Jetpack Compose
- **Preference translation** — Translates Preference titles/summaries on settings pages
- **Runtime configuration** — Toggle each feature from the niconico settings page

## Requirements

| Item | Requirement |
| --- | --- |
| Android | 10 (API 29) or higher |
| LSPosed | v1.9+ / v2.x |
| Device | Rooted (KernelSU / Magisk / APatch) |

## Installation

1. Enable the NicoEnhance module in the LSPosed Manager
2. Check the target app `jp.nicovideo.android`
3. Force stop and reopen niconico
4. The NicoEnhance configuration entry can be found in the niconico settings page
