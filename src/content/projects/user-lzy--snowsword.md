# SnowSword

**Windows 10/11 x64 Kernel Analysis & Anti-Rootkit Toolkit**

[English](https://github.com/user-lzy/SnowSword/blob/HEAD/README_EN.md) | **Simplified Chinese**

SnowSword is a kernel analysis and Anti-Rootkit tool for **Windows 10/11 x64**, consisting of a **Ring0 kernel driver + Ring3 GUI/CLI**. It is mainly used for learning Windows kernel development, security research, Rootkit detection, and low-level system analysis.

The project covers Windows Internals capabilities including hidden process/driver detection, Kernel Callback, SSDT / Shadow SSDT, IDT / GDT, Inline Hook, Minifilter, WFP, NTFS / FAT32, process memory and kernel objects.

> **Positioning:** Windows Kernel Analysis / Anti-Rootkit / Rootkit Detection / Windows Internals / Kernel Security Research

|---|---|
| **Rootkit Detection** | Hidden process detection, hidden file detection, hidden network connection detection, Inline Hook detection |
| **Process & Thread** | Process/thread enumeration, terminate/suspend/resume, module enumeration, thread call stacks, process signature information |
