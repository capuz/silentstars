## What is this

**鱼排编辑器 (Yupai Editor)** renders Markdown into **inline-styled HTML**: paste the whole thing into the WeChat Official Account editor and you get the finished layout.

It is also a **human-in-the-loop revision desk**. The panel and the model look at the same document, so it is clear at a glance who changed what.

Quick mode uses the rendering core and themes maintained in this repository. Its initial design originates from [MoPai 墨排 / mopai-markdown](https://github.com/ye4wzp/mopai-markdown) (MIT). Pro mode provides document-level canvas specs, semantic components, and a free-form HTML / SVG creation area.
