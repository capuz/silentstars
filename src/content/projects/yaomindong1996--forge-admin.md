## ✨ Project Introduction

**Forge Admin** is a backend/admin framework designed for enterprise backends, SaaS management, data visualization platforms, and internal low-code tools. It not only provides basic capabilities like users, roles, menus, dictionaries, files, logs, etc., but also makes **AI code generation**, **AI data dashboards**, **AI agent management**, **Flowable workflow**, and **multi-tenant isolation** into a sustainably extensible engineering system.

If you're building a long-term evolving backend system, Forge Admin focuses more on three things:

| Goal | What Forge Admin Provides |
|------|---------------------|
| Faster business page delivery | AI form generation, CRUD page configuration, code generation plugin, downloadable code package |
| More stable for enterprise complexity | RBAC, multi-tenant, data permissions, operation logs, dynamic configuration, file storage, Excel import/export |
| Easier to extend new capabilities | Microkernel +…
