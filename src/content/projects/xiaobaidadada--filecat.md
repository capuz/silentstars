FileCat is a web file server that you deploy yourself, and it is also a **lightweight server management tool**. Once deployed, you can manage files on your server from a browser anywhere, anytime, and enjoy a rich set of operations and maintenance features.

FileCat is built using the UI of [filebrowser](https://github.com/filebrowser/filebrowser).

> **Core philosophy**: Centered on file management, it integrates AI Agent, remote desktop, intranet penetration, system monitoring, and other capabilities to make server management simpler.
