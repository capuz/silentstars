# Overview
Used to optimize the slow page loading of some foreign websites caused by DNS pollution.
# Principle
Achieving the above goal relies on the capabilities provided by the following tools:

* [hosts-generator](https://github.com/eyelly-wu/hosts-generator): Fetches the IPs of specified domains and generates a hosts file
* [GitHub Actions](https://github.com/features/actions): Scheduled tasks that automatically update hosts every 24 hours
* [Vercel Serverless Functions](https://vercel.com/docs/concepts/functions/serverless-functions): Deployed function endpoints that can retrieve the latest hosts file even when GitHub is not accessible
* [Switch Hosts](https://swh.app/zh): Allows flexible configuration of remote hosts, with support for scheduled updates
