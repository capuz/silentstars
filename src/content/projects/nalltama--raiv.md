# Realtime AI Image Viewer (RAIV)

RAIV is a Windows image viewer that automatically performs image super-resolution and restoration using Real-CUGAN / Real-ESRGAN, or Topaz Gigapixel AI if installed separately, while you browse. Simply opening an image displays the processed image, and you can compare before and after processing, move between pages, zoom, pan, and navigate via thumbnails. It emphasizes fast page turning and prefetching, aiming for comfortable browsing of large numbers of images. The development of `RAIV` was done entirely with AI coding using Codex.

An English version is below the Japanese section.

## Download

The latest version can be downloaded from the GitHub Releases page.

- [RAIV Releases](https://github.com/nalltama/RAIV/releases)

There are two distribution ZIP files.

- `RAIV-vX.Y.Z-pyw.zip`: Lean pyw version. Small in size, intended for environments where Python is already installed.
- `RAIV-vX.Y.Z-standalone.zip`: Standalone version. Larger in size, but can be launched from `RAIV.exe` without installing Python on your PC.
