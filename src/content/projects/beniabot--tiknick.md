# 📋 Tik-Nick (טיקניק)

**A Hebrew desktop application for managing and tracking usernames ("nicks") on forums.**
All data is stored locally on your computer — full privacy.

---

## ✨ Features

### 📇 Nick management
Consolidate usernames with full details (real name, phone, email, address, groups, reputation, status, notes, and more), in table or card view. Includes additional contacts, private notes, and bulk deletion/editing.

### 🔗 Linked identities
Link nicks that represent the same person across different forums, with transitive identity groups.

### 🎖️ Source and reliability mechanism
Each value is attributed to a source (me / scan / import) with a reliability rank; the most reliable value wins. ❗ marks conflicting information, with an option for manual resolution.

### 🔍 Advanced search and filtering
Fast search across all fields (FTS5), and multi-condition filtering (for example: name contains "משה" **and** address contains "בני ברק") with bulk actions on the results.
