# foss-banner

A lightweight terminal utility that displays various Free and Open Source Software (FOSS) project names as animated ASCII art banners.

## Features

* Animated ASCII art banners of FOSS projects
* Random color selection for each banner
* Includes 32 different FOSS project banners
* Pure Python implementation (no external dependencies)

## Included Banners

* LINUX
* C
* PYTHON
* BASH
* NEOVIM
* GNU
* FIREFOX
* VIM
* GIT
* DEBIAN
* RUST
* ARCH

...and more.

## Supported Platforms

- Windows
- Linux
- macOS

## Requirements

* Python 3.6 or later
* Terminal with ANSI escape sequence support

## Installation

### Clone the repository :

```bash
git clone https://github.com/MohssineX/foss-banner.git
cd foss-banner
```

## Usage

Run the program :

```bash
cd src
```

```bash
python foss-banner.py
```

If your system uses `python3` :

```bash
python3 foss-banner.py
```

## Quick Run (Without Cloning)

> [!NOTE]
> This command works on **Linux** and **macOS**.
> On **Windows**, run it inside **WSL** or **Git Bash**.

```bash
curl -sSL https://raw.githubusercontent.com/MohssineX/foss-banner/main/src/foss-banner.py | python3
```
