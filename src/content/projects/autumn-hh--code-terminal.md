# Code Terminal

A desktop terminal workbench for multi-project development. It puts commonly used projects, local terminals, single-tab / multi-tile layouts, and appearance settings into one lightweight window, suited to developers who maintain multiple code repositories at once and frequently switch command-line contexts.

> Built with Tauri, React, TypeScript, Rust and xterm.js.
