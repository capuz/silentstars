# reMarkable SPACE

Chinese · [English](https://github.com/boangs/remarkable-space/blob/HEAD/README.en.md)

"Space" (空间) is the app desktop for reMarkable. The home screen cards show today's plan, the weather, and the music that's playing at a glance. Apps install from the store with one tap and can be uninstalled at any time, without changing system files.

## Download and install

Install with the "Space Assistant": connect your reMarkable to your computer with a USB cable, and the assistant will install Space along with the base it needs, all at once.

| Assistant | Download |
|---|---|
| Mac | [space-assistant-mac.zip](https://github.com/boangs/remarkable-space/releases/latest/download/space-assistant-mac.zip) |
| Windows | [space-assistant-windows.exe](https://github.com/boangs/remarkable-space/releases/latest/download/space-assistant-windows.exe) |

Checksums are in `SHA256SUMS` on the [Release](https://github.com/boangs/remarkable-space/releases/latest) page.
