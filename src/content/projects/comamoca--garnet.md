# garnet

Compile gleam to single binary, via Deno and Bun.

<br>
<br>

</div>

</div>

## 🚀 How to use

```sh
# Compile via Deno(default)
gleam run -m garnet_tool garnet_tool/example out

# Compile via Bun
gleam run -m garnet_tool garnet_tool/example out bun
```

## ⬇️ Install

```sh
gleam add -m garnet_tool
```
