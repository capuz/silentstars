# Dishes Cook

> [!NOTE]
> **Built with AI.** This repository is created and maintained with AI: code, configuration, CI and documentation are written by [Claude Code](https://claude.com/claude-code) (Anthropic), under the direction and review of the repository owner. Eligible pull requests (not drafts or bot PRs) are also reviewed automatically by [CodeRabbit](https://www.coderabbit.ai/).

Mobile app that helps you decide what to eat, picking from the recipes you've saved.

Android first (iOS later, same codebase); the same app runs on Android TV, read-only, to pick and show recipes on the big screen, and in a desktop browser, served by the sync server ([web app](https://github.com/someoneinthe/dishes-cook/blob/HEAD/docs/sync.md#web-app)). Built with Expo + React Native + TypeScript. Data lives on the device; it can optionally be synced with your own self-hosted [PocketBase](https://pocketbase.io) server to share recipes between phones ([how](https://github.com/someoneinthe/dishes-cook/blob/HEAD/docs/sync.md)).

What it does, screen by screen: [Features](https://github.com/someoneinthe/dishes-cook/blob/HEAD/docs/features.md).
