# 🍉 Tech Melon Watch Companion

A **real-time Twitter monitoring + wallet monitoring** voice broadcast plugin for **GMGN and Debot**.

When influencers tweet or smart money buys and sells, you don't have to stare at the screen. **Read the trend by sound and act faster than everyone else.**

## ✨ Core Features

### 🐦 Twitter Monitoring
- When a followed influencer tweets, a dedicated alert tone plays within **0.01 seconds**
- Supports custom audio mapping: bind a unique ringtone to each influencer (built-in sound effects for Elon Musk and CZ)
- **AI voice broadcast**: connects to the Cloudflare Edge-TTS cloud engine to automatically read out tweet summaries
- Filter by event type (tweet / retweet / reply / quote)
