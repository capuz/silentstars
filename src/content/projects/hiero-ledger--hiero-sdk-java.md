# Hiero Java SDK

> The Java SDK for interacting a Hiero based network:: the official distributed
> consensus platform built using the hashgraph consensus algorithm for fast,
> fair and secure transactions. Hiero enables and empowers developers to
> build an entirely new class of decentralized applications.

## Java app quickstart

[The Java application quickstart guide](https://github.com/hiero-ledger/hiero-sdk-java/blob/HEAD/docs/java-app/java-app-quickstart.md) covers how to properly set up the dependencies
needed to start developing your Java project using the Hiero Java SDK.

## Android app quickstart

[The Android application quickstart guide](https://github.com/hiero-ledger/hiero-sdk-java/blob/HEAD/docs/android-app/android-app-quickstart.md) covers how to properly set up the dependencies
needed to start developing your Android project using the Hiero Java SDK.

## Examples

This repository includes [Java examples](https://github.com/hiero-ledger/hiero-sdk-java/blob/HEAD/examples/README.md) and [an Android example](https://github.com/hiero-ledger/hiero-sdk-java/blob/HEAD/example-android/README.md)
that showcase different use cases and workflows.
