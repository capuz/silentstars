# YoPlayer

面向电视和遥控操作的 Kodi 媒体界面，包含 **YoPlayer · Infuse 皮肤**和**首页数据组件**。单首页集中展示分库、继续观看、最近添加和播放历史，保留 Kodi 原生播放与设置能力。

当前分支源码：**Skin 2026.10.3.168 / Home 1.0.55**。移除9个无运行调用的旧文件，保留167功能与历史检查契约，见[168说明](https://github.com/yyhoworks/YoPlayer/blob/HEAD/docs/github/CLEANUP168.md)。最近公开交付仍为165。
保留[163筛选快照](https://github.com/yyhoworks/YoPlayer/blob/HEAD/docs/github/BROWSE163.md)、[162首页优化](https://github.com/yyhoworks/YoPlayer/blob/HEAD/docs/github/HOME161.md)及[160原生弹窗修复](https://github.com/yyhoworks/YoPlayer/blob/HEAD/docs/github/VALIDATION160.md)。源码与公开交付分别见[当前状态](https://github.com/yyhoworks/YoPlayer/blob/HEAD/docs/github/CURRENT.md)。
