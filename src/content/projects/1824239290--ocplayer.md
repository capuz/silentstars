# OcPlayer · Orange Cat Player

A native player for Jellyfin / Emby, built with SwiftUI for both platforms (primarily macOS, with iOS / iPadOS from the same codebase). The playback core is [liberika](https://github.com/AimesSoft/liberika), written in Rust (formerly Erika, with built-in FFmpeg decoding and libass subtitle rendering). Danmaku (bullet comment) support connects to dandanplay, and the app also integrates Bangumi anime tracking and MoviePilot for finding, downloading, and subscribing to titles.

## Features

- **Media library** — Automatically detects Jellyfin / Emby. Multiple servers are remembered and can be switched with one click. A server can have several addresses (LAN / Tailscale / reverse-proxy domain), and the app automatically picks the fastest reachable one and switches to another if it becomes unreachable. Library sorting, watch-status filtering, and full-library search. Home page with Continue Watching, Up Next, and Recently Added. Detail pages show complete media info (resolution, codec, bitrate, with audio and subtitle tracks listed individually) and a poster-based ambient background.
