# comfyui-zh-tag-autocomplete

Chinese tag autocomplete for ComfyUI: type **Chinese directly** into a node's text box and matching Danbooru English tags pop up for you to pick from. You can also **translate** an entire Chinese prompt into tags in one click. Chinese terms that aren't in the dictionary (including full sentence descriptions) are translated with Google or DeepSeek, which suits models like Anima that understand natural language.

For the SD WebUI / Forge version, see [sd-webui-zh-tag-autocomplete](https://github.com/wangjue520/sd-webui-zh-tag-autocomplete).

- Includes **125,778** tags with 50 or more Danbooru images, each with a Chinese name and several Chinese synonyms
- General tags include colloquial phrasings, e.g. `head_out_of_frame` ← "head out of frame" / "head outside the frame" / "head not captured"…; fuzzy matching also applies when phrasing isn't an exact match
- Characters and works support translated names, short names and community nicknames, e.g. `saber_(fate)` ← "my king" / "ahoge king" / "knight king"
