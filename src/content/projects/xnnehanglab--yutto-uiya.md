## 🎯 Features

- 🎬 **Video / Favorites / Collection Parsing** — Automatically identify type by inputting URL, supports batch parsing and grouped display
- 🖼️ **Video Detail Preview** — Displays cover, title, UP master, duration, view count
- ✅ **Batch Download Selection** — Select all / by group / single selection, flexible combinations
- 🎵 **Multi-format Export** — Supports exporting audio formats m4a / mp3 / flac / wav
- ⚙️ **Download Options** — Selectable video, audio, cover; supports specifying video quality
- 📊 **Download Queue** — Real-time progress, cancel tasks, directly open directory after completion
- 🔑 **Bilibili Account Login** — Scan code to log in, supports premium member content
- 📋 **Console Logs** — Real-time output, auto-scroll, one-click export
