# Prompt Optimizer: a Skill for any AI agent that turns rough requests into copy-ready prompts

**English** · [简体中文](https://github.com/Samuel-Shek/prompt-optimizer-skill/blob/HEAD/README.zh-CN.md)

Prompt Optimizer is a Skill for any AI agent that can load Skills. It turns a rough request or an existing prompt into one copy-ready prompt. It only rewrites the prompt and doesn't do the task. It keeps your wording verbatim and doesn't invent missing facts. If the request is already clear, the agent just does the work. It auto-optimizes only when the request is clearly vague or missing key information, or when you explicitly ask. If a tool can't install Skills, paste [`SKILL.md`](https://github.com/Samuel-Shek/prompt-optimizer-skill/blob/HEAD/SKILL.md) into its custom instructions. These docs are in English and Simplified Chinese; there is one skill, and it replies in the language you write in.
