# 📖 Project Description

An automatically updated collection of public VPN configs (`V2Ray` / `VLESS` / `Hysteria` / `Trojan` / `VMess` / `Reality` / `Shadowsocks`) for quick circumvention of blocks.
  
Each config is a TXT subscription that can be imported into almost any modern client (`v2rayNG`, `NekoRay`, `Throne`, `v2rayN`, `V2Box`, `v2RayTun`, `Hiddify`, etc.).

Configs are updated every **9 minutes** using GitHub Actions, so links from the section **«📋 General list of always up-to-date configs»** are always current.
