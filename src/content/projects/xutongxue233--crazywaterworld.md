# Crazy Water World · Voyage Console

  [](LICENSE)

Manage your Crazy Water World accounts on this machine. Connects directly to the game WebSocket to schedule reward claims, base management, hero development, and fleet missions. Supports independent per-account configuration, resource budgets, and runtime logs. Primarily targets Windows, with basic macOS runtime support.

[Quick Start](#快速开始) · [Features](#功能一览) · [Common Commands](#常用命令) · [Usage Guide](https://github.com/xutongxue233/crazywaterworld/blob/HEAD/docs/console-guide.md) · [Changelog](https://github.com/xutongxue233/crazywaterworld/blob/HEAD/CHANGELOG.md)

## Quick Start

### 1. Install the environment and download the project

Install **Node.js 22.12 or later** (also compatible with 20.x 20.19+) and Git, then reopen your terminal and run:

```powershell
git clone https://github.com/xutongxue233/crazywaterworld.git
cd crazywaterworld
```
