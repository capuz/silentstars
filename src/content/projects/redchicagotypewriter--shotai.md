## Project Overview

ShotAI brings local large language models, file Q&A, a document library, image understanding, image creation, and host monitoring together into one desktop application. After an administrator installs it on a Windows or Ubuntu host and prepares the models, other users on the LAN only need to open a browser; they do not need to install model runtimes separately.

ShotAI handles the interface, model management, task routing, file processing, and LAN sharing. Ollama and the local image runtime components perform the actual inference. Model weights are not included in the installation package.
