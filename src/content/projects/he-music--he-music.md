# HE-Music

> A minimalist music player, modified from and following [SPlayer](https://github.com/imsyy/SPlayer). SPlayer is a very beautiful player.
>
> This version is a backend-less pure frontend. It cannot run independently and is not compatible with SPlayer. Users who don't know about the backend service should use SPlayer.

An AI-driven Android version based on Flutter: [HE-Music-Flutter](https://github.com/he-music/HE-Music-Flutter.git)
