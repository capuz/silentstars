# Utatane / 転寝

Utatane is a main application for running Ukagaka on macOS.

Still in development. We are steadily increasing compatibility with existing ghosts. It is not a complete SSP package.

Supported Languages: Japanese / English / Simplified Chinese / Traditional Chinese / Korean

## What it can roughly do

### Ghost Display and Conversation

- Loading and switching between ghosts, shells, and balloons
- Display of multiple characters, surfaces, and SERIKO animations
- Window mode that consolidates ghosts and balloons into a single shared window across all ghosts or a separate window for each ghost
- Speech history with surface images that can be displayed in an independent window or within window mode
- Conversation, choices, and link playback via SakuraScript
- Mouse operations such as clicking, double-clicking, stroking, and wheel scrolling
- Calling and communication between multiple ghosts
- Saving character and balloon positions and selected shells and balloons per ghost
- Characters become semi-transparent while being dragged, displaying coordinates and movement distance (balloons also follow)
