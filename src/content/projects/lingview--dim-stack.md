# Dim Stack

> A simple and easy-to-use personal blog system

---

## 🌟 Project Introduction

**Dim Stack** is a personal blog system newly built on Spring Boot 4.

**Official QQ Group**: 577040366 (You can experience the preview version in the group)

### Core Features

- 📝 Content Management (CMS)
- 💬 User Interaction: Comments, Likes
- 🔖 Tag Classification: Supports cross-domain content organization
- 👥 User System: Personal homepage, article publishing management, complete RBAC permission system
- 📱 Responsive frontend, supports mobile browsing
- 📦 Supports server-side rendering (SSR) for homepage and article pages
- 🤖 Large model content review & generation
- 🖼️ Intelligent image compression
- 🔍 SEO Optimization: Dynamic Sitemap, Robots, search engine friendly
