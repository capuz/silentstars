# mixin-bot

An AI Agent application bot for China Telecom's 量子密信: **@ the bot** in a group, or **chat with it directly** in a 1:1 chat. Describe what you need, and it searches shared materials, calls tools, and sends the answer or generated files back to the original conversation.

By default, it is a product materials assistant with document processing capabilities: looking up products, sending original files, editing Word documents, selecting and compiling PPT slides, generating proposals from templates, and creating comparison tables, for document work in pre-sales, delivery, and after-sales. Swap in a different prompt and materials, and it becomes an assistant for another purpose.
