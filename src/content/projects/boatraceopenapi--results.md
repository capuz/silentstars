# 🚤 Boatrace Open API for Results

## ⚠️ Notes

> 
> ⚡ This API is **unofficial** and has no relation to the official BOATRACE website or organization.<br>
> 🕒 The data is not updated in real-time, but is updated **approximately every 30 minutes**. (Refer to cron.yml for the GitHub Actions schedule)<br>
> 🔍 It does not guarantee the accuracy or completeness of the data.<br>
> 🙇‍♂️ Please use it at your own risk.

## 📌 Overview

This API allows you to obtain results data for boat racing (kyotei).<br>
The data is published on GitHub Pages and provided in JSON format.

## 🌐 Endpoints

### [](https://github.com/BoatraceOpenAPI/results/tree/gh-pages/docs/v3)

```bash
https://boatraceopenapi.github.io/results/v3/YYYY/YYYYMMDD.json
```

### [](https://github.com/BoatraceOpenAPI/results/tree/gh-pages/docs/v2)

```bash
https://boatraceopenapi.github.io/results/v2/YYYY/YYYYMMDD.json
```

📅 YYYY → Year<br>
📅 YYYYMMDD → Year Month Day<br>
(Date is based on Japan Standard Time JST〔UTC+9〕)

* Due to a specification defect, **v1** has been discarded.
