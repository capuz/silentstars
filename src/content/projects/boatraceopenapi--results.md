# 🚤 Boatrace Open API for Results

## 🛑 Notice of Deprecation

> ⚠️ This repository (Boatrace Open API for Results) is **not recommended for future use**.<br>
> 
> 👉 Please use the successor repository [boatraceopenapi/api](https://github.com/boatraceopenapi/api) going forward.
> 
> ℹ️ Although it is deprecated, the data updates and API provision of this repository are **still operational**.<br>
> There is no immediate need to migrate existing usage, and it is possible to continue using it as is.<br>
> However, there is a possibility that updates may stop in the future, so please consider migrating to the successor API as much as possible.

## ⚠️ Important Notes

> **Before using this API, please check the following:**
>
> - ⚡ **This API is unofficial.**
>   It has no relation to the official BOATRACE website or related organizations.
>
> - 🕒 **Data is not real-time.**
>   Regular updates are performed approximately every 3 hours via GitHub Actions. Since it is not a real-time feed, there may be a delay of a few hours before the latest information is reflected.
