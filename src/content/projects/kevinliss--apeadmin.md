ApeAdmin is a back-office development framework built for the new era of AI applications. It is built on FastAPI + Vue3 to form a platform-based management foundation. Breaking away from the design approach of traditional back-office systems, it is natively adapted for AI Agent capability invocation.

The project supports plugin-based development and has a well-developed plugin community ecosystem. It includes built-in enterprise-grade foundations such as RBAC permission control, a plugin marketplace, and audit logging. The framework integrates an MCP-SSE gateway, which can wrap the features of the system foundation and business plugins directly as standardized AI tools for Agent invocation.
