# A-share Strong Stock Scanner v7.9

A stable and efficient **A-share strong stock scanning tool** with automatic multi-data-source fallback.

## ✨ Key Features

- **Dual data source with smart fallback**: Prefers AkShare, automatically switches to Baostock on failure
- **Multi-board adaptation**: Main Board / STAR Market / ChiNext / Beijing Stock Exchange use different parameters
- **Smart scoring system**: Outputs S/A/B/C/D five-level ratings + trading suggestions
- **Detailed technical indicators**: Big bullish candle count, chip efficiency, ADX trend, OBV money flow, relative strength RS, etc.
- **Risk control**: Dynamic ATR stop-loss levels + maximum drawdown protection
- **Report output**: Generates a complete Excel file (including indicator interpretation manual, top 20 volume-surge stocks, market statistics, etc.)
