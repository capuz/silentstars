# Codex Upstream Skills Marketplace

This is a public Codex Git Marketplace for distributing research, writing, documentation, development, and diagram design workflows that have clear upstream sources and redistributable licenses. Each packaged third-party Skill keeps its original directory, scripts, reference materials, resource files, and license. Versions and commit SHAs are recorded in `sources.json`. The external plugins Tavotto and Diagram Design are referenced in the marketplace manifest by their official branches, so installation fetches the complete upstream plugin.

## License Boundary

The MIT License in the repository root applies only to the wrapper scripts, manifests, validators, and documentation added in this repository. It does not change the license of any third-party content.

Please note in particular: Academic Research Skills and its Codex version use **CC-BY-NC-4.0**, which requires attribution and restricts commercial use. Other packaged sources use MIT or Apache-2.0. Full attribution is in `THIRD_PARTY_NOTICES.md`, and the locked license location for each Skill is in `sources.json`.
