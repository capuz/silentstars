# Goldfish Scheme / [金鱼 Scheme](https://github.com/MoganLab/goldfish/blob/HEAD/README_ZH.md)
> Make Scheme as easy to use and practical as Python!

Goldfish Scheme is a Scheme interpreter with the following features:
+ R7RS-small compatible
+ Python-like versatile standard library
+ AI Coding friendly
+ Small and fast

## Simplicity is Beauty
Goldfish Scheme still follows the same principle of simplicity as S7 Scheme. Currently, Goldfish Scheme only depends on [S7 Scheme](https://ccrma.stanford.edu/software/s7/), [tbox](https://gitee.com/tboox/tbox) and C++ standard library defined in C++ 17.

Just like S7 Scheme, [src/goldfish.hpp](https://github.com/MoganLab/goldfish/blob/HEAD/src/goldfish.hpp) and [src/goldfish.cpp](https://github.com/MoganLab/goldfish/blob/HEAD/src/goldfish.cpp) are the only key source code needed to build the goldfish interpreter binary.
