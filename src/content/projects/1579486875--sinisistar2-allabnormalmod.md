# SiNiSistar 2 "All Abnormal States" Mod

> **📦 Download**: [Latest release](https://github.com/1579486875/SiNiSistar2-AllAbnormalMod/releases/latest) — extract the archive and run `install.bat`; the installer will automatically locate the game directory.

A runtime mod for SiNiSistar 2 that turns all of the game's abnormal states (70 in total) into a floating panel where each one can be **freely toggled on or off and its level freely adjusted**.
It does not modify any game files; everything is done through the game's public interfaces.
