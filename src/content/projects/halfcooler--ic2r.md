## Introduction

IC2 is probably dead. There has been no official response from the open-source, and the successor developers are still absent.

But the community's voice has never ceased. Players have waited too long for a version that can run on higher versions, a pure IC2.

So someone stepped up. [IC2CR](https://github.com/yu1745/ic2-fabric) was the first to go open-source, making quite a splash. It is unclear how much it has altered the original work, but it is no longer a successor to IC2.

Our goal is: **to bring IC2 and its affiliated mods to 1.20.1 and higher versions as completely and modernized as possible, without changing the original functions and values.**

It is still the IC2 you remember, only now it is IC2R.
