# Doc View

Generate API documentation from Java source code in IntelliJ IDEA. Supports **Spring, Feign, Dubbo**, without starting the application and without configuring upload accounts.

[Install plugin](https://plugins.jetbrains.com/plugin/15305-doc-view) · [Quick start](https://github.com/liuzhihang/doc-view/blob/HEAD/docs/user-guide/index.md) · [Changelog](https://github.com/liuzhihang/doc-view/blob/HEAD/CHANGELOG.md) · [Report issues](https://github.com/liuzhihang/doc-view/issues)

## Three steps to get started

1. Search for and install `Doc View` in **Settings → Plugins → Marketplace**, then restart IDEA as prompted.
2. Open a Java project, wait for indexing to finish, then right-click an interface method or class declaration and select **Doc View**.
3. Preview the result. Use **Copy** to copy the Markdown, or **Export** to save the documentation.

**Requirements:** IDEA IU `263.7031.23` or later, Java 25. For older IDEA versions, choose a compatible older plugin version. For installable versions, refer to [Marketplace](https://plugins.jetbrains.com/plugin/15305-doc-view/versions) and [Releases](https://github.com/liuzhihang/doc-view/releases).
