# Echo Memory / 回声记忆

[中文文档](https://github.com/questionjie-max/echo-memory/blob/HEAD/README.zh-CN.md) · [Download v0.9.0](https://github.com/questionjie-max/echo-memory/releases/latest) · [MCP reference](https://github.com/questionjie-max/echo-memory/blob/HEAD/docs/mcp.md) · [Security](https://github.com/questionjie-max/echo-memory/blob/HEAD/SECURITY.md) · [Contributing](https://github.com/questionjie-max/echo-memory/blob/HEAD/CONTRIBUTING.md)

**Turn every conversation into long-term memory.** Echo Memory is a Personal Memory OS for AI-native work. It turns conversations, documents, decisions, and changing ideas into a traceable personal memory layer that can be reused by different AI agents.

> AI knows more about the world every day, but it still does not truly know you. Echo Memory gives your AI a memory of what you experienced, why you decided, and how your thinking changed.

**[Download the signed macOS release](https://github.com/questionjie-max/echo-memory/releases/latest)** or build from source.
