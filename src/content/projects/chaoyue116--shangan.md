# Shanggan (上岸)

**An civil-service exam practice app that fits 200,000 real exam questions on your phone. Works offline, has no ads, and explanations don't require a membership.**

An offline practice tool for civil service exams, public institution recruitment, and the Three-Support-One-Assistance program (三支一扶), covering 行测 (Administrative Aptitude Test) / 职测 (Occupational Aptitude Test) / 公基 (Public Basic Knowledge) / 申论 (Essay Writing) / 综应 (Comprehensive Application). Question banks, explanations, and formula images are all bundled in the installation package and run on local SQLite on the phone, so you can practice without a network connection.

The question sources are two sets: Fenbi (粉笔) with 166,000 questions, including official difficulty ratings and site-wide correct rates, and Huatu (华图) with 33,000 real exam papers, imported according to the official exam paper structure, with an official module tree and five difficulty levels.
