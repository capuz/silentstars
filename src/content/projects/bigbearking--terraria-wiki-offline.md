# Terraria Wiki Offline

An application built with .NET MAUI Blazor Hybrid that provides a fast, offline Terraria Wiki browsing experience.

[BigBearK's Personal Space - BigBearK Personal Homepage - Bilibili Video](https://space.bilibili.com/470138112)

## Core Features

### 1. Offline Browsing

- **Local Access**: Text, images, audio and video data are all stored locally and can be accessed without an internet connection.
- **Web Typography**: Uses built-in local web server and Iframe rendering to preserve the official Wiki's layout and styling.
- **Page Navigation**: Implements refresh-free page navigation within the app by intercepting internal links.
- **Image Viewer**: Includes an image viewer that displays the full-size image when clicked.

### 2. Search and Indexing

- **Real-time Search**: The top search bar provides keyword matching based on the local SQLite database, with a dropdown panel for entry preview. Also supports matching keywords for other list pages.
- **Page List**: Provides an **All Pages** overview view containing all pages in the database.
