# FlyWP Nginx and PHP config

### Update Cloudflare IP

To update CloudFlare IP's, run the command:

```bash
./scripts/cloudflare-ip.sh
```

### Update 8g Firewall

To update 8g Firewall rules, run the command:

```bash
./scripts/8g-firewall.sh
```
