# Hawtio React

A Hawtio reimplementation based on TypeScript + React.
This project reimplements the following Hawtio JS components in one project:

- [hawtio-core](https://github.com/hawtio/hawtio-core)
- [hawtio-integration](https://github.com/hawtio/hawtio-integration)
- [hawtio-oauth](https://github.com/hawtio/hawtio-oauth)

## Development

This project uses [tsup](https://tsup.egoist.dev/) and [Webpack](https://webpack.js.org/) for building packages.

See also [Developing Hawtio React](https://github.com/hawtio/hawtio-react/blob/HEAD/docs/developing.md) for the project styling, guidelines, and more details on development.
See [`Architecture`](https://github.com/hawtio/hawtio-react/blob/HEAD/docs/architecture.md) for high level overview of Hawtio concepts and building blocks.
