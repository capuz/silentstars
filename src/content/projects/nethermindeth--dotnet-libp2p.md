# dotnet-libp2p

The project aims to implement [libp2p](https://libp2p.io) to unlock building .NET peer-to-peer applications using a battle-tested specification of network communication of the new age.

The docs from the application developer perspective: [quick start](https://github.com/NethermindEth/dotnet-libp2p/blob/HEAD/docs/README.md), [sessions](https://github.com/NethermindEth/dotnet-libp2p/blob/HEAD/docs/sessions.md), [discovery](https://github.com/NethermindEth/dotnet-libp2p/blob/HEAD/docs/discovery.md), and [pubsub](https://github.com/NethermindEth/dotnet-libp2p/blob/HEAD/src/libp2p/Libp2p.Protocols.Pubsub/README.md).
As a libp2p protocol implementer, you may be interested in [more advanced tutorials](https://github.com/NethermindEth/dotnet-libp2p/blob/HEAD/docs/development/README.md). You can rewire and reconfigure the library in any way you want!
