# Lava

Lava is a modular infrastructure toolkit for Java 25, providing Java applications with ID, retry, bounded IO, JSON, HTTP/SSE, payment channel protocols, in-process scheduling, cryptography, and email capabilities.
Each module can be used independently without dependence on Spring or other application frameworks, applicable to backend services, command-line tools, and standalone Java applications.

- [GitHub](https://github.com/zhengshuyuncom/lava)
