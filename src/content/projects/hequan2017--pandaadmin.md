# pandaAdmin Panda Backend

> Author: He Quan, GitHub address: <https://github.com/hequan2017>, QQ group: 620176501

> Complete this tutorial from the beginning and be able to independently write a simple CMDB system.

> Currently, the mainstream development methods are divided into 2 types: MVC and MVVC. This project provides introductory tutorials for both MVC and MVVC (frontend-backend separation) approaches.

## Project Introduction

pandaAdmin (Panda) is a companion project for the 'Django Beginner's Guide to CMDB System' tutorial series: based on Django 2.2 + DRF 3.10 + MySQL, using CBV programming, implementing Token login authentication, user information interface, and a complete CRUD example (test table), with built-in API documentation and Django Admin backend for the frontend project [panda](https://github.com/hequan2017/panda) to call. Suitable for students who want to learn Django Web / CMDB development from scratch.
