# LiveCopilot

**Chinese** · [English](https://github.com/carey-bk/LiveCopilot/blob/HEAD/README.en.md) · [Chinese introduction page](https://carey-bk.github.io/LiveCopilot/) · [English website](https://carey-bk.github.io/LiveCopilot/en/)

Native macOS personal AI assistant based on [vortechron/stealth](https://github.com/vortechron/stealth), designed for interviews, meetings, and academic presentations. Retains Swift/SwiftUI, ScreenCaptureKit system audio, AVAudioEngine microphone, menu bar, floating window, global hotkeys, and local history.

V1.4.1 can choose between **local streaming recognition with Apple SpeechAnalyzer / SpeechTranscriber**, **local Paraformer Chinese/English streaming recognition**, or OpenAI Live for speech recognition; knowledge base can choose between **local BGE-M3** or OpenAI Embeddings; analysis can select OpenAI, DeepSeek, Qwen, GLM, Kimi, or OpenAI-compatible services. **You can also directly input questions when listening is turned off.** No AI voice playback, cloud vector database, Ollama, or account system.
