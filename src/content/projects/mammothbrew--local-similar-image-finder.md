# Local Similar Image Finder — Review Groups & Bulk Cleanup

AI Duplicate Photo Finder for Windows — detect exact and visually similar images across folders, compare duplicates side by side, review file paths and metadata, group matches, and clean up large photo libraries locally.

> **Offline-first design:** this project is organized around local processing on the user's Windows PC. The intended workflow does not require mandatory cloud upload.
