## Introduction
**ApiGo** is a multi-database plugin-based data source framework, an enterprise project scaffold, sql2Api, etc. It deeply integrates SpringBoot and Mybatis to implement dynamic data sources and dynamic SQL, functions, and stored procedures.
Supports MCP integration with AI office platforms such as WorkBuddy, Qianwen Office, and Doubao,
supports connecting SQL or/NoSQL data sources (mysql, oracle, postgresql, Dameng, TiDB, OpenGauss, StarRocks), etc.
Write SQL online with visual tools, then quickly generate interfaces to serve externally; interfaces can be taken online or offline with one click. This reduces the SQL writing needed for common interfaces, letting developers focus on more complex business logic.
Supports Mybatis tag syntax such as if, data masking, data transformation, national cryptography (SM-series) encryption, collaborative development, interface orchestration, and more.
