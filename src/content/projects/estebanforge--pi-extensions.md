# pi-extensions

Twenty-one [Pi Coding Agent](https://github.com/earendil-works/pi) extensions in one npm workspace. Install only what you need; each package publishes and installs on its own under the `@estebanforge` scope.

## Extensions

### [pi-agentmemory](https://github.com/EstebanForge/pi-extensions/blob/HEAD/packages/pi-agentmemory)

Cross-session memory via the agentmemory REST API.

```bash
pi install npm:@estebanforge/pi-agentmemory
```

### [pi-antigravity-bridge](https://github.com/EstebanForge/pi-extensions/blob/HEAD/packages/pi-antigravity-bridge)

Bridge Pi to Google Antigravity: ACP driver, approval gates, ask tool.

```bash
pi install npm:@estebanforge/pi-antigravity-bridge
```

### [pi-asana-me](https://github.com/EstebanForge/pi-extensions/blob/HEAD/packages/pi-asana-me)

Asana tasks, projects, and comments.

```bash
pi install npm:@estebanforge/pi-asana-me
```

### [pi-ask-antigravity](https://github.com/EstebanForge/pi-extensions/blob/HEAD/packages/pi-ask-antigravity)

One-shot delegation to Antigravity.

```bash
pi install npm:@estebanforge/pi-ask-antigravity
```
