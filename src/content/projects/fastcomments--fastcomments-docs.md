# fastcomments-docs

Documentation and Tutorials that lives at https://docs.fastcomments.com

## Contributing

duplicated by accident.

When you have something to show - create a pull request!

*Read the Conventions section below!*

## Setup

This project uses a small framework written in NodeJS. It requires Node 10 or newer.

    npm install

### Setup - Windows
    
    npm build-windows

### Setup - Linux/Unix

    npm build-posix

### Run Development Watch Job

    npm run watch

### Adding Content

1. In `src/content/guides`, add a folder.
2. Follow the pattern of the other folders for the file structure (you'll need an `items` directory and a `meta.json` for example).

#### Items Directory

The `items` directory is where the content for your guide lives. Content is organized by locale under `items/`, for example `items/en/`, `items/fr_fr/`, etc.

The default locale is `en` (defined in `src/locales.js`). Always add new content to `items/en/`. The `en_us` folders are generated by the translation system — do not use `en_us` as the source locale.
