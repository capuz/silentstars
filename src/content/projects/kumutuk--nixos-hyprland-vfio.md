# NixOS · Hyprland · AMD GPU Passthrough (VFIO)

A flake-based NixOS gaming desktop that passes its single AMD Radeon GPU through to a Windows 10 virtual machine, while using Hyprland for the host desktop. See [the repair and validation report](https://github.com/kUmutUK/nixos-hyprland-vfio/blob/HEAD/docs/REPAIR-AND-VALIDATION-REPORT.md) for current verification and the historical 2026-11-04 source-tree cross-checks.
