# LyricEditor

A much modified lyric editor with fancy (maybe) UI. Written in `C#`, `WPF`, `.NET 10`.

If you want to compile the source code, please use a Windows toolchain with the .NET 10 SDK installed.

The current UI is shown below. Only Chinese version is provided.

# 歌词制作器

一个优化了界面的歌词制作器，使用 `C#`，`WPF`，`.NET 10` 制作。
