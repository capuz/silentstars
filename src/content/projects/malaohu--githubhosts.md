# Purpose
Automatically retrieves the IP addresses that domains under Github.com resolve to, to solve the problem of users in mainland China being unable to access Github normally.

# Approach
Reference article: https://51.ruyo.net/17580.html

# Source code
Written in Golang. This is my first time writing a small program in Go, so if anything is wrong, please point it out, experts!

# Running
```
#Requires a local Golang environment to be installed
go run .\doit.go
```

On Windows, you can run github_hosts.exe directly.

On Linux, you can run github_hosts directly.
