# Purpose
Automatically obtain the IP addresses that GitHub.com domain names resolve to, and solve the problem of GitHub being inaccessible for domestic users

# Approach
Reference article: https://51.ruyo.net/17580.html

# Source Code
Written in Golang, first time writing small things in Golang. Please point out any mistakes!

# Running
```
# Local Golang environment installation required
go run .\doit.go
```

Windows can run github_hosts.exe directly

Linux can run github_hosts directly
