# Candy

**C**ode-oriented **A**nimation e**N**gine **D**esigned for t**Y**pst

Candy is an animation engine for Typst, using Rust as a high-performance rendering
and encoding backend. Inspired by 3Blue1Brown's
[Manim](https://github.com/3b1b/manim), with API inspiration from
[tanim](https://github.com/liquidhelium/tanim) and
[kino](https://github.com/aualbert/kino).

> **Documentation has moved.** The full, restructured docs live in [`docs/`](https://github.com/ViCo-Lab/candy/blob/HEAD/docs/README.md)
> — split into a [Tutorial](https://github.com/ViCo-Lab/candy/blob/HEAD/docs/tutorial/README.md) (learn by doing) and a
> [Reference](https://github.com/ViCo-Lab/candy/blob/HEAD/docs/reference/README.md) (look things up). This README is a short project
> overview; the package-specific READMEs are [`typst/README.md`](https://github.com/ViCo-Lab/candy/blob/HEAD/typst/README.md) (user DSL)
> and [`rust/README.md`](https://github.com/ViCo-Lab/candy/blob/HEAD/rust/README.md) (backend API).
