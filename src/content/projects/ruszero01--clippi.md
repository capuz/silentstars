# Clippi

  **Simple · Lightweight · Open-source** native clipboard manager<br>
  Rust + GPUI · Windows / macOS

## Core Features

- **Capture & organize**: Save copied content such as text, rich text, images, and files. Supports search, tags, favorites, notes, and batch operations.
- **Quick paste**: Summon the window with a global hotkey. The quick window does not interrupt your current input. Hold Alt to view and use the toggle shortcut.
- **Content recognition**: Image OCR and QR code recognition for quickly extracting and reusing content.
- **Cross-device sync**: Sync text entries and tags via OneDrive, an iCloud folder, or WebDAV. Multiple backends are supported.
- **Utilities**: Entry editing, an emoji and symbol panel, and a file transfer station.
- **Personalization & privacy**: Light and dark themes, font and theme color settings, redaction of sensitive content in previews, and local backup and restore.
