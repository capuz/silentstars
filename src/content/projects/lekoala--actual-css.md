# Actual CSS

Plain CSS component framework for new projects. Semantic classes, shared variants, small tokens, theme hooks, and progressive enhancement.

Documentation: <https://lekoala.github.io/actual-css/site/>

Actual CSS claims a documented set of global class names; the package publishes
it as [`actual-css/reserved-classes.json`](https://github.com/lekoala/actual-css/blob/HEAD/reserved-classes.json). Tools can
also read [`actual-css/components.json`](https://github.com/lekoala/actual-css/blob/HEAD/components.json) (components, imports,
hooks, docs URLs), [`actual-css/forms.json`](https://github.com/lekoala/actual-css/blob/HEAD/forms.json) (the same for forms)
and [`actual-css/tokens.json`](https://github.com/lekoala/actual-css/blob/HEAD/tokens.json) (public global tokens).

For existing projects: use cascade layers, import order, or your own build-time
prefix transform.

## Install

```sh
npm install actual-css
```
