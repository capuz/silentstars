# Paseo plugins

Plugins for [Paseo](https://paseo.sh). Each directory is a separate plugin with its own `paseo-plugin.json`, `OVERVIEW.md`, README and license. The interfaces come in English and Simplified Chinese, and you can add your own language (see [Languages](#languages)).

| Plugin | Directory | What it does |
| --- | --- | --- |
| Agent Observatory | [`agent-observatory`](https://github.com/zhjiang22/paseo-plugins/blob/HEAD/agent-observatory) | Results-first dashboard for every Paseo agent and subagent: unread queue, timelines, usage and token statistics, scheduled runs, optional AI reviews and turn summaries, plus alerts and scheduled sends. |
| Ferry | [`ferry`](https://github.com/zhjiang22/paseo-plugins/blob/HEAD/ferry) | Move a conversation to another provider and back. Providers that share a session store continue the same session; others get a budgeted handoff with a searchable history, and switching back sends only what was missed. |
| Project Notes | [`project-notes`](https://github.com/zhjiang22/paseo-plugins/blob/HEAD/project-notes) | Tasks, prompts and ideas per project, with one-tap prompt pills, a launcher that shows each started agent on its task, and an…
