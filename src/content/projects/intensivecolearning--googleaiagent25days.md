# Google 25-Day AI Agent Course

## Introduction

**Google Cloud Advent of Agents Study Plan (25 Days)**

**Advent of Agents (Google Cloud Edition)** is a series of challenges focused on building production-grade agents on Google Cloud using **ADK (Agent Development Kit)** and **Gemini 3** models. It is a complete path to building production-grade Google Cloud AI agents from scratch.

Course highlights
* 🎯 One feature per day, each taking under 5 minutes to try
* 📋 Ready-to-use copy-and-paste commands
* 📚 Links to official documentation
*  🆓 100% free

For more information, see Google Advent of Agents 2025 (the website is expected to remain open until March 2026): https://adventofagents.com/
