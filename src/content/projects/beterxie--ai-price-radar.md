# AI Price Memory

An open-source public price aggregation platform for AI subscription products. The project discovers products from public storefronts, performs standardization, classification, inventory and price updates, and provides price comparison through web catalogs with verifiable sources.

**Online site: [https://ai.pricememo.cn/](https://ai.pricememo.cn/)**

> This project is not an official website of OpenAI, Anthropic, Google, xAI, or any third-party storefront, and it does not handle transactions, payment collection, delivery, or after-sales service.
