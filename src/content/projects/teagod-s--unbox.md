Cross-platform <b>TVBox compatible</b> desktop player: live + on-demand, ready to use out of the box with a single installer.

UnBox is a desktop player for TV box / IPTV users. It supports TVBox single-line sources, FongMi multi-line sources (CMS JSON, drpy service, FongMi js0 crawlers), and M3U / TXT live sources. No service deployment or Go / Node environment setup is required. Download the installer for your platform and use it.

## ✨ Features

- **Live + On-demand**: One interface supports both IPTV live streaming and video on demand, with full category / group / search support.
- **Local media library**: Add local folders and recursively scan for videos. Supports poster / title display, automatically grabs the first video frame when no poster is available, resumes playback, and provides a unified playback entry point.
- **Smart playback routing**: H.264 uses the built-in web player (hls.js / mpegts.js / native `<video>`). Local containers such as HEVC / RTMP / MKV automatically switch to external mpv. MP4 / M4V / WebM prefer built-in web playback.
- **Resume playback**: Automatically records viewing progress and history. Continue watching with one click from the home page.
