# AI-Assisted Development Documentation

This directory contains all documentation for LLM-assisted development on the Skyline/ProteoWizard project.

## Quick Start

**New LLM session? Start here:**
1. Read [CRITICAL-RULES.md](https://github.com/ProteoWizard/pwiz-ai/blob/HEAD/CRITICAL-RULES.md) - Absolute constraints (limit: 100 lines)
2. Read [MEMORY.md](https://github.com/ProteoWizard/pwiz-ai/blob/HEAD/MEMORY.md) - Project context and critical gotchas (limit: 200 lines)
3. Read [WORKFLOW.md](https://github.com/ProteoWizard/pwiz-ai/blob/HEAD/WORKFLOW.md) - Git workflows and TODO system (limit: 200 lines)
4. Read active TODO in [todos/active/](https://github.com/ProteoWizard/pwiz-ai/blob/HEAD/todos/active/) - Current branch context

**Budget: 500 lines** for essential context - that is the sum of the three limits
above, not a measurement. For where these files actually stand right now:

```powershell
pwsh -File ./ai/scripts/audit-docs.ps1 -Section ai
```

**Need more?** See [TOC.md](https://github.com/ProteoWizard/pwiz-ai/blob/HEAD/TOC.md) for a complete index of every document with
descriptions and current line counts, regenerated by `ai/scripts/Generate-TOC.ps1`.
