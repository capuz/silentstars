# Librescoot

This project aims to create a free and open source firmware for iMX6-based electric scooters.

## Getting Started

For installation instructions, documentation, and the installer, please visit [https://librescoot.org/](https://librescoot.org/).

## Goals
- Create a fully open source scooter firmware
- Improve safety through transparency
- Enable community-driven development and customization
