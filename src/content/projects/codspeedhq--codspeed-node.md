Node.js libraries to create CodSpeed benchmarks

## Documentation

Check out the [documentation](https://docs.codspeed.io/benchmarks/nodejs) for complete integration instructions.

## Packages

This mono-repo contains the integration packages for using CodSpeed with Node.js:

- [`@codspeed/vitest-plugin`](https://github.com/CodSpeedHQ/codspeed-node/blob/HEAD/packages/vitest-plugin): vitest compatibility layer for CodSpeed
- [`@codspeed/tinybench-plugin`](https://github.com/CodSpeedHQ/codspeed-node/blob/HEAD/packages/tinybench-plugin): tinybench compatibility layer for CodSpeed
- [`@codspeed/benchmark.js-plugin`](https://github.com/CodSpeedHQ/codspeed-node/blob/HEAD/packages/benchmark.js-plugin): Benchmark.js compatibility layer for CodSpeed
- [`@codspeed/core`](https://github.com/CodSpeedHQ/codspeed-node/blob/HEAD/packages/core): The core library used to integrate with Codspeed runners
