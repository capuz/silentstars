# Architecture & Multi-Platform Hub (Architecture & Multi-Platform Hub)

Eridanus uses a unified multi-platform bridging architecture based on the **OneBot v11 protocol standard** and an **event-driven Hub**: there is no need to start multiple copies of the bot core plugins. The WebUI server acts as a WebSocket Hub relay, enabling seamless access and shared context across QQ, WebUI, Telegram, and mobile clients…
