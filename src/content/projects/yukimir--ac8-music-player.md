# ACE COMBAT 8 Interactive Music Player

On Windows, plays the *ACE COMBAT 8* soundtrack by the game's sections, loop points, and stems. The player remembers the last arrangement chosen for each track, supports switching stems by pass count and by bar, and allows manual queuing or immediate section switching in free arrangement.

## Android Phone Playback

The phone version uses Kotlin, Jetpack Compose, and Material 3 Expressive. arm64 phones running Android 8.0 or later can receive music, and x86_64 emulators can also run it. On first use, connect the phone and computer to the same local network.
