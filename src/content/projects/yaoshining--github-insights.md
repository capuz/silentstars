# GitHub Insights 📊

> Daily tracking of GitHub popular projects, AI open-source dynamics, and technology trends

## Directory Structure

```
github-insights/
├── README.md                      # Project homepage
├── index.html                     # Latest report entry point
├── reports/
│   └── 2026/
│       └── 03/
│           ├── index.html         # Monthly report index
│           └── 2026-03-25.html    # Daily report
└── posts/                        # In-depth articles/series topics
    └── template.html             # Article template
```

## Series Description

- **Daily Reports (reports/)**: Daily GitHub Trending popular projects selection
- **Articles (posts/)**: In-depth technical analysis, project reviews, trend interpretation

## Publishing

Website entry: [GitHub Insights](https://yaoshining.github.io/github-insights/).

New daily reports use `reports/YYYY/MM/DD.html`, following complete Chinese HTML and responsive dark card layout. Dates are calculated in Beijing time, noting data collection time, source, and ranking criteria; total stars and daily additions are recorded separately. Data snapshots can be saved in `DD.json` in the same directory.
