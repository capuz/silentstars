# GitHub Insights 📊

> 每日追踪 GitHub 热门项目、AI 开源动态与技术趋势

## 目录结构

```
github-insights/
├── README.md                      # 项目首页
├── index.html                     # 最新报告入口
├── reports/
│   └── 2026/
│       └── 03/
│           ├── index.html         # 月度报告索引
│           └── 2026-03-25.html    # 每日报告
└── posts/                        # 深度文章/系列专题
    └── template.html             # 文章模板

## 系列说明

- **日报 (reports/)**: 每日 GitHub Trending 热点项目精选
- **文章 (posts/)**: 深度技术分析、项目评测、趋势解读

```
