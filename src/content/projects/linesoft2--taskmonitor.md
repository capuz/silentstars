# TaskMonitor

**Chinese** | English (TODO)

Monitor system load in real time from the process dimension.

## Installation & Usage

Recommended for use on Windows 11. This project is distributed as a single-file EXE that can be downloaded directly from the release page.

Download: [CNB (China-friendly)](https://cnb.cool/linesoft2/TaskMonitor/-/releases) | [GitHub](https://github.com/linesoft2/TaskMonitor/releases)

After downloading and opening, you can see a persistent taskbar window on the left or right side of the **system taskbar** (depending on your taskbar settings). Click on any item to view its details and the high-load processes of that item.

## Development Background

When a program performs high-load tasks or the system becomes sluggish, we often need to check the system load and locate which specific program/process is executing the high-load task. TaskMonitor was born from this need. It not only resides in the taskbar to display real-time load across five dimensions, but also allows viewing details of each item and the load of each process when clicked.
