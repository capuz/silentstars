# Qishui Music Android Automation Script

An automation script built on the AScript Android engine that automatically watches Qishui Music ads to earn free listening time.

> ### 📌 Source Statement (Acknowledgment of the Original Author)
>
> **This project is adapted from the open-source project [wei6718189/qishuiAScriptProject](https://github.com/wei6718189/qishuiAScriptProject) by [@wei6718189](https://github.com/wei6718189) (iOS version)**
>
> The original project is an iOS-only script that depends on WebDriverAgent + `ascript.ios.*`.  
> This project builds on it to complete **full Android platform adaptation**, rewriting it to use the `ascript.android.*` engine, and completes end-to-end stability hardening for the complex ad ecosystem. The original iOS code is fully preserved at [`__init___ios_backup.py`](https://github.com/wangyudawang1/qishuiAScriptProject/blob/HEAD/__init___ios_backup.py).
>
> Heartfelt thanks to the original author [@wei6718189](https://github.com/wei6718189) for the open-source contribution!
