# Subs Free

Built on [Wails v3](https://v3.wails.io/), a cross-platform client program for [subs-check-pro](https://github.com/sinspired/subs-check-pro), supporting `Android phones` and `Windows`, `Linux`, `Mac`.

## ✨ Features

- [x] Native UI support for `Windows`, `Linux`, `Mac`, `Android`
- [x] Auto-start on boot, run scheduled tasks in the background
- [x] Auto-check for updates, version upgrades
- [x] Support for switching configuration files, port conflict detection
- [x] One-click to get subscription links and detection result analysis reports
- [x] Support for native system notifications
- [x] Support for notification channels like DingTalk, TG, email, etc.
