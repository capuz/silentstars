## ⚡ About the project

**Tachyon** is a high-performance, autonomous and uncompromising solution for orchestrating network traffic, proxying and bypassing censorship on routers running **OpenWrt** (full compatibility with **OpenWrt 23.05, 24.10, 25.x and SNAPSHOT**). A direct fork of the **[Forkop from @ushan0v](https://github.com/ushan0v/forkop)** project (formerly **Podkop Plus**).

Tachyon combines the **sing-box** core, the high-speed **FPTN** (Fast Packet Tunnel Network) protocol, local hardware DPI bypass tools (**Zapret v1 / Zapret v2 / ByeDPI**), an interactive combinatorial **DPI Strategy Fuzzer**, a secure **Telegram management bot**, and an innovative **AI Stack** (autonomous **AI Doctor v2.5**, offline diagnostics, **HTTP REST Agent API / OpenAPI 3.0** and **MCP Server** for connecting AI agents).

All internal logic is implemented on the **ucode** scripting engine — a native C interpreter for OpenWrt, providing ultra-low RAM consumption (from 128 MB RAM) and instant response.
