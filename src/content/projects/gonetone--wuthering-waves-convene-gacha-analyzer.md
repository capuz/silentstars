# Wuthering Waves Convene Gacha Analyzer

Traditional Chinese | [Simplified Chinese](https://github.com/GoneTone/wuthering-waves-convene-gacha-analyzer/blob/HEAD/README_ZH-HANS.md) | [English](https://github.com/GoneTone/wuthering-waves-convene-gacha-analyzer/blob/HEAD/README_EN.md) | [Japanese](https://github.com/GoneTone/wuthering-waves-convene-gacha-analyzer/blob/HEAD/README_JA-JP.md)

I developed a software tool for analyzing convene gacha banner history. Once you open it, all the data is clearly laid out, so you no longer have to calculate things by hand!

How this software works: after you press "Update Data", an interception program that runs only on your computer is started locally. It requires administrator privileges, so a UAC prompt will appear; please click "Yes". The program also automatically installs a locally generated root certificate. It then redirects the single request that the Wuthering Waves convene record page makes to the official convene history API so that it is parsed locally, which intercepts that request.
