# ComputeSec (计算安全小助手)

**A Linux desktop security assessment tool built with **GTK4 / libadwaita / Python**. It reads your system state, compares it against a security baseline, explains in plain language what each check means and the harm of what's missing, and gives repair steps you can copy and paste directly. Where things are done well, it tells you in green: keep it up! 🤗**

  [🇨🇳 Chinese] • <a href="README.en.md">🇺🇸 English</a> •

## Why build this?

To make security hardening feel approachable.

For ordinary users without a technical background, "security hardening" often feels like a distant concept. Most professional security advice makes people feel overwhelmed before they even start. So 梨 built this small tool.

In ComputeSec, security advice is written in plain language and is actionable. It won't tell you "your CPU has a silicon defect", which is just useless scaremongering. It will tell you "IOMMU is turned off in your BIOS; reboot now and turn it on". That is real security engineering.
