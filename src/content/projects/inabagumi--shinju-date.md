# SHINJU DATE

"[SHINJU DATE](https://shinju.date/)" is a web service that lets you search videos that talents affiliated with [Nanashi Inc.](https://www.774.ai/) have streamed or posted on [YouTube](https://www.youtube.com/). It is developed and operated by [Haneru Developers](https://haneru.dev/), a non-profit, non-commercial group with no direct relationship to Nanashi Inc., in accordance with the [derivative work guidelines set by Nanashi Inc.](https://www.774.ai/guideline).

## Project Structure

This project is a monorepo composed of multiple applications and shared packages.

### Applications (`apps/`)

- **[web](https://github.com/inabagumi/shinju-date/blob/HEAD/apps/web/)** - Frontend for the public website (https://shinju.date)
- **[admin](https://github.com/inabagumi/shinju-date/blob/HEAD/apps/admin/)** - Admin interface for content management
- **[batch](https://github.com/inabagumi/shinju-date/blob/HEAD/apps/batch/)** - Scheduled batch processing (Nitro)
