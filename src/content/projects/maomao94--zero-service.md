# Zero-Service

A collection of Go microservices designed for industrial IoT and edge integration scenarios. The project is built on [go-zero](https://github.com/zeromicro/go-zero) and covers capabilities including industrial protocol access, stream data processing, task scheduling, real-time communication, and UAV docking stations.

Zero-Service is not a monolithic application that must be deployed as a whole. Each service can run independently as needed, or can be combined through gRPC, Kafka, MQTT, and SocketIO to form a complete business workflow.
