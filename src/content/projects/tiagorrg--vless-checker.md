# VLESS Key Checker

Automatic service for finding working VLESS keys with server availability checks.

🌐 **Website:** [tiagorrg.github.io/vless-checker](https://tiagorrg.github.io/vless-checker/)

---

## How to use

Open the website and choose the desired mode:

### Regular VPN (full traffic tunnel)

| Country | Description |
|---|---|
| 🇪🇪 **Estonia** | Recommended for Russia — close, fast |
| 🇫🇮 **Finland** | Close to Russia, stable connection |
| 🇩🇪 **Germany** | Good bandwidth |
| 🇸🇪 **Sweden** | Fast servers, close to Russia |
| 🇳🇱 **Netherlands** | One of the largest internet hubs in Europe |

### Whitelists (tunneling only blocked sites)

| Mode | Description |
|---|---|
| 🌐 **Whitelists** | Only blocked sites through VPN, everything else directly |
| 🇷🇺 **Russia (Moscow)** | Through Moscow servers — for whitelists |

Click **Copy** and paste the key into your VPN application (v2rayTUN, Hiddify, Streisand, etc.).
