# Resource site, a platform for gathering and collecting film and television resource sites and collection sites, including video sources, playback sources, json, xml, and other formats, supporting LibreTV, maccms, LunaTV, KatelyaTV, OrionTV, MoonTVPlus, etc.

An open-source tool for automatically monitoring the availability of the film and television resource site [ziyuanzu.com](https://www.ziyuanzu.com/), running on a schedule via GitHub Actions, generating static monitoring pages and publishing them through GitHub Pages.

**✨ New: MCP (Model Context Protocol) server support - allows AI tools to directly query resource site data!**

## Features
- **Scheduled Monitoring**: Automatically fetch and check the status of all resource sites every 2 hours
- **Real-time Data**: HTTP status codes, response times, online/offline status
- **Static Pages**: Automatically generate a visually appealing dark-themed monitoring dashboard
- **Historical Archive**: Each monitoring result is saved as JSON, supporting historical comparisons
- **GitHub Pages**: Zero-cost deployment, automatic updates
- **🤖 MCP Server**: Provides resource site query capabilities for AI tools like Claude/Cursor
