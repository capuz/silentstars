## Overview

FAT-P provides containers, concurrency primitives, memory management utilities, serialization, and diagnostic tools as a self-contained, header-only library. Copy `include/fat_p/` into your project and go — no build system integration required.

## How This Library Was Built

All code, architecture, documentation, and governance in this library were authored by AI systems — primarily Claude (Anthropic), with contributions from ChatGPT, Gemini, and Grok. The human ([Matthew Schroeder](https://github.com/schroedermatthew/FatP/blob/HEAD/Authors.md)) provided direction, constraints, and judgment but wrote none of the code.
