# Agent Lookout

See every AI coding agent running on your computer on one page, and which one is waiting on you.

It finds your Claude Code, Codex, Antigravity, Antigravity CLI, Mistral Vibe, Gemini CLI, OpenCode, Qwen Code, Hermes Agent and Cline sessions on its own, with no setup. It never starts a session, and it stops one or answers a prompt only when you press the button, or by a rule you set.

[Install](#install) · [Download for Mac](https://github.com/Olanetsoft/agent-lookout/releases/latest) · [Guide](https://github.com/Olanetsoft/agent-lookout/blob/HEAD/docs/GUIDE.md) · [Privacy](#privacy) · [Changelog](https://github.com/Olanetsoft/agent-lookout/blob/HEAD/CHANGELOG.md) · [Website](https://www.agentlookout.app)

_A Claude Code session asks to run `npm test`. With the Claude Code plugin, Allow or Deny answers it from the page, and Jump takes you to it in Terminal._

## Install

**With Node.js 22.12 or newer**, on macOS, Linux or Windows:

```sh
npx agent-lookout
```

Then open http://127.0.0.1:4777. Your sessions appear within a few seconds.
