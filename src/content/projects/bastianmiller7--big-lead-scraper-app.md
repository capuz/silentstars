## Overview

Big Lead Scraper is a web application designed for scraping lead data. It brings lead-focused scraping activities into a browser-based interface that can support broader lead generation work.

The project is suited to people who want a simple web tool for managing lead scraping tasks. Since it is built as an HTML application, it can be opened in a modern browser without a dedicated desktop client.
