# 🚀 GersangStation | GersangStation
A comprehensive utility program for Gersang multi-client (다클라) users.

[<img width="200" height="200" alt="StoreLogo scale-400" src="https://github.com/user-attachments/assets/e1099422-467c-43b8-910d-f5ca56058dd9" />](https://apps.microsoft.com/detail/9NVVQ6MLSWQB?hl=ko-kr&gl=KR&ocid=pdpshare)

## ✨ Features
- [X] Gersang auto-login and game launch<br>
- [X] Multi-account & multi-client support (up to 3)<br>
- [X] Fast, lightweight multi-client creation<br>
- [X] Game installation and patch support<br>
- [X] Support for main server, test server, and Cheonra server<br>
- [X] Display of game notices and events (highlighted when ending soon)<br>
- [X] Easily claim event rewards from a browser page<br>
- [X] Enhanced mouse confinement (Contributed By [@chlrhkd4](https://github.com/chlrhkd4))
- [X] Enhanced window switching (quickly and easily switch between clients 1, 2, and 3)
- [ ] (In development) Planner (schedule management for dormant accounts and production facilities, alerts for siege/national suppression battles, etc.)
