# Linux DO Threaded Reading

Chain replies together by their discussion relationships, or switch back to a quote mode that reads in floor order.

**Current version: v6.1.2** · [Forum sharing and feedback](https://linux.do/t/topic/3021097) · [Changelog](https://github.com/mengxiaoww/linuxdo-threaded-reader/blob/HEAD/CHANGELOG.md)

## Installation / Update

1. Install a userscript manager such as Tampermonkey in your browser, and allow access to `linux.do`.
2. [Open the full script](https://raw.githubusercontent.com/mengxiaoww/linuxdo-threaded-reader/main/linuxdo-comments.user.js). If the manager shows an install page, follow the prompts; otherwise copy all the code, create a new script in the manager, and fully replace its contents.
3. After saving, refresh any topics that are already open. When updating from an older version, replace the original script to avoid running two copies at once.

The script in the repository keeps its original formatting and is not minified. The download file is at [linuxdo-comments.user.js](https://github.com/mengxiaoww/linuxdo-threaded-reader/blob/HEAD/linuxdo-comments.user.js).
