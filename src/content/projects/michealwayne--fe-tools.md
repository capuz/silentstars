# fe-tools

  Front-end resource navigation, browser tools, a TypeScript utility package, and project templates

------------------

## Quick Entry

Choose an entry point based on your goal:

- **Look up front-end resources**: Start from [Common Websites and Resources](#1-常用网站), suitable for looking up documentation, compatibility, frameworks, and engineering resources.
- **Use tools directly**: Install the [Chrome extension](#fe-tools---chrome插件), suitable for everyday tasks such as JSON, SVG, regex, screenshots, and API debugging.
- **Install utility functions**: See the [utils package](#21-utils说明) and choose an npm package based on your runtime environment.
- **Create a project**: See the [project-templates](#22-project-templates-一些前后端项目模版), copy it, then start it following the template README.

> This repository contains four categories: resource navigation, browser tools, a TypeScript toolkit, and project templates. They can be used independently, and you do not need to read the full README at once.
