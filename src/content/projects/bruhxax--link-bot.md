# Link-Bot

Telegram-бот, Mini App и веб-кабинет для VPN-подписок Remnawave.

## Features

| Cabinet | Sales | Administration |
| :--- | :--- | :--- |
| Telegram and browser | Plans, trial, devices and traffic | Integrations, design and content |
| Subscriptions, balance and history | Payment systems and Telegram Stars | Finance, GA4 and Яндекс Метрика |
| Tickets, FAQ and AI assistant | Promo codes, referrals and review rewards | Mailings and languages: RU / EN / FA |

In **Content → Telegram → Main menu → Pinned message** you can write a message in the bot's chat, preview it, and enable pinning on `/start`. The user first receives the pinned message, then the regular menu. The current pinned copy is not duplicated; an unpinned copy is pinned again, and a deleted one is restored. Formatting, premium emoji, and attachments are preserved. There is no mass sending. Turning it off removes only this pin.

In the **Plans → Order of plans and payment methods** editor, the pencil icon next to a payment method lets you set a name and description for that payment option in the cabinet. Empty fields use the system values. Click "Done", then save the changes to the plans.
