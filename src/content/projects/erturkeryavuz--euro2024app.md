# Euro2024App

An iOS football companion application built with **SwiftUI** and **Firebase** (Firebase Authentication, Cloud Firestore, and Firebase Storage), accompanied by a JSON tournament dataset and a Python Firestore seeding script.

The repository also includes a self-contained, zero-backend **interactive phone-framed web showcase** under [`docs/`](https://github.com/erturkeryavuz/Euro2024App/blob/HEAD/docs/) that faithfully reproduces the SwiftUI views and preserves all 20 national teams, 220 real player identities, and 5 bundled sample matches using verified Creative Commons photography and original geometric badges.

**Live Interactive Showcase (GitHub Pages):** [https://erturkeryavuz.github.io/Euro2024App/](https://erturkeryavuz.github.io/Euro2024App/) *(static browser simulation — no live Firebase)* · [Third-Party Photo Credits & Licenses](https://erturkeryavuz.github.io/Euro2024App/notices.html)
