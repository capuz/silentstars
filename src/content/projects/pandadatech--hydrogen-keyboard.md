# 轻键 Hydrogen Keyboard

Windows on-screen keyboard, single-file, no third-party runtime dependencies, runs from XP to 11.

## Features

- **Click to input**: Native Win32 GDI double-buffered rendering, key response with no noticeable latency; Backspace, Delete, Space, and Arrow keys support continuous repeat when held.
- **Resolution adaptive**: Scales proportionally by DPI at 1080P / 2K / 4K (125% to 250%), window freely draggable in eight directions, key caps and font size scale together; rounded corners vary by Windows version, Windows 11 uses native rounded corners, older systems are custom drawn.
- **Transition animations**: Window appearance and disappearance use native system offset and transparency gradients, main keyboard, settings window, and close prompt window unified at 400ms fade in and fade out.
- **Complete QWERTY and Fn layer**: Standard full keyboard layout; click `Fn` to switch number row to F1 through F12 function keys.
- **Font**: Uses [MiSans Medium](https://hyperos.mi.com/font). Consistent appearance in offline and WinPE environments without installing system fonts.
