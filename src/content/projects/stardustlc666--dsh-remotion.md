# Remotion

**Make React projects into videos in DSH.**

**[Installation](#安装) · [Usage flow](#开始使用) · [Full documentation](https://github.com/STARDUSTLC666/dsh-remotion/blob/master/docs/REFERENCE.zh.md)**

## Features

- Use official skills and workbench templates.
- Manage projects, asset order, and Studio preview.
- Export a local MP4 and keep an editable project backup for later changes.

## Installation

Install `dsh-remotion` from the “Plugins” panel in the DSH desktop app. Once the command line is configured, you can also install it with:

```bash
dsh plugin --profile desktop add dsh-remotion
```

For the web version, change `desktop` to `web`. After installing, restart the corresponding DSH. The host requirement follows the `>=0.2.2-rc.3` declared by the package.
