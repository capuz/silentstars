# OpenChain Project Japan Work Group(JWG)

OpenChain Japan Work Group (hereafter Japan WG) is one of the activities of the [OpenChain Project](https://www.openchainproject.org/). Therefore, we first explain the OpenChain Project.

## About the OpenChain Project
* The OpenChain Project is an open project hosted by the [Linux Foundation](https://www.linuxfoundation.jp/), which aims to build trust across the supply chain (between organizations) by promoting compliance with Open Source Software (hereafter OSS) licenses.
* It provides [specifications](https://github.com/OpenChain-Project/Specification/tree/master/Official/ja/2.1) for OSS license compliance, a curriculum, and a [self-certification program](https://certification.openchainproject.org/?locale=ja).
* The OpenChain Project defines Platinum members and general members.
* Platinum members are paid members and can attend the OpenChain Project board meetings.
* General members can participate in the activities freely and at no cost.
* For details, please contact the Project General Manager, [Shane Coughlan](https://github.com/OpenChain-Project/OpenChain-JWG/blob/HEAD/<mailto:coughlan@linux.com>).
