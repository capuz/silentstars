# agent-plugins

A repository of plugins for AI agents, published by u-ichi. Each plugin supports both the Claude Code plugin format and [Agent Plugins](https://agent-plugins.org/) (Codex, Cursor, GitHub Copilot, etc.). The skills inside are `SKILL.md` files from [Agent Skills](https://agentskills.io/), and both environments reference the same files.

| plugin | Overview |
|---|---|
| [figure-docs](https://github.com/u-ichi/agent-plugins/blob/HEAD/plugins/figure-docs) | A skill for creating documents meant to be read by people (reports, decision materials, business materials, development explanations), centered on figures. Includes samples of 112 business figures and 38 development figures. For details, see the [plugin README](https://github.com/u-ichi/agent-plugins/blob/HEAD/plugins/figure-docs/README.md) |
