# Ait

**Manage multiple programming agents in one interface.**

Ait supports Codex, Claude Code, OpenCode, DeepSeek Harness, Pi, Oh My Pi, and other programming agents.
You can use several agents on your computer at the same time, view files and Git changes, and operate the terminal. You can also connect from a phone or another computer to check progress, send messages, and handle approvals.
Ait provides a central relay service. When devices are not on the same network, log in to the same account to connect to an online work computer, without configuring a public IP or router port forwarding on the work computer.

[Download and install](https://github.com/ait-app/ait/releases) · [Changelog](https://github.com/ait-app/ait/blob/HEAD/CHANGELOG.md)

## What you can do

- **Agent chat**: Send tasks, view replies, tool calls, and run status, and handle permission approvals.
- **Projects and files**: Add projects, create Git worktrees, browse files, view code changes, and use the terminal.
