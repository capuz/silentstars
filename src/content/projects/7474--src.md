# SRC#（Simulation RPG Construction Sharp）

This is a C# .NET port of [SRC (Simulation RPG Construction)](http://www.src-srpg.jpn.org/). It is called SRC# (SRC Sharp).

The goal is to run original SRC (VB6) scenarios and data as-is. It runs on Windows, as well as macOS, Linux, and browsers.

## Usage

| Purpose | Software | Get / Run |
|---|---|---|
| Play in a browser | SRC#Web (recommended) | https://src.koudenpa.net/ (release version; the site is managed in [7474/SRC-Site](https://github.com/7474/SRC-Site)) ・ https://7474.github.io/SRC/web/ (development version). You can also host it on your own site ([Hosting on an external site](https://github.com/7474/SRC/blob/HEAD/docs/gui/web-hosting.md)) |
| Play on Windows, macOS, Linux | SRC#Avalonia (recommended) | [Releases](https://github.com/7474/SRC/releases) `SRCSharpAvalonia-<OS>.zip` ・ [Quick start](#srcavalonia) ・ [Documentation](https://github.com/7474/SRC/blob/HEAD/docs/gui/avalonia.md) |
| Play on Windows (x64) | SRC#Form (maintenance only) | [Releases](https://github.com/7474/SRC/releases) `SRCSharpForm.zip` ・ [Quick start](#srcform) |
| View data | Data viewer | https://7474.github.io/SRC/ ・ https://srcv.7474.jp/ |
