# MangaAlpha

**MangaAlpha** (formerly `fake-komga-115`) is a **100% pure Go (`CGO_ENABLED=0`), single-file, self-contained** lightweight Komga-compatible comic library and reading server. It also ships as a standalone Android app.

It unifies the **115 cloud drive**, **server-local / SMB mounted directories**, and **WebDAV (CloudDrive2 / OpenList / NAS)** into one library, with support for multi-source layered union libraries. It includes a **responsive web bookshelf and reading history timeline**, a **Simplified Chinese dual-page web reader with automatic white-margin cropping**, a **dual-engine Bangumi (`bgm.tv`) metadata scraping center that uses a Chinese synopsis-enhancing mirror by default**, **cross-platform update detection**, and an **AI Agent library governance API**. It is fully compatible with **Mihon (Komga extension)**, **Koharia**, and **KOReader (OPDS v1.2 + OPDS-PSE)** clients.
