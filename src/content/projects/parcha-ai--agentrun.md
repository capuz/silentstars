# AgentRun

Open-source packages for your pi agent. Install the ones you need.

This repository holds the AgentRun harness: the workflow DSL and the pi extensions around it.

**pi-vision** lets a pi agent answer questions about documents, images and video, and show the page, second or region each answer rests on. Try it free, with no key (the models are scripted): `npm run demo:vision -- examples/document-check`. It needs ffmpeg, ffprobe, pdftoppm and pdftotext (`brew install ffmpeg poppler`, or `sudo apt-get install ffmpeg poppler-utils`). See [pi-vision](https://github.com/Parcha-ai/agentrun/blob/HEAD/packages/pi-vision/README.md).
