# Free Node Subscriptions: Usage Guide for Clash, V2RayN, and Shadowrocket

A public subscription directory for Clash, V2RayN, v2rayNG, and Shadowrocket (小火箭). The project maintains only two easily recognizable subscription formats that are simple to import: **Base64 universal subscription** and **Clash YAML subscription**.

> Project homepage: [nodes.udptoos.com](https://nodes.udptoos.com/) · Update frequency: every 2 hours · This repository makes no promises about node speed, stability, or availability in any region.

## Subscription Links

| Format | Compatible clients | Subscription link |
| --- | --- | --- |
| Base64 (universal) | V2RayN, v2rayNG, Shadowrocket / 小火箭, and other clients that support URI subscriptions | `https://nodes.udptoos.com/subscriptions/base64.txt` |
| Clash YAML | Clash Meta, Mihomo, Clash Verge, ClashX, and other YAML configuration clients | `https://nodes.udptoos.com/subscriptions/clash.yaml` |
