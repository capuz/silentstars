# Chinese

## What is this

HKUST(GZ) Connect is used to access Hong Kong University of Science and Technology (Guangzhou) intranet websites and servers from outside campus.
It comes with a multi-tab campus browser, so ordinary users don't need to install Clash, configure proxies, or modify system DNS:
Just log in and click "Open Campus Website".

The application only handles the campus browser and software that actively connects to the local proxy port. It does not modify system DNS, system proxy, default routes, or the network environment of other browsers. No need to "fix network" after exiting.
