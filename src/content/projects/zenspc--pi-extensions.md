# Pi Extensions

Installable packages for the [Pi coding agent](https://pi.dev), published under `@zenspc`.

> Unmaintained extensions are preserved in [`packages/archived/`](https://github.com/zenspc/pi-extensions/blob/HEAD/packages/archived).
> See the [archive README](https://github.com/zenspc/pi-extensions/blob/HEAD/packages/archived/README.md) for their status and limitations.

## Packages

| Package | Install | What you get |
|---|---|---|
| [`@zenspc/pi-autopilot`](https://github.com/zenspc/pi-extensions/blob/HEAD/packages/pi-autopilot) | `pi install npm:@zenspc/pi-autopilot` | Autonomous task DAGs, isolated workers, verification, review, and quota recovery |
| [`@zenspc/pi-browser`](https://github.com/zenspc/pi-extensions/blob/HEAD/packages/pi-browser) | `pi install npm:@zenspc/pi-browser` | Drive a dedicated Chrome with per-domain approval |
| [`@zenspc/pi-devtools`](https://github.com/zenspc/pi-extensions/blob/HEAD/packages/pi-devtools) | `pi install npm:@zenspc/pi-devtools` | `/ctx` context audit + richer footer |
