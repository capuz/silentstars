# Projeto Final de Computação Gráfica — BomberMan

> Jogo web 2D inspirado no clássico Bomberman, com modos solo e dupla local, implementado em JavaScript para disciplina universitária.

## 🎮 Jogar agora

- [GitHub Pages](https://dillikel.github.io/bomberman/)
- [Plataforma DCC](https://www.plataformadcc.com.br/)

## Sobre

Este projeto é uma implementação autoral do Bomberman, criada como trabalho final para a disciplina de **Computação Gráfica** do curso de Ciência da Computação na **UFRR**. A proposta foi desenvolver um jogo funcional e visualmente atrativo, usando sprites, animações e lógica de colisão e explosão em canvas.

O desenvolvimento foi em dupla, cobrindo todas as etapas: concepção, lógica, arte e programação. O jogo roda diretamente no navegador, sem dependências externas — o Kaboom.js está embutido localmente.
