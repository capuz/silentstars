# KikoeruManager

An integrated local and remote workbench for the DLsite doujin audio library. It is not just a simple "extract and rename" script. It chains together archive recognition, automatic extraction, metadata scraping, inventory intake, subtitle matching, ASMR completion, DLsite bonus content detection, HTTP external-link downloads, Baidu Netdisk transfers, duplicate and conflict handling, a task center, operation auditing, and notification templates into a complete business workflow. It is suited for long-term maintenance of local multi-drive and remote Synology inventories.

### Interface and Workflow

KikoeruManager organizes its features into multiple workbenches. The overview page centrally displays entry points for import, RJ subtitles, subtitle supplementation, ASMR downloads, HTTP external links, inventory backup, and problem works. It also shows active tasks, items awaiting manual action, failed retries, and recent archives…
