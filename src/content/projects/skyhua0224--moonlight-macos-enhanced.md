**Moonlight macOS / Moonlight for macOS Native Enhanced Client**

`Moonlight macOS Enhanced` is a native macOS streaming client for connecting to Sunshine, Foundation Sunshine, and GameStream-compatible hosts. The interface is built with AppKit / SwiftUI, supports Apple Silicon and Intel Macs, and requires macOS 12 or later.
