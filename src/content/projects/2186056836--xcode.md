# XCode

  Simplified Chinese | <a href="README.en.md">English</a>

## Setup

Prepare Git, Node.js **24.14.0**, and pnpm **10.33.2**; the versions are defined in [mise.toml](https://github.com/2186056836/XCode/blob/HEAD/mise.toml). All of the development and packaging commands below are run from the repository root.

```bash
pnpm bootstrap
```

`pnpm bootstrap` installs the workspace dependencies, prepares the desktop app's local runtime resources, and then runs `build:bootstrap`.
