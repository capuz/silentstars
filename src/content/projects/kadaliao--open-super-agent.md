# open-super-agent

**A self-hostable, always-on AI teammate: it chats, delegates tasks, and has a computer that can see and take over.**

Open source, and an alternative to [Grok Bot](https://x.ai/bot). Choose your own model, billed by token.

Simplified Chinese · [English](https://github.com/kadaliao/open-super-agent/blob/HEAD/README.en.md)

## Highlights

- **Chats and delegates**: Each Bot has its own persona, memory, and conversations. Time-consuming work goes to background tasks while you keep chatting, and you can see what each step did. Several Bots can join a group: one looks up material, and its findings are automatically handed to another to write a summary.
- **A shared knowledge base written together**: Plans and reports made by Bots are saved as pages that you can edit directly, like Notion. Several Bots can continue writing the same page section by section, with each section marked by its author. Leave a comment on a section and the Bot that wrote it will revise it and reply to you in the comments. Every version can be viewed and rolled back. You can also create databases to use as task boards. Claude Code and Codex can read and write them via MCP, and Notion…
