# HypoMuxPlus

**Multi-NIC bandwidth aggregation tool**

HypoMuxPlus is a **multi-NIC bandwidth aggregation tool** for the Windows platform. It is a complete reconstruction based on the core idea of the open-source project HypoMux by [Hypostasis-Cat](https://github.com/Hypostasis-Cat/HypoMux), using **Tauri + Rust + React + TailwindCSS**, providing a more beautiful, smoother, and more professional desktop experience, and the traffic diversion engine is natively rewritten in Rust (tokio), resulting in a standalone executable file with zero runtime dependencies.

> This project is a derivative work based on the original HypoMux and is open-sourced under the **AGPL-3.0** license. Original author: Hypostasis-Cat; derivative developer: **Qingyun Production_Peng Minghang**.
