# Human Cognome Project (HCP)

**Choose your path:** [bounded work, project understanding, review, first run or history](https://github.com/Human-Cognome-Project/human-cognome-project/blob/HEAD/docs/onboarding/README.md).

The Human Cognome Project is an open-source experimental architecture for digital intelligence built around explicit structure, field dynamics, and auditable data rather than a monolithic statistical model.

A useful starting comparison is Minecraft: a relatively small set of primitive building elements can produce complex structures through composition. HCP follows that compositional principle, with stable structures recorded as reusable elements for general use in further compositions. This is the intended model; the [current state](https://github.com/Human-Cognome-Project/human-cognome-project/blob/HEAD/docs/onboarding/CURRENT-STATE.md) distinguishes implemented capabilities from remaining work.
