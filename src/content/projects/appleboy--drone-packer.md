# drone-packer

Drone plugin for build Automated machine images with [Packer](https://www.packer.io/). For the usage information and a listing of the available options please take a look at [the docs](https://plugins.drone.io/plugins/packer).

## Build

Build the binary with the following commands:

```sh
make build
```
