# Kodovoz Labs Website

Kodovoz Labs is an AI and enterprise software company based in Nairobi, Kenya, building intelligent operational systems for businesses across East Africa. The website presents its product portfolio, capabilities, delivery approach, and contact options.

## Pages

- `index.html` is the primary company website, including Guard OS, LumaBridge, industries, AI capabilities, dashboard examples, security, and an enquiry form.
- `About.html` covers the company mission, vision, and software pillars.
- `service.html` renders capability detail pages from `services.js`.
- `pricing.html` describes outcome-based engagement models.
- `privacy-policy.html` contains the privacy notice.

## Implementation

This workspace currently contains a static HTML, CSS, and JavaScript website. There is no `package.json`, App Router source, Tailwind setup, or React dependency manifest in the repository. `next.config.mjs` alone does not make the project a Next.js application. The current website therefore uses the existing static-site structure and can be served by a static host, including Vercel.
