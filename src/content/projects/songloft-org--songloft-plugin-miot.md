# songloft-jsplugin-miot

A Songloft JS plugin generated by `create-songloft-plugin`. [English](https://github.com/songloft-org/songloft-plugin-miot/blob/HEAD/README.en.md).

An example plugin that casts songs to smart speaker devices via the MIoT protocol.

## Development

```bash
npm install
npm run dev         # watch + auto-upload to local Songloft
npm run build       # produce dist/miot.jsplugin.zip
npm run validate    # verify plugin.json hashes
```

### Lynx frontend

The frontend references the bili plugin and uses native ReactLynx elements with `@songloft/lynx-plugin-sdk`. It outputs `main.lynx.bundle`, `main.web.bundle`, and an automatically generated HTML fallback entry. It retains six settings categories: song list, mini/full player, and devices, playback, voice, AI, scheduling, and toolbox.
