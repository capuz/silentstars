# songloft-jsplugin-miot

A Songloft JS plugin generated by `create-songloft-plugin`.

An example plugin for streaming songs to smart speaker devices via the MIoT protocol.

## Development

```bash
npm install
npm run dev         # watch + auto-upload to local Songloft
npm run build       # produce dist/miot.jsplugin.zip
npm run validate    # verify plugin.json hashes
```

## Description

An example plugin for controlling smart speaker devices. This repository only provides scaffold code for integration with the host SDK, **without any third-party device protocol implementations or account systems**; users are responsible for compliance.
