#  nap511

An Android client for personal use of 115 Cloud Disk, used for [Jetpack Compose](https://developer.android.com/jetpack/compose) practice

# Features

The features that are not crossed out are currently implemented, and those that are crossed out are planned.

1. Login (account password web login, cookie login, logout)
2. Cloud disk file related (cut, delete, rename, create folder, multi-select, recycle bin, get download link, search, ~~create small text~~, online decompression)
3. Offline file related (offline list, click to jump to cloud disk folder, view video files, delete, clear)
4. View (small text, ~~audio~~, photos, videos)
5. Offline (magnet link offline download, 115sha1 export, torrent offline download)
6. Custom (number of file requests per session, default offline location)
7. Others (magnet jump, ~~support for large screens~~)

Does not support **file upload and download**, **two-step verification**, **security key**
