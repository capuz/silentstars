# 🚤 Boatrace Open API for Programs

## 🛑 Notice of Deprecation

> ⚠️ This repository (Boatrace Open API for Programs) is **not recommended for future use**.<br>
> 
> 👉 Please use the successor repository [boatraceopenapi/api](https://github.com/boatraceopenapi/api) going forward.

## ⚠️ Important Notes

> **Before using this API, please check the following information.**
>
> - ⚡ **This API is unofficial.**
>   It has no relation to the official BOATRACE website or related organizations.
>
> - 🕒 **Data is not real-time.**
>   Regular updates are performed approximately every hour via GitHub Actions. Since it is not a real-time feed, there may be a delay of a few minutes before the latest information is reflected.
>
> - 📊 **The accuracy and completeness of the data are not guaranteed.**
>   Due to the nature of collection and conversion, there may be missing or erroneous data.
>
> - 🚫 **If official information is required, please be sure to check the official BOATRACE website.**
>
> - 🙇‍♂️ **Use of this API is at your own risk.**
