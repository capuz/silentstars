# Boatrace Open API for Programs

---

## 🛑 Notice of Deprecation

This repository (Boatrace Open API for Programs) is **not recommended for future use**. Please use the successor repository [boatraceopenapi/api](https://github.com/boatraceopenapi/api) going forward.

Although it is deprecated, the data updates and API provision of this repository are **still operational**. There is no immediate need to migrate existing usage, and you can continue to use it as is. However, since there is a possibility that updates may stop in the future, please consider migrating to the successor API as much as possible.

---

## ⚠️ Important Notes

**Before using this API, please check the following:**

- **Unofficial.** It is not affiliated with the official BOATRACE website or related organizations.
- **Not real-time.** Due to regular updates every approximately 3 hours via GitHub Actions, there may be a delay of a few hours in reflecting the latest information.
- **Accuracy and completeness are not guaranteed.** There may be omissions or errors due to the collection and conversion process.
- **If official information is needed, please be sure to check the official BOATRACE website.**
