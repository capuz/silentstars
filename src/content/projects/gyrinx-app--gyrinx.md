This repository contains the Gyrinx Django application - a gang management tool
for Necromunda. The code for this application is in the [`gyrinx`](https://github.com/gyrinx-app/gyrinx/blob/HEAD/gyrinx)
directory.

📚 **[Full Documentation](https://github.com/gyrinx-app/gyrinx/blob/HEAD/docs/README.md)** - Technical overview, architecture,
and development guides.

- **Python 3.12+** - Use [pyenv](https://github.com/pyenv/pyenv) to manage versions
- **[uv](https://docs.astral.sh/uv/) 0.11.12+** - Manages the Python environment and dependencies.
  Install with `curl -LsSf https://astral.sh/uv/install.sh | sh`
