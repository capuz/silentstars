# Vex · 维刻

Write down your ideas, see their structure.

Vex is a desktop Markdown editor built on .NET 10 and Avalonia 12. It supports **Windows, Linux, and macOS**, and centers on local files with instant editing, source view, reading, chapter mind maps, export, and local MCP collaboration.

Official site: [vex.codewf.com](https://vex.codewf.com/) · Published by [码坊 CodeWF](https://codewf.com) · Current version: **1.7.3**

## Download

Download the installers and their SHA256 checksums from [GitHub Releases](https://github.com/dotnet9/Vex/releases/latest): Windows x64 EXE, Linux x64/arm64 DEB, and macOS x64/arm64 DMG.

## Features

- Instant editing, source, reading, and chapter mind maps, with eight fixed layouts and standalone view windows that share the current document.
- Local files and folders, recent history, outline, find and replace, auto-save, and draft recovery.
- Export to Markdown, HTML, PDF, PNG, and Word; copy to WeChat Official Accounts, Zhihu, and 稀土掘金.
- Sixteen interface color schemes and twenty-seven body typography presets, with light, dark, and follow-system themes and four interface languages.
- Folder and outline collapsing, layout, navigation, and…
