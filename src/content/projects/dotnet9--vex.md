# Vex · 维刻

Write down your ideas, see their structure.

Vex is a desktop Markdown editor built on .NET 10 and Avalonia 12, supporting **Windows, Linux, macOS**. Around local files, it provides live editing, source view, reading, chapter mind maps, export, and local MCP collaboration.

Website: [vex.codewf.com](https://vex.codewf.com/) · Author: 沙漠尽头的狼 · Published by: [码坊 CodeWF](https://codewf.com) · Current version: **1.7.3**

## 下载 Download

Download the installers and matching SHA256 checksums from [GitHub Releases](https://github.com/dotnet9/Vex/releases/latest): Windows x64 EXE, Linux x64/arm64 DEB, macOS x64/arm64 DMG.

## 功能 Features

- Live editing, source view, reading, and chapter mind maps, with eight fixed layouts and standalone view windows that share the current document.
- Local files and folders, recent records, outline, find and replace, auto-save, and draft recovery.
- Export to Markdown, HTML, PDF, PNG, and Word; copy to WeChat Official Account, Zhihu (知乎), and Juejin (稀土掘金).
- Sixteen UI color themes and twenty-seven body typography layouts, supporting light, dark, follow-system, and four interface languages.
- Folder and outline collapse, layout, navigation,…
