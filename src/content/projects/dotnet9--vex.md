# Vex · 维刻

Write down ideas, see their structure.

Vex is a desktop Markdown editor built on .NET and Avalonia. It runs on **Windows, Linux, and macOS**, and works with local files, offering live editing, source view, reading view, chapter mind maps, export, and local MCP collaboration.

Website: [vex.codewf.com](https://vex.codewf.com/) · Published by [码坊 CodeWF](https://codewf.com) · Current version: **1.21.0.0**

## Download

Download the installers and their matching SHA256 checksums from [GitHub Releases](https://github.com/dotnet9/Vex/releases/latest): Windows x64 EXE, Linux x64/arm64 DEB, and macOS x64/arm64 DMG.

## Features

- Instant editing, source view, reading view, and chapter mind maps, with eight fixed layouts and independent view windows that share the current document.
- Local files and folders, recent records, outline, find and replace, auto-save, and draft recovery after an abnormal exit.
- Export to Markdown, HTML, PDF, PNG, and Word; copy for WeChat Official Accounts, Zhihu, and Juejin.
- Nine UI color schemes and thirteen body typography presets, with light, dark, and system-following themes, plus four interface languages.
