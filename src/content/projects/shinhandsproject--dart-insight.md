# dart-insight

A disclosure analysis web service that compares two DART periodic reports and shows the changed financial figures and sentences alongside the original source evidence. It lets people unfamiliar with disclosures search for companies without logging in, select two periodic reports from the same company, and check what changed.

> The service name (Dart Insight or 공시레이더) has not been decided yet. Planning, scope, and decisions are based on Notion. See the [documentation guide](#문서-안내) below.

## MVP Scope

**Flow:** Company search → Report selection → Comparison validation → Analysis in progress → Results (summary, financial figure changes, sentence changes) → Source check

| Category | Content |
| --- | --- |
| MVP (P1) | Company search, periodic report list and correction status, comparison report selection and comparability validation, financial account comparison, body and table change detection and prioritization, evidence-based summary, figure and sentence evidence with DART source locations, automatic checks for investment-solicitation expressions |
| Top-priority extension | Citation verification → audit log and Kill Switch → ML anomaly detection |
| Extension…
