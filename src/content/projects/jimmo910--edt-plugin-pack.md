# 1C:EDT Plugin Pack

A set of useful **third-party** 1C:EDT plugins, installed by checking a box for one category: **by link** (update site, with updates) or **as an offline archive**. EDT versions **2026.1** and **2026.2** are supported (each with its own set, verified by installing on a real EDT).

> **1C:EDT 2025.2 is no longer supported.** The last build for it is in the release [v1.1.4](https://github.com/Jimmo910/edt-plugin-pack/releases/tag/v1.1.4)
> (`EDT-Plugin-Pack-2025.2-1.1.4.zip`). It remains available but is no longer updated; the update site at `…/2025.2/` is no longer published.
