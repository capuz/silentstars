# Warning
This mod has a steep learning curve because of its very high degree of customization and flexibility.<br/>
This is because the mod lets server administrators use **programming** to control every aspect of the server.

Although this mod provides detailed documentation and explanations to teach you how to write code,<br/>
if you are not a command specialist with some technical background (or prior knowledge),<br/>
you are not recommended to use this mod to develop your server (such as a small private server).

Of course, if you plan to learn a programming language in the future, I think this mod is a good choice.<br/>
Even if you find the mod difficult to handle, you can still introduce it to other administrators of your server (such as command specialists).
