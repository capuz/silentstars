# DM PICKER

A song finder that takes you straight to the song you're looking for

## Overview

**DM PICKER** is a song finder for the DJMAX RESPECT V song select screen.

Open the search bar with a shortcut, type a song name, and press Enter to jump straight to that song without scrolling through the list.

**Supported environment** · Windows 10/11

[Download](https://github.com/eun-yeon/DmPicker/releases/latest) · [User guide](https://djmax.gg/dmpicker/guide)

## Key Features

**Search**: song name · initial consonants · composer · nickname · my keywords · level (`sc15`, `4b sc14-15`, `sc14~`) · ranking table (`15.1~`, `14.1~15.3`) · BPM (`bpm:150~180`, `sc14 bpm:200~`) · pattern traits (`트릴:1~`)

**Playlists**: load song lists from djmax.gg playlist URLs · layout · goals · view comments

**Navigation**: jump directly to the selected song · match button mode and difficulty · pick at random · recently visited songs and playlists · favorites

**Display**: freestyle and online rooms · automatic detection of resolution and aspect ratio

**Updates**: new songs · levels · ranking tables applied automatically · new version notifications
