# Carve

A lightweight markup language with visual mnemonics and human-centered design.

This repository is the normative definition of the language: the [formal
grammar](https://github.com/markup-carve/carve/blob/HEAD/resources/grammar.ebnf), the conformance corpus every implementation is
tested against, and the design rationale behind each decision.

## Status

**Carve 0.1 is specified and shipping.**

| | |
|---|---|
| **Specification** | 0.1. Tier-1 core and Tier-2 standard extensions are normative and stable; Tier-3 app-level extensions ship but evolve. See [VERSIONING.md](https://github.com/markup-carve/carve/blob/HEAD/VERSIONING.md). |
| **Conformance** | Over 1,000 corpus examples pinning exact HTML output, plus 43 optional-corpus examples for host-dependent extensions. |
| **Engines** | [carve-js](https://github.com/markup-carve/carve-js) (TypeScript, reference), [carve-php](https://github.com/markup-carve/carve-php), [carve-rs](https://github.com/markup-carve/carve-rs) - all three run the same corpus, with no open or intentional divergences ([tracker](https://github.com/markup-carve/carve/blob/HEAD/MAINTAINING.md#known-cross-impl-divergences)). |
