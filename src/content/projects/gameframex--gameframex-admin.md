## Project Overview

> One-line positioning: **an operations + publishing backend platform for indie game developers**. Backend `.NET 10 + SqlSugar` with three hosts (Admin / Client / Hub), frontend `Vue 3 + PrimeVue` — a full-stack pipeline from admin login to player payment callbacks, ready out of the box.

**GameFrameX Admin** is a **game-operations-oriented** backend system: the Admin API lets operations / GM / customer service staff edit menus, query orders, push versions, and view logs; the Client API handles game-side login / payments / config fetching; the Hub API serves external systems (CI builds, Tapd WebHooks,…
