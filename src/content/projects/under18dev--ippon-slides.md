# ippon-slides

**One message per slide.** A CLI that builds slides from Markdown.

- Black background, large text, and a fade-in on slide transitions
- Output is a **single HTML file** with all CSS and JS included, so it opens offline at the venue
- `--pdf` also outputs a **PDF** in 16:9
- No dependencies

📚 Detailed documentation is in [`docs/`](https://github.com/under18dev/ippon-slides/blob/HEAD/docs/README.md) ([syntax](https://github.com/under18dev/ippon-slides/blob/HEAD/docs/syntax.md) ・ [`::http::`](https://github.com/under18dev/ippon-slides/blob/HEAD/docs/http.md) ・ [`ippon serve`](https://github.com/under18dev/ippon-slides/blob/HEAD/docs/serve.md) ・ [presenter view](https://github.com/under18dev/ippon-slides/blob/HEAD/docs/presenter.md) ・ [theming](https://github.com/under18dev/ippon-slides/blob/HEAD/docs/theming.md) ・ [CLI](https://github.com/under18dev/ippon-slides/blob/HEAD/docs/cli.md)).

## Philosophy: why "ippon"?

The name **ippon (一本)** comes from the judo term for a decisive winning point. One slide decides one message. That is all there is to ippon-slides.
