### Features

- Home: Video card AI summary and preview, single-column recommendations, header image source switching
- Video page: Double-tap the fullscreen button for portrait playback, swipe left and right to switch the sidebar, long press for speed playback
- Search page: Double-tap the search button to clear the input box, swipe left and right to switch categories
- Personal space: Double-tap the search button for global search, swipe left and right to switch categories
- More: Element hiding, browsing duration reminders, and other settings can be found in the script menu (operation preferences / element hiding settings)

Firefox recommended extension: [User Agent Switcher](https://addons.mozilla.org/zh-CN/firefox/addon/uaswitcher/)
