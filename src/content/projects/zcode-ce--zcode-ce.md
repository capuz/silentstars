# ZCode-CE

Simplified Chinese | <a href="README.en.md">English</a>

ZCode-CE is the open-source community edition of the AI coding workbench **ZCode**, offering a desktop application, browser interface, and terminal Agent. This repository contains the source code for the client, backend services, shared UI, Agent CLI, and runtime.

## About This Project

ZCode-CE is built on [zai-org/ZCode](https://github.com/zai-org/ZCode) (Apache-2.0), targeting users who want to **have complete control over their development environment**. **Community members are welcome to contribute** — whether in feature development, issue reporting, or documentation improvements.
