# OpenMRS ESM Patient Chart

The `openmrs-esm-patient-chart` is a frontend module for the OpenMRS SPA. It contains various microfrontends that constitute widgets in a patient dashboard. These widgets include:

- [Allergies](https://github.com/openmrs/openmrs-esm-patient-chart/blob/HEAD/packages/esm-patient-allergies-app/README.md)
- [Attachments](https://github.com/openmrs/openmrs-esm-patient-chart/blob/HEAD/packages/esm-patient-attachments-app/README.md)
- [Conditions](https://github.com/openmrs/openmrs-esm-patient-chart/blob/HEAD/packages/esm-patient-conditions-app/README.md)
- [Flags](https://github.com/openmrs/openmrs-esm-patient-chart/blob/HEAD/packages/esm-patient-flags-app/README.md)
- [Forms](https://github.com/openmrs/openmrs-esm-patient-chart/blob/HEAD/packages/esm-patient-forms-app/README.md)
- [Generic patient widgets](https://github.com/openmrs/openmrs-esm-patient-chart/blob/HEAD/packages/esm-generic-patient-widgets-app/README.md)
