# MNSTRY Atelier

**Turn a Git repository into a governed knowledge graph.**

Define what your files mean, enforce which sources may cross boundaries, and
give people, agents, and tools a bounded view of the work. Git remains the
source of record. Your files remain plain text. The authoring runtime remains
local, with zero telemetry and Apache-2.0 licensing.

- **Current package:** `@mnstry/atelier@0.3.0` (Node.js 22 or 24)
- **Stability & contracts:** [stability manifest](https://github.com/MNSTRY/atelier/blob/HEAD/contracts/stability-manifest.v1.json) · [contract stability](https://github.com/MNSTRY/atelier/blob/HEAD/docs/reference/contract-stability.md) · [security & egress limits](https://github.com/MNSTRY/atelier/blob/HEAD/SECURITY.md)
- **Release history:** [CHANGELOG.md](https://github.com/MNSTRY/atelier/blob/HEAD/CHANGELOG.md)
