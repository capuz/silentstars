# CUDA Learning Roadmap

> Systematically designed based on NVIDIA's official *CUDA C++ Programming Guide* (598 pages) and *CUDA C++ Best Practices Guide* (118 pages)
> One CUDA code sample per day, building familiarity with CUDA and understanding of the GPU while learning parallel heterogeneous computing and GPU programming

## GPU Architecture Interactive Homepage

**[Open the GPU Architecture Interactive Homepage →](https://shaun-sheep111.github.io/cuda-learning-roadmap/)**

The black-and-green chip diagram supports clicking to view **CPU, work distributor, SM, L2, video memory, and copy engine**. Switching views shows how **Grid → Block → Warp → Thread** map onto hardware, and step-by-step playback shows the execution flow **H2D → kernel → D2H → synchronization**. It supports mobile browsing and keyboard operation.

> The diagram above can be viewed directly on the GitHub homepage; after clicking through to GitHub Pages, use the interactive features. The counts in the diagram are teaching illustrations and do not represent a specific GPU configuration. This is an independent learning project and is not the official NVIDIA website.
