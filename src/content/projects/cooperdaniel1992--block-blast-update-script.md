## What It Is

Block Blast Hack is a browser-first HTML game mod designed around a static site publishing workflow. It targets Block Blast and puts emphasis on a mod menu interface, ad removal, and a setup that fits naturally with GitHub Pages.

The repository is organized so the project can be published and refreshed with minimal friction through a static HTML structure. SEO metadata support is also included, helping the deployed page present the mod in a cleaner, more structured way.
