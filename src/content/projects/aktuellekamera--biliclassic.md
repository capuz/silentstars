# BiliClassic - Android 1 can watch Bilibili too!

A third-party Bilibili client for a range of older devices, supporting Android 1.0+, Windows Mobile 5.0+, Windows Phone 7.0+, Mymobile 0.9.3+ and webOS 3.0+. It aims to recreate the classic interface and interaction experience from around 2013, so those old devices gathering dust in drawers can enjoy Bilibili again~
