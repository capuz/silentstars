# Haiagaru for Morphe

A Morphe patch that adds settings, viewing, search, NG, and backup features to ChMate.
Supported original APKs are **0.8.10.191 dev / 0.8.10.226 dev / 0.8.10.242 dev**. 0.8.10.241 and 0.8.10.243 dev are not supported.
