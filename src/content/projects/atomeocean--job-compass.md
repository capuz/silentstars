# Atomeocean Job Compass

Atomeocean Job Compass is an open-source job search tool initiated by the Atomeocean team, dedicated to helping job seekers explore the U.S. job market more efficiently.

## Features

- 📃 All in Markdown:
  - Uses Markdown and Markdown extended syntax to record and organize job search-related information, with each page being a Markdown file.
- 🚀 Powered by [VitePress](https://vitepress.dev):
  - A powerful static documentation page generator based on Vite, which generates the pages of our knowledge base, providing easy-to-use themes and tools.

🔗 Official website: [Job Compass](https://jobcompass.atomeocean.com/)
