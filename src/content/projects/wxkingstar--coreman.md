# CoreMan

**Turn Claude Code and Codex into AI employees your team can reach anytime in Feishu and WeCom.**

Mention it in a group or message it privately, and it runs Claude Code / Codex on your own machines to do the work, then sends the results back to the chat. Administrators manage all AI employees from one console: which model they use, which machine they run on, which skills they have installed, and who may use them.

- **Scan to get a bot**: when you create an AI employee, scan a QR code with Feishu or WeCom and the bot is created automatically, so you don't have to configure an app manually on the open platform. Chat runs over the platform's long-lived connection, so no public IP or callback domain is needed.
- **Runs in your own environment**: CoreMan is self-hosted. The AI runs on the machine you specify, under the system user you specify, and work files stay on that machine.
- **Built for teams**: teams and roles, skill approval, scheduled tasks, conversation records, usage statistics, and audit logs are available out of the box.
