# CryptoFlash - Web3 News Push System

## 🌟 Project Introduction

CryptoFlash is a Web3 news push system based on the adapter pattern. It automatically crawls cryptocurrency-related news and pushes it to users in real time through multiple notification channels. The system uses a modular design and supports flexible extension of crawler sources and notification sources, achieving the design goal of "adding new sources without modifying core code".

## ✨ Features

- 🕷️ **Multi-source crawling**: Supports multiple news sources, including Binance exchange announcements and FORESIGHTNEWS
- 📢 **Multi-channel notifications**: Supports multiple notification methods, including DingTalk bots and email
- 📊 **Data deduplication**: Incremental data storage based on SQLite prevents duplicate pushes
- 🎨 **Markdown format**: Supports Markdown-formatted notification content for a better reading experience
- 🔧 **Flexible extension**: Uses the adapter pattern, so adding a new crawler or notification channel only requires implementing the interface
- 📦 **Lightweight deployment**: Supports local deployment and GitHub Actions automated deployment
