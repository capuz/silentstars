# Silver Formily

[English README](https://github.com/hezhengxu2018/silver-formily/blob/HEAD/README.en.md)

Silver Formily is a form infrastructure monorepo for Vue 3. The core reactive, path, validation, Schema, runtime binding, and UI component adapter layers in this repository have all been migrated from the original Formily dependency to the self-owned `@silver-formily/*` implementations. The current repository is no longer just "a secondary wrapper around Formily", but an independently evolvable implementation and documentation system.

The project is organized with `pnpm`, `Turborepo`, `Vite` and `VitePress`. It covers the core runtime, Vue / React bindings, Element Plus / Vant / Ant Design component solutions, as well as the accompanying documentation sites and internal toolchain.
