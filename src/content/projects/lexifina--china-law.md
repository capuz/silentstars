# China: law history in git

**Simplified Chinese** · [English](https://github.com/lexifina/china-law/blob/HEAD/README.en.md)

China's national laws presented as a git history: each article is one file, each version is one commit, and the date of each commit is the date that version takes effect. The author of each commit is the legal instrument that made that change. `git blame` shows the legal instrument behind each paragraph (款); `git log` lists all amendments to an article; choosing a date gives the text in effect on that day.

This repository is part of [lexifina/global-law](https://github.com/lexifina/global-law), which combines the laws of many countries into one git history. This is the part covering China's national laws; global-law reads them from `china/national/acts/`.
