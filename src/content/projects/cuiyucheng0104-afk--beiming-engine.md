# Beiming Engine · Beiming Engine

**Code as film. One engine, three routes.**

A frame-by-frame, deterministic rendering pipeline for 3D-to-2D and 2.5D: modeling, lighting, ink lines, camera, layout, and mixing are all written as code, so the output can be re-rendered, traced, and redone in a different art style.<br>
Hand-painted backgrounds, concept artwork, AI-generated imagery, and public-domain footage are used only as source material, with each source recorded in its case card. The public showcase includes 79 finished films, and the repository fully archives 96 cases.
