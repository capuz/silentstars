## What is this?
※Not yet compatible with Resonite

An inventory organization support tool for [Neos](https://neos.com). It is currently in beta version.

## Why?
As far as I know, Neos cannot move between directories like Windows "Explorer". Through conversations, I heard cases such as "There is an event to organize inventory on New Year's Eve" and "It is necessary to take out all items and sort them". Also, as a developer myself, while saving items to the inventory in-game, the items directly under the inventory had already become about 8 columns. I predicted that continuing to save at this pace would inevitably cause the direct level to become a chaotic mess, so I decided to create this tool.
