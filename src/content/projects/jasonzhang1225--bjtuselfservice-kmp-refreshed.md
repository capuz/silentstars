# 🚄 交大自由行KMP (BJTU Self Service KMP Refreshed)

> BJTU campus service client — making campus life within reach  ↩
> This repository is the **Kotlin Multiplatform refactored version** (Android / iOS / macOS / Windows).

## 📖 Project Introduction

**交大自由行** is a campus service app built for students and staff of Beijing Jiaotong University. By automatically logging into the MIS system, it brings common campus features such as grade queries, class timetables, exam schedules, assignment management, and email viewing into a single clean, intuitive interface.

Login page parsing, password encryption, and school data parsing are all performed **locally**. Account passwords are not uploaded to any third-party server.

This project ([BJTUselfService-KMP-Refreshed](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed)) builds on the Android version of the original author’s project [HFDLYS/BJTUselfService](https://github.com/HFDLYS/BJTUselfService), using **KMP + Compose Multiplatform** for a shared multi-platform implementation.
