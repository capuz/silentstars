# KixDNS Panel

**Simplified Chinese** | [English](https://github.com/tuoro/kixdns-panel/blob/HEAD/README.en.md)

A web panel for self-hosted DNS. Configure split-routing rules and blocklists with forms, and see for every query which rule it matched and who answered. The core is KixDNS, written in Rust. It installs with one command, or you can [try it online](https://tuoro.github.io/kixdns-panel/) first: no installation needed, it uses sample data, and changes are reset on refresh.
