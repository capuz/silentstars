# NandinaUI · 南天竹

**A C++26 GUI framework for Linux desktops — making desktop application development a pleasant experience.**

## Introduction

NandinaUI (南天竹) is a native desktop UI framework written in **C++26** and built with **Meson**. Built on C++ widgets and a scene tree, it provides declarative interface construction, reactive state, theming, animation, resource management, and page navigation. It lets application code organize desktop interfaces with a type-safe DSL while retaining the ability to directly access widget objects.

During development, the project drew on design ideas from existing mainstream frameworks, such as the page scheduling and reactive mechanisms of `Angular`, the primitives + token component design of `Shadcn`, the dirty-data update and file rendering mechanisms of `Slint`, and the new signal-slot mechanism and component API design of `Qt`.

> Currently in **alpha** stage. The officially supported scope is the `linux-desktop-source` profile (Linux desktop source integration). The API is still evolving rapidly; the project does not guarantee preservation of old public header files or namespace source-compatibility entry points.
