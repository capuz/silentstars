## Installation
1. Download the contents of this repository and place the two folders MuAiCore and TensorReactions into \Minionapp\Bots\FFXIVMinion64\LuaMods to overwrite.

<br>2. After entering the game and injecting, add MuAiCore in the profiler.
<br>$${\color{red}Note: Do not use a configuration file named "Optifine"; this configuration cannot be added. If you must use it, please clone one!}$$
<br>
<br>After reloading, you will see the following
<br><img width="465" height="471" alt="image" src="https://github.com/user-attachments/assets/7ee15be2-4719-44dd-adb6-8c0d06e91d93" />
<br>You can click here to open the plugin page, which is the same as opening it with a shortcut key (if you do not have a profiler, skip this step)
<br>$${\color{red}3. For details on inheriting the corresponding timeline, see the description of the dungeon support module below.}$$
<br>$${\color{red}4. Please strictly check the inheritance relationship and observe whether there are duplicate contents at the time nodes; duplicates will lead to a lot of navigation bugs!}$$
