# FSFE Website

This repository contains the source files of [fsfe.org](https://fsfe.org), pdfreaders.org, freeyourandroid.org, ilovefs.org, drm.info, and test.fsfe.org.

## Technical information

Our web team has compiled some information about technology used for this website on the [Information for Webmasters](https://fsfe.org/contribute/web/) page. This is mainly focused on page content.

For information on how the build process works see [docs subfolder](https://github.com/fsfe/fsfe-website/blob/HEAD/docs/overview.md). For more information on contributing to the build process, please see the [contributor docs](https://github.com/fsfe/fsfe-website/blob/HEAD/docs/contributing.md) for some useful tips.

Some tips for management can be found in the [management docs](https://github.com/fsfe/fsfe-website/blob/HEAD/docs/management.md)
