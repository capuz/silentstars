**An enterprise-grade open-source version of Grok Bot, better suited for private on-premises deployment inside companies.**

Connect Claude Code, Codex, Grok, and OpenCode running on multiple machines into one agent legion, and command them all from a single desktop app.

## Why Agent Network

- 🤖 **A cross-machine agent legion**: Claude Code, Claude Agent SDK, Codex, Grok Build, and OpenCode can all join the same network as nodes. Nodes discover each other and dispatch work to one another through MCP.
- 🛰️ **One Hub connecting all machines**: CommHub exposes tools through MCP and delivers tasks in real time through SSE. Each machine runs one `anet daemon`, so you can create, start, and stop nodes on that machine remotely from the client.
