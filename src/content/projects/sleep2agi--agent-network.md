# Agent Network

[Docs](https://anet.sh) · [Download desktop app](https://github.com/sleep2agi/agent-network-app/releases/latest) · [Quick start](https://anet.sh/guide/getting-started) · **Chinese** · [English](https://github.com/sleep2agi/agent-network/blob/HEAD/README.en.md)

**Connect Claude Code, Codex, Grok, and OpenCode spread across multiple machines into one agent army, and command them from a single desktop app.**

## Why Agent Network

- 🤖 **A cross-machine agent army**: Claude Code, Claude Agent SDK, Codex, Grok Build, and OpenCode can all join the same network as nodes. Nodes discover each other and dispatch tasks to one another via MCP.
- 🛰️ **One Hub connects all machines**: CommHub exposes tools via MCP and delivers tasks in real time via SSE. Each machine runs one `anet daemon`, so you can remotely create, start, and stop nodes on that machine from the client.
- 💬 **One client manages everything**: Desktop (macOS / Windows) and Android. Dispatch tasks via chat and send or receive files.
