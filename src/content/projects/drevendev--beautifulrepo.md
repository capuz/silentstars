> **Tip**
>
> **Beautiful is not “more decoration.”** A strong repository reduces the time from landing on the page to understanding the result, trying it, trusting it, and knowing how to contribute.

## Start here

Choose the result you need:

- **Diagnose an existing repository:** run the [offline audit](https://github.com/drevendev/BeautifulRepo/blob/HEAD/guides/repository-audit.md) with the [repository checklist](https://github.com/drevendev/BeautifulRepo/blob/HEAD/checklists/repository.md) to get specific findings, not a beauty score.
- **Start a new repository:** adapt the [README scaffold](https://github.com/drevendev/BeautifulRepo/blob/HEAD/templates/README.template.md) using the [first-success checklist](https://github.com/drevendev/BeautifulRepo/blob/HEAD/checklists/first-success.md) to provide a reproducible command and honest scope.
- **Borrow a working example:** explore [five working starter types plus a terminal game](https://github.com/drevendev/BeautifulRepo/blob/HEAD/examples/README.md) for runnable source, tests and documented limitations.
