## About the Tool

CRE Deal Analyzer is an HTML-based application that runs in a web browser and supports commercial real estate underwriting and transaction analysis. It combines important evaluation steps in a single interface so users can enter assumptions, compare calculated results, and see how input changes influence a potential deal.

The application is suited to analysts, investors, and others reviewing commercial real estate opportunities. Alongside its main underwriting features, it provides saved deals, member access, usage tracking, and an integrated AI assistant chat.
