Typora Next is a Markdown previewer for technical documentation writers. While you edit documents in VS Code or Obsidian, it provides rendering quality beyond Typora: exceptional math formula rendering, rich diagram support, polished code highlighting, and project-level document management.

---

## ✨ Core Features

| Feature | Description |
|------|------|
| **Markdown Rendering** | Based on `pulldown-cmark`, supports CommonMark + GFM (tables, task lists, strikethrough, Alerts) |
| **Math Formulas** | Powered by KaTeX, supports inline `$...$` and block `$$...$$` formulas, 10× faster than MathJax |
| **Code Highlighting** | Prism.js deployed locally, supports 20+ languages, with line numbers and a one-click copy button |
| **Mermaid Diagrams** | Supports 13 diagram types, including flowcharts, sequence diagrams, Gantt charts, and class diagrams; failed renders can be fixed with AI |
| **Image Handling** | Local relative paths, network images, and Obsidian WikiLink `![[image.png]]`, with Lightbox zoom |
| **Highlight Annotations** | WeRead-style annotation experience: select text to show a toolbar, supports highlight/underline/notes, with automatic persistence |
