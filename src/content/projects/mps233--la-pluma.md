# La Pluma

> **Origin of the name**: La Pluma (Quill) is a five-star Guard operator in Arknights. This project is named after her as a tribute to this elegant lady.

## ✨ Features

- 🧭 **Console overview** - Summarizes today's events, task status, live preview, and drop information
- 🎮 **Automated task workflow** - Launch game, Sanity farming, base shift scheduling, auto recruitment, credit income/expenditure, claim rewards, close game
- 🎯 **Multi-stage support** - Set counts independently for each stage; event stage codes are automatically replaced (HD-X → OR-X)
- 🧠 **Smart detection** - Daily/chip-stage open-day detection, auto-stop when Sanity is exhausted, game state monitoring
- ⏰ **Scheduled tasks** - Supports multiple scheduled tasks with real-time execution status and progress
- 🖥️ **Emulator preview** - Integrates ScrcpyOverWebRTC, supporting in-browser viewing and basic device control
- 📊 **Data & progression** - Recognizes warehouse and operator Box, tracks drops, generates operator development material plans
- 🧰 **Utilities** - Pixel art fill, auto potential upgrade, material synthesis, Roguelike farming, and event shop exchange
