# 📺 Automated Push System for Xinwen Lianbo Transcripts

This project is a purely automated news retrieval and distribution tool based on GitHub Actions. Every day at 21:00, the system automatically fetches the full transcript of that day's 《新闻联播》(Xinwen Lianbo), converts and formats it, and then pushes it to your devices through multiple channels, so you can read the daily official media news in an elegant and efficient way, like 「批阅奏章」(reviewing memorials).
