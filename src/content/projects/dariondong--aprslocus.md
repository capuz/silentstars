# APRSlocus

**APRS Location Tracking and Maps · Local APRS Client (No Preset Server Address)**

A lightweight APRS client built exclusively for amateur radio enthusiasts — real-time positioning, station tracking, messaging, and map display, all in one place to keep track of everything happening on the airwaves.
