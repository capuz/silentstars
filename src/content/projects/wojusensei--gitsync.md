# GitSync 

An interactive Git history browser that visualizes commit graphs, branches, diffs, Blame, and more, helping developers intuitively understand and manage Git repositories.

🌐 Compatible with macOS, Windows, and most Linux distributions, built with Rust + Tauri, explosive performance💥

Current version: version 0.3.3

## ✨ Features

### Core Browsing
- **Interactive Commit History**: Hover highlighting, flashlight effect, virtual scrolling supports 1k+ commits without lag
- **Branch Visualization and Management**: One-click branch switching, blue dot follows current branch
- **Commit Details Panel**: View Diff, file change statistics, syntax highlighting
- **Smart Blame**: Display code author and timestamp line by line
- **File Timeline**: View complete modification history of a single file

### Code Tracing
- **Diff Syntax Highlighting**: Added/deleted lines distinguished by color, supports character-level inline highlighting
- **Side-by-Side Comparison**: Compare code of any two commits side by side
- **Semantic Code Search**: Search code content across all historical changes
- **Diff Comparison Tool**: Quickly compare differences between two commits or branches
