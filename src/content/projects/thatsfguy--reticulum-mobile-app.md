# Reticulum Mobile App

*Off-grid encrypted messaging for Android & iOS, over LoRa radio or the open internet. No servers, no accounts, no app-store lock-in.*

## Quick start

### 1. Install

**Android:** download `Reticulum-Android-<version>-release.apk` from the [latest release](https://github.com/thatSFguy/reticulum-mobile-app/releases/latest), open it, and allow the install. For automatic updates, [use Obtainium](https://github.com/thatSFguy/reticulum-mobile-app/blob/HEAD/docs/TECHNICAL.md#install-via-obtainium-recommended-for-ongoing-updates).

**iOS:** the app is sideloaded with a free Apple ID.

1. Install [AltStore](https://altstore.io/) or [SideStore](https://sidestore.io/).
2. Add this source: `https://thatsfguy.github.io/reticulum-mobile-app/altstore.json`
3. Install **Reticulum Mobile App** from that source.
4. On first run, trust your Apple ID under **Settings → General → VPN & Device Management**.

[More iOS install options](https://github.com/thatSFguy/reticulum-mobile-app/blob/HEAD/docs/TECHNICAL.md#install-on-ios-via-altstore--sidestore), including signature renewal.

### 2. Start

Open the app and go to **Settings → Connection**. Your identity is created for you…
