# Pokémon Azoth Encyclopedia

## Play Directly (feature testing in progress, 2026-10-16)

The navigation and homepage entry is `docs/play/index.md`. The start card opens `docs/play/app.html` in full in the same tab.
The online v2 version is generated by the new workspace `tools/web-player/package_online.py` from the existing single-file v4 snapshot. The first screen is about 116 KB, and the total initial resource size is about 17.82 MB.
The ROM is still `52808835e884f28a4da424a583567addadaa577fd0d3be993af241ef98700c87`; the single-file source SHA-256 is `461e1fcf7b037061e22ab546516c04c4924f6e60367b4d476f91a3d3240e0e01`.

Gzipped binary assets are placed in `docs/play/assets/<SHA256>.bin`. The ROM is split into 256 KiB chunks, fetched over 6 parallel connections, and each chunk's SHA-256 is verified. In production, the site prefers the jsDelivr Fastly/Gcore mirrors at a pinned commit. If a chunk is not finished after 8 seconds, another route is raced, and the first complete response that passes verification wins, with the original Pages as fallback.
