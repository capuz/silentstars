## Project Vision

**《万界道友》** aims to build an "open-source skeleton for a cultivation universe." It is not only a text-based cultivation game that can be played directly, but also a highly structured, AIGC-friendly underlying architecture. Through **high-freedom input + AIGC feedback**, combined with **rigorous numerical and combat models**, we hope creators can quickly build their own cultivation worlds on top of it.

- **Gameplay**: Players are encouraged to shape characters through text descriptions, with AI generating feedback in real time, delivering a "thousand players, thousand faces" experience.
- **System**: Keep the system stable, orthogonal, and composable, ensuring balanced values and self-consistent logic.
- **Presentation**: Adhere to "text as interface," using an ink-wash style UI adapted for mobile.
