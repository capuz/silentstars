## Project Vision

**《万界道友》** aims to build an "open-source skeleton for the cultivation universe." It is not only a text cultivation game that can be played right away, but also a highly structured, AIGC-friendly underlying architecture. Through **high-freedom input + AIGC feedback**, combined with **rigorous numerical and combat models**, we hope creators can quickly build their own cultivation worlds on top of it.

- **Gameplay**: Encourages players to shape characters through text descriptions, with AI generating real-time feedback, delivering a "thousand players, thousand faces" experience.
- **Systems**: Keeps the system stable, orthogonal, and composable, ensuring numerical balance and logical consistency.
- **Presentation**: Holds to "text as interface," using an ink-wash-style UI adapted for mobile.
