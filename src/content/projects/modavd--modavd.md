# ModAVD (modified AVD)

An Android emulator based on AOSP Android Emulator 37.2.10, with a set of patches applied and then compiled by us. It currently supports Windows, and more platforms are planned (see [#27](https://github.com/ModAVD/ModAVD/issues/27)).

The package includes the manager `ModAVD.exe` and the command-line tool `tools\\modavd.exe`, for creating instances and starting and stopping them. It can also be connected to automation tools such as [AUTO-MAS](https://github.com/AUTO-MAS-Project/AUTO-MAS), which handle instance orchestration and task workflows.

**Documentation site: <https://modavd.github.io/>** (installation, upgrades, feedback, privacy, and notes on each component and on contributing are all there)
