## Adding news articles

Adding news articles requires **no environment setup**. If you have a GitHub account, you can add an entry :blush:

~~I think this is probably the easiest way...!!~~   
:new: **Now automated!!** :wrench::robot::dash::sparkles:

1. Open [_data/news.yml](https://github.com/yasslab/yasslab.jp/blob/main/_data/news.yml) in your browser
2. Click the ✎ icon on the right side of the screen (Fork this project and edit this file)
3. Add the news information
   - `title:` the title of the linked article
   - `date:` the publication date of the linked article
   - `url:` the URL of the linked article
4. Add a title and description to the change, then click Propose file change
5. Review the change, and if there are no problems, click Create pull request

That's it. Added news items are reviewed by other members, and if there are no problems, the proposed change is applied. Even if there is a problem, other members can notice it and fix it, so feel free to propose your change…
