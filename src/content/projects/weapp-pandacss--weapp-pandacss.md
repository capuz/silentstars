# weapp-pandacss

Use Panda CSS 2.5.0 in WeChat and other mini-program runtimes. The adapter accepts stable Panda releases from 2.1.2 onward (`>=2.1.2`) with no upper version bound; the examples use 2.5.0. Real consumer tests cover 2.1.2 and 2.5.0, and AST checks reject incompatible generated artifacts.

Documentation: [English](https://panda.weapp.dev/) · [简体中文](https://panda.weapp.dev/zh/).

This repository is a pnpm/Turborepo monorepo managed by [repoctl](https://github.com/icelib/repoctl). The published adapter lives in [packages/weapp-pandacss](https://github.com/weapp-pandacss/weapp-pandacss/blob/HEAD/packages/weapp-pandacss); the [Chinese configuration guide](https://github.com/weapp-pandacss/weapp-pandacss/blob/HEAD/packages/weapp-pandacss/README.zh.md) covers installation, PostCSS and runtime codegen.
