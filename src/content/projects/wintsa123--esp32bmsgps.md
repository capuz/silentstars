<h1 align="center">⚡ ESP32 BMS GPS 🛰️</h1>

  ·
</p>

ESP32 smart instrument firmware for electric motorcycles, electric vehicles, and light vehicles: integrates BMS, controller, GPS, touchscreen, device hotspot, web control, and mobile screen projection on a single device.

> The current project is in continuous development and real machine debugging stage. The core firmware and main interaction links are available, while OTA, trajectory storage, and some hardware compatibility are still incomplete.
