# 🛡️ Keenetic Auto-Setup Suite — Mihomo + MagiTrickle

Automated installation and integration of **[Mihomo](https://github.com/MetaCubeX/mihomo) + [MagiTrickle](https://magitrickle.dev/)** on Keenetic with Entware. **Mihomo** provides proxy connections and routes to your servers, while **MagiTrickle** manages groups and traffic-selection rules by DNS/domains. Both components are essential for the system to work.
