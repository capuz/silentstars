## Overview 📢
- RenpyBox: an all-in-one localization toolbox for Ren'Py that combines text extraction, translation, proofreading, repair, and packaging. The desktop app (Electron + Web UI) is the only frontend. The legacy Python / Qt5 interface and packaging workflow have been removed, so the repository now keeps only the headless Python backend and the desktop shell.
- Target users: visual novel developers, fan translation groups, Ren'Py translators
- **Recommended: use [SiliconFlow](https://cloud.siliconflow.cn/i/Cvmvkm5d) for translation**
