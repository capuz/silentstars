**Native SoundCloud client for Windows and Linux in the Liquid Glass aesthetic.**  
Ad-free and without a browser tab: its own Rust audio engine, a local LRU track cache,  
synced karaoke-style lyrics, the free **Star aura**, the personal **SoundWave** wave and **Discord Rich Presence**.

---

## Features

### Audio engine (Rust)
- Custom player built on `rodio`, with MP3/OGG/Opus decoding without the browser `<audio>` element
- **10-band equalizer** with presets, ReplayGain normalization and crossfade
- Playback speed, sleep timer, repeat, shuffle, and seeking with the mouse wheel (`Shift` — ±15 s)
- Global media keys and control from the system tray

### Liquid Glass interface
- Semi-transparent glass panels over a live mesh gradient and a dynamic cover-art palette
- No-blur mode (**No-Glass**) in settings for maximum performance
- "Now Playing" panel on the right, full-screen player and mini player over other windows
- Custom fonts (system or from a file), custom CSS, UI scaling (`Ctrl` + wheel)
- Russian and English interface

### Library and offline cache
- Favorite tracks, playlists, subscriptions and listening history
- Superlikes, local list…
