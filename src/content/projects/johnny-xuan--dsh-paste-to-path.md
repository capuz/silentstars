# dsh-paste-to-path

> **A universal attachment dock for DSH.**

English | [简体中文](https://github.com/Johnny-xuan/dsh-paste-to-path/blob/main/docs/README.zh.md)

> [!IMPORTANT]
> **Final release — v0.0.7**
>
> DSH now provides an official generic-file attachment pipeline, so the compatibility gap this plugin was created to fill has been closed. Version `0.0.7` is the final release; no further versions are planned.
>
> DSH Native owns ordinary files and images by default. Enable **Take over DSH Native attachments** only when you explicitly want the classic path-backed P2P workflow. Long-text conversion remains independently available.

The rest of this README documents the classic P2P workflow available when takeover is enabled.

`dsh-paste-to-path` adds a general-purpose attachment Dock to the DSH Web composer.

Paste, drop, or choose images, PDFs, Word and Excel documents, archives, code, logs, and other files, then review and manage them together before sending.

</p>
