# English Syntax Analyzer / Editor

[한국어](https://github.com/romantech/syntax-analyzer/blob/HEAD/README.md) · [English](https://github.com/romantech/syntax-analyzer/blob/HEAD/README.en.md) · [简体中文](https://github.com/romantech/syntax-analyzer/blob/HEAD/README.zh-Hans.md) · [日本語](https://github.com/romantech/syntax-analyzer/blob/HEAD/README.ja.md)

Syntax Analyzer is a web application that automatically analyzes various syntactic structures of English sentences and lets you edit them into any form you like. With about 30 commonly used grammar tags, it helps you grasp complex sentence structures at a glance. It also provides a feature that generates random sentences related to a topic you enter.
