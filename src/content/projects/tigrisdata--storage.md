# Tigris Storage SDKs

Tigris is a globally distributed object storage service that provides low latency anywhere in the world, enabling developers to store and access any amount of data for a wide range of use cases.

## JavaScript/TypeScript SDK

This monorepo contains multiple JavaScript/TypeScript packages for Tigris object storage:

- [`@tigrisdata/storage`](https://github.com/tigrisdata/storage/blob/HEAD/packages/storage) - Tigris Storage SDK
- [`@tigrisdata/iam`](https://github.com/tigrisdata/storage/blob/HEAD/packages/iam) - Tigris IAM SDK
- [`@tigrisdata/cli`](https://github.com/tigrisdata/storage/blob/HEAD/packages/cli) - Command line interface for Tigris object storage
- [`@tigrisdata/agent-kit`](https://github.com/tigrisdata/storage/blob/HEAD/packages/agent-kit) - Composed workflows for AI agents (sandboxes, workspaces, checkpoints, coordination)
- [`@tigrisdata/keyv-tigris`](https://github.com/tigrisdata/storage/blob/HEAD/packages/keyv-tigris) - Tigris adapter for [Keyv](https://keyv.org/)
- [`@tigrisdata/react`](https://github.com/tigrisdata/storage/blob/HEAD/packages/react) - Ready to use React Components and Hooks
