# GNOME Build Metadata

The GNOME Build Metadata repository is where the GNOME release team manages build metadata for building the GNOME Flatpak runtime, GNOME OS, and GNOME OCI images.

## Getting started

If you'd like to **use** GNOME OS, please see the [installation guide](https://github.com/GNOME/gnome-build-meta/blob/HEAD/docs/install.md) and the [user guide](https://github.com/GNOME/gnome-build-meta/blob/HEAD/docs/using.md). For an overview of the project, visit the [GNOME OS website](https://os.gnome.org/).

To **contribute** to the GNOME Flatpak runtime, GNOME OS or GNOME OCI images, see the [contribution guide](https://github.com/GNOME/gnome-build-meta/blob/HEAD/CONTRIBUTING.md) to get started, and the [debugging guide](https://github.com/GNOME/gnome-build-meta/blob/HEAD/docs/debugging.md) for common troubleshooting steps.
