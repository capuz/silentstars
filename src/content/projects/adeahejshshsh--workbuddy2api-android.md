# WorkBuddy2API · Android Self-Hosted Gateway

Packages [workbuddy2api-panel](https://github.com/linguo2625469/workbuddy2api-panel) (upstream [Sliverkiss/workbuddy2api](https://github.com/Sliverkiss/workbuddy2api)) as an Android app that **can be installed on a phone and run persistently**: gateway binary + management panel + watchdog + keep-alive, all bundled into a single APK.

One phone = one OpenAI-compatible gateway: `http://127.0.0.1:7863/v1` (for LAN access, replace `127.0.0.1` with the phone's IP).
