# Wuwatappo Native

Wuwatappo Native is the native Windows implementation of WuwaTappo 1.0.2, written in C# / .NET 8, WinForms, and WebView2. It connects to Kuro's official desktop pet service. This project is not an official Kuro project.

## Feature Summary

**Implemented features:**

- ✅ Supports all original online content and multiplayer
- ✅ Supports switching between the CN and International (Global) servers, with inheritance of official login
- ✅ Supports CN phone number + SMS verification code login (Kuro Pass)
- ✅ Supports customizing all skins (in others' rooms, only the skins you actually own are shown, but you can set any skin locally)
- ✅ Supports sending any emote (regardless of ownership or character restrictions; visible to others)
- ✅ Supports local fine-tuning of headpiece position
- ✅ Supports adding Key count (one click for +10000)
- ✅ Supports automatically claiming chests
- ✅ Supports auto emotes, auto tapping, and game mode rules
- ✅ Supports hotkeys
- ✅ Supports displaying the current keyboard/gamepad key bindings
