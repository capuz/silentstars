# HomePage-Haze (微岚主页)
A clean, beautiful, feature-rich pure static personal homepage. Built with HTML+CSS+JavaScript.
### Notes before reading the code
This project may show the following, including but not limited to:

- Messy handwriting
- Strange comments
- Inconsistent styles
- Tangled logic

and many other issues.

Of course, if you have any suggestions or corrections, feel free to open an Issue or PR. I will gladly accept them (though I may not be able to change things, or may have no time to, qwq ....).
## Features
1. Block loading animation and mask-layer pull effect
2. Modern frosted-glass background
3. Parallax effect when hovering over cards
4. Avatar rotation on focus
5. Typewriter effect in the search bar
6. Mouse ripple and particle effects
7. Footer time statistics and 每日一言 (daily quote)
8. Unified standalone config file, ready to use out of the box and easy to customize
9. Glowing floating dust background effect
10. Breathing "light" effect on the main card, and floating effect driven by a multi-layer blended Sin wave
11. Slight floating effect on the main card when it is not focused
12. Custom small-dot mouse cursor style
