# Vexo — Cross-platform SSH & SFTP GUI Client

A modern, cross-platform SSH and SFTP desktop GUI application built with Go and Wails v3.

---

## 📖 Introduction

**Vexo** is a sleek and responsive desktop application that brings the power of SSH and SFTP to your fingertips—without leaving a native GUI environment. Built with [Wails v3](https://wails.io) and Go, Vexo runs natively on Windows, macOS, and Linux, providing a unified remote access and file management tool for developers and system administrators.

Design philosophy: Clean and simple, professional and reliable, eye-friendly comfort

---

## ✨ Features

- SSH ProxyJump support, connecting to target servers through intermediate nodes
- SSH port forwarding/tunneling, supporting local forwarding, remote forwarding, SOCKS5 dynamic proxy
- Multi-tab switching, dragging, copying, refreshing
- SFTP file browser supporting upload, download, delete, rename files
- File transfer task management
- Bookmark management for quick connection to frequently used servers
- Theme switching support with multiple themes: light mode, dark mode, blue night mode, eye-care mode
- Command library functionality to build your own command library…
