# Notes

## 构建

### HTML

参考[官方文档](https://zensical.org/docs/get-started/#installation)安装 `zensical`.

```sh
zensical build # 构建网站
zensical serve # 持续构建网站并启用本地 HTTP 服务器
```

### PDF

先构建为 HTML 文件, 然后使用浏览器打开指定页面并打印为 PDF 文件.
