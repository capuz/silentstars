# auditor-doctrine-provider [](https://twitter.com/intent/tweet?text=auditor-doctrine-provider,%20Doctrine%20ORM%20audit%20logs%20made%20easy.&url=https://github.com/DamienHarper/auditor-doctrine-provider&hashtags=auditor)

`auditor-doctrine-provider` brings the auditing features of [`auditor`](https://github.com/DamienHarper/auditor) to applications using [Doctrine ORM](https://www.doctrine-project.org/projects/orm.html).

## Official Documentation
`auditor-doctrine-provider` documentation can be found locally in the [docs/](https://github.com/DamienHarper/auditor-doctrine-provider/blob/HEAD/docs/) folder.
