> Pine is currently an early developer preview and is not suitable for daily work or important data. The UI, data formats, Agent behavior, and project structure may all undergo incompatible changes; no stable release, migration, or compatibility guarantees are provided.

## Background

Most AI Agent tools are aimed at developers: terminals, editor plugins, and command-line arguments. People who handle documents, spreadsheets, reports, and materials every day can mostly only reach their own files indirectly through a web chat box.

Pine aims to provide a desktop Agent harness for this kind of scenario:

- Common office file formats (text, images, video, PDF, DOCX, XLS/XLSX, PPTX) can be previewed directly within the workspace. The Agent operates on the files you see.
- The Agent's reads, reasoning, tool calls, and file modifications are all shown in the session log. Operations that require approval ask first, and a run can be aborted at any time.
- Projects, sessions, and files are stored on your local machine. Model connections (API key / OAuth) are configured by you; Pine does not act as a relay.
- Open-sourced under AGPL-3.0.
