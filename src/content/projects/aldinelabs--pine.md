# Pine

An AI agent workspace dedicated to providing more possibilities for everyone.

> [!CAUTION]
> Pine is currently an early developer preview. Its interface, data formats, and Agent behavior may all undergo incompatible changes. Do not use it for important data.

## Introduction

Most AI Agent tools are aimed at developers: terminals, editor plugins, command-line arguments. Pine is a desktop Agent workspace for people who work with documents, spreadsheets, reports, and materials every day:

- Various files can be previewed directly within the workspace, so the Agent operates on the files you see.
- The Agent's reads, tool calls, and file modifications are all shown in the session. Operations that require approval ask first, and you can abort at any time.
- Projects, sessions, and files are saved on your local machine. Model connections (API key / OAuth) are configured by you; Pine does not act as a relay.

## Features

- Sessions are organized by project. One project can link to multiple folders, each with read-only or read-write permissions set separately. Multiple sessions can run at the same time.
- Preview of text and code, PDF, Office / iWork documents, data…
