## 📋 Project Introduction

BossAnalyze is a recruitment data analysis and visualization platform for BOSS 直聘, built on a microservices architecture using the Spring Cloud ecosystem. It aims to provide job seekers, recruiters, and data analysts with in-depth insights into the recruitment market. Through a distributed crawler system that scrapes, cleans, and analyzes BOSS 直聘 recruitment data, the system can display in real time salary distributions, skill demands, and market trends across different positions, regions, and industries.

### ✨ Core Features

- **📊 Multi-dimensional analysis**: supports cross-analysis across dimensions such as city, position, industry, and company size
