## What is this

Fuyu (浮屿) is a lightweight, borderless, always-on-top floating island. It stays tucked at the top of the screen most of the time, expands when needed, and retracts automatically after use. Frequently used things are kept on the island, so you don't have to switch windows back and forth just to glance at information.

## What's on the island

The island's appearance, size, collapse behavior, shortcut keys, and each feature can be adjusted in the settings window. In-app automatic updates are supported. All data is stored locally on your machine.

## Resource usage

When collapsed, idle, and not playing music (default settings, no plugins installed):

| | Measured |
|---|---|
| CPU | About **10%** of a single core (about 0.5% of total on a 20-core computer) |
| Memory | Fuyu itself, about **16 MB** |
| Agent page refreshing the session list once per second | **0.1%** of a single core |
| Each PowerShell plugin installed | About **60 MB** more |

For measurement methods and data, see [idle-usage.md](https://github.com/TixXin/Fuyu/blob/HEAD/docs/investigations/idle-usage.md).
