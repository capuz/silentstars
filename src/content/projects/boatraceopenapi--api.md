## ⚠️ Caution

**Please confirm the following before using this API.**

- **It is unofficial.** It has no connection whatsoever to the official BOATRACE website and related organizations.
- **It is not real-time.** Due to regular updates at approximately 3-minute intervals by GitHub Actions, there may be a delay of several minutes in reflecting the latest information.
- **Accuracy and completeness are not guaranteed.** Due to circumstances in collection and conversion, there is a possibility that omissions and errors may be included.
- **If you need official information, please be sure to check the official BOATRACE website.**
- **Please use at your own risk.**

## 📝 Overview

With this API, you can obtain boatrace data. The data is published on GitHub Pages and provided in JSON format.

| Item | Content |
|---|---|
| Supported Venues | All 24 venues nationwide (one day's data includes information for all venues) |
| Obtainable Data | Entry tables, pre-race information, and results |

---

## 🌐 Endpoints

Supported Period: **From January 1, 2026 onwards**

```bash
https://boatraceopenapi.github.io/api/v1/YYYY/YYYYMMDD.json
```

- `YYYY` → Year
- `YYYYMMDD` →…
