# Eason Agent Skills

A personal AI skills library for content creation, image-text publishing, technical writing, and Rokid AI application development. Author: Eason ([EasonZhu1997](https://github.com/EasonZhu1997)).

Each skill is a standalone directory containing `SKILL.md`, plus the reference notes, helper scripts, and tests its workflow needs. They help the AI assistant that uses them get work done, **but they are not software that logs in, uploads, or publishes with a double-click**.
