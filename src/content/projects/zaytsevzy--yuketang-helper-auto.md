## Quick Start

- 安装 [Node.js](https://nodejs.org/en) 24.x 和 npm 11.x。

```sh
git clone https://github.com/ZaytsevZY/yuketang-helper-auto.git
cd yuketang-helper-auto/ykt-helper-win
npm ci --include=dev --include=optional
npm run build
npm start
```

- 登录雨课堂

- 填入 API 并设置各功能的对应模型

- 连接需要 AI 辅助的课程

- 在其他页面选取 AI 辅助的功能
