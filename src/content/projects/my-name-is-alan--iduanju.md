# i短剧 (iDuanJu)

> **This project is completely free and open source. Any form of paid distribution or sale is prohibited.**
> This project is released under the **GPL-3.0** license: any work that uses, modifies, or derives from this project's code must likewise be open-sourced under GPL-3.0 and publish its complete source code.
> If you paid for this App or this code, you have been scammed. Please report the seller.

i短剧 is a native SwiftUI iOS multi-source short drama / video / comic / Telegram channel aggregator player, with a native Kotlin [Android version](#android-版) also available. The App itself **hosts no content**. All data is requested directly from various public sites by your device.

**Download**: Get the iOS unsigned IPA and Android APK from [Releases](https://github.com/my-name-is-alan/iDuanJu/releases) ([Android 1.5.8](https://github.com/my-name-is-alan/iDuanJu/releases/tag/v1.5.8-android), [iOS 1.5 build 8](https://github.com/my-name-is-alan/iDuanJu/releases/tag/v1.5b8)).
