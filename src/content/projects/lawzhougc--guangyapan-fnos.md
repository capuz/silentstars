# Guangya Cloud Drive fnOS Official Adapted Suite for Feiniu Private Cloud

High-speed upload and download · Multi-select batch and concurrent queue downloads · Magnet link/BT cloud offline · STRM media library 302 direct-connect gateway · Day/night theme auto-adaptation

> 🌐 **Web Access Address and Port Information**:
> - **Default Web service port**: `8998`
> - **Access via fnOS desktop window**: After installing the suite, click the Guangya Cloud Drive icon on the fnOS desktop to open the native micro-app window.
> - **Standalone browser access**: From any computer or phone browser on the local network, enter **`http://<NAS_IP>:8998`** directly (e.g., `http://192.168.x.x:8998`) to use the full standalone web version.
> - **STRM 302 streaming gateway address**: `http://<NAS_IP>:8998/strm/<fileId>/<filename>`
