# JSON Formatting Tool

A clean and elegant online JSON formatting tool that quickly formats, beautifies, and validates JSON data.

[https://rodert.github.io/jsonformat/](https://rodert.github.io/jsonformat/)

## Usage

| Method | Description |
| --- | --- |
| Online | Visit [GitHub Pages](https://rodert.github.io/jsonformat/) directly and use it right away. |
| Local | After cloning or downloading the project, open `index.html` in a browser. It works offline, and data is processed locally. |
| Docker | After installing Docker, run `docker compose up --build -d`, then visit `http://localhost:8080`. |

## Core Features

| Open Source Code | Local Data Processing |
| --- | --- |
| Source code repositories are available on [GitHub](https://github.com/Rodert/jsonformat) and [Gitee](https://gitee.com/rodert/jsonformat). | Input content and processing results are not uploaded to the cloud. |
