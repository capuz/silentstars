## Project Introduction

GoWind Shop（风行商城）is an enterprise-grade multilingual e-commerce platform built for going global. It uses an API-first architecture with decoupled frontend and backend, and provides native multilingual content distribution, multi-currency product display, and a single settlement currency. The backend is built on [golang](https://go.dev/) + [go-kratos](https://go-kratos.dev/) microservices, following a Protobuf-first (contract-driven) workflow. The admin frontend is based on [Vue.js 3](https://vuejs.org/) + [TypeScript](https://www.typescriptlang.org/), and the storefront is based on [Nuxt](https://nuxt.com/) + Vue 3.
