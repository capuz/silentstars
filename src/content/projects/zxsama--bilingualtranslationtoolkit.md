# BilingualTranslationToolkit

[ZH](https://github.com/zxsama/BilingualTranslationToolkit/blob/main/README.md) | [EN](https://github.com/zxsama/BilingualTranslationToolkit/blob/main/README_EN.md)

A toolkit for displaying bilingual interfaces in Blender.

> Blender 3.6–5.3 can use the same installation ZIP. For 3.6–4.1, install it under "Add-ons"; 4.2 and later recognize it as an extension when installed via "Install from Disk".

## Bilingual Interface Translation

A bilingual interface compiled from Blender's original translation files. It supports most languages built into Blender and a degree of format definitions, and also supports blacklists and whitelists for individual words.

> First-time use:
>   1. Install the add-on
>   2. Click the `双语翻译初始化(自动重启)` button in the add-on settings
>   3. Wait for Blender to restart automatically
>   4. Click the `编译双语翻译` button in the add-on settings again
