# WECHATAUTO.SDK - Modern WeChat RPA Automation Framework for AI

WeChatAuto.SDK is an AI-oriented WeChat RPA automation SDK, developed based on .NET and UI automation technology. It is designed specifically for scenarios integrating artificial intelligence (such as LLM context interaction). The SDK provides rich and intuitive APIs, supports modern .NET features such as dependency injection, and also provides an official Python SDK, allowing you to easily integrate WeChat automation workflows into your existing systems.

## ✨ Features

- 💬 **Comprehensive Message and Social Features** - Supports sending text, emojis, files, @mentions, message forwarding, group management, Moments operations, and address book management, and provides common capabilities such as message listening; all important interfaces are covered by unit tests.
  
- 🛡️ **Reduced Risk Control Risk** - Supports pure software automation and solutions combined with hardware keyboard/mouse simulators, allowing you to choose more robust execution methods based on business needs and security levels.
