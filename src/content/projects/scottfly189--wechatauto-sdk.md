# WECHATAUTO.SDK - A Modern AI-Oriented WeChat RPA Automation Framework

WeChatAuto.SDK is an AI-oriented WeChat RPA automation SDK built on .NET and UI automation technology. It is designed for scenarios that integrate artificial intelligence, such as LLM context interaction. The SDK provides a rich, intuitive API, supports modern .NET features such as dependency injection, and also offers an official Python SDK, so you can easily integrate WeChat automation workflows into existing systems.

## ✨ Features

- 💬 **Comprehensive messaging and social capabilities** - Supports sending text, emoji, files, @mentions, message forwarding, group management, Moments operations, and contact management, and provides common capabilities such as message listening; all important interfaces are covered by unit tests.
  
- 🛡️ **Lower anti-abuse risk** - Supports pure software automation as well as solutions combined with hardware keyboard and mouse simulators, so you can choose a more robust execution method based on business needs and security level.
