# LCSC3D: LCSC Component 3D Model Download and Altium Designer Component Library Export

**Search for components from the LCSC Mall, select them from account favorites or by C-number, view prices, stock and documentation, batch-download STEP / OBJ, export AD component libraries, and preview.**

LCSC3D is a Windows portable tool for hardware development, PCB design and mechanical fit. It brings together mall-based selection, account favorites, model download, Altium Designer component library export, and three kinds of preview. Download `LCSC3D.exe` to run it; no Python installation is needed. Exporting AD libraries also does not require Altium Designer to be installed on the computer.
