YLang is implemented in C17. Its compiler tokenizes and parses `.yl` files, checks names, initialization and types, generates C, and invokes GCC or Clang to produce a native executable. Linux and macOS are the primary tested targets; experimental native Windows support is available for 64-bit Windows with MinGW-w64. Windows support currently has a focused CI smoke suite and is not yet a claim of complete platform parity. It is a compiled language toolchain, not an interpreter.

YLang **2.2.0** is the latest stable release. The documented core language and default C-backend workflow remain the compatibility foundation. The stable compatibility commitment covers the documented core language and the default C-backend workflow. Newer subsystems—named imports, typed enums and structs, SDL2-backed GUI/Game2D APIs, the NASM backend, native Windows support, and optional YSPM packaging—remain explicitly experimental and may change independently of the stable core. Linux and macOS are the primary tested targets; native Windows x86-64 uses a limited MinGW-w64 smoke-tested path. YLang does not claim Rust-level memory safety or provide a security sandbox.
