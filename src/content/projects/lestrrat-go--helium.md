# helium

Helium is a fast XML toolkit for Go covering XML parsing, SAX2-style streaming,
XPath 3.1, XSLT 3.0, XInclude, XSD, Relax NG, and Schematron.

The root `helium` package handles parsing, DOM building, and serialization, but
the module is broader than an XML parser. It also includes
[`xpath3`](https://github.com/lestrrat-go/helium/blob/HEAD/xpath3/README.md) for XPath 3.1 querying and
[`xslt3`](https://github.com/lestrrat-go/helium/blob/HEAD/xslt3/README.md) for XSLT 3.0 transformations, alongside
[`xpath1`](https://github.com/lestrrat-go/helium/blob/HEAD/xpath1/README.md) for XPath 1.0 compatibility,
[`xsd`](https://github.com/lestrrat-go/helium/blob/HEAD/xsd/README.md), [`relaxng`](https://github.com/lestrrat-go/helium/blob/HEAD/relaxng/README.md), and
[`schematron`](https://github.com/lestrrat-go/helium/blob/HEAD/schematron/README.md) for validation,
[`xinclude`](https://github.com/lestrrat-go/helium/blob/HEAD/xinclude/README.md) for inclusion processing,
[`c14n`](https://github.com/lestrrat-go/helium/blob/HEAD/c14n/README.md) for canonicalization,
[`html`](https://github.com/lestrrat-go/helium/blob/HEAD/html/README.md) for HTML parsing, and…
