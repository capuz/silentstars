# Legato UI

A Vue 3 + TypeScript component library with seven themes and explicit CSS imports.

Starting with 1.2.0, the npm package is `legato-ui`. The previous release remains
available as [gavia-ui@1.1.0](https://www.npmjs.com/package/gavia-ui/v/1.1.0).
The [migration guide](https://github.com/whitewolf06/legato-ui/blob/HEAD/docs/migration.md#migration-1-2) includes an alias for existing imports.
When upgrading from 0.x, start with the [1.0 migration](https://github.com/whitewolf06/legato-ui/blob/HEAD/docs/migration.md#migration-1-0).
