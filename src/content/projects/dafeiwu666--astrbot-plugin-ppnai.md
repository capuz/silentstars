## 📖 Introduction
Send **/nai** to view help.
This plugin brings powerful **NovelAI** drawing capabilities to AstrBot. It is more than a simple API calling tool. It also integrates **LLM-assisted image generation**, **automatic drawing**, **quota management**, a **queue system**, and advanced NovelAI features such as Vibe Transfer and Character Keep.

Supports **Opus free mode** (small image mode). Subscribers can use it without limits.
