# Project Raco

**Universal Android Performance & Optimization Module**

## 📱 Compatibility
Project Raco is designed to support a wide range of chipsets, including but not limited to:
* **Snapdragon**
* **MediaTek**
* **Exynos**
* **Kirin**
* **UniSoc**

> **Note:** This module likely supports almost all mobile architectures (excluding PC/x86 CPUs). The best way to verify compatibility is to install it; the installer will verify support automatically.

---

## ⚡ Features
**NEW:** Project Raco now includes a robust **Companion App** with an **In-Game Overlay**, featuring:
* **Auto Game Detection & Monitoring**
* **Real-time Floating FPS & System Info**
* **Quick Controls Overlay** (Refresh Rate, Rotation Lock, Brightness, Volume, RAM Clean)
* **Gaming Tools** (Custom Crosshair, Auxiliary Lines)
