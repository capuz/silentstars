# Arcadia Eternity

Welcome to **阿卡迪亚:永恒之门** (Arcadia Eternity)

This project is a battle simulation system for 约瑟传说 (赛尔号2). It provides an online web page, a team editor, and a desktop content-pack workbench.

The web version uses HTML5, and the desktop client uses Electron. The battle core is shared by the Node server, the CLI, and local battles. The current development and integration branch is `main`.

Supports local AI battles, friend rooms, and regular matchmaking.

[创作者文档](https://battle-docs.yuuinih.com/) · [霜击教程](https://battle-docs.yuuinih.com/frost-strike) · [战斗 SDK 参考](https://battle-docs.yuuinih.com/sdk/)

You can learn about the project's architecture and some of its design philosophy in the DeepWiki linked above.
