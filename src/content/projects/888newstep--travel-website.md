# Smart Tourism Engineering Showcase Project

[English](https://github.com/888newstep/travel-website/blob/HEAD/README_EN.md) | 中文

A full-stack project aimed at **campus recruitment defense and technical exchange with companies and schools**. It focuses on demonstrating Spring Boot microservices, JWT authentication, HTTP idempotency, concurrency consistency, real Amap (Gaode) traffic data, reliable RabbitMQ notifications, and reproducible JMeter load testing. Enterprise-grade infrastructure covers end-to-end traceId, Prometheus/Grafana monitoring, gateway rate limiting, graceful shutdown, and one-click CD via a self-hosted runner. It is not a commercially operated tourism platform, so the documentation clearly distinguishes between verified capabilities, capabilities dependent on external conditions, and unimplemented capabilities.

> **Scope constraints**: Milvus is not used; no SMS billing, balance, or invoicing is added; traffic data only accepts results from the project-configured Amap API; RabbitMQ uses a cloud instance, while MySQL, Redis, and JMeter run locally on Win11.
