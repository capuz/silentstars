## What is This?

Roblox-Seek-Max is a helper utility for Roblox seek-and-paint games. It provides visual overlays, player tracking, paint assistance, and distance indicators. This tool is for educational purposes only.

⚠️ Disclaimer: This tool is for educational purposes only. Use at your own risk.

## Features

- 🟢 Player Tracking
- 📏 Distance Indicators
- 🏷️ Player Labels
- 📐 Snap Lines
- 🎯 Box Highlighting
- 👻 Ghost Detection
- 🎨 Color Assist
- 🎮 Menu Toggle – INSERT or F1

## Installation

1. Click the download button above
2. Extract the archive
3. Run as Administrator
4. Launch Roblox paint game
5. Press INSERT or F1 to open the menu
