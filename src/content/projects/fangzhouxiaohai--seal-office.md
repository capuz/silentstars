# Seal Office (海豹办公)

Seal Office provides Windows, Ubuntu, mobile, and web versions, supporting word processing, spreadsheet, and presentation editing, as well as PDF reading and page handling. **[Use the web version directly](https://seal.xingmasoft.com/office/)**. The home page and opened files share a multi-tab bar fixed to the bottom of the window. The interface uses Seal Office's own layout and interaction language. Office file support is limited to some formats and object round-trips. For the scope of basic features, see [Feature Scope and Known Limitations](https://github.com/fangzhouxiaohai/seal-office/blob/HEAD/docs/v1.6.3-WPS对标与已知限制.md). For the new-file dialog, printing, and template content, see [1.8.1 Upgrade Notes](https://github.com/fangzhouxiaohai/seal-office/blob/HEAD/docs/v1.8.1-打印与模板升级.md). For DOCX import fixes, see [1.8.2 Upgrade Notes](https://github.com/fangzhouxiaohai/seal-office/blob/HEAD/docs/v1.8.2-DOCX导入修复.md) and [1.8.3 Upgrade Notes](https://github.com/fangzhouxiaohai/seal-office/blob/HEAD/docs/v1.8.3-DOCX导入修复.md).
