# YouTube Timestamp Notes

A simple and practical browser extension that helps you mark important moments while watching YouTube videos, take notes, and jump back to those positions at any time. Suitable for language learning, course review, organizing long videos, and recording key points.

## Features

- **Mark timestamps**: Save highlights or important content from a video.
- **Record notes**: Add text to a timestamp, or save just the time marker.
- **Quick review**: Click a note to jump to the corresponding position in the video.
- **Categorized management**: Use folders to organize videos and notes, and search by video title or note content.
- **Edit and delete**: Edit notes, delete records, or clear all notes for the current video at any time.
