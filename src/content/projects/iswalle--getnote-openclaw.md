# Dedao Brain (formerly Get Notes) Skill

Make AI your second brain. Record anything at any time, and recall it when you need it.

---

## ✨ Core Capabilities

| Capability | Description |
|------|------|
| **📎 Save links in one step** | Send a link to save it. The original content is automatically fetched and a summary is generated. Supports Xiaoyuzhou podcasts, Xiaohongshu, WeChat Official Account articles, Bilibili, Douyin, and any public web page |
| **🖼 Turn images into notes instantly** | Send an image and it is automatically OCR'd for text, and the AI analyzes its content |
| **🔍 Semantic search** | No need to scroll through all your notes. Search by keyword, and the AI semantically recalls related content |
