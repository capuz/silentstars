# soRound OS (GeekTool)

[English](https://github.com/soBigRice/soRound_os/blob/HEAD/README.en.md) ·
**[Project website](https://sobigrice.github.io/soRound_os/)** ·
[Firmware download](https://github.com/soBigRice/soRound_os/releases) ·
[Installation guide](#快速开始主线固件)

A lightweight multi-function system for the **ESP32-S3-Touch-AMOLED-1.75C** round AMOLED development board. The project is built mainly on ESP-IDF firmware, providing a round-screen launcher, watch faces and lock screen, network and sensor tools, audio, mini games, BLE digital twin, and dual-partition cloud OTA.

**Current stable release: [v1.8](https://github.com/soBigRice/soRound_os/releases/tag/v1.8).**
Features released in beta.38 are promoted to the stable release; the stable and beta OTA channels are updated together. Devices with the dual 8MiB layout can check for updates without enabling the test channel.
62 watch faces in five groups, 32 of which are new in this release; STUDIO has 41 in total and uses a pure black background.
