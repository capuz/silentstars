## 🎯 What is this?

**Tech Digest Daily** is a **fully automated tech news aggregation system**:

- 🔄 **Automatic crawling** - Automatically fetches the latest popular content from 4 major tech platforms every day
- 🤖 **AI smart summaries** - Uses LLMs to generate personalized tech trend analysis
- 📧 **Email delivery** - Polished HTML emails, supporting Resend/SMTP
- 🎯 **Personalized recommendations** - Recommends the most relevant content based on your GitHub preferences
- 🆓 **Completely free** - Runs on GitHub Actions, no server required
