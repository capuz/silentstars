## Project Overview

csgoluck v2 is a lightweight web application built around a lucky-site presentation and intended for quick browser access. Its design follows a focused landing-page workflow instead of requiring a large, installable desktop program.

The repository provides a straightforward web entry point with limited setup requirements. Since the project is HTML-based, it can run in ordinary browser environments and be published through static hosting without a desktop runtime.
