Re:PhiEdit Next is refactored by **cmdysj** from the original **Re:PhiEdit (RPE)**, using **AI (GPT)**. The web and desktop versions share the same editing interface, supporting notes, judgment line animations, audio analysis, and video rendering.

Current code version: **0.14.1**. For update details, see [Release notes](https://github.com/kclg-YSJ/rpe-next/releases).

## Feature overview

| Area | Main features |
| --- | --- |
| Notes and events | Single and multi-line editing, batch operations, guide-line snapping, XY binding, undo and redo |
| Animation and trajectories | Standard easing, custom animation curves, judgment line trajectories, speed curves, event value scaling |
| Preview and rendering | Real-time preview, spatial trajectories, custom shaders, chart video output, editor playback rendering |
| Audio analysis | Waveform and spectrum, voice separation, prominent pitch, onset detection, rhythm drafts |
| Chart management | JSON / PEC / PEZ import, local chart library, automatic backups, chart version control |
| Extensions and collaboration | Editor skins, note resource packs, mods, global events, online collaboration |
