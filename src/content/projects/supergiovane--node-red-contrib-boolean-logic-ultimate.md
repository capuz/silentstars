# Boolean Logic Ultimate

A collection of enhanced logic and utility nodes for Node-RED. It supports persistent values after reboot and conversion of common Home Assistant values.

</p>

## Getting started

Install the package from the Node-RED palette manager or run this command in your Node-RED user directory:

```shell
npm install node-red-contrib-boolean-logic-ultimate
```

Importable flows are available from the Node-RED editor under **Menu (☰) → Import → Examples**, or directly in the [`examples/`](https://github.com/Supergiovane/node-red-contrib-boolean-logic-ultimate/blob/HEAD/examples/) folder. See the [examples overview](https://github.com/Supergiovane/node-red-contrib-boolean-logic-ultimate/blob/HEAD/examples/README.md) for the complete list.
