# Gitee Ai - JMeter Agent

[English](https://github.com/azhengzz/JMeter-AI-Agent-Plugin/blob/HEAD/README_en.md) | Chinese

Gitee Ai is a JMeter AI assistant plugin: describe what you need in natural language, and the AI creates, modifies, runs, and troubleshoots test plans directly in your test plan tree.

## Core Features

- **Generate a test plan from one sentence** — Describe your requirement (e.g. '10 threads sending GET requests to an endpoint and validating the response code'), and the AI creates thread groups, samplers, assertions, and timers directly in the tree, with no manual form-filling
- **Directly manipulate the test plan tree** — Add, edit, delete, move, copy, and batch enable/disable elements, with changes visible instantly; you can also have the AI analyze an existing plan and troubleshoot issues
- **Automatic parameter validation** — Parameter Schemas for 73 JMeter components. Wrong property names, types, or value ranges are reported immediately, without waiting for runtime
