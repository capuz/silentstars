# Nuxt + Supabase Starter

---

## What is this?

If you are already familiar with Nuxt and want to quickly create a complete project with **backend, database, authentication, and deployable**, this template can help you complete what usually takes weeks in just a few days.

This is not just a boilerplate—it includes the development experience of actual medium-sized enterprise systems:

- Complete processes including default authentication, CRUD, RLS, CI/CD, deployment, etc.
- Best practices and workflows for collaboration with Claude Code
- Pitfalls encountered, validated patterns, and anti-patterns to avoid

**Target audience**: Developers with Nuxt/Vue experience who want to try Supabase or are looking for a reliable full-stack development workflow.
