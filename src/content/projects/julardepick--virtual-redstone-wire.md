# Virtual Redstone Wire (Virtual Redstone Wire)

[English]
| [[English]](./README_en-US.md)

</div>

A Minecraft mod implementing remote transmission of redstone signals, not relying on physical redstone blocks, supporting one-to-one, one-to-many, and many-to-one connections.

---

# Mod Usage Tutorial

This mod highly depends on Forge but has no mod prerequisites and is not bundled with any other mods or modpacks.

Installation: Place the downloaded mod jar into the `.minecraft/mods` folder (requires Forge 1.20.1).

The mod currently only supports Minecraft 1.20.1. If you need compatibility with other versions, please [submit an Issue](https://github.com/JularDepick/Virtual-Redstone-Wire/issues/new) or [contribute](#contribution-guide).
