# Korea Research Tracker

**Automated dashboard for tracking Korean small-cap research reports**

> Automatically crawls ValueFinder · 리서치알음 reports and updates returns every day based on each report's publication date.

🌐 **Live:** [korea-research-tracker.vercel.app](https://korea-research-tracker.vercel.app)

## ✨ Key Features

- 📋 **Automatic crawling** — Detects new reports and sends Telegram notifications (ValueFinder + 리서치알음)
- 📈 **Return tracking** — Calculates returns in real time against the current price, based on the report's publication date
- 🏆 **Highest/lowest price** — Tracks the maximum gain and maximum loss periods after each report
- 📊 **Interactive charts** — 8 chart types, including forecast accuracy, target price analysis, and market reaction
- 🤖 **Fully automated** — Runs automatically every 4 hours on weekdays via GitHub Actions
- 🌐 **Web dashboard** — Next.js dashboard deployed on Vercel
