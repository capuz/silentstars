# C桌面 / CDesk

[Chinese](https://github.com/gcy529/CDesk/blob/HEAD/README.md) | [English](https://github.com/gcy529/CDesk/blob/HEAD/README.en.md)

> **C = Car · Clean · Cheap**
> A clean desktop for old car head units, TV boxes, and Android TV. No ads, no recommendation feed.

**Official website (direct access in China): [https://gcy5.cn.mt](https://gcy5.cn.mt)**: feature overview, installation steps, FAQ, and group joining/feedback are all here.

## What is this

China has many car head units and TV boxes from 2015–2022. The hardware still works, but the system desktops are laggy, ugly, and full of ads, and the vendors stopped updating them long ago.

**C桌面 only does four things:**

| Feature | Description |
|---|---|
| 🖥 Replaces the default desktop | Three desktop pages (Recent / Apps / Media), opens on "Recent", flip pages with remote D-pad arrow keys |
| 🌙 Wallpapers | 4 built-in (日光少女 / 鲸夜 / 晨光 / 金色时刻) + solid colors + up to 3 custom photos; optional day/night auto-switch (晨光 from 6:00 to 18:00, 金色时刻 otherwise) |
| 📶 Real-time network speed | Floating display in the lower left and right corners, sampled with simple `TrafficStats` deltas, zero wake-up…
