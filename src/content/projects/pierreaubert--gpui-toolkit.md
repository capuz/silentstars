# gpui-toolkit

Libraries, examples, and tooling for building GPUI applications with native
`div()`-based rendering, reusable components, charting primitives, design
tokens, working on all platforms: macOS, Linux, Windows, iOS, tvOS, Android
and WASM.

## Build your first app

**[Start here: generate, run, and build a small interactive app →](https://github.com/pierreaubert/gpui-toolkit/blob/HEAD/TUTORIAL.md)**

| --- | --- |
| [Rust: scaffold a native app](https://github.com/pierreaubert/gpui-toolkit/blob/HEAD/TUTORIAL.md#1-scaffold-an-app) | Create a project, add a working counter, run a desktop window, and build a release executable. Continue to the generated iOS and Android hosts. |
| [Python: write a native app](https://github.com/pierreaubert/gpui-toolkit/blob/HEAD/TUTORIAL.md#12-python-runtime-demo) | Set up the Python package, write the same counter, and run it through the native GPUI host. |
| [Build with an agent](https://github.com/pierreaubert/gpui-toolkit/blob/HEAD/TUTORIAL.md#agent-workflow) | Discover the CLI contract, scaffold a project, look up real APIs, and verify the result. |
