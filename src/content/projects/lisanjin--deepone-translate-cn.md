# DeepOne Chinese Localization Tool

## Overview

For translation progress and resources awaiting archiving, see [Translation status](https://collect.deeponer.online/)

The translation tool uses [GalTransl](https://github.com/cx2333-gt/GalTransl)

The local deployment method is deprecated. If you previously used the local deployment patch, please switch to the new version. The code for the local version is still retained, so if you want to replace the text yourself you may continue to use it, but it is no longer maintained.

For the Android client localization implementation, see the repository [DeepOne-Mod](https://github.com/anosu/DeepOne-Mod)

Translators: Atrili, mamomo, 刚大木, SK, 科斯卡特

Patch production: 某江南的黎三金

Special thanks: 518, 红凯, anosu

The story and characters from the first anniversary of the localization files and earlier come from the now-shut-down Traditional Chinese server. From Chapter 7 of the main storyline onward, the localization comes from the translators listed above. Other content was translated using GPT4/Claude + GPT3.5 + deepseek.

This patch is for exchange and study only and may not be used for any commercial profit. Please delete it within 24 hours…
