# Eufy Mega Security for Home Assistant

The project is maintained as an open-source gateway and Home Assistant integration. Start with the [developers start here guide](https://github.com/mscodemonkey/eufy-mega-security/blob/HEAD/docs/DEVELOPERS_START_HERE.md) if you are new to the codebase, then use the [Mega platform reference](https://github.com/mscodemonkey/eufy-mega-security/blob/HEAD/docs/MEGA_PLATFORM.md) for protocol and data-flow detail. The [contributor guide](https://github.com/mscodemonkey/eufy-mega-security/blob/HEAD/CONTRIBUTING.md) covers local setup, testing, protocol boundaries, and release rules. The [file map](https://github.com/mscodemonkey/eufy-mega-security/blob/HEAD/docs/FILE_MAP.md) explains where each part lives, and [SECURITY.md](https://github.com/mscodemonkey/eufy-mega-security/blob/HEAD/SECURITY.md) covers private reports and secret handling.

</p>

Reliable, event-first Home Assistant support for Eufy cameras that do not provide a permanent RTSP stream.
