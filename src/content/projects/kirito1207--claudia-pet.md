# claudia-pet

claudia-pet is a Claude desktop pet for Windows (there is also a Linux version, see [linux/README.md](https://github.com/kirito1207/claudia-pet/blob/HEAD/linux/README.md)). The pet's name is claudia. She lives in the Claude desktop app window (she can also be placed on the desktop), follows Claude Code's working state with her actions, and keeps you company while you chat and write code.

This project is modified from [CrossPet](https://github.com/lokicorvus/crosspet) (lokicorvus) and references [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) (PC2005-cloud). The sources and licenses of the code, character art, and icons are described in the "Sources and License" section at the end of this document and in [NOTICE.md](https://github.com/kirito1207/claudia-pet/blob/HEAD/NOTICE.md). This is an unofficial fan project and is not affiliated with Anthropic.

## What she does

- **Follows the Claude window**: She floats just above the Claude window, not always on top, so other windows can cover her. When Claude is minimized, she hides along with it. When Claude is closed, she exits too, and comes back out the next time you open Claude.
