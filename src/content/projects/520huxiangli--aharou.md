## Download and Install

- **Latest package**: Download `Aharou-*.apk` from the [Releases](https://github.com/520huxiangli/Aharou/releases/latest) page. Allow "Install unknown apps," then install it.
- Supports Android 8.0+ and does not require root. The built-in Linux environment initializes automatically on first launch.
- You configure all models, keys, and endpoints yourself. No models are bundled, and there is no provider lock-in.

## Introduction

Aharou packs a complete AI assistant and Linux environment into your phone. It includes a built-in Alpine container and a multi-tab terminal. The Agent can read and write files, run commands, and run builds. You can also switch the execution backend to a remote SSH host. Everything runs on the device itself, so you don't need a computer or have to set up your own environment.
