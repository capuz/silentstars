## 🖥️ Client Usage

Juejin Usage provides macOS / Windows desktop clients that work out of the box with no additional configuration.

### Download and Install

Go to the [Releases](https://github.com/juejin-cn/juejin-usage/releases) page to download the installation package for your system (macOS: select `.dmg` by chip type, Windows: select `.exe`). Works immediately after installation.

> 💡 macOS showing "damaged"? Execute `sudo xattr -dr com.apple.quarantine` in the terminal, then drag the app into the terminal window.

### First Launch

1. Open the **Juejin Usage** application
2. On first run, it will automatically attempt to register Claude / Codex Hook and sync local usage
3. The panel will automatically pop up, displaying usage trends, model distribution, and other data

If Claude / Codex or other Agent tools are not detected, please confirm that they have been installed and used at least once.
