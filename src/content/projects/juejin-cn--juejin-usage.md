## 🖥️ Desktop Client Usage

Juejin Usage provides macOS / Windows desktop clients, ready to use upon installation, no additional configuration needed.

### Download and Installation

Go to the [Releases](https://github.com/juejin-cn/juejin-usage/releases) page to download the installation package for your system (macOS select `.dmg` by chip, Windows select `.exe`), ready to use upon installation.

> 💡 macOS shows "damaged"? Execute `sudo xattr -dr com.apple.quarantine` in the terminal, then drag the application into the terminal window.

### First Launch

1. Open the **Juejin Usage** application
2. On first run, it will automatically attempt to register Claude / Codex Hook and sync local usage
3. The panel will automatically pop up, displaying usage trends, model distribution, and other data

If Claude / Codex and other Agent tools are not detected, please confirm they are installed and have been used at least once.
