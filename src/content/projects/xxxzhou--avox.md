# avox

avox is a cross-platform audio-video capability library (C++17) that provides a unified pipeline from device capture, hardware decode/encode, GPU image processing to rendering, streaming and recording. The player is currently the most complete module; WebRTC real-time communication and AI capabilities (speech recognition, machine translation, image restoration, super-resolution) are integrated on-demand in plugin form; XR/VR·MR camera calibration and virtual-real fusion (virtual production) modules have been verified in production and integrated, with virtual human (digital human) modules currently being integrated; texture-level direct passthrough has been achieved with UE5, Unity3D, and Godot game engines.

avox is derived from the author's years of accumulated audio-video/GPU technology expertise, organized with the assistance of large models.
