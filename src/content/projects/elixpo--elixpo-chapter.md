## About this repository

`elixpo_chapter` is Elixpo's master Chapter collection. It holds shared Chapter
operations and selected project material while preserving each project's
canonical repository, history, issues, releases, and maintainer authority.
Repository transfer is a separate custody decision, never an entry requirement.

Read [CONTRIBUTING.md](https://github.com/elixpo/elixpo_chapter/blob/HEAD/CONTRIBUTING.md) and the
[Code of Conduct](https://github.com/elixpo/elixpo_chapter/blob/HEAD/CODE_OF_CONDUCT.md) before participating. Current repository
classifications and custody decisions are published from the canonical registry
maintained by `elixpo/elixpo`.

## What Elixpo is

**An open-source project foundry where people build in public and release meaningful projects together.**

> **Build in public. Release as a project.**

Elixpo works with active maintainers to build and release open software, reproducible research, and publicly operated services. Time-bounded Chapters give work a clear public story, prepared contribution pathways, accountable review, and a durable release record. Successful projects may continue as Elixpo Member Projects.
