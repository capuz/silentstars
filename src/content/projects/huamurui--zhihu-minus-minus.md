# 🐱 Zhihu-- (Zhihu Minus Minus)

> [!IMPORTANT]
> **🚧 Project Statement**: The core functionality of this project is currently stable, but there are still many imperfections, and the Zhihu API may change, causing features to fail.  
> PR Issues or forks for modifications are welcome. You can also check out other software: <https://github.com/zhihulite/Hydrogen> and <https://github.com/zly2006/zhihu-plus-plus>

A lightweight, clean, ad-free third-party Zhihu client built on **React Native (Expo)**. It aims to return to the essence of reading and provide an extremely smooth Zhihu browsing experience.

## ✨ Features

- **Clean and Lightweight**: Only the content you want to see, no ads, no bloated features.
- **Immersive Experience**: Adapts to system light and dark modes, supports **global theme color customization**, and supports automatic rotation on sensing devices.
- **Multiple Accounts and Guest Mode**: Supports **seamless switching between multiple accounts** and provides a basic reading **guest mode** (browsing Feed without logging in).
