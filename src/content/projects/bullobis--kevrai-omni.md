> **Current source version: v4.18.3** · One-click local AI workstation: LLM / TTS / image / video / 3D / audio / super-resolution / music / source separation / ASR, multi-engine (llama.cpp + MNN + vLLM + ComfyUI), hardware-aware recommendations, built-in LTX-2.5 video, Agent assistant, knowledge base and super search.
>
> v4.18.3 has been released with installers for Linux (deb / AppImage), macOS (arm64 / x64 dmg), and Windows (x64 exe / zip). The installers bundle a complete PyInstaller onedir sidecar. The Release also provides `sidecar-linux-x64.tar.gz` as a complete onedir, and it was unpacked and launch-verified before release.

Kevrai Omni is an **Electron + native HTML/CSS/JS** desktop application, paired with a local Python (FastAPI) sidecar that handles the model catalog, downloads, engines, and inference. All data is stored on the local machine by default, and downloaded models can be used without relying on any remote service.
