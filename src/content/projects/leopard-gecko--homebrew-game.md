## Rogue for macOS (Japanese/English switchable, color-enabled version)

Rogue is one of the earliest RPGs, created in 1980. It is known for characters represented by single characters and dungeons that are randomly generated each time you play. It is very old, but it has a unique charm that I think is still enjoyable to play today.

The packages distributed here are **version 5.4**, the final form of the original Rogue lineage, and **Clone Version 3** (hereinafter referred to as **Clone III**), the final form of the clone lineage.

Version 5.4 is the mainline version of Rogue, and this site also recommends it as the main choice. In Japan, however, clone-2 lineages such as data-separated Rogue are more common. Clone III has almost the same usability as the Japanese clone-2 versions, so if you are familiar with the traditional Japanese versions, Clone III is recommended.

Both add UTF-8 Japanese/English display switching, support for Japanese and emoji input, color display, and fixes for macOS, among other changes. The official Homebrew repository already has an English Rogue package, so the packages here are named `jrogue` and `jrogue-clone`.
