# 万象

**An all-encompassing personal management suite for Obsidian**: diary, to-dos, Pomodoro focus, vocabulary memorization, self-discipline, fitness, intensive listening dictation, word roots and affixes, phrases, account passwords, focus planning, going-out checklist, job search progress, asset tracking, bookkeeping, sleep log, mind maps, canvas, weather, meeting DDLs, daily schedule, calendar, current focus, life system, statistics, countdown, and **37 interactive modules** + **11 plugin-level features**.
Each module is a `homepage` code block that can be embedded in any note. You can also use it as a standalone app in the **full-screen workbench**.
You can also use 'Homepage' to assemble them into an out-of-the-box personal dashboard. One plugin holds multiple modules that don't interfere with each other, with zero theme dependency.

> 📛 **Starting from v1.80.0, this plugin has been renamed from 'Homepage Modules' to '万象'**. Only the display name changed. The plugin id, `homepage` code blocks, release repository address, and purchased License Keys are all unchanged, so no action is needed after upgrading.
