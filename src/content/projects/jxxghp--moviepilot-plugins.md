# MoviePilot-Plugins

MoviePilot official plugin repository, also the source code and index repository of the default plugin marketplace:
<https://github.com/jxxghp/MoviePilot-Plugins>

The current development target is MoviePilot V3. New plugin developers do not need to read V2 documentation first, nor should they self-assemble procedures between multiple "adaptation guides".

## Getting Started Here

### Developing a New V3 Plugin

Read [MoviePilot Plugin Development Guide (V3)](https://github.com/jxxghp/MoviePilot-Plugins/blob/HEAD/docs/Plugin_Development.md). This is currently the only comprehensive main guide, covering directory structure, minimal skeleton, lifecycle, stable SDK, configuration and data, V3 database transactions, pages, events, API, services, testing and publishing.

### Migrating Old Plugins to V3

Read the main guide first, then check [Migrating V2 Plugins to V3](https://github.com/jxxghp/MoviePilot-Plugins/blob/HEAD/docs/V3_Plugin_Adaptation.md).
