# btnews
This is an archive repository of 睡前消息 scripts.

[View online](https://mdark.org/docs/btnews/index)

[rss](https://mdark.org/rss/btnews)

This repository was originally created as an archive of 睡前消息 script content. Other sections have been added since.

The master branch only stores script content and the script that fetches it.
### clone
If you need to clone this repository and submit content, be sure to use a single-branch clone. The single-branch clone is about 1G (images files). A full clone is too large at 4g (being optimized).
```
git clone -b master --single-branch https://github.com/mdark-org/btnews
```

### 2025

The main branch has removed all documentation framework and is now a pure documentation repository. It is part of MDARK.
See [https://github.com/mdark-org](https://github.com/mdark-org) for details.
