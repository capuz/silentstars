boruta is an identity and access management solution implementing OAuth 2.0
specifications up to decentralized identity. It includes along with the
authorization server a gateway and an administration interface that helps to
provide authentication and authorization to HTTP services with possible
verifiable credentials issuance and presentation.

## Status

boruta is currently in an __open beta phase__, if you are interested in the project and the tools it provides, you are encourage to test the product within your context. Production readyness will depend on your feedback, helping to fix the possible bugs and improve the solution usability. While being mostly stable and security asessed for some of its parts, boruta is a work in progress, please read the [General Terms and Conditions](https://github.com/malach-it/boruta-server/blob/HEAD/GENERAL_TERMS_AND_CONDITIONS.md).
