## 快速开始

### 直接运行

1. Go to the [Releases](https://github.com/710850609/EasyTier-EUI/releases) page and download the installer package for your platform
2. Run the program package ```EasyTier-EUI```
3. On the "配置" (Configuration) page, add a network configuration. For beginners, the quick mode configuration is recommended: just enter the network name and key
4. To join other devices to the virtual network: in the "应用" (Applications) menu, select the installer package matching the device's system architecture, then follow the instructions on the page to join the network
5. View the network status on the "节点" (Nodes) page. Done!
