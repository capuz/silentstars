# Onmyoji Script (Onmyoji-Script)

An automation script tool only for the desktop version of the game "Onmyoji".

Mainly updates and releases packages at https://gitee.com/clannad_cai/onmyoji-script, GitHub occasionally has issues.

## Usage Instructions

1. Download the latest release version `yys-script-x64.rar` and extract it completely to a folder.
2. Right-click and run `yys-script.exe` as administrator to use it.
3. With default settings, the script can run while the game window is minimized.
4. **Important:** Must run as administrator! Otherwise, injection will not work.

## Notes

⚠️ **Important Reminder:**
- The current version requires the desktop version of "Onmyoji" to always be running in the foreground.
- Brief tests have not yet been detected by "Kisuke Urahara"; the desktop version will definitely get flagged over time. Be cautious!
- Please use responsibly and follow game rules.
- Use at your own risk.
