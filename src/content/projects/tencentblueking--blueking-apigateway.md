## Overview

BlueKing API Gateway (API Gateway) is a high-performance, highly available API hosting service that helps developers create, publish, maintain, monitor, and protect APIs, so that data or services from BlueKing applications or other systems can be opened to external users quickly, at low cost, and with low risk.

BlueKing API Gateway is divided into a control plane and a data plane. The control plane handles API configuration, publishing, monitoring, permission management, and similar functions. The data plane handles API traffic forwarding, security protection, and similar functions. The data plane is built on [Apache APISIX](https://github.com/apache/apisix) with a series of added plugins to support BlueKing API Gateway's features. Thanks to the dynamic, real-time, and high-performance characteristics of Apache APISIX, BlueKing API Gateway can support high-concurrency, low-latency API hosting services.

This project is `BlueKing API Gateway - Control Plane`.
