## Overview

This repository contains the complete source code for a dual-experience personal portfolio application.

Rather than presenting everything through one conventional portfolio page, the application introduces two distinct experiences:

- **Tech** — an engineering-focused experience for software projects, technical capabilities, and development work.
- **Everything Else** — a creative experience for interests, experiments, visual storytelling, and explorations beyond software engineering.

Both experiences belong to the same application and share its underlying engineering foundation while maintaining their own visual identity and presentation.

The result is a portfolio that functions as a cohesive digital product rather than a collection of disconnected landing pages.
