**XOps CLI** is a modern command line operations toolset developed in Go, designed to simplify and automate daily server management tasks.

In addition to traditional SSH management and batch execution features, XOps natively integrates the **Model Context Protocol (MCP)** server, allowing AI Agents (such as Claude) to interact directly with your infrastructure under secure constraints. It is the perfect bridge connecting AI assistants with real server environments.

### ✨ Core Features

- 🤖 **AI Native (MCP Server)**: Built-in Model Context Protocol server, including complete security constraints, risk assessment, and policy control. Allows AI assistants to manage servers securely for you.
- 🛡️ **Enhanced SSH and TUI**: Fully compatible with OpenSSH (supports JumpHost, tunneling, Agent forwarding). Built-in beautiful **TUI (Terminal User Interface)**, and supports automatic Sudo elevation mode.
