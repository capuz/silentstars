# GSNode

> The install script always fetches the latest version; after running, the terminal prints the version number actually used.
>
> [Latest release](https://github.com/gsvps/GSNode/releases/latest) · **Website [GSVPS](https://www.gsvps.com)**

**English**  
GSNode is a lightweight server node quality probe for the [GSVPS](https://www.gsvps.com) ecosystem. One command downloads the binary, runs a full benchmark, uploads the report to GSVPS, and prints the online report URL in your terminal.

**Chinese**  
GSNode is a server node quality testing tool within the [GSVPS](https://www.gsvps.com) ecosystem. A single command handles the download, full detection, and report upload, and outputs an online report link and module score summary in the terminal.
