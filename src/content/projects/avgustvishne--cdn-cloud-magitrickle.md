## What this is

Twice a day, the repository collects address ranges of CDNs, cloud providers, and individual services, cross-checks them against each other, and publishes ready-made `.txt` subscriptions that can be connected directly in MagiTrickle.

## How to use

1. Choose a set in the table below.
2. Open the IPv4 or IPv6 link. It leads directly to the file with the address list.
3. Add this link to MagiTrickle as a subscription source (URL, not a file).
