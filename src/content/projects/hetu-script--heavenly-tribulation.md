# 天道奇劫

A game draws a lot of inspiration from Battlebrothers & Slay the Spire.

This is a game that borrows many gameplay mechanics from 《太阁立志传》 and 《弈仙牌》.

For more about gameplay and setting, please refer to the documents in the **docs** directory.
