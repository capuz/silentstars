> 🍎 **Mac users** are recommended to use [HeyBuds](https://github.com/abaichuan1017/HeyBuds).

EncoDeck is a Windows earbuds control tool written in **WinUI 3**. It brings common earbud settings to the PC: check left and right earbud and charging case battery levels, switch noise control, adjust EQ and spatial audio, and manage earbud touch controls. You can keep just a tray icon running without leaving the main window open all the time.

It currently focuses on **OPPO / OnePlus** earbuds and also supports some **realme / DIZO, vivo / iQOO, Huawei, Honor, Xiaomi / Redmi, Sony, AKG, Sennheiser, Edifier, MOONDROP, Samsung, Google, Bose, Nothing / CMF** earbuds and USB 2.4G gaming headsets. Available settings vary by model. **Hardware verification is currently done mainly on the OPPO Enco X4**; other models are implemented mainly based on protocols and model configuration. Test feedback is welcome.
