# HardTrans (hdTrans)

An offline translation program that translates Japanese into Korean.
It comes with a built-in dictionary and translation engine, so it is ready to use as soon as you extract the archive.
It provides a Windows translation window, a command-line program, and a connection tool for ezTrans.

Creator: Sokcuri ([Homepage](https://sokcuri.neko.kr/), [X](https://x.com/sokcuri))

## Try it on the web

Before installing, you can try translating sentences at the [web translator](https://trans.kuri.kr).

## Translation improvement examples

The original ezTrans column is quoted from a [public comparison post](https://x.com/sokcuri/status/2111443062698451143/photo/1), and the hdTrans column shows results translated directly by the fixed C++ engine from the benchmark below.

| Japanese | Original ezTrans | hdTrans |
|---|---|---|
| 肉がジュージューと焼ける | Meat Jewish Jewish burns | Meat sizzles and gets grilled |
| バイトに行く | Go to bite | Go to a part-time job |
| おっと、すまんね | Husband, sorry | Oops, sorry |
| 夢みたい | Wanting to see a dream | Like a dream |
| くそっ！ | Poop! | Damn it! |
| やったー！ | Did it-! | Got it! |
