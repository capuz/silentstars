# Phira Pro

Phira Pro is an **unofficial remix** of [Phira](https://github.com/TeamFlos/phira) v0.8.3.

While keeping the original gameplay and feel as unchanged as possible, it adds many features related to **practice, debugging, appearance customization, and local score management**, making it suitable for practicing high-difficulty charts, studying judgment feel, or creating custom appearances.

> **This project is an unofficial remix and has no relation to TeamFlos / the official Phira.**
> Any consequences arising from using this remix are borne by the user. Please do not report issues with this remix to the official project.

## Download

Download the Windows, macOS, and Linux archives, the Android arm64 APK, or the unsigned iOS IPA from the [Releases](https://github.com/Phira-Pro/Phira-Pro/releases) page. On Windows, extract the archive and run `phira-main.exe`; on macOS / Linux, run `phira-main`. Android updates keep app data; the iOS IPA must be signed and installed by yourself.

The current source version is **pro.19 development build** (in-app `0.8.3-pro.19`, build 96). It includes RPEN upgraded to **0.14.0**, and keeps chart video export, Plugin API v3, and PRCA…
