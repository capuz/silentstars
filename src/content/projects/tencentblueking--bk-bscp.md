BlueKing Service Configuration Provider (BlueKing Service Configuration Provider) provides service configuration management for businesses. The platform integrates with other BlueKing products to offer a one-stop solution for businesses.
The platform is organized around businesses as the top-level unit, isolating each business's service configurations. It uses the BlueKing Permission Center for service-level access control and supports hosting business configurations for both traditional and container-based deployments. It currently supports file-type configurations and key-value (KV) configurations.

## Overview

What can BSCP do?

- Separate business processes from configuration files
- Configuration version management and hot update
- Full-time gray release control
- Templated configuration management
- Support for file, KV, and table-type configurations
- Multiple consumption methods, including containers, hosts, SDKs, APIs, and pipeline plugins
