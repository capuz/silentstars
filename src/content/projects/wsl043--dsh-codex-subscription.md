# DSH Codex Subscription

**Simplified Chinese** · [English](https://github.com/WSL043/dsh-codex-subscription/blob/main/README.en.md)

**Connect your ChatGPT / Codex subscription directly to DeepSeek Harness**

Sign in with a ChatGPT Plus / Pro subscription to use GPT-6 and other Codex models in DSH, check quota, search the web, and generate images. No OpenAI API key is needed, and it does not depend on the Codex CLI.
