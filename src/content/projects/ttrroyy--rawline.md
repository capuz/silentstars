# Rawline

**Client for Windows, Linux and macOS based on the sing-box and Xray cores**

Fork of [Throne](https://github.com/throneproj/Throne)

In addition to the standard sing-box and Xray protocols, it supports MRTT, qWDTT, WDTT Plus, CSQTT 2.5.0 Legacy, FreeTurn, SSTP, olcRTC, OpenFlux, DNSTT, VayDNS, SlipStream, MasterDNS, CottenDNS, Soar, S3 Bypass and WireGuard obfuscation (wg-obfuscator, Phobos, wgobfs) - with subscriptions, ping testing and split routing.

## Download

The latest version is available in [Releases](https://github.com/ttrroyy/Rawline/releases/latest).

- Windows: the installer `windows-universal-installer.exe` or the archives `windows64`, `windows-arm64`, `windows32`. For older systems - `windowslegacy64`.
- Linux: `.deb`, `.rpm`, Arch (`.pkg.tar.zst`) packages and the `linux-amd64` / `linux-arm64` archives. `system-qt` builds use the system Qt.
- macOS: `macos-arm64`, `macos-amd64`; for older versions - `macoslegacy-amd64`.

The client notifies you about new versions itself.
