# 🎵 ncmm

`ncmm` is a command-line assistant tool specifically designed for **NetEase Cloud Musicians**, developed in Go language.

This project aims to help NetEase Cloud musicians / regular accounts complete daily check-ins with one click, automatically execute black vinyl VIP advanced tasks (including automatic publishing of graphic notes and quick deletion, relay playback volume for multiple fan accounts, etc.), helping musicians easily obtain and maintain black vinyl membership rights. The tool strictly follows anti-risk control design, supports safe isolation of multiple accounts, playback volume sharing rollback, daily song mixed listening interference, and self-playback interception and other security strategies.

---

1. **🔑 Account login management (`ncmm login`)**: Supports QR code login, Cookie import, and CookieCloud synchronization.
2. **🎵 Simulate song playback (`ncmm playids`)**: Realistically simulates audio traffic download, playback duration waiting, and song playback action reporting.
