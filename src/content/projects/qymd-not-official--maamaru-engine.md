# まあ丸 `🦊` — Touken Ranbu ONLINE 本丸 Steward

**Simplified Chinese** · [English](https://github.com/qymd-NOT-official/maamaru-engine/blob/HEAD/README_EN.md)

I've been playing Touken Ranbu for nine years and still want to play, but I no longer want to tap through every round of repetitive actions myself, nor keep calculating resources by hand in Excel. So I built まあ丸: it looks after my honmaru when I need it, and when I come back, I can flip through the record of what happened that day.

> **You decide what the honmaru does today; execution, supervision, wrap-up, and recording are handed off to まあ丸.**

The Chinese server version can run tasks for you, or be used only for bookkeeping. The Japanese server version can connect to the game browser and update honmaru records while you play, and it can also select an era and a small map in the 「日服合战场」 (JP-server 合戦場 Battlefield) to repeatedly run maps you've already cleared.
