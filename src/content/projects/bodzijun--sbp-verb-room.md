# Verb Room

Version 0.1.16 smooths the start of the late tail, adds **Physical / Creative** modes with an Absorption scale and an RT60 target assistant, remembers Walls / Floors / Ceilings / Plates layer locks in projects and presets, and adds pan, zoom-to-cursor and fit-to-view to the 3D view. See the [0.1.16 release notes](https://github.com/Bodzijun/sbp-verb-room/blob/HEAD/docs/Release_0.1.16_en.md); older projects and presets still load. Version 0.1.15 extends the Energy analyzer to 48 / 64 / 96-cell grids and adds 0.5–120 dB colour range with Auto contrast. See the [latest release notes](https://github.com/Bodzijun/sbp-verb-room/blob/HEAD/docs/Release_0.1.15_en.md) and [analyzer guide](https://github.com/Bodzijun/sbp-verb-room/blob/HEAD/docs/Energy_analyzer_0.1.14_en.md). The background energy map offers source, height, component and octave-band selection. This includes positioned dry sound and the scene Outliner from 0.1.12, plus the 0.1.13 layout fixes; see the [editor guide](https://github.com/Bodzijun/sbp-verb-room/blob/HEAD/docs/Spatial_editor_0.1.12_en.md) and [preset exchange guide](https://github.com/Bodzijun/sbp-verb-room/blob/HEAD/docs/Presets_0.1.10_en.md).…
