# Sporttery Engine

Sporttery football probability analysis and virtual betting simulation system. It is based on the Dixon-Coles Poisson model and Monte Carlo simulation, uses market-dominant probability fusion, allocates virtual bets with the Kelly criterion, and runs fully automatically on GitHub Actions at zero server cost. **For data analysis and algorithm learning only. It does not constitute any betting advice. All outputs are virtual bookkeeping.**
