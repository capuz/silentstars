# Sporttery Engine

Sporttery football probability analysis and virtual betting simulation system. Based on the Dixon-Coles Poisson model + Monte Carlo simulation, with market-probability-dominant fusion and Kelly criterion for virtual bet allocation. Runs fully automatically on GitHub Actions at zero server cost. **For data analysis and algorithm learning only. Does not constitute any betting advice; all outputs are virtual bookkeeping.**
