# Bookx

**A GNOME-native e-book library, reader and EPUB editor, written in Rust with GTK 4, libadwaita and [Relm4](https://relm4.org).**

> **Beta.** Bookx 0.3.0-beta.3 is beta software. It can have bugs, so keep a backup of anything you care about (Bookx can back up your library for you). Reports help us fix bugs: choose **Main Menu → Report a Problem**, read the log report, then **Open GitHub Issue**. Download it from [GitHub Releases](https://github.com/adhadse/Bookx/releases/latest); there are Linux (x86_64) files only for now.

📖 **Documentation: <https://bookx.adhadse.com>** (features, formats, limits, shortcuts, command line, devices, plugins)

This README is for people working on Bookx. What the app can and cannot do is described in the
[wiki](https://bookx.adhadse.com); its source is in [`wiki/`](https://github.com/adhadse/Bookx/blob/HEAD/wiki/).
