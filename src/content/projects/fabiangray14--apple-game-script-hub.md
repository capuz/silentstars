## What Apple Hack Does

Apple Hack is designed to run in the browser alongside an HTML-based brick game. It provides a compact companion layer for web sessions, giving users a simple script utility without requiring a large supporting toolchain.

The project is organized for browser delivery and folder-based installation. Its structure is intended to make setup and future replacement straightforward, while providing controls related to input handling and timing for HTML game play.
