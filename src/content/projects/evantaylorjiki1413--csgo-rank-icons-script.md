## What This Collection Contains

CS:GO Rank Icons provides an organized set of rank symbols associated with Counter-Strike: Global Offensive. It is intended for Windows users who need the game's extracted visual assets for reference, interface design, documentation, or other content workflows rather than a tool that runs during gameplay.

The files originate from the game's binary data, including VPK-based extraction sources and the original icon artwork. By bringing these assets together in one place, the repository offers a practical way to inspect and reuse the CS:GO rank icon set.
