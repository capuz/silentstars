## Sweet LIME

(Lightweight Input Method Editor) The code is licensed under open-source GPL, and the original project website is available on Github and Academia Sinica OpenFoundary.

Github Project URL http://github.com/lime-ime/    http://www.limeime.org/

**The current LIME HD has not been updated for a long time. So I forked it to modify it into the form I want.**

## Major Changes
1. Rebuilt the repo on Github (originally over 900 MB). Otherwise, just to change some code, one would have to download nearly 1GB of repo to their computer, which is daunting.
2. Removed ads.
3. Removed integration with Google Drive and Dropbox. Although this feature is very convenient, I prefer the input method to have no connection to the internet.
4. Removed a bunch of local libraries that I don't know why were imported in the first place. It seems to still work after removal, and the apk size shrank from the original 10MB to 3.9MB!
