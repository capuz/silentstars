DeepSeek Harness lightweight launcher. Pick a version, start DSH web.

> [!IMPORTANT]
> **DSH-X launches the official DeepSeek Harness Web page, not the desktop version.**
> It is only responsible for version installation, launching, and plugin management. It does not embed WebView, nor does it modify or remake DSH's web interface. DSH-X itself is a community open-source project and is not an official DeepSeek product.

## Features

- **Pick and use a version**: Launch / Stop / Restart / Update / Uninstall
- **macOS support**: Native `.app` and dmg installation packages (separate versions for Apple Silicon / Intel), auto-update, autostart on boot, and directory selection all use native system methods
- **Plugin page**: List installed plugins with one-click toggles, check and update plugins (individual / all), profile switching available here
- **Compatibility mode**: Automatically disable problematic plugins based on error messages on startup failure (one-click recovery available); self-check client plugin packages referenced on the page after startup, management page provides conclusions (distinguish instance issues from stale tabs)
