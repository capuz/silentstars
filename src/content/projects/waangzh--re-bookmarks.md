# ReMarks

**AI bookmark organization extension for Chrome / Edge that learns classification preferences**

Preview first, then confirm; automatically back up before organizing, leaving the final decision on bookmarks to you.

[Version Highlights](#-v170-版本亮点) · [Core Capabilities](#-核心能力) · [Preference Learning](#分类偏好无感学习) · [Installation](#-安装与体验) · [Usage Process](#-使用流程) · [Privacy and Permissions](#-隐私与权限) · [Local Development](#-本地开发) · [Roadmap](#-路线图)

## Why ReMarks

The more bookmarks you have, the higher the organization cost; directly handing over bulk moves to AI can be concerning.

ReMarks provides a controllable path between the two: it reads the browser bookmark tree, combines local rules, learned classification preferences, and OpenAI-compatible AI services to generate suggestions; you can first check the target folder, confidence level, and reasons, manually adjust the preview results, and only after confirmation will the bookmarks be moved. Each correction will also serve as a reference for future classifications, eliminating the need to manually maintain prompts.
