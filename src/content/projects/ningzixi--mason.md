## 📌 Overview

**Mason** is a desktop application built with Tauri 2 + Python (build123d) that converts Gerber ZIP files exported from JLCPCB into 3D-printable solder paste printing tools. It offers two working modes covering different scenarios from prototyping to small-batch…
