# MAS Lab

MAS Lab builds, runs, and tests multi-agent systems (MAS) from YAML files. A MAS
is a team of LLM agents with tools and a workflow that says who talks to whom.

It is for three audiences:

- **Developers** write agents, tools, and workflows as specs instead of glue code. Start with the [tutorials](https://github.com/ioc-project/mas-lab/blob/HEAD/docs/tutorials/index.md).
- **Enterprises** add policy, audit, and budget controls as overlays. Start with the [user guide](https://github.com/ioc-project/mas-lab/blob/HEAD/docs/user-guide.md).
- **Researchers** run repeatable experiments and compare designs. Start with the [paper labs](https://github.com/ioc-project/mas-lab/blob/HEAD/docs/paper/index.md).
