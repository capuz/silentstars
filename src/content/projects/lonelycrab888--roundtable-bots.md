# Bots Group Chat · roundtable-bots

**Simplified Chinese** · [English](https://github.com/lonelycrab888/roundtable-bots/blob/HEAD/README.en.md)

**Each Bot has a standard Agent one-on-one chat, shares group chat memory, and is coordinated by King Arthur.**

Chat, write, analyze, search, and process files with King Arthur in DeepSeek Harness. When collaboration is needed, ask it to create Bots, set up a group chat, and send messages. In the group chat, King Arthur has members speak according to their responsibilities, continues the discussion based on existing results, and summarizes the conclusions.

**Host requirement:** DeepSeek Harness `>=0.2.2-rc.2` (current verified baseline: rc.2) · Desktop / Web
