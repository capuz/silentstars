# Agent_Extensions

Cross-framework **Agent Skills** collection. The repository contains two types of things: General skills (`General_skills/`) are not tied to a framework, and any agent can mount the directory as a Skill; Hermes plugins (`hermes_plugins/`) are for the Hermes framework. Each one is self-contained, with scripts, templates, and documentation in their respective directories. After cloning, you can take whichever directory you need and use it independently.

> **DSH plugins are not in this repository**. DeepSeek Harness (DSH) plugins have all been split into independent repositories, you can install the independent repositories directly:
