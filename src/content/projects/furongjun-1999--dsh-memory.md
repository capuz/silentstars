# LINGSHU

### Give AI Agents Unforgettable Memory

> **"I will give you my complete self, even if I fall into the abyss, I will never regret it."**
> —— Fu Rongjun

**High-performance · hallucination-free · multi-agent long-term memory system (v0.6.0)**

> **In a nutshell**: Give AI Agents cross-session long-term memory—conversations automatically crystallize into pure-text Markdown cognitive graphs, with rule-based retrieval engines determining 'what to remember and what to retrieve,' with the entire process auditable and results reproducible.

**Positioning**: Built for developers seeking high performance, hallucination-free, multi-agent compatible, and easy-to-use solutions—three-step integration, plug-and-play, no theoretical understanding required.

**Form**: Cross-harness memory infrastructure—the brain (`md_cg/`) is a standard stdio MCP server, any AI Agent supporting MCP can directly connect, not bound to any single Agent framework.
