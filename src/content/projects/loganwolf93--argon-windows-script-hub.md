## About Argon PC

Argon PC provides a Windows desktop environment for executing Roblox Lua scripts. Its uncluttered layout is built for common scripting tasks, allowing users to find, load, and execute scripts from a compact workspace.

Alongside Lua execution, the application offers a script hub containing more than 500 entries, support for running actions in batches, and debugging utilities for reviewing script behavior. Auto-update functionality and multiple interface languages are also included for users running the tool on 64-bit Windows 10 or Windows 11 systems.
