# Portal

Based on [Portal](https://github.com/fuqiuluo/Portal) [@fuqiuluo](https://github.com/fuqiuluo)

Android location and environment simulation tool. Supports single-point location, route playback, and a floating joystick. Simulates GNSS/NMEA, WiFi/cell-tower environments, and sensors. Supports no-Root/Xposed/Native + Xposed modes.

## ✨ Highlights
- Supports no-Root/Xposed/Native + Xposed (Root required)
- Anti-detection / stack cleaning / fingerprint hiding
- GPS/Network/Fused simulation
- System/Google Fused fusion location channel (experimental)
- Reflection-based clearing of mock markers before submission
- Floating joystick, route planning and freehand drawing
- Location and scene management, JSON/GPX import/export
- GPS/BeiDou/GLONASS/Galileo/QZSS
- Same-source GnssStatus/NMEA generation and active delivery
- GGA/RMC/GSA/GSV/GST/ZDA
- WiFi/cell-tower environment collection, generation and playback (experimental)
- Gridded AP, fixed seed, RSSI path-loss model
- Import and playback of self-built WiFi fingerprint database (experimental)
- Per-app exclusion and fixed points
- libxposed API 102 native Hooker/Chain
- Native sensor extension (experimental)
- HIDL/AIDL sensor…
