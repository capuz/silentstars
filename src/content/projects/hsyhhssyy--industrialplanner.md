# Arknights Endfield Integrated Industrial Simulator

Arknights Endfield Industrial Planner is a browser-based tool for planning integrated industrial production lines, managing blueprints, and running simulations for Arknights: Endfield.

You can place machines, connect conveyor belts, configure logistics, run simulations, look up recipes, plan production chains, and save blueprints on the web without opening the game. Use it as a web-based production line sandbox, validator, and scratchpad.

## Online use

- International site: https://endfield.anonymous-test.top/
- Mainland China CDN: https://endfield.amiyabot.com/

The current version supports desktop, tablet, and landscape phone use. Portrait phone mode shows a rotation prompt. For complex editing, long simulations, or large-scale blueprint organization, desktop remains the most efficient option.

In compatible browsers, you can enable offline use and add the site to your desktop. Once offline resources are ready, the main features can be opened and used even without a network connection.
