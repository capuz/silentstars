Arknights Endfield Industrial Planner is a browser-based integrated industrial production line layout, blueprint management, and simulation tool for "Arknights: Endfield".

You can set up production lines, connect conveyor belts, manage logistics, run simulations, check recipes, plan production chains, and save blueprints on the web without opening the game, using it as a web-based production line practice field, validator, and draft board.

## Online Use

- International Site: https://endfield.anonymous-test.top/
- China Mainland CDN: https://endfield.amiyabot.com/

The current version supports desktop, tablet, and mobile landscape use. Mobile portrait mode will display a rotation prompt; for complex editing, long simulations, or large-scale blueprint organization, the desktop version remains the most efficient way to use it.

Compatible browsers can enable offline use and add to the desktop. Once offline resources are prepared, the main features can be opened and used even without an internet connection.
