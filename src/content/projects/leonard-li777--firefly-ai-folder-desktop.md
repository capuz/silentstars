## 🌟 Project Overview

**Firefly (萤核) Smart Folder** is an intelligent file management tool built on advanced AI technology. It integrates a local multimodal AI engine to provide automatic tagging and summarization, semantic-based intelligent batch renaming, multi-dimensional virtual directories, and file deduplication and cleanup, with 100% of data retained locally.

Unlike traditional file managers, Firefly brings AI's comprehension into the file system, so your files are no longer just cold data, but knowledge assets with semantics, quality scores, and multi-dimensional tags.
