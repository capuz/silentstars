# gentoo-zh

Overlay for Gentoo Users.\
gentoo-zh is an inclusive overlay.

## Community

For overlay-related questions, GitHub Issues is preferred.

## How to add this overlay to Gentoo Linux

```
eselect repository enable gentoo-zh
emaint sync
```

For mainland China mirror acceleration and overlay usage, please refer to: https://gentoozh.org/overlay
