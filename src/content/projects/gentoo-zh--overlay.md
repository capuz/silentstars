# gentoo-zh

Overlay for Gentoo Users.
gentoo-zh is an inclusive overlay.

> [!NOTE]
> The gentoo-zh overlay has migrated to https://github.com/gentoo-zh/overlay. The old GitHub URL will continue to redirect. If you have manually configured the remote, you can update it at your convenience.
> For details, see [MIGRATION.md](https://github.com/gentoo-zh/overlay/blob/HEAD/MIGRATION.md).

## Community

GitHub Issues should be used as the priority channel for overlay-related issues.

## How to Add This Overlay to Gentoo Linux

```
eselect repository enable gentoo-zh
emaint sync
```

For information about mainland China mirror acceleration and overlay usage, refer to: https://gentoozh.org/overlay

## distfiles and Binary Packages

Some packages provide distfiles and binary packages, with builds triggered nightly. For configuration and mirror information, refer to: https://distfiles.gentoozh.org
