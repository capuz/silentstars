# DevAgents

[English](https://github.com/ItlaStudent/DevAgents/blob/HEAD/README.en.md)

**DevAgents es un entorno de desarrollo con agentes (ADE), libre y gratuito, en beta.** La cabina gráfica es para Windows 10/11 de 64 bits; el motor, la CLI y el servidor MCP también funcionan en Linux. Puedes trabajar con un modelo en Directo o repartir una orden entre varios modelos en Orquestado y Colmena. Las capacidades y sus límites se detallan abajo.

> **Corte documental: 23-nov-2026.** El código es público bajo Apache-2.0; todavía no hay binarios ni instalador publicados: hoy se compila desde el código fuente. Hay un paquete instalable construido y probado en el equipo de desarrollo; falta el recorrido en una máquina limpia.
