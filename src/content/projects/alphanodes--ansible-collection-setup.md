# Ansible Collection - alphanodes.setup

## Description

This collection provides setup for:

- Linux operating systems:
  - Debian 13
  - Ubuntu 26.04

All provided roles do not use docker as container system.

## Minimum required Ansible-version

- Ansible >= 2.19.0
