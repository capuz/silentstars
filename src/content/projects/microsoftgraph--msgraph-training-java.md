# Build Java apps with the Microsoft Graph Java SDK - Completed project

This sample will introduce you to working with the Microsoft Graph SDK to access data in Microsoft 365 from Java applications. This code is the result of completing the [Java Microsoft Graph tutorial](https://learn.microsoft.com/graph/tutorials/java) and the [Java Microsoft Graph app-only tutorial](https://learn.microsoft.com/graph/tutorials/java-app-only).

## Running the sample

The code for the delegated user authentication sample is in the [user-auth](https://github.com/microsoftgraph/msgraph-training-java/blob/HEAD/user-auth) folder. Instructions to configure and run the sample can be found in the [README](https://github.com/microsoftgraph/msgraph-training-java/blob/HEAD/user-auth/README.md) in that folder.

The code for the app-only authentication sample is in the [app-auth](https://github.com/microsoftgraph/msgraph-training-java/blob/HEAD/app-auth) folder. Instructions to configure and run the sample can be found in the [README](https://github.com/microsoftgraph/msgraph-training-java/blob/HEAD/app-auth/README.md) in that folder.
