# Trending Hub 🔥

A multi-platform social media trending aggregation tool that supports X/Twitter, TikTok, Bilibili, YouTube, Instagram, Weibo, Zhihu, Baidu, Douyin, and other platforms.

## Features

- 🔄 **Automatically updates every 30 minutes** - Scheduled scraping via GitHub Actions
- 🌐 **Multi-platform support** - Covers major domestic and international social media
- 📱 **Responsive design** - Supports desktop and mobile
- 🆓 **Completely free** - Hosted on GitHub Pages
- 🔓 **Open source** - Customizable and extensible

## Supported Platforms
