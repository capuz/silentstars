# 📅 Schedule Plugin

## Introduction

**Schedule Plugin** is a schedule management plugin based on [Yunzai-Bot V3](https://github.com/TimeRainStarSky/Yunzai). It supports one-click import of schedules via ~~WakeUp schedule commands~~, Xinglink schedule commands, JSON files (supporting both the plugin's native format and export files from [ShiGuang Schedule](https://github.com/XingHeYuZhuan/shiguangschedule)), ICS files, and Wakeup backup files. It also provides practical features such as schedule query, viewing classmates' class status, schedule push subscription, schedule export, and quick schedule adjustment.

The plugin also includes a built-in birthday module that supports members setting their birthdays and automatically receiving birthday wishes. The birthday module supports per-group configuration, allowing you to freely control which groups can receive push notifications.

> 🚀 **Almost zero configuration, ready to use out of the box!**
