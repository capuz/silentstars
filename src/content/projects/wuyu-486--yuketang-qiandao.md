# Yuketang Assistant (Auto Sign-in + Auto Answering)

A GUI automation tool for Yuketang: automatically waits for classes, signs in to the classroom, listens for questions in real time and answers them automatically, and supports running multiple accounts at the same time.

> Core logic adapted from the Yuketang section of [timeflykai/lazytool](https://github.com/timeflykai/lazytool). For personal study and research only. Please follow your school's rules. Use at your own risk.

## Features

- **Auto-wait for class**: Checks every 30 seconds whether a class is in progress. When one is detected, it automatically signs in to the classroom. If sign-in fails, it keeps retrying on a backoff schedule and does not give up on that class.
- **Scheduled on/off**: Set start and stop listening times for each account (e.g., start at 20:30, stop at 22:30). They run automatically at the set times, and each account is scheduled independently.
- **Auto-answer**: Listens to classroom events in real time via websocket. After a question is pushed, it answers after a random delay of 3–5 seconds. Answers are generated by a large language model.
