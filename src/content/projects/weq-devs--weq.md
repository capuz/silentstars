**WeQ** is an independent NTQQ local database decryption, parsing, and export tool.

If you need to export and analyze **WeChat chat records**: [WeChatDataAnalysis](https://github.com/LifeArchiveProject/WeChatDataAnalysis) is a fairly good choice

Welcome to join the **QQ discussion group** to discuss and exchange ideas: [](https://qm.qq.com/q/ysMZoAcC1a)

---

## Core Features

- <details> <summary>Database key acquisition</summary> Obtains the database key by locally saving credentials, decrypting sent packets, offline computation (Android), and other methods<br> No need to restart QQ or log in in advance during this process. The project dynamically selects a scheme to obtain the key based on credential validity, <strong>so users do not need to do anything</strong> </details>
- <details> <summary>Offline viewing and editing of chat records</summary> This project is based on Electron and implements a highly faithful imitation of the QQ chat interface, <strong>for an authentic chat record viewing experience</strong> <br> This project supports parsing of almost all chat records, including <strong>private chats, group chats, official accounts, channel private chats, etc.</strong>…
