Team members join your in-progress Codex session from a browser and chat directly with the same AI coding agent.

## Quick start

Keep the official Codex Desktop app running on the sharer's Mac, then install:

```sh
brew tap SpaceCoder-Kafka/tap && brew install --cask SpaceCoder-Kafka/tap/codex-co2
```

1. Open Co², and select a conversation.
2. Generate an invitation and send it to your colleague privately.
3. Approve the colleague's join request. They can open the session in a browser. No installation is needed, and they don't need to log in to Codex.

The latest version of Codex Desktop must connect through the Co² bridge plugin. Click **"Install plugin"** in the top-right corner and confirm. Co² will connect automatically. If Co² has stopped waiting, click "Reconnect Codex" once.

Need a DMG or Windows version? Download it from [Releases](https://github.com/SpaceCoder-Kafka/codex-co2/releases/tag/v0.6.0). The installers have not been notarized yet, so macOS will ask you to confirm when you first open them.

**If Co² is useful to your team, please give it a ⭐ so more Codex users can find it.**
