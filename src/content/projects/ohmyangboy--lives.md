## Product overview

Lives is a tool built specifically for Live Photo collages, offering a native macOS desktop app and iOS mobile support:

- **macOS version (Lives Mac)**: **Fully open source and free**. A native macOS tool for converting videos into iPhone Live Photos. Freely clip segments from multiple MOV/MP4/M4V sources, adjust the Live duration from 1–15 seconds, control precisely with keyframes, sync to Apple Photos in one click, with 100% local processing throughout.
