# CrossLink Inter-Library Loan Platform

CrossLink project provides software services for the implementation of Inter-Library Loan (ILL) solutions. It was developed by Index Data, led by the IDS Project, and supported by the Institute of Museum and Library Services.

See individual components docs for details:

* [broker](https://github.com/indexdata/crosslink/blob/HEAD/broker/README.md): ISO18626 transaction broker
* [directory](https://github.com/indexdata/crosslink/blob/HEAD/directory/README.md): CrossLink directory service
* [illmock](https://github.com/indexdata/crosslink/blob/HEAD/illmock/README.md): ISO18626 and SRU mocking service
* [supply](https://github.com/indexdata/crosslink/blob/HEAD/supply/README.md): S3-backed document storage service

# Project goals and architecture

The CrossLink project improves the efficiency and reduces the cost of resource sharing by fostering interoperability between library systems, including facilitating cross-consortial lending. It focuses on promoting technology that allows libraries to engage in consortial resource sharing while maintaining flexible local ILL workflows.
