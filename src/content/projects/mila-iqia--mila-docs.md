# mila-docs

This is the repository of the offical Mila Cluster documentation.

The docs are generated with Properdocs, and are published on the Internet thanks to BuildTheDocs, GitHub Actions/Pages.

The official URL for the docs is https://docs.mila.quebec/

## Contribution and issues
Please feel free to reach out at [Mila support](https://mila-iqia.atlassian.net/servicedesk/customer/portal/5/group/13/create/39) in case your are facing any issue with the cluster, or to create a [Git issue](https://github.com/mila-iqia/mila-docs/issues/new) if you are facing a problem with this documentation.

Contributions are welcome through Pull Requests our team will validate. See [CONTRIBUTING.md](https://github.com/mila-iqia/mila-docs/blob/HEAD/CONTRIBUTING.md) for more details.
