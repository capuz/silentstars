Aira is an open-source HarmonyOS NEXT browser, with source code released under GPL-3.0. The same repository also includes a desktop sync extension and a single-owner service for self-hosted sync.

Browsing, bookmarks, history, downloads, filtering, scripts, and the home page can all be handled locally. Community does not depend on Aira's official cloud or a Huawei account; to sync across devices, use your own WebDAV or Personal Server.

## Features

### Browsing

- Native HarmonyOS NEXT client, supporting phones, tablets, and 2in1 devices.
- Multiple tabs, startup restore, background tab resource management, and automatic closing of tabs based on how long they have gone unused.
- Drag-to-reorder bottom toolbar; appearance, theme, app icon, and top immersive mode are adjustable.
- Custom home page, where you can write your own page; websites can also be installed as desktop apps.
- Large screens have keyboard shortcuts and two-column settings.

### Privacy and Security

- Private mode is stored separately from regular browsing data, can require identity verification on entry, and can blur private tab previews.
