# ACEmulator Core Server

Build status: [](https://github.com/ACEmulator/ACE/commits/master) [](https://ci.appveyor.com/project/LtRipley36706/ace/branch/master) [](https://hub.docker.com/r/acemulator/ace)

**ACEmulator is a custom, completely from-scratch open source server implementation for Asheron's Call built on C#**
 * MySQL and MariaDB are used as the database engine.
 * Latest client supported.
 * [](https://github.com/ACEmulator/ACE/blob/master/LICENSE)
