# Good Youth | LeetCode Check-in Group

## Disclaimer

This project is for study and exchange reference only and must not be used for any commercial purpose under any circumstances. The author accepts no responsibility for any accidents. ^\_^

## Purpose

- Daily report: Every hour at 50 minutes past, fetch each user's problem-solving records for the current day. Results are recorded under the [data/records directory](https://github.com/nice-people-frontend-community/nice-leetcode/blob/HEAD/data/records/).
- Weekly report: After the daily report is updated, the weekly report is automatically summarized. Results are recorded under the [data/weeks directory](https://github.com/nice-people-frontend-community/nice-leetcode/blob/HEAD/data/weeks/).
- First-class flights: Members who have left the group (“off-group flights”) depart on the 1st of each month. Passengers are members who did not check in during the previous month. After leaving, members may apply to rejoin the group.

Note: Because the API used can only return the 15 most recent AC records, problems may appear more than once. If a user repeatedly resubmits the same problems, the statistics may be incomplete~
