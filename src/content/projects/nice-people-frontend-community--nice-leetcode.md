# Nice Youth | LeetCode Check-in Group

## Disclaimer

This project is for learning and exchange reference only and must not be used for any commercial purpose under any circumstances. The author is not responsible for any unexpected consequences. ^\_^

## Purpose

- Daily report: At 50 minutes past every hour, the day's problem-solving records for each user are fetched and saved under the [data/records directory](https://github.com/nice-people-frontend-community/nice-leetcode/blob/HEAD/data/records/)
- Weekly report: After the daily report is updated, this week's weekly report is automatically summarized and saved under the [data/weeks directory](https://github.com/nice-people-frontend-community/nice-leetcode/blob/HEAD/data/weeks/)
- First-class cabin flights: Off-group flights depart on the 1st of each month. Passengers are members who did not check in last month. After leaving the group, they may reapply to join.

Note: The API used can only return the 15 most recent accepted (AC) submissions, so duplicate problems may appear. If a user repeatedly resubmits the same problems, statistics may be incomplete~
