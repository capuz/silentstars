# Hashflag Archive

Unofficial archive of twitter hashflag campaigns.

- Campaigns are stored in the [data/campaigns.json](https://github.com/ianmuchina/HashflagArchive/blob/HEAD/data/campaigns.json) file
- Hashtags are stored in the [data/hashtags.json](https://github.com/ianmuchina/HashflagArchive/blob/HEAD/data/hashtags.json) file
- Campaign images are downloaded to the [img](https://github.com/ianmuchina/HashflagArchive/blob/HEAD/img) folder
- Data is dowloaded and saved using the github action in [workflow.yml](https://github.com/ianmuchina/HashflagArchive/blob/HEAD/.github/workflows/workflow.yml)
