# Docling TS

TypeScript/JavaScript client for [docling-serve](https://github.com/docling-project/docling-serve) and interfaces for working with the JSON output format of [Docling](https://docling.ai).

## Docling Core

The [docling-core](https://github.com/docling-project/docling-ts/blob/HEAD/docling-core) package matches the type definitions and utility functions of the [docling-core](https://github.com/docling-project/docling-core) library.

## Docling Client

The [docling-client](https://github.com/docling-project/docling-ts/blob/HEAD/docling-client) package is the official TypeScript client
for Docling Serve and managed services implementing its API. It is modeled after
the official python client.
