# torne mobile HomeBrew Edition

An unofficial, independently developed client app for continuing to operate a nasne with official firmware from a smartphone, even after Sony's end of support. It supports iOS / Android / Mac / Windows / Linux.

## Current status

We have released v1.4.4. Distribution files (IPA / APK / Mac version / Windows version / Linux version) are available from GitHub Releases.

## Features

- nasne discovery and registration
- Retrieving information about the unit, HDD, tuners, etc.
