# Genshin University Alliance

Welcome to the Genshin University Alliance project! This project aims to collect and organize lists of Genshin-related universities from across the country (currently 314 universities, of which 81 are valid), providing a campus hub.

Non-university entities can also be added~

If you like this project, you can give it a star on [GitHub](https://github.com/cokice/List-of-genshin-University).
**This list prioritizes displaying valid domains; within each validity group, schools are sorted alphabetically by school name**
