# Genshin University Alliance

Welcome to the Genshin University Alliance project! This project aims to collect and organize lists of Genshin-related universities across China (currently 314 universities, 81 of which are valid), providing a campus hub.

Non-university entities can be added too~

If you like this project, please give it a star on [GitHub](https://github.com/cokice/List-of-genshin-University).
**This list displays valid domains first. Within each validity group, schools are sorted alphabetically by school name.**
