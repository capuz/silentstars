# Genshin University Alliance

Welcome to the Genshin University Alliance project! This project aims to collect and organize lists of Genshin-related universities from across the country (currently 314 universities, of which 81 are valid), providing a campus hub.

Non-university entries can also be added~

If you like this project, feel free to give it a star on [GitHub](https://github.com/cokice/List-of-genshin-University).
**This list displays valid domain names first, and within each validity group, entries are sorted alphabetically by school name.**
