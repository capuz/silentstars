# Genshin Impact University Alliance

Welcome to the Genshin Impact University Alliance project! This project aims to collect and organize lists of Genshin Impact-related universities across the country (currently 307 universities) (74 of which are active), providing a campus gathering place.

Non-university institutions can also be added~

If you like this project, please give it a star on [GitHub](https://github.com/cokice/List-of-genshin-University).
**This list prioritizes displaying valid domains, with schools within the same validity group sorted alphabetically by school name**
