# Genshin Impact University Alliance

Welcome to the Genshin Impact University Alliance project! This project aims to collect and organize a list of Genshin Impact-related universities across the country (currently 308 universities, of which 75 are valid), providing a campus gathering place.

Non-universities can also be added~

If you like this project, you can give it a star on [GitHub](https://github.com/cokice/List-of-genshin-University).
**This list prioritizes displaying valid domains, sorted alphabetically by school name within the same validity group**
