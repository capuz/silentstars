# Genshin Impact (原神) University Alliance

Welcome to the Genshin Impact University Alliance project! This project aims to collect and organize lists of Genshin-related universities from across the country (currently 314 universities, 81 of them valid), providing a campus hub.

Non-university entries can be added too~

If you like this project, please give it a star on [GitHub](https://github.com/cokice/List-of-genshin-University).
**This list prioritizes valid domains. Within each validity group, schools are sorted alphabetically by school name.**
