# Genshin Impact University Alliance

Welcome to the Genshin Impact University Alliance project! This project aims to collect and organize lists of Genshin Impact-related universities from across the country (currently 314 universities, 81 of which are valid), providing a campus hub.

Non-university entries can also be added~

If you like this project, please give it a star on [GitHub](https://github.com/cokice/List-of-genshin-University).
**This list displays valid domain names first. Within each validity group, schools are sorted alphabetically by school name.**
