# vxe-pc-ui

Simplified Chinese | [繁體中文](https://github.com/x-extends/vxe-pc-ui/blob/HEAD/README.zh-TW.md) | [English](https://github.com/x-extends/vxe-pc-ui/blob/HEAD/README.en.md) | [日本語](https://github.com/x-extends/vxe-pc-ui/blob/HEAD/README.ja-JP.md)  

A PC-side component library based on [vue](https://www.npmjs.com/package/vue)  

* Design philosophy
  * Designed for modern browsers, with an efficient and concise API design
  * On-demand loading

* Branch notes
  * The v3 and v4 branches keep features and APIs in sync with each other
  * The v3 branch corresponds to vue 2.6~2.7 and is a long-term maintained version
  * The v4 branch corresponds to vue 3.x and is a long-term maintained version

* Version notes
  * **V4**
    * [x] v4.7 is based on xe-utils@4.0+ and splits the [vxe-design](https://github.com/x-extends/vxe-design) visual components from the base component library
    * [x] v4.0 is based on vue 3.2~2.7 and only supports modern browsers, not IE
