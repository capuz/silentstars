Blue Big Fat Fish is an open archive of AI-girl fan-made sticker images. The site collects memes, illustrations, setting sheets, and comics, organized by character. It supports search by name, tag, and character alias. Each work has its own detail page that shows its source and license, and it provides a link to download the original image.

The interface supports Chinese, English, and Japanese.

## Project overview

| Item | Details |
| --- | --- |
| Frontend | Pure static site built with Astro |
| UI languages | Chinese, English, Japanese |
| Work types | Memes, illustrations, setting sheets, comics |
| Image source | Separate image archive repository |
| Submission methods | On-site, QQ group, GitHub Issue form |
