# DSH × HALOFLUX — Live-Linked Desktop Wallpaper

**Chinese** | [English](https://github.com/ACyCar1o/dsh-hud-haloflux/blob/HEAD/README.en.md)

Connects [HALOFLUX](https://github.com/Ryder191/haloflux) (a single-file Canvas sci-fi visualization) to the real session data of the local **DeepSeek Harness**:
the wheel's rotation speed, beam bursts, and panel numbers are all driven by real events, idling at a slow standby pace and bursting into action when working.

It also brings the status of the **local media player** (QQ Music / Spotify…) and **Codex / WorkBuddy / Claude Code / ChatGPT** into the same screen, and runs permanently as a desktop wallpaper via **Lively Wallpaper**.
