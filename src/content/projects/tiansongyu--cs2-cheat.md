# CS2 External ESP

An educational CS2 external ESP project based on SDL2, ImGui, and C++20. It includes a game overlay, a fixed-map Radar, and an optional public network sharing service.

**Chinese** | [English](https://github.com/tiansongyu/cs2_cheat/blob/HEAD/README_EN.md)

> [!WARNING]
> This project is intended only for learning reverse engineering and graphics rendering. It may only be run in an offline environment launched with `-insecure`. It is forbidden to use it on VAC servers or any online game. Users bear full responsibility for the risks of improper use.
