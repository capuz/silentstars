# SYR Connect - Home Assistant Integration

## Installation

### Home Assistant Community Store - [HACS](https://hacs.xyz/) (recommended)

1. Open HACS in Home Assistant
2. Go to "Integrations"
3. Search for "SYR Connect"
4. Click "Install"
5. Restart Home Assistant
