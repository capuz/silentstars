# Vibe Mathematics — Multi-Agent Math Problem Solving and Verification Framework (Four Architectures)

[English](https://github.com/ChongCyrus/Vibe-Mathematics/blob/HEAD/README.en.md) | Chinese

> A set of **agent presets** (`vibe-math-v2` / `vibe-math-v3` / `vibe-math-v4` / `vibe-math-v5`) running inside the **DeepSeek Harness**. They use multi-agent collaboration to solve math problems automatically and cross-verify conclusions with multiple agents. All four presets share the same foundation: **resumable runs**, **mid-run human intervention**, **progress reporting**, and **natural-language control**, but they use four generations of different solving architectures.
> **💡 v4/v5 first**: `vibe-math-v4` (the “resident self-organizing collaborative research” architecture) and `vibe-math-v5` (the latest “research institute system”) are the **current main maintenance direction**. `vibe-math-v2` and `vibe-math-v3` are **classic/early architectures** that have **matured and been finalized**, and going forward they receive only **compatibility maintenance** (new features go only into v4/v5).
