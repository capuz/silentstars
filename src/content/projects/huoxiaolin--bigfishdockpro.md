# BigFish Dock · BigFishDockpro

A desktop organization and beautification tool for **Windows 10 / 11 x64**. Launch apps with the Dock, organize files with cards, and check your computer status, AI usage, and schedule with the dynamic capsule. The Windows 11 Start menu, search, and notifications can also use the same glass look.

[Download releases](https://github.com/HuoXiaolin/BigFishDockpro/releases) · [User guide](https://github.com/HuoXiaolin/BigFishDockpro/blob/HEAD/使用说明.md) · [Changelog](https://github.com/HuoXiaolin/BigFishDockpro/blob/HEAD/CHANGELOG.md) · [Issue tracker](https://github.com/HuoXiaolin/BigFishDockpro/issues)

*Interface demos use original backgrounds and sample data. Glass panels use 90% opacity.*

## Download and Getting Started

| Version | How to use |
| --- | --- |
| Installer | Run `BigFishDockpro-Setup-x64.exe` and follow the setup wizard. |
| Portable single-file version | Place `BigFishDockpro.exe` in a fixed location and run it. Python does not need to be installed. |
