# Lophine

*Lophine is a fork based on Folia, with many useful optimizations and configurable vanilla features. Its goal is to bring more redstone content to Folia (note that full redstone builds should use Fabric).*

[English](https://github.com/LophineLabs/Lophine/blob/HEAD/README.en.md) | **Chinese (Simplified)** | [Chinese (Traditional)](https://github.com/LophineLabs/Lophine/blob/HEAD/README.zh-TW.md)

## ✨ Core Features

- **Configurable vanilla features** - Flexibly adjust game mechanics to suit different server needs
- **Tpsbar support** - Display real-time server TPS status
- **Folia bug fixes** - Targeted fixes for known Folia issues
- **Multiple world format support** - Supports the b_linear (linear re-implementation) world format
- **Enhanced redstone features** - Implements more redstone content…
