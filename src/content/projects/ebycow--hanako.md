# Hanako
General-purpose Discord Chat Text-to-Speech (TTS) Bot
Powerful SE features, compatible with any voice server, fast operation across multiple servers😼

# Usage
## Conversation with Hanako
You can use various features by entering commands to Hanako.
Commands can be entered in text channels as a reply in the format `@botname command-name`, or by saying `>command-name`.
Slash commands (/command-name) are also available. With slash commands, arguments are clearly specified and descriptions are displayed.
