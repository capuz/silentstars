# K.S.R.V. Njord App

De Flut-ter versie.

## How do I?

### ⚠️ This project uses FVM (Flutter Version Manager)

**First time setup:**

1. Install FVM: `dart pub global activate fvm`
3. Add `%LOCALAPPDATA%\Pub\Cache\bin` to your System Variable PATH
2. Install the project's Flutter version: `fvm install`

**Daily usage - Always use `fvm` prefix:**
```bash
fvm flutter run
fvm flutter pub get
```

> 📖 See [FVM_SETUP.md](https://github.com/ksrvnjord/app.main/blob/HEAD/FVM_SETUP.md) for detailed instructions

### Running the app

- Start an emulator or connect your phone
- Run: `fvm flutter run`

> For web: `fvm flutter run -d chrome --web-browser-flag "--disable-web-security"`
