## Quick start

[Download the Android APK](https://github.com/AieXile/AnimeTrack/releases/latest) and expand **Assets**. Your device must run **Android 8.0 (API 26) or later**.

| Package | Suitable devices |
| --- | --- |
| `-v8a.apk` | Most newer Android phones and tablets |
| `-v7a.apk` | 32-bit ARM devices |
| `-universal.apk` | Choose this if you are not sure of your device's architecture |

Open the APK and follow the system prompts to install. Users who already have the official GitHub release installed can upgrade over it directly.
