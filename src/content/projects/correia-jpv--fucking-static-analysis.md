This repository lists **static analysis tools** for all programming languages, build tools, config files and more. The focus is on tools which improve code quality such as linters and formatters.
The official website, 🌎 [analysis-tools.dev](https://github.com/Correia-jpv/fucking-static-analysis/blob/HEAD/analysis-tools.dev/) is based on this repository and adds rankings, user comments, and additional resources like videos for each tool.
