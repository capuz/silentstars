## Getting started

You'll need Node.js 20+, Bun 1.4+, a stable Rust toolchain, and Pi installed and signed in.

```bash
bun install
bun run tauri:dev     # development
bun run tauri:build   # package
```

See [`docs/ARCHITECTURE.md`](https://github.com/ErKeLost/Orbit/blob/HEAD/docs/ARCHITECTURE.md) for the layer boundaries, state ownership, and RPC routing, and [`docs/CAPABILITIES.md`](https://github.com/ErKeLost/Orbit/blob/HEAD/docs/CAPABILITIES.md) for the full feature set and its boundaries.
