# Memgraph AI Toolkit

Python packages for building AI applications with [Memgraph](https://memgraph.com/): agent memory, knowledge graphs, GraphRAG, and framework integrations.

Use the packages independently, or combine them to bring documents, databases, and agent activity into a graph.

[Documentation](https://memgraph.com/docs/ai-ecosystem) · [Examples](#choose-your-starting-point) · [Discord](https://discord.gg/memgraph) · [Issues](https://github.com/memgraph/ai-toolkit/issues)

## Choose your starting point

| I want to… | Start here |
|---|---|
| Give coding agents memory across sessions and tools | [Context Graph](https://github.com/memgraph/ai-toolkit/blob/HEAD/context-graph/) |
| Extract entities and relationships from documents | [unstructured2graph](https://github.com/memgraph/ai-toolkit/blob/HEAD/unstructured2graph/) |
| Query Memgraph in natural language or build a LangChain agent | [langchain-memgraph](https://github.com/memgraph/ai-toolkit/blob/HEAD/integrations/langchain-memgraph/) |
| Connect an MCP client to Memgraph | [mcp-memgraph](https://github.com/memgraph/ai-toolkit/blob/HEAD/integrations/mcp-memgraph/) |
