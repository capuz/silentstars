# HIMI Sync Watch

**HIMI — Cross-platform Emby Client**

Full-platform Emby media library client · Multiple playback engines · Danmaku · Synchronized group watching · TV mode

---

## Project Overview

HIMI is essentially a cross-platform **[Flutter](https://flutter.dev)** client for **[Emby](https://emby.media)**, covering Android / iOS / Windows / Android TV / HarmonyOS. Its core capability is a complete Emby media library experience: sign-in, browsing, search, favorites, episode selection, and multi-route playback, along with localized high-quality decoding (multiple playback engines, full-chain HDR, native bitmap subtitles/PGS, low-latency startup). Remote group sync watch rooms, danmaku, liquid glass UI, and similar features are only additional enhancements.

## Core Features

| Feature | Description |
|------|------|
| **Emby Media Library** | Sign-in, browsing, search, favorites, detail pages, episode selection, playback routes |
| **High-Quality Playback** | Three playback engines, full-chain HDR, native bitmap subtitles/PGS, low-latency startup |
| **Multi-User Sync Rooms** | Join via room code / QR code scan, playback controls synced for all members (optional feature) |…
