# HIMI Sync Watch

**HIMI — Cross-platform Emby Client**

Full-platform Emby media library client · Multiple playback engines · Danmaku · Synchronized group watching · TV mode

---

## Project Introduction

HIMI is essentially a cross-platform **[Flutter](https://flutter.dev)**-based **[Emby](https://emby.media)** client, covering Android / iOS / Windows / Android TV (HarmonyOS planned). Its core capability is a complete Emby media library experience: sign-in, browsing, search, favorites, detail pages, episode selection, multi-route playback, and high-quality local decoding (multiple playback engines, end-to-end HDR, native bitmap subtitles/PGS, low-latency startup). Remote synchronized group viewing rooms, danmaku, liquid glass UI, and similar features are only additional enhancements.
