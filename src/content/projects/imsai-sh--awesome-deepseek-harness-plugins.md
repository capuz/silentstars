# Awesome DeepSeek Harness Plugins

A community plugin directory for the [DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek-Harness) (`dsh`) ecosystem. It currently lists **14203** plugins, including those added through PRs and automatic discovery via the GitHub `dsh-plugin` topic. The directory data was last updated on 2026-11-23.

>
> **New open-source project: [Fish Pocket](https://github.com/imsai-sh/fish-pocket)**
>
> Run DeepSeek Harness on iPhone and iPad, and use it anywhere, anytime. Star the project to follow along, and join us in building it.

> 📦 **Repository split notice**: Since 2026-08-25, the source code for the deepseek1024.com website and the `dsh1024` CLI has been split into a separate repository, [imsai-sh/dsh-1024store](https://github.com/imsai-sh/dsh-1024store). This repository now focuses on the plugin directory (the awesome list) and the submission workflow. Issues and PRs related to the website or CLI should be filed in the new repository. Plugin submissions remain here.
