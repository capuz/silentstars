# Awesome DeepSeek Harness Plugins

A community plugin directory for the [DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek-Harness) (`dsh`) ecosystem. It currently lists **13902** plugins, including those added through PRs and automatic discovery of the GitHub `dsh-plugin` topic. The directory data was updated on 2026-10-29.

> 📦 **Repository split notice**: Since 2026-08-25, the source code for the deepseek1024.com website and the `dsh1024` CLI has been split into a separate repository, [imsai-sh/dsh-1024store](https://github.com/imsai-sh/dsh-1024store). This repository now focuses on the plugin directory (awesome list) and the submission workflow. Issues and PRs related to the website or CLI should be filed in the new repository. Plugin submissions continue to be made here.

**But this project is more than an awesome list.** It also includes an online plugin marketplace, a plugin that brings the marketplace into the `dsh` itself, and a free public query API. The application code is open source in the sister repository [dsh-1024store](https://github.com/imsai-sh/dsh-1024store).
