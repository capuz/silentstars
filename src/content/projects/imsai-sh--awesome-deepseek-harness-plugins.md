# Awesome DeepSeek Harness Plugins

A community plugin directory for the [DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek-Harness) (`dsh`) ecosystem. It currently lists **14086** plugins (including plugins added via PR and those automatically discovered through the GitHub `dsh-plugin` topic). The directory data was last updated on 2026-11-21.

> **Tip**
>
> **New open-source project: [Fish Pocket](https://github.com/imsai-sh/fish-pocket)**
>
> Runs DeepSeek Harness on iPhone and iPad, so you can use it anytime, anywhere. Star the project to follow along, and join us in building it.

> 📦 **Repository split notice**: Since 2026-08-25, the source code for the deepseek1024.com website and the `dsh1024` CLI has been split into a separate repository, [imsai-sh/dsh-1024store](https://github.com/imsai-sh/dsh-1024store). This repository now focuses solely on the plugin directory (awesome list) and the submission workflow. Issues and PRs related to the website or CLI should be filed in the new repository; plugin submissions continue to be made here.
