# Interslavic JS utilities

Libraries for working with [Interslavic](https://interslavic-language.org): its
morphology, its alphabets, and how close its words are to the Slavic languages
they were built from.

| Package | What it does |
|---|---|
| [`@interslavic/morphology`](https://github.com/medzuslovjansky/js-utils/blob/HEAD/packages/morphology) | inflection, derivation, POS detection; get paradigms and derived forms as CoNLL-U tokens |
| [`@interslavic/translit`](https://github.com/medzuslovjansky/js-utils/blob/HEAD/packages/translit) | Latin ⇄ Cyrillic ⇄ Glagolitic ⇄ IPA, addressed by BCP 47 codes |
| [`@interslavic/levenshtein`](https://github.com/medzuslovjansky/js-utils/blob/HEAD/packages/levenshtein) | how recognizable an Interslavic word is to a speaker of a given Slavic language |
| [`@interslavic/conllu`](https://github.com/medzuslovjansky/js-utils/blob/HEAD/packages/conllu) | the token type and UD features the others speak |
| [`@interslavic/stemmer`](https://github.com/medzuslovjansky/js-utils/blob/HEAD/packages/stemmer) | stemming and full-text search: one index key per word, whatever alphabet it was typed in |

Each package README has installation and examples.…
