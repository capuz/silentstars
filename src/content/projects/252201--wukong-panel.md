# Wukong Panel (Wukong Panel)

Wukong Panel is an autonomous VPS node console for individuals and small teams. Any panel can enable a central master to consolidate node lifecycle management, shared subscriptions, real-time rates, host status, and whole-machine traffic billing cycles for the local machine and 2–10 remote hosts in a single secure interface.

## Core Features

- **Central fleet and multi-machine management**: Any panel can manage the local machine and up to 10 remote VPS instances. Supports real-time network speed monitoring on cards, unified node scheduling, merged cross-machine subscriptions, and lossless smooth switching.
- **Lightweight probe with zero overhead**: VPS instances without a panel can independently install the minimal, stateless `wukong-probe` single binary to report resources and network quality. The central master automatically manages billing-cycle traffic quotas and expiration times, and counters resume accumulating without resetting after a restart.
