# GTL-Enhancedcore

Core mod dedicated to the GregTech Leisure Enhanced modpack. It extends industrial machines, storage bays, megastructures, automation tools, and integration with GTCEu / AE2 / JEI / Jade. It cannot run when installed on its own.

- Mod ID: `gtl_enhancedcore`
- Environment: Minecraft 1.20.1 / Forge 47.x / Java 21
- Current version: 5.2.8 (`gradle.properties` is authoritative)
- License: [LGPL-3.0](https://github.com/hongshaotimo/GTL-Enhancedcore/blob/HEAD/LICENSE)

## Main Features

- Large furnace, basic ore processing plant, four Plus factories, four IV factories, and a universal joint factory.
- Super pattern assembly isolated orders: cross-recipe queues, shared budgets, persistence of inventory/energy/outputs, and cancellation with material refund.
- Late-game megastructures such as the Stellar Constrained Fusion Reactor, Super-Structured Chemical Twister, Platinum-Group Refining Matrix, Dragon-Style Field-Constrained Breeding Core, Void-Constrained Mining Site, Neutron Control Factory, Star Core Stripping Device, Hot-Press Leaching Complex, Super Particle Collider, and Xuanxing Space Station.
- Wireless Charger (single-block machine), End Crystal Resonator,…
