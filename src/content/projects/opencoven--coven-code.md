# Coven Code

> 🎉 **The unified Coven CLI is here.** The supported way to use this engine is now the single `coven` CLI, which installs, pins, and manages it for you:
>
> ```bash
> npm install -g @opencoven/cli
> ```
>
> This repository is the **Coven engine** — `coven-code` **v0.9.2**. The unified `coven` CLI (`@opencoven/cli`) installs and checksum-verifies its pinned engine version, which may differ from this release. You no longer install `coven-code` from npm directly. See the [release notes](https://github.com/OpenCoven/coven/blob/main/docs/release-notes-unified-cli.md) and the [merge guide](https://github.com/OpenCoven/coven-code/blob/HEAD/docs/unification.md).

**Coven Code** is an open-source agentic coding TUI built in Rust. It is maintained by [OpenCoven](https://opencoven.ai) as a GPL-3.0 fork of [Claurst](https://github.com/Kuberwastaken/claurst) by Kuber Mehta.
