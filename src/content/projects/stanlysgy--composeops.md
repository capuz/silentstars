# ComposeOps

**轻量级 Docker Compose 运维面板，专为个人服务器设计**

Automatically discovers Compose projects and integrates service control, configuration editing, real-time logs, data volume backup, GitOps, an AI operations agent, and resource monitoring into a single web interface

[功能特性](#功能特性) • [快速开始](#快速开始) • [AI Operations Agent](#-ai-运维-agent) • [Security Model](#安全模型) • [English](https://github.com/StanlySGY/ComposeOps/blob/HEAD/README.en.md)

> **What it is**: A single-user operations panel for your own server. Docker Socket is equivalent to root. The interface is in Chinese (an English interface is planned).
> **What it is not**: It does not support multi-tenancy or team collaboration (use Portainer for multiple users). It is not a CI/CD platform and does not provide pipelines or unattended releases. Managed projects can manually pull source code and run Compose builds on the target node. See [GitOps and Source Deployment Guide](https://github.com/StanlySGY/ComposeOps/blob/HEAD/docs/public/USE_CASE_GITOPS.md) for details.
> **Positioning**: Among tools of this kind, ComposeOps differentiates itself with its **AI operations agent**.
