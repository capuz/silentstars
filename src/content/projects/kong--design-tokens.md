# design-tokens

This is a **pnpm monorepo** that publishes three independently-versioned packages for Kong UI design systems.

## Packages

| Package | Description | Version |
|---|---|---|
| [`@kong/design-tokens`](https://github.com/Kong/design-tokens/blob/HEAD/packages/design-tokens/README.md) | Konnect design tokens | [](https://www.npmjs.com/package/@kong/design-tokens) |
| [`@kong/stylelint-plugin-design-tokens`](https://github.com/Kong/design-tokens/blob/HEAD/packages/stylelint-plugin-design-tokens/README.md) | Stylelint plugin for Kong design token rules | [](https://www.npmjs.com/package/@kong/stylelint-plugin-design-tokens) |
| [`@kong/eslint-plugin-design-tokens`](https://github.com/Kong/design-tokens/blob/HEAD/packages/eslint-plugin-design-tokens/README.md) | ESLint plugin for Kong design token rules | [](https://www.npmjs.com/package/@kong/eslint-plugin-design-tokens) |

## Getting Started

Install dependencies from the repo root:

```sh
pnpm install
```
