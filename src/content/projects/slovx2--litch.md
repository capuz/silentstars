# Litch

**Simplified Chinese** | [English](https://github.com/slovx2/litch/blob/HEAD/README.en.md)

Litch aims to deliver a comfortable desktop client and remote connection experience.

- Direct SSH connection
- Mobile (Android) direct SSH to remote devices; works even when the desktop app is not running
- Built-in browser and Computer Use (macOS, Windows)
- When a desktop is connected, remote devices can use the desktop browser and Computer Use, and after your approval can also run commands and read/write files on this computer
- Session tree (spawn sub-sessions across harnesses, report back, and wake up) and scheduled tasks (run on the device on time, even when the desktop app is closed)
- Scan a QR code to bind a remote device already configured on the desktop to your phone, without setting up SSH keys on the phone
