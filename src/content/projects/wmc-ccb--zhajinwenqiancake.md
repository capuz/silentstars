# ZhaJinWenQianCake

[English](https://github.com/wmc-ccb/ZhaJinWenQianCake/blob/HEAD/README_EN.md) · Official site: <https://wmc-ccb.github.io/ZhaJinWenQianCake/>

**Self-developed local portrait retouching project**: portrait refinement engine + desktop application.
All code, model selection, and assets were implemented and curated from scratch. It contains no code, models, or assets from any third-party commercial product.

- Runs fully offline; photos never leave your machine
- Python (FastAPI) engine + ONNX inference + WebView2 desktop window
- Tone and color grading / portrait refinement / cutout and background replacement / object removal / batch processing / RAW / tethered shooting
- 11 headless regression suites + CI; [Security Policy](https://github.com/wmc-ccb/ZhaJinWenQianCake/blob/HEAD/SECURITY.md) ·
