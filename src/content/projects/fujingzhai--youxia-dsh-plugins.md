# youxia-dsh-plugins

A collection of [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH) plugins that I use personally and keep maintaining. Each plugin is installed and updated independently.

| Plugin | Current version | Purpose |
|---|---|---|
| [dsh-pi-mode](https://github.com/fujingzhai/youxia-dsh-plugins/blob/HEAD/dsh-pi-mode) | 0.4.3 | A streamlined core shared by Pi / Pi+ / Pi-IM, on-demand Office tools, low-frequency silent reminders, and an entry point to the official dsh-doc |
| [dsh-session-history](https://github.com/fujingzhai/youxia-dsh-plugins/blob/HEAD/dsh-session-history) | 0.1.0 | Local conversation history for each agent (Claude Code, Codex, Antigravity, Pi, DSH): deterministic cleanup and offline search, provided to all agents through one shared skill via a symlink |
| [dsh-session-fee](https://github.com/fujingzhai/youxia-dsh-plugins/blob/HEAD/dsh-session-fee) | 0.4.9 | Shows the session cost (including subagents) in the stats bar, converted at market token prices |
