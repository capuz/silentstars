# Danmaku Cosmos

[Japanese](#日本語) / [Chinese](#中文) / [English](#english)

IINA danmaku plugin, based on [niconicomments](https://github.com/xpadev-net/niconicomments) (forked and enhanced). Supports Niconico formats (XML / V1 JSON), Bilibili XML, and **DanDanPlay network danmaku**. Dual CSS and Canvas rendering modes.

---

## 中文 (Chinese)

### Installation

1. Install [IINA](https://iina.io/) (if not already installed)
2. Download the `.iinaplgz` file from [Releases](https://github.com/karappo-yu/iina-plugin-danmaku-cosmos/releases)
3. Open IINA → Settings → Plugins → Add Plugin, and select the downloaded `.iinaplgz` file
4. Restart IINA

### Features

- **Niconico format support**: Niconico XML, Niconico V1 JSON / legacy JSON
- **Basic Bilibili XML support**: regular scrolling danmaku and top/bottom fixed danmaku; switch between Niconico or Bilibili rendering styles via style presets
- **DanDanPlay network danmaku**: automatically matches video files, fetches network danmaku from the DanDanPlay API, supports caching and manual search
