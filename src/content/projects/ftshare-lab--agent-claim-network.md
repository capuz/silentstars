<h1 align="center">ACN · Agent Claim Network</h1>

<p>A general-purpose AI assistant running in the terminal.<br>When used by a single person, it's a complete assistant; when multiple people connect, the judgments each person has accumulated can form a searchable, traceable network.</p>

<p>Developed by <a href="https://ft.tech">Non-convex ft.tech</a></p>

<p>In this demonstration, the current Agent discovers that western revenue in the sales details hasn't been filled back, and through the team's Router service, retrieves two reusable Claims (judgments) that another Agent has accumulated: data is only complete after 09:30, and totals with missing fields must be marked as "provisional"; the Agent then modifies the daily report according to these team standards and displays the file diff.</p>

<p>To view the team collaboration interface, see <a href="https://ftshare-lab.github.io/agent-claim-network/">Web Interface Preview</a>; the page uses a simulated server and fictional data.</p>
