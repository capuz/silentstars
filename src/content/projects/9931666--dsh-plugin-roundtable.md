## In one sentence

> You only raise the topic. DeepSeek acts as moderator, brings up a ring of expert nodes on the topology diagram, organizes collaboration with arrowed connection lines, consolidates results through a convergence gateway, and hands the decision back to you when there is disagreement.

## Features

### Meeting organization
| Capability | Description |
| --- | --- |
| **Left moderator + right roundtable topology** | The session view adds a 'Roundtable' tab: moderator anchor on the left, ring of expert nodes on the right, convergence gateway in the center. Connection lines carry directional arrows, so the whole meeting is visualized throughout. |
| **Persistent sub-agent experts** | Each expert is an independent sub-agent that can be resumed. It joins the meeting carrying the *Global Collaboration Charter* (goals / role boundaries / collaboration protocol / safety red lines), and can be assigned models from different vendors. |
| **Visual connections** | Hover over a node and drag the '+' to draw a connection. Right-click a connection to switch between one-way and two-way channels, or delete it. Two-way channels have an arrow at each end. |
