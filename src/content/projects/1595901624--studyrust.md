# StudyRust Learning Diary Source Code

#### Introduction

Rust is a systems programming language focused on safety, especially concurrent safety, supporting multiple programming paradigms such as functional, imperative, and generics. Rust's syntax is similar to C++, but the designers aimed to provide better memory safety while ensuring performance. Rust was initially designed and created by Graydon Hoare at Mozilla Research, and was gradually improved with contributions from Dave Herman, Brendan Eich, and many others. The designers of Rust optimized the Rust language and Rust compiler based on the experience gained during the development of the Servo web browser layout engine. Rust aims to be a programming language that elegantly solves high concurrency and high safety system problems, suitable for large scenarios, that is, creating and maintaining boundaries that can keep large systems intact. This leads to its emphasis on safety, memory layout control, and concurrency. The performance of standard Rust is on par with that of standard C++.
