# GCMP - Extension supporting multiple domestic native large model providers

**[English](https://github.com/VicBilibily/GCMP/blob/HEAD/README.en.md)** | 中文

By integrating mainstream domestic native large model providers, we provide developers with a richer and more suitable AI programming assistant choice for local needs. Currently, it supports built-in native large model providers such as Zhizhu AI, MiniMax, Moonshot AI, DeepSeek, Alibaba Cloud Bailian, Kuaishou Wanqing, Volcano Ark, Tencent Cloud, Xiaomi MiMo, Baidu Qianfan, Jiyue Xingchen, Ant Bailing, Xunfei Xingchen, LongCat, and others. In addition, the extension plugin has adapted to support API-compatible models from OpenAI and Anthropic, allowing for custom integration of any third-party cloud service model that provides a compatible interface.

## 🚀 Quick Start

### 1. Install the Extension

Search for `GCMP` in the VS Code extension marketplace and install it, or use the extension identifier: [`vicanent.gcmp`](https://marketplace.visualstudio.com/items?itemName=vicanent.gcmp)

### 2. Start Using

1. Open the `GitHub Copilot Chat` panel in `VS Code`
