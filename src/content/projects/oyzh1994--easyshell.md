# EasyShell

[Chinese](https://github.com/oyzh1994/easyshell/blob/HEAD/README.md) | [English](https://github.com/oyzh1994/easyshell/blob/HEAD/README_EN.md)

A powerful, modern, cross-platform, multi-protocol client.

## Features

- **Multi-protocol support**: Supports connections via SSH, FTP, SFTP, Redis, Valkey, ZooKeeper, HTTP, serial port, VNC, Telnet, RLogin, S3, RDP, SMB, Webdav, Mysql, Mongodb, Mariadb, 达梦, PostgreSQL, SQLite, Mosh, local terminal, and other connection methods.
- **Connection management**: Add, edit, delete, import, and export connections.
- **Key management**: Generate, import, export, edit, and copy keys to hosts.
- **Snippet execution**: Save and run code snippets.
- **SSH emulated terminal**: SSH protocol connections, service monitoring, SFTP, Docker management, process management, service information viewing, configuration file editing, and more.
- **RLogin emulated terminal**: RLogin protocol connections.
- **Telnet emulated terminal**: Telnet protocol connections.
- **SerialPort emulated terminal**: SerialPort protocol connections.
- **S3 client**: S3 protocol connections and file management, including upload, download, rename, preview, edit, share…
