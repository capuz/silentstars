# Strata NEXUS — Local LLM Workbench (Deeply Customized Frontend Edition)

**Simplified Chinese** · [English](https://github.com/SuperWJ062/Strata-NEXUS/blob/HEAD/README.en.md)

  

**Current version v0.69** (2026-10-29) · For incremental changes, see the [Changelog](https://github.com/SuperWJ062/Strata-NEXUS/blob/HEAD/CHANGELOG.md)

A **deeply customized frontend edition** built on the upstream engine of [Niko1221/Strata](https://github.com/Niko1221/Strata). The engine capabilities are unchanged; the entire interface has been redone to turn local inference into a visible, adjustable, polished workbench.

## Interface Overview

**Control Overview** — generation speed / VRAM / model status / API request volume at a glance on one screen; resource overview refreshes in real time

**Smart Chat** — streaming output, Markdown rendering, collapsible thinking process, right-side parameter panel; the whole page locks the viewport so it doesn't jump

**Live Monitoring** — real-time GPU/VRAM/CPU/memory levels + service health self-check (health/status/metrics/slots)
