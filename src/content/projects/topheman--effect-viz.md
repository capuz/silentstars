# Effect runtime visualizer

This is a visualizer for Effect runtime.

It allows you to **visualize** the execution of Effect code in the browser, and **edit** the example programs.

You can **slow down** a program so that its sleeps stretch out, or **pause** it and **step** through it one event at a time.

This project is a learning project for me to understand the Effect runtime. My learning journey is documented in the [`workshop/`](https://github.com/topheman/effect-viz/blob/HEAD/workshop/) folder, with each phase covering different Effect concepts (lazy evaluation, fibers, scheduling, errors, scopes). Check out the [AGENTS.md](https://github.com/topheman/effect-viz/blob/HEAD/AGENTS.md) file for the AI approach.
