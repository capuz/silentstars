# AzurPilot — Azur Lane Automation Assistant Tool

  &nbsp;&nbsp;&nbsp;&nbsp;

## Project Introduction

AzurPilot is an automation assistant tool for Azur Lane, modified from AzurLaneAutoScript. It retains the core capabilities of the original project and, on that basis, integrates several forks, feature improvements, and experimental features. It controls Android emulators via ADB/uiautomator2 and automatically executes game tasks using screenshot recognition, image matching, and OCR. It supports the CN/EN/JP/TW servers.

> **Please note**: The code of this project is largely generated and assisted by AI and carries considerable uncertainty. Pull requests to correct it are welcome: [Pull Request](https://github.com/wess09/AzurPilot/pulls).

Visit the **[AzurPilot website](https://azurpilot.com/)** for more feature details, or go to the **[download page](https://azurpilot.com/download.html)** to get the latest version.
