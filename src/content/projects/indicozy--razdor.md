# Razdor

A small Rust prototype inspired by *Discord Times* ("Times of Discord", Aterdux, 2004): travel across the kingdom's map, hire a squad in towns, and fight turn-based tactical battles on a grid.

**All rights to the original code and graphics of Times of Discord belong to their authors — Nikolay and Denis (Aterdux Entertainment).**

**Website:** [indicozy.github.io/razdor](https://indicozy.github.io/razdor/) · **Trailer:** [youtu.be/p7g0yvwtEeM](https://youtu.be/p7g0yvwtEeM)

```sh
cargo run --release
cargo test          # game rules
```
