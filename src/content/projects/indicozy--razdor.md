# Razdor

A small Rust prototype inspired by *Discord Times* («Времена раздора», Aterdux, 2004). Travel across the kingdom map, recruit a squad in cities, and fight turn-based tactical battles on a grid-based field.

**All rights to the original code and graphics of «Времена раздора» belong to their authors, Nikolay and Denis (Aterdux Entertainment).**

**Website:** [indicozy.github.io/razdor](https://indicozy.github.io/razdor/) · **Trailer:** [youtu.be/p7g0yvwtEeM](https://youtu.be/p7g0yvwtEeM)

```sh
cargo run --release
cargo test          # game rules
```
