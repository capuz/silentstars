# Astarship

Sistema de gestión para la generación automática de itinerarios turísticos.

## Inicio rápido

Requiere [Docker](https://www.docker.com/), [uv](https://docs.astral.sh/uv/) y [pnpm](https://pnpm.io/).

```bash
docker compose up -d
cd frontend && pnpm install && pnpm dev
```
