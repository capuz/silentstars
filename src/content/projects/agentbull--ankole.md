# Ankole

**The open-source Digital HQ where people and AI Agents run company operations together**

[Website](https://ankole.agentbull.com/) · [Documentation](https://ankole.agentbull.com/en-US/docs/introduction/) · [Quick start](#quick-start) · [How it works](#how-it-works) · [Discussions](https://github.com/AgentBull/ankole/discussions)

**English** · [简体中文](https://github.com/AgentBull/ankole/blob/HEAD/README.zh-Hans.md) · [日本語](https://github.com/AgentBull/ankole/blob/HEAD/README.ja.md) · [한국어](https://github.com/AgentBull/ankole/blob/HEAD/README.ko.md)

Ankole is an open-source workspace (**Pod**) and multi-agent runtime for AI-native teams. In one browser workspace, people, each member's **Personal Assistant**, and specialist **AI Colleagues** share collaborative **Documents** and **Slides**, relational **Base** tables, on-demand **Applets** (with stateless cloud backends and deterministic **Applet Actions**), multiplayer **Pod Chat** with peer-to-peer Agent delegation, and **Meta Ankole** (**Company Brain**, shared **Skills**, and **`AGENTS.md` / `DESIGN.md`** contracts)—while unified **Connectors** link Slack, Lark/Feishu, Microsoft Teams, DingTalk, WeCom, GitHub, Linear,…
