# 5050 Localization Collection

- **Localization Authors:** Cokepoetry, Tsukimi-tori, qsefthuopq
- **Exclusive for 5050 Live Stream**
- **Follow the Live Stream:** [https://live.bilibili.com/5050](https://live.bilibili.com/5050)
- qsefthuopq Localization Collection [Bilibili Column](https://www.bilibili.com/read/readlist/rl673289) (Recorded)
- Tsukimi-tori Localization Collection [Release](https://github.com/5050ResearchCenter/5050-Localization-Collections/releases) (Recorded)

This repository is used to organize and maintain Simplified Chinese patches for games made by the **5050 Localization Group**, translation texts, auxiliary scripts, verification information, and installation instructions.

This project was established and maintained by fans of bilibili content creator **EdmundDZhang**. All localizations are released free of charge, driven by interest and passion, contributing for the love of it. This project has no official affiliation or authorization with game developers, publishers, or platforms.
