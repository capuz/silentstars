# PI agent 学习指南

A fresh-styled personal learning site based on a source-code breakdown of the open-source project **[Pi](https://github.com/earendil-works/pi)** (a production-grade AI Agent runtime foundation). It organizes core mechanisms such as the Agent Loop, tool pipeline, message system, event-driven design, context engineering, compression algorithms, and session trees into a ten-chapter, readable and verifiable guide written in Chinese.

## 🔗 在线阅读

**https://pistudy.com.cn**

The fully deployed site, with all pages pre-rendered as static HTML. Open and read; mobile-friendly.

## 功能亮点

- **Ten-chapter guide**: from the three-layer architecture to the Agent Loop, model calls, tool system, message system, event-driven design, context engineering, compression algorithms, and session management, broken down layer by layer
- **3 interview Q&A bubbles per chapter**: a "read with questions" opener at the start of each chapter, and floating "面试题 N" Q&A bubbles beside the matching paragraphs in the body, so you can self-test as you read
