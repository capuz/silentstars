# Minimal Ontology Engine Demo

This is a complete, runnable minimal ontology engine implementation, intended to help readers better understand the content of the WeChat Official Account article series 《工程师的本体论》 (*The Engineer's Ontology*).

The project is organized by phase:
- **phase1**: Core ontology engine (articles 5-7)
- **phase2**: Agent interaction layer (articles 8-11)
- **phase3**: Memory system (articles 12-17)
- **phase4**: Multi-Agent architecture (articles 18-23)
- **phase5**: Intent compilation and productionization (articles 24-29)
- **phase6**: Memory ontology kernel (articles 29-36)
- **phase7**: Memory-aware multi-agent systems (article 037)
- **phase8**: Harness + dual Agent (article 041)
- **article-062-supplier**: Article 062: Factory No. 7 replaces its supplier, with two business databases committed together
