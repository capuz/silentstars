# SHYXIN Skills

Personal Claude Code skill collection.

> Users in mainland China should follow "Domestic Installation" (pulls from Gitee, no VPN needed). Users outside China should follow "Overseas Installation" (GitHub + npx skills).

## Domestic Installation (no VPN needed, recommended)

This repository is mirrored to Gitee (`theshyxin/skills`). With [cn-skills-cli](https://github.com/SHYXIN/cn-skills-cli), it can be pulled from Gitee **without needing a VPN**. `cn-skills-cli` has built-in aliases: `SHYXIN/skills` and `mattpocock/skills` are automatically routed to the Gitee mirror (requires `cn-skills-cli >= 0.1.10`; `cn-skills update` requires `>= 0.1.15`).

> **Windows users, please go directly to "Method 1 · Manual Commands"**: pure npm + cn-skills commands that work in PowerShell / CMD / Git Bash, no bash required. The "one-click script" below is a bash script, only applicable to macOS / Linux / Windows with Git Bash installed.
