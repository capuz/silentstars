**Unified API gateway, billing platform, and operations console for multi-model services.**

## What is SnowAPI

SnowAPI is an all-in-one platform designed for AI model aggregation, distribution, and commercialization. It connects different upstream vendors behind a unified entry point, providing applications with common protocols such as OpenAI Chat Completions, OpenAI Responses, and Anthropic Messages. It simultaneously covers channel scheduling, model pricing, quota settlement, subscription benefits, access control, log auditing, and operations management.

The project includes a complete Go backend, React console, database models, protocol conversion layer, Docker builds, and production deployment examples. It can be used for personal model gateways, team-shared services, or user-facing API platforms.
