# 🤖 Nav Copilot Customizations

Agenter, instruksjoner, skills og MCP-servere som gjør GitHub Copilot smartere for Navs stack. Alt samlet i én verktøyskatalog.

## Hva er dette?

En samling Copilot-tilpasninger for Nav-økosystemet:

- **🤖 [10 Agenter](https://github.com/navikt/copilot/blob/HEAD/docs/README.agents.md)** — Spesialiserte KI-assistenter for Nav-domener
- **📋 [16 Instruksjoner](https://github.com/navikt/copilot/blob/HEAD/docs/README.instructions.md)** — Kodestandarder som aktiveres automatisk basert på filmønster
- **⚡ [7 Prompts](https://github.com/navikt/copilot/blob/HEAD/docs/README.prompts.md)** — Scaffolding-maler for vanlige Nav-mønstre
- **🎯 [35 Skills](https://github.com/navikt/copilot/blob/HEAD/docs/README.skills.md)** — Produksjonsmønstre fra ekte Nav-repoer
- **🔌 [MCP-servere](https://github.com/navikt/copilot/blob/HEAD/docs/README.mcp.md)** — Nav-godkjente MCP-servere fra registeret

Alle tilpasninger finnes på **[verktøysida](https://ki-utvikling.nav.no/verktoy)** med søk, filtrering og installeringshjelp.
