# DataPressr 🍇 ➛ 🍷

Creating datasets and data stories fast with AI

And then publishing them to DataHub.

Turn raw data into something polished.

Start a new agent session with “Read NEXT.md and follow it.” The [session prompt](https://github.com/datasets/datapressr/blob/HEAD/NEXT.md) selects work from `bd ready`; the [handoff protocol](https://github.com/datasets/datapressr/blob/HEAD/docs/next-session-brief.md) provides execution details and the [migration audit](https://github.com/datasets/datapressr/blob/HEAD/docs/next-audit.md) records completed work and the Beads plan.

Built by [Rufus Pollock](https://rufuspollock.com) and [Datopian](https://datopian.com), drawing on more than 20 years of data wrangling and open data experience.

The DataPressr skills, code and accompanying documentation are open source under the [MIT licence](https://github.com/datasets/datapressr/blob/HEAD/LICENSE). Datasets and archived source material retain their own licences, recorded in each dataset’s metadata.
