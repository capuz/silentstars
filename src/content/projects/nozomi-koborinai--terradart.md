# TerraDart

> **Type-safe IaC for Dart.**
>
> Cloud infrastructure as real Dart code — typed, refactor-safe, drop-in for `terraform apply`.

**Alpha** — no SemVer until v1.0.0, but breaking changes land only on **minor** bumps. Pin `^0.30.x`, read [`MIGRATING.md`](https://github.com/nozomi-koborinai/terradart/blob/HEAD/MIGRATING.md) before minor bumps, and see [status on terradart.dev](https://terradart.dev/docs/status/).
