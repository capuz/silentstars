# Codey

Codey is an enhancement launcher for the Codex desktop client, centrally managing model routes, accounts, sessions, and extensions, and providing usage analytics and task notifications.

## Key Features

- Routes and Models: Manage official and third-party routes, configure proxies, sync available models for accounts, drag to adjust route and model order, switch models and thinking intensity in tasks; when local routing is enabled, exhausted official quota will not prevent switching to third-party routes.
- Official Accounts: Manage multiple ChatGPT accounts, customize gateway addresses, view quota and reset time separately, and switch between accounts in the same conversation.
- Requests and Usage: Query request latency, tokens and errors, analyze usage trends, model proportion and cost estimation.
- Session Management: View task status, import and export sessions, delete specific turns and restore backups.
- Extension Management: Manage MCP, Skill and trusted Codey plugins, support configuration, enable/disable, import/export and plugin log viewing and cleaning.
