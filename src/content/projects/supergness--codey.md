## Main Features

### Centralized management in the console

| Feature | What it can do |
| :--- | :--- |
| **Model routes** | Manage official and third-party routes, and switch models, reasoning intensity, and speed tiers within conversations. |
| **Official accounts** | Manage multiple ChatGPT accounts and their quotas, and enable Sign in with ChatGPT direct official authorization as needed. |
| **Usage analytics** | Query request records and analyze model usage, output speed, and errors. |
| **Session management** | Import and export sessions, delete specific turns, and restore from backups. |
| **Extension management** | Centrally manage MCP, Skills, trusted Codey native plugins, and Codex plugin marketplace resources. |
| **Task notifications** | Receive completion, failure, and waiting-for-intervention notifications via Feishu, WeCom, Telegram, ntfy, or WeChat ClawBot. |
| **Diagnostics and updates** | Check and fix configuration issues, disable automatic checks as needed, or choose stable or experimental updates. |
