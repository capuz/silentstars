# Mattermost Helm Charts [](https://github.com/mattermost/mattermost-helm/actions/workflows/release.yml)

This repository collects a set of [Helm](https://helm.sh) charts curated by [Mattermost](https://www.mattermost.com).

## Charts

If you are looking to deploy Mattermost, start with the official Mattermost Operator helm chart:

- [mattermost-operator](https://github.com/mattermost/mattermost-helm/blob/HEAD/charts/mattermost-operator/)

Other charts are provided which support or extend existing deployments:

- [mattermost-rtcd](https://github.com/mattermost/mattermost-helm/blob/HEAD/charts/mattermost-rtcd/)
- [mattermost-calls-offloader](https://github.com/mattermost/mattermost-helm/blob/HEAD/charts/mattermost-calls-offloader/)
- [mattermost-push-proxy](https://github.com/mattermost/mattermost-helm/blob/HEAD/charts/mattermost-push-proxy/)
- [mattermost-chaos-engine](https://github.com/mattermost/mattermost-helm/blob/HEAD/charts/mattermost-chaos-engine/)
- [focalboard](https://github.com/mattermost/mattermost-helm/blob/HEAD/charts/focalboard/)
