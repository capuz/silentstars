# Meta2Cloud

An automatic media library organizer for cloud drives, designed to work with players such as Infuse and NetEase Popcorn.



## Why use this?

**Get a well-scraped media library experience without a media server.**

If you:
- store movies and TV shows on a cloud drive
- don't want to set up a Plex/Emby/Jellyfin server
- watch by connecting players like Infuse or NetEase Popcorn directly to your cloud drive

Then Meta2Cloud can help you:
- automatically recognize filenames and organize them into a standard directory structure
- automatically query TMDB and generate NFO files
- automatically download posters and backdrop images
- let Infuse/NetEase Popcorn read the files and directly display posters, synopses, and cast information
