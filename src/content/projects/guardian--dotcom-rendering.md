# DCAR: Dotcom & Apps Rendering

This repository contains the rendering logic for theguardian.com and content in the live apps.

## Run

Go to [dotcom rendering](https://github.com/guardian/dotcom-rendering/blob/HEAD/dotcom-rendering/README.md) for more details.

## Root actions

Most commands are run from within the dotcom-rendering project but the following can be run from the root:

### Storybook

`pnpm storybook` - Runs Storybook for all projects
`pnpm build-storybook` - Builds Storybook for all projects
