## About 书屿

I like keeping novels stored locally, but the files keep piling up and become harder to organize. Later I came across [Wenku8_Flutter](https://github.com/mikufoxxx/Wenku8_Flutter), which I really liked, so I modified it and built 「书屿」 (Shuyu), which better fits my own needs.

Compared with the original version it is based on, 书屿 removes account login, the cloud bookshelf, daily check-in, book review replies, and legacy record import. The home page is changed to a local library. It adds and improves TXT／PDF／EPUB import, automatic scanning, tag organization, random reading, file renaming and deletion, reading progress, and backup and restore.

I am sharing it in the hope that it helps others who also like collecting novel files. This is my first software project, so there are bound to be shortcomings. Please bear with me, and feedback on issues and suggestions is welcome.

Thanks to the original author and all contributors. The original project's copyright and open-source license notices are retained.
