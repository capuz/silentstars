# NekoCode

---

NekoCode is an open-source **AI programming workbench**. You can describe what you need directly, and it will read the project, modify code, run commands, and verify the results. Larger tasks can be handed to multiple sub-agents that proceed in parallel, and the process, usage, and file changes can all be viewed.

Daily use starts with a terminal program and a model configuration. When you need more capability, you can gradually add Skill, Plugin, MCP, and Hook, or connect the same Agent foundation to an editor, IM, or your own application.

## Why it's good to use

### Smooth interaction, clear process

The TUI supports streaming responses, Markdown display, command completion, and menu selection. Running status, tool activity, file changes, and task progress are shown in one place, and approvals and questions are handled in the current interface. When you scroll up to read history, your position is preserved; press `End` to return to the latest content. When you need to change direction, you can interrupt or add instructions while it's running.

Press `Ctrl+G` or type `/tasks` to open the sub-task center, where you can view execution status, historical rounds,…
