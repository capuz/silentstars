# OW Bridge

Cross-platform tray application that provides free models for WorkBuddy through isolated OpenCode. Uses Electron for shared UI and existing Node.js proxy core.

> **Windows x64 portable version has been verified on actual Windows hardware; v0.2.3 portable package is recommended. macOS (Apple Silicon) version also has actual usage verification. Windows ARM64 and Linux have not been formally tested and cannot reuse x64 verification conclusions.**

## Interface Preview

Screenshots are from actual macOS runtime interface; model list, free quota, and detection results may change with upstream updates.
