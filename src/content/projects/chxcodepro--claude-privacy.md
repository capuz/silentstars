# Claude Privacy Gate

A SukiSU Ultra module and LSPosed hook for Claude Android and Claude Duet. It provides public IPv4 launch verification, in-app privacy decoy configuration, and local diagnostic logs. The settings UI follows the system light/dark theme.

**Supports `com.anthropic.claude` and `com.anthropic.aibo`** · Static APK interface checks completed for Claude **1.261113.19 / 1.261117.19 / 1.261120.19 / 1.261124.19** and Claude Duet **1.261125.9**.

[Download ZIP](https://github.com/chxcodepro/claude-privacy/releases) · [Changelog](https://github.com/chxcodepro/claude-privacy/blob/HEAD/CHANGELOG.zh.md) · [Issues](https://github.com/chxcodepro/claude-privacy/issues)

> **Warning**
>
> This is a development build. Guard recovery anomalies still need on-site logs to locate, and the log-saving process on the target phone has not yet been verified. Some capture interception may affect login, card binding, voice, or push notifications. Keeping a backup of your original configuration is recommended.
