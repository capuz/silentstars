# ProtVista

A Web Component which uses [Nightingale](https://github.com/ebi-webcomponents/nightingale) components to display protein sequence information.

> **v5 is the stable release.** **`5.0.0`** is on npm `latest`: install it with `npm install protvista-uniprot`, or load it from `https://cdn.jsdelivr.net/npm/protvista-uniprot@5.0.0/dist/protvista-uniprot.mjs`. v5 is a breaking change from 4.x; see [CHANGELOG.md](https://github.com/ebi-webcomponents/protvista/blob/HEAD/CHANGELOG.md) before upgrading.
