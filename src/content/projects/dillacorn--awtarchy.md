# `awtarchy-shell`

#### [Installation guide](https://github.com/dillacorn/awtarchy/blob/HEAD/INSTALL.md) · [Updating guide](https://github.com/dillacorn/awtarchy/blob/HEAD/UPDATING.md) · [Releases](https://github.com/dillacorn/awtarchy/releases)

---

pronounced: **aw-tar-chee**

**awtarchy** is not a Linux distribution. It is an overlay environment for **Arch Linux and CachyOS**, maintaining three Wayland compositors: **Umbriel, Sway, and Hyprland**. Awtarchy does not designate a preferred default compositor.

## Install model

1. Install vanilla Arch Linux with `archinstall` (Minimal profile recommended), manually install Arch, or install CachyOS.
2. Apply the Awtarchy overlay on top of the working base system.

For the current commands and install behavior, use the [Installation guide](https://github.com/dillacorn/awtarchy/blob/HEAD/INSTALL.md). Existing users should use the [Updating guide](https://github.com/dillacorn/awtarchy/blob/HEAD/UPDATING.md).
