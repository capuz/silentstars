# NorthPlus-MD3

A browser extension (Manifest V3) that gives the North+ forum a **Material Design 3** interface, along with a number of usability improvements.

## Features

**Appearance**
- MD3 interface: one-click toggle; turning it off restores the forum's original styles
- Color scheme: follow system / light / dark
- Seed color: 7 preset colors or a custom color picker; generates a full palette following Material 3 tonal spot rules
- Post page: the editor toolbar and editing area are combined into a single card; the WYSIWYG editing area and the post preview page adapt to dark mode and the seed color

**Layout**
- Wide-screen adaptation: removes large blank margins on both sides; maximum content width is adjustable (1000px ~ full width)
- Compact header: hides the large logo banner; the navigation bar stays pinned to the top
- Collapsed section announcements: long announcements are collapsed by default, and the expanded state is remembered per section
- Responsive layout that also works on narrow screens
