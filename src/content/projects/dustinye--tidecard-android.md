# TideCard / TideCard Android

[Download installer](https://github.com/DustinYe/TideCard-Android/releases/latest) · [Open source licenses and sources](https://github.com/DustinYe/TideCard-Android/blob/HEAD/THIRD_PARTY.md) · [Pre-publication review records](https://github.com/DustinYe/TideCard-Android/blob/HEAD/docs/PUBLICATION_REVIEW.md)

The current official Android release is **2.4.3**, which adds "Clear old region configuration". After background activation, it can be accessed from the main screen or Settings. Select a SIM slot, check the restore target, then confirm the clearing. It supports abnormal, partial, and persistent region/carrier name overrides. Processing stops if other fields are present, the original configuration cannot be verified, or a TideCard restore backup exists. For full steps and limitations, see [Old configuration cleanup](https://github.com/DustinYe/TideCard-Android/blob/HEAD/docs/CARRIER_CLEANUP.md). It retains 2.4.2's in-notification manual pairing, three languages, light and dark appearance, the region dial, and in-app updates.
