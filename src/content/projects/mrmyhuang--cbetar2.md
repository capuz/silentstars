# CBETA 電子佛典閱讀器 2 (非官方)

## <a id='feature'>特色</a>

Table of contents search, full-text search, bookmarks, URL sharing, offline browsing, text-to-speech playback, Buddhist dictionary, theme switching, sutra tabs, font adjustment, Kaishu (regular script) font, vertical text, printing sutras / copying-scripture booklets, online/offline DB support, cross-platform, ad-free, open source.

## 說明

CBETA 電子佛典閱讀器 2 (非官方) (Chinese Buddhist Electronic Text Association Reader 2), abbreviated cbetar2. It accesses electronic Buddhist scriptures using the CBETA API online or offline CBETA sutra files, and supports the following features:

* <a id='search'>搜尋、瀏覽(線上查詢)</a>
  1. Search the catalog: On the catalog page, press the magnifying glass icon at the top right. Enter part (or all) of a sutra title in the dialog, then press "搜索目錄" (Search catalog) to list related sutras.

  2. Full-text search: Similar to "Search catalog", but in the dialog you can enter a passage from within a volume of a sutra, such as "大水忽起卒至無期" (a sample passage).

  3. Search within a sutra.
