# Unitrad UI

Reactで構築された蔵書検索のための汎用的なユーザーインターフェース。

## 主な特徴

- シンプルで実用的なユーザーインターフェース
- ソートやフィルタのクライアントサイド実装
- 検索結果へのパーマリンク対応
- ウェブアクセシビリティ対応

## ビルド

```bash
npm install
npm run release
```

開発用のビルド＆プレビューサーバーは `npm start`。

## ロードマップ

- ドキュメントの充実
- Unitrad API以外への対応（OpenSearchなど）
