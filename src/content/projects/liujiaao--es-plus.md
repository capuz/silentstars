# ES-Plus

Make AI-generated CRUD pages **directly mergeable into a codebase**: the LLM writes only one JSON config, and ES-Plus handles Schema validation and deterministic compilation to produce **Vue 3 + Element Plus / Vue 2 + Element UI / Vue 3 + Ant Design Vue**, three runnable code sets from the same config, consistent across all three and reproducible.
