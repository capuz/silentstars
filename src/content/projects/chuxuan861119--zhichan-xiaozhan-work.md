# 知产小栈 Work · 中国专利撰写与文档管理工作台

**把专利文稿、附图和常用撰写工具，放在一个本地工作台里。**

[品牌官网](https://zcxzz.cn/) · [Work 产品与官方下载](https://zcxzz.cn/work/) · [使用手册](https://github.com/chuxuan861119/zhichan-xiaozhan-work/blob/HEAD/docs/official-user-guide.md)

知产小栈 Work 是面向中国专利撰写场景的桌面软件，支持发明专利、实用新型专利和外观设计专利。可以在本地管理案件，编写专利五书、制作附图和二维 CAD 标注，也可以整理外观设计图片、编写简要说明并导出材料。

适合专利代理师、专利工程师、科研人员，以及需要整理技术方案和专利文稿的个人与团队。核心撰写与资料管理功能在本地运行，无需注册账号即可使用；AI 服务、更新检查等联网功能按各自配置使用。

*工作台概览。本文图片展示软件实际界面中的示例资料；点击图片可查看原图。*

## 当前开源版本

- **发行版**：[v1.1.8](https://github.com/chuxuan861119/zhichan-xiaozhan-work/releases/tag/v1.1.8)。
- **当前源码**：默认分支包含外观设计专利工作台、小栈修图以及六视图整理和申报材料导出。以下功能介绍以当前源码为准。
- **开源许可：GPL-3.0。** 个人与企业均可依许可证使用、研究、修改和再分发。

## 适合哪些工作

| 使用场景 | 可以怎样使用 Work |
| --- | --- |
| 专利代理师、专利工程师撰写案件 | 集中管理多件专利，对照五书，减少编号、格式、附图处理和交付整理的重复操作 |
| 企业研发人员整理技术方案 | 把技术说明、结构附图、公式和参考资料归集到同一件专利中，持续补充和修改 |
| 科研人员整理发明与实验材料 | 编排技术文本、参数表、数学公式、化学结构式和流程图 |
| 个人学习专利撰写 | 通过示例和教程理解权项、说明书、附图及标记之间的关系 |
| 开发者研究桌面编辑工具 | 阅读文档模型、编辑器、图形工作区、规则检查及 Agent CLI 等实现，按 GPL-3.0 参与改进 |
