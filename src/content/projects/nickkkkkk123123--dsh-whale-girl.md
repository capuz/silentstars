# dsh-whale-girl

**Whale Girl·Dynamic Widget** — A DSH desktop widget that can be cute, keep accounts, and bounce.

> ✅ Listed in [dsh-market Creative Workshop](https://dsh-market.com/) (community plugin index), can be installed directly by searching "Whale Girl / 鲸鱼娘" within DSH.

Display a whale girl in the bottom-right corner of DSH Desktop, showing DeepSeek balance, usage, and context occupancy in real-time, supporting dragging, flinging and bouncing, middle-click slingshot flinging, easter egg bubbles, and right-click menu.

## Features

- 🖼️ **Whale Girl Illustration** — Image embedded in the script (quantized and compressed to 46KB), no network dependency, displayable in any environment
- 💰 **Balance / Usage** — Real-time display of DeepSeek balance, today's usage, last conversation consumption; automatic bubble alerts when balance falls below warning threshold
- 📊 **Context Usage** — Progress bar showing current session context usage (aligned with DSH display), active reminders when ≥90% to start a new session
- ⏱ **Peak-Valley Reminder** — Determines whether the current time period is a high-peak or low-valley usage period
