# Punchi Dock Remastered

[English](https://github.com/PunchiSoft/punchi-dock-remastered/blob/HEAD/README.md) | [Español](https://github.com/PunchiSoft/punchi-dock-remastered/blob/HEAD/README.es.md) | [Deutsch](https://github.com/PunchiSoft/punchi-dock-remastered/blob/HEAD/README.de.md) | [Português (Brasil)](https://github.com/PunchiSoft/punchi-dock-remastered/blob/HEAD/README.pt_BR.md)

> [!WARNING]
> **The published 0.9.7.74 package does not support Plasma 6.8; building from source does.** The Plasma 6.8 fix landed in 0.9.7.77 and has been validated on Plasma 6.8. Packages built before it may fail to load or lose functionality. Until the next release is published, install from source with `scripts-user/setup.sh --install`.

Punchi Dock Remastered brings application launchers, running windows, folders,
media controls, and desktop utilities together in a customizable dock for KDE
Plasma 6. Use it as a floating dock or inside a Plasma panel, horizontally or
vertically, with the active Plasma theme or a custom background.

It includes PunchiMenu for finding and organizing applications and is a modular
rewrite of the original Punchi Dock Plasmoid.
