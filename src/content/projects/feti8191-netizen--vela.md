# Vela

**Vela** is an interpreted general-purpose language with its own syntax — not a Python clone.  
You write `.vel` files and run them with the Vela interpreter (or use the REPL).

```bash
make
./vela                         # REPL
./vela examples/01_hello.vel   # run a file
```

**Learn the language in depth:** see **[TUTORIAL.md](https://github.com/feti8191-netizen/Vela/blob/HEAD/TUTORIAL.md)** — full tutorial (tokens, bindings, control flow, functions, collections, modules, errors, records, **visual art**, builtins, std, REPL, common mistakes).
