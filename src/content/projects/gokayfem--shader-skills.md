# Shader Skills — GLSL & Shadertoy for AI coding agents

Shader Skills helps coding agents write, debug and optimize procedural GLSL for Shadertoy and WebGL2. Start with an editable scene, change the lighting or geometry, and bundle it into a single shader. The skill includes **196 GLSL functions across 21 modules**, a dependency bundler and a checker. It works with Claude Code, Codex, Cursor, GitHub Copilot and Gemini CLI.

The full repository includes **25 interactive shader studies** and **two WebGPU worlds**. Use the studies to isolate an effect, then explore how a swimmable kelp forest or a streamed landscape handles visibility, lighting and frame time. [Offline shader viewer](https://github.com/gokayfem/shader-skills/blob/HEAD/gallery/studies.html) · [WebGPU worlds](https://github.com/gokayfem/shader-skills/blob/HEAD/worlds/README.md) · [Performance guide](https://github.com/gokayfem/shader-skills/blob/HEAD/skills/shader-art-coding/references/frame-budgets.md)
