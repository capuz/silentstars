# Acorn 🌰

**Parallel AI coding agent sessions in one window — split panes, isolated git worktrees, native PTY terminals.**

AI is powerful and smart, but the decisions and responsibilities ultimately fall to humans. Acorn is a tool designed for seamless collaboration between AI and humans.

</div>

## Overview

Acorn is a desktop app for managing multiple AI coding agent (Claude Code / Codex / Antigravity / Ollama / llm, etc.) sessions in parallel within a single window. It provides native PTY and chat, split panes and Kanban, session-isolated git worktrees, task summaries, and progress indicators all in one workspace.
