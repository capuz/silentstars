**Codaro** is a local-first programmable studio that connects **notebook learning, reactive code execution, and personal desktop automation** into a single document model on local Python. It automatically infers cell dependencies through AST analysis, executes/shares the `# %%` percent format `.py` as is, and promotes validated cells to tasks that can be scheduled or triggered by Webhooks. AI is optional, and when attached, it calls the product API as `tool_use` to teach and validate on a cell-by-cell basis.
