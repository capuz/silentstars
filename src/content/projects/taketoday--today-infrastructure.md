# TODAY Infrastructure

A Java library for applications software infrastructure.

## Overview

This project originated in 2017. It is primarily a Java library for building high-performance Web applications and general applications.

## Main Purpose

Primarily for learning technology, and also to provide a basic framework for my blog website https://taketoday.cn (the blog website was actually built to learn and practice technology). The blog is also open-sourced: https://github.com/TAKETODAY/today-blog

Although I had just started learning programming, when I was studying [Struts2](https://struts.apache.org/), I tried to write a similar program that eliminated a large amount of repetitive code through `XML` configuration. Thus the first-generation [infra-web](https://gitee.com/I-TAKE-TODAY/today-web/tree/v1.1.1/) was born and open-sourced.
