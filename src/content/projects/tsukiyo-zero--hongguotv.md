# Guoying TV · hongguoTV

An unofficial Hongguo short-drama client. It mainly maintains the Android TV version and also provides the native Mac client hongguoMac.

The Android TV version uses the native Kotlin client in `kotlin-tv/` and supports **Android 6.0 and above**. Install a single APK to use it; no need to deploy Node or Docker. The Mac client is built and updated independently.
