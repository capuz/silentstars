# Battle Cats Web Editor

**A web-based save editing and backup tool for The Battle Cats. No installation or jailbreak required.**

---

## Project Overview

Battle Cats Web Editor is a web-based save editing tool designed for The Battle Cats players. There is no need to install complicated modifiers on your phone, and no need to jailbreak your phone or obtain root access. Just open a browser, enter the in-game transfer code (引繼碼), and you can directly adjust resources, unlock cats, and change your progress. After you finish editing, the tool automatically generates a new transfer code, which you can use to transfer the save back to your phone so you can keep playing.

- No jailbreak, no root: Say goodbye to the tedious process of installing unknown modified APKs or changing system files. Everything is done through a pure web interface.
