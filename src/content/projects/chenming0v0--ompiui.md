# OMPiUI

**Use the OMP programming assistant on your computer, phone, and browser.**

OMPiUI is a third-party client for [oh-my-pi (OMP)](https://github.com/can1357/oh-my-pi). You can manage programming tasks on the desktop, or connect your phone to a computer or server to continue working on the same project.

The desktop app bundles the interface, the OMPiUI backend, and the official OMP runtime together. The mobile app only provides the interface, and tasks always run on the connected computer or server. Two terminal management interfaces are also available: one for managing headless backends, and one for managing a self-hosted public relay.

[Download and install](https://github.com/chenming0v0/OMPiUI/releases) · [Server deployment](https://github.com/chenming0v0/OMPiUI/blob/HEAD/deploy/README.md) · [Self-hosted relay](https://github.com/chenming0v0/OMPiUI/blob/HEAD/docs/tunnel.md) · [TUI usage guide](https://github.com/chenming0v0/OMPiUI/blob/HEAD/docs/tui.md)

## What you can do

- **Programming tasks**: chat, view tool execution results, use models and sub-agents, and access OMP's MCP, LSP, and extension capabilities.
