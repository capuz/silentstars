# PetOS · My Pet

## Logo

The official brand icon comes from [`icons.zip`](https://github.com/AnkioTomas/petos/blob/HEAD/icons.zip) in the repository root, and has been extracted to [`assets/brand/`](https://github.com/AnkioTomas/petos/blob/HEAD/assets/brand/):

| File | Purpose |
|------|------|
| `assets/brand/logo.png` | Main README / documentation image (512×512) |
| `assets/brand/webapp/android-chrome-512x512.png` | High-resolution app icon |
| `assets/brand/webapp/android-chrome-192x192.png` | Medium icon |
| `assets/brand/webapp/apple-touch-icon-180x180.png` | Apple Touch |
| `assets/brand/webapp/favicon-32x32.png` / `favicon-16x16.png` | Favicon |
| `assets/brand/webapp/favicon.ico` | Multi-size ICO |
| `assets/brand/webapp/site.webmanifest` | Web App Manifest |

For Electron / installer icons, prefer `assets/brand/logo.png` or the 512 image. When changing the brand, replace `icons.zip` and then re-extract it to `assets/brand/`.

---

A general-purpose desktop pet framework: **gameplay built in, visuals hand-drawn**. The product is not tied to any specific pet character; appearance, animations, and copy are all driven by the user's asset packs.
