Humans and AI build back-office products under the same rules: design tokens, React components, `AppLayout`, 70 page components, business templates, and Skills and MCP servers for Claude Code, Codex, and Cursor.

## Why Forge

- **Full-page source code is ready to use.** 70 page components cover dashboard home screens, data lists, detail views, forms, settings, authentication, and agent product pages. Install them into your project with a single shadcn command. Multi-page templates for orders, products, customers, and projects can be modified directly.
- **Visual standards live in the components.** Button, Form, DataTable, Calendar, Chart, Card, Toolbar, Dialog, and others come from `@forge-ui-official/core`. Colors, fonts, corner radii, borders, and density don't need to be rewritten on every page.
- **The back-office shell is already built.**…
