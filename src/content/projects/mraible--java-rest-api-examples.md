# Java REST API Examples: Micronaut, Quarkus, Spring Boot, and Helidon

This repository contains example OAuth 2.0 resource servers built with imperative and reactive versions of Micronaut, Quarkus, Spring Boot, and Helidon. See the [imperative](https://github.com/mraible/java-rest-api-examples/blob/HEAD/imperative/demo.adoc) and [reactive](https://github.com/mraible/java-rest-api-examples/blob/HEAD/reactive/demo.adoc) demo scripts to see how these examples were created.

**Prerequisites:** [Java 25 with GraalVM](https://sdkman.io/) and [HTTPie](https://httpie.io/).
