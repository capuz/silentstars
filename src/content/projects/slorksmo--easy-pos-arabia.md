# Easy POS Arabia

**Arabic point-of-sale system for small shops**

Easy POS Arabia manages products, inventory, sales and purchase invoices, and reports from a responsive web interface.

*An Arabic point-of-sale web app for small retailers, with product and inventory management, sales and purchase invoices, and transaction reporting.*

## A day at the store

Add products and organize them into categories before you start selling. When recording a sale, select the products and create a sales invoice. Record purchase invoices when goods are delivered, and refer to the reports to review transactions.

## Running locally

```bash
git clone https://github.com/slorksmo/easy-pos-arabia.git
cd easy-pos-arabia
npm install
npm run dev
```

Open the link that Vite prints in the terminal to preview the app.

## Technologies

[React](https://react.dev/) and [TypeScript](https://www.typescriptlang.org/) and [Vite](https://vite.dev/) and [Tailwind CSS](https://tailwindcss.com/) and [shadcn/ui](https://ui.shadcn.com/).
