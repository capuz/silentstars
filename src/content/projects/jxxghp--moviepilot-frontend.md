# MoviePilot-Frontend

*Chinese | [English](https://github.com/jxxghp/MoviePilot-Frontend/blob/HEAD/README_EN.md)*

[MoviePilot](https://github.com/jxxghp/MoviePilot) is the frontend project, minimum support for Node.js `20.19`, recommended to use Node.js `24`.

## Features

- Modern interface built with Vue 3 and Vuetify 3
- Uses Vite as the build tool, providing a fast development experience
- Support for multiple languages (Chinese/English)
- Complete plugin system support, including dynamic loading of remote components

## Development and Deployment

### Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=johnsoncodehk.volar) (and disable Vetur).

### Configuring Vite

Please see [Vite configuration reference](https://vitejs.dev/config/).

### Dependency Installation

```sh
yarn
```

### Development Run

```sh
yarn dev
```

### Build and Package

```sh
yarn build
```

### Unit Testing

```sh
yarn test:run
yarn test:coverage
```
