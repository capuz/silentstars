# seL4\_tools

Provides tools used to build seL4 projects.
Also collects common config and tools for style checks.

* [elfloader-tool](https://github.com/seL4/seL4_tools/blob/HEAD/elfloader-tool/): loads the arm kernel.
* [cmake-tool](https://github.com/seL4/seL4_tools/blob/HEAD/cmake-tool/): most of the build system.
* [misc](https://github.com/seL4/seL4_tools/blob/HEAD/misc/): miscellaneous extra tools, including code style checks.
