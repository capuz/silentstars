Lightweight, free-form editing and management tool for local folders, external files, code projects and Git repositories.<br>

## Product Positioning

MarkTextPro is a multimodal file editor manager with integrated Git. It keeps native free folder management, suited to code repositories and external documents; natively integrates Markdown, Draw.io architecture diagrams, GeoGebra math modeling, MindMap mind maps and professional PDF reading annotation; supports simple editing of common text files such as txt and json; includes a built-in KDBX encrypted key vault with 2FA dynamic passcodes, and provides direct SSH terminal connections (requires setting up a key vault; connects directly through the key vault with automatic 2FA verification), seamlessly linked with Git for version control, commits and sync.

## Product Selection

MarkTextPro and MarkNotePro are two independent products with complementary capabilities. Both natively support Markdown, Draw.io, GeoGebra, MindMap, KDBX encrypted password vaults and PDF professional reading annotation.
