# ZipNest 解压缩

**Free, open-source, ad-free file extractor for Windows. Native UI, zero runtime dependencies, installer only 3.6 MB.**

Double-click an archive to open it directly, as naturally as a built-in system feature. It is powered by the official 7-Zip engine (`7z.dll`, loaded dynamically at runtime) and handles ZIP / 7z / RAR / TAR / GZ / BZ2 / XZ / ISO without exception. **All features are free, and none are locked.**
