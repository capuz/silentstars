## 📖 Introduction

Shutter Sound Zero is an open-source Android app that manages camera shutter sound behavior using Samsung Galaxy's stock system (CSC) settings.

It does not continuously monitor the screen or camera execution using accessibility services. After initially linking the `WRITE_SECURE_SETTINGS` permission via local wireless ADB once, you can change the actual CSC values by enabling wireless debugging only when needed.

The current app version is **v1.5.10**. In this version, the task results of the quick settings tile and the state of the open home screen are updated to match the actual camera settings, and the wireless debugging settings and 6-digit code reconnection guidance have been separated. App lock authentication cancellation and existing ADB pairing key preservation handling have also been improved. For details on changes, please check the [v1.5.10 release notes](https://github.com/hoons1994/ShutterSoundZero/blob/HEAD/.github/release-notes/v1.5.10.md).
