# Argon Modern Theme
Argon Modern - A modernized refactored version based on Argon, a lighter, cleaner, and more beautiful WordPress theme

Original project: [github.com/solstice23/argon-theme](https://github.com/solstice23/argon-theme)

# Project Status

> This project is a modernized refactoring of the original Argon theme, adopting **Object-Oriented Programming (OOP)**, **On-demand Loading**, and **standardized architecture**, aiming to improve the theme's performance and maintainability.

# Features

## Core Features

+ **Lightweight and Beautiful** - Uses the Argon Design System frontend framework, with refined details, lightweight and beautiful design
+ **Highly Customizable** - Customizable theme colors, layouts (two-column/single-column/three-column), header, sidebar, banner, background images, different backgrounds for day/night modes, immersive backgrounds, floating action buttons, etc., offering rich customization options
+ **Night Mode** - Supports three modes: day, night, and pure black, with automatic switching based on time or following the system's night mode
+ **Rich Features** - Tag and category statistics, author links, additional links,…
