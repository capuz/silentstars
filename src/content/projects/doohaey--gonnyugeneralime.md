# Gan Universal Input Method GonnyuGeneralIME | Gan Pinyin GonPin

**Simplified Chinese** | [English](https://github.com/Doohaey/GonnyuGeneralIME/blob/HEAD/README.en.md)

> A digital writing scheme belonging to the Gan-Poyang region.

Currently supported: **Nanchang dialect (Lancong), Fenyi dialect (Fenni), Fengcheng dialect (Fungcen), Lichuan dialect (Tiqien), Xinyu dialect (Sinyi), Shanggao dialect (Songau), Susong dialect (Seusong), Ji'an dialect (Jingon), Yiyang-Henfeng dialect (Yikyan-Henfeng), Jishui Badu dialect (Jisuibaedu), Suichuan dialect (Xyucuênn), Xingzi dialect (Singzï), Gao'an dialect (Goungon)**. More regions are welcome to join, and existing regions are welcome to be expanded!

**One-click install / easy to use / ready for daily use: a Gan input method that anyone who knows Pinyin can use, with Gan Pinyin compatible with Mandarin Pinyin. Don't speak Gan? You can still play with it! Even with Gan thinking, you can easily output long passages of Mandarin text (such as this document)!**

**Now available on the iOS App Store ('Gan Input Method'), with quick installation for macOS, Android, Windows, and Linux, as well as Rime resource packs for each platform.**
