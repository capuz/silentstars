# Chinese introduction DUIThink
DUIThink is a free and open-source DirectUI interface library for Windows that includes a complete set of desktop software development components. Rather than just calling it an interface library, it's more accurate to call it a development framework. Functional components include (thread pool, file operations, IOCP network model, file monitoring, registry monitoring, file drag-and-drop, command-line parsing, magnetic absorption algorithm, memory pool, resolution conversion, string operations, etc.). You can directly use this framework to develop any desktop application you want.
