# copr

Here lives the spec files for my [copr repositories](https://copr.fedorainfracloud.org/coprs/sneexy/).

## [Zen Browser](https://copr.fedorainfracloud.org/coprs/sneexy/zen-browser/)

Fork of the Firefox browser with various different improvements and modifications akin to the Arc Browser. See the [`zen-browser` subdirectory](https://github.com/SnenxyTengoku/copr/blob/HEAD/zen-browser/) for more information, and [Zen's website](https://zen-browser.app/).

## [Floorp](https://copr.fedorainfracloud.org/coprs/sneexy/floorp/)

Fork of the Firefox browser with various different improvements and modifications. See the [`floorp` subdirectory](https://github.com/SnenxyTengoku/copr/blob/HEAD/floorp) for more information, and [Floorp's website](https://floorp.app/).

## [python-validity](https://copr.fedorainfracloud.org/coprs/sneexy/python-validity/)

The [`python-validity`](https://github.com/uunicorn/python-validity) project, built off the latest commit to make it function with Immutable distros.
