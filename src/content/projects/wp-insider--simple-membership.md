# Simple Membership

This is the development repository for the [Simple Membership](https://wordpress.org/plugins/simple-membership/) WordPress plugin.

Simple Membership adds membership functionality to a WordPress site. You can create free and paid membership levels, protect posts and pages so only members can view them, and take one-time or subscription payments with PayPal, Stripe or Braintree.

To use the plugin on your site, install it from [WordPress.org](https://wordpress.org/plugins/simple-membership/) (**Plugins → Add New** in your WordPress admin). You don't need this repository for that.
