# Open Grind

**Unofficial Grindr client. Cross-platform, free, libre, ad-free, tracker-free, privacy-centered and community-driven.**

## Download

- **[Download Open Grind](https://git.opengrind.org/open-grind/open-grind/releases#install)** from the Releases page

Never install Open Grind from sources not listed above.

## Security

All releases are signed. [Learn more](https://github.com/VityaSchel/open-grind/blob/HEAD/KEYS.md) about releases signatures.

Open Grind supports reproducible builds. Read more in [REPRODUCIBILITY.md](https://github.com/VityaSchel/open-grind/blob/HEAD/REPRODUCIBILITY.md).

## Development

Interested in contributing to the project? Head to [CONTRIBUTING.md](https://github.com/VityaSchel/open-grind/blob/HEAD/CONTRIBUTING.md) to get started. All contributions must be aligned with [CODE_OF_CONDUCT.md](https://github.com/VityaSchel/open-grind/blob/HEAD/CODE_OF_CONDUCT.md).

## Problems, bugs, feature requests?

Check out [issues](https://git.opengrind.org/open-grind/open-grind/issues) and the Matrix chatroom [#opengrind:opengrind.org](https://matrix.to/#/#opengrind:opengrind.org).
