# Crazy Flasher 7: Mercenary Empire · Single-Player MOD

**Crazy Flasher 7: Mercenary Empire**

Building on the classic Flash action game, this project continues to expand mercenary combat, character development, and exploration content, and also documents how an old game has gradually updated its interface, visuals, and runtime architecture.
