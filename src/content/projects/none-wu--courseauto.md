# 刷课助手 courseauto(学习通 / 智慧树 / 雨课堂)

A Tampermonkey (油猴) userscript that runs in the browser and automatically completes online course tasks: muted continuous video playback, document/image tasks, popup question answering, automatic chapter quiz answering, and automatic chapter switching.
Supports three platforms: **Xuexitong (Chaoxing), Zhihuishu (Zhihuishu), and Yuketang**.

- **Usable by beginners**: install Tampermonkey → install the script → open the course page. No coding required throughout.
- **Answering channel**: web AI (no API Key needed, requires installing a bridge script). API Key support was removed starting from v1.5.7.
- **Panel fully in Chinese**. Every setting item has a description. Default values lean 'fast'; for stability, adjust them according to [Safety and Compliance Recommendations](#-安全与合规建议).
