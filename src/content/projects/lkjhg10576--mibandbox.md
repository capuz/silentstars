## What is this

BandBox is a **purely local** toolbox for the **Xiaomi Band 10 / 10 NFC / 11 / 11 NFC** (212 × 520 narrow runway screen), **Xiaomi Band 9 Pro / 10 Pro** (336 × 480 rectangular screen), and **Xiaomi Band 9** (192 × 490 capsule screen). Each model has its own installation package (the package name is the same, so choose the one for your model). The Band 9 package has been available in Beta since `0.1.2-269` (Vela 4 engine; for on-device calibration items, see the release notes). **Xiaomi Band 11 has been supported since `0.1.2-271`** (same 212×520 as Band 10, using the same standard package).

The band's screen is narrow and has little usable space, so it usually only shows the time and step count. BandBox fits forty small tools onto this screen: calculator, logging, countdown days, lunar calendar lookup, QR code generation, Morse code conversion, wooden fish tapping, marquee, local lyrics playback, dynamic one-time password generation...

All data stays on the band locally. **No network requests, free of charge, no registration, no uploads.**
