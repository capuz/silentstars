## What is MDCx

MDCx is a desktop tool that automatically fetches metadata (title, actors, cover, description, etc.) of video files from 52 websites, generates standard .nfo files and organized folders for media servers like Emby, Jellyfin, and Kodi to use directly.

In one sentence: Transform a messy collection of video files into an organized library that media servers can recognize.

## Quick Installation

Download the installation package or executable file for your system from [GitHub Releases](https://github.com/cdlongbow/MDCx/releases). On Linux, run `chmod +x MDCx` before first run, then run `./MDCx`.

Detailed installation instructions: [docs/Install.md](https://github.com/z291173301/MDCx/blob/HEAD/docs/Install.md)
