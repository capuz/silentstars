# MDCx

## What is MDCx

MDCx is a desktop tool that automatically scrapes metadata (titles, actors, cover art, synopses, etc.) for video files from 52 websites, then generates standard .nfo files and organized folders for direct use with media servers such as Emby, Jellyfin, and Kodi.

In short: it turns a pile of messy video files into a tidy library that media servers can recognize.

## Quick Install

Download the installer or executable for your system from [GitHub Releases](https://github.com/cdlongbow/MDCx/releases). On Linux, run `chmod +x MDCx` before the first run, then run `./MDCx`.

Detailed installation instructions: [docs/Install.md](https://github.com/z291173301/MDCx/blob/HEAD/docs/Install.md)
