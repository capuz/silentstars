## What is MDCx

MDCx is a desktop tool that automatically scrapes metadata for video files (titles, cast, cover art, synopses, etc.) from 47 websites. It generates standard .nfo files and organized folders, ready to use directly with media servers such as Emby, Jellyfin, and Kodi.
