Chronicle is a desktop timeline backup tool for game saves, software configurations, and arbitrary folders. Based on a local repository, it saves each backup as a recoverable `.7z` snapshot and can sync to WebDAV, GitHub, or OpenDAL object storage.

The current official version is **1.3.5**, adding native image wallpapers, full-window semi-transparent preview, drag-to-create archives, and category selection during creation. Supports multi-device recognition, sync preview and snapshot deletion protection, Steam archive recognition, Galgame archive scanning (Beta), Simplified Chinese and English interfaces, automatic backup, automatic upload, system tray background running, and multi-source cloud sync.

## Features

- Scan archive sources from multiple Steam game libraries, group by account nickname, batch add after checking; scan results are locally cached, manual refresh available.
- Galgame archive scanning (Beta): select a collection folder, recursively identify games in nested directories, check for existing archives in-game and in common Windows user directories, batch add after verification.
