# CPU-web

药大拾间 is a campus information aggregation site for students of China Pharmaceutical University. The current repository is no longer just a web MVP. It is a complete multi-platform project that includes:

- `web/`: Vue 3 frontend site and `/schedule` PWA timetable page
- `server/`: Express + Prisma + PostgreSQL backend
- `voicehub/`: 药苑之声 Nuxt full-stack sub-application (fully retains the VoiceHub song-request system)
- `android/`: Android WebView shell and desktop timetable widget
- `harmony/`: HarmonyOS WebView shell and JS Bridge
- `desktop/`: Windows / Apple Silicon macOS desktop app (Electron single-window tabbed app, OAuth2 login, automatic campus network connection, and 学习通 tab)

Repository: [https://github.com/sx120609/CPU-web](https://github.com/sx120609/CPU-web)

To get a less technical overview of the whole project, you can read [《药大拾间完整技术路线》](https://github.com/sx120609/CPU-web/blob/HEAD/docs/technical-overview.md) (Complete Technical Roadmap of 药大拾间), or download the [typeset PDF version](https://github.com/sx120609/CPU-web/blob/HEAD/output/pdf/yaoda-shijian-complete-technical-route.pdf) directly.
