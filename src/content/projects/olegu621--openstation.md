> According to the project owner, users have confirmed that the OpenStation USB installer works. Previously, version 1.2 reported write and boot errors; details are in the [instructions](https://github.com/Olegu621/OPENSTATION/blob/HEAD/docs/INSTALLER.md).

> **OpenStation USB for Station Max:** [download the latest installer (v1.6.2)](https://github.com/Olegu621/OPENSTATION/releases/latest). The installer uses direct WorldCup exchange and automatically runs `after_ubt` after writing partitions. Connect the station in a mode in which USB Burning Tool can see it, close USB Burning Tool, and run the installer as administrator. The installer automatically downloads the current ROM v1.6.2 (or uses a local `rom\`) and verifies checksums. Do not disconnect power during writing.
>
> Partition transfer and a full boot after flashing with this installer have not yet been verified on a physical station. USB commands and memory writes were checked in the original PR; automatic completion was verified with a simulated device.
