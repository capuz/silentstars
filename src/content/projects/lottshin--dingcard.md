## Free-form canvas

**Select any element and edit it in place.** Text, images, shapes, lines, icons, charts, tables, timelines, and QR codes sit on the same canvas. Each page of a multi-page work can have its own size.

- **Text**: Select a span of text to make it bold, colored, highlighted, or underlined. Apply any of 16 decorative text styles with one click (neon, outline, 3D, label background color, and more). Import your own font files (TTF / OTF / WOFF / WOFF2), which are used for both the canvas and exports.
- **Images**: Once a standalone image enters crop mode, you can move it within its original frame, drag the eight black handles, or resize the frame while keeping proportions. You can also add rounded corners, photo frames, and filters. With the server deployed, the online image library in the image drawer lets you search for commercially usable images directly.
- **Assets**: 97 searchable line icons, 48 hand-drawn lines, stickers, and labels. Charts include bar, donut, line, and radar, and data can be pasted column by column from a table.
