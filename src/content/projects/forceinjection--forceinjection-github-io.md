# AI Fundamentals

This repository is a comprehensive collection of learning resources on AI Infrastructure, covering the full technology stack from hardware fundamentals to advanced applications. Content includes GPU architecture and programming, CUDA development, large language models, AI system design, performance optimization, enterprise-grade deployment, and other core areas. It aims to provide AI engineers, researchers, and technology enthusiasts with a systematic learning path and practical guidance.

> - **Target audience**: AI engineers, system architects, GPU programming developers, LLM application developers, and technology researchers.
> - **Tech stack**: CUDA, GPU architecture, LLM, AI systems, distributed computing, containerized deployment, performance optimization.
