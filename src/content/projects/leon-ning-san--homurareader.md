> This fish only stuffs books into your local bookshelf. Uploading them to the cloud? Don't even think about it. 🐋

HOMURA is a **local-first** reader: comics, light novels, PDFs, and image collections can be read once imported. Parsing, pagination, and rendering are all done on your machine, and book content is never uploaded. The desktop app is packaged with Tauri 2, and the same frontend also provides an Android build.

- Current version: **2.2.7**
- Tech stack: Vue 3 + Pinia + Vite 6 + Tauri 2 + TypeScript
- Repository: [Leon-Ning-san/HomuraReader](https://github.com/Leon-Ning-san/HomuraReader)
- Download: [GitHub Releases](https://github.com/Leon-Ning-san/HomuraReader/releases)

## Feature Overview

- **Multi-format bookshelf**: EPUB / KEPUB, CBZ / ZIP comic archives, PDF, MOBI, TXT, Markdown, and image folders.
- **Top-level libraries and favorites**: create, rename, and delete libraries; multi-select to move items in, or move them across libraries. The favorites page shows all favorites in a flat list.
