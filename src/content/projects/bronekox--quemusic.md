# QueMusic Project

> QueMusic is an open-source, cross-platform music player that puts performance and responsiveness first.
>
> All computation and I/O are handled by C++ and worker threads; QML only handles presentation. Rendering uses Qt RHI's GPU pipeline, so animations don't drop frames, and even integrated graphics can run steadily at a full 60 FPS.
>
> QueMusic Project is **permanently free & open source**.
>
> 🚧 The project is in **development / preview stage**: features are still being filled in, some modules are unfinished, and there are known issues. It will be updated continuously.
> Stars & Forks are welcome. Before you start, please read the [Contributing Guide](https://github.com/BroNekoX/QueMusic/blob/HEAD/CONTRIBUTING.md) (including build instructions for three platforms and a pre-submission checklist).
> If you want to write plugins (lyrics interfaces / features), you can go straight to the [QuePlugins](https://github.com/bronekox/queplugins) plugin repository.
