# Bangumi Open

View anime broadcast schedules and the anime index in VS Code, and get reminded when anime episodes update. Data comes from [Bangumi (bgm.tv)](https://bgm.tv) by default, but you can switch to Bilibili.

## Features

- **Weekly schedule**: An update timetable laid out by weekday. The 'Today' column marks the current time and the countdown to the next update.
- **Two data sources**: The weekly schedule uses Bangumi's daily broadcast list by default, but you can switch to the Bilibili timetable (which includes air times).
- **Anime index**: Multi-level filtering by genre, region, status, copyright, payment, season, time, and style.
- **Update reminders**: The status bar shows the next update, a notification pops up when an update arrives, and advance reminders are supported.
- **Today overview**: With the default Bangumi data source, the status bar shows a summary of anime updating today.
