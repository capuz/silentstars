## What It Does

This browser-based utility creates ready-to-import keymap files for Call of Duty: Mobile running inside the Gameloop emulator. Rather than configuring each control binding manually, you set your preferences in the HTML interface and the tool outputs a file that Gameloop can load directly. The generator covers standard CODM actions—movement, aiming, firing, and tactical commands.

This release improves compatibility with recent Gameloop versions and the latest CODM seasonal content. It handles both basic and advanced control schemes, so you can adjust your setup without editing configuration files by hand. Every generated keymap follows Gameloop's import format.
