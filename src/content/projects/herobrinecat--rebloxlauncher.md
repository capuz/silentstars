# <div align="center"><img src="https://raw.githubusercontent.com/herobrinecat/ReBloxLauncher/refs/heads/master/ReBloxIcon.png" alt="A logo of ReBlox" width="75" height="75"><h3>ReBlox</h3></div>

A launcher revival for old ROBLOX that is built from scratch and currently under development.

## Introduction

ReBlox is a offline launcher revival of ROBLOX, with its purpose is to support clients such as 2016E, 2014L, 2019M, etc. This project contains C# (ReBloxLauncher) and JS code (RobloxAssetFixer).

## Building

Building this application requires:

* Visual Studio 2019+ (Visual Studio 2012-2017 is not tested, but is theoretically possible)
* .NET Framework 4.8

## Downloads
You can download the latest stable release in the [download server](http://rebloxfileserver.servehttp.com), however you can also download the beta version patches by signing up to be a Beta Tester in the [Discord server](https://discord.gg/74s7U4Sbef). Even though this repo will be used for the launcher, it will **NOT** contain the clients, asset packs, maps, and node included if you downloaded from the Actions tab.
