# Kwrg IRC

【[devlog] Skyblock QOL IRC Mod - KwrgIRC 26.1.2】

https://www.bilibili.com/video/BV1Ukxh6NEbi/?share_source=copy_web&vd_source=626a20fc228373f6416c8f5e140c93f0

A Fabric client mod for Hypixel SkyBlock that provides built-in IRC chat, waypoint and route management, and customizable GUI and HUD.

[English](https://github.com/cow76192/Kwrg-IRC/blob/HEAD/README.en.md) · [Source code](https://github.com/cow76192/Kwrg-IRC)

## Installation

Runtime environment for the current source code:

| Component | Version |
| --- | --- |
| Minecraft | 26.1.2 |
| Java | 25 or higher |
| Fabric Loader | 0.19.3 or higher |
| Fabric API | Matching Minecraft 26.1.2 |
| owo-lib | 0.13.1+26.1 |

1. Install Fabric Loader for Minecraft 26.1.2.
2. Place the Kwrg mod JAR and the matching version of Fabric API into the `mods/` folder in your game directory.
3. Install the matching version of owo-lib. The build package also includes owo-sentinel, which can guide installation if owo-lib is missing.
4. Launch the game and enter a world, then press **Right Shift** or type `/irc gui` to open the interface.
5. ENJOY your GAME
