# Documentation for MusicBrainz Picard

This project was created with the intent of developing a comprehensive user manual for [MusicBrainz Picard](https://picard.musicbrainz.org), a full-featured, cross-platform music file tagging system using metadata from [MusicBrainz](https://musicbrainz.org).

This documentation project is open source and provided under CC0 1.0. To view a copy of this license, visit [https://creativecommons.org/publicdomain/zero/1.0](https://creativecommons.org/publicdomain/zero/1.0).

The project currently produces the on-line documentation in [ReadTheDocs](https://readthedocs.org) format theme using [Sphinx](https://www.sphinx-doc.org/). Stand-alone PDF documents are also being produced. The latest build of the documentation produced by this initiative can be viewed on the [web page](https://picard-docs.readthedocs.io/).

## Contributing to the Documentation

This documentation project only exists because of the volunteer effort that goes into its development.
