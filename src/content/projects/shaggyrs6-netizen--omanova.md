# OMANOVA

*Promotional illustration. [Actual app screenshots](https://github.com/shaggyrs6-netizen/omanova/blob/HEAD/docs/SCREENSHOTS-0.1.8.md) · [Star-chart reference data attribution](https://github.com/shaggyrs6-netizen/omanova/blob/HEAD/observatory/final_sky/HYG-LICENSE.md).*

OMANOVA is a local astronomy Observatory and bar widget for Omarchy Quattro.
Left-click the widget to open the resizable Observatory. Middle-click for the
compact fallback. Set your observing location manually under **Settings**.

> **Version 0.1.8** fixes widget installation on Omarchy 4.5, improves installer recovery and adds battery-aware Mission Control wallpaper controls. Read the [release notes](https://github.com/shaggyrs6-netizen/omanova/blob/HEAD/docs/RELEASE-0.1.8.md), [changelog](https://github.com/shaggyrs6-netizen/omanova/blob/HEAD/CHANGELOG.md) and [screenshots](https://github.com/shaggyrs6-netizen/omanova/blob/HEAD/docs/SCREENSHOTS-0.1.8.md).

> The Omarchy marketplace listing is managed separately from GitHub releases. See the [upgrade instructions](#upgrading-an-existing-installation) if you installed the marketplace version.
