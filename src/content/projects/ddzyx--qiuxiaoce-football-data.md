# 球小策 & XG Mind · Global Football Match Quantitative Analysis Open Dataset and AI Agent (Global Football Intelligence & Agent Skill)

> **球小策 (QiuXiaoCe)** and the overseas official terminal **XG Mind AI** jointly open-source project: aggregating structured pre-match quantitative data packs, bilingual in-depth AI tactical and technical reasoning reports, and a publicly verifiable, tamper-proof ledger of real post-match scores, covering 88 professional football leagues worldwide (Europe's top five leagues, Champions League, UEFA Nations League, World Cup, Asian Cup, etc.). It also includes the official **Creator API dedicated AI Agent Skill**, which can be called with one click in environments such as Cursor, Claude Desktop, Dify, Coze, and Python, empowering global sports self-media, quantitative researchers, and match data analysts.
