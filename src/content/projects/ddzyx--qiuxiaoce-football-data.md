# 球小策 & XG Mind · 全球足球赛事量化分析开放数据集与 AI Agent 智能体 (Global Football Intelligence & Agent Skill)

> **球小策 (QiuXiaoCe)** and the overseas official terminal **XG Mind AI** jointly open-source this project. It aggregates structured pre-match quantitative data packs, bilingual in-depth AI tactical and technical analysis reports, and a tamper-proof public verification ledger of actual post-match scores, covering 88 professional football leagues worldwide (Europe's top five leagues, the Champions League, the UEFA Nations League, the World Cup, the Asian Cup, etc.). It also includes the official **Creator API exclusive AI agent Skill**, which can be invoked with one click in environments such as Cursor, Claude Desktop, Dify, Coze, and Python, empowering global sports self-media, quantitative researchers, and match data analysts.
