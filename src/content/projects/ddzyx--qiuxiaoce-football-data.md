# QiuXiaoCe & XG Mind · Global Football Match Quantitative Analysis Open Dataset & AI Agent (Global Football Intelligence & Agent Skill)

> **QiuXiaoCe (球小策)** and the overseas official terminal **XG Mind AI** jointly open-source this project. It aggregates structured pre-match quantitative data packs, bilingual in-depth AI tactical analysis reports, and a public, tamper-proof ledger for verifying real post-match scores, covering 88 professional football leagues worldwide (Europe's Big Five leagues, the Champions League, the UEFA Nations League, the World Cup, the Asian Cup, and more). It also includes an official **Creator API**-exclusive **AI Agent Skill** that can be invoked with one click in Cursor, Claude Desktop, Dify, Coze, Python, and other environments, empowering global sports self-media, quantitative researchers, and match data analysts.
