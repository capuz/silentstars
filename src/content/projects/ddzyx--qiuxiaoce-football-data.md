# QiuXiaoCe & XG Mind · Global Football Match Quantitative Analysis Open Dataset & AI Agent (Global Football Intelligence & Agent Skill)

> **QiuXiaoCe** and the overseas official terminal **XG Mind AI** jointly open-source project: aggregating structured pre-match quantitative data packs, bilingual in-depth AI tactical and technical analysis reports, and a public, tamper-proof ledger of verified post-match actual scores, covering 88 professional football leagues worldwide (Europe's top five leagues, Champions League, UEFA Nations League, World Cup, Asian Cup, etc.). It also includes the official **Creator API exclusive AI agent Skill**, which can be invoked with one click in environments such as Cursor, Claude Desktop, Dify, Coze, and Python, empowering global sports media creators, quantitative researchers, and match data analysts.
