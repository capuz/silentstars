# 球小策 & XG Mind · Global Football Match Quantitative Analysis Open Dataset and AI Agent (Global Football Intelligence & Agent Skill)

> **球小策 (QiuXiaoCe)** and the overseas official terminal **XG Mind AI** jointly open-source this project. It aggregates structured pre-match quantitative data packs for 88 professional football leagues worldwide (Europe's top five leagues, the Champions League, the UEFA Nations League, the World Cup, the Asian Cup, and others), bilingual in-depth AI tactical and technical analysis reports, and a public, tamper-proof ledger of real post-match scores for verification. It also includes the official **Creator API exclusive AI agent Skill**, which can be invoked with one click in environments such as Cursor, Claude Desktop, Dify, Coze, and Python, empowering global sports media creators, quantitative researchers, and match data analysts.
