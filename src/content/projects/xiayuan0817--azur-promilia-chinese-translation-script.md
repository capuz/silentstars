# Azur Promilia Simplified Chinese Localization / Erran Issue Feedback QQ Group: 1055713417 (often offline, group is full...)

Simplified Chinese localization tool for the Taiwan and Japan servers of *Azur Promilia: Rover Rumors* (《蓝色星原：旅谣》) game and launcher. Supports localization, anti-virtualization removal, restoration, and file verification.

> **If you cannot log in, restore the files. This project has not been tested for anti-cheat and later versions are not guaranteed to be compatible.**

## Download

Go to [Releases](https://github.com/xiayuan0817/Azur-Promilia-Chinese-Translation-Script/releases) to download the complete localization package:

**`AzurPromilia-Localization-Full-v6.zip`**

The full package includes the run scripts and replacement resources; no separate CN-server package is needed.

**The repository source code does not include game replacement resources. Downloading the repository ZIP alone cannot complete the localization.**
