# Text lists of domains and IPs of gaming services blocked in Russia

The lists can be used with **Zapret**, DNS filters, routing, firewall/ipset, and other similar tools.

---

> [!NOTE]
> The repository is updated automatically via **GitHub Actions** and searches GitHub for new domains/IPs when they appear.
> A quick update runs **every 3 hours**, and a full extended search runs **every 2 days**.

> [!TIP]
> These lists are already built in **out of the box** and are used together with the game mode in my [Zapret GUI](https://github.com/medvedeff-true/Zapret-GUI).
