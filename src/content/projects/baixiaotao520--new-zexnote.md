# ZexNote
A concise and elegant local note-taking APP, developed based on Flutter + Material3

## ✨ Software Features
- Theme: Automatically switch with system light/dark night mode; Android 12+ supports Material You wallpaper dynamic color picking
- Bottom small floating capsule navigation bar with smooth slide indicator animation for page switching
- Fully local note storage with basic note-taking functions: create, edit, delete, archive notes
- Support for batch operations on notes (multi-select batch delete, batch archive)
- Note JSON backup and recovery for convenient data export and import

## 📱 Device Support
- CPU Architecture: **ARM64 only (arm64-v8a)**, does not support 32-bit ARM or x86 architecture
- Android Version: Android 9.0 (API 28) and above (compatible with Android 9–16)

## 🔄 Dual-Channel Version Update System
1. **Dual-Channel Version Detection**: Prioritizes GitHub Releases API; automatically switches to Releases Atom feed when hitting IP rate limits to avoid access frequency control
2. Optional Mirror Sauce high-speed download source; Mirror Sauce project page can only be opened via browser; automatically falls back to direct GitHub connection on interface…
