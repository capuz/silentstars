# GTOCore-Main

[English](https://github.com/GregTech-Odyssey/GTOCore-Main/blob/HEAD/README_EN.md)

## Project Introduction

GTOCore is the unified core mod of GregTech Odyssey, targeting Minecraft 1.20.1 and Forge 47.4.20, with mod ID `gtocore`.

This repository makes the source code and resources of GTOCore public, so everyone can read, study, and review the implementation.

The license for the contents of this repository follows the [GregTech Odyssey License Notice](https://github.com/GregTech-Odyssey/GregTech-Odyssey/blob/main/README_zh.md#许可证). gtolib remains a closed-source component.
