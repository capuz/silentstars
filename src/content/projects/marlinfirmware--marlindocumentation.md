## About

This repository contains the raw documentation for [Marlin 3D printer firmware](https://github.com/MarlinFirmware/MarlinDocumentation/blob/HEAD//github.com/MarlinFirmware/Marlin) which is automatically deployed to [marlinfw.org](https://github.com/MarlinFirmware/MarlinDocumentation/blob/HEAD//marlinfw.org/). This documentation is open and available on GitHub so anyone may contribute by completing, correcting, or creating articles.
