# chromeext

Small Chrome extensions, one per folder. imdb-ratings is also on the Chrome
Web Store; the others you load straight from this repository.

| Extension | What it does |
| --- | --- |
| [youtube-old-layout](https://github.com/Lwolf12/chromeext/blob/HEAD/youtube-old-layout/) | Brings back the classic YouTube watch page: recommended videos on the right, comments under the video. |
| [imdb-ratings](https://github.com/Lwolf12/chromeext/blob/HEAD/imdb-ratings/) | Overlays the IMDb user rating on title cards while browsing Netflix, Prime Video, Hulu and HBO Max. [Install from the Chrome Web Store](https://chromewebstore.google.com/detail/biopmnlghmgjoloionocinndfopncelh). |

## Installing from this repository

1. Open the [Releases page](https://github.com/Lwolf12/chromeext/releases)
   and download the ZIP for the extension you want (each release is named
   after its extension, for example `imdb-ratings v0.4.0`). Extract it
   somewhere you'll keep it: Chrome loads the extension from that folder
   every time it starts, so don't delete it afterwards.
2. In Chrome, open `chrome://extensions`.
3. Turn on **Developer mode** (toggle in the top right).
4. Click **Load unpacked**…
