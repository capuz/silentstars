# AutoClipping_S AviUtl ExEdit2 Margin Removal Script

This is a script for AviUtl ExEdit 2 that searches for non-transparent pixels in objects and clips the top, bottom, left, and right edges to achieve minimum size.

This is a ported and feature-added version of Mr-Ojii's [AutoClipping_M](https://github.com/Mr-Ojii/AviUtl-AutoClipping_M-Script), and a ported version of my [margin removal σ](https://github.com/sigma-axis/aviutl_CropBlank_S).

[Download here.](https://github.com/sigma-axis/aviutl2_script_AutoClipping_S/releases)

## Operating Requirements

- AviUtl ExEdit2

  http://spring-fragrance.mints.ne.jp/aviutl

  - Confirmed to work with `2.1.9`.

## Installation Method

Drag & drop the downloaded `aviutl2_script_AutoClipping_S-v*.**.au2pkg.zip` into the AviUtl2 window.

By default, AutoClipping_S is added to the 'Clipping' in the 'Add Filter Effect' menu.
- You can change the category in the 'Label' item of 'Object Add Menu Settings'.
