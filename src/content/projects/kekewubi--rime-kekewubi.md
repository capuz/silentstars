### About me

Keke Wubi official website: https://keke.kim/  

Tips:
* To use it, copy all files from this project into the “user folder” of each RIME frontend (all platforms call it “Rime”), then redeploy.
* RIME frontends by platform: Windows: Weasel (小狼毫); macOS: Squirrel (鼠须管); iOS: Hamster (仓输入法); Android: Trime (同文); Linux: ibus-rime.
* Press F4 (or Ctrl+` or Ctrl+0) repeatedly to switch between the three Wubi schemes (Keke Wubi - 86 Edition, Keke Wubi - 98 Edition, Keke Wubi - New Century Edition).
* To change features, edit the settings in the scheme file keke_wubi_XX.schema.yaml and the global custom file default.custom.yaml, then redeploy after your changes.
* Important: Settings in these two files that have no comments should be changed with extreme caution, extreme caution, extreme caution.
* It is recommended to use the Windows version of Keke Wubi to build your own dictionary (it supports importing words only and generates codes automatically). After exporting, copy the file to keke_wubi_dict/keke_wubi_XX_user.dict.yaml and redeploy.
* Regarding online word addition: this feature generates a lot of junk words.
