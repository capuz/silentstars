# MyHomeLib

**Ukrainian** · [English](https://github.com/OleksiyPenkov/MyHomeLib/blob/HEAD/README.en.md) · [Български](https://github.com/OleksiyPenkov/MyHomeLib/blob/HEAD/README.bg.md)

Managing a home e-book library: cataloging your own collection of files and working as a client of libraries on the Librusec engine.

## What it is

MyHomeLib is a desktop program for Windows that lets you catalog your own collection of e-book files: books are sorted by authors, series, and genres, searched by any combination of criteria, and opened in the reading program you have configured.

Besides your own collections, MyHomeLib works as a client for libraries on the Librusec engine, including Flibusta and similar sites. The catalog of such a library is connected from an INPX file, after which books can be searched and browsed locally, and only the ones you actually need are downloaded from the server.

Books are stored in FB2 format (individual files or zip archives), FBD, and any others; collection metadata is stored in an SQLite database.
