# [CoSky](https://github.com/Ahoo-Wang/CoSky): Configuration and Service Discovery

> **[Documentation](https://cosky.ahoo.me/)** | [中文文档](https://cosky.ahoo.me/zh/) | [中文 README](https://github.com/Ahoo-Wang/CoSky/blob/HEAD/README.zh-CN.md)

> **Important**
>
> **8.0 is a release candidate.** From `8.0.0-rc.1` to `8.0.0`, its API, wire format, configuration, documented metrics and Redis data only grow ([what the freeze keeps](https://github.com/Ahoo-Wang/CoSky/blob/HEAD/CONTRIBUTING.md#releases-and-versioning)). It becomes `8.0.0` once it has run in a real environment for two weeks without a serious problem: run it in one of yours before production, and [tell us](https://github.com/Ahoo-Wang/CoSky/issues/new/choose) what breaks or surprises you. The stable release is 6.x, and `ahoowang/cosky:latest` is still 6.x; it moves to 8.0 with `8.0.0`, so a 6.x deployment should name its version, such as `ahoowang/cosky:6.2.0`. 6.x is maintained on the [`v6`](https://github.com/Ahoo-Wang/CoSky/tree/v6) branch, which takes bug fixes only, and its documentation is in that branch's [`wiki/`](https://github.com/Ahoo-Wang/CoSky/tree/v6/wiki/guide).
