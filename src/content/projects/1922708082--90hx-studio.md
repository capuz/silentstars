# 90HX Studio

An unlock and tuning tool for the CMP 90HX (GA102). It unlocks graphics, compute, and ray tracing together, and includes GPU identity spoofing, in-game overlay unlocking, DLSS 3 frame generation, and dual-GPU scheduling. It is a single file that needs no installation: double-click to run.

## Features

- **Unlock**: NVPermissiveEFI approach, enabling graphics / compute / ray tracing together. Runs directly from the EFI Shell, deploys a separate boot entry without touching the Windows bootloader, and falls back automatically on failure. Three boot channels are available: modern UEFI direct boot, legacy motherboard Shell, and USB direct boot.
- **GPU spoofing**: Presents the 90HX as an RTX 3080. It modifies the registry, INF driver files, and NVIDIA App cache together. The driver hot-reloads, so changes take effect without rebooting the PC. The original factory name can be restored at any time.
- **In-game overlay**: Bypasses the NVIDIA App allowlist, unlocking the Alt+R performance overlay and ShadowPlay recording.
