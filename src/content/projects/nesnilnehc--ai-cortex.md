# AI Cortex

A governance and delivery asset library for AI agents: reusable **skills**, **specs**,
**protocols** and **rules** for software delivery and project governance.

[Website](https://ai-cortex.nesnilnehc.top/) · [中文介绍](https://ai-cortex.nesnilnehc.top/zh) · [Quick start](#quick-start) · [MIT license](https://github.com/nesnilnehc/ai-cortex/blob/HEAD/LICENSE)

Use the website to explore the capability map and examples, or start below to
install the library. Read the [mission](https://github.com/nesnilnehc/ai-cortex/blob/HEAD/docs/project-overview/mission.md) and
[vision](https://github.com/nesnilnehc/ai-cortex/blob/HEAD/docs/project-overview/vision.md) for the project's direction.

For agents working in this repository, [AGENTS.md](https://github.com/nesnilnehc/ai-cortex/blob/HEAD/AGENTS.md) defines the execution
contract, asset precedence and discovery. See [terminology](https://github.com/nesnilnehc/ai-cortex/blob/HEAD/docs/architecture/terminology.md)
for the four asset layers and the [website guide](https://github.com/nesnilnehc/ai-cortex/blob/HEAD/website/README.md) for site maintenance.
