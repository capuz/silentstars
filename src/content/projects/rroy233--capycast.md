Supports starting screen casts from the Bilibili mobile app. The app itself does not provide content browsing, recommendations, or subscription feeds, making it suitable for homes, dormitories, classrooms, and similar settings.

## Interface Preview

| Home | Continue Casting |
| --- | --- |
|  |  |
| Minimalist, clean, and ad-free; ready to use as soon as it opens. | Continue Casting can be closed at any time, so you control your playback history. |

| Video Playback | Quality Selection |
| --- | --- |
|  |  |
| Smooth playback with danmaku. | Supports the highest quality within your account's entitlements. |

## Feature Highlights

- **Playback based on account entitlements**: Supports QR code login on TV, and guest use is also available;
- **Highest possible quality**: Big VIP members can play 4K, 8K, HDR, and Dolby quality tiers, plus Dolby Atmos audio tracks;
- **Automatic selection of the best playback route**: Prioritizes the official route among candidate playback addresses to reduce the impact of low-quality PCDN sources.
