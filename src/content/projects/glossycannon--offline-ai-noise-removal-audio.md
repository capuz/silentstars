# AI Podcast & Interview Audio Cleaner — Local Batch Tool

Local AI Audio Cleaner for Windows — offline noise reduction, de-reverb, hum and buzz removal, speech enhancement, normalization, batch processing, waveform preview and WAV/MP3/FLAC export.

> **Local-first design:** source files are intended to be processed on the user's Windows PC; mandatory cloud upload is not part of the project concept.

## Features

- **De-reverb**

- **FLAC export**
- **Preset profiles**

---

## Workflow

1. Import audio files
2. Choose voice / music profile
3. Set denoise strength
4. Set de-reverb / de-hum
5. Preview cleaned segment
6. Normalize loudness
7. Batch process
8. Export cleaned audio
