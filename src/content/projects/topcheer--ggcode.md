# ggcode

**English** | **[中文](https://github.com/topcheer/ggcode/blob/HEAD/README_zh-CN.md)**

An AI coding agent for the terminal. Understands your codebase, edits files, runs commands, and ships code — with a polished TUI, resumable sessions, and multi-agent support.

---

## Install

**macOS / Linux:**
```bash
curl -fsSL https://ggcode.dev/install.sh | bash
```

**Windows:**
```powershell
irm https://ggcode.dev/install.ps1 | iex
```

**Other methods:** [Homebrew](https://github.com/topcheer/ggcode/blob/HEAD/docs/guide/install.md#macos) · [winget](https://github.com/topcheer/ggcode/blob/HEAD/docs/guide/install.md#windows) · [npm](https://github.com/topcheer/ggcode/blob/HEAD/docs/guide/install.md#npm) · [pip](https://github.com/topcheer/ggcode/blob/HEAD/docs/guide/install.md#pip) · [build from source](https://github.com/topcheer/ggcode/blob/HEAD/docs/guide/install.md#build-from-source)

> All install scripts default to non-privileged (no sudo / admin required).
