# vimdoc-ja-working

This is a project for translating the help documentation bundled with Vim into Japanese.

## I want to use the help

Please access the [page](https://github.com/vim-jp/vimdoc-ja) for distribution only!

## I want to help translate the help

For the work procedure, please see the [wiki](https://github.com/vim-jp/vimdoc-ja-working/wiki).

If you find a mistake, please let us know at the [issue tracker](https://github.com/vim-jp/vimdoc-ja-working/issues). Pull requests are also very welcome.

If you do not have a GitHub account, you can also contact us by the following method.

- Mailing list <https://groups.google.com/group/vimdoc-ja>

### There is a sister project!

Translations into Japanese of Vim's own messages, GUI menus, tutorial, man files, and so on are done at [vim-jp/lang-ja](https://github.com/vim-jp/lang-ja). Feel free to join in.
