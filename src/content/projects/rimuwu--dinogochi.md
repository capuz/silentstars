# DinoGochi - telegram.bot in python

Telegram bot in the style of Tamagotchi, but with dinosaurs! A gaming bot where you must take care of your dinosaurs, but it also has RPG elements.

### 🦕 | About the bot

- Take care of your friend, play together with him!

- Travel with the dinosaur in the best ideas of Fallout.

- Engage in crafting, create, trade!

- Join a huge community of friends! And also...
- Join this exciting RPG world of dinosaurs!

### 🛠 | To run the bot
#### Locally
- Install Python version 3
- The bot can run on both the old `3.8` and the new `3.11` (The main bot runs on `3.11`)
- Next, install all libraries from the `requirements.txt` file
>
    # Windows or Linux
    pip install -r requirements.txt

- Install the database on your PC
• [# Windows](
    https://metanit.com/nosql/mongodb/1.2.php

    https://www.dmosk.ru/miniinstruktions.php?mini=mongodb-ubuntu
