Welcome to the Simplified Chinese version of the Rustlings exercises 😃
This project contains small exercises to help you get used to reading and writing idiomatic Rust code.
It also covers how to read compiler messages and modify your code accordingly!

While working on the Rustlings exercises, it is recommended to read [The Rust Programming Language (The Rust Book)](https://kaisery.github.io/trpl-zh-cn/) (a community Chinese translation; original: [The Rust Book](https://doc.rust-lang.org/book/)), the most comprehensive resource for learning Rust 📚️
