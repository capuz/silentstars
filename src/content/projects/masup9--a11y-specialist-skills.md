# a11y-specialist-skills

[日本語版 (Japanese)](https://github.com/masuP9/a11y-specialist-skills/blob/HEAD/README.ja.md)

Accessibility specialist skills plugin for [Claude Code](https://claude.ai/claude-code) and [Codex](https://developers.openai.com/codex/).

Provides accessibility review skills based on WCAG 2.2 & WAI-ARIA APG.

## Skills

| Skill | Description |
|-------|-------------|
| [reviewing-a11y](https://github.com/masuP9/a11y-specialist-skills/blob/HEAD/skills/reviewing-a11y/) | Accessibility review for web pages, component implementations, design mockups, and specifications |
| [auditing-wcag](https://github.com/masuP9/a11y-specialist-skills/blob/HEAD/skills/auditing-wcag/) | Systematic WCAG 2.2 AA conformance auditing with automated test scripts |
| [planning-wcag-audit](https://github.com/masuP9/a11y-specialist-skills/blob/HEAD/skills/planning-wcag-audit/) | WCAG audit planning based on WAIC guidelines (page selection, test methods) |
| [planning-a11y-improvement](https://github.com/masuP9/a11y-specialist-skills/blob/HEAD/skills/planning-a11y-improvement/) | Accessibility improvement planning with maturity assessment, roadmap, KPI design |
