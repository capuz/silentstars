## Quick Start
1. Download the [latest version](https://github.com/zhugecaomao/ALTRun/releases/latest) and extract it to any folder; or install [AutoHotkey v2](https://www.autohotkey.com/) and directly run `ALTRun.ahk` from the source code
2. Press `Alt+Space` to bring up the search window, type a name, and press `Enter` to open
3. Press `Ctrl+,` to open Preferences, modify hotkeys, themes, indexing scope, etc.

Portable and green, no registry writes: settings are saved in `ALTRun.json` in the program directory.

**Upgrading from older versions**: Exit the old version, extract the new version to the original folder to replace `ALTRun.exe`, and run it again. On first run, it automatically imports the old `ALTRun.ini` (settings, custom commands, hotkeys), and the original file remains…
