## What it does

A NovelAI image stores the prompt, each character, the negative prompt, and all parameters from when it was made. NovelAI Prompt Studio reads them out so you can understand, organize, and edit them locally, then generate a new version with your own NovelAI account. Where each version came from and what changed are recorded automatically, and generated images go into the image library automatically.

| Read | Organize | Generate | Keep |
| --- | --- | --- | --- |
| Drag in, paste, or open a file; recognizes V4, V4.5, V5 | Prompts shown in blocks; text can be edited directly, like on a webpage | Start from this image's parameters and know the cost before generating | Generated images go into the image library automatically, one group per work |
| Separates what you wrote yourself from what NovelAI added automatically | Over 50,000 built-in Chinese translations for offline translation and categorization | Queues, random pools, inpainting, outpainting, director tools | Search, filter, favorite collections, export and share original images |
