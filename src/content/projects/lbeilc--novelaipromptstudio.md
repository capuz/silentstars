## What it can do

A NovelAI image stores the prompt, every character, the negative prompt, and all the parameters from when it was made. NovelAI Prompt Studio reads them out so you can understand, organize, and edit them locally, then generate a new version with your own NovelAI account. Where each version came from and what changed are recorded automatically, and generated images go into the image library automatically.

| Read out | Organize | Generate | Keep |
| --- | --- | --- | --- |
| Drag in, paste, or open files; recognizes V4, V4.5, V5 | Prompts shown as blocks, and you can edit text directly like on a web page | Starts from this image's parameters, so you know the cost before generating | Generated images go into the image library automatically, one group per work |
| Separates what you wrote yourself from what NovelAI added automatically | Over 50,000 built-in Chinese translations, offline translation and classification | Queues, random pools, inpainting, outpainting, director tools | Search, filter, collections, export and share original images |
