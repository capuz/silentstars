# Devcon/nect Monorepo

This is the main repository for events organized by the Ethereum Foundation

- [Devcon](https://devcon.org/) - the Ethereum conference for developers, thinkers, and makers.
- [Devconnect](https://devconnect.org/) - a week-long gathering of independent Ethereum events to learn, share, and make progress together.

## Projects

Active:

- [devcon](https://github.com/efdevcon/monorepo/blob/HEAD/devcon/README.md) - main Devcon website @ [devcon.org](https://devcon.org/)
- [devcon-api](https://github.com/efdevcon/monorepo/blob/HEAD/devcon-api/README.md) - API for all Devcon-related apps @ [api.devcon.org](https://api.devcon.org/)
- [event-app](https://github.com/efdevcon/monorepo/blob/HEAD/event-app/README.md) - offline-first PWA for Devcon 8 (successor to devcon-app)
- [archive](https://github.com/efdevcon/monorepo/blob/HEAD/archive/README.md) - Devcon video archive @ [archive.devcon.org](https://archive.devcon.org/)
- [lib](https://github.com/efdevcon/monorepo/blob/HEAD/lib/README.md) - shared components for all projects
- [data](https://github.com/efdevcon/monorepo/blob/HEAD/devcon-api/data) - all Devcon data, recorded talks, sessions, speaker info, etc.
