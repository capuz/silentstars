# Metasequoia IME

Metasequoia IME (MSIME) is a multi-platform Chinese input method for Android, iOS, macOS, Linux, Windows, and HarmonyOS. Each of the six platforms has its own native input method host; all connect to the same shared input runtime and the same React settings interface; the React management interface calls general Rust business libraries through Tauri; the input algorithm is provided by msime-engine.

Project homepage: [msime.app](https://msime.app/) · [GitHub repository](https://github.com/metasequoiaime/msime) · [Contributors](https://github.com/metasequoiaime/msime/graphs/contributors) · [Report issues](https://github.com/metasequoiaime/msime/issues)

## Star History

> **About the name**: MSIME is short for Metasequoia IME (Metasequoia Input Method), unrelated to Microsoft IME and has no association with Microsoft. The `msime` in code, package names, and repository names all have this meaning. The `shuangpin_profile: microsoft` in settings is the "Microsoft Shuangpin" scheme, one of four key layout schemes alongside Xiaohong, Ziran, and Shoudo, for users accustomed to that layout, and similarly represents no association.
