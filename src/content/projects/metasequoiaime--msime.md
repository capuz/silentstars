# Metasequoia IME

Metasequoia IME (MSIME) is a multi-platform Chinese input method for Android, iOS, macOS, Linux, Windows, and HarmonyOS. Each of the six platforms has its own native input method host, all connecting to the same shared input runtime and the same React settings interface; the React management interface calls a general Rust business library through Tauri; the input algorithm is provided by msime-engine.

Project homepage: [msime.app](https://msime.app/) · [GitHub repository](https://github.com/metasequoiaime/msime) · [Contributors](https://github.com/metasequoiaime/msime/graphs/contributors) · [Issue feedback](https://github.com/metasequoiaime/msime/issues)

> **About the name**: MSIME is an abbreviation of Metasequoia IME (Metasequoia Input Method), unrelated to Microsoft IME and has no association with Microsoft. The code, package name, and repository name use `msime` with this meaning exclusively. The `shuangpin_profile: microsoft` in settings is the "Microsoft Shuangpin" scheme, one of four key position schemes alongside Xiaohezi, Ziran Code, and Shoudo, for users accustomed to that key layout, and similarly does not represent any association.…
