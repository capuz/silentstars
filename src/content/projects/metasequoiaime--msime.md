# Metasequoia IME

Metasequoia IME (MSIME) is a multi-platform Chinese input method for Android, iOS, macOS, Linux, Windows, and HarmonyOS. The six platforms each have their own native input method hosts, all connected to the same shared input runtime and the same React settings interface; the React management interface calls ordinary Rust business libraries through Tauri; the input algorithm is provided by msime-engine.

Project homepage: [msime.app](https://msime.app/) · [GitHub repository](https://github.com/metasequoiaime/msime) · [Contributors](https://github.com/metasequoiaime/msime/graphs/contributors) · [Issue feedback](https://github.com/metasequoiaime/msime/issues)
