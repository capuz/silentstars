# Metasequoia Input Method

Metasequoia Input Method (MSIME) is a multi-platform Chinese input method for Android, iOS, macOS, Linux, Windows, and HarmonyOS. Each of the six platforms has its own native input method host, all connecting to the same shared input runtime and the same React settings interface; the React management interface calls a standard Rust business library through Tauri; the input algorithm is provided by msime-engine.
