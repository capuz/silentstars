## About the Project

Apexsignal delivers a lightweight web experience that runs in a standard browser. It is intended for people who want to use the application online without installing a package designed for a particular operating system.

The repository is built around HTML files, so it can be hosted as a static site, examined locally, or served from a development environment. The hosted version is the quickest option for access, while the repository provides the files needed for local review and deployment.
