# dsh-nahida-theme · Nahida Theme





Swaps the DSH Web GUI to a dendro-green theme based on Nahida from Genshin Impact. The small fish in the sidebar and welcome page become four-leaf clovers, and the primary color, canvas, and sidebar switch to a dendro palette. A rotating blessing line appears below the input box, and a few semi-transparent grass leaves drift across the frame. You can also pick a chat wallpaper (15 bundled) under **Settings → Nahida theme**. The four-leaf-clover button in the bottom-right corner of the chat page opens the same settings page. Chat cards and the input box are flat, single-color, translucent light-green panels (no frosted glass, no border, no glow), with only a very faint four-leaf-clover watermark in the middle, dark-green text, and a DOS-style green underscore caret. Everything is rendered through CSS variables and slots. It does not change the host layout or touch other plugins' DOM, and uninstalling restores everything.
