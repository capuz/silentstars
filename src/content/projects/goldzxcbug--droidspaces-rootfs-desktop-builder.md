# Droidspaces RootFS Automated Build

Builds Debian, Ubuntu, Fedora, or Arch Linux ARM64 RootFS images for Droidspaces on Android via GitHub Actions. You can choose KDE, KDE Mobile, GNOME, Anland Next, Niri, Hyprland, Mango, Denial, or a plain command-line environment, then download the `.tar.xz` and import it into Droidspaces.

**Quick start:** Fork the repository → open `Actions` → run “Build and Publish Droidspaces RootFS” → download the RootFS from `Releases`.

Fixed all-desktop subscription feeds: in Droidspaces’ RootFS repository management, add [Chinese RootFS (GitHub)](https://github.com/Goldzxcbug/Droidspaces-rootfs-Desktop-builder/releases/download/droidspaces-rootfs-all-wayland/rootfs_zh.json), [Chinese RootFS (CNB)](https://cnb.cool/goldzxcbug/droidspaces-package/-/releases/download/droidspaces-rootfs-all-wayland/rootfs_zh.json), or [English RootFS (GitHub)](https://github.com/Goldzxcbug/Droidspaces-rootfs-Desktop-builder/releases/download/droidspaces-rootfs-all-wayland/rootfs_en.json).
