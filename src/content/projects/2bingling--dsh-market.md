## Two Forms

The DSH ecosystem is growing extremely fast, and plugins and skills are scattered across GitHub —— **it's hard to know which ones are good, how to install them, or how to combine them into a working environment**. DSH Market brings them together on one platform and offers two ways to use them:

| | <img src="https://raw.githubusercontent.com/2BingLing/dsh-market/HEAD/assets/readme/logo-web.svg" width="26" alt="Web Logo"> **Web version** (live) | <img src="https://raw.githubusercontent.com/2BingLing/dsh-market/HEAD/assets/readme/logo-plugin.svg" width="26" alt="Plugin Logo"> **DSH plugin version** (development complete) |
|---|---|---|
| **Location** | Browser · GitHub Pages static site | DSH sidebar · cordis plugin |
| **Purpose** | Discovery and evaluation | Installation and management |
| **Content** | Plugins (cordis/skill) + bundle section (ecosystem content market) | 5-tab panel · one-click install · beginner recommendations · personalized recommendations · scenario recommendations · AI agent install (see [DSH plugin version](#dsh-插件版)) + bundle tab |
