## Two Forms

The DSH ecosystem is growing extremely fast, and plugins and skills are scattered across GitHub — **it's hard to know which are good, how to install them, and how to combine them into a working environment**. DSH Market gathers them on one platform and offers two entry points:

| | <img src="https://raw.githubusercontent.com/2BingLing/dsh-market/HEAD/assets/readme/logo-web.svg" width="26" alt="Web 版 Logo"> **Web version** (live) | <img src="https://raw.githubusercontent.com/2BingLing/dsh-market/HEAD/assets/readme/logo-plugin.svg" width="26" alt="插件版 Logo"> **DSH plugin version** (development complete) |
|---|---|---|
| **Location** | Browser · GitHub Pages static site | DSH sidebar · cordis plugin |
| **Purpose** | Discovery and evaluation | Installation and management |
| **Content** | Plugins (cordis/skill) + bundle section (ecosystem content market) | 5-tab panel · one-click install · beginner recommendations · personalized recommendations · scenario recommendations · AI agent install (see [DSH plugin version](#dsh-插件版)) + bundle tab |
| **Installation** | Zero install, open in browser and use | `npx @deepseek-ai/dsh plugin --profile web add @dsh-market/plugin` |…
