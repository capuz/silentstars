# 🐈‍⬛ KuroCat

> 🌐 **Official website & online web demo / high-speed download in China**: [**https://qianyi.one/kurocat**](https://qianyi.one/kurocat)

A lightweight, transparent, always-on-top desktop typing cat companion for **Windows (Win11/10 & Win7 SP1) / macOS (10.15+ Apple Silicon & Intel) / Linux (Galaxy Kylin (KylinOS) / Ubuntu / UOS)** (out of the box includes **6 hand-drawn cat skins + 🐳 BigFish (whale-girl)**: classic little black cat, warm milk-tea ragdoll cat, big orange cat, calico cat, cow cat, Siamese cat, and BigFish; supports **automatic eye-closing / hand-covering when typing passwords to prevent peeking**, and natively includes an **MCP protocol server** so you can customize or add more of your own cats with a single AI sentence!), built on **Tauri v2 (Rust global native hooks + built-in MCP engine + HTML5 Canvas 2D)**. Single-file, lightweight and low-resource, with zero external runtime dependencies.
