# Symaira EraseMe

> **Accepted product direction — implementation pending:** EraseMe remains an independent privacy product. Browse/Operate becoming optional Brain modules and credential UI moving to Brain must not introduce a mandatory Brain dependency into privacy workflows. See [PB-2026-09-09](https://github.com/danieljustus/symaira-eraseme/blob/HEAD/docs/product-boundaries.md).

Symaira EraseMe helps you exercise your GDPR/CCPA right to erasure against
data brokers. It is a local-first Rust CLI with a native SwiftUI macOS app and
an authenticated MCP JSON-RPC interface.
