# DeepSeek Code Agent v1.5

  <strong>🤖 AI desktop assistant based on WEB browser</strong>
  <br>
  Embedded with rich tools, it completes complex tasks such as file editing, code diagnosis, multi-Agent collaboration, and TTS voice reading through dialogue.
</p>

</p>

## ✨ Core Features

- **🧠 Multi-Agent Collaboration**: Multiple AI assistants can be created to collaborate, sending messages to each other to execute tasks, forming an efficient collaborative pipeline.
- **📊 Context Layer Management**: Management of dialogue, tools, summaries, etc., with real-time visualization of monitoring at each layer, fully controlling the distribution of token usage.
- **⚡ KV Cache Optimization**: Fully utilize DeepSeek prefix caching to effectively reduce usage costs.
- **🔒 Encrypted Storage**: Dialogue data is saved encrypted to ensure privacy and security.
- **🛡️ ACL Anti-Tampering**: Prevents project files from being accidentally tampered with.
- **🔊 TTS Voice Reading**: AI responses are broadcasted in real-time voice, supporting edge-tts (free, high quality, multiple tones), with independent on/off switches for each session.
