## About

**SVL (Stardew Valley Launcher)** is a full-featured launcher and mod manager for Stardew Valley. Built on Avalonia UI and .NET 10, it provides a modern cross-platform desktop experience that makes it easy to manage game instances, install and organize mods, integrate NexusMods / CurseForge downloads, and create and share modpacks.

## Feature Highlights

### 🎮 Game Launching

- Automatically detects Stardew Valley install paths (Steam / GOG)
- Multi-game instance management with version isolation
- SMAPI auto-detection, installation, and version management
- Supports launching in vanilla and mod modes
- Custom window titles and launch arguments
- Launcher self-update

### 📦 Mod Management

- Install mods from ZIP files or folders
- One-click enable / disable / uninstall
- Smart dependency resolution (topological sorting + cycle detection)
- Conflict detection (duplicate IDs, file conflicts, dependency conflicts)
- Mod details view (version, author, description, dependency relationships, file list)
- Batch mod update checks
- Community translation support (GitHub + Gitee dual sources)
