## About

This project turns a personal portfolio into a nostalgic nod to Counter-Strike 1.6, one of the most legendary multiplayer shooters. By leveraging the cs16 CSS library, the site mimics classic game interface elements such as weapon selection menus, health bars, and the iconic green-on-black terminal aesthetic. Visitors can explore work samples and project details while immersed in the visual style of early 2000s PC gaming.

The portfolio relies solely on HTML and CSS, keeping it lightweight and quick to load. The design recreates the Counter-Strike 1.6 user interface without needing external game assets or JavaScript frameworks. Each page section is styled to resemble in-game menus, complete with custom scrollbars, buttons, and typography that match the original Half-Life engine font system.
