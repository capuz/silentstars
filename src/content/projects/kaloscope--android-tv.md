This is a native TV client for the [Kaloscope](https://github.com/kaloscope/kaloscope) project, designed for Android TV devices that use remote controls only.
The client connects to a server deployed by the user, providing media library browsing, network resource search, and TV-side video playback, image and text reading capabilities.

This project does not include a server and does not provide local media management services. Before using it, you need to prepare a server that the client can access.
