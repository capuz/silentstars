This is a native TV client for the [Kaloscope](https://github.com/kaloscope/kaloscope) project, designed for Android TV devices that operate using only remote controls.
The client connects to a server deployed by the user and provides media library browsing, network resource searching, and TV-side video playback, image and text reading capabilities.

This project does not include a server component and does not provide local media management services. Before use, you need to prepare a server that the client can access.

- Manage multiple servers and save login status separately for each
- Browse recent viewing history, media libraries,…
