## Quick Start

Go to [Releases](https://github.com/yuexps/Antigravity-Hans/blob/HEAD/../../releases) and download the single-file build for your platform to run it;

Untested latest builds can be downloaded from [GitHub Actions Artifacts](https://github.com/yuexps/Antigravity-Hans/actions/workflows/test.yml).

- **Windows**: Double-click `antigravity-hans-windows-amd64.exe` and select the desired mode in the interactive menu.
- **macOS**:
  ```bash
  chmod +x antigravity-hans-macos-*
  ./antigravity-hans-macos-arm64  # Apple Silicon
  ./antigravity-hans-macos-amd64  # Intel
  ```
- **Linux** (x64 / ARM64, compatible with mainstream installation methods such as `.deb` / `.rpm` / Arch AUR `/opt/Antigravity` / official `.tar.gz`):
  ```bash
  chmod +x antigravity-hans-linux-*
  ./antigravity-hans-linux-amd64  # x64
  ./antigravity-hans-linux-arm64  # ARM64
  ```
