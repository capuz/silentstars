# b3os (b3rys team os)

**Multiple AIs as one team.**
_An AI team operating system for human-led multi-agent work._

> 🌐 **한국어** · [English README](https://github.com/b3rys/b3rys-team-os/blob/HEAD/README.en.md)

---

> ### b3os is an **AI team operating system** that combines *organization responsibility loop* with *agent execution loop*.

In short, **b3os**. It operates multiple AI agents as a single team. Create team members, assign work as naturally as chatting on Telegram or Slack, and see who's responsible for what on **one dashboard**.

**The key is not the number of agents. The key is the environment that makes AI team members work as one team.**

```text
Direction → Assignment → Task Card → Execution → Validation → Report → Completion
```

> ⚠️ **Install only on your personal device.** The dashboard and API are local-only (`127.0.0.1`) and **have no app-level authentication.** If you need to expose it on a public or shared server, you must place **edge authentication like Cloudflare Access in front.** → [Opening the dashboard via domain](https://github.com/b3rys/b3rys-team-os/blob/HEAD/docs/public-dashboard.md)
