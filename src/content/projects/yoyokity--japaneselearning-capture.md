# Japanese Learning Capture

An Electron-based tool for scraping and managing Japanese learning materials.

## 📘 Usage

- Batch scrape metadata for video materials
- Manage locally scraped data

## ⚠️ Notes

- Before the first run, make sure the local scraping directory is configured correctly
- Some translation features depend on external AI APIs or local models

## 📢 Disclaimer

- This project does not provide any video downloads; it only manages local resources
- This project and its outputs are for technical and academic exchange and Electron performance testing only
- Permanently open source and free

## 🛠️ Build

Just [install vp](https://viteplus.dev/guide/); Node.js and pnpm will be set up automatically according to the project's declarations.

```bash
vp install      # Install dependencies
vp run dev      # Start the development environment
vp run package  # Build and package into out/
```

For the release process, see `AGENTS.md`.
