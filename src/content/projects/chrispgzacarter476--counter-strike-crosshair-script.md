## What It Does

Counter-Strike Crosshair Randomiser gives players a quick way to discover new crosshair styles without changing every setting by hand. Each generated result provides a random crosshair code that can be copied, tested, and saved for later use.

The browser tool works with crosshair codes for both CS:GO and CS2. Its streamlined interface is intended for quick experiments, making it easy to move through multiple possibilities and compare different in-game appearances.
