# haxsd byok

**Use your own configured models in Cursor, Devin, Codex in the ChatGPT client, and Claude Code CLI and Claude Desktop: a local model gateway with a built-in model library, takeover status, and call logs.**

[Download Windows installer](https://github.com/haxsd/haxsd-byok/releases/latest) · [User guide](https://github.com/haxsd/haxsd-byok/blob/HEAD/docs/user-guide.md) · [Troubleshooting](https://github.com/haxsd/haxsd-byok/blob/HEAD/docs/troubleshooting.md) · Simplified Chinese · [English](https://github.com/haxsd/haxsd-byok/blob/HEAD/README-EN.md) · [Russian](https://github.com/haxsd/haxsd-byok/blob/HEAD/README-RU.md)

## Why use it

- **Keep your workflow**: continue using the interfaces and habits of Cursor, Devin, Codex, Claude Code CLI, and Claude Desktop, and only swap model inference for the service you configure.
- **Manage models yourself**: endpoints, API keys, and model IDs are stored locally. Cursor also supports three model sources (official, local, and mixed), and official and self-configured models can be available at the same time.
