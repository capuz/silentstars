# ROS/ROS2 Examples

This repository contains ROS/ROS2 examples for environment setup, tutorials, and people and vehicles.

## Environment Setup

Run [`serve.bat`](https://github.com/OpenHUTB/ros2/blob/master/serve.bat) (which runs `mkdocs serve`; any changes must also be verified by running this script to check the modified content on [the web page](http://127.0.0.1:8000/)). It will open a browser showing the homepage. For details, see [serve.bat](https://github.com/OpenHUTB/.github/blob/master/serve.bat). For documentation writing conventions, see the homepage of the [doc](https://github.com/OpenHUTB/doc) repository.
