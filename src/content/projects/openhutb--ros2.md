# ROS/ROS2 Examples

This repository contains ROS/ROS2 examples covering environment setup, tutorials, people, and vehicles.

## Environment Setup

Run [`serve.bat`](https://github.com/OpenHUTB/ros2/blob/master/serve.bat) (which runs `mkdocs serve`; changes you make must also be checked by running this script and verifying the modified content on [the web page](http://127.0.0.1:8000/)). This opens a browser showing the home page. For details, see [serve.bat](https://github.com/OpenHUTB/.github/blob/master/serve.bat). For documentation writing conventions, see the home page of the [doc](https://github.com/OpenHUTB/doc) repository.

## Notes

* Before submitting a Pull Request, check the following:
    * **Must** use **`mkdocs serve --livereload`** to check that the web page shows the intended changes before submitting
    * The Pull Request title and commit messages must not be arbitrary; they must explain why the change was made, not just what was changed
    * Check that the content under "File changed" on the Pull Request page is the intended change
    * Check whether the Pull Request page shows a red warning (conflicts); if it does, merge the latest repository changes before…
