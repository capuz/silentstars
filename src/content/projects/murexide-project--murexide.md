# Murexide

A third-party client for Yunhu, designed with Material 3.

# Declaration
This project (Murexide) is developed purely for personal interest and is only for learning and testing purposes. Please delete it within 24 hours after downloading. All APIs are collected from the official website, and no cracked content is provided.
