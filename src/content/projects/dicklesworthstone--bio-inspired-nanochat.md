# Bio-Inspired Nanochat

> **"What if a Transformer had a metabolism?"**

This research fork of Nanochat adds state to Transformer attention. During cached generation, release and recovery change the attention bias applied to individual keys. The standard chat engine keeps Hebbian writes off. Training can enable fast-weight updates and an expert split/merge controller.
