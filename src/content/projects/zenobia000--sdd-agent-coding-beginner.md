# Vibe Coding × SDD × AI Development Practical Bootcamp

Two days, 14 hours. **Day 1: experience the works in an independent folder, converging to a PRD; Day 2: use the LeaveBot blank project to complete the form leave feature with specifications, general skills, and tests.**

| | Main track | Takeaways for students |
|---|---|---|
| D1 | Website replication, tarot card drawing, scroll animation; choose one to do, add context for comparison, operation and repair | First version and comparison notes, simplified PRD |
| D2 | Brief / PRD / SRS → Archify process → minimal design and TC → two main-track tickets → TDD → changes and delivery | Executable form, SQLite, tests and manual evidence |

**Open the [handbook website](https://github.com/Zenobia000/SDD-agent-coding-beginner/blob/HEAD/handbook/site/index.html)**. When downloading, keep the entire `handbook/site/` folder.
On Day 2, students fork the `main` branch of [leavebot-bootcamp](https://github.com/Zenobia000/leavebot-bootcamp); only copying main is needed. Checkpoints are obtained from the instructor's upstream. The main track does not require a model API key; LLM parsing is an extension.
