# Breath of the Wild · Interactive Map

**[English](https://github.com/yalincc/BOTWmap/blob/HEAD/README_EN.md) | Simplified Chinese**

A multi-layer interactive map for The Legend of Zelda: Breath of the Wild in Simplified Chinese · Collection progress tracking · Real-time character navigation

　

## What is this

A fully Chinese interactive map: all markers use the official Simplified Chinese names; multiple layers can be displayed at once, with collection progress tracking and custom markers. Optionally pair it with **xnavi** to show your character's position in real time while the game is running. It is a pure static page: open and use, with no server and no installation required.

## Direct use

| Method | Action |
|---|---|
| **Online version** | Open <https://botw.yalin.site/> |
| Local use | Open `app/index.html` in a browser (tiles, icons, and data are all local, so it works offline) |

Completion progress, layer selection, and custom markers are saved automatically in the browser, so they are not lost when the page is closed.
