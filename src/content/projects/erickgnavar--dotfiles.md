# Dotfiles

These are my config files for the tools I use:

## Emacs

Requires emacs 26 because it uses native line numbers. Go to `.emacs.d` folder to check the config.

Tested on MacOS Mojave

## Vim

I use vim for quick edits, check out the cconf [here](https://github.com/erickgnavar/dotfiles/blob/HEAD/.vimrc)

## Alacrity

A multiplatform terminal emulator. It's simple and configurable by a yaml [config](https://github.com/erickgnavar/dotfiles/blob/HEAD/.alacritty.yml) file.

## Tmux

A terminal multiplexer, easy to handle panes, splitted windows, sessions, etc. 

## ZSH

Go to `zsh` folder to check the config.
