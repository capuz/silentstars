# Goonami

Goonami is a partial rewrite in Golang of the
[Tsunami project](https://github.com/google/tsunami-security-scanner) with an
emphasis on improving the software fingerprinting phase.

## Contributing

Goonami is a work in progress and as such the project does not accept
contributions for now.

[Contribution guidelines](https://github.com/google/goonami-scanner/blob/HEAD/CONTRIBUTING.md)
