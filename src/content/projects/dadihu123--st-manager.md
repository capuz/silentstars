# ST Manager

> A local resource workbench for SillyTavern creators: centrally manage character cards, world books, chat logs, presets, extension scripts, and visual themes.

## Project Positioning

ST Manager is a SillyTavern resource manager that primarily uses local files, supplemented by SQLite metadata. It is suitable for individual creator workflows that need to maintain a large number of character cards, world books, chats, presets, and extension resources long-term.

The project provides unified browsing, searching, filtering, editing, previewing, importing, exporting, syncing, and recovery entry points. Resources are still saved in local directories, and the manager is only responsible for indexing, maintaining interface data, and providing workbench capabilities.
