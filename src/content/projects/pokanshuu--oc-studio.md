# OC Studio

A local-first workbench for original characters (OCs) and worldbuilding.

Current version: **v0.19.1-beta**

---

## Features

**Overview (home)**
Opening the app shows the world overview: world name and synopsis, counts of characters, events, countries, and entries, main characters, and recent updates. The "Home" entry at the top of the sidebar always returns you here.

**Characters / Events / Countries**
Full character info cards (synopsis, biography, portrait, birthday as year/month/day). Events support time spans and negative years. Countries can be linked to characters and events.

**Worldbuilding encyclopedia**
Tree-structured entry editor with `[[` internal links and `@` references for linking lore across entries. The hierarchy is the directory structure, so exporting the site turns it directly into chapters.

**Timeline**
Year, decade, fifty-year, and century aggregate views. Events are shown as rectangular bars and can be dragged to adjust timing. Character birthdays automatically become "X born" nodes. Period bars mark historical eras, with 6 selectable colors.
