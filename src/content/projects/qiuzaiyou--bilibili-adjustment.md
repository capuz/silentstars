# 🎬 Bilibili (bilibili.com) Enhancement

> A Bilibili experience enhancement user script mainly for personal use, V3 restructured version.
>
> Because script hosting websites (such as GreasyFork) do not allow uploading obfuscated and minified code, this version is no longer published through script hosting websites, only hosted on a personal server, supporting automatic update checking and popup reminders.

**Current Version: `v3.36.13`** (Last updated `09.24 2026`, changelog see end of document)

---

## ✨ Feature Overview

- **Full Three-Platform Compatibility** — Homepage / Playback page (regular videos + anime series) / Dynamics page all have corresponding enhancements
- **Full Browser Compatibility** — Compatible with mainstream browsers like Chrome, Firefox (Tampermonkey / Violentmonkey / ScriptCat)
- **In-Page Settings Panel** — No need to rely on the script manager menu, modify settings directly in the popup window, changes take effect immediately
- **Theme Appearance** — Popups and enhanced interface support "Bilibili Night" dark theme, or "Follow Bilibili" to automatically switch between official light/dark themes as Bilibili night mode changes
