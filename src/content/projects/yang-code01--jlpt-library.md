# Personal Workbench

An offline-capable personal workbench with two learning tracks, Japanese (JLPT N1–N5) and English (word frequency 1k–4k), plus AI research reports and documentation and downloads for self-built tools. The home page is organized into three sections: **Language Learning**, **Research Reports**, and **Tool Development**. There is no build step and no external dependencies; it works by opening `file://` directly.

🌐 **Online browsing**: https://Yang-Code01.github.io/jlpt-library/

## Modules

The portal `index.html` is the unified entry point for all modules, built as a workbench shell: a **180px persistent navigation sidebar on the left** (4 sections, plus 11 modules within the Language Learning section, which can be collapsed) + a **48px top bar** (section name / module type filter / search box) + **single-column cards**.
The right column of each card shows learning progress (`Viewed 12 / 168`). The denominator comes from `assets/units.js`, generated by `tools/portal.mjs`, and the numerator comes from browser-local progress. Japanese and English appear as two sub-group headings within the Language Learning section, and **there is no longer a language toggle**…
