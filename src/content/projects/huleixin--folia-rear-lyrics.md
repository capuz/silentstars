# Folia Xiaomi Rear-Screen Lyrics

Test build of Folia Android adapted for the Xiaomi 17 Pro. It keeps Folia's lyrics styles, themes and animations. The background fills the rear screen, and the main readable content sits on the right, away from the camera.

## r245 Lightweight Mobile UI Test Build

- [Direct download r245 APK](https://github.com/huleixin/folia-rear-lyrics/releases/download/mobile-r245/Folia-Android-mobile-r245-debug.apk)
- [r245 release notes](https://github.com/huleixin/folia-rear-lyrics/releases/tag/mobile-r245)

Adds a lightweight home page, playlist/album and artist pages, using virtualized lists and an independently updating bottom player bar. It keeps the original lyrics stage style, online playback and rear-screen core. Android uses the new UI by default, and you can still switch back to the old UI in settings.

Unofficial debug test build, versionCode `245`, version `0.7.20-android.194-rear.r245`. It can be installed over r244 with the same signature; do not uninstall first. Passed automated verification; not yet tested on a real device.
