# mcpcat

An MCP (Model Context Protocol) aggregation platform that supports unified management and operation of multiple MCP protocols.

---

## Features

- 🔌 Supports multiple MCP protocols:
  - STDIO (default, for local tools)
  - Streamable HTTP (recommended for web services)
  - SSE (traditional web transport)
- 🧩 Supports openapi3 configuration, converting directly to the MCP protocol
- 📊 Unified MCP service management interface
- WeCom (Enterprise WeChat) self-built app web login, sharing permissions and member management with Feishu and API Key
