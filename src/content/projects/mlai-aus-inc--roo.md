# Roo

Roo is MLAI's Slack-facing AI agent service. The active FastAPI application,
tests, skills, runtime configuration, and Docker files live under
[`roo-standalone/`](https://github.com/MLAI-AUS-Inc/roo/blob/HEAD/roo-standalone/).

Roo integrates with Slack, `mlai-backend`, Linear, content services, and
configured AI providers. It supports separate public and administrative
surfaces; their credentials and permissions must remain isolated.

See [verified MLAI Chat DMs](https://github.com/MLAI-AUS-Inc/roo/blob/HEAD/docs/mlai-chat-dms.md) for private message routing,
points authorization, and the backend-first deployment order.

For the wider platform map, start with
[`mlai-engineering`](https://github.com/MLAI-AUS-Inc/mlai-engineering). AI
coding agents must read [`.agents/AGENTS.md`](https://github.com/MLAI-AUS-Inc/roo/blob/HEAD/.agents/AGENTS.md). Repository
quality work is recorded in the [improvement log](https://github.com/MLAI-AUS-Inc/roo/blob/HEAD/IMPROVEMENT_LOG.md).
