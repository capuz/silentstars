## Install

| Windows | macOS | Linux | Android |
|---|---|---|---|
| `.exe` | `.dmg` (Universal) | `.deb` / `.AppImage` | `.apk` |

**Windows (winget)**

```
winget install Hitalin.NoteDeck
```

**Arch Linux (AUR)**

```bash
yay -S misskey-notedeck-bin
```

**Nix Flake**

```bash
nix run github:hitalin/notedeck
```
