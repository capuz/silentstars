# NetDeploy AI

**A web-based tool for managing VPS servers and quickly deploying common open-source projects.**

Add servers, check SSH connections, choose software, and confirm deployments. The entire process can be completed in your browser.

> **Currently an Alpha test version.** Please try it first on a VPS that you can back up or reinstall.

[📖 Online documentation](https://slobys.github.io/netdeploy-ai/) · [🚀 Installation guide](https://slobys.github.io/netdeploy-ai/installation.html) · [❓ FAQ](https://slobys.github.io/netdeploy-ai/troubleshooting.html) · [💬 Report issues](https://github.com/slobys/netdeploy-ai/issues)

## Main features

- **VPS management**: Add servers, connect via SSH password or key, and verify host fingerprints.
- **Guided deployment**: Automatically checks the runtime environment, executes only after the installation plan is confirmed, and shows progress and logs.
- **HTTPS certificates**: 3X-UI and S-UI can automatically request IP or domain certificates, or delegate unified HTTPS management to NPM.
- **Port management**: Manage UFW rules on the VPS, with entry points to common cloud provider security groups.
