## Project Positioning

PayIncus is a commercial delivery platform for hosting businesses based on Incus. It integrates package sales, balance deduction, instance creation, NAT networking, bandwidth and traffic management, user self-service backend, management backend, payment callbacks, ticket notifications, host machine Agent, resource risk control, extension center, theme system, Public API, and online upgrades into a single auditable process.

The public documentation, source code, releases, extension market, and theme market for PayIncus are based on the current repository:

- Project Repository: <https://github.com/VipMaxxxx/payincus>
- Documentation Site: <https://payincus.com>
- Online Demo: <https://payincus.com/demo>
- Extension Market: <https://payincus.com/plugins/market>
- API Reference: <https://payincus.com/api/overview>
- Telegram: <https://t.me/Payincus>

## Core Capabilities

- Instance Delivery: Create and manage LXC / KVM instances based on Incus, supporting NAT, IPv6, images, packages, plans, storage pools,…
