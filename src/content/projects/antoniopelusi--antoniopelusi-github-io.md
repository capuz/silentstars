# antoniopelusi.github.io

Static site and CV (EN/IT). Pages are generated by a single Node script with no dependencies; the generated HTML is committed.

## Commands

```
make build   # generate the four pages
make run     # build and serve on http://localhost:8000
```

Requires Node 22 (`.nvmrc`) and Python 3 for `make run`.

## Structure

```
tools/build.mjs          generator
assets/data/             config.json, en.json, it.json
assets/css/              base.css, site.css, cv.css
assets/js/               site.js, cv.js
assets/icons/            site/, cv/, favicon/ (includes site.webmanifest)
assets/fonts/            Roboto
index.html               generated: site (EN)
it/index.html            generated: site (IT)
cv/index.html            generated: CV (EN)
cv/it/index.html         generated: CV (IT)
404.html                 standalone
humans.txt
robots.txt
sitemap.xml
```

## Editing

Everything the build uses lives in three JSON files in `assets/data/`. After any change, run `make build`.

- `config.json`: everything that does not depend on the language.
  - `site`: name, URL, app title, repository, Search Console token, languages, assets path, fonts, title and description…
