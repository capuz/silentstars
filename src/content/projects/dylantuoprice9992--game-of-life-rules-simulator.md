## Overview

Conway's Game of Life Extended Rules Canvas is a browser-based cellular automaton playground built around an interactive HTML5 Canvas grid. Create an initial arrangement, run it through successive generations, and see how birth and survival rules affect the resulting behavior.

The simulator supports both well-known patterns and user-defined rule sets. Presets, direct cell editing, variable playback speed, and continuously updated statistics provide a convenient way to study patterns and compare rules including Conway, HighLife, and Maze.
