> [!TIP]
> **Building a multi-package system?** This template is optimized for single-library development. For large-scale monorepos with multiple packages, internal CLIs, and automatic sync, check out [**Turboforge**](https://github.com/turboforge-dev/turboforge) — the Monorepo Operating System.

> [Explore featured packages built with this template.](https://github.com/react18-tools/turborepo-template/blob/HEAD/FEATURED.md)

> Now it is super easy to use this template. Just run `pnpm create r18` and provide your project name. That's it, we will automatically load the template and initiate rebranding.
