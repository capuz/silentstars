# 悦谱 Dolce

**Chinese** | [English](https://github.com/lodebar2026/dolce/blob/HEAD/README.en.md)

> An open-source tool for editing, reading, typesetting, auditioning, and exporting jianpu and staff notation. Write scores, recognize scores, typeset, listen, and export. It works instantly in the browser and also has Windows / macOS desktop versions. The interface is bilingual (Chinese and English).
