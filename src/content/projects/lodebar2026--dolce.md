# Dolce

**Chinese** | [English](https://github.com/lodebar2026/dolce/blob/HEAD/README.en.md)

> Open-source jianpu and staff notation editing, score recognition and typesetting tool: compose, recognize, typeset, listen, and export. Available in the browser for immediate use, and also available as Windows / macOS desktop versions; interface is bilingual in Chinese and English.

## Quick Start

| | Entry | Description |
| :-: | --- | --- |
| 🌐 | **[Online Use](https://lodebar2026.github.io/dolce/)** | No installation required, open directly in browser |
| 🍎 | **[macOS Version Download](https://github.com/lodebar2026/dolce/releases/latest)**（`.dmg`, Apple Silicon） | First time opening shows 'corrupted' - see [macOS Won't Open](https://github.com/lodebar2026/dolce/blob/HEAD/docs/macOS-打不开.md) |
| 🪟 | **[Windows Version Download](https://github.com/lodebar2026/dolce/releases/latest)**（`x64-setup.exe`） | Installer, Windows 10/11 x64 |

<sub>Four-part jianpu image (《Holy! Holy! Holy!》) after recognition, open 'side-by-side original': the left is the original image, the right is the score typeset as originally, click a note to simultaneously highlight it on both sides.</sub>
