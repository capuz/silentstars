## Getting Started

#### Security setup

- Read the [proxy documentation](https://app.notion.com/p/passcultureapp/Proxyfication-des-outils-du-pass-d1f0da09eafb4158904e9197bbe7c1d4), you may need to add some variable to you .rc file like NIX_SSL_CERT_FILE to avoir certificate error.  
- Install [safe-chain](https://app.notion.com/p/passcultureapp/Installation-de-safe-chain-285ad4e0ff98803bbdf0e12e5add41ae)
- Setup pre-commit hook : `chmod +x ./.githooks/pre-commit && git config --local core.hooksPath ./.githooks`

To be able to install and run the mobile apps (iOS and Android) and web app, you first need to :

- [Setup](https://github.com/pass-culture/pass-culture-app-native/blob/HEAD/doc/installation/setup.md) your environment
- Configure Sentry through [this tutorial](https://github.com/pass-culture/pass-culture-app-native/blob/master/doc/installation/sentry.md#-configure-sentry-cli)
