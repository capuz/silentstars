## 📖 Introduction

**dbVisitor** is a **unified data access foundation** built on the JDBC standard, dedicated to realizing the vision of **“One APIs Access Any DataBase”**. Through its unique **dual-layer adapter architecture**, it breaks the programming barrier between RDBMS and NoSQL, allowing developers to seamlessly operate MySQL, MongoDB, Elasticsearch, and other databases using **the same set of standard APIs**.
dbVisitor does not advocate inventing new syntax to hide differences. Instead, it **manages differences** scientifically through **standardization** and **layered abstraction**, providing Java applications with a general data foundation that offers both convenience and the flexibility of JDBC.
