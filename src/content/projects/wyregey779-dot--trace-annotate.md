# TraceAnnotate

Local media review and temporal video annotation tools for Python.

[English](https://github.com/wyregey779-dot/trace-annotate/blob/HEAD/README.md) · [中文说明](https://github.com/wyregey779-dot/trace-annotate/blob/HEAD/README_CN.md) · [Quickstart](https://github.com/wyregey779-dot/trace-annotate/blob/HEAD/docs/QUICKSTART.md) · [Releases](https://github.com/wyregey779-dot/trace-annotate/releases)

Current preview: [v1.1.0.dev1](https://github.com/wyregey779-dot/trace-annotate/releases/tag/v1.1.0.dev1).
It includes the multi-video workspace, professional JSON and annotated-video exports.
The latest stable release is [v1.0.2](https://github.com/wyregey779-dot/trace-annotate/releases/tag/v1.0.2).

TraceAnnotate supports local media review and temporal annotation. The development version adds general video segments with custom event labels, descriptions, tags and overlapping tracks. The embodied workflow keeps its working/idle intervals, step checks and verdicts. The Python library also provides batched media staging, field-level provenance and asset review helpers.
