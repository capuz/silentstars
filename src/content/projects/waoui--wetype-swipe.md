# WeChat Input Method Swipe Shortcuts (WeType Swipe)

An LSPosed module for the Android version of WeChat input method, allowing swipe shortcuts for 26 letter keys and the `2–9` physical keys on a numeric keypad.

> Current stable version: v1.9.4

## Download

- [Go to GitHub Releases](https://github.com/waoui/WeType-Swipe/releases/latest)
- [Direct download v1.9.4 APK](https://github.com/waoui/WeType-Swipe/releases/download/v1.9.4/WeType_Swipe_LSPosed_v1.9.4.apk)

Please only download official versions from this repository's Releases and verify the SHA-256 on the release page.

## Features

- Select all, cut, copy, paste
- Move to the beginning or end of a paragraph
- Select to the beginning or end of a paragraph
- Disable swipe for specified keys
- Independent mapping and trigger distance for 26 keys and numeric keypad
- QWERTY and numeric keypad layout settings interface
- Supports disabling haptic feedback and hiding desktop icons
- No internet connection, does not collect or save input content
