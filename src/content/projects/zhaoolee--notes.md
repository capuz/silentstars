# Open-source Hammer Notes

| Mobile version support | One-click official account sharing |
| --- | --- |
|  |  |

- A Hammer Notes style exporter with preview and image export supporting **warm white paper**, **late night notes**, **iPhone memo light/dark modes**, and **Bear minimal layout**.
- Can be used to share conversation records with openclaw.
- Perfectly recreates the Hammer Notes web and PC versions, supports multiple notes with categorized storage.
- Support Docker one-click private deployment
- Pure web application, no app installation needed, ready to use
- Support PC and mobile versions, multi-device data sync, supports public network deployment
- Image insertion support.
- One-click paste to official account assistant.
- Support direct export of notes as images, or copy as markdown format for sharing.
- Built-in browser persistence, data won't be lost when closing the page.
- Open source and free, supports private deployment.
- Craftsman spirit infused with AI, tools can be directly called through AI Skill to generate notes.
- Support custom footer branding (clickable to edit)
- API natively supports Hermes Agent, OpenClaw can directly manage notes through skill
