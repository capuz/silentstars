# Engineering Incidents Playbook

> **Reader:** visitor — what this is and whether it's worth taking.

**A catalog of 214 rules for Claude Code and GitHub, where each one grew out of a real breakage.** Covers work with agent windows and the project brief (`CLAUDE.md`), the GitHub pipeline, parallel executors, and auditing. Each entry comes with its history: what broke, how it was discovered, and what it cost.

## Two roles — for external projects and for the family

**For an external project, the catalog provides the rules.** Badges and facts are optional.
