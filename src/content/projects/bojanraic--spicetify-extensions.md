# spicetify-extensions
bojanraic's Spicetify Extensions

## [Private-Session](https://github.com/bojanraic/spicetify-extensions/blob/HEAD/private-session/README.md)

Private Session (PS) is a simple Spicetify extension that will always enable private session.

## [Side-Hide](https://github.com/bojanraic/spicetify-extensions/blob/HEAD/side-hide/README.md)

Side Hide (SH) is a simple Spicetify extension that hides the Spotify Now Playing and Friend Activity Views in the sidebar and associated buttons. Queue and Connect functionality is unchanged. *(For more flexibility, see [SidebarCustomizer](#sidebarcustomizer) below)*

## [YT-Video](https://github.com/bojanraic/spicetify-extensions/blob/HEAD/yt-video/README.md)

YT-Video is a Spicetify extension that adds YouTube video functionality to the player, allowing you to search and watch music videos for Spotify tracks without cookies or tracking. 
NOTE: A YouTube API Key is needed for this extension to work. 

## [Sesh-Stats](https://github.com/bojanraic/spicetify-extensions/blob/HEAD/sesh-stats/README.md)
