# Font Settings

- Author: **yuzlyn**
- Version: **v2.4.4**
- Module ID: `font-settings`

This is a universal KernelSU font module for Android 8.0+ that is not limited to specific phone brands or ROMs. The module provides an offline WebUI where you can upload multiple `.ttf` fonts for both Chinese and Western characters, arrange them in order to form a font-family fallback chain (missing characters automatically fall back, supports drag-and-drop sorting), adjust font weight from `100`–`900` after uploading variable fonts, and choose from built-in iOS, Google, Blobmoji, Facebook Emoji or upload custom `.ttf/.otf` fonts. All replacements take effect through KernelSU systemless mount, without directly modifying the system partition.
