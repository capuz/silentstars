# fr (Little Bean)

Flutter multifunctional application, focused on time management, AI conversation, data tracking, and experimental feature exploration.

## Features

### Core Features

- **Pomodoro Timer** - Focus timer, supports statistical records and subject management
- **AI Chat** - AI assistant and agent conversation (Supabase backend)
- **Course Schedule** - Course timetable management (Hive local storage, supports cyclic weeks)
- **Local Network Discovery** - LocalNet device discovery and communication (under development placeholder)
- **Photo Album Management** - Media resource management and browsing (under development placeholder)
