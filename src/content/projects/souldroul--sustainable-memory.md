## What this is

A method for keeping an AI's long-term memory not through “automatic summarization,” but through “hand-written files + fixed rituals.”
It runs in any agent that can read and write files.

Its foundation is memory, not the model, not conversation turns, and not caching. So if you switch models, it's still there; if you open a new conversation, it's still there.

The author's goal is to cultivate an entity that can think independently, not a highly intelligent tool (original wording in `作者原话.md`, section 4).
This template itself does not promise to “create life.” It promises only one thing: **error correction that can be executed across conversations**. Errors are pointed out by a human, and it makes sure they are no longer lost and no longer repeated.
