Blueking PaaS Platform is an open development platform that enables developers to conveniently and quickly create, develop, deploy, and manage SaaS applications. Its core services include: Developer Center, API Gateway, Unified Login, Blueking Desktop, etc., aiming to help users rapidly and cost-effectively build operations systems and supporting tools that require minimal operations and maintenance.

This project is `PaaS Platform - Developer Center`.

**PaaS Platform Core Services Open Source Projects**

- PaaS Platform - [Developer Center](https://github.com/TencentBlueKing/blueking-paas)
- PaaS Platform - [Blueking API Gateway](https://github.com/TencentBlueKing/blueking-apigateway)
- PaaS Platform - [Unified Login](https://github.com/TencentBlueKing/bk-user)
- PaaS Platform - [Blueking Desktop](https://github.com/TencentBlueKing/blueking-console)
