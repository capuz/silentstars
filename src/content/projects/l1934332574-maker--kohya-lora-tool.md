Puts environment setup, model downloads, tagging, parameter configuration, training, and result viewing into one Windows desktop tool. Suited for training **character, art style, and concept LoRAs**, and also includes video and audio training modes.

## Core Advantages

| Advantage | What you can use directly |
|---|---|
| **Four engines, one workflow** | Choose the model and version first, then get a kohya, musubi, AI Toolkit, or Fizgig recommendation based on your GPU, with the reasoning shown |
| **AI assistant takes part in training directly** | State your goal; the assistant asks follow-up questions to fill in requirements, then calls environment checks, model downloads, project configuration, and training workflows |
| **Less hassle with environments and downloads** | Graphical install and repair, domestic (China) download mirrors, resumable downloads for large files; existing models can be selected |
| **Parameter changes are visible** | Six training presets; parameter changes are shown before applying, with undo and manual adjustment supported |
| **From data preparation to result comparison** | WD14, Chinese / English captions, tag editing, fixed-seed sampling, history…
