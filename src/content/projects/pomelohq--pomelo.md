# Pomelo

Welcome to Pomelo, a native macOS app that gives every branch of a multi-repo project its own running
environment: services, databases and shared infrastructure, next to a code editor, terminals and your AI agent.

---

### Installation

On macOS 14+ with Apple Silicon, [download Pomelo](https://github.com/pomelohq/pomelo/releases/latest), drag it
into Applications and open it. It updates itself. Full docs: [pomelohq.app](https://pomelohq.app).

Other platforms are not yet available.
