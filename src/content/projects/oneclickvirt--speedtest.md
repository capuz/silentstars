# speedtest

Nearby Node Speed Test Module

## Description

- [x] Based on data from [speedtest.net-crawler](https://github.com/spiritLHLS/speedtest.net-CN-ID) and [speedtest.cn-crawler](https://github.com/spiritLHLS/speedtest.cn-CN-ID)
- [x] Developed based on [speedtest-go](https://github.com/showwin/speedtest-go), implemented in Go without the need for shell commands for nearby speed testing
- [x] The main logic is inspired by [ecsspeed](https://github.com/spiritLHLS/ecsspeed)
- [x] Uses the shell command ```speedtest``` for speed testing

## Download speedtest or speedtest-go
