## Separating the Web from specific companies' implementations

Orinium is a browser engine that aims to return the Web to an open runtime environment that does not depend on the implementations or policies of any particular company, and that users and developers can control.

Currently, many browsers depend on Chromium. Chromium is an excellent open-source project, but when a single implementation becomes the de facto standard for the entire Web, it affects the diversity and independence of the Web.

When browser engines concentrate in a single direction, the interpretation of Web standards, the spread of non-standard features, and future technical choices may be largely determined by the judgment of one organization.
