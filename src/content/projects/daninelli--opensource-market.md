# 开源集市 (Open Source Market)

A navigation site for ready-to-use open-source applications, organized by category, for learning, development, and exchange.

- Plain HTML + CSS + vanilla JS, no framework, no build step
- All data lives in `projects.json`. Adding a project only requires editing this one file
- Can be deployed directly to GitHub Pages / Vercel / Netlify / any static server

Live site: <https://daninelli.github.io/opensource-market/>

## Submitting a New Project

No Git knowledge needed, and no files need to be edited.

Open [New issue](https://github.com/Daninelli/opensource-market/issues/new?template=submit.yml), choose the form 「**收录开源项目** (Submit Open-Source Project)」, and fill in four fields: project name, repository URL, top-level category, and a one-sentence description.

After submission, the Action automatically fetches the star count, last update time, license, latest Release, and installation packages from GitHub. Once validation passes, it creates a PR to add the project, which a maintainer reviews and merges. For the detailed process, see [CONTRIBUTING.md](https://github.com/Daninelli/opensource-market/blob/HEAD/CONTRIBUTING.md).
