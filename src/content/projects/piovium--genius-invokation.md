# Genius Invokation TCG Simulator

[中文版](https://github.com/piovium/genius-invokation/blob/HEAD/README.md)  | [English Version](https://github.com/piovium/genius-invokation/blob/HEAD/README.en.md) | [日本語版](https://github.com/piovium/genius-invokation/blob/HEAD/README.jp.md)

You can try it at https://standalone.piovium.org.

## Features of this project

- Fully open source (mainly using AGPLv3.0 or later)
- The core implements the current rules closest to the official settlement rules
- All card definitions up to date
  - Definition format is concise, clear, and easy to read
  - Easy to maintain
- All definitions of old version cards (before balance adjustments)
  - Supports starting games with selected game versions
- Frontend features:
  - Game visualization and local simulation
  - Historical backtracking (replay) and mid-game continuation
  - Game import and export
  - View settlement detail logs
- [Battle platform](https://play.piovium.org) (in public testing)
- Cross-language support
