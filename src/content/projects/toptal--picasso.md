This repository is the home for all of Toptal's reusable UI, split up into distinct monorepo packages distributed through NPM:

- [@toptal/picasso](https://github.com/toptal/picasso/blob/HEAD/packages/picasso/README.md) - core UI building blocks
- [@toptal/picasso-charts](https://github.com/toptal/picasso/blob/HEAD/packages/picasso-charts/README.md) - reusable charts, based on `recharts`
- [@toptal/picasso-forms](https://github.com/toptal/picasso/blob/HEAD/packages/picasso-forms/README.md) - a form solution, based on `react-final-form`
- [@toptal/picasso-codemod](https://github.com/toptal/picasso/blob/HEAD/packages/picasso-codemod/README.md) - scripts that help developers migrate to the latest version
- [@toptal/picasso-shared](https://github.com/toptal/picasso/blob/HEAD/packages/picasso-shared/README.md) - shared utilities between the packages

## Contributing

Please read our documentation [here](https://github.com/toptal/picasso/blob/HEAD/CONTRIBUTING.md)

## Supported browsers

Picasso guarantees to work in Chrome and it supports other browsers specified in `@toptal/browserslist-config` package.
