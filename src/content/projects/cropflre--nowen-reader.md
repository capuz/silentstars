## 💡 Project Introduction

Nowen Reader (弄文阅读) is a self-hosted comic / novel management and reading platform optimized for NAS and personal server use.

| 🏆 Core Advantages | Description |
|:---|:---|
| 💾 **Extremely lightweight** | Runs smoothly with a 512 MB memory limit; the Docker image is only about 30 MB |
| 📦 **Zero-dependency deployment** | Go compiled into a single static binary; the frontend is embedded via `go:embed` |
| 🐳 **One-command Docker startup** | Provides general, production, and NAS Compose configurations |
| 🤖 **AI-assisted** | Optionally connects to 17+ LLM providers, including mainstream Chinese large language models |
| 📚 **Full format coverage** | Comics: ZIP / CBZ / CBR / RAR / 7Z / CB7 / PDF; novels: TXT / EPUB / MOBI / AZW3 / HTML |
| 🌐 **Native Chinese support** | Bilingual Chinese/English interface and translation of metadata between Chinese and English |
| 📱 **Multi-platform access** | Web PWA plus Flutter native clients (Android / iOS / desktop) |
