# qrcode-parser

A pure javascript QR code decoding library, accept File object, image url, image base64.

## Example

👉 [DEMO](https://qrcode-parser.netlify.app)

## Install

```bash
yarn add qrcode-parser
```

## Usage

```js
import qrcodeParser from "qrcode-parser";

qrcodeParser(input);
// => return promise
```
