# 时序 · Chronos

**Give every stretch of time a clear direction.**

An Android time-management app for study and long-term planning: plan, focus, review, one closed loop.

**Zero framework · zero dependencies · no Gradle. Packaged with a single build.sh**

### Download and install

**Android 8.0+** | About 110 KB | No background network access, no account, all data stored locally on the device

After downloading, allow "Install unknown apps" and you're set. For all versions, see [Releases](https://github.com/Dvesiz/chronos/releases).

### Product website

[Open the Chronos product website](https://dvesiz.github.io/chronos/)

The website includes feature overview, screenshots, APK download link, and privacy notice.

### Try it online

[Try Chronos in your browser](https://dvesiz.github.io/chronos/app/)

The browser version directly reuses the APK's UI and interaction logic. Planning, focus, Pomodoro timer, statistics, check-ins, and import/export all run locally. For Android-only features such as system notifications, exact alarms, floating windows, and ultra-immersive mode, install the APK.
