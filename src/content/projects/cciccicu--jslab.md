<h1>JSLab</h1>
  <p>Write, run, and manage JavaScript on your wrist</p>
  <p>
  </p>
</div>

JSLab is a JavaScript development environment for Xiaomi Vela wristbands. It combines an editor, script runtime, AstroBox companion, and cloud workspace into a complete creation workflow: scripts can be written and run on the wristband, or transferred via computer, saved to cloud space, and published to the marketplace.

> This project is still under continuous development. Build commands do not automatically connect to emulators or physical devices; any device deployment and ADB operations require separate authorization.
