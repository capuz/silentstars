## About the project

**Aether** is an AI agent that runs directly on the phone: it reads and edits files, runs commands,
maintains a local environment (Alpine), connects extensions, and communicates with any model via an
OpenAI-compatible API. The interface and settings are in Russian.

Requests to models and web services require a network connection and a configured provider; everything else
(tools, files, environment, history) stays on the device.

## Features

| Feature | What's available |
|---|---|
| Russian interface | Settings, chat, file manager, extensions, documentation |
| Chat | Streaming responses, markdown, tools with confirmation, history and search |
| Interactive polls | ` ```poll ` cards in chat: options, multiple choice, and a custom answer right in the card |
| Charts in responses | ` ```chart ` cards (line, bar, pie) with a legend and collapsing — the agent draws them instead of tables |
| Clear chat list | Each chat has its own colored badge and shape, a preview of the last message, time, and grouping into "Today / Yesterday / Earlier" |
| Full-text search | Searches by titles and message text, showing the matching fragment with highlighting |
