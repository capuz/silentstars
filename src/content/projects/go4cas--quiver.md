```bash
bunx degit go4cas/quiver/starter my-app
```

A drop-in router, context and meta layer for [Arrow.js](https://arrow-js.com), with composables for any Arrow app, copy-in UI recipes, and a starter app that puts them together.

- **[`@go4cas/quiver`](https://github.com/go4cas/quiver/blob/HEAD/packages/quiver)**: routing on the Navigation API with layouts, guards, `afterEach`/`onError`, base paths, `provide`/`inject` and `useMeta`. File-based routes through a Vite plugin, a `Bun.build` plugin or the `quiver routes` CLI. 13 exports, one peer dependency, no CSS.
- **[`arrow-use`](https://github.com/go4cas/quiver/blob/HEAD/packages/arrow-use)**: `useFetch`, `useStorage`, `useMediaQuery` and `useEventListener` for any Arrow app, with or without Quiver.
- **[Recipes](https://github.com/go4cas/quiver/blob/HEAD/recipes)**: theme tokens (`--q-*`), toasts, a theme switcher, layouts, loading and error views, `Link`, `useForm`, `hmrState`. Copied into your app, then yours.
- **[The starter](https://github.com/go4cas/quiver/blob/HEAD/starter)**: a full app with five themes in plain CSS, Vitest, Playwright and screenshot tests, and agent docs for Claude Code, Codex and Copilot.
