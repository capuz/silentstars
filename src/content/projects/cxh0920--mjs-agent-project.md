# Legendary General Kill Agent

A multimodal desktop application based on **OCR + RAG** with a focus on the mobile game 'Legendary General Kill'. The project primarily explores:

- **Multimodal screen recognition**: Template matching pre-filtering + RapidOCR recognition + Chinese character feature library name correction
- **RAG corpus hierarchical architecture**: ODS/DWD/mart three-tier data warehouse stratification, corpus task single source of truth scheduling and version stamps
- **Multi-vendor LLM integration**: API (multi-vendor profile) + browser automation dual backend, RAG corpus-enhanced generation
- **Desktop application engineering**: PySide6 + PyInstaller dual-mode packaging, CI integration and release smoke testing pipeline
