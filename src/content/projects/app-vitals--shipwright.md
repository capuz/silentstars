# Shipwright Harness -- autonomous delivery agent for Claude Code

By [App Vitals](https://app-vitals.com) · [shipwrightharness.com](https://shipwrightharness.com) · not affiliated with other projects named "Shipwright".

**The open-source autonomous delivery agent for Claude Code.** A deployable cloud agent and the autonomous coding system that powers it — built on the Shipwright plugin, running on your own codebase.

**Coming from _How to Build Your Own Software Factory_?** This is the factory the lessons are built on:

- [Lesson 1: Plan, Execute, Loop](https://www.youtube.com/watch?v=c4qi_zu3vZI) → [`/shipwright:plan-session`](https://github.com/app-vitals/shipwright/blob/HEAD/plugins/shipwright/commands/plan-session.md) + [`/shipwright:dev-task`](https://github.com/app-vitals/shipwright/blob/HEAD/plugins/shipwright/commands/dev-task.md), the loop the agent runs on a schedule.
- [Lesson 2: A Plan That Looks First](https://www.youtube.com/watch?v=dr-JNCWH0Yc) → [`/shipwright:plan-session`](https://github.com/app-vitals/shipwright/blob/HEAD/plugins/shipwright/commands/plan-session.md), which reads the codebase before it writes tasks.
