# TeknoParrot Manager

TeknoParrot Manager is a Windows PowerShell tool for managing TeknoParrot arcade libraries on Windows. It registers extracted games, propagates controls, deploys lightgun crosshairs, applies ReShade and dgVoodoo2 compatibility fixes, and exports libraries to LaunchBox.

TeknoParrot Manager is made for beginners and is also useful if you already know TeknoParrot. It hides complexity, not detail. Repeatable bulk steps (AutoSync, Register, Propagate Controls) save manual work. Where it changes your files it says so, makes a backup first, and shows what it did under Details and in the log. It keeps four things apart: games found, games registered, a game that launches, and controls that are set up. See [Advanced users](https://github.com/Jumpstile/teknoparrot-manager/blob/HEAD/docs/ADVANCED-USERS.md).
