# Codex Token Cost

  &nbsp;·&nbsp;
  &nbsp;·&nbsp;
  &nbsp;·&nbsp;

Codex Token Cost is a local userscript for [Codex++](https://github.com/BigPizzaV3/CodexPlusPlus). It shows above the Codex input area the current turn, the current session, cache hits, cost, and today's cumulative totals. It also provides standalone usage statistics, model price management, and local Profile data.

The main script runs independently, and historical usage records are based on the local Profile ledger / archive. The script automatically reads local Codex session files to backfill missing usage. All of this is done on your machine.

## Core capabilities

| Capability | Description |
|---|---|
| Real-time HUD | Shows current turn input/output, session totals, cache hits, session cost, and today's cost. Output rate can be toggled separately |
| Usage statistics | Supports today, 7 days, 30 days, and custom date ranges, with KPI period-over-period changes, trends, token composition, and model filtering |
| Local Profile | After real ChatGPT login, the local ledger overrides Profile usage and account menu display. Under pure API Key login, no fake profile page is created |
