## 📖 Introduction

**VitePress Theme Minimalism** is a minimalist blog theme built on the VitePress default theme, focused on content presentation and reading experience. It seamlessly blends blog mode and documentation mode, so you can have both blog and documentation features on the same site.

## ✨ Features

### ✨ Highlights

- 🎯 **Minimalist design** - focused on content, with redundant elements removed
- 🔌 **Fully compatible** - integrates seamlessly with the VitePress default theme
- 🎨 **Modern UI** - uses the Geist font for an excellent visual experience
- 🛠️ **Easy to customize** - flexible configuration options
