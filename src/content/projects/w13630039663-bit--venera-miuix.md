# venera-miuix

**An Android comic and gallery aggregator reader: describe comic sources with JavaScript plugins, aggregate local and online comics, and deeply integrate native gallery and Pixiv ecosystems.**

This branch replaces the upstream Venera Flutter implementation entirely with pure native Kotlin + Jetpack Compose, rebuilds the full-screen UI in the Miuix design system from Xiaomi HyperOS, and adds a powerful native gallery and multi-source Pixiv aggregation module.
