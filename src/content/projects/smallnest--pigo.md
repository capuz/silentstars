# pigo

The [pi](https://pi.dev) AI Agent replicated in Go — a command-line coding agent that supports both **headless script mode** and **interactive REPL**.

pigo can read and write files, execute commands, retrieve code, scrape web pages, and complete the loop from "understanding requirements" to "fixing code" with the help of large models. It is compatible with various protocol gateways such as OpenAI / Anthropic, supports session continuation, project trust, skills, plugins, and package management.
