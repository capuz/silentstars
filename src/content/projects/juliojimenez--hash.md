# hash
A modern command line interpreter for Linux, macOS, and BSD.

Demo made with [vhs](https://github.com/charmbracelet/vhs).

## Install

### From Release

#### Linux x86_64

```bash
curl -LO https://github.com/juliojimenez/hash/releases/download/v48/hash-shell-v48-linux-x86_64
chmod +x hash-shell-v48-linux-x86_64
sudo mv hash-shell-v48-linux-x86_64 /usr/local/bin/hash-shell
hash-shell
```

#### Linux ARM64

```bash
curl -LO https://github.com/juliojimenez/hash/releases/download/v48/hash-shell-v48-linux-aarch64
chmod +x hash-shell-v48-linux-aarch64
sudo mv hash-shell-v48-linux-aarch64 /usr/local/bin/hash-shell
hash-shell
```
