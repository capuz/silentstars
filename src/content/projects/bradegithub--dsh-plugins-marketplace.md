# DSH Plugin Marketplace (dsh-plugin-marketplace)

Chinese · [English](https://github.com/bradeGithub/DSH-Plugins-Marketplace/blob/HEAD/README.en.md)

A marketplace plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH). It automatically indexes all plugins under the GitHub `dsh-plugin` topic and displays them as cards on the DSH Web GUI settings page. It supports one-click installation, version detection, and automatic updates, with no command line needed.
