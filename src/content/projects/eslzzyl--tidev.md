# tidev

AI coding agent built in pure Rust. tidev reimplements the interaction model of [OpenCode](https://github.com/anomalyco/opencode) with a focus on performance and memory efficiency. It also introduced richer extended features.

> tidev underwent a radical rewrite, with version v0.7.0 being the rewritten version. The rewrite removed most of the features I didn't need and included architectural restructuring and performance optimizations to the best of my ability. The [`last-full`](https://github.com/Eslzzyl/tidev/tree/last-full) tag marks the last commit that contains a complete feature.
