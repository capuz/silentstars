## ✨ Features

- One-click reading and automatic announcements, with filtering of URLs, code, and similar content.
- Xiaomi MiMo and Doubao streaming voices, supporting built-in, custom, and cloned voices; browser voice can be used first or as a fallback.
- Speed, volume, pause, and stop controls, with audio history preview and download.
- Optional UI sound effects, host event announcements, third-party plugin linkage, and Whale Girl Agent presets.

## 🚀 Installation and Usage

Requires DSH `0.2.2` or higher and Node.js 24.9+. The current target adaptation is DSH `0.2.2-alpha.2`.

Search for `dsh-xiaomi-tts` in the DSH plugin management panel to install it, or use the Web command:

```bash
dsh plugin --profile web add dsh-xiaomi-tts@latest
```

To uninstall the plugin:

```bash
dsh plugin --profile web remove dsh-xiaomi-tts
```
