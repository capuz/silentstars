# UCLC (Use CATIA Like AutoCAD)
# Use CATIA Like AutoCAD
---

## Introduction

**UCLC** is a CATIA efficiency enhancement tool written in [AutoHotkey v2](https://www.autohotkey.com/). It aims to replace CATIA's command habits with an AutoCAD-style `combined-character command` + `space` execution method, greatly improving drafting and modeling efficiency.

Starting with **v3.0.0**, UCLC has undergone a brand-new evolution, fully adopting a **graphical configuration center**, **CATIA middle-mouse-button shortcut operations**, and a **built-in online update service**, making configuration and usage more intuitive and convenient.

---
