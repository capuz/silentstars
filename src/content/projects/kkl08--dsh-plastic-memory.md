# dsh-plastic-memory

**Plastic Memory · Long-term Memory Plugin for DeepSeek Harness**

**Simplified Chinese** · [English](https://github.com/KKL08/dsh-plastic-memory/blob/HEAD/README.en.md)

[Installation](#安装) · [Getting Started](#上手) · [User Guide](#使用指南)

This is a long-term memory plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) that integrates automatic memory curation, on-demand recall, and quality maintenance. It records key information worth keeping during everyday conversations and tasks, provides relevant context background during later collaboration, and continuously maintains memory quality through a health-monitoring mechanism.
