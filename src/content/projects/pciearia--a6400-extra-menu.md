# A6400 Extra-Menu

*Live-camera display of the latest **V3 CLite** menu (semi-transparent dark floating cards, Sony Alpha orange-gold status highlights, and a Traditional Chinese interface).*

A research project that summons a custom touch menu with **MENU + magnifier** to manage LUT on/off and Film options on the camera.

**This project is still under active development and updates, and is currently experimental.** Menu operation, LUT management, and post-capture processing will be refined gradually through on-camera verification. Verified features, known limitations, and pending items are updated in the "Actual Progress" section below and in [Feature Status](https://github.com/PCIEARIA/A6400-Extra-Menu/blob/HEAD/docs/功能狀態.md).

The main documentation is written in Traditional Chinese.
