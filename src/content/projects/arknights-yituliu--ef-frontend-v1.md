# Endfield One-Image Guide Website

A one-image guide website for *Arknights: Endfield*, built with Nuxt 4.x.

## 🚀 Quick Start

### Clone the project

```bash
git clone --depth 1 --branch dev https://github.com/Arknights-yituliu/ef-frontend-v1.git
```

### Install dependencies

```bash
cd ef-frontend-v1
yarn install
```

### Development environment

Start the development server, then visit: `http://localhost:3000`

```bash
yarn dev
```

### Production build

Build the production version (SSG):

```bash
yarn generate
```

Preview the production build:

```bash
yarn preview
```
