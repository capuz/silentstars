# Harlequin

Harlequin is an AI harness for boring office work. It does not aim to land on the Moon, solve cancer, or achieve sentience. The ideal Harlequin user is:

* Not a developer / programmer
* Works with a lot of documents of different "normal" types - contracts, invoices, rules and regulations, that need to be cross-checked
* Lets IT manage their computer
* Just tries to get on with their lives

Harlequin has a bit of an "enterprise"-y architecture. Instead of executing a full harness on the user's machine, users run lightweight clients that connect to the server, which does all the work. The server can be self-hosted, or you can try the official public server. The server is user-aware, has access roles, differentiates between user-specific data, shared (e.g. company-wide) data, and per-project data. It has "system admins can perform memory surgery" as a first-class feature. It can reach out to do web search, document analysis and synthesis, and has a proactive memory system.
