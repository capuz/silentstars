How to build and run:
* From Ubuntu 18.04, 20.04 (real or virtual machine): use the instructions below.
* From Windows 10: follow [this guide](https://github.com/dreamland-mud/dreamland_code/wiki/WSL-and-VS-Code) for Windows Subsystem for Linux and the VS Code editor.
* From a Docker environment: build a ready-to-use Docker container as described in the Readme for the project [dreamland_docker](https://github.com/dreamland-mud/dreamland_docker).
* From online development environments in the browser: [Goorm Online IDE](https://github.com/dreamland-mud/dreamland_code/wiki/Goorm-IDE) or https://gitpod.io.
