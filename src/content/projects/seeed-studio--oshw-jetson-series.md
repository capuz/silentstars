# Open Source Hardware - NVIDIA Jetson Carrier Board

Copyright (c) [Seeed Studio](https://www.seeedstudio.com/). All rights reserved.

## Overview

This project contains the open-source hardware design files for Seeed Studio's **NVIDIA Jetson hardware series** — including the `reComputer` and `reServer` carrier boards, mini PCs, and industrial computers based on **Jetson Nano, Jetson Xavier NX, Jetson Orin NX/Orin Nano, Jetson AGX Orin, and Jetson AGX Thor**.

For every product you will find its **BRD / DSN circuit design source files** (created in Cadence **Allegro 17.4**), **visualized PDF schematics**, plus the full supporting resource set: **datasheets, 3D models, mechanical drawings (DXF), user manuals, firmware, and certifications** (CE / EUDOC / FCC / KC / ROHS / REACH / UKDOC / UKCA).
