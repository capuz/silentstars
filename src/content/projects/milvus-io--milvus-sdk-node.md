# @zilliz/milvus2-sdk-node

Official Node.js SDK for [Milvus](https://github.com/milvus-io/milvus) vector database. Provides gRPC and HTTP clients for vector similarity search, metadata filtering, and full collection/index/user management.

**Package**: `@zilliz/milvus2-sdk-node` | **Node.js**: v18+ | **License**: Apache-2.0

Documentation: [Guides & API reference](https://milvus-io.github.io/milvus-sdk-node/) · [3.0.10 release notes](https://milvus-io.github.io/milvus-sdk-node/reference/release-notes/) · [llms.txt](https://milvus-io.github.io/milvus-sdk-node/llms.txt) · [llms-full.txt](https://milvus-io.github.io/milvus-sdk-node/llms-full.txt)

SDK **3.0.10** is tested with Milvus **3.0.6**. Changes since 3.0.5 include StructArray nesting and path-level partial upserts, function chains and search aggregation, portable snapshots, replication and WAL streams, new gRPC administration APIs, and expanded Milvus REST v2 coverage in `HttpClient`.

## Installation

```bash
npm install @zilliz/milvus2-sdk-node
# or
yarn add @zilliz/milvus2-sdk-node
```
