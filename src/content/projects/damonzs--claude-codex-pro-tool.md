# Claude Codex Pro Tool

</p>

  Chinese | <a href="README_EN.md">English</a>
</p>

</p>

**Local AI operations and maintenance control console for Codex App, Claude Desktop, and Claude Code on Windows and macOS.**

Claude Codex Pro Tool (CCP) consolidates third-party API vendors, model and protocol conversion, local proxy and routing, Codex enhancement, Claude Desktop integration, MCP/Skills/plugins, session repair, Codex themes, and system prompts into a Rust + Tauri desktop application. It only manages local configuration and third-party APIs, and does not take over official accounts, subscriptions, or payments.

Unique project repository address:

<https://github.com/DamonZS/Claude-Codex-Pro-Tool>

> **Codex model selection is the responsibility of Codex's native logic.** CCP does not inject candidates into the Codex model selector, does not modify the model whitelist or model fields in requests, and does not display specific models through frontend enhancement. The vendor page can still manage model catalogs and routing configuration; whether Codex can display or call a model depends on Codex's own version, login status, configuration, and upstream API capabilities.
