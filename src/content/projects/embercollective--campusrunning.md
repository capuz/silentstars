## Campus running has been a long ordeal

Early check-ins, mileage and pace, none of it can be skipped. Students have suffered from it for a long time.

The community already has many virtual location solutions, each with its own trade-offs. This tool takes a different path: **it generates sports data files (FIT by default, TCX-compatible) with real track coordinates, real pace, and real cadence and step counts. Import them into a sports app and they are ready to use.**

The author maintains this project out of passion and hopes to help students struggling with campus running everywhere. If this project has helped you, starring it is the best encouragement the author can receive.
