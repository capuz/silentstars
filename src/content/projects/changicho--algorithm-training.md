# 🖐 Problem Solving Repository

> This is a repository of algorithm problem solutions. (Baekjoon, Samsung, Programmers, etc.)

The README.md records notes from solving problems, answer rates (percentages), original links, and more.

[View problem-solving note template](https://github.com/changicho/algorithm-training/blob/HEAD/templates/c++/boj/README.md)

You are free to use the template. If you do, please click star.

---

## 🗂 Folder Structure

Folder names consist of the problem number and the problem name.

```sh
problem_title
├── README.md   # Problem solution notes record
├── code.cpp, answer.cpp  # Solution files (.cpp, .js, .py ...)
└── input.txt   # input
```
