行旅录(TransitU) is an Android app focused on reading transit cards and recording trips. Hold your phone near a transit card to read the balance, transaction history, and city route information, and generate statistical charts and trip maps locally.

Built on publicly available transit card protocol documentation ([NFC Wiki 智能卡手册](https://nfcwiki.com)). It is read-only: it does not write to cards or modify balances.

## Features

| Module | Content |
| ------ | ------- |
| Card reading | Card number, issue date, expiry date, issuing institution, real-time balance, issuing city |
| Transactions | Recent transactions (time, amount, station, card type), trips this month, cumulative discounts |
| Analytics | Spending trends by week/month/year/custom range; total spending, number of trips, average daily spending; most-used stations and routes |
| Review | Map tracks, route playback (play/pause/speed control), Tencent Maps transfer plans (show only start and end points…
