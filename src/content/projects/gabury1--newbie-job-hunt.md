# Pre-Peeled Postings

**Developer entry-level and junior job postings, peeled and delivered every morning**

This is a markdown collection of currently open domestic developer entry-level and junior job postings, gathered every morning and organized to be **easy for AI to consume**.

## Use It Right Away

Give an AI only the address below and say "Pick the postings that match my conditions."

```
https://raw.githubusercontent.com/gabury1/newbie-job-hunt/main/AGENTS.md
```

To check new postings every morning, install it as a skill (Node 22 or later).

```
npx skills add gabury1/newbie-job-hunt
```

| Where to use | How to do it |
|---|---|
| **Claude Code · Codex · Cursor** | Give it the address above, or open the repo and it will read it automatically |
| **ChatGPT · Claude web chat** | Paste the address above |
