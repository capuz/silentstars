Reproducible Builds for Maven Central Repository
====================================================

This project is the [Java part](https://reproducible-builds.org/docs/jvm/) of the [Reproducible Builds](https://reproducible-builds.org/) effort:

_an independently-verifiable path from source to binary code_

--------------------------------------------------------------------------------------------------------------------------

Its objectives are to provide:
1) [**Tools and methods**](https://github.com/jvm-repo-rebuild/reproducible-central/blob/HEAD/doc/TOOLS.md) enabling the verification of reproducible Java builds
2) [**A list of reproducible releases**](https://github.com/jvm-repo-rebuild/reproducible-central/blob/HEAD/content/README.md) available on Maven Central
