# HashGate

A HMAC (Hash-based Message Authentication Code) authentication system for ASP.NET Core applications. This library provides both server-side authentication and client-side HTTP handlers for secure API communication.

| Package                                                                    | Version                                                                                                                 | Description                                                   |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| [HashGate.AspNetCore](https://www.nuget.org/packages/HashGate.AspNetCore/) | [](https://www.nuget.org/packages/HashGate.AspNetCore/) | Server-side HMAC authentication for ASP.NET Core applications |
| [HashGate.HttpClient](https://www.nuget.org/packages/HashGate.HttpClient/) | [](https://www.nuget.org/packages/HashGate.HttpClient/) | Client-side HTTP message handler for HMAC authentication      |
