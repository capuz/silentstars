# Zippy CRM

CRM system (inventory, trade, production, cafe, PRRO) with a web interface.  
Designed for automating the accounting of small businesses as an alternative to paid and/or Russian software.   
Can be deployed both online (on website hosting) and offline (on a personal computer or in a local network).  
The web interface allows working from both a desktop browser and a mobile device.  
   
Project homepage:  <https://zippy.com.ua/>
 
## Main functionality

* inventory management
* purchasing
* sales
* accounting of payments and settlements with counterparties
* user management and access control
* working with leads and other CRM elements
* reports on sales, purchases, and inventory movement
* services, tasks, work execution calendar
* production, work orders, production processes, and production stages
* payroll calculation
* support for barcode scanner (keyboard)
* support for receipt and label printers
* access control between branches (e.g., retail outlets)
* integration with OpenCart, WooCommerce, PromUa
* integration with Nova Poshta
* built-in software RRO
* integration with CheckBox and VchasnoKasa
* connection of fiscal registrars...
