# Codex Dream Skin Manager

Change backgrounds, manage themes, and adjust the interface appearance of the Codex desktop client. The Windows version also supports the Code page of Claude Desktop, DSH rc (Community Edition DeepSeek Harness), and DSH Next. Windows and macOS share the same management interface, core logic, and Codex skinning runtime, each hosted by its native window.

## Download and Installation

Current version: `3.3.0`. Go to [GitHub Releases](https://github.com/xxloocee/Codex-Dream-Skin-Manager/releases) to download the appropriate installer:

| Platform | System requirements | Installer |
| --- | --- | --- |
| Windows installer | Windows 10/11 x64 | `CodexDreamSkinManager-v3.3.0-windows-x64-setup.exe` |
| Windows portable | Windows 10/11 x64 | `CodexDreamSkinManager-v3.3.0-windows-x64-portable.zip` |
| macOS Intel | macOS 13+ | `CodexDreamSkinManager-v3.3.0-macos-x64.dmg` |
| macOS Apple Silicon | macOS 13+ | `CodexDreamSkinManager-v3.3.0-macos-arm64.dmg` |
