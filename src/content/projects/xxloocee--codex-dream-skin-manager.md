# Codex Dream Skin Manager

Change backgrounds, manage themes, and adjust the appearance of the Codex desktop client. Windows and macOS share one management interface, one business core, and one skinning runtime, each hosted by its own native window.

## Download and Installation

Current version: `3.1.5`. Go to [GitHub Releases](https://github.com/xxloocee/Codex-Dream-Skin-Manager/releases) to download the package for your platform:

| Platform | System Requirements | Package |
| --- | --- | --- |
| Windows installer | Windows 10/11 x64 | `CodexDreamSkinManager-v3.1.5-windows-x64-setup.exe` |
| Windows portable | Windows 10/11 x64 | `CodexDreamSkinManager-v3.1.5-windows-x64-portable.zip` |
| macOS Intel | macOS 13+ | `CodexDreamSkinManager-v3.1.5-macos-x64.dmg` |
| macOS Apple Silicon | macOS 13+ | `CodexDreamSkinManager-v3.1.5-macos-arm64.dmg` |

Please install the Codex desktop client first. The release packages include Node.js, so no separate runtime setup is needed. The Windows portable version must be fully extracted; copying only the EXE is not enough. `SHA256SUMS.txt` provides checksums for the downloaded packages.
