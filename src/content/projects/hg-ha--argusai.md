## Agent Runs Throughout the Workbench

ArgusAI is an Agent-native security workbench open-sourced by [Dawa Technology](https://dawahezhi.com/). It places an AI assistant, scanning tasks, browser, proxy traffic, reverse-engineering samples, and evidence into a single local workspace, targeting intranet security protection, application security protection, attack tracing, and continuous offense and defense. It supports everything from organizing goals and materials through controlled verification, reporting, and remediation retesting.

Hand over goals, materials, and authorized scope to the Agent, and it coordinates scanning, browser, proxy, reverse engineering, knowledge management, and scheduled tasks, continuously advancing analysis, verification, and delivery. The Agent is the default entry point for work; the feature pages are for observing progress, reviewing evidence, and stepping in when needed. The GUI, CLI, and Python kernel connect to the same set of working capabilities.
