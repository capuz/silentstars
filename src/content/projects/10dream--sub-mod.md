# ⚡️ Intelligent and Automatic Config Aggregation System (V2ray & Clash)

A fully dynamic and modular project based on GitHub Actions for downloading, parsing, and filtering duplicate data (based on a technical connection fingerprint algorithm), and for intelligently separating consecutive, stuck-together configs.

> 🔄 **Auto-update:** Every 1 hour, data from all sources is re-fetched and broken configs are filtered out.
