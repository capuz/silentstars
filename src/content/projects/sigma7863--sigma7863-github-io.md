# Technical Stack
## Analytics
### Umami (Open Source)
The analytics services are mostly geared towards businesses, and there were limitations on usable services because it was necessary to rewrite the scripts for collecting analytics in TypeScript and implement XSS countermeasures. Among them, one of the easiest to implement was Umami, so I adopted it.
[Umami Official Site](https://umami.is/)
[Umami Repository](https://github.com/umami-software/umami)

## Framework
### Next.js (Open Source)
It may not be very suitable for a portfolio, but the simple reason for adopting it was that I wanted to try it out.
[Next.js Official Site](https://nextjs.org/)
[Next.js Repository](https://github.com/vercel/next.js)

### Tailwind CSS (Open Source)
Tailwind CSS is a CSS framework that allows you to directly assign CSS to the classes of HTML tags, making it convenient. However, it reduces readability, so it is not very suitable for use in large team development.
[Tailwind CSS Official Site](https://tailwindcss.com/)
[Tailwind CSS Repository](https://github.com/tailwindlabs/tailwindcss)
