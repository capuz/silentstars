# Bastra Recall

[English](#english) · [Deutsch](#deutsch)

## 🇬🇧 English

**Less repeating yourself. One shared memory for your AI tools.**

We’re building with the ambition to create the best personal memory for everyday work with AI—open, transparent, and under your control.

Keep your preferences, decisions and hard-won fixes available beyond a single chat. Bastra Recall stores them as readable Markdown files on your computer and makes them available to your connected AI assistants.

[What you can use Recall for](https://github.com/n0mad-ai/bastra-recall/blob/HEAD/docs/use-cases.md#english) gives practical examples for conversations, rules, tasks, documents and shared work.

Proactive tasks (unreleased): notify reminders can be added and controlled in conversation; local hooks/MCP receive Agent access automatically. Due cards arrive at next contact, with acknowledgement and completion kept separate. The Recall UI Tasks tab lists active, completed and failed/cancelled work. The existing action path uses exact Owner signatures for one registered reversible local UTF-8 adapter; that approval policy remains open for later discussion.
