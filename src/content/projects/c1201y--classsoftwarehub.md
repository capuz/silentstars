# ClassSoftwareHub

**Commonly Used Software Download Site for Audio-Visual Education Committee Members (Vue Source Edition)**

ClassSoftwareHub is a software download site for audio-visual education committee members, built with **Vue 3 + Vite + TypeScript**. It uses the [WinUIonWeb](https://github.com/Furry-Xiyi/WinUIonWeb) component library to provide a WinUI-style interface. This site was reverse-engineered from the single file `indexV20260831.html`, splitting the previously compressed page core into a readable, maintainable project.

## Features

- **Software downloads**: Displays commonly used software by category. Supports viewing details, system restrictions, version numbers, file sizes, and checksums, and provides direct file download links.
- **Site-wide search**: Press `Ctrl + K` (or `Ctrl + F`) to open the search panel, which searches software, built-in tools, AI navigation sites, and pages in one go.
- **AI navigation**: Built-in navigation for common AI websites for quick access.
- **Welcome dialog**: On first visit, shows a WinUI-style welcome window with links to the repository, the author's homepage, related articles, the QQ group, and sponsoring the author.
