# Official Go SDK for [Stream](https://getstream.io/)

    Official Go API client for Stream Chat and Video, a service for building chat and video applications.
    ·

## Migrating from stream-chat-go?

If you are currently using [`stream-chat-go`](https://github.com/GetStream/stream-chat-go), we have a detailed migration guide with side-by-side code examples for common Chat use cases. See the [Migration Guide](https://github.com/GetStream/getstream-go/blob/HEAD/docs/migration-from-stream-chat-go/README.md).

## Upgrading from an older major?

- [v6 → v7](https://github.com/GetStream/getstream-go/blob/HEAD/MIGRATION_v6_to_v7.md): new import path; CreateReminder returns CreateReminderResponse.
- [v7 → v8](https://github.com/GetStream/getstream-go/blob/HEAD/MIGRATION_v7_to_v8.md): new import path; FLU-1105 named enum types in the generated client.

- [v4 → v5](https://github.com/GetStream/getstream-go/blob/HEAD/MIGRATION_v4_to_v5.md): new import path, four removed response fields, `CheckResponse` no longer comparable.
- [v3 → v4](https://github.com/GetStream/getstream-go/blob/HEAD/MIGRATION_v3_to_v4.md): OpenAPI-aligned type renaming.
