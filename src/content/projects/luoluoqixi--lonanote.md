# 露娜笔记 (LonaNote)

[Chinese](https://github.com/luoluoqixi/lonanote/blob/HEAD/README.md) | [English](https://github.com/luoluoqixi/lonanote/blob/HEAD/README_en.md)

A local-first open source note-taking app, written in **TypeScript** and **Rust**.

## 🎉 Introduction

**露娜笔记** is an open source, cross-platform, local-first Markdown note-taking app that supports WYSIWYG (What You See Is What You Get) editing of Markdown.

Notes are stored **offline, locally** in the open Markdown format, so you can switch to other note-taking apps at any time without importing or exporting.

**Supported platforms**: `Windows`, `MacOS`, `Linux`, `Android`, `iOS`.

## ✨ Key Features

- **Local storage** - Markdown text files are stored entirely locally
- **Raw file system** - no database
- **WYSIWYG editing** - live preview
- **Architecture** - desktop uses Tauri + React Native Web, mobile uses Expo / React Native, core uses Rust
