# Media Saber Media Library Management Tool

Docker: https://hub.docker.com/repository/docker/xylplm/media-saber

## Features:

A media management tool designed for personal use.

Frontend: Angular
Mobile Client: Flutter
Backend: GO

Created through the collaborative efforts of multiple enthusiastic Pterodactyl community members, developed for personal use, entirely self-developed, to build a fresh, efficient, stable, fast, convenient, and powerful media management tool!

Given that projects like NT MP have too high exposure and pose significant risks, this project is private and is only used by the development team and invited users on a small scale.

We welcome more capable users to participate. Friends with relevant development skills are invited to join!

## Installation

### 1. Docker

```
docker pull xylplm/media-saber:latest
```

Tutorial available [here](https://wiki.msaber.fun).
