# CommTool — Serial Debugging Assistant + Network Debugging Tool

An open-source **serial debugging assistant / network debugging tool** that combines UART serial ports, SEGGER J-Link RTT, and TCP/UDP debugging in one desktop interface. It is aimed at embedded development, device integration, Modbus / custom protocol testing, and communication log analysis. Official release packages support **Windows**, **macOS**, and **Linux x86_64**.

> Serial / RTT terminal and TCP/UDP network debugger in one desktop app — HEX, logging, Modbus, scripting, and automated tests.
