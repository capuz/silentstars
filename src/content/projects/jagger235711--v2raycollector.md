## 📋 Project Overview

**V2rayCollector** is a powerful, fully automated node collection and management tool that integrates crawling, deduplication, speed testing, and format conversion. It can:

- 🕷️ **Automatically crawl** V2ray node configurations from Telegram channels
- 🔗 **Aggregate and process** nodes from multiple subscription links
- 🧹 **Smart deduplication** with concurrent detection, excluding invalid and slow links
- ⚡ **Efficient speed testing** using singtools for batch node speed tests
- 🔄 **Format conversion** supporting multiple subscription formats based on subconverter
- ⏰ **Automatic updates** running daily on a schedule via GitHub Actions
- 📊 **Categorized output** with results sorted by protocol type
