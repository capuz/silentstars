# scientific-writing-agent

Reusable AI-assisted workflows for writing, reviewing, and revising LaTeX research
papers in Pi, Claude Code, and Codex. Install them into an existing manuscript
repository to add structured scientific-writing assistance without replacing its
LaTeX template or build system.

Use the workflows to:

- **Write and revise:** plan arguments and draft evidence-bounded passages.
- **Review:** check scientific support, terminology, grammar, and
  implementation-dependent claims.
- **Validate:** check LaTeX structure, builds, and selected rendered pages.
- **Prepare submissions:** audit the manuscript and develop responses to reviewers.

Authors control substantive revisions. Reviewers diagnose rather than rewrite,
and manuscript edits require author approval.
