# Zongsoft Framework

[English](https://github.com/Zongsoft/framework/blob/HEAD/README.md) |
[简体中文](https://github.com/Zongsoft/framework/blob/HEAD/README.zh-Hans.md)

-----

This is a collection of open source projects for the _**Z**ongsoft_ development framework, supporting _**.NET**_ `8`,`9`,`10` and other versions.
The ecosystem of pluggable applications is a big strength of _**Z**ongsoft_, help us [build it](https://github.com/Zongsoft/framework/blob/HEAD/CONTRIBUTING.md)!

> 💡 After cloning this project's source code, you need to use the `git submodule update` command to update the [submodules](https://github.com/Zongsoft/framework/blob/HEAD/.gitmodules).

> - 🛠️ Contributors can use the [code analysis checks](#code-analysis) to verify coding style and build diagnostics.
> - 📦 Maintainers should read the [NuGet publishing guide](https://github.com/Zongsoft/framework/blob/HEAD/PUBLISHING.md) before releasing packages.
