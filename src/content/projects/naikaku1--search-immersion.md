# Search Immersion

**Search Immersion is a Chrome extension that turns your new tab into a searchable smart display.**

This is currently a release test version (beta). Behavior may differ depending on your environment.

---

## What's new in v28

### Search

- `⌘/Ctrl + K`, or `>` opens commands. You can operate themes, timers, Zen, Horizon, and more using only the keyboard.
- Typing something like `!yt 猫` changes the search destination. You can add your own search destinations in settings.
- `12*3+4`, `10 km to mi`, and `10坪は畳` are answered on the spot.
- You can also search open tabs and bookmarks. Press `/` to move to the search field.

### Cards

Hover over a card on Home and choose "Replace". The "How to use" section, shown when a Web Clip or Read Later card is empty, has the steps.

- Web Clip: Right-click a page to place part of a site on Home. When it updates, newly added rows are marked.
- Focus: Each time you finish a session, one plant grows.
- Ambient sound: Mix rain, wind, waves, campfire, stream, insect sounds, and noise, all synthesized on the spot. No audio files are used.
- Read Later: Right-click a page or link to add it.
- Tab save: Saves your current tabs…
