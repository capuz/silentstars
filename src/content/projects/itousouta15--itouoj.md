# itouOJ

A self-hostable Online Judge offering programming problems, reading practice, CTF, contests, courses, and offline submission. The website is built with Next.js; official program submissions are judged by a self-built Linux sandbox.

[Website](https://oj.itousouta.me) · [Downloads (Android App／Windows submission client)](https://github.com/itousouta15/itouOJ/releases) · [Contributing guide](https://github.com/itousouta15/itouOJ/blob/HEAD/CONTRIBUTING.md)

## Features

| Feature | Description |
| --- | --- |
| Programming problems | Problem statements in Markdown／math notation, sample test cases, tags, subtask scoring, submission history, and leaderboards; supports C++, C, Python, JavaScript, and 喵++. |
| Coding | CodeMirror editor, per-problem drafts per language saved to your account (synced between the website and Android App, with local drafts kept offline), and sample testing; on mobile, you can prepare stdin before testing. On desktop, you can drag to resize the problem and code panes left and right. |
| Terminal | On desktop, enter input line by line directly in a terminal and view output in real time; supports C++, C, Python, JavaScript|
