# Big Fish's Little House

> A video wallpaper plugin for AstrBot: each node on the theme canvas is a video clip, and the wallpaper plays out according to how the nodes are connected.

**v3.0.2** · AstrBot >= 4.9.0 · Vue 3 + Element Plus panel · MIT License

---

## Introduction

'Big Fish's Little House' turns a character into an animated video wallpaper:

- When idle, it plays an idle video on a looping node;
- When a message arrives, it follows the canvas connections to the 'Reply to Message' node, and the QQ reply is only sent once the character actually picks up the phone;
- When an action node finishes, it automatically continues along the outgoing edge; when there are multiple branches, the model chooses based on the node descriptions;
- Nodes are joined with cross-fades, so multiple videos never compete for frames;
- The bottom speech bubble is generated by the model on the fly and fades out after 3 seconds;
- It has a standalone wallpaper page that can be added directly as an OBS browser source or used as a desktop wallpaper.

The entire runtime does not rely on built-in fixed action slots; everything is driven by the current theme's canvas.
