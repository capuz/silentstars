# TakasakiInfo

**Love Live! songs, albums, streaming links, members and voice actors<br>in Japanese, romaji and Korean, as CSV and JSON.**

[English](#english) · [한국어](#korean) · [日本語](#japanese)

> **Note**
>
> **Updates are back (October 2026).** The database now runs on a rebuilt pipeline: each song, person and release is kept once as an entity in [`data/`](https://github.com/AuroraCaelum/TakasakiInfo/blob/HEAD/data), and every CSV and JSON file in this repository is generated from it. How it works: [automation/README.md](https://github.com/AuroraCaelum/TakasakiInfo/blob/HEAD/automation/README.md).

> **Important**
>
> The data is still being filled in, so entries may be missing and the structure may change. 821 tracks have no pronunciation (kana) yet.
