# rekordbox Migration Helper · Library Workbench

  
  
  

A local browser application for understanding a rekordbox library, reviewing duplicates and preparing edited copies. Use it to prepare a move to a new computer or compare a library before and after a version change: inspect references, preparation and history, then verify the target collection. Linux is the primary development platform. Windows, macOS and Linux x86-64 portable applications are built and exercised by CI.

**DJ insights** adds explainable rotation/discovery views, seeded genre-balanced random picks, a clickable bubble explorer and **Colour cloud**. **Tonality & tempo** inspects saved keys, BPM distributions and duration statistics. The per-track file view opens Comments directly and provides a quick colour palette; both stage local working edits without unlocking other metadata. Everything runs locally over retained snapshots. See the [DJ insights guide](https://github.com/fantuz/rekordbox-migration-helper/blob/HEAD/docs/DJ-INSIGHTS.md) for evidence sources, unknown values, grouping rules, colour meanings, privacy and copy-export limits.
