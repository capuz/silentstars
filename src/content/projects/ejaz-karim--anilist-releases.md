# AniList Releases

SeaDex and Nyaa for AniList

Available for [Chrome](https://chromewebstore.google.com/detail/anilist-releases/blclflofdjaghfcdjilfbfdllcgicapb) and [Firefox](https://addons.mozilla.org/en-US/firefox/addon/anilist-releases/), including Firefox for Android

## Building from source
Install [Bun](https://bun.com/) (any version works), Next run the command ```bun install``` then ```bun run build``` in the project directory.
