## 📜 Project Origin and License Statement

**EsjzoneViewer is a third-party Android application for ESJ Zone, not the official ESJ Zone client.**

This project continues development based on [DeeChael/Esjzone](https://github.com/DeeChael/Esjzone), improving reading experience, local bookshelf, download and community features on the original basis. Thanks to the original author's contribution.

### 🌐 Data Source

Novels, covers, chapters, comments and other content come from the currently selected ESJ Zone site. The application provides a browsing and reading interface suitable for Android devices, and does not represent the original site's publication of content or make commitments.
