## About WeAreDevs Executor

WeAreDevs Executor is a Windows-native tool for injecting and running Lua scripts within Roblox sessions. It offers a straightforward interface where users can load custom scripts or explore the integrated script hub for pre-built automation routines. The tool relies on a one-click injection system that connects to Roblox processes without manual setup.
