# MyFinder Device Battery

A multi-brand wireless mouse, headset, and keyboard battery card for Windows. It supports MyDockFinder / MyFinder and can also be used on its own as a system tray application.

Current source version **1.4.1-beta.1** (beta), for Windows 10/11 x64. The native UI uses the system .NET Framework. The release package bundles the device-reading component, so users do not need to install Python, vendor drivers, or enter VID/PID. For publicly downloadable versions, the Releases page is authoritative. Older versions remain in the historical Releases.
