# YYB Go Enhanced

A YYB protocol service and WeChat account management platform for self-hosted environments. Provides WeChat QR code login, account and OpenID management, `wx.login` code retrieval, credential renewal, account-specific proxy, and integration with QL, DaiDai, and Arcadia panels.

[Live Demo](https://525815266.github.io/YYB-Go-Enhanced/) · [Releases](https://github.com/525815266/YYB-Go-Enhanced/releases) · [Changelog](https://github.com/525815266/YYB-Go-Enhanced/blob/HEAD/CHANGELOG.md) · [Scripts Directory](https://github.com/525815266/YYB-Go-Enhanced/blob/HEAD/scripts/README.md) · [Issue Feedback](https://github.com/525815266/YYB-Go-Enhanced/issues)

> The live demo uses fictional accounts and data, does not connect to the real YYB service, and will not save inputs.
