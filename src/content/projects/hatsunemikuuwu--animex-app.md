## Sorotan

| | |
| :-- | :-- |
| ⚡ **Cepat & ringan** | Buka, cari, langsung nonton. |
| 🎨 **Material 3 Expressive** | Warna dinamis, liquid glass, dan belasan latar animasi. |
| 📥 **Mode offline** | Unduh episode di latar belakang, tonton tanpa kuota. |
| 🔄 **Sinkronisasi** | Progres otomatis ke MyAnimeList atau AniList. |
| 🔔 **Notifikasi rilis** | Dikabari saat episode anime pilihanmu tayang. |

## Fitur

### 🏠 Beranda & Navigasi
- Lima tab: **Home**, **Jadwal**, **Explore**, **Bookmark**, dan **Profil**.
- Baris konten: `Lanjut Nonton` · `Episode Baru` · `Sedang Hangat` · `Judul Baru` · `Jadwal Hari Ini` · `Paling Ditunggu` · `Populer`.
- Jadwal tayang anime per hari.
- Ukuran kartu di beranda bisa diatur.

### 🔍 Pencarian & Explore
- Jelajahi berdasarkan **Kategori**, **Studio**, **Tahun**, dan **Tipe**.
