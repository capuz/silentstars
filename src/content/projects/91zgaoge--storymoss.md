## ✨ Core Features

| | Feature | Description |
| :---: | --- | --- |
| 🎬 | **Dual-Interface Writing** | Front-stage 'Ink & Paper' immersive writing plus back-stage 'Mechanical' studio management; two design languages, each suited to its role |
| 🎛️ | **Adaptive Back-Stage Workbench** | Dark theme, container-aware cards and forms, independently scrolling panels; from 800×600 to widescreen, with no character-by-character vertical text, fixed height-limited clipping, or floating overlays |
| 🤖 | **Agency Multi-Agent Writing** | Three agents (lead writer, manager, editorial auditor) collaborate in parallel on a shared blackboard; each chapter is delivered only after passing the Gate v2 weighted quality gate (code 0.2 / rules 0.3 / editor 0.5, threshold 0.75); your revision rate feeds back as an independent signal |
