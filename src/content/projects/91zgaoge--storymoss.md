## ✨ Core Features

| | Feature | Description |
| :---: | --- | --- |
| 🎬 | **Dual-Interface Writing** | Front-stage "Ink & Paper" immersive writing plus back-stage "Machine" studio management; two design languages, each suited to its purpose |
| 🎛️ | **Adaptive Back-Stage Workbench** | Dark theme, container-aware cards and forms, independently scrolling panels; from 800×600 to widescreen, with no character-by-character vertical text, fixed-height clipping, or floating overlays |
| 🤖 | **Agency Multi-Agent Writing** | Chief writer / manager / editorial audit: three agents collaborate in parallel on a shared blackboard.
