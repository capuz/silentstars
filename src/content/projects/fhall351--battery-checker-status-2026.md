## Overview

battery-checker is a compact HTML web tool that presents battery status through a clear, browser-accessible interface. It is intended for anyone who needs a quick battery view without installing a large application or configuring additional tooling.

The project works well in lightweight web workflows. Since the utility runs as a web page, it can be opened in a browser and included on a landing page, private tool page, or collection of personal utilities.
