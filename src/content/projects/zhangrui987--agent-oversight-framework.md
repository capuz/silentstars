# AI Execution and Oversight Framework (Agent Oversight Framework)

**A layered governance specification for AI agent oversight: evidence-graded, self-correcting, and boundary-honest.**

> **English**: A layered governance specification for AI agent oversight — evidence-graded, self-correcting, and boundary-honest. Covers swarm-level emergent behavior, evidence integrity (kernel-level collection), and a voluntary-abstention incentive mechanism. (Translation tracker: [`i18n/TRANSLATION.md`](https://github.com/ZhangRui987/agent-oversight-framework/blob/HEAD/i18n/TRANSLATION.md) — see Issue #1.)

This repository is a **governance architecture design specification** for AI Agent deployers, standards bodies, and researchers. It is not a sandbox tool, an observability platform, or a rule engine. It is a complete design document covering “why to govern, how to govern, and where the boundaries lie.”
