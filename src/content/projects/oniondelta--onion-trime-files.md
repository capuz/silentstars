# Mobile Same Text Input Method Trime Onion Plan (Bopomofo, Double Pinyin, Shape Code)

####  ※ Commercial use is prohibited

## Preliminary Notes

- First, install the simplified [initialization plan](https://github.com/oniondelta/Onion_Trime_Files/tree/main/trimefiles/%E5%88%9D%E5%A7%8B%E5%8C%96%E6%96%B9%E6%A1%88), ensure it operates normally before installing this heavy plan.

- Set the mobile "Settings" "Screen On" time to the longest before "deploying".

  > "Screen Off Sleep" will affect the "deploy" time, and may even prevent "deployment".

- Go to "Settings" → "Keyboard Settings" → "Embedded Editing Mode" and select "None". (Not needed for version 3.3.1, required for version 3.2.14)

  > This aligns with the original intention of the plan.

- Go to "Settings" → "Keyboard Settings" → "Click Candidate Words" and enable "Directly Display Candidate Words". (Not needed for version 3.3.1, required for version 3.2.14)

  > This aligns with the original intention of the plan.
