# UDP Tunnel 

 - Script to set up a tunnel between a server in Iran and abroad
</div>
 
```
bash <(curl -Ls https://raw.githubusercontent.com/amirmbn/UDP2RAW/main/udp2raw.sh)
```
</div>

 - After running the script, first select option 1 (Install UDP2RAW binary)
 - Option 2 is related to the settings of the external server tunnel
 - Option 3 is related to the settings of the Iranian server tunnel.
