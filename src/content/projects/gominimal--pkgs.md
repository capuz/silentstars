# Minimal's Public Registry

The MPR has build specifications for a curated, regularly-updated set of open source packages
for use with Minimal. It also contains other specifications for common toolsets and other
helpers for development and working in CLI environments.

## Current Status

We have many common toolchains, shells, agents, and dev tools available and more are being added.

Thank you for your interest.

## Contributing

We'd love your help! Contributions to add new packages or update existing ones
are welcome.

**Not sure you want to write the package yourself?** That's completely fine —
please [open an issue](https://github.com/gominimal/pkgs/issues/new/choose)
requesting a new package or an update to an existing one and we'll take a look.
For anything non-trivial, opening an issue first is a great idea anyway so we
can align on approach before you invest time in a PR.

**Ready to send a PR?** Head over to [CONTRIBUTING.md](https://github.com/gominimal/pkgs/blob/HEAD/CONTRIBUTING.md) for
the development workflow and what we look for in a contribution.
