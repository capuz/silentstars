## What is InstructionX

InstructionX handles the parts of a desktop application that are not very exciting but that every tool has to deal with: plugin loading and unloading, configuration and data storage, background tasks, LLM, MCP, and a unified set of UI components. The specific tools built are determined by the plugins.

The current version is **Alpha 1.1.4**, and it runs on Windows 10/11 and macOS. The project is still under development, and interfaces may change. The framework runs from source code and is not distributed as a library.
