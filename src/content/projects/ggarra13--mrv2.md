mrv2
====

mrv2 is an open source professional player and review tool for VFX, animation and computer graphics.

macOS playback supports optional [VideoToolbox hardware decoding](https://github.com/ggarra13/mrv2/blob/HEAD/docs/hardware-decoding.md) for ProRes, H.264, and H.265, with automatic software fallback.
