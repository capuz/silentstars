## 📻 Project Introduction

**Omni-Agent Workshop** is a multi-dimensional agent platform based on secondary development of iFlytek's Astron-Agent. Three different types of agents have been built on a locally deployed platform: instruction-based, workflow, and real-time interactive digital humans.

**Instruction-based Agent** is a programmer proficient in multiple programming languages. It can help users efficiently complete various programming language-related development tasks and provide high-quality code solutions.

**Workflow Agent** is a resume optimization workflow that scores resumes submitted by users and provides improvement suggestions based on deficiencies.

**Real-time Interactive Digital Human Agent** is a host of a worry-relief platform that can transform user content into smooth and humorous program text, ensuring each sentence resonates with the audience. Through agent workflow orchestration, it automatically rewrites user-inputted text content into podcast-style scripts, and uses iFlytek's hyper-realistic voice synthesis technology to generate high-quality audio.
