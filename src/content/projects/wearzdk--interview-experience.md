# 面灵面经

> Real interview experiences from major internet companies, first-hand shares from platforms such as Nowcoder and Maimai.

**https://mj.mianlingai.com**

---

Automatically collects the latest interview experiences from platforms such as Nowcoder and Maimai every day, covering companies including ByteDance, Tencent, Meituan, Kuaishou, DiDi, Alibaba, and Ctrip, and popular positions such as Java, frontend, Go, and algorithms.

Supports multi-dimensional filtering by **company** / **position** / **technical tags** to quickly find the interview experiences you need.

## Local Development

```bash
bun install   # Install dependencies
bun dev       # Start the dev server at localhost:4321
bun build     # Build
```
