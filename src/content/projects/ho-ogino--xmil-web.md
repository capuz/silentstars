# X millennium Web

This is a web port of the X millennium emulator for the SHARP X1 series (X1 / X1turbo / X1turboZ), compiled to WebAssembly.
You can run X1 software in your browser without installing anything.

## Features

- Supports X1 / X1turbo / X1turboZ
- Floppy disks (D88 / 2D formats)
- Cassette tapes (CAS / CMT / TAP formats, with APSS head search support)
- SASI hard disk (up to 2 slots)
- PSG / FM sound (YM2151)
- File library (saved to browser storage, automatically remounted)
- State save / load (quick save and overwrite mode supported)
- Soft keyboard (follows X1 layout, with numeric keypad and cursor keys)
- Google Drive integration (uses only the drive.file scope)
- Fullscreen support (double-click)
- 4096-color mode (turboZ)
- **[X1Pen](https://github.com/ho-ogino/xmil-web/blob/HEAD/docs/X1PEN.md)** — A web IDE for writing and immediately running FuzzyBASIC + Z80 assembly in the browser
- **[X1Pen MCP Connector](https://github.com/ho-ogino/xmil-web/blob/HEAD/docs/X1PEN_MCP.md)** — Collaborate on an open X1Pen tab from Codex / Claude Code
