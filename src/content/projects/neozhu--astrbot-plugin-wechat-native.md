# WeChat Native

Connect AstrBot to personal WeChat so you can use models, voice, and plugin capabilities in private and group chats.
The plugin connects to WeChat through the **agent-wechat-native /v1 API**, runs inside AstrBot, and requires no additional Bridge service.

**Compatible versions:** AstrBot `>=4.29.3,<5` · Native `v2.9.0` (bound state databases can keep receiving events on `v2.7.1`–`v2.8.0`) · Python `3.12+`
