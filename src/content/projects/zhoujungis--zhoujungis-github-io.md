# Zhou Jun's Blog

> A personal blog recording technology, travel, and life, featuring a natural-colored responsive interface and frontend-backend separation architecture.

🔗 **Visit Online:** [zhoujungis.github.io](https://zhoujungis.github.io)

---

## ✨ Features

- 📝 **Article Management** — Markdown writing + Vditor online editor, supports drafts/publishing/pinning/scheduled publishing
- 🏷️ **Categories & Tags** — Article categorization, tag cloud, category filtering
- 💬 **Comment System** — Supports replies, nested comments, honeypot anti-spam
- 🔍 **Full-text Search** — Backend Django search, search result highlighting
- 🖼️ **Photo Gallery** — Image display + lightbox preview
- 🔗 **Friendly Links** — Dedicated links page
- 🗺️ **Footprint Map** — ECharts China map, city markers visited, grouped statistics by region
- 🌓 **Light/Dark Theme** — Warm white natural color / deep green dark color, auto memory
- 📡 **RSS Subscription** — Atom Feed
- 📧 **Email Subscription** — Auto notify subscribers on new articles (supports 163/QQ/Gmail SMTP)
- 📊 **Admin Dashboard** — Dashboard, article management, comment moderation, subscriber management
