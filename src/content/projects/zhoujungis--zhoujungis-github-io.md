# Stack Frame


> A "stack frame" of the mortal world that records technology, travel, and life, with a natural-color responsive interface and a frontend/backend separated architecture.

🔗 **Live site:** [zhoujungis.github.io](https://zhoujungis.github.io)

---

## ✨ Features

- 📝 **Article management** — Markdown writing + Vditor online editor, supports drafts/publish/pin/scheduled publishing
- 🏷️ **Categories & tags** — article categorization, tag cloud, category filtering
- 💬 **Comment system** — supports replies and nested comments, honeypot anti-spam
- 🔍 **Full-text search** — Django backend search with highlighted results
- 🖼️ **Photo wall** — image display + lightbox preview
- 🔗 **Friend links** — standalone friend links page
- 🗺️ **Footprint map** — ECharts map of China, markers for visited cities, statistics grouped by region
- 🌓 **Light/dark theme** — warm white natural tones / deep green dark tones, remembers your choice automatically
- 📡 **RSS subscription** — Atom Feed
- 📧 **Email subscription** — automatically notifies subscribers when a new article is published (supports 163/QQ/Gmail SMTP)
- 📊 **Admin dashboard** — dashboard, article management, comment…
