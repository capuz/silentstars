# 大肥鱼 · Memory System Benchmark

What do the various memory frameworks actually remember, and what do they forget? This project organizes facts, changed statements, agreements, and boundaries from long-running chats into checkable questions, and uses one shared set of rules to compare different systems.

The project currently focuses on **ultra-light chat scenarios with about two rounds per day, spanning up to six months**. One round means one user message and one assistant reply. It does not represent high-frequency chat, multi-person group chat, or the full range of real-user usage.

**The formal six-character test set is now public: the complete synthetic histories, 714 formal questions, scoring criteria and evidence, and an offline question-reading tool.** A standalone single-character example is also kept; the example and the formal volume are not the same data.
