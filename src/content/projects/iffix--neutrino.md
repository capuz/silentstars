## What is Neutrino Hub

Neutrino Hub is an app deployment panel plus a set of secure external access routes, built for programmers and students.

- **Panel**: Installs on your existing Windows, macOS, or Linux computer. Apps install with one click, and everything is managed in a single panel.
- **External access routes**: Scan a code once with your phone, and you can open these apps from anywhere. There are 6 connection methods, and traffic between your device and the hub is encrypted end to end.

**Just deploy it on your own computer. No domain name or extra server is needed.**

Want to keep running Claude Code on your phone, open your lab's VS Code from the dorm, or invite classmates to co-edit a paper? None of these apps need environment setup or port configuration.
