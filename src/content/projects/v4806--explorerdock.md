# ExplorerDock

Move window buttons from the Windows taskbar into a floating bar displayed at the top.

When working with multiple windows open, the taskbar gets cluttered with a row of window buttons. ExplorerDock removes these buttons from the taskbar and collects them in a lightweight floating bar that you can click to switch between them.

Demo video: https://www.bilibili.com/video/BV1UGew6rEWA/

## Features

- Window buttons are removed from the taskbar and displayed and switched in the floating bar instead; new windows automatically appear, closed ones automatically disappear
- Left-click to switch, minimize if already in focus; the currently active window button is highlighted
- Buttons display the window name and path, with icons taken from the actual path
- Dark / Light / Follow system / Fully customizable (color scheme, border width, overall scale, font)
- Takes over Alt+Tab: use more powerful app switching cards
- Floating bar position is draggable and remembered
- Floating bar auto-hides when docked to edge, center mode, lock position
- Floating bar can switch between banner/stacked mode
- Alt+Tab app switching cards can merge windows of programs with the same name
