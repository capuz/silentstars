## Usage Instructions

1. Download and unzip the compressed package
2. Double-click **LanWan.exe** to start the program
3. Click the **Refresh List** button to get the latest server list
4. Click the **Sequential Connect** button to connect to the servers in the server list one by one
5. The first connection will request **administrator privileges** to configure the security parameters required for L2TP/IPsec
