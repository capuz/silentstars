# M5Stack Firmware Simulation Platform

Simplified Chinese · [English](https://github.com/m5agent/m5stack-esp-emulator/blob/HEAD/README.en.md)

Run M5Stack firmware in a browser or local service, observe the screen, operate buttons and touch, integration-test the covered peripherals, and save reviewable runtime evidence.
The platform is based on C/QEMU and standalone device backends. UIFlow2 has the most complete validation coverage, and it also supports Arduino, ESP-IDF, and MicroPython images that have passed compatibility checks.
