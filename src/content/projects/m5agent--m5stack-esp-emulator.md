# M5Stack Firmware Simulation Platform

Simplified Chinese · [English](https://github.com/m5agent/m5stack-esp-emulator/blob/HEAD/README.en.md)

Run M5Stack firmware in a browser or local service to observe the screen, operate buttons and touch, integration-test the covered peripherals, and save reviewable runtime evidence.
The platform is built on C/QEMU and separate device backends. UIFlow2 has the most complete verification coverage, and the platform also supports Arduino, ESP-IDF, and MicroPython images that pass compatibility checks.
