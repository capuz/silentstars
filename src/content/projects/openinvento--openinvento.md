# OpenInvento

OpenInvento - Selfhosted Inventory Manager

Landing Page: https://openinvento.github.io/landingpage/
Documentation: https://openinvento.github.io/docs/

## Features
- Self-hosted inventory management system
- Simple and intuitive user interface
- Support for article images and attachments
- User management and shared inventories
- Very flexible and customizable inventory structure (custom fields, categories, etc.)
- Easy installation with Docker
- QR and Barcode Support
