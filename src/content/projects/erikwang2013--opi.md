# Open People Input (OPI)

The Chinese name is **小欧** (also the project's pet), and the English name is **opi**. The input method is officially called **小欧输入法** (opi input method also works).

## A multi-platform input method that returns to its essentials and is usable by everyone

> **Want to install it on your own machine?** Installation guides for each platform are in **[`docs/install/`](https://github.com/erikwang2013/opi/blob/HEAD/docs/install/README.md)** (build / package / install / usage, split by platform).
> **One more step is required after installing**: **add OPI to the input method group**. A newly installed input method is not enabled automatically. Without this step, it appears in the input method list but nothing happens when you type. (The fcitx5 plugin reload is already done automatically by the install script.)
> For step-by-step commands, see §4 of [`docs/install/linux.md`](https://github.com/erikwang2013/opi/blob/HEAD/docs/install/linux.md).
