# GitHub Developer Ranking in China

This project collects follower data of Chinese developers on GitHub and ranks them by distinguishing between developers and Markdown engineers.

## 🔍 Project Description

- **Data Source**: Public data obtained from the GitHub official API
- **Automatic Updates**: Data is automatically updated daily to maintain the timeliness of the ranking
- **Fast Loading**: The website loads quickly, providing a good browsing experience
- **Mobile Friendly**: Accessible on mobile, tablet, and computer

## 💻 Technical Implementation

### Frontend Architecture

- **[Astro](https://astro.build/)**: High-performance static site generation framework
- **[Tailwind CSS](https://tailwindcss.com/)**: Atomic CSS framework
- **TypeScript**: Type-safe development experience

### Data Processing

- **[GitHub REST API v3](https://docs.github.com/en/rest)**: Public data retrieval
- **Node.js**: Data processing service
- **[GitHub Actions](https://github.com/features/actions)**: Automation workflows

### Build Tools

- **pnpm**: High-performance package manager
- **Vite**: Modern frontend build tool
