# 1С как иностранный язык

> Учебный курс чтения кода 1С для абсолютных новичков без опыта программирования.

Эта книга — **первая**. Книги взаимно автономны, но связаны сквозным примером —
фирмой «Канцтовары».

## О книге

Главная идея — рассматривать 1С как **язык описания и преобразования данных в деловой системе**, а не как набор синтаксических конструкций.

Метафора иностранного языка проходит через весь курс: лексика → семантика → структура → идиомы → контекст.…
