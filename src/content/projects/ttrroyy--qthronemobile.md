# RawlineMobile

**Android client based on the sing-box and Xray cores**

Fork of [RawlineForAndroid](https://github.com/throneproj/ThroneForAndroid)

In addition to the standard sing-box and Xray protocols, it supports qWDTT, CSQTT, olcRTC, OpenFlux, DNSTT, VayDNS, SlipStream, MasterDNS, CottenDNS, Soar, S3 Bypass, and WireGuard obfuscation (wg-obfuscator, Phobos, wgobfs), with subscriptions, ping testing, and split routing.

  &nbsp;&nbsp;

## Download

The latest APK is available in [Releases](https://github.com/ttrroyy/qThroneMobile/releases/latest). Requires Android 7.0 or later; builds are available for arm64-v8a, armeabi-v7a, and x86_64. The app notifies you about new versions itself.

## Features

**New protocols.** qWDTT, CSQTT, olcRTC, OpenFlux, DNS tunnels, and S3 Bypass run through the original clients of these projects. They work like regular profiles: with routing, chaining, and ping testing.

**VK account binding.** Call hashes for qWDTT and CSQTT can be obtained automatically.
