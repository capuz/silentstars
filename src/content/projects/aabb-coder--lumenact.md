# LumenAct · Local Expression Model Preview Package

This package is the **local showcase page for the LumenAct expression model suite**. It bundles only one Lumen face, so users can see the public semantic selection and performance-curve effects. The page uses the single-character dashboard layout of Lumen's current promotional website, and does not provide Unity, Motive, or main project dependencies.

Source repository: [AaBb-coder/LumenAct](https://github.com/AaBb-coder/LumenAct). The preview source code and documentation are published. Companion resources are located in the [Hugging Face resource repository](https://huggingface.co/AaBbcoder/LumenAct). The resource repository contains `lumen-reference-face.blend` with 118 shape keys; the complete ready-to-use package will still be added after version organization. Downloading only the GitHub source cannot launch the model preview for now.

Project author: **Bilibili creator Lumen_流明_**. The base mesh of the Lumen reference face was made by **ぷらすわん**, and the project has obtained the corresponding commercial use license. The reference face resource is still licensed separately under CC BY-NC 4.0.
