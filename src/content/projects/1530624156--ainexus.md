# AiNexus AI Gateway

Enterprise-internal AI large model gateway: a pure HTTP transparent proxy (OpenAI compatible) that provides unified authentication, dynamic routing, and multi-channel disaster recovery, with an admin/internal user console; **no Token billing, no C-end user management**.

> Design taboos: do not introduce Spring AI / LangChain4j, and do not introduce WebFlux/Reactor. Only pass through HTTP messages and raw JSON/SSE streams.

---

## 1. Tech Stack

| Layer | Choice | Notes |
|---|---|---|
| Language/runtime | JDK 21 (LTS) | Full virtual thread support |
| Web | Spring Boot 3.3.5 + Servlet(Tomcat) | `spring.threads.virtual.enabled=true`, request handling runs on virtual threads |
| Upstream forwarding | OkHttp3 4.12 | Dual-instance connection pool + streaming ResponseBody, see `OkHttpConfig` |
| Persistence | MySQL + MyBatis-Plus 3.5.7 | Channel main table `channel` + model binding table `channel_model` |
| Cache/concurrency | Redisson 3.34 | `RouteCacheService` versioned Token/route cache, channel round-robin RAtomicLong, channel concurrency RSemaphore |
| Auth | HandlerInterceptor | `Authorization: Bearer {Internal-Key}`, Mock whitelist + Redis set |
