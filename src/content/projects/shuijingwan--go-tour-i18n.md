# go-tour-i18n

**Simplified Chinese** | [English](https://github.com/shuijingwan/go-tour-i18n/blob/HEAD/README.en.md)

`go-tour-i18n` is a multi-language-oriented A Tour of Go translation, verification, synchronization and publishing project.

This project is a community-maintained unofficial project, not maintained by Google, the Go team, or go.dev officials, and does not imply affiliation, endorsement, or sponsorship with the official project. The original A Tour of Go content and source code come from the official Go upstream repository.
