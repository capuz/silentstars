# LightBoard (轻白板)

A full-screen whiteboard built on .NET 11 and WPF, for classroom writing and courseware annotation.

- Ready to use out of the box
- Designed around classroom needs, validated in real classrooms, and continuously improved based on classroom feedback
- Extreme performance, suitable for low-end devices
- Can replace Seewo Whiteboard / Seewo Light Whiteboard / Honghe Whiteboard (鸿合白板)

## Performance

- Test machine: Seewo large display, Windows 10, 6th-gen i7
    - Startup time < 0.5s
    - Zooming and dragging easily saturate the screen's 30 Hz frame rate
    - Drawing pipeline latency < 30ms
    - Erasing pipeline latency < 40ms
