# EmVB

EmVB is a visual page builder plugin for [EmDash CMS](https://github.com/emdash-cms/emdash). You build pages in a full-screen editor inside the EmDash admin, and EmVB publishes them as plain HTML and CSS. It runs wherever EmDash runs: Node with SQLite, or Cloudflare Workers with D1.

Try it without installing anything in the [playground](https://emvb.dev/playground): the real editor and a starter page, in your browser. Your edits stay on your device.

**Current release:** 1.3.0 (see the [changelog](https://github.com/PerkyZZ999/EmVB/blob/HEAD/CHANGELOG.md)). It adds the marketing widgets (Counter, Progress bar, Countdown, Map, Price table, Price list, Call to action, Flip box, Animated headline, Share buttons, Hotspots) and imports them from Elementor, with Slides and Testimonial Carousel as a Carousel. Everything is additive: 1.x pages open unchanged and the page format stays frozen for 1.x ([docs/SCHEMA.md](https://github.com/PerkyZZ999/EmVB/blob/HEAD/docs/SCHEMA.md): layout schema 18, design schema 17). Public pages load no script unless an element opts in. See the [changelog](https://github.com/PerkyZZ999/EmVB/blob/HEAD/CHANGELOG.md) for every release.
