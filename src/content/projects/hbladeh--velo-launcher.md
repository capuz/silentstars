Velo is a Chinese-language app launcher for **Windows 10 / 11 x64**, built with **Rust + Slint**. Press `Alt+Space`, type an app name, Pinyin, or initials, then press `Enter` to launch. Frequently used apps, pinned home items, and Windows system shortcuts are all in one window.

The native UI and business logic run in the same process. Settings, the app index, and usage records are stored locally on your machine. It supports list and grid views, light and dark themes, and the software interface is in Simplified Chinese. This page is the main documentation, and an [English README](https://github.com/HBLADEH/velo-launcher/blob/HEAD/README.en.md) is also available.

> **v0.13.0** updates the workbench (a test feature that is disabled by default). Launch combinations support home-page pinning and frequency sorting. The installer is not yet signed. [v0.13.0 release notes](https://github.com/HBLADEH/velo-launcher/blob/HEAD/docs/releases/0.13.0.md)
