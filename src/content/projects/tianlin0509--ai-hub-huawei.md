# AI HUB-Huawei · Beta Pioneer Edition (CodeAgent)

> **⚠️ Downloads and updates are available only on the internal company source:** The latest version is published only on the internal company source platform (OpenX, search for **AI Hub** (project name AI HUB-Huawei)). The GitHub page no longer receives new releases and is kept only as a historical archive (frozen at v5.6.107). Please download and install from the internal company source; after that, update in-app with one click.

This brings the company intranet's **Code Agent CLI** into a Windows desktop workbench: standalone sessions, multi-AI group chats, card view, hibernation and resume, history search, and automatic naming. This is the company edition of AI Hub (product name AI HUB-Huawei, Beta Pioneer Edition). The current version is **v5.6.125**, synced from upstream **1.6.738** (see `community-edition.json` for the specific commit).
