# PLATEAU QGIS Plugin

This is a beta plugin for loading "PLATEAU 3D City Models" in [QGIS](https://www.qgis.org/), an open-source GIS application. It can load CityGML files that conform to version 3.0 of the "3D City Model Standard Product Specification" for PLATEAU.

Example of loading [CityGML (v2) for Numazu City, Shizuoka Prefecture](https://www.geospatial.jp/ckan/dataset/plateau-22203-numazu-shi-2021/resource/758fe63a-b20f-4d5d-817d-c35eac530143) and displaying the LOD3 data with Qgis2threejs:

## How to Use the Plugin

### System Requirements

To use this plugin, QGIS (version 3.28 or later) must be installed. For information on downloading and installing QGIS, see the [QGIS official download page](https://qgis.org/ja/site/forusers/download.html).

### Installing the Plugin

This plugin is [published in the official QGIS plugin repository](https://plugins.qgis.org/plugins/plateau_plugin/) and can be installed in QGIS with the following steps:

1. Start QGIS.
2. From the menu, open "Plugins" → "Manage and Install Plugins".
3. In the plugin search box, type "PLATEAU" or similar, then install the "PLATEAU QGIS Plugin" from the results.
