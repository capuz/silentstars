# M3U Media Resource Library

Private media resource organization and M3U/TXT source generation tool (background program, no UI).

Uses SQLite to maintain the resource library. After manually adding resources, one command generates `movie.m3u` / `tv.m3u` / `anime.m3u` / `variety.m3u` **importable into 途播** (plus optional `.txt` text sources). The collection module is designed independently, so multiple collection sites can be added later without invasive changes.

## Tech Stack

- Python 3.10+ (phase one uses only the standard library, **zero third-party dependencies**)
- SQLite (database file `data/media.db`, WAL mode)

## Quick Start

```bash
# 1. Add resources
python main.py add -c movie -n "流浪地球2" -t 科幻 -r 中国大陆 -y 2023 \
    -u "http://example.com/wander2.m3u8" -q "4K" -d "太阳危机下的人类迁徙计划"

# 2. View resources
python main.py list                # all
python main.py list -c movie       # movies only
python main.py list -k 流浪         # search by name/description keyword

# 3. Generate source files (output to output/)
python main.py generate            # movie.m3u / tv.m3u / anime.m3u / variety.m3u
python main.py generate --txt      # also generate .txt text sources
