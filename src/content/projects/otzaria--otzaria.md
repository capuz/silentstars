## About The Project

I felt the absence of an open-source application for the Jewish library, for computers.

Torat Emet is old and no longer maintained, and Sefaria's app is great, but it does not work well on computers.

So I decided to build one myself. At first I didn't know Dart and Flutter at all, but it was fun. I **love** learning new technologies!

The database itself is accessible to everyone thanks to the important work of the Sefaria organization, so a big thank you to them for that.

Main features of the project:
* The software is free and will remain free forever.
* It was built to work efficiently on every device, including Windows, Linux and Android.
