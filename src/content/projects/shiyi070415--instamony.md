# Instamony

A native HarmonyOS (ArkTS / ArkUI) Instagram client: the entire UI is built with ArkUI, and data comes from **the session held by a hidden WebView together with the private mobile API used by instagrapi**.

A personal / learning project, not affiliated with Instagram / Meta.

[English](https://github.com/ShiYi070415/Instamony/blob/HEAD/README.en.md) · Licensed under [Apache-2.0](https://github.com/ShiYi070415/Instamony/blob/HEAD/LICENSE).

## Feature Overview

| | |
|:--|:--|
| **Full feed experience** | Home timeline (pull to refresh / load more at the bottom / skeleton screens), story tray and player, full-screen vertical swiping for Reels, post page and comments overlay. |
| **Direct messages** | Inbox and conversation page (text / media / shared posts / Reels / stickers / voice and other XMA types), sending text, **real-time MQTToT push** (new messages are inserted directly into the current conversation), local notifications, and "tap a notification to go straight to the conversation". |
| **Search** | Search accounts by keyword, a three-column recommendation waterfall when the keyword is empty, tap to open Reels. |
| **Profile** | Four tabs: posts / videos /…
