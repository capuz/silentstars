# Learn Tsinghua App: Tsinghua Online Classroom PC Desktop App

This software has the following advantages compared to other Tsinghua Online Classroom clients:

1. Will not save any account or password
2. Uses modern encryption protocols to communicate with Tsinghua Online Classroom
3. The code is very concise, anyone can conduct security audits
4. App is built by GitHub, the build process is open and trustworthy
5. The macOS version runs in application sandbox, will not damage your system

Supported platforms: macOS and Windows

## Download

Find the file for your platform [here](https://github.com/jiegec/learn_tsinghua_app/releases), download and open it.

## Local Running

```shell
git clone https://github.com/jiegec/learn_tsinghua_app
npm install
npm start
```
