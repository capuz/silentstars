Dela is an agent product designed specifically for SJTUer.

Dela's core is built on Pi. All campus service features interact with the school's servers through SJTU's public APIs. Account credentials are encrypted with the system keychain and stored locally on this machine. Model service information is saved as JSON files in `~/.dela`. All data is stored locally and is not uploaded to any server.
