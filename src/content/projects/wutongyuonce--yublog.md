# YuBlog

[Live preview](https://www.wutongyu.site/) · [Documentation index](https://github.com/wutongyuonce/YuBlog/blob/HEAD/docs/README.md) · [Development & deployment](https://github.com/wutongyuonce/YuBlog/blob/HEAD/docs/guides/development.md) · [English](https://github.com/wutongyuonce/YuBlog/blob/HEAD/README_ENG.md) · [Changelog](https://github.com/wutongyuonce/YuBlog/blob/HEAD/CHANGELOG.md)

Wutongyu's personal blog, built with Astro 7, TypeScript, and Markdown/MDX. It focuses on reading articles, with sections for projects, books/movies/games, personal introduction, and friend links. It offers light and dark themes, optional accent color schemes, full-text search, and full-text RSS.

Pages and articles are generated as static HTML at build time, so normal reading does not depend on a backend. The homepage Last.fm ranking and the [Shiqu (拾趣) playlists](https://github.com/wutongyuonce/YuBlog/blob/HEAD/docs/design/playlists.md) are fetched through runtime APIs, and comments are provided by GitHub Discussions/Giscus.
