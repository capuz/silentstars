# ArtCraft Agent Skills

**Twenty evidence-verified agent skills — plain `SKILL.md` files following the [agentskills.io](https://agentskills.io) standard — that teach AI coding agents to drive the [ArtCraft](https://getartcraft.com) creative suite. Built for Claude Code, OpenAI Codex & ChatGPT desktop, OpenCode, Devin, CommandCode, ZCode, Google Antigravity and Gemini CLI.**

ArtCraft is the open-source, clean-room creative suite from the [`storytold`](https://github.com/storytold) organization — thirteen pure-Rust apps covering image editing, photo raw development, vector illustration, interface design, page layout, word processing, presentations, spreadsheets, PDF work, motion graphics, video editing, audio and 2D CAD, plus ArtCraft Studio, a Rust + TypeScript AI image and video generation workspace, AniCraft (2D vector animation studio) and Craft Anything (ArtCraft's own "see how software works, rebuild it with AI" workbench) — all installable via the [ArtCraft Launcher](https://github.com/storytold/craft-launcher). Four more ship in the same launcher: TextureCraft (3D texture painting) and MaterialCraft (node-based procedural materials and PBR map export) from storytold,…
