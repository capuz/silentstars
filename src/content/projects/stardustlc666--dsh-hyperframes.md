# HyperFrames

**Create and export videos with HTML in DSH.**

**[Installation](#安装) · [Usage flow](#开始使用) · [Full documentation](https://github.com/STARDUSTLC666/dsh-hyperframes/blob/master/docs/REFERENCE.zh.md)**

## Features

- Start from title card, product introduction, and image carousel templates.
- Edit content, upload assets, and adjust image order.
- Use the official preview and local rendering, keeping the project editable.

## Installation

In the DSH desktop app’s “Plugins” panel, install `dsh-hyperframes`. If the command line is already configured, you can also use:

```bash
dsh plugin --profile desktop add dsh-hyperframes
```

For the web version, change `desktop` to `web`. After installation, restart the corresponding DSH. The host requirement follows the package declaration `>=0.2.2-rc.3`.

## Getting Started

1. Open HyperFrames from the left sidebar, click “New video,” choose a template, and fill in the content.
2. Save the project first, then upload assets. Adjust the order on the “Assets” page; the original files remain unchanged.
