# dsh-posterflow-ai

A [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH) plugin that adds an “**Enable Image Generation Mode**” entry to the web interface sidebar. Clicking it **covers the entire window** with a transition animation, then navigates to [PosterFlow](https://www.posterflow-ai.xyz/).

# PosterFlow AI

## Online Use

Visit **[PosterFlow AI Online](https://www.posterflow-ai.xyz)**. No download or installation is needed; just open it and start using it. You can use the platform credits you get when you sign up, or use your own API Key to configure and control the API yourself.

> Your own key is stored only in the current browser tab. It is not written to the database, generation history, or cloud image storage. You will need to enter it again after closing the tab. Only use HTTPS endpoints provided by trusted vendors.

PosterFlow AI is an AI image workspace that brings everyday image generation, reference-image editing, local inpainting, and an infinite canvas together on one page.
