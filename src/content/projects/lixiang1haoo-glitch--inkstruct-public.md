# InkStruct 墨构

Turn your own handwriting into a reusable font, then use it to typeset a Markdown page. InkStruct handles capture, generation, font packaging, and typesetting entirely on your local machine.

[Highlights](#项目特色) · [Download](#下载) · [Documentation site](https://lixiang1haoo-glitch.github.io/InkStruct-Public/) · [Developer docs](https://lixiang1haoo-glitch.github.io/InkStruct-Public/developers/) · [Build from source](#源码构建) · [Quick guide](https://github.com/lixiang1haoo-glitch/InkStruct-Public/blob/HEAD/docs/USER_GUIDE.md) · [Report issues](https://github.com/lixiang1haoo-glitch/InkStruct-Public/blob/HEAD/CONTRIBUTING.md)

Windows x64 · 0.1.107 · Python / Qt

The “Settings” panel in the lower-left corner provides, in one place, the current document, defaults for new documents, and application preferences. The typesetting page supports direct USB connection control of the 炽写 N1.

0.1.100 adds three recommended recording tasks under “Capture → Chinese character samples,” with cumulative targets of 32, 100, and 400 characters. When a task is opened, the remaining character count is calculated from the current writer's existing qualified samples.
