# 青春幻想引擎 · Youth Fantasy Engine

**A long-form writing workbench that links worldbuilding, characters, outlines, and manuscript text into one thread**

Desktop (Windows) | Portable (run from a USB drive) | **Web** (use directly in the browser) | Source version `v3.2.2`

📦 Repository: [Gitee](https://gitee.com/tgxy2026/youth-fantasy-engine) | [GitHub](https://github.com/tgxy2026/youth-fantasy-engine) | ⬇️ Download: [Releases](https://gitee.com/tgxy2026/youth-fantasy-engine/releases)

🖥️ Three forms: **Desktop installer** (no Node.js needed, double-click to install) | **Portable** (run from a USB drive, requires Node.js) | **Web** (no installation; guests save locally, paying users get cloud storage for cross-device use)
