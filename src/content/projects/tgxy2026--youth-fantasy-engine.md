# Youth Fantasy Engine · Youth Fantasy Engine

**A long-form creative workbench that links worldbuilding, characters, outlines, and manuscript text into one thread**

Desktop (Windows) ｜ Portable (run from a USB drive) ｜ **Web version** (use directly in the browser) ｜ Current source version `v3.5.3`

📦 Repository: [Gitee](https://gitee.com/tgxy2026/youth-fantasy-engine)　｜　[GitHub](https://github.com/tgxy2026/youth-fantasy-engine)　｜　⬇️ Download: [Releases](https://gitee.com/tgxy2026/youth-fantasy-engine/releases)

🖥️ Three forms: **Desktop installer** (no Node required, double-click to install)　｜　**Portable** (run from USB, requires Node.js)　｜　**Web version** (no installation; guest local storage / cloud storage with a logged-in account)
🌐 Web version direct link: <https://youth-fantasy-engine.online> (open in a browser and start writing, nothing to install)
🔗 Starting from 3.3.2: **Same account across desktop, web, and switching computers — pick up right where you left off** (cloud works library · automatic per-book sync · you choose how conflicts are resolved · deleted items can be recovered)
