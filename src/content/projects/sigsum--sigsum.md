# Documentation

This repository contains protocol specifications and other
documentation related to the [Sigsum project][].

[Sigsum project]: https://www.sigsum.org/

## Structure

  - [archive/](https://github.com/sigsum/sigsum/blob/HEAD/archive) - persisted pads and meeting minutes
  - [assets/](https://github.com/sigsum/sigsum/blob/HEAD/assets) - project assets such as fonts, colors, and logos
  - [proposals/](https://github.com/sigsum/sigsum/blob/HEAD/proposals) - proposals relating to design or the project at large
  - [www.sigsum.org/](https://github.com/sigsum/sigsum/blob/HEAD/www.sigsum.org) - source code of the project website
  - Top-level - documents like [log server protocol](https://github.com/sigsum/sigsum/blob/HEAD/log.md), and
    [project history](https://github.com/sigsum/sigsum/blob/HEAD/history.md)

## Contributing

Feedback ranging from minor nits to proposals are most welcome.  Get in touch
via the [sigsum-general][] email list, in room `#sigsum` at OFTC.net and Matrix,
or through GitLab issues and merge requests.  Anything that requires a formal
decision is decided on Tuesdays at 1100 UTC during [weekly project meets][].
