# Genfeed.ai

**The open-source content engine your agent can run. Self-host it free or use Cloud.**

Create on-brand videos, images and posts, then review and publish to your
connected channels. Work in Genfeed or connect the AI agent you already use.

**If Genfeed is useful, [star it on GitHub](https://github.com/genfeedai/genfeed.ai) ⭐ so others can find it.**

_One real generation on a self-hosted instance: prompt, generate, approve. About 20 seconds, unedited apart from trimming._

```bash
npx @genfeedai/create my-genfeed
```

Needs Docker Compose v2 and Node.js 24 or newer. The wizard verifies the release bundle,
asks for your [OpenRouter API key](https://openrouter.ai/keys), then starts it. Install guide: [genfeed.ai/self-hosted](https://genfeed.ai/self-hosted)
· [docs.genfeed.ai](https://docs.genfeed.ai/self-host/installation).

> [!WARNING]
> Genfeed is `0.x` and under active development. Breaking changes ship with an
> **Upgrade note** in the release body; semver becomes strict at `v1.0.0`.
