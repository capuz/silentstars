# StarCraft II Galaxy to GUI Trigger Converter — KSP Edition

**A reworked Trigger Revizer implementation, developed together with Vise.**

> **Windows release candidate: installer, portable app and reproducible public build.** See [Install and run](https://github.com/VoVanRusLvSC2/SC2-Trigger-Recovery-Tool-KSP-Edition/blob/HEAD/INSTALL.md), [build instructions](https://github.com/VoVanRusLvSC2/SC2-Trigger-Recovery-Tool-KSP-Edition/blob/HEAD/BUILDING.md), [source status](https://github.com/VoVanRusLvSC2/SC2-Trigger-Recovery-Tool-KSP-Edition/blob/HEAD/SOURCE_STATUS.md) and [remaining qualification](https://github.com/VoVanRusLvSC2/SC2-Trigger-Recovery-Tool-KSP-Edition/blob/HEAD/ROADMAP.md). Node and runtime dependencies are bundled; game metadata comes from your installed SC2.

**Trigger Revizer KSP** is a StarCraft II (SC2) trigger recovery project. It reconstructs editable GUI trigger markup (`Triggers` XML) from Galaxy source such as `MapScript.galaxy`, and completes missing or changed sections of an existing trigger tree.
