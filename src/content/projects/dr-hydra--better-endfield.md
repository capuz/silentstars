# Better Endfield Next

[Simplified Chinese](https://github.com/Dr-hydra/Better-Endfield/blob/HEAD/README.md) | [English](https://github.com/Dr-hydra/Better-Endfield/blob/HEAD/README.en.md)

Better Endfield Next is an open-source modular tool for Arknights: Endfield. It provides third-party character models, MMD playback, camera and UI enhancements, per-character voice lines, title-screen customization, and PC combat statistics and gacha record management. Windows and Android share most of the core native feature source code. BEM model packs and MMD works can be used across both platforms.
