# Cytellect

**Get your microscopy publication-ready.**

🏆 Winner, Tokyo AI Hackathon 2026

[Product LP](https://cytellect.app/) · [Public demo](https://cytellect.app/demo) · [Windows](https://github.com/genellect/cytellect/releases/tag/v0.1.0-local.24) · [Docker](https://github.com/genellect/cytellect/blob/HEAD/docs/docker-desktop.md) · [Statistical analysis methods](https://github.com/genellect/cytellect/blob/HEAD/docs/implementation-overview.ja.md#統計解析) · [Documentation](https://github.com/genellect/cytellect/blob/HEAD/docs/README.md)

Cytellect is an analysis platform for life science researchers that handles everything from microscopy image analysis through statistical processing to graph output. For instance segmentation it uses the deep learning models StarDist and Cellpose-SAM (SAM ViT-L), and for quantification and statistical inference it uses shared implementations built on NumPy, SciPy, and statsmodels.
