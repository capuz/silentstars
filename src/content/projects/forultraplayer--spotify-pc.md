**Korean** | [English](https://github.com/ForUltraplayer/SPOTIFY_PC/blob/HEAD/README.en.md)

Shows the Korean pronunciation of Japanese songs alongside the lyrics in the Spotify desktop lyrics view. It pulls Korean readings from 한음 and 나무위키 (Namu Wiki) and aligns them line by line with the Spotify lyrics. YouTube links can also be played from the same list as Spotify tracks.

Built on [SpotX](https://github.com/SpotX-Official/SpotX) + [Spicetify](https://github.com/spicetify/cli) + [ivLyrics](https://github.com/ivLis-Studio/ivLyrics). The current public version is 0.9.3.

> This is an unofficial hobby project by an individual. Maintenance and updates are not guaranteed, so please read the [Disclaimer](#면책) first.
