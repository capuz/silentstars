# WorkBuddy2API-Hub — Multi-Account Gateway Hub for International and China Editions

> **Important**
>
> **Official group chat**: [https://t.me/wb2apihub](https://t.me/wb2apihub)
>
> **Credential security**: This project is a locally deployed gateway. At runtime it reads the account credentials that users import themselves, locally, in order to call official APIs; credentials are stored in the user's own `accounts/` directory. The project does not upload credentials to any third-party server of this project, and it has no hidden credential collection or upload logic. Immediately shut down public exposure, contact the official provider to revoke all OAuth / device authorizations, and re-authorize only after confirming the old token returns `401`.
