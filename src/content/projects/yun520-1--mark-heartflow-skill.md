# HeartFlow (心虫) — AGI's Discrimination Layer

> Large models can generate infinitely, but who will judge? HeartFlow is that "judge".

**In the five layers of AGI capabilities, HeartFlow only occupies the 1st layer — discrimination. It does not generate, reason, remember, or execute. It only judges whether existing things are right or wrong.**

## One Sentence

**HeartFlow is not a chatbot, nor a search engine; it is a verification gate installed between AI and users.**

- LLM generates answers → HeartFlow checks if the evidence is sufficient → only outputs if passed
- LLM gives suggestions → HeartFlow checks the Q table for similar errors → only allows if none found
- LLM wants to execute actions → HeartFlow performs mission alignment checks → aligned/drifted/diverged

**Big companies do not do this because it is not profitable. But without a discrimination layer, AGI is like a person without pain perception.**
