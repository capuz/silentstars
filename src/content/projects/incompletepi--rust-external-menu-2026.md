# 🟥 Rust Mod Menu 2026 — External Interface & Configuration Toolkit

**Rust Mod Menu 2026** provides a modern external interface for Rust with profile presets, visual information panels, item and world views, map utilities, interface customization, and configurable hotkeys.

This variant is designed around a minimal UI and reusable settings so the repository stays easy to understand and update.

> **Note:** This repository describes the interface and configuration layer of the project. Exact behavior can vary between builds and Rust updates.

## Features

### 🖥️ External Overlay Interface

The project is organized around a standalone menu-style interface with multiple sections:

```text
Dashboard
Overlay
Player Info
Items
World
Map
Profiles
Interface
Settings
```

Each section can be configured independently.

### 👤 Player Information

Supported interface fields can include:

- player name;
- distance;
- status;
- group / team information;
- configurable range;
- display filters.
