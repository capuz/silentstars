## Welcome

- CatClawVideo is a cross-platform video player built on .NET MAUI
  - A modern cross-platform video player built with .NET MAUI

## Feature

- **Multi-source Aggregation**
  - CatClaw Source (local JSON source files) + TVBox / Video Repository subscriptions (MacCMS JSON sites, spider crawler sites), unified browsing of multiple sources and cross-source search
- **Subscription Parsing**
  - TVBox plaintext JSON configuration parsing, triple decryption channels for encrypted sources (image tail steganography, FanTaiHard official decryption interface, plaintext reading)
- **Crawler Runtime**
  - `drpy2` JS script crawler (built-in Jint JS engine); Java jar/dex crawler (`csp_Xxx`, loaded via JavaBridge on desktop)
- **Dual-platform Player**
  - Android uses Media3 ExoPlayer (including HLS), Windows uses WinUI MediaPlayer
- **Complete Media Library**
  - Play history, favorites, local media; built-in BitTorrent download and streaming cache
