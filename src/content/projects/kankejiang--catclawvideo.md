## Welcome

  - A modern cross-platform video player built with .NET MAUI

## Feature

- **Multi-source Aggregation**
  - CatClawVideo sources (local JSON source files) + TVBox / Video Repository subscriptions (MacCMS JSON sites, spider crawler sites), unified browsing across multiple sources and cross-source search
- **Subscription Parsing**
  - TVBox plaintext JSON configuration parsing, encrypted source with triple decryption channels (image tail steganography, official decryption API, plaintext direct read)
- **Crawler Runtime**
  - `drpy2` JS script crawler (built-in Jint JS engine); Java jar/dex crawler (`csp_Xxx`, loaded via JavaBridge on desktop)
- **Dual-end Player**
  - Android uses Media3 ExoPlayer (with HLS), Windows uses WinUI MediaPlayer
- **Complete Media Library**
  - Playback history, favorites, local media; built-in BitTorrent download and streaming cache
