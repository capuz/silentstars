# ServerS4A12 Management Toolkit

[AGPL v3.0] [.NET 10.0] [Windows 10/11]

---

## Project Introduction

A fully functional management suite designed for the ServerS4A12 server simulator, specifically for non-technical users, allowing easy completion of tasks without needing to understand .NET SDK, PowerShell, or server architecture:

- **Incremental Updates**: One-click incremental/full updates, automatically pulling the latest source code and compiling it.
- **Save Management**: Switch/rename/import/export/backup, supports drag-and-drop switching.
- **DX11/DX12 Rendering**: One-click patch switching to improve game smoothness, supports watermark removal.
- **GM Tools**: Integrated official synchronized update version.
- **Server Control**: Start/stop management + PVF status detection.
- **Environment Detection**: Automatically detects and installs .NET SDK.
