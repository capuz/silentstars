# Selective Remote

### Your infrastructure. One workspace.

**Russian** · [English](https://github.com/PastFly/Selective-Remote/blob/HEAD/README_EN.md)

A native Mac app where connections, files and commands are kept side by side. Work with SSH, RDP, SFTP and tunnels without losing context between tools.

**Current release: v0.31.0 (162)** · macOS 14+ · Apple Silicon · free, open source

**[Download v0.31.0](https://github.com/PastFly/Selective-Remote/releases/tag/v0.31.0)** · [Site](https://pastfly.github.io/Selective-Remote/ru/) · [Cloud](https://cloud.pastfly.ru/) · [Guides](https://pastfly.github.io/Selective-Remote/ru/#guides)

> All screenshots below show the real application **0.32.0 (163) candidate** with fictional demo data. This interface has not been released yet; the downloadable release is **v0.31.0 (162)**.

## Connect. Organize. Work.

- **Connect:** SSH and RDP on selected Mac displays; Telnet and Serial for specific scenarios.
- **Organize:** profiles, groups, favorites and tags keep your infrastructure in order.
- **Work:** terminal, two-pane SFTP, SSH tunnels and Snippets, all available from one app.
