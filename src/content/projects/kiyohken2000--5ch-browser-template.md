# Ember

A browser dedicated to 5ch.io (Tauri + React desktop app).

## Download

Download the latest ZIP from [GitHub Releases](https://github.com/kiyohken2000/5ch-browser-template/releases) and extract it to start using the app.

- **Windows**: `ember-win-x64.zip`
- **macOS**: `ember-mac-arm64.zip`
- **Linux**: AppImage / deb / rpm (x86_64 / AArch64)

Official site: https://ember-5ch.pages.dev

## Main Features

### Browsing

- Board list (category tree / search filter / Boards and Fav tab switching)
- Board button bar (one-click access to favorite boards, drag to reorder, and the "お気に入り" button opens new posts from favorite threads together in tabs)
- Thread list (sort / search / search history / NG / unread management / new post count / momentum bar / age-based color coding / dat number column / new thread ★ mark / column display and order switching)
- Thread list sort remembered per board (opens in the last sort order for each board, favorites, or recently opened threads; ON/OFF)
- In the thread list, hovering over a row with a truncated title shows the full title in a popup
- Search thread titles across all boards (search from the thread list search box; run with Ctrl+Enter;…
