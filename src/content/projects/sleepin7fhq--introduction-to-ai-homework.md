# Introduction-to-AI-homework

Welcome to the Introduction to Artificial Intelligence course homework submission repository! This repository uses **direct submission through the web interface**. All students must strictly follow the rules below when submitting homework.

## 📌 Submission Guidelines

1. **Accept the collaborator invitation**: The class representative adds everyone as a Collaborator in the backend. Check the inbox of the email address you registered with GitHub for the invitation email and click to accept it, or open this repository's homepage and click the Accept invitation button at the top.
2. **Upload directly**: No need to Fork, create branches, or open PRs. Everything is done directly in this repository's web interface by uploading files.
3. **Create your personal directory**: Complete your homework under homework/hwn/your student ID and name/. For example, homework/hw1/63026001张三/. Each assignment must have its own folder under hwn, such as hw1/63026001张三 and hw2/63026001张三.
