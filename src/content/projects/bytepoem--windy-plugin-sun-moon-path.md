# Sun & Moon Path for Windy

**Chinese** · [English](https://github.com/bytepoem/windy-plugin-sun-moon-path/blob/HEAD/README_EN.md)

Plan photography of sunrise, sunset, the Moon, the Milky Way, morning and evening glow, fiery clouds, and rainbows on the Windy map. Combine celestial direction, cloud distance, weather, and saved shooting spots to choose the best timing. Supports Chinese and English, desktop and mobile.

## Installation and Getting Started

Current release: **0.12.4** · [Changelog](https://github.com/bytepoem/windy-plugin-sun-moon-path/releases/tag/0.12.4)

Enter the following URL in Windy's external plugin loader, then open **Sun & Moon Path**:

```text
https://windy-plugins.com/17629746/windy-plugin-sun-moon-path/0.12.4/plugin.min.js
```

1. **Choose a location**: Click the map, or enter WGS84 / GCJ-02 coordinates. Chinese place-name search requires your own map service API key, entered in "Settings."
2. **Choose a time**: Select a date, then jump to shooting times using the local time bar or the Sun, Moon, or Galactic Center rise/set buttons.
3. **Check conditions**: Review events and weather, plan using clouds or rainbows, or select 2–5…
