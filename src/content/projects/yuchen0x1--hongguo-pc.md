## 📦 Download

Download the Windows x64 installer from the [latest stable release](https://github.com/yuchen0x1/HongGuo-PC/releases/latest).

| | |
|---|---|
| **Download link** | [GitHub Releases latest](https://github.com/yuchen0x1/HongGuo-PC/releases/latest) |
| **File** | `hongguo-downloader-<版本>-win-x64-setup.exe` |
| **Install** | Double-click to run. Guided setup, with a choice of install directory |

The installer is **not code-signed**. If a SmartScreen prompt appears on first run, click More info → Run anyway.

Installers for previous versions are kept on the [releases page](https://github.com/yuchen0x1/HongGuo-PC/releases).

> The release page also has a `latest.yml`. It is the metadata that automatic updates need for older and later installed versions. It is not an installer, so do not run it on its own.
