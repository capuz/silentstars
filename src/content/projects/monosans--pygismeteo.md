# <img src="https://raw.githubusercontent.com/monosans/pygismeteo/main/docs/assets/logo.svg" alt="" width="40" align="top"> pygismeteo

A Python wrapper for the [Gismeteo API](https://gismeteo.ru/api/) with typed responses. The async version is called [aiopygismeteo](https://github.com/monosans/aiopygismeteo).

Development is on hold: the author doesn't have a Gismeteo API token, so the library isn't tested against the real API. It works with Gismeteo API v2; the new v4 is not supported. Weather data without a token can be obtained through [pywttr](https://github.com/monosans/pywttr).
