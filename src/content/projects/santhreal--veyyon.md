## Install

**Linux and macOS**

```sh
curl -fsSL https://get.veyyon.dev | sh
```

**Windows**

```powershell
irm https://veyyon.dev/install.ps1 | iex
```

The installer verifies the release checksum and binary before replacing an existing installation. See [Install Veyyon](https://github.com/santhreal/veyyon/blob/HEAD/docs/handbook/src/using/install.md) for supported platforms, pinned releases, source checkouts, updates, rollback, and uninstall.
