# Claude Fable 5.2 / GPT-6.2 Astra / Gemini 4 Game Collection

**133 games and interactive works · 89 game repositories · 4 community collections · 96 with browser playable links · appendix with 23 additional works**

Games and interactive works made with Claude Fable 5.2, GPT-6.2 Astra, Gemini 4 Carbon, and Gemini 4 Neon have grown from small demos into open worlds, 3D racing, first-person horror, and multiplayer fighting.

This repository organizes them into a searchable list: **each entry has a source code link, a gameplay description, model attribution, and the actual tech stack. Entries with an online playable version link to it, and entries without a playable page state how to run them locally**. Multi-model collaboration and different model versions within the same repository are labeled separately, so the works made by different models are easy to compare.
