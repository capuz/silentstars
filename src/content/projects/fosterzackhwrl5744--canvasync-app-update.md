## Overview

CanvaSync provides a web interface for Canva synchronization workflows. The project is distributed as a set of built HTML assets, so it can be served from a web host or run locally through a browser.

The repository is intended for users who want a browser-accessible tool for Canva-related synchronization tasks. Because it contains ready-built assets rather than documented framework source, it can be treated as a web project prepared for serving.
