# 🚀 Eternal

> An exploratory/experimental self-study service center dedicated to providing high-quality self-learning resources for students

## 🚀 Quick Start

### Environment Requirements

- Node.js >= 24.0.0
- npm >= 10.0.0

### Installation Steps

1. **Clone the project**

   ```bash
   git clone https://github.com/suyangzuo/suyangzuo.github.io.git
   cd suyangzuo.github.io
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Configure environment variables (optional)**

   Copy `.env.example` to `.env` and modify as needed:

   ```bash
   cp .env.example .env
   ```

4. **Start development server**

   ```bash
   npm run dev
   ```

   Or start production server:

   ```bash
   npm start
   ```

4. **Access the application**

   Open your browser and visit [http://localhost:3000](http://localhost:3000)

### Production Deployment

The project supports multiple deployment methods:

- **Traditional server**: Use `npm start` to start Express server
- **Cloud platforms**: Render, Railway, Heroku and other Node.js-supporting platforms
- **Static hosting**: For static hosting, deploy the `public` directory to GitHub Pages, Netlify, etc.
