## 📖 Introduction

**PowerfulTS** is a real-time monitoring and multimedia panel for TeamSpeak (TS3 / TS6) servers, adopting a **separated front-end and back-end** architecture. The back-end directly connects to the TS3 ServerQuery to provide monitoring data, while music and on-demand capabilities are delegated to the TSMusicBot multi-platform engine, allowing a single web panel to aggregate and present the server's online status, users, channels, and multimedia capabilities.

> 💡 **Cross-platform**: Provides a complete Dockerized solution, deployable with one click on Linux / Windows / macOS / NAS (Synology, QNAP, etc.).

> ⚠️ **Early Testing Version**: This project is currently in the **early development and testing stage**, with features rapidly iterating and many bugs present. If you encounter issues, feel free to [submit an Issue](https://github.com/Slldyd2077/PowerfulTS/issues) for feedback.
