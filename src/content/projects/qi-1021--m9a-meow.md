# M9A-Meow

**This is a native implementation of M9A (Reverse: 1999 Assistant) for mobile devices**

> Note: After the author finished development, they discovered that the M9A developers were already building a mobile version that is nearly identical to this one, so this project reinvents the wheel. Still, no harm done. The porting experience can be applied to more development work, and I'm going to develop the mobile version of MAAend (Endfield) next. --isqi
> 
> By the way, the M9A mobile beta testing group is 1080177843. Their implementation will also be released soon.

Based on MaaFramework and Android virtual display technology, one-click automation of all daily tasks in Reverse: 1999!
