# M9A-Meow

**This is a native implementation of the M9A (Reverse: 1999 Assistant) mobile version**

> Note: After the author finished development, they discovered that the M9A developers were already building a mobile version that is nearly identical to this one, so this is reinventing the wheel. However, that's fine. The porting experience can be applied to more development, and I am going to develop the mobile version of MAAend for Endfield. --isqi
> 
> By the way, the M9A mobile closed beta group is 1080177843. Their implementation will also go live soon.

Based on MaaFramework and Android virtual display technology, one-tap full daily automation for Reverse: 1999!
