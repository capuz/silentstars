# Golang Development Utilities

Utilities for golang development on Conflux blockchain, especially for backend service.

|Module|Description|
|------|-------|
|[Alert](https://github.com/Conflux-Chain/go-conflux-util/blob/HEAD/alert/README.md)|Send notification messages to DingTalk, Telegram, SMTP email or PagerDuty.|
|[API](https://github.com/Conflux-Chain/go-conflux-util/blob/HEAD/api/README.md)|REST API utilities based on [gin](https://github.com/gin-gonic/gin).|
|[Blockchain/sync](https://github.com/Conflux-Chain/go-conflux-util/blob/HEAD/blockchain/sync/README.md)|Utilities to sync blockchain data.|
|[Channel](https://github.com/Conflux-Chain/go-conflux-util/blob/HEAD/channel/README.md)|Provides more powerful channels.|
|[Cmd](https://github.com/Conflux-Chain/go-conflux-util/blob/HEAD/cmd)|Utilities for CLI tools.|
|[Config](https://github.com/Conflux-Chain/go-conflux-util/blob/HEAD/config/README.md)|Initialize all modules.|
|[DLock](https://github.com/Conflux-Chain/go-conflux-util/blob/HEAD/dlock/README.md)|Utilities for distributed lock.|
|[Health](https://github.com/Conflux-Chain/go-conflux-util/blob/HEAD/health/README.md)|Utilities for health management.|…
