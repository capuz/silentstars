# adobe-mcp

MCP servers for Adobe applications. Install one application's server on its
own, or the suite: one server for every application, with tools that work
across them.

The InDesign server was published as `indesign-mcp-server` up to 2.3.0. It is
now `adobe-mcp-indesign`, with the same tools; replace the package name in your
client configuration.

| Package | What it drives | npm |
|---|---|---|
| [adobe-mcp-indesign](https://github.com/zachshallbetter/adobe-mcp/blob/HEAD/packages/indesign) | Adobe InDesign: documents, pages, text, styles, tables, books, PDF and EPUB export (137 tools) | [`adobe-mcp-indesign`](https://www.npmjs.com/package/adobe-mcp-indesign) |
| [adobe-mcp-illustrator](https://github.com/zachshallbetter/adobe-mcp/blob/HEAD/packages/illustrator) | Adobe Illustrator: documents, artboards, layers, shapes and paths, typography, colour and swatches, effects and 3D, symbols, patterns, Image Trace, images and links, variables and data sets, actions, export, prepress and printing (308 tools) | `adobe-mcp-illustrator` |
| [adobe-mcp-suite](https://github.com/zachshallbetter/adobe-mcp/blob/HEAD/packages/suite) | InDesign and Illustrator in one server, plus…
