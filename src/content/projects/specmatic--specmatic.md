Specmatic
=========

## Shift-left API Integration and auto-fix integration drift before integration

Specmatic turns API specifications into executable contracts, continuously verifying that every change made by AI coding agents and engineers stays true to the desired behaviour. Ship AI-ready APIs 10x faster, from intent to implementation, with Spec-Driven API Development.

### Context

In a complex, interdependent ecosystem, where each service is evolving rapidly, esp with AI-coding agents, we want to make the dependencies between them explicit in the form of executable contracts.

Design, build, test and govern high-quality, AI-ready APIs at scale. [Spec-Driven API Development](https://specmatic.io/contract_driven_development.html) drives every stage of the API lifecycle from the same API specifications, turning [OpenAPI/Swagger](https://spec.openapis.org/#openapi-specification), [AsyncAPI](https://www.asyncapi.com/), [GraphQL](https://graphql.org/) SDL files, [gRPC](https://grpc.io/) Proto files, [Arazzo](https://www.openapis.org/arazzo-specification) and WSDL into executable contracts. Scribe is your AI-native API designer, taking you from idea to AI-ready API specifications.…
