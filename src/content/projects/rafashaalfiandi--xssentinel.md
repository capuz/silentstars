## Overview

XSSentinel is a Python-based command-line XSS scanner that helps security testers find and triage reflected cross-site scripting, DOM XSS risk, and API responses that reflect input. It tests URL and form parameters, analyzes reflection contexts, and uses browser-assisted validation.
