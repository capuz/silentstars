# Proteus: a semantically converged cross-platform application framework

> **One semantic model. Any render engine. Zero native glue.**
> One semantic kernel, any render engine, any native capability. Business code talks only to the semantic layer. The rendering substrate, compiler, host container, and execution carrier are all pluggable.
>
> **Not cross-platform translation, but a cross-platform operating system: semantics are the kernel, backends are drivers.**
