# Proteus —— Semantic-Convergent Cross-Platform Application Framework

> **One semantic model. Any render engine. Zero native glue.**
> One semantic kernel, any rendering engine, any native capability. Business code only talks to the semantic layer — rendering foundation, compiler, host container, and execution carrier are all pluggable.
>
> **Not doing cross-platform translation, but building a cross-platform operating system: semantic is the kernel, backend is the driver.**
