# Proteus (普罗透斯): A Semantically Converged Cross-Platform Application Framework

> **One semantic model. Any render engine. Zero native glue.**
> One semantic kernel, any rendering engine, any native capability. Business code only talks to the semantic layer. The render substrate, compiler, host container, and execution carrier are all pluggable.
>
> **Not cross-platform translation, but a cross-platform operating system: semantics are the kernel, backends are drivers.**
