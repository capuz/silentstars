# 同文输入法咩版

An enhanced Android input method based on [同文 Trime](https://github.com/osfans/trime) and Rime. While keeping the schemas, dictionaries, and YAML theme ecosystem, it adds a floating keyboard, a full one-handed mode, visual layout editing, Baidu skin import, input statistics, and built-in voice input.
