# EaseMind — Zero-threshold AI Training and Fine-tuning Platform

</p>

> An open-source platform that allows everyone to easily train, fine-tune, and use AI models. From model download to end-to-end dialogue integration, no ML experience is required.

## ✨ Features

- 🎯 **Zero-threshold Experience**: Foolproof fine-tuning with one-click start, no need to understand any parameters
- 🔧 **Professional Adjustable**: Open LoRA rank, learning rate, batch size, and 9 other professional parameters
- 🔬 **Model Distillation**: Distill a small model (student) from a large model (teacher), available only to administrators
- 📉 **Loss Curve Visualization**: Real-time plotting of loss decline curve during training/distillation
- ✏️ **Model Renaming**: Supports modification of local model display names for easier management
- 🔑 **API Key Management**: Generate OpenAI compatible keys for third-party client calls
- 📥 **Automatic Model Download**: Input the model name from the Magic Community, automatically download to local
- 📄 **Multi-format Datasets**: Supports `docx` / `txt` / `md` / `csv` / `json` / `jsonl` files, as well as web URL scraping
