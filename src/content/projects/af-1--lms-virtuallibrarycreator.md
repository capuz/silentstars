Virtual Library Creator
====
%3D'plugin'%20and%20%40name%3D'VirtualLibraryCreator'%5D%2F%40minTarget&label=Min.%20LMS%20Version%20Required&color=darkgreen)<br>

🔎 The user interface and menus are here: `Home Menu > Extras > Virtual Library Creator`<br>

> [!TIP]
> The template allows you to create virtual libraries for many purposes, but of course it can not cover all conceivable use cases.<br>
> Don't forget: with this plugin you can also use customized (raw) SQLite statements tailored exactly to your needs (see [FAQ](#faq)).

## Features

* **Easily create custom virtual libraries** *in your browser* choosing from a comprehensive list of selection criteria / options.

* Existing virtual libraries created with VLC can be **easily edited later**.
