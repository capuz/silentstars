# LxMine

A cross-platform music player for **Windows**, **Android**, and **HarmonyOS phones / tablets / car head units**.

**Official site: [yurilin1028.github.io/LxMine](https://yurilin1028.github.io/LxMine/)** · Immersive light-effect preview, multi-platform introduction, and GitHub download acceleration entry.

LxMine is built on the immersive visuals and desktop experience of [Mineradio](#上游与致谢) 2.2.0. It integrates the custom audio source protocol and music library capabilities of [LX Music](#上游与致谢), unifies the home page, playlists, search, local music, and playback detail experience across PC and HarmonyOS, and provides a native Android client.

Current version **1.1.0** (2026-11-17). Installers are available on [Releases](https://github.com/YuriLin1028/LxMine/releases/latest).
For version contents, see [RELEASE_NOTES](https://github.com/YuriLin1028/LxMine/blob/HEAD/docs/RELEASE_NOTES.md). For build and release records, see [RELEASE](https://github.com/YuriLin1028/LxMine/blob/HEAD/docs/RELEASE.md).
