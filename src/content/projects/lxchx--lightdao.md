# 氢岛 (lightdao)

> A lightweight, cross-platform third-party NMBXD client.

This project is an unofficial NMBXD forum client built with [Flutter](https://flutter.dev), aiming to provide a clean, smooth, and feature-rich forum browsing experience.

> **⚠️ Note**
>
> This project is built with Flutter and is cross-platform. However, currently only the **Android** build has been reasonably well tested. Other platforms (iOS, Web, desktop) may have unknown issues and are provided only as a technical preview or experimental support.

## ✨ Features

- **Core features**: Complete forum browsing, thread viewing, replying, timeline bookmarks, and content filtering.

- **Highlights**:
