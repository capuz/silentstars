# 🦁 ProxyProwler

**ProxyProwler** is a powerful, automated Python tool for collecting, verifying, and managing **SOCKS5**, **SOCKS4**, and **HTTPS** proxies from public sources. This project is designed to provide active, high-quality proxies for developers and users, and it saves its output in organized files.

---

## 🎯 Why ProxyProwler?
- 🌐 **Automatic collection**: Proxies are collected from reliable, up-to-date sources.
- ⚡ **Quality checks**: The online status and ping of each proxy are checked.
- 🗑 **Duplicate removal**: Duplicate proxies are removed automatically.
- 📊 **Organized output**: Proxies are saved in separate files.
- 🖥 **Professional interface**: Proxy information is displayed in the README with neat tables.

---

## 🚀 Features
- **Support for diverse sources**: Collects proxies from text links and JSON links.
- **Parallel execution**: Uses ThreadPoolExecutor to check proxies quickly.
- **Ping measurement**: Shows the ping of each proxy to help choose the best ones.
- **Removal of inactive proxies**: Only online proxies are saved.
- **Manual updates**: Can be run manually via GitHub Actions.
