# angee-django

**Developer framework and reusable addons for building Django + React applications
on the [Angee platform](https://angee.ai).**

> **For developers, not end users.** This repository is the framework source for
> teams building Angee applications and addons. If you want a product to use,
> start with a product-specific distribution built on Angee.

Public [feed streams and held replies](https://github.com/ang-ee/angee-django/blob/HEAD/src/angee/posts/README.md) compose
[integration discovery](https://github.com/ang-ee/angee-django/blob/HEAD/src/angee/integrate/README.md),
[delivery settlement](https://github.com/ang-ee/angee-django/blob/HEAD/src/angee/messaging/README.md) and
[workflow conversations](https://github.com/ang-ee/angee-django/blob/HEAD/src/angee/workflows_posts/README.md).

> **Public alpha / active refactor.** Angee is being opened while major addon,
> API, and UI surfaces are still moving. Use it for exploration and feedback,
> not production. Roadmap and compatibility guarantees are still in progress.
