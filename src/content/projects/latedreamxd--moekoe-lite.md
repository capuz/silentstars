# MoeKoe Music Lite

Tired of the shortcomings of the [full version](https://github.com/MoeKoeMusic/MoeKoeMusic)? Try the lite version!

| Comparison       | Full Version         | Lite Version                  |
| ---------------- | --------------------- | ----------------------------- |
| Features         | ✅ Complete           | 🛠️ Some features are still being adapted[^1] |
| Performance      | 🤔 Average            | ✅ Better                      |
| Executable Size  | ❌️ Large (Size ~400MB) | ✅ Very small (Size ~30MB)    |

<small>
* Comparison based on test results on Windows 11.
</small>

## Manual Build

Want to try a manual build? Please refer to the development command reference in the [contribution guide](https://github.com/LateDreamXD/moekoe-lite/blob/HEAD/CONTRIBUTING.md)

[^1]: Features still being adapted can be found in [#1](https://github.com/LateDreamXD/moekoe-lite/issues/1)
