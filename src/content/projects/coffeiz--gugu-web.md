# Gugu

### Agent UI — the UI comes first.

Gugu's idea: bring scattered kanban boards, calendars, notes, files, and canvases together, so users and Agents can get work done in one place.

*This is a personal Vibe Coding project. Contributions through Issues and PRs are welcome.*

[Chinese](https://github.com/Coffeiz/Gugu-web/blob/HEAD/README.md) ｜ [English](https://github.com/Coffeiz/Gugu-web/blob/HEAD/README_en.md) ｜ [Quick Deploy](https://github.com/Coffeiz/Gugu-web/blob/HEAD/docs/quick-deploy.md) ｜ [Live Demo](https://www.gugugu.site)

## What It Can Do

| Area | Capabilities |
| --- | --- |
| Agent | Multi-turn conversation, tool calls, web search, scheduled tasks, and streaming responses |
| Custom Skills | Create and maintain your own task knowledge and workflows, letting Gugu load personal work methods on demand |
| Workspace | Manage projects, stages, tasks, calendars, reminders, files, notes, terminals, and an infinite canvas |
| Information retrieval | Web search, in-site full-text search, Knowledge / RAG, file content retrieval, and similar-image search |
| Long-term context | Remembers user habits, recent state, knowledge, and behavior patterns, and carries context…
