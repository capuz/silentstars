# AI-Assisted VRChat Avatar Modification

VRCForge is an open-source modding tool for VRChat avatar creators. You can describe in natural language the face shape, clothing, materials, or animations you want to change, and the assistant will inspect the project, propose changes, and apply them.

> Before using any feature that writes to Unity assets, back up your Unity / VRChat Avatar project.
