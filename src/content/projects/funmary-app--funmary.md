# Funmary

Funmary (ファンマリー) is a convenient comprehensive web app for students of Hakodate Future University.

> [!IMPORTANT]
> Funmary is an unofficial app unrelated to the university. Please do not contact the university about it.

## What you can do (planned)

Funmary has just started development and there are no usable features yet. Here are the features we will create first:

- Personal timetable reflecting cancellations, make-up classes, and room changes
- Subscription URLs (ICS) that automatically deliver class schedules to Google Calendar or iPhone Calendar
- Class details (day and period, classroom, instructor, syllabus content, cancellation history)
- Features to receive notifications about cancellations and other updates through the app's notification section, Discord, RSS feeds, and similar channels
- Login with university Google account and new user registration via invitation code

After that, we will add browser push notifications, reminders before class, attendance tracking, timetable sharing, and more.
