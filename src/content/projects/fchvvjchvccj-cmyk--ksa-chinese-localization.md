# Kitten Space Agency Simplified Chinese Localization

Applicable version: **2026.11.16.5901** (Windows). This is an unofficial Simplified Chinese localization patch. Download `KSA-zh-CN-2026.11.16.5901.zip` from the [2026.11.16.5901 Release](https://github.com/fchvvjchvccj-cmyk/KSA-Chinese-Localization/releases/tag/2026.11.16.5901).

## Installation, Launch, and Restoration

1. Confirm that you have the official RocketWerkz 5901 game installed, and exit the game normally.
2. Fully extract the archive. Double-click **简体中文启动.cmd** (Simplified Chinese Launch.cmd). On first use, paste the game installation directory that contains `KSA.exe`. A normal first installation shows a support notice that can be closed directly. It does not require payment.
3. **原版英文启动.cmd** (Original English Launch.cmd) launches the game in English and keeps the localization. **仅安装汉化.cmd** (Install Localization Only.cmd) installs without launching the game. **检查汉化包.cmd** (Check Localization Package.cmd) only checks the package. **还原原始游戏.cmd** (Restore Original Game.cmd) restores the original 5901 files affected by the patch without changing save files.
