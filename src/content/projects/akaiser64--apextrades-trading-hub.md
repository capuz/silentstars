## Project Overview

ApexTrades is a web-based project for trading-focused use. Rather than requiring a conventional desktop installation, it provides access through a browser interface.

The repository contains an HTML-based application that can be hosted as a static website, tested locally, or deployed with a compatible web hosting workflow. This browser-first approach supports access from supported desktop and mobile environments.
