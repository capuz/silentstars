# APIMonitorBot

API availability monitoring and QQ notification bot for OpenAI/Anthropic-compatible interfaces.

Manage multiple APIs in a single WebUI, view status and latency, track channel multipliers, and send failures, recoveries, and price changes to designated groups or private chats via OneBot v11. The project runs independently and is suitable for local or self-hosted deployment.
