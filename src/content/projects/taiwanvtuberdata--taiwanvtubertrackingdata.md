# TaiwanVTuberTrackingData

Stores data used by the [Taiwan VTuber List](https://taiwanvtuberdata.github.io/)
This repo will only keep recent data; for complete data, please use [TaiwanVTuberTrackingDataArchive](https://github.com/TaiwanVtuberData/TaiwanVTuberTrackingDataArchive)

## File Description

[TW_VTUBER_TRACK_LIST.csv](https://github.com/TaiwanVtuberData/TaiwanVtuberTrackingData/blob/master/DATA/TW_VTUBER_TRACK_LIST.csv) The validation program is from the TrackListValidation Project in [VTuberTrackingDataProject](https://github.com/TaiwanVtuberData/VTuberTrackingDataProject/tree/master).
