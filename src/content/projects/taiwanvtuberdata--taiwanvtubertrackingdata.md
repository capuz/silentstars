# TaiwanVTuberTrackingData

Stores the data used by the [臺灣 VTuber 列表](https://taiwanvtuberdata.github.io/)  
This repo only keeps recent data. For complete data, use [TaiwanVTuberTrackingDataArchive](https://github.com/TaiwanVtuberData/TaiwanVTuberTrackingDataArchive)

## File Description

[TW_VTUBER_TRACK_LIST.csv](https://github.com/TaiwanVtuberData/TaiwanVtuberTrackingData/blob/master/DATA/TW_VTUBER_TRACK_LIST.csv) The validation program is the TrackListValidation Project in [VTuberTrackingDataProject](https://github.com/TaiwanVtuberData/VTuberTrackingDataProject/tree/master).
