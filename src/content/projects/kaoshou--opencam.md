# OpenCam (Screen Recording Tool)

[English](#english) ｜ [Official website](https://kaoshou.github.io/OpenCam/) ｜ [Download latest version](https://github.com/kaoshou/OpenCam/releases/latest) ｜ [Full user guide](https://github.com/kaoshou/OpenCam/blob/HEAD/docs/USER_GUIDE.zh-TW.md)

OpenCam is a desktop screen recording tool for Windows, macOS, and Linux (Beta). It lets you record, edit, and then continue recording. Recording clips and edits are saved in projects that can be reopened. When needed, you can export to MP4, GIF, or a web player with chapters and subtitles.

## v1.3.2 Highlights

- Fixed rescue so you can directly select a recording project, a folder, or a single session.
- When merging complete clips whose video is compatible and whose audio uses the specified PCM format, the original video can be kept, which speeds up MP4 export.
