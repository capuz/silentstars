A miHoYo game soundtrack data website built with Vue 3

This repository is the frontend repository of the project.

## Features

- **Music discovery**: Search for songs by game, album series, and artist. Supports search, hot charts, and generating random playlists.
- **Online playback**: Playback queue, loop, and shuffle modes.
- **Immersive player**: Fullscreen player, scrolling lyrics, lyric translation, and audio spectrum visualization.
- **Playlists and favorites**: Create, edit, and share playlists. Favorite songs and playlists.
- **Community interaction**: Account login and posting comments.
- **Convenient experience**: Theme and background settings, desktop and mobile adaptation, keyboard shortcuts.
