# SEPIKA

Integrated Structural Analysis

## 概要

SEPIKA（セピカ）is an integrated structural calculation program for Japanese building structures, developed in Rust.
It handles everything in one workflow, from model creation through load calculation, structural analysis, code checking, design, and reporting. It aims to be open-source software that lets structural designers proceed with their design while checking the calculation basis.

## Development Status and Getting Started

The project is currently in development. We are working on implementing and verifying features and on developing the GUI, and it is not yet at the stage where it can be announced as a finished official release for general users.
For participating in development and verifying from source code, see [CONTRIBUTING.md](https://github.com/hrntsm/SEPIKA/blob/HEAD/CONTRIBUTING.md).

## Documentation

For usage instructions, the current supported scope, constraints, and calculation basis, see the [user documentation site](https://hrntsm.github.io/SEPIKA/).
