# SEPIKA

Integrated Structural Analysis

## Overview

SEPIKA (セピカ) is an integrated structural calculation program for building structures in Japan, developed in Rust.
It covers the full workflow in one flow, from model creation through load calculation, structural analysis, code checks, design, and reporting.
The goal is open-source software that lets engineers advance structural design while checking the calculation basis.

## Development Status and Getting Started

The project is currently in development. Feature implementation, verification, and GUI work are ongoing,
so it is not yet presented as a finished, official release for general use.
For contributing to development and verifying from source code, see [CONTRIBUTING.md](https://github.com/hrntsm/SEPIKA/blob/HEAD/CONTRIBUTING.md).

## Documentation

For usage instructions, the current scope of support, limitations, and calculation basis, see the [user documentation site](https://hrntsm.github.io/SEPIKA/).
