# Autumn

Autumn is an extensible backend framework: it provides capabilities such as permission management, system management, code generation, two-level caching, distributed queues, HTTP mixed encryption and decryption, **field storage encryption**, scheduled tasks, robot open APIs, payment security credentials, etc., built on top of Spring Boot, along with **`docs/` constraint documents** and **Cursor Skill**, supporting traditional development and AI collaboration in parallel.
