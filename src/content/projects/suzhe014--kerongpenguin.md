# 🤖 KERONG Penguin

> ⚠️ **This plugin is a deeply customized version based on an open-source QQ bot client solution** (the source code has been rewritten as a readable Kotlin project)

A Minecraft QQ bot plugin that uses the official QQ bot API to enable deep interaction between QQ groups and the server.

## Design References

- **Image rendering UI design reference: BaiZhouziYou / 新亭泪** (source:
  <https://xintinglei.cn/>, template collection:
  <https://github.com/BaizhouziYou/easybot-image-templates/>)
  — The frosted-glass dark style of /查信息卡片, /查在线列表, and the leaderboard follows the earlier versions, which were recreations of the image templates this author published on the EasyBot resource marketplace (see
  [issue #1](https://github.com/SUZHE014/KERONGPenguin/issues/1)). The liquid-glass style of the /查性能卡片 (performance card) references the liquid-glass theme of its EasybotServerPerformanceTemplate-WebGL template; it was later unified with the other cards into a semi-transparent frosted-glass system (blur strength is controlled by render.blur-strength).
