# Socat一键安装脚本（支持DDNS域名）
系统要求：支持CentOS 6+ 、Debian 7+、Ubuntu 14+

脚本说明：脚本默认开启UDP、TCP转发，带开机自启功能。

使用 root 运行以下命令：

```bash
wget https://raw.githubusercontent.com/baichal/Socat/main/socat.sh && bash socat.sh
```

按要求输入本地服务器端口，要转发的目标端口和服务器IP即可！
