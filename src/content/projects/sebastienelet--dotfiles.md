# Dotfiles

## Install

```bash

  https://raw.githubusercontent.com/SebastienElet/dotfiles/main/install.sh | sh
```

## Manual install

```bash
cd && \
  git clone --depth 1 https://github.com/SebastienElet/dotfiles.git .dotfiles &&
  make all
```
