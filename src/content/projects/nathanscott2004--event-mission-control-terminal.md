## What This Is

This fan-made web app acts as a mission control terminal for airsoft events built around the Operation Green Light storyline from Call of Duty: Black Ops Cold War. It is meant to run in any current browser and gives teams a shared station for mission intel, a working nuclear terminal with ARM/DISARM controls, and a countdown clock that shapes the flow of the event. The visual design borrows from military control interfaces to help keep players immersed.
