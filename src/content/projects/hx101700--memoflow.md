# MemoFlow

Chinese | [English](https://github.com/hx101700/memoflow/blob/HEAD/README.en.md)

> MemoFlow is an interactive speech transcription and self-learning minutes generation skill for Codex.

> **Platform note: the current version only supports Windows 10/11 x64.**

MemoFlow is an interactive speech transcription and self-learning minutes generation skill for scenarios such as meeting transcription, content production, and call analysis. Users provide pre-recorded audio, enable features as needed, and confirm settings. Codex then calls Alibaba Cloud Bailian's ASR model to generate proofreading drafts in three formats: Word, Excel, and Markdown. In the future, MemoFlow will use an LLM to keep learning from users' proofread drafts, feedback, and existing formatted minutes documents, generating new minutes that match the user's habits, are neatly formatted, and are ready to deliver.
