# LiteBBS

LiteBBS is a lightweight PHP + MySQL/ forum program, providing topic discussion, section management, user management, content moderation, audit logs, template and extension management features.

## Demo

[Demo site](https://bolgk.eu.org/)

## Advantages
- Extremely small and lightweight: the source code is only about 100KB, with no large amounts of redundant code or bloated dependency packages,
- Very low resource usage. Fast access speed: runs smoothly on low-spec virtual hosts and small servers, with low load pressure.
- Simple deployment: low PHP+MySQL environment requirements. Upload the source code and you can set it up quickly, with a low barrier to entry.
- Template + extension mechanism support: includes template management and extension interfaces, making it easy to change the interface and add features on demand without modifying the core code.
- Open source: source code is open, deployable on your own servers, and you keep control of your data. Clean, minimalist interface: native mobile adaptation, with no cluttered or superfluous components.
