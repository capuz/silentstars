# Eurohouse UX/UI

An elegant *web desktop* environment created by **Eurohouse**. Take it with you wherever you go. All files, user data and personal settings under your control. Presented with high quality *dynamic wallpaper* collections, this app will be a perfect addition to your workspace, no matter where you are now.



The latest version of the web app features:

* Highly customizable *web desktop environment*.
  * Set up styles, icon sets, fonts, sound effects, CSS colors and effects however you want.
  * Use built-in *command palette* to set up profile data and settings, set up *content limits* per user by package names or calculate *mathematical expressions* be it arithmetic operations, equations with multiple variables and operations with *sets* or *arrays* containing both *numbers* and *strings*.
* Multifunctional *main menu* easily configured.
  * There are thumbnails, icons and list menu view modes.
  * *Main menu* items can be configured as set of entries.
* A built in *wallpaper engine* working based on current time.
  * You can switch between *wallpaper collection and series* in the dropdown menu at top of the *web app* page.
