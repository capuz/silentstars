# lies.exposed

---

## Project Structure

The project is built using `pnpm workspaces` and divided in `packages` and `services`.

### Packages

Packages contains all the common code used in `services`.

- [@liexp/core](https://github.com/lies-exposed/lies.exposed/blob/HEAD/packages/@liexp/core/README.md) contains all the core modules
- [@liexp/shared](https://github.com/lies-exposed/lies.exposed/blob/HEAD/packages/@liexp/shared/README.md) contains domain specific definitions for `models` and `endpoints`
- [@liexp/test](https://github.com/lies-exposed/lies.exposed/blob/HEAD/packages/@liexp/test/README.md) contains some test utils
- [@liexp/ui](https://github.com/lies-exposed/lies.exposed/blob/HEAD/packages/@liexp/ui/README.md) contains all `ui` components

### Services

The `services` are the deployable projects:

- [admin](https://github.com/lies-exposed/lies.exposed/blob/HEAD/services/admin/README.md)
- [api](https://github.com/lies-exposed/lies.exposed/blob/HEAD/services/api/README.md)
- [storybook](https://github.com/lies-exposed/lies.exposed/blob/HEAD/services/storybook/README.md)
- [web](https://github.com/lies-exposed/lies.exposed/blob/HEAD/services/web/README.md)
