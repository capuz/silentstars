# ⚡ Nyra

**A lightweight AI assistant for Telegram, powered by Cloudflare Workers.**

English · [فارسی](https://github.com/MHDLabs/Nyra/blob/HEAD/README.fa.md)

---

Nyra brings AI chat to Telegram with a simple serverless setup. Built and maintained by **MHDLabs**.

## 🚀 Deploy to Cloudflare

Deploy your Worker, configure the required secrets and open your Telegram bot. Send /start to get going.

Configure the model catalog in the admin panel: users can select an enabled model, while provider keys stay encrypted server-side. Groq Qwen is the default; Cloudflare Qwen is the specific HTTP 429 fallback. See the [configuration guide](https://github.com/MHDLabs/Nyra/blob/HEAD/docs/CONFIGURATION.md) for the encryption secret and provider setup.
