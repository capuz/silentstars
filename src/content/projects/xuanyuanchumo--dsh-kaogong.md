# dsh-kaogong — Civil Service Exam Prep Integration Plugin (DSH Host-Native Panel) · v1.34.3

> **In one sentence**: Integrate **16** excellent open-source civil service exam repositories into a **native** learning platform inside [DeepSeek Harness](https://github.com/deepseek-ai) (DSH): practice questions / SRS mistake notebook / past-exam paper sets / full mock exams / Shenlun essay review / **Huasheng-13 methodology system** / interactive knowledge graph / white-box observability, **fully usable offline**.

> ⚠️ **Read before installing (one-line version)**: This plugin is an **integration and visualization layer**. The npm package **does not include any question banks or methodology corpora**.
> After installing the plugin, open the Question Bank Management panel and **one-click install the required packages** (`huasheng13` + `xingcezhenti` + `gk-tuxing`). Core features will then be immediately available.
> Question bank management depends on **`git`** (shallow clone/update). Please confirm the host machine can run `git --version` first.
