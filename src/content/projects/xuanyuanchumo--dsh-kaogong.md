# dsh-kaogong — Civil Service Exam Prep Integration Plugin (DSH Host Native Panel) · v1.26.0

> **In one sentence**: Integrates **16** excellent open-source civil service exam repositories into a **native** learning platform inside [DeepSeek Harness](https://github.com/deepseek-ai) (DSH): quiz practice / SRS wrong-answer notebook / past-paper sets / full mock exams / essay grading / **Huasheng 13 methodology system** / interactive knowledge graph / white-box observability, **fully usable offline**.

> ⚠️ **Read before installing (one-sentence version)**: This plugin is an **integration and visualization layer**. The npm package **contains no question banks or methodology corpora**.
> After installing the plugin, open '📦 Question Bank Management' → **one-click install of required packages** (`huasheng13` + `xingcezhenti` + `gk-tuxing`), and core features are immediately available.
> Question bank management depends on **`git`** (shallow clone/update). Please first confirm that the host machine can run `git --version`.
