# kpi-thesis

LaTeX class and templates for the bachelor's diploma project and coursework at Igor Sikorsky KPI, FICE, Department of Informatics and Software Engineering (educational program “Software Engineering of Information Systems”). Plus a normcontrol linter and a Claude Code plugin.

*LaTeX class and templates for a KPI FICE bachelor diploma and courseworks (ДСТУ 3008:2015), with a normcontrol linter and a Claude Code plugin. Docs are in Ukrainian.*

## What's inside

- **The full diploma package** from a single `meta.tex`: title page, assignment with calendar plan, annotations in Ukrainian and English, project drawing list with ЄСКД stamp, technical specification (ТЗ), explanatory note, program text, program and testing methodology, user manual, A3 graphic material sheets. Codes, full names (ПІБ) and order dates are written once.
- **Formatting per ДСТУ 3008:2015 and the department's methodological guidelines**: margins, fonts, headings, figure and table captions, “Continuation of table N”, formulas with “where”, lists, appendices.
- **Numbers for the annotation and drawing list are calculated automatically**: pages, figures, tables, sources, appendices.
- **`just check`**…
