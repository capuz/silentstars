# MeteoQuake

You can view earthquake and tsunami information, as well as weather information.

In each tab of the app, you can check the following information:

- **Earthquake Information**

- **Tsunami Information**

- **Weather Information**

  (Currently under development)

- **Warnings and Disaster Prevention Information**

  (Currently under development)

## How to Use / Installation Method

As it is a web application, you can use it simply by accessing the [website](https://skotm.github.io/MeteoQuake/).

Additionally, since it supports PWA, you can install it on your device like a native app.
  (It may not be available on all devices and browsers)

- For Desktop Chrome  
  **Install button in the address bar or Menu → Save and Share → Install**

- For iOS  
  **Share → Add to Home Screen**

- For Android  
  **Install banner or Menu → Add to Home Screen**
