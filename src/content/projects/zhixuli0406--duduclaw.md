# DuDuClaw 🐾

**Traditional Chinese** · [English](https://github.com/zhixuli0406/DuDuClaw/blob/HEAD/README.en.md) · [日本語](https://github.com/zhixuli0406/DuDuClaw/blob/HEAD/README.ja.md)

</div>

DuDuClaw transforms AI command-line tools like Claude Code, Codex, and Gemini into deliverable AI employees for your company: resident in Telegram, LINE, Discord, and 11 other communication software, with independent validation before delivery, and every dollar spent is tracked and recorded.

You only need one Rust binary. Channel routing, conversation memory, multi-account switching, behavior security boundaries, local inference, and web admin dashboard are all built-in. Your AI brain can use Claude, Codex, Gemini, Antigravity, or any OpenAI-compatible API—you can switch anytime. Configuration and memory stay on your own machine. Core licensed under Apache 2.0.
