# Hongguo Standalone

**Discover great shows on your phone and pick up where you left off, anytime.**

A native Android short-drama client built with Kotlin, Jetpack Compose, and Media3.<br>Requests, media processing, caching, and playback all run on the device. No server deployment or API key configuration is required.
