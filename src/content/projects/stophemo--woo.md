## ✨ Why Woo

Woo (无我笔记, "No-Self Notes") is a local-first Markdown note-taking app. You can write offline on your device without an account. When you need to sync across devices, configure the same WebDAV account on each device, then join the same end-to-end encrypted space using a six-digit pairing code.

> **v0.8.2**: Fixes the Android "project homepage" not opening links, and fixes a bug where sync refresh mistook the local device's old snapshot for a remote conflict, repeatedly generating conflict copies. The installation package uses a higher Android versionCode, so it can directly overwrite the 0.9.x beta.
