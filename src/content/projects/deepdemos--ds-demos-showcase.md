# DeepDemos Showcase

Full rewrite of the DeepDemos showcase: React frontend + Go backend. The original Vue 3 + FastAPI implementation is preserved in the `main` branch history.
License: AGPL-3.0-only. Collaboration rules are in [AGENTS.md](https://github.com/deepdemos/ds-demos-showcase/blob/HEAD/AGENTS.md), and development, review, and merge gates are in [docs/development-workflow.md](https://github.com/deepdemos/ds-demos-showcase/blob/HEAD/docs/development-workflow.md).

## Quick Start (Frontend / Dev Room)

Requires Node 24.19+ and pnpm 11.21+.

```bash
pnpm --dir web install
pnpm --dir web dev
```

- Home page: <http://127.0.0.1:5173/>
- Dev Room (development environment only): <http://127.0.0.1:5173/dev-room>

## Backend

Requires Go 1.27.3+.

```bash
cd backend
go run ./cmd/api
# GET http://127.0.0.1:8080/healthz
```
