# Agent Deck (智能体甲板)

> Dispatch AI tasks from your journal, and review daily token usage and project investment on the Dashboard.

The project is currently in an early, fast-iteration phase, so the experience may occasionally lack polish or include breaking updates. Feel free to check the [Roadmap](https://matsuri.site/portfolio/journal-workflow/#whistlist) for future plans, add suggestions, and vote, or report issues via [GitHub Issues](https://github.com/MatsuriMW/obsidian-agent-deck/issues) and email [klauschen2799@gmail.com](mailto:klauschen2799@gmail.com).

Agent Deck gathers the AI Agent sessions scattered across different local clients onto a single Obsidian deck: which Agent is running, which is waiting for confirmation, and how far each has progressed are all visible at a glance.
