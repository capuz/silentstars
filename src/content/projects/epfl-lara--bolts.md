# Bolts: Stainless Verified Scala

This repository showcases examples of code verified using
[Stainless](https://stainless.epfl.ch) system for Scala. The benchmarks
executed from [run-tests.sh](https://github.com/epfl-lara/bolts/blob/HEAD/run-tests.sh) should run correctly with a 
recent [main branch of Stainless](https://github.com/epfl-lara/stainless/) and most are [in this file](https://github.com/epfl-lara/bolts/blob/HEAD/tctests.txt).

Some highlights:
  * [Quite OK Image Format](https://github.com/epfl-lara/bolts/blob/HEAD/qoi)
  * [System F](https://github.com/epfl-lara/bolts/blob/HEAD/system-f) soundness (progress and preservation)
  * [Data structures](https://github.com/epfl-lara/bolts/blob/HEAD/data-structures), for example [Conc Rope](https://github.com/epfl-lara/bolts/blob/HEAD/data-structures/trees/concrope) and [Red-Black Tree with Remove](https://github.com/epfl-lara/bolts/blob/HEAD/data-structures/trees/redblack)
  * [Expression Compiler Correctness](https://github.com/epfl-lara/bolts/blob/HEAD/expression-compiler)
  * [Algorithms of varrying complexity](https://github.com/epfl-lara/bolts/blob/HEAD/algorithms)
