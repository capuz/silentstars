# PintreeNewTab

[Chinese](https://github.com/tangxiaoqi-tangxiao/PintreeNewTab/blob/HEAD/README.md) | [English](https://github.com/tangxiaoqi-tangxiao/PintreeNewTab/blob/HEAD/README_en.md)

PintreeNewTab is an open-source project based on [Pintree](https://github.com/Pintree-io/pintree), designed to turn browser bookmarks into a tab page. By installing the extension, bookmarks that are inconvenient to manage are converted into a beautiful and easy-to-use navigation page.

## Supported languages (adjusted automatically based on browser language)

- Simplified Chinese
- Traditional Chinese
- English
- Japanese
- Russian
- Korean
- German

## Planned features

- [x] Create folders
- [x] Move bookmarks into folders
- [x] Save sidebar position
- [x] Add AI search

## Installation and running

### Edge/Chrome browsers

1. Install the Edge ([PintreeNewTab](https://microsoftedge.microsoft.com/addons/detail/pintreenewtab/mjiogedjmkbihhahaljlefekjbcgplog)) and Chrome ([PintreeNewTab](https://chromewebstore.google.com/detail/ekfkalhnkifkoijcioheanlegfgcgnee)) extensions.
2. Click the extension icon, and the new tab page will open.
