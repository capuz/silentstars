Bringing the Morandi texture of <a href="https://github.com/webkubor/typora-Bloom-theme">Bloom</a> (a 90★ Typora theme) into DSH, so that even the wait while AI thinks breathes along with the theme.

## 📌 Desktop first — about the DSH Web UI

**Conclusion: Bloom's upcoming iterations will prioritize compatibility with the DSH desktop app. The Web UI will no longer be actively adapted and will gradually be phased out.**

Starting with 0.17.0, desktop is the priority. This update uses the top bar and global overlay Slot currently provided by the host, with a minimum supported DSH version of 0.2.2-rc.1. The plugin version prompt reads the desktop app version.

DSH now has a desktop app, and I have already switched to it for daily use. A theme's value lives in the UI: as the host changes the interface, the colors and glass have to keep up. So the focus of iteration has moved to the desktop.

What this means for you:

| You're using | What happens |
|---|---|
| **Desktop** | New palettes, new animations, and visual fixes will land here first. I use it every day, so when the interface changes, I'll follow. |
| **Web UI** | Stays usable as it is, but I no longer actively adapt to new…
