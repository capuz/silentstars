# YPlayer

An **Apple-platform media shell** built on the [FongMi/TV](https://github.com/FongMi/TV) / [CatVod](https://github.com/FongMi/CatVodSpider) ecosystem. Implemented in Swift, for iOS/iPadOS 15+ and macOS 13+.

Reference implementation: [Silent1566/webhtv](https://github.com/Silent1566/webhtv) (used as the compatibility baseline for protocol and interaction; its Java/Android implementation is not ported).

**Current version: v1.0.3** — download from [Releases](https://github.com/1970905901/Y-Player/releases). For this version's contents and known limitations, see [`docs/发布说明.md`](https://github.com/1970905901/Y-Player/blob/HEAD/docs/发布说明.md).
