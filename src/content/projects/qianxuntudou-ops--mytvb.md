# MyTVB

📺 A third-party Bilibili client designed for Android TV, also adapted for phones, tablets, and car touchscreens, pixel-aligned with BLBL.

## ✨ Main Features

- 🎬 **Video playback** - UGC / anime / movies / TV series / documentaries; 8K / 4K / HDR / Dolby Vision
- 💬 **Danmaku engine** - smart collision avoidance; font size, opacity, speed, line spacing, and area adjustable
- 📝 **Comments panel** - comments, nested replies, and comment images
- 📡 **Live & TV channels** - live danmaku displayed instantly; CCTV channels switchable with remote up/down
- ✈️ **Skip assistant** - automatically skips sponsorships / openings / endings
- 🎮 **Interactive video / Douyin mode** - interactive branch selection; swipe up/down to switch recommendations
- 👶 **Teen mode** - viewing time limits, break reminders, public service ads
- 🖱️ **Long-press quick menu** - watch later, favorite, video details, uploader homepage, not interested
- 📲 **QR code login** - scan QR code on TV; premium membership / avatar frames / level badges all displayed
- 📚 **Me** - history, favorites, watch later, following / follower lists
- 🔍 **Search** - search videos and users, with direct follow
