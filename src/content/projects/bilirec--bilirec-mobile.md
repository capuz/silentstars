# bilirec-mobile

Flutter Android client that runs the Bilirec recording backend (embedding `libbilirec.so`) on the phone as a foreground service.

**Discussion and feedback:** For bug reports, problems, and suggestions, please go to the main repository [bilirec Issues](https://github.com/bilirec/bilirec/issues/new/choose) (choose the mobile version or feature request template). **Issues opened in this repository will be closed automatically.** For usage questions, see the [FAQ](https://www.bilirec.org/zh-cn/guides/faq/) or the QQ group [834229325](https://qm.qq.com/q/oMTN3EsGBy).

## Quick Start

1. Download and install the APK from [Releases](https://github.com/bilirec/bilirec-mobile/releases).
2. Open the app, grant battery optimization and notification permissions, then tap "Start".
3. Tap "Open Recording Manager", then complete Bilibili QR code login in the web interface to start using it.
