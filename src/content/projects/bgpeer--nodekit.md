# nodekit · bgpeer One-Click Script

sing-box + xray dual-core, multi-protocol one-click deployment, automatically generates **mihomo / sing-box / Shadowrocket** three types of subscriptions, and can one-click block Chinese domains/IPs (whitelist bypass). Rewritten in Python based on protocol combinations from mack-a/v2ray-agent, after installation you can directly provide clients with one subscription link.
