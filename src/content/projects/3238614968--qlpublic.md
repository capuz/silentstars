# QLPublic

## Project Introduction

This is a script repository aimed at the QL (Qinglong) / local scheduled task scenario, mainly used for automating daily sign-in tasks and auxiliary processes (such as CAPTCHA handling, notification pushing).

## Notes

- Please do not disclose account passwords in public scenarios.
- The interface belongs to a third-party service; if the page or interface policy changes, the script may need to be updated accordingly.
- If the environment lacks `requests`, the script will not run.
- The script is for reference only.
