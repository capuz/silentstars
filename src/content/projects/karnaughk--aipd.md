# AIPD - AI Native Software Development Framework

Learn AIPD: Start from [Learning Documentation Entry](https://github.com/KarnaughK/AIPD/blob/HEAD/docs/README.md).

AIPD is not a code framework like Vue, Next, or Spring. It is aimed at the software development process with deep involvement of AI Agents: organizing project knowledge, context retrieval, task execution, Agent collaboration, and experience feedback into a sustainable development framework.

In short: **AI Agents are responsible for execution, AIPD is responsible for making the project remember itself.**

## What Problems Does AIPD Solve

AI Agents can already write a lot of code, but the challenges in real projects often lie not in "generating code," but in context management:

- After entering the project, Agents do not know why the project has developed into its current state.
- Code can explain how to do things now, but it is difficult to explain historical reasons, product boundaries, and long-term trade-offs.
- Chat records can be interrupted, Issues and PRs are too fragmented, and READMEs usually only cover installation and entry points.
- After a long discussion on a task, requirements, guesses, denials,…
