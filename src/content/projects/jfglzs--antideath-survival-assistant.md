## Features

### Creeper Warning
Alerts the player when a creeper is within the specified range
- Type: `Boolean`
- Default value: `true`
- Reference options: `true`, `false`
- Categories: `ALL`, `FUNCTIONS`

### Creeper Warning Range
Adjusts the creeper warning range
- Type: `Float`
- Default value: `8,0`
- Categories: `ALL`, `FUNCTIONS`
