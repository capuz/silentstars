# Lyricard · 浮声

**A lyrics card floating on your desktop.** By default it only watches Apple Music, but it also works with 10 other players, including NetEase Cloud Music, QQ Music, and Spotify, and displays whichever one is playing.

A small tool that lives in the Windows system tray. By default it only watches **Apple Music (Windows version)**, but you can also tick **NetEase Cloud Music / QQ Music / Spotify / KuGou** and 9 players in total on the main page. Whichever one is playing gets shown. The desktop corner displays the song title, artist, single-line synced lyrics, a progress bar, previous / pause / next buttons, and a circular album cover.
