# CAD Drafting Toolset

**Keyboard-first CAD drafting for urban planning, inside QGIS.**

Type `L` ↵ and draw a line. Type `F` ↵ and fillet a corner. Type `BR` ↵ and break it.
**44 CAD tools, a CAD-style command line, and street and parcel design, without leaving QGIS.**

|---|---|
