# АЙТИДОКСИ / ITDOXY — your guide to the world of IT 💻

**АЙТИДОКСИ / ITDOXY** is a technical blog and knowledge base on information technology, built with the static site generator [Hugo](https://gohugo.io). Here you'll find a wide range of IT articles: system and network administration, programming, databases, Linux, Docker, and more.

🌐 Site: **[ITDOXY.com](https://itdoxy.com)**

---

## 📖 About the project

**АЙТИДОКСИ / ITDOXY** is a static site built with Hugo. The project is aimed at readers interested in modern information technology. Content is written in Markdown, and publishing is fully automated: after a push to the main branch, GitHub Actions automatically builds the site and deploys it.

### What's on the site:

- 🔎 **Search** — full-text search across all articles
- 🏷 **Categories** — navigation by section
- 🏛 **Forum** — discussion on Telegram
- 👨‍🏫 **Services** — classes, consultations, and IT help
- 📰 **RSS feed** — subscribe to new articles
