# netPlayer Next

Also available in English. Click [HERE](https://github.com/Zhoucheng133/netPlayer-Next/blob/HEAD/documents/en.md) to view the English version of the README

## Introduction

This is a desktop app based on the Subsonic (Navidrome) API. You can [**click here**](https://www.navidrome.org/docs/installation/) to learn how to set up a music server with Navidrome (recommended). If you are looking for the mobile version, visit the [**netPlayer Mobile**](https://github.com/Zhoucheng133/netPlayer-Mobile) repository.

Before using it, make sure the device running netPlayer can connect to your music server over the network.  
If you find any bugs, feel free to submit them to Issues.
