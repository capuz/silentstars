# Ydsz Cloud

Enterprise-level microservices development platform based on JDK 21 & Spring Boot 4 & Spring Cloud

---

## Project Introduction

**Ydsz Cloud** is a rapid microservices development platform for enterprise-level applications, built on **Spring Boot 4.0.8**, **Spring Cloud 2025.1.2**, and **Spring Cloud Alibaba 2025.1.0.0**. The platform adopts a **DDD (Domain-Driven Design)** six-layer architecture (`api` / `domain` / `infra` / `server` / `app` / `web`), with **11 core modules** built-in (1 gateway + 9 microservices + 1 code generator + 1 shared dependency library), covering enterprise-level full-business scenarios including user authentication, system management, workflow engine, messaging engine, task engine, rules engine, file storage engine, intelligent engine, and code generation.
