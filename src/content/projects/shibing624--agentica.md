**Agentica** is not a chat shell that wraps an LLM API, but an Async-First agent harness. It allows agents to truly run: invoke tools, perform long tasks, collaborate across multiple agents, retain memory across sessions, and connect to an evolving self-learn workflow through the Skill system.

| Capability | Description |
|------|------|
| **Long-running Agent Loop** | `Runner` driven LLM ↔ Tool loop, with built-in compression, retries, cost budgeting, and infinite loop protection |
| **Works Beyond Chat** | Files, execution, search, browser, MCP, multi-agent, Workflow, not tied to a single IDE scenario |
| **Memory That Survives Sessions** | Workspace memory stored by entry, relevance recall, and confirmed preferences can be synced to `~/.agentica/AGENTS.md` |
| **Skill-Based Self-Learn** | SkillTool can load external skills; built-in agent continuous learning strategy |
| **Self-Evolution** | Tool failures / user corrections / success sequences → experience cards → automatically generate SKILL.md, reusable across sessions |
| **Open, Composable Harness** | Models, tools, memory, Skills, Guardrails, MCP are all replaceable components, not a closed SaaS black box |
