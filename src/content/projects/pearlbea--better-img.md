# better-img

A simple web component that adds a fallback url and logging function to an image.

This repository contains four different versions of the component:

* [better-img](https://github.com/pearlbea/better-img/blob/HEAD/packages/better-img) - a vanilla web component
* [better-img-nutmeg](https://github.com/pearlbea/better-img/blob/HEAD/packages/better-img-nutmeg) - the same component built with Nutmeg
* [better-img-polymer](https://github.com/pearlbea/better-img/blob/HEAD/packages/better-img-polymer) - same thing made with Polymer
* [better-img-stencil](https://github.com/pearlbea/better-img/blob/HEAD/packages/better-img-stencil) - again with Stencil

See a demo [here](https://component-demo.firebaseapp.com/). Read more about these components [here](https://bendyworks.com/blog/tale-of-four-components).
