# Binggo · Bilibili Lottery Assistant

**No need to search for events one by one, nor click to participate one by one.**

A Bilibili lottery management tool running locally: automatically discovers events from UP collections and monitors user dynamics, allowing one-click/three-click participation in the web console, with optional scheduled tasks. Cookies and data are only stored on your computer, and the console only listens to `127.0.0.1`.
