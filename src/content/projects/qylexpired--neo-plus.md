#### About This Plugin
- Neo+ is a companion plugin for the Neo theme, providing color schemes and style extensions for the Neo theme. It only takes effect when using the Neo theme.
- Neo+ does not write or modify any document data; it only makes appearance modifications.
- All features have a complete lifecycle and only consume performance when enabled. Some features may have a significant performance impact and should be selectively enabled based on your device's performance.
- For more details, please see the Neo theme introduction page.
