## What This Project Does

piggy Script VIP is a compact automation tool made for the piggy game environment on PC. It is centered on aiming support, using silent aim and aimbot functions to help make target acquisition more direct and responsive during play. The script is designed to stay lightweight and straightforward, fitting into normal gameplay with minimal setup.

The current release focuses on improving the underlying targeting logic for better reaction time and more dependable accuracy. If you are working through difficult stages or want extra assistance in multiplayer situations, piggy Script VIP is intended to provide steady support. This tool is for users who understand the consequences of using gameplay helpers and take full responsibility for how they use it.
