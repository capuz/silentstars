# SciLoom Research Cabin

SciLoom is an AI-assisted desktop research management workbench for researchers, centered on local research workflows.

This source candidate version is **1.1.1**, targeting Windows x64 (NSIS). Installer release status is determined by [GitHub Releases](https://github.com/zluer7/SciLoom/releases); this file itself does not indicate that a release has been published.

## Key Capabilities

- Organize projects, roadmaps, tasks, experiments, literature, reviews, and outputs to connect daily research work.
- Shared structured outlines are read-only by default, with support for explicit editing, saving, and cancelling.
- Literature-specific project notes support exporting to Markdown from the six saved fields.
- Built-in synthetic examples let you try the upcoming plan, calendar, and comparison views for sibling-experiment Runs; example dates are fixed, but the display changes with the current date.
- AI suggestions and drafts are written only after preview and explicit user confirmation; the AI service must be configured by the user.
- Stores materials in a local workspace, and provides project import, export, and manuscript management.
