AI Native OpenTelemetry APM

Online demo requires joining the group below to obtain account credentials.

DataBuff is an **AI-native open-source APM software** designed for AI agents, microservices, and cloud-native scenarios, integrating with the OpenTelemetry standard to provide **full-link monitoring**, service topology, RED metrics, agent monitoring, and an AI workbench.

## Features

- 🤖 **AI native, not an external chat box** — LLM directly queries Trace, metrics, topology, and alerts, answering based on real data
- 🧠 **Multi-agent collaboration** — AI brain orchestrates, intelligent querying / inspection experts each perform their roles, complex problems collaborate in parallel
- 🎯 **AI application monitoring** (Roadmap) — LLM call chain · Token analysis · Agent topology · Skill/tool/model call tracking
- ⚡ **eBPF APM** (Roadmap) — Kernel-level non-intrusive collection, zero code modification to obtain call chain and performance data
- 📊 **OpenTelemetry APM base** — OTLP standard integration, covering fault diagnosis, link tracing, service metrics, service topology
- 🚨 **Alert closed-loop** — Threshold and anomaly detection, scheduled evaluation, alert event recording…
