# HomeworkKiller4BJTU · 北交作业助手

A desktop study-assistance tool for university students. It combines course automation for 中国大学慕课 (中国大学MOOC), covering videos, quizzes, discussions, and documents, along with 高铁答题 (bjtu custom), C language programming practice (bjtu custom), and plugin extensions, all in one local desktop application.
