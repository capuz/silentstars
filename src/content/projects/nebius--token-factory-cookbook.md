# Nebius Token Factory Cookbook

Runnable examples for building applications with open models on [Nebius Token Factory](https://tokenfactory.nebius.com/). Explore an API, build an agent, evaluate a model, or adapt a complete application.

[Start here](https://github.com/nebius/token-factory-cookbook/blob/HEAD/start-here/README.md) · [Browse recipes](#browse-recipes) · [Model guides](https://github.com/nebius/token-factory-cookbook/blob/HEAD/models/README.md) · [Documentation](https://docs.tokenfactory.nebius.com/) · [Contribute](https://github.com/nebius/token-factory-cookbook/blob/HEAD/CONTRIBUTING.md)

## Start building

**New to Token Factory?** Follow the [quick tour](https://github.com/nebius/token-factory-cookbook/blob/HEAD/start-here/README.md) and [environment setup](https://github.com/nebius/token-factory-cookbook/blob/HEAD/start-here/setup.md). Each recipe has its own dependencies and run instructions.

```bash
git clone https://github.com/nebius/token-factory-cookbook.git
cd token-factory-cookbook
cp env_sample.txt .env
```
