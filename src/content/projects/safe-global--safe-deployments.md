# Safe Deployments

This contract contains a collection of deployments of the contract of the [Safe contracts repository](https://github.com/safe-fndn/safe-smart-account).

The addresses on the different networks and the abi files are available for each deployment. To get an overview of the available versions, check the available [json assets](https://github.com/safe-global/safe-deployments/blob/HEAD/src/assets/).

## Adding additional deployments

To register a new chain deployment, read the [contributing guide](https://github.com/safe-global/safe-deployments/blob/HEAD/CONTRIBUTING.md).
