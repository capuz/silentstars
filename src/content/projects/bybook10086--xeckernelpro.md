# XECKernel Pro

An Android root solution and manager modified from [KernelSU](https://github.com/tiann/KernelSU), featuring kernel-level su, a module system, App Profile, a built-in TEE engine, and SUSFS support.

## This update: Liquid Home

- **XEC Score**: Real-time scoring across Root, SELinux, SUSFS, TEE injection, guard components, LKM, UAPI, stable release, and running mode (0–100, S/A/B/C/D). Every item is explainable.
- **Dynamic Home Hero**: Score ring, breathing glow, scan line, and guard days. The score and colors change with status, so it is no longer a static glass card.
- **Status card appearance editor**: Pick an image, preview it, set blur 0–24 dp, set dimming 0–65%, and restore defaults with one tap. Images are stored only in the app's private directory.
- **Share device card**: Generates a 1080×1440 PNG locally with Canvas, including score, device, kernel, and check items, and shares directly through the system share sheet.
- **Desktop widget + Quick Settings tile**: View the score on the desktop. Tap to enter the existing “One-Tap Hide” flow. The tile is highlighted based on status.
