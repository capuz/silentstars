# Ciallang

A TJS2 script language interpreter implemented in C++20, aimed at Kirikiri script compatibility and host embedding.
Supports Linux, macOS, and Windows.

## What it can do

- Executes TJS2 source code: functions, classes, properties, exceptions, preprocessing, variadic arguments, and common literals.
- Provides standard library capabilities for Array, Dictionary, String, Math, Date, RegExp, Exception, and Octet.
- Loads TJS2 bytecode and translates it into internal instructions for execution. For the compatibility scope, see [compatibility notes](https://github.com/2468785842/Ciallang/blob/HEAD/doc/compatibility.md).
- Provides a CLI, REPL, `cial-fmt` source formatting, an LSP and VSCode client, and control flow and execution path export.
- Embeds as a CMake subproject or as an installed SDK, registering host classes, functions, and properties through the C++ API.

Integer JIT, Trace JIT, and tail-call optimization must be explicitly enabled. For their scope, see [JIT](https://github.com/2468785842/Ciallang/blob/HEAD/doc/jit.md) and [tail recursion](https://github.com/2468785842/Ciallang/blob/HEAD/doc/tail-recursion.md).
