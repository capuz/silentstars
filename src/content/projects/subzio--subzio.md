# Free proxy keys for Russian mobile internet (LTE/4G)

English version: [README.en.md](https://github.com/Subzio/subzio/blob/HEAD/README.en.md)

This repository collects keys from free servers with a focus on bypassing БС.

The lists are adapted for sing-box clients and are 100% compatible with xray core.
