# Dataflow Solution Guides

Welcome to the **Dataflow Solution Guides**!

The Dataflow Solution Guides provide production-grade **Cloud + Code reference architectures** and full end-to-end deployments for the most common real-time streaming and batch AI workloads on [Google Cloud Dataflow](https://cloud.google.com/dataflow/).

Each guide in this repository includes:

- **Architecture & Solution Documentation** ([`use_cases/`](https://github.com/GoogleCloudPlatform/dataflow-solution-guides/blob/HEAD/use_cases/)): Architectural blueprints, design considerations, one-pagers, and verification runbooks.
- **Cloud Foundation Fabric Terraform Modules** ([`terraform/`](https://github.com/GoogleCloudPlatform/dataflow-solution-guides/blob/HEAD/terraform/)): Lightweight, application-level Infrastructure-as-Code that works in any existing Google Cloud project (with local VPCs or Shared VPCs) and automatically generates the pipeline environment configuration script.
