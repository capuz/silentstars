> Music can transcend the prejudices between us and each other, transcend time and space, and convey the author's ideas.

**OFPlayer Community** is a Windows desktop community edition focused on local music and video playback. It officially succeeds the original Tauri Community.

This generation of the client has moved away from the WebView approach. It adopts a new architecture of **WinUI native interface + Rust music core + Windows Media video engine**, focused on a pure, smooth Local-First desktop audio-visual experience. This repository is maintained for the public community. It contains the complete source code and public dependencies needed for an independent build, and it keeps a desktop player baseline that can be built locally, reviewed, and further developed.
