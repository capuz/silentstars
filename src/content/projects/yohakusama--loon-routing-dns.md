# Loon Routing DNS

A complete third-party configuration for **Loon iOS**: direct connections for domestic traffic, foreign traffic proxied by policy, AliDNS encrypted resolution, ad blocking, and routing for common services and CDNs.

**Version: v4.4.7 · AliDNS** · [Get configuration](https://raw.githubusercontent.com/YohakuSama/loon-routing-dns/main/Loon_Routing_DNS.lcf) · [View source](https://github.com/YohakuSama/loon-routing-dns/blob/HEAD/Loon_Routing_DNS.lcf) · [Report issue](https://github.com/YohakuSama/loon-routing-dns/issues)

> **This is a complete configuration, not a plugin, and it does not include nodes.** After importing, you must add your own node subscription. Please back up your original configuration and subscription address first. This project is not affiliated with Loon.

**Icons:** The 33 policy group icons are self-hosted by this project. See [icons](https://github.com/YohakuSama/loon-routing-dns/blob/HEAD/icons/README.md).
