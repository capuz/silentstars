# Quark Drive Lite · Minimal Quark Cloud Drive

**A lightweight, pure, and fast open-source Quark Cloud Drive desktop client**  
Built on a **Tauri 2 + Rust** native core · Uses native WebView · Zero ads · Zero background residency · Privacy first
