# Bible

Colby Goettel's translation of the _Biblia Hebraica Stuttgartensia_, typeset in XeTeX. The most recent PDF version can be viewed [here](https://github.com/cgoettel/bible/blob/HEAD/bible.pdf).

More information about the translation can be found in the [preface](https://github.com/cgoettel/bible/blob/HEAD/preface.tex).
