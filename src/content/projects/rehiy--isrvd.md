# iSrvd

> The name derives from *"it is a server daemon"*, `srv` corresponds to the Linux conventional directory `/srv`, `d` represents daemon. **Pronunciation**: pronounced as **"I served"** (/ˈaɪ sɜːrvd/), a homophone for "love service".

A lightweight operations dashboard built with Go + Vue 3, integrating file management, Docker container orchestration, APISIX/Caddy gateway configuration, Web terminal, GPU monitoring, scheduled tasks, and AI assistant, providing one-stop management experience for personal servers and small-to-medium teams.

## Features

| Module | Features |
| ------ | ------ |
| System Overview | CPU, memory, disk, network, Go runtime and GPU monitoring, supporting historical data collection, service availability detection, and online upgrades |
| File Management | Browse, upload, download, edit, create/delete directories, rename, permission modification, compress/decompress |
| Web Terminal | Shell terminal based on xterm.js, supporting container terminal access |
| Local Processes | View host process list (CPU, memory, command line), terminate specified processes (founders only, mandatory audit) |
