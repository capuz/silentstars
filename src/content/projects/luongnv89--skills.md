# Install expert workflows for AI coding agents

One command drops a tested, versioned skill into your agent. No more ad-hoc prompts. The same rigorous steps run every time.

Skills are independent files. Works with Claude Code, Cursor, Windsurf, GitHub Copilot, OpenAI Codex, OpenCode, Google Antigravity (`install.sh:23`).

## What's New in 6.0.0

This catalog release ships lstack and lstack-extras 0.11.0, and lstack grows to 17 skills. [readme-generator](https://github.com/luongnv89/skills/blob/HEAD/skills/readme-generator/) 1.0.0 is a new core skill that writes or rewrites a README so a new user can act from the first screen: the project name, a one-sentence pitch, `## Install` with one command and `## Quick start` with the most common task and its expected output, in at most 30 lines. A rewrite keeps a `README.backup.md` and every original section, each command traces to a project file, and the skill never runs project code.
