# Xu Wentao's Blog

A [personal website](https://alvinhui.github.io) built with [Astro](https://astro.build/) + [Tailwind CSS](https://tailwindcss.com/).

## Local Development

### Requirements

- [Node.js](https://nodejs.org/) >= 18

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

After starting, visit http://localhost:4321 to preview the website.

### Build

```bash
npm run build
```

Build output is written to the `dist/` directory.

## Deployment

After pushing to the `main` branch, GitHub Actions automatically builds and deploys to GitHub Pages.
