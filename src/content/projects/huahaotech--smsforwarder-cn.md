# SMS Forwarding Assistant (SmsForwarder.cn)

A lightweight, stable, open-source Android SMS forwarding application. Supports various forwarding channels such as WeChat Work, DingTalk, Feishu, and custom Webhook, as well as features like keyword filtering, verification code extraction, and local number recognition.

## ✨ Features

### 🎯 Core Features
- **Multi-channel support** - Four forwarding channels: WeChat Work, DingTalk, Feishu, and generic Webhook
- **Keyword filtering** - Flexible keyword rule configuration, empty keywords forward all
- **Verification code extraction** - Automatically identifies and highlights SMS verification codes for easy copying
- **Local number recognition** - Dual SIM devices support recognition of the number receiving SMS, displaying the local number during forwarding
- **Custom SIM number** - Supports manual input of the local number when automatic retrieval is not possible
- **Configurable message format** - Flexibly configure whether to display the local number, sender number, and verification code
