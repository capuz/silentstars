# Writing Agent · Article-Writing Agent

**Turn an idea into an article with its own voice.**

Writing Agent is an open-source AI writing assistant for WeChat Official Account articles, opinion analysis, personal essays, and experience sharing. Bring your topic, materials, and judgment, and work with it to find an angle, write a first draft, and discuss revisions, polishing the article over successive rounds.

**[Download the Windows desktop version](https://github.com/dongbeixiaohuo/writing-agent/releases/tag/desktop-v1.0.0-rc.103)** · [Quick start](#desktop-start) · [Claude Code plugin](#claude-code-skill) · [Contribute](#development) · [Documentation center](https://github.com/dongbeixiaohuo/writing-agent/blob/HEAD/docs/README.md)

Windows x64 desktop version · Claude Code Skill / plugin · [MIT open source](https://github.com/dongbeixiaohuo/writing-agent/blob/HEAD/LICENSE)

## Think through every step of writing together

The hard parts of an article often lie before you start drafting and after the first draft is done. Where should this topic enter? Which materials are worth using? Why should readers keep reading? After revisions, does it still sound like you?
