# Playdock

A free alternative to CrossOver. Playdock is a Mac dashboard for the Windows games (and programs)
you're already running through Wine, built on the Sikarugir engine. It does not include CrossOver's
compatibility list, and a title running there is not a promise it runs here.

Steam is the main feature here: install it once, and Playdock shows your library as a proper grid -
box art, a short description, your account's name and avatar. Installed store clients sit on the
right edge as small icons; click one to open it. If none are installed, that spot is a question
mark that opens the Install tab. Drag-and-drop `.exe` support is still in here too, under the
C: Drive tab.

## Developing again

School slowed Playdock down for a while. Development is active again. The library, the game page, and the Install tab are changing in this repo now. Thanks to everyone who has liked, used, or followed this side project.

## Installing

**Homebrew:**

```sh
brew install --cask jasonilization/playdock/playdock
```

**Manual:** grab the `.dmg` from [Releases](https://github.com/Jasonilization/Playdock/blob/HEAD/../../releases) and drag the app into `/Applications`.
