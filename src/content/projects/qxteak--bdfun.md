# bdFun

bdFun is a third-party Bilibili Android client written in Kotlin + Jetpack Compose, dedicated to a lightweight, smooth, concise, and beautiful user experience.

> This project is an unofficial third-party client. It has no affiliation, authorization, or cooperation with Bilibili (Shanghai Kuanyu Digital Technology Co., Ltd.) or its related parties. The project is solely for learning, research, and technical exchange, and does not provide, include, or distribute any cracked content, paid-content bypass mechanisms, or membership-privilege cracking features.

## Interface Preview

Uses the design style of HyperOS 4.

## Installation

System requirements: Android 13+

## Feedback

Feel free to report issues or make suggestions via Issues, or join our Telegram group: https://t.me/+tQrDYf-hb702ZjM1.

## Build

Environment:

- JDK 21
- Android SDK Platform 37 / Build Tools 37.0.0
- Gradle Wrapper (included in the repository)

```bash
# Linux / macOS
./gradlew :app:assembleDebug

# Windows
gradlew.bat :app:assembleDebug
```
