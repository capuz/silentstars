# PiliAurora

[Simplified Chinese](https://github.com/wallpap/PiliAurora/blob/HEAD/README.md) · [English](https://github.com/wallpap/PiliAurora/blob/HEAD/README.en.md)

PiliAurora is a third-party Bilibili client for Android and Windows x64, based on [PiliPlus 2.1.5](https://github.com/bggRGjQaUbCoE/PiliPlus/tree/2.1.5) and developed with Flutter. It supports videos, anime, live streaming, dynamics, private messages, and offline downloads, and provides a standalone Windows playback window, danmaku merging, and content filtering.

[Download and install](https://github.com/wallpap/PiliAurora/releases/latest) · [2.0.1 release notes](https://github.com/wallpap/PiliAurora/blob/HEAD/doc/releases/v2.0.1.md) · [User guide](https://github.com/wallpap/PiliAurora/blob/HEAD/doc/README.md#使用指南) · [Issue tracker](https://github.com/wallpap/PiliAurora/issues)
