# ProxyPilot

### Proxy Toggle & Smart Routing Tool

Routes **only selected domains** through your proxy or a selected free pool — the rest of the traffic goes directly. Targeted, not a "VPN for the entire browser". No account, no tracking, everything is local.

> ## ⚠️ Important before installation
>
> If you already have **other proxy extensions** — **Proxy SwitchyOmega**, FoxyProxy, VPN extensions, and any proxy management tools — **disable or remove them**.
>
> Chrome allows proxy control to only **one** extension. If there are multiple, there will be a conflict: sites stop opening, even though the proxy is "connected".
>
> **In Opera**, additionally disable the **built-in VPN** (Settings → Privacy → VPN) — it also manages traffic and causes conflicts.
>
> 💬 *Real user case: "there was a conflict with another extension — Proxy SwitchyOmega 3, I disabled it and everything was fine!"*
