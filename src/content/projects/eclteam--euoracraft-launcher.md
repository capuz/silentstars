## Introduction

**EuoraCraft Launcher** is a third-party Minecraft launcher that helps you install and start the game, manage different versions and modpacks, and play with friends online. If you are new to Minecraft, you can start with the Quick Start section below.

---

## Features

- **Manage games**: View and launch different versions of the game and modpacks in one place.
- **Add accounts**: Supports Microsoft accounts, offline accounts, and third-party login services.
- **Install modpacks and mods**: Find and install modpacks online, and manage game mods (Mod) and other resources.
- **Multiplayer**: Play with friends.
