# HaoMD
English| [English](https://github.com/yf-hao/haomd/blob/HEAD/README_EN.md)

High-performance, cross-platform Markdown editor built on Tauri 2 + React + TypeScript. Features real-time preview, AI assistant integration, visual charts, multi-tab editing, and offline-first experience.

----

## Features

### User Experience

> **Global Custom Background**

HaoMD supports setting **custom backgrounds** (including local images) for the editor and AI conversation window, creating an immersive writing experience:

- 🎨 **Multiple Themes and Dark Mode**: Supports various theme styles, default eye-friendly dark mode
- 📱 **Responsive Design**: Adapts to different window sizes
- ⌨️ **Keyboard Shortcuts**: Full keyboard shortcut support

### Core Editor
- 🚀 **High Performance**: Based on CodeMirror 6, supports smooth editing of large files (>10MB)
- 📑 **Multi-Tab**: Edit multiple documents simultaneously
- 👁️ **Real-Time Preview**: Split-screen editing, real-time Markdown rendering
- 💾 **Auto Save**: Intelligent auto-save with conflict detection
- 🔍 **Outline Navigation**: Automatically generates document outline for quick navigation
