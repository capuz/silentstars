# DiscordAITranslator

[Simplified Chinese](https://github.com/ROOT94-MAX/DiscordAITranslator/blob/HEAD/README.md) | [English](https://github.com/ROOT94-MAX/DiscordAITranslator/blob/HEAD/README.en.md)

A BetterDiscord translation plugin that supports channel-level incoming message translation, pre-send translation, history backfill translation, manual operations, forwarded messages, and protected text.

**Current version: v1.0.0** · **Runtime environment: BetterDiscord + BDFDB Library**

Version 1.0.0 has been officially released; public downloads and update information are available at [GitHub Releases](https://github.com/ROOT94-MAX/DiscordAITranslator/releases/latest). Cache capacity can be set to 100–10,000 items in "Advanced" (default 500); "Diagnostics" provides version, build, and service status information, with expandable troubleshooting details.
