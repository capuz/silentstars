# utils
A collection of scripts and simple applications

* [dtapply](https://github.com/raspberrypi/utils/blob/HEAD/dtapply/) - A script that reads a Raspberry Pi `config.txt` and uses `dtmerge`
    to apply all its `dtparam` and `dtoverlay` directives to a base `.dtb` file.
* [dtmerge](https://github.com/raspberrypi/utils/blob/HEAD/dtmerge/) - A tool for applying compiled DT overlays (`*.dtbo`) to base Device
    Tree files (`*.dtb`). Also includes the `dtoverlay` and `dtparam` utilities.
* [eeptools](https://github.com/raspberrypi/utils/blob/HEAD/eeptools/) - Tools for creating and managing EEPROMs for HAT+ and HAT board.
* [kdtc](https://github.com/raspberrypi/utils/blob/HEAD/kdtc/) - A tool for compiling overlays with #includes, etc., as used in the kernel tree.
* [otamaker](https://github.com/raspberrypi/utils/blob/HEAD/otamaker/) - A tool for building Remote Update artefacts, as used by Raspberry
    Pi Connect Remote Update.
* [otpset](https://github.com/raspberrypi/utils/blob/HEAD/otpset/) - A short script to help with reading and setting the customer OTP
    bits.
