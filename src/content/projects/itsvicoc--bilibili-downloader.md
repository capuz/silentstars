B 站视频下载 · 直播录制 · 本地归档<br>
Organize the audio and video content you are entitled to save, using one desktop workspace.

**BiliFlow** (repository name `bilibili-downloader`) is an open-source desktop downloader and live stream recorder for Bilibili, offering both **GUI and CLI**. From single videos, multi-part videos, anime, collections, series, and favorites lists, you can filter batch tasks, pause and resume downloads, and organize videos or audio locally together with subtitles, danmaku, covers, and metadata.

Supports Windows, macOS, and Linux. Prebuilt packages are provided for Windows and Apple Silicon Macs, and Linux can run from source. The project code is licensed under the MIT License.
