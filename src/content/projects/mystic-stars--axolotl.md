# Axolotl Launcher

Axolotl Launcher is a free cross-platform Minecraft launcher developed by Mystic Stars.

This project is based on the Modrinth monorepo for downstream development, focusing on the desktop launcher experience. It is an independent unofficial client using the Modrinth public API and has no affiliation or endorsement from Rinth, Inc.

> Recommended API service (advertisement): [FutureAPI](https://www.futureapi.cc/register?invite=8xmfivnh)

## Features

- Supports Windows, macOS, and Linux
- Manages Minecraft instances, modpacks, mods, resource packs, and shaders
- Supports Microsoft official accounts and offline accounts
- Supports instance screenshot management, offline skins, and server management
- Customizable theme accent colors and launcher backgrounds
- Complete Simplified Chinese interface with multilingual support
- Automatically checks for and installs new versions via signed GitHub Release update packages
