# SolveCraft

SolveCraft is an open-source parametric 3D CAD application written in Rust, in the style of
Autodesk Fusion: sketch on a plane, constrain and dimension the sketch, turn profiles into solids
with extrude and revolve, round edges, combine bodies, and change a parameter to watch the whole
timeline rebuild. It is a clean-room implementation (see [CLAUDE.md](https://github.com/bherbruck/solvecraft/blob/HEAD/CLAUDE.md)) and part of the
storytold "craft" family.

*An agent builds an electronics enclosure over MCP: sketches on faces, shell, a port cut, one screw boss patterned to four, then width 80 → 100 mm in the Parameters dialog and the timeline rebuilds. 3× speed; [full video](https://github.com/bherbruck/solvecraft/releases/download/v0.1.0/enclosure-demo-v3.mp4), script in [examples/demo](https://github.com/bherbruck/solvecraft/blob/HEAD/examples/demo).*

**Documentation:** the [SolveCraft book](https://bherbruck.github.io/solvecraft/) (user guide,
developer guide and command reference; sources in [docs/book](https://github.com/bherbruck/solvecraft/blob/HEAD/docs/book)), and the
[web app](https://bherbruck.github.io/solvecraft/app/) to try it in the browser.
