# Better Life Naver - Naver Blog Automation

An AI-powered blog automation tool for a better life

An Electron desktop application that handles Naver blog management in one place, from content generation to automatic posting.

## Project Status

- **Maintenance status**: Actively maintained
- **Main technologies**: TypeScript, Electron, Puppeteer, Playwright, Vitest
- **Target platforms**: Windows and macOS desktop apps
- **Quality control**: CI, release verification gate, automated testing, security regression testing
- **Latest version**: See [GitHub Releases](https://github.com/cd000242-sudo/naver/releases/latest)

For contribution guidelines, see [CONTRIBUTING.md](https://github.com/cd000242-sudo/naver/blob/HEAD/CONTRIBUTING.md), and for reporting security vulnerabilities, see [SECURITY.md](https://github.com/cd000242-sudo/naver/blob/HEAD/SECURITY.md).

## Key Features

### 🤖 AI Content Generation
- **Automatic structured content generation**: Enter an RSS feed, URL, keyword, or draft text, and AI automatically generates a title, subheadings, body, and hashtags.
