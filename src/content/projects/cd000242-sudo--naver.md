# Better Life Naver - Naver Blog Automation

An AI-powered blog automation tool for a better life

An Electron desktop application that handles Naver Blog management in one place, from content generation to automatic posting.

## Project Status

- **Maintenance status**: Actively maintained
- **Main technologies**: TypeScript, Electron, Puppeteer, Playwright, Vitest
- **Platforms**: Windows and macOS desktop apps
- **Quality assurance**: CI, release verification gates, automated tests, security regression tests
- **Latest version**: Check [GitHub Releases](https://github.com/cd000242-sudo/naver/releases/latest)

For information on how to contribute, see [CONTRIBUTING.md](https://github.com/cd000242-sudo/naver/blob/HEAD/CONTRIBUTING.md). For how to report security vulnerabilities, see [SECURITY.md](https://github.com/cd000242-sudo/naver/blob/HEAD/SECURITY.md).
