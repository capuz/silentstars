# ai-lab · ШІ-лаб

**🇺🇦 In Ukrainian** · [🇬🇧 English](#-english)

> Central repository for processing multilingual projects with AI assistance.
> A personal **productivity lab**: we create, improve, simplify, and invent
> automations, skills, and workflows. Works are stored as samples
> in `projects/` and may later be moved into standalone repositories.

## Principles
1. **Experiment above all**: hypothesis → run → measure → conclusion.
2. **Ukrainian is always present**: the UA version is the canon, EN is a mirror with switching.
3. **Automations as code**: versioned, reviewed, tested.
4. **One automation, one task** (no noise).
5. **Security by default**: no secrets in the repo, automatic checks.
6. **Knowledge accumulates**: the conclusions log compounds.

## Structure
| Path | Purpose |
|------|-------------|
| `docs/` | Methodology, roadmap, plan, conclusions log, glossary |
| `docs/ua/`, `docs/en/` | Bilingual onboarding (setup, guidelines, ai-integration) |
| `projects/` | Standalone sample projects (with `project-template/`) |
| `experiments/` | Small hypothesis experiments |
| `skills/`, `.claude/skills/` | Skills…
