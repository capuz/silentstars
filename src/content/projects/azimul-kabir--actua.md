# Actua

**A native Android client for [Actual Budget](https://actualbudget.org/), built with Kotlin and Jetpack Compose.**

## About

Actua brings Actual Budget to Android with a native Material You interface.

It connects directly to your self-hosted Actual Budget server, keeps a local copy of your budget for offline use, and synchronizes changes with Actual. You can also use Actua completely offline with standalone on-device budgets—no server required.

Actua is an independent community project and is not affiliated with or endorsed by Actual Budget.

## Features

- Native Material You Android interface
- English, Brazilian Portuguese (pt-BR) and Spanish (es) with in-app language selection
- Home dashboard with an at-a-glance financial overview (ready to budget, favorite categories and accounts as full-row lists that follow the Budget display settings, upcoming bills, this month, reports and recent activity with cleared and reconciled marks), customizable via show/hide and drag-to-reorder, with sections you can collapse (Actua remembers which), and an optional start day for the This Month summary to match mid-month pay cycles
- Customizable floating bottom tab bar, blurring…
