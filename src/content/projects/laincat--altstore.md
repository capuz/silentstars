# Laincat 工具箱 — SideStore / AltStore / LiveContainer 源文件

Personal iOS sideloading source (source name **Laincat 工具箱**, icon is the GitHub avatar of [@laincat](https://github.com/laincat)): includes 30 iOS apps, **automatically follows upstream GitHub Release updates**.

All three clients are supported: **SideStore / AltStore / LiveContainer**.

> ⚠️ SideStore, AltStore, and LiveContainer parse sources **differently**, so the same source may look different in each.
> A typical example is beta versions: LiveContainer installs `versions[0]` directly, while SideStore requires the Beta toggle to be turned on first.
> See [docs/clients.md](https://github.com/laincat/AltStore/blob/HEAD/docs/clients.md) for details.
