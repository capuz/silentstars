# Caesura (AmeKAG)

**Next Generation of Visual Novel**

**Modern cross-platform visual novel engine · KAG Neo-Genesis scripting · C++20 core**

*A modern, cross-platform visual novel engine — KAG Neo-Genesis scripting on a C++20 core.*

Caesura is an open-source visual novel engine for programmers and independent teams. Its script language is **KAG Neo-Genesis**, a modernized iteration of the KAG scripting language (evolved from KAG3 and compatible with KAG3, so existing projects can be imported and migrated). From writing the first line of a script to packaging the game as finished builds for Windows / Linux / macOS / Web, the entire workflow is completed within a single repository.

The engine core is C++20: bgfx rendering, SDL3 windowing, SoLoud audio, and a Lua 5.4 script VM.
