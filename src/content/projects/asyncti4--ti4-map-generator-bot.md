# Getting Started

Hello Async TI Developers!

This repository is for the AsyncTI4 Game Management Bot which is written in Java using the Discord JDA library to interface with Discord. The AsyncTI4 Game Management Bot is what handles the slash commands, buttons, map images, server management automation, etc.

To get started with development, please read the following:

1. [Code of Conduct](https://github.com/AsyncTI4/TI4_map_generator_bot/blob/HEAD/CODE_OF_CONDUCT.md)
2. [Contribution Guide](https://github.com/AsyncTI4/TI4_map_generator_bot/blob/HEAD/CONTRIBUTING.md)
3. [Website Integration](https://github.com/AsyncTI4/TI4_map_generator_bot/blob/HEAD/WEBSITE_INTEGRATION.md) - How the bot integrates with the AsyncTI4 website UI
