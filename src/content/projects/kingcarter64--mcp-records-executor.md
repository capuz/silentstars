## What It Does

MCP-Records converts raw Cytooxien party minigame data into an organized, interactive table. The tool pulls statistics from the Tabulator system and displays them in a flexible layout where you can sort, filter, and evaluate player performance across various minigames. Whether monitoring your own stats or reviewing the leaderboard, this script offers a clear perspective on the competitive environment.

The latest version improves the data analysis pipeline with Python, simplifying the processing of large datasets and generating useful insights.
