# ZeroWeb

ZeroWeb is an experimental cross-platform browser written from scratch in Rust, supporting macOS, Linux, Windows, and Android. It delivers two things:

- **`ZeroWebView`**: a web rendering library that can be embedded in other applications
- **`ZeroBrowser`**: a complete browser application built on the same engine

DOM, CSS, layout, rendering, JavaScript bindings, networking, and security boundaries are all implemented in this repository, mainly relying on Rust components with permissive licenses.

This is also an AI-first engineering experiment: humans are responsible only for solution design, key decisions, and result verification, while nearly all code is written by AI. We want to see how far AI can push a complex system like a browser when architectural boundaries, tests, and acceptance criteria are clearly defined.

> [!IMPORTANT]
> The project is in an experimental stage and **is not a browser for everyday use**. It is suitable for learning, research, and engineering exploration. For commercial or production use, please evaluate the risks related to features, security, compatibility, performance, and licensing yourself.
