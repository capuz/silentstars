# MuchoCore — Geometry Dash Private Server (GDPS)

**Open-source PHP server core for Geometry Dash.** Accounts, levels, comments, scores, social features, moderation, Cloud Save, admin tools, migration and client patching. One codebase with version-aware protocol handling.

[Website](https://muchogdps.space/muchocore/) · [Stable releases](https://github.com/IZKGMD/GMDmucho-core/releases) · [Changelog](https://github.com/IZKGMD/GMDmucho-core/blob/HEAD/CHANGELOG.md) · [Report an issue](https://github.com/IZKGMD/GMDmucho-core/issues)

> **Choose the correct package first.** The standard MuchoCore runtime requires **PHP 8.2+** (8.3+ recommended). The separate **5v.pl / PHP 7.0** build contains a native runtime, the compiled original application services and the original administration interface. It remains a development preview: complete real-client acceptance is **not certified**. See [native port coverage](https://github.com/IZKGMD/GMDmucho-core/blob/HEAD/docs/PHP7_NATIVE_PHASE1.md) and [release readiness](https://github.com/IZKGMD/GMDmucho-core/blob/HEAD/docs/V110_RELEASE.md).
