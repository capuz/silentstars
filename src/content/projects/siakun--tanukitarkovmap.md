# TanukiTarkovMap

**Korean** | [English](https://github.com/siakun/TanukiTarkovMap/blob/HEAD/README.en.md) | [Japanese](https://github.com/siakun/TanukiTarkovMap/blob/HEAD/README.ja.md)

> **An in-game minimap overlay tool for Escape from Tarkov.<br>When you take a screenshot, it detects the coordinates and displays your current position on the minimap.**

An always-on-top window that shows the interactive map from [tarkov-market.com](https://tarkov-market.com/pilot) over the game, and displays your current position in real time using the coordinates recorded in in-game screenshots. You can check the map with a single hotkey press, without alt-tabbing.

---

## Installation

1. Download the latest Setup installer (`TanukiTarkovMap-Setup-<version>-x64.exe`) from the [Releases page](https://github.com/siakun/TanukiTarkovMap/releases/latest).
2. Run the installer, and future updates will be applied automatically. In settings, you can also turn off automatic updates or revert to a specific version.
