# Rebellion 2

An open-source remake of the 1998 strategy game *Star Wars: Rebellion*, built with Unity and the
improvements we have always wanted.

## Download

Rebellion 2 is available in early access for Windows, macOS, and Linux.

### Running on Linux

The Linux download is an AppImage: a portable application that runs without a traditional
installer. After downloading it, open the file's properties, allow it to run as a program, and
double-click it. You can also launch it from a terminal:

```bash
cd ~/Downloads
chmod +x Rebellion2-*-x86_64.AppImage
./Rebellion2-*-x86_64.AppImage
```

[View release notes and all downloads](https://github.com/adasgames/rebellion2-installers/releases)
or browse the public [installer and launcher source code](https://github.com/adasgames/rebellion2-installers).

The installer verifies ownership automatically. You must own either *Star Wars: Rebellion* or
*Star Wars: Empire at War: Gold Pack* on GOG or Steam.

## Project status

The single-player and multiplayer campaigns are fully playable. Modding tools and 3D tactical
combat, including multiplayer combat, remain in development.
