# ACTIN

ACTIN is a system that determines available treatment options for cancer patients based on the following inputs:

- Comprehensive clinical record of the patient
- Comprehensive molecular analysis of the tumor
- Set of all treatment options available (standard-of-care (SOC) and experimental).

More details on the following modules are available from the links below:

| Module                 | Description                                                                                |
|------------------------|--------------------------------------------------------------------------------------------|
| [Molecular](https://github.com/hartwigmedical/actin/blob/HEAD/molecular) | Interpretation of molecular tests and ingestion into ACTIN.                                | |
| [Algo](https://github.com/hartwigmedical/actin/blob/HEAD/algo)           | Matching all data from a patient to available treatment options.                           |
| [Database](https://github.com/hartwigmedical/actin/blob/HEAD/database)   | Capture of all ACTIN data in a database.                                                   |
