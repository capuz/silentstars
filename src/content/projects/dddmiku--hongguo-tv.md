# Hongguo Living Room TV

A short-drama player for Android TV and TV boxes. Midnight-blue and warm-gold interface; use the remote to browse shows, pick episodes, switch seasons, and resume where you left off.

**[Download TV package](https://github.com/dddmiku/hongguo-tv/releases/latest)** · [Remote control operations](#遥控器操作) · [Feedback](https://github.com/dddmiku/hongguo-tv/issues) · [Desktop version](https://github.com/dddmiku/hongguo-desktop)

The current package is for **ARM64** devices. Existing users should install over the old version, which keeps your account, history, followed shows, and settings.
