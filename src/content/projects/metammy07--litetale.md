### Features

- Switch between 哔哩轻小说, 文库8, 轻书架, and 轻小说百科, or import custom rule-based book sources. Each source's account, bookshelf, and reading records are stored separately.
- Supports EPUB 2/3 illustrated books. On Android, they can be read offline within the app while keeping common original-book CSS. On iOS, the original book can be handed off to Apple Books.
- Supports search, book details, table of contents, and reading. Adds reading from the original 哔哩轻小说 site and a verification recovery entry, and continues to improve loading stability…
