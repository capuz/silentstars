# Causal Studio

🌐 Language: English | [한국어](https://github.com/CausalInferenceLab/causal-studio/blob/HEAD/README-ko_kr.md)

- YouTube: <https://www.youtube.com/@CausalStudio>

Project working rules: [CONTRIBUTING.md](https://github.com/CausalInferenceLab/causal-studio/blob/HEAD/CONTRIBUTING.md) | [한국어](https://github.com/CausalInferenceLab/causal-studio/blob/HEAD/CONTRIBUTING-ko_kr.md)

## How to Learn

1. Watch the videos: Learn each chapter through clear visual explanations.
2. Run and explore the notebooks: Practice hands-on in Binder or Colab, then build a deeper understanding with the notebook code and explanations.
