# Fullseye

**Documentation: [furuse.work](https://furuse.work/)** — the operator index (3,529
operators in the machine-readable index, `docs/OP_INDEX.json`: 940 single-input 2-D operators +
17 n-ary + 2,572 in the typed ledgers, each with a per-operator note), the family guides, and the
release notes.

**What it can do: [CAPABILITIES.en.md](https://github.com/furuse-kazufumi/fullseye/blob/HEAD/docs/CAPABILITIES.en.md)** — an index organised by
*what you want to do*, every entry tied to operators that exist and an example that runs.
**What the PoCs hardened: [HARDENING.en.md](https://github.com/furuse-kazufumi/fullseye/blob/HEAD/docs/HARDENING.en.md)** — the ledger of defects
the PoC series found, what changed, and which gate now stops each one coming back.
