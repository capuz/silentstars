# WeChat Official Accounts / Channels / TikTok / Kuaishou / Little Red Book / Bilibili Download and Transcoding Toolkit

A local one-stop multi-platform content download and management tool that supports offline downloading of WeChat Official Accounts, Channels, TikTok, Kuaishou, Little Red Book, and Bilibili resources, RSS subscriptions, and video transcoding.

Supports running as a native desktop application window (`pywebview`), and can also be accessed in a browser as a web service.

> [!TIP]
> **Ready to use out of the box, no need to configure a local Python development environment!**
> This project has been automatically built with Windows and macOS dual-platform clients through GitHub Actions. Please go directly to [👉 GitHub Releases download the latest version (v2.0.9)](https://github.com/x554960766/wechat-mp-tools/releases).
