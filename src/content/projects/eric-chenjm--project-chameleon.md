# 🦎 Project Chameleon (变色龙计划)

**One-line summary: The ultimate Antigravity fully-featured Chinese localization framework. It features an original "cloud neural network hot update" and "local zero-power sniffing", solving all interface garbled-character and white-screen-crash-during-update issues, and delivering a 100% immersive geek-style Chinese experience.**

> 🔥 **Antigravity flagship-grade seamless cross-platform Chinese localization patch (immune to crashes across versions)**

> **Important**
>
> **💻 Platform statement**: The current automated unpacking and low-level interceptor injection engine (`smart_patch.py`) **natively and fully supports Windows and Mac environments**.

## 🌟 Why do we need this patch?
In the past, traditional localization packs used brute-force "static source code replacement". This led to a fatal problem: if the official side changed even one line of code or a single component, the entire frontend page would crash (the so-called "white screen of death"). Moreover, a large number of dynamic long sentences hidden in obscure corners, dropdown menus, and over 40 dynamic Skills could not be matched at all.
