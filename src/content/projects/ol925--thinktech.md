# Think This Can Work!

## Think Tech

**GTNH Modpack Exclusive MOD**

---

##  Installation

### Prerequisites
- GTNH 2.9.x/2.8.0/2.7.X modpack

### Installation Steps
1. Download the ThinkTech version that matches your modpack
2. Place the jar file into the `mods` folder

##  Project Overview

The project began only as a way to implement in-game a **generator powered by fluid explosives** that the author had conceived. After the first attempt, however, the author felt it was worth refining and developing into an independent project.

So, based on the philosophy of **"Think This Can Work"**, **ThinkTech** was born.

##  Main Content

ThinkTech now includes not only the Implosion Generator, but also:

-  **Machines I came up with** - new multiblock machines
-  **Many new processing chains** - enriching game content
-  **Vanilla recipe modifications** - optimizing the game experience

##  Project Purpose

Improve every aspect of GTNH, and add your own ideas and designs to the game, so you can **play the things you want to play**.
