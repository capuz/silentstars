## Instructions

GitHub Actions automatically fetches Weibo trending searches and archives [website](https://xiadd.github.io/tg-wb-trending/) daily, and sends trending messages to the Telegram channel [Weibo Real-time Trending](https://t.me/weibo_hots) hourly

## Deployment

1. Create a bot at [BotFather](https://t.me/BotFather) and obtain the bot's token

2. Create a channel and set the bot as the channel's administrator

3. Obtain the channel's ID, you can use the [GetID](https://t.me/getidsbot) bot to get the channel's ID

4. Set TOKEN and CHANNEL_ID in GitHub project settings

5. Change docs/public/CNAME to your own domain, set GitHub Pages to the gh-pages branch
