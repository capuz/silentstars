# Evolia 🌿

> **“We are not born complete; we keep evolving into a better version of ourselves through collisions with the world.”**

Evolia is an in-depth AI companion app focused on “personal growth” and “emotional resonance.” This project is a derivative of [LastChat](https://github.com/RikkaHub/LastChat). While keeping LastChat's powerful AI integration capabilities, it substantially restructures the memory system and interaction, and adds features such as schedule management and automated tasks.

---
## 🧠 Core Features

### 1. Deeply Evolving Memory System (L0-L3 Hierarchy)
We designed a rigorous memory hierarchy so the AI understands you better than you understand yourself:
- **L0: Immediate context**: a sliding window that captures the thread of the current conversation.
- **L1: Rolling summary (Context Refresh)**: automatically compresses past conversation, preserving long-term context while saving tokens.
- **L2: All-day episodic memory (Episodic Memory)**: maintains coherence across multiple conversation windows, giving the AI round-the-clock timeline awareness.
