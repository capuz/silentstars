# dsh-later — In-Session Scheduled Message Plugin

**Chinese** | [English](https://github.com/dsh-plugin-collection/dsh-later/blob/HEAD/README.en.md)

> Set reminders for yourself in DSH: **set by the user, received in the current conversation, server-driven, cross-device**. They arrive on time, even if you have closed the web page.

**`/later` delayed send**: no panel needed. Type one line in the input box and it will be sent later as you. (Demo: type `/later +5s` / `+3m` / `+1h20m` character by character. After you press Enter, a countdown starts. The `+5s` message is actually delivered when due.)
