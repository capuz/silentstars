# DSH-Reforge

**DSH-Reforge (npm package name `dsh-reforge`) is a community plugin for DeepSeek Harness that accumulates traceable experience from test-verified Python bug fixes, and selects applicable experience as a reference for later similar tasks.**

DSH-Reforge is a DeepSeek Harness plugin for traceable experience from test-verified Python bug fixes, with scoped retrieval for later tasks.

**This release: `dsh-reforge@0.1.0-alpha.2`, experimental alpha.** It includes the new workbench, complete examples, configuration checks, and backup and restore. Whether the public npm/Release has been verified is subject to the [release status](https://github.com/wang1299/dsh-reforge/blob/HEAD/docs/release-status.md) and [Issue #113](https://github.com/wang1299/dsh-reforge/issues/113). This project is independently developed by the community and does not represent official DeepSeek review, recommendation, or security certification.
