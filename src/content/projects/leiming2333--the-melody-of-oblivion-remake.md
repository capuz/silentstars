## Project Overview

忘却的旋律启动器 is an Electron-based Minecraft Java Edition launcher built from scratch. It keeps the quiet, compact character of the old launcher and rewrites the internals using modern workflows for downloads, accounts, Java runtimes, mod loaders, and game launching.
