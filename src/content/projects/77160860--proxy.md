The sing script is a one-click installation script for multiple protocols based on the **Sing-box** kernel, supporting Hysteria2, Snell v5, Tuic v5, VLESS-Reality, SS2022-shadowtls, and Trojan-WS protocols, and integrates Cloudflare Argo tunnel functionality for use with Trojan, supporting both single protocol and all protocol one-click installation.

### 1. Basic Installation Command
This script controls which protocols to enable through environment variables. You need to set the corresponding variables before executing the command.

#### Common Protocol Variable Descriptions:
*   `tu`: Set Tuic v5 port (e.g., `tu=20000`, if not set, it will be randomly generated)
*   `sn`: Set Snell v5 port (e.g., `sn=20001`, if not set, it will be randomly generated)
*   `hy`: Set Hysteria2 port (e.g., `hy=20002`, if not set, it will be randomly generated)
*   `vr`: Set VLESS-Reality port (e.g., `vr=8443`, if not set, it will be randomly generated)
*   `ss`: Set SS2022-shadowtls port (e.g., `ss=443`, if not set, it will be randomly generated)
*   `tr`: Set Trojan-WS port (e.g., `tr=20003`, if not set, it will be randomly generated and used with Argo locally on VPS)
