# Santodan Patches

Independent patches for the [Morphe](https://morphe.software/) patcher.

Built for **Morphe Patcher 2.0.0**, including **Morphe Desktop 1.19.0**.
See [client compatibility and verification](https://github.com/Santodan/santodan-patches/blob/HEAD/docs/MorpheCompatibility.md).
