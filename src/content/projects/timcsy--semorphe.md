Paste real C++ or Python into it, and it turns into blocks. Drag a block and the code changes with it. Switch to the flowchart and it draws the same program.

🔴 **All three sides are entry points, not "one editable + two read-only"**:

```
You edit the code  →  blocks and flowchart change on the spot
You edit the blocks  →  code and flowchart change on the spot
You edit the flowchart  →  code and blocks change on the spot
```

Not a "convert" button, and not an update only on save. **While you type, the other two sides are already moving.**

  Type a piece of C++ → all three sides grow at once → <b>edit once in the code, once in the blocks, once in the flowchart</b>, and the other two sides follow on the spot → press Run, and it really runs

## How it differs from other block tools

Most block tools are **one-way**: blocks can become code, but code can't turn back into blocks.
A few that are two-way (for example MakeCode) can't go back once you step outside the subset they support.
