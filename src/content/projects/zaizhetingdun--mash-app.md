# Mash

An automation tool for Fate/Grand Order built with Tauri, Rust, and React. It connects to Android devices or emulators via ADB and performs actions using image recognition.

[Download and install](https://docs.mash.xiaotongx.com/start/install/) · [Usage docs](https://docs.mash.xiaotongx.com/) · [Development docs](https://github.com/ZaiZheTingDun/mash-app/blob/HEAD/docs/README.md) · [Contributing](https://github.com/ZaiZheTingDun/mash-app/blob/HEAD/CONTRIBUTING.md)

## Features

- Auto battle: cast skills, use Noble Phantasms, and select command cards based on turn, battle phase, and custom conditions.
- Teams and support: manage Servant and Craft Essence configurations, and filter support Servants by conditions.
- Auto enhancement: Servant enhancement, Concept Craft Essence enhancement, and orb rolling (搓丸子).
- Friend Point summoning: automatically performs Friend Point draws.
