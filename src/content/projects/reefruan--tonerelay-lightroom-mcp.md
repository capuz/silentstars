### Describe the look you want, and work with an Agent to retouch your photos until you're satisfied.

> Source preview: currently only the source code and installation instructions are provided. No stable installation package has been released, and full cross-platform acceptance has not been declared. When installing, pin a commit and verify the actual environment against the installation instructions for the version you choose.

A local MCP retouching tool for photography and Adobe Lightroom Classic. In conversation, you can view the current photo and folder previews, match color and tone to a reference image, fine-tune people and lighting, and organize a whole set of photos. After you review the results, keep telling it what to change; the edits stay in Lightroom Classic.
