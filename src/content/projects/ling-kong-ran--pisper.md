Multi-Agent Application across Desktop, Terminal, and Mobile: Manage Agents like managing code branches - branch out from any completed Turn, advance in parallel.

## ✨ Why Pisper

- **Conversations can branch too.** Derive new sessions from any completed Turn, inherit context, source session remains unchanged; stable Turn labels pin key nodes into searchable anchors -- like Git, but for Agents.
- **True parallel multi-Agent.** Each session has its own model, context, working directory, and permissions; drag labels for four-way split-screen, progress visible on screen.
- **Tools with clear hot/cold distinction.** Core tools reside in context permanently; plugins, MCP, and skills are activated on-demand via discover/call gateway, withdrawn after use -- no matter how rich the capabilities, context won't become a junk room.
- **Stable prefix, hot cache.** Tool definitions stabilized and sorted, prompt form hash diagnosis, maximize Provider's prompt cache usage -- longer sessions faster and more economical.
- **Missing any capability? Say it directly.** Pisper writes, validates, and installs local plugins by itself, next conversation can call them.
