A multi-agent application spanning desktop, terminal, and mobile: the idea of managing agents the way you manage code branches, branching off from any completed Turn and advancing in parallel.

## ✨ Why Pisper

- **Conversations can branch too.** Spin off a new session from any completed Turn, inheriting its context while leaving the source session untouched. Stable Turn tags pin key milestones as searchable anchors. It's like Git, but for agents.
- **Truly parallel multi-agent work.** Each session has its own model, context, working directory, and permissions. Drag tabs to split the screen into four panes, with progress visible side by side.
- **Clear separation of hot and cold tools.** Core tools stay resident in context. Plugins, MCP servers, and skills are activated on demand through the discover/call gateway and deactivated once used, so capabilities can grow without turning the context into a junk room.
- **Stable prefixes keep the cache hot.** Tool definitions are sorted in a stable order, and prompt shapes are diagnosed with hashing, maximizing use of the provider's prompt cache. Long sessions become faster and cheaper.
