# Public EOL Source Code (Elma OnLine)

This repository contains the source code for EOL, an online-enabled version of Elasto Mania featuring online battles, hosted on https://elma.online/.

This repository is a fork of the [Elasto Mania source code](https://github.com/elastomania/elma-classic) published and [licensed](https://github.com/elmadev/elma-classic/blob/HEAD/LICENSE.md) by the Elasto Mania Team. Game assets such as elma.res and default.lgr are not open-source, and are only available from [purchasing](https://elastomania.com/) the game.

The server-side code as well as the communication protocol between EOL and the server is closed-source.

# Getting Started

We welcome everyone that would like to contribute and help improve EOL.

To get started:

- Join us on the Elasto Mania Discord https://discord.gg/j5WMFC6 in #elma-developers!
- Make sure you are able to build the game: [docs/BUILDING.md](https://github.com/elmadev/elma-classic/blob/HEAD/docs/BUILDING.md)
- Look through open issues or design your own improvement
- Prepare and submit a pull request [CONTRIBUTING.md](https://github.com/elmadev/elma-classic/blob/HEAD/CONTRIBUTING.md)
