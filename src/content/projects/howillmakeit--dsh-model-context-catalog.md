`dsh-model-context-catalog` is the model context configuration plugin for DSH. Click **One-Click Match** to find context capacity for models already added to the model catalog, view model vendors, providers, and data sources, then check the models you want and configure them in batch. This saves you from looking up and filling in each one individually.

**Models that already have a context window can also be managed.** By default the current value is kept. To change it, choose a reference capacity or enter one manually. After adding, you can edit, enable or disable, and keep syncing them in one place.
