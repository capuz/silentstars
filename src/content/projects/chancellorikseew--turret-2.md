# Project "Turret" (Turret_2)
Project "Turret" (Turret_2). A 2D tower-defense game. Distributed completely free.
___
## General Information
Inspirations for "Turret": "Mindustry", "Yorg.io", "Factorio".
The game's graphics are based on SDL3 and OpenGL 4.6.
___
## Minimum System Requirements
1) Intel Core i3 / AMD FX processor with a clock speed of 2.5 GHz or higher (or equivalent with SSE4.2 instruction support).
2) 4 GB RAM.
3) Graphics card or integrated graphics core with OpenGL 4.6 support: (NVIDIA GeForce GTX 750 Ti / GTX 950, AMD Radeon RX 360, Intel HD 530) or newer.
4) Free disk space 25 MB for the game itself, 512 MB for saves.
5) 64-bit OS: Windows 10/11, Linux Ubuntu latest (there may be difficulties running on other Linux distributions, please report if you find errors).
___
