Local-first Windows knowledge workbench<br>
  From a single note to an entire project: bring reading, writing, material organization, and relationship exploration into one workspace.

## Not just opening files, but continuing your work

Files may be scattered across notes, reports, configs, spreadsheets, and images, but your train of thought should not be chopped up by file type. Long编辑 uses local directories as its material library, connecting different reading and editing workspaces within the same navigation: first find materials, then understand the content, and finally keep your own records in the right place.

### What kinds of work is it suited for?

| Your task | How to use it |
| --- | --- |
| Study, reading, and excerpting | Search course materials, extract text from reference reports or PDFs in a side panel, and organize selected passages and sources into Markdown notes |
| Project materials and meeting notes | Build a material library for a project, record meetings with templates, save working context, and track related files with smart collections |
| Technical documentation and config organization | Read Markdown in the same library, inspect JSON structure, and edit…
