# PSGameSpider
Automatically crawl all game information from all PlayStation Store regions, including covers, descriptions, prices, ratings, etc., generate static pages for indexing, and automatically generate price and rating history charts.
Contains all games from five regions: Hong Kong, Japan, Korea, Europe, and North America, with multi-language support.

Online preview: https://psgamespider.ravelloh.top

## Introduction
Automated Node.js web crawler based on GitHub Actions that retrieves PlayStation Store game information daily and builds pages
