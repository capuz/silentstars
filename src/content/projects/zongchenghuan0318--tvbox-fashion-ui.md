# Z影视

An Android video aggregation client developed and refined from the open-source project [TVBoxOSC](https://github.com/CatVodTVOfficial/TVBoxOSC) (CatVodTVOfficial), designed for TV boxes, TVs, and landscape-mode phones.

This project only provides the client itself: **movie resources and all third-party interfaces come from the internet; this software does not store or distribute any video content.**

> The software and movie interfaces are completely free. For software issues, please contact the developer 宗成焕.

For first-time use, please read **[Z影视 User Guide](https://github.com/zongchenghuan0318/TVBox-fashion-UI/blob/HEAD/使用指南.md)**: installation steps, homepage and search, remote control keys, player page operations, item-by-item explanations of settings, and common FAQs.

## Project Introduction

Z影视 is a multi-source video aggregation client. It does not provide its own sources. Instead, it combines a set of “collection sources” and “parsing sources” from the configuration into one unified viewing entry: a single search queries all checked sources at once, displays results in the priority order you set, and then passes them to the built-in player for playback.…
