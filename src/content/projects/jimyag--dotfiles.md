# dotfiles

My personal dotfiles, environment bootstrap scripts, and Agent Skills, managed by Chezmoi. You can install skills individually, or use the full configuration to bootstrap a macOS or Linux environment.

## Repository Features

- Shell and Git: zsh, a single-line Starship prompt, oh-my-zsh plugins, aliases, functions, and Git configuration; `gwl` shows worktrees and their associated GitHub PRs.
- macOS configuration: Homebrew package list, plus Neovim, Ghostty, Kitty, Zellij, and Hammerspoon configs.
- Linux bootstrap: installs command-line tools, Docker, and network tools; configures SSH public key authentication, Fail2ban, and IP forwarding; can create users, import GitHub public keys, and set the hostname.
- Agent Skills: requirements clarification, debugging, code review, GitHub delivery, technical writing, skill maintenance, and specialized analysis.

The full configuration includes a personal Git identity, default repositories, and application preferences. Environment bootstrap installs software and modifies configuration, so read the [installation and reuse guide](https://github.com/jimyag/dotfiles/blob/HEAD/docs/installation.md) before use.
