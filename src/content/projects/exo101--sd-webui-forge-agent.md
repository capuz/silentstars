## 📋 Project Introduction

**sd-webui-forge-agent** is a Chinese agent-enhanced integrated version based on **Stable Diffusion WebUI Forge**, improved for domestic users, multi-modal models, and conversational AI workflows. The project goal is no longer just to provide a complex parameter panel, but to allow users to call WebUI capabilities through chat, combine models, expand prompts, process images/videos, diagnose problems, and complete complex tasks.

> [!NOTE]
> This is an improved version. Some plugins will encounter compatibility errors when installed directly. To accommodate many new and old plugins, certain modifications have been made. If you need to install old plugins, simply ask the agent to help with installation, bug fixes, and incompatibility resolution.
