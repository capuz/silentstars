# dsh-plugin-smooth-stream

Simplified Chinese | [English](https://github.com/SpookySandwich/dsh-plugin-smooth-stream/blob/HEAD/README.en.md)

Replaces the character-by-character jittery streaming output with a reading experience that reveals content in paragraph batches with a fade-in. During streaming, the page smoothly follows the scroll; thinking blocks show a live single-line summary.

**Left: DSH native rendering · Right: Smooth Stream** — the same question, started at the same time:

## Installation

```bash
dsh plugin --profile web add dsh-plugin-smooth-stream
```

Open any session to take effect. Settings entry: Settings panel → **Smooth Stream**.
