# puremacro

**New in 5.7.0:** [one model, several solution methods](https://github.com/jalonso1979/puremacro/blob/HEAD/docs/dsge_workflows.md): ordered `.mod` programs, nonlinear transitions, local/global policy comparisons, and eight revised MAV notebooks. This version also includes [DP models in `.mod` files](https://github.com/jalonso1979/puremacro/blob/HEAD/docs/dp_modfiles.md), [reproducible studies](https://github.com/jalonso1979/puremacro/blob/HEAD/docs/studies.md) and [editable HANK equations](https://github.com/jalonso1979/puremacro/blob/HEAD/docs/hank_model_closure.md) developed for 5.6.0.

**Macroeconometrics and structural modeling on the core scientific-Python stack.**

Estimate policy effects, compare economic models, and export results for a
research note or policy brief with NumPy, SciPy, pandas and Matplotlib.
A local workstation installation is the supported target; the numerical core
also runs under Pyodide, with best-effort browser and tablet support.

Requires Python 3.11 or later:

```bash
python -m pip install puremacro
```
