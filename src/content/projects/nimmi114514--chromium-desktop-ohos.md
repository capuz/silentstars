# Chromium Desktop for OHOS

A Chromium desktop browser HAP application project for **HarmonyOS / OHOS tablet and 2in1 devices**, currently integrating **Chromium 158.0.8116.0 / arm64 / API 26**.

**This repository continues development from the Chromium 132 HAP project at [Nyaacho0v0/chromium-2in1-hap](https://github.com/Nyaacho0v0/chromium-2in1-hap).** The original author and upstream community provided the app shell, system interface bridging, and packaging foundation. This project builds on that work by integrating the 158 kernel and making compatibility adaptations. Thanks to the original author and related contributors.

Original 132 baseline commit: [`cc241f6d431c52144afe58f3d4232ca7c9658c43`](https://github.com/Nyaacho0v0/chromium-2in1-hap/commit/cc241f6d431c52144afe58f3d4232ca7c9658c43). This repository retains the Git history of that baseline and the copyright and license notices in the files carried over from it.
