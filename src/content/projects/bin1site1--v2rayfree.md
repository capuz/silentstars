## Usage Instructions

Add [this link](https://gh-proxy.com/raw.githubusercontent.com/bin1site1/V2rayFree/refs/heads/main/config.txt) as a subscription link in any client that supports V2Ray (such as v2rayNG, V2RayN, Shadowrocket, etc.). The link will update every 15 minutes!

## Tips:

If you need to customize the fetching of Telegram channels, you can download the attached exe local version software, input the Telegram link yourself to fetch, and the process needs to run using a VPN proxy (for mainland China).
