# DoraMusic

### Product Name

Dora Music (English name: Dora Music)

### Product Introduction

A practical music player for Android phones.

### Product Features

- Pre-installed app
- Basic music playback controls
- Playback mode switching, including single-track repeat, list repeat, sequential playback, and shuffle
- Equalizer for sound adjustment
- Music playback notifications and notification bar controls
- Instant playback on launch
- Shake to switch songs
- Headphone detection with considerate auto-pause
- Timed pause
- Change theme color
- Dark mode
- One-handed operation
- External audio file playback
- Tablet layout support
