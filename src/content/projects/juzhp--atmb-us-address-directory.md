# Anytime Mailbox US Residential Address Screening Guide

A US address screening project that organizes Anytime Mailbox address data. Combined with RDI, CMRA, price, ZIP, mailbox number range, and Google Maps street view links, it helps determine whether an address is worth further review and renting.

> This project is not an official Anytime Mailbox project, and it does not guarantee that any address will be usable. RDI, CMRA, street view, price, and mailbox number range are only auxiliary reference information. Users must still verify everything themselves.

## Main Features

- Public home page, all addresses page, and residential addresses page, with priority given to SEO and performance.
- Supports filtering addresses by keyword, state, RDI, CMRA, USPS CMRA, C1 pre-approval (Capital One address pre-approval), and price.
- Address cards display price, ZIP, RDI, CMRA, USPS CMRA, C1 pre-approval, and mailbox number range.
- View details links to the Anytime Mailbox address page.
- View photos links to Google Maps, where users judge the street view themselves.
- Back office supports address management, task management, system settings, and login authentication.
