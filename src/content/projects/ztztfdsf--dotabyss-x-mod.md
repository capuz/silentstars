# dotabyss-x-mod

An unofficial, community-made Simplified Chinese integration mod repository for Dot Abyss X for Android (Dot Abyss X / DMM GAMES). It is not affiliated with EXNOA / FANZAGAMES / DMM.

> ⚠️ This repository is for technical archiving and version continuity only. Logging into online services with a third-party client carries account risk, so please assess that yourself. Download the game itself from the official [DMM GAMES](https://games.dmm.com/) channel.

**Original release point (1.14.4 era, by author anosu/Jitsu)**: <https://github.com/anosu/DMM-Mod/releases/tag/mod-dotabyss-v30> · Mirror site entry <https://release.ntr.best/> (this line is no longer updated)

## What is this

A full-package repack (repack) of the official APK, based on the AbyssMod v1.1.4 (MelonLoader/LemonLoader injection approach) by community mod author Jitsu, maintained along with official version upgrades. **The release from this repository only includes the translation feature**:
