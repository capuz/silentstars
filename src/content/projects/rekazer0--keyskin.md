# KeySkin (键设)

A visual editor for Baidu IME iOS `.bdi` / Android `.bds` and `.bda` skins, and Sogou mobile IME `.ssf` / `.mssf` and Shouxin IME `.sxi` skins. It supports macOS, Windows and Android, and offers an online version usable in mobile browsers. It brings skin files, keyboard layouts, key styles and image assets into one live-preview workflow, with creating, editing, undo/redo, saving, cross-format conversion and sharing.

The desktop app uses a three-column layout: file navigator, live canvas and property inspector. The mobile version switches to an adjustable top/bottom split so you can move between files, canvas and properties. The interface supports light/dark mode, device safe areas and a lightweight frosted-glass effect. Skin files are always processed locally.
