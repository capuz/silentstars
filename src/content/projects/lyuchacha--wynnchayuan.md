# WynnChaYuan

English: **[README.en.md](https://github.com/LyuChaCha/WynnChaYuan/blob/HEAD/README.en.md)**

WynnChaYuan is an open-source, non-profit project dedicated to multilingual translation for Wynncraft (a client-side mod for Fabric 1.21.11). It replaces the English text in the game with your language. **Whether to keep the original text is up to you: the translation can be shown in a side panel, or written directly into the original position.**

**It will always be free. There will never be a model where you have to pay to get the full translation or features.**
