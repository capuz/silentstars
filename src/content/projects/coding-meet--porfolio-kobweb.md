# 🚀 Coding Meet - Modern Developer Portfolio & Showcase

---

## 🌟 Overview

**Coding Meet Portfolio** is an agency-grade personal developer website built with **Kotlin**, **Compose HTML**, and **Kobweb**. Designed with modern glassmorphism, responsive ambient aurora backgrounds, interactive maps, and deep-linking architecture, it highlights production mobile applications, Kotlin Multiplatform software, client services, technical articles, and social proof.

---

## ✨ Key Features & Capabilities

### 📱 1. Production Projects Showcase

- **31+ Comprehensive Projects**: Spanning Android, Kotlin Multiplatform (KMP), Compose Multiplatform (CMP), iOS (Swift), Desktop, and Web.
- **Deep-Linkable Project Dialogs**: Share direct URLs with clients (e.g. `https://codingmeet.com/projects?project=what-event` or `/projects#what-event`) to pop open the project showcase modal directly.
- **Rich Media**: Multi-slide mockups, real device screenshots, YouTube demos, GitHub stars sync, and live store links.
- **Live Categorization**: Instant category filtering (`ALL`, `ANDROID`, `KOTLIN MULTIPLATFORM`, `COMPOSE MULTIPLATFORM`, `DESKTOP`, `WEBSITE`, `IOT`).
