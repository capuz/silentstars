# Flutter Brain Game

A brain-training game built with Flutter and designed in Figma. The project includes a playable web demo and screens for starting and completing a game.

**Live demo:** https://khalid-alsaleh-dev.github.io/BrainGame/#/

## Tech stack

- Flutter
- Dart

## Run locally

1. Install the Flutter SDK.
2. Clone this repository:
   `git clone https://github.com/khalid-alsaleh-dev/FlutterBrainGame.git`
3. Install dependencies and launch:
   `cd FlutterBrainGame`
   `flutter pub get`
   `flutter run`
