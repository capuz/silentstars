Self-hosted transactional email, newsletters, campaigns, and inbound conversations with Amazon SES. Use **Receiving** to route mail to addresses, run [rules](https://github.com/anomalyco/nightmail/blob/HEAD/docs/rules.md) on it, send it to endpoints, and read and reply to threads ([how it fits together](https://github.com/anomalyco/nightmail/blob/HEAD/docs/receiving.md)). One installation, OIDC sign-in, and one public API shared by the dashboard, SDK, and MCP server.

1. Clone the repo:

   ```sh
   git clone https://github.com/anomalyco/nightmail.git
   cd bane
   ```
