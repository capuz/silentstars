# MCP Connector: Specialist Data Source Marketplace for DeepSeek Harness

> The MCP data marketplace for DeepSeek Harness: it gathers vertical-domain data providers and open data sources, connects to MCP Servers through over 100 MCP connectors, and provides unified authorization, tool search, and connection troubleshooting.

Connect to MCP Servers from a continuously updated connector catalog. Search tools across the currently enabled connections, view readable parameters, sources, and the time of the last successful cache, and when something goes wrong, check the connection or rediscover tools. Supports OAuth 2.0 PKCE, API Key, Streamable HTTP/stdio, and `mcpServers` JSON import.

Whether OAuth is available depends on the provider's client registration, account permissions, and authorization policy. A saved connection, discovered tools, and a successful business call should each be verified separately.

> Note: "Skill extension" refers to extending agent capabilities through MCP tools and Prompts. This package does not pose as a standalone DSH Skill.
