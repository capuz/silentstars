## ✨ What is this

A single script handles all automation for **WorkBuddy Growth Center + mini-program/PC chained tasks**: **automatic token renewal → points/usage/growth queries → 22 cloud tasks → 6 mini-program chained tasks + 1 PC inspiration task → 8 interactive gameplay tasks → automatic makeup claims based on progress → Chinese report push**. The whole process runs unattended, and repeat runs only fill gaps without claiming twice.
>
> 🗂️ **Archived when activities go offline**: Ended or removed tasks (back-to-school campaign, campus day, public-welfare experts) no longer occupy the main script. Their code has moved to [`archive/`](https://github.com/L0NE-6/WorkBuddy-Daily/blob/HEAD/archive/) for reference, keeping the main script lean.
