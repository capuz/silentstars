# Sanguosha "One General Makes a Name" · Multi-Channel Web Login Launcher

Provides a unified multi-channel login panel on the Sanguosha web version login page. It connects the current browser session to each channel's official QR-code scan, web authorization, and Youka redemption flows, and provides local account management and quick direct login.

Current version: `1.4.3`
Supported channels: Xiaomi, Vivo, OPPO, Huawei, Honor, Bilibili, WeGame, App Treasure (应用宝), Steam (9 total)<br>
How to run: Tampermonkey userscript (Chrome / Edge / QQ Browser extreme mode)

> This project is a local helper tool. It does not bypass official login, real-name verification, payment, or risk control. Whether login succeeds is ultimately determined by the channel servers, the Youka servers, and the account status.  
> Account names, server zones, and records in screenshots are demo data.
