# 🐱 Mihomo / Clash Config

Personal Mihomo / Clash Meta configuration, providing YAML, JS preprocessing scripts, and hand-drawn Qure-style SVG icons. No nodes or airport subscriptions are provided.

## 🚀 Usage

Click the copy button in the upper-right corner of the code block to copy the link.

### YAML Configuration

Can be imported directly into **FlClash's custom configuration**:

```text
https://raw.githubusercontent.com/aaANDkk/ClashConfig/main/mihomo.yaml
```

Alternatively, download [mihomo.yaml](https://github.com/aaANDkk/ClashConfig/blob/HEAD/mihomo.yaml), fill in your own subscription link under `proxy-providers`, and then import it.

### JS Preprocessing Script

In clients that support subscription JS preprocessing, add [mihomo.js](https://github.com/aaANDkk/ClashConfig/blob/HEAD/mihomo.js); remote script link:

```text
https://raw.githubusercontent.com/aaANDkk/ClashConfig/main/mihomo.js
```
