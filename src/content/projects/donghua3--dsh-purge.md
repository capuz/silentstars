> **This line is under continuous maintenance.** Current version **1.1.83** (see [Releases](https://github.com/DongHua3/dsh-purge/releases)), adapted for DSH **0.2.1-rc.2**.
>
> This line is for **local personal use only**: patch engine, desktop package swapping, and session gating. It does not include the skill library or knowledge base, and the repository does not commit to following every new dsh release.
>
> This project has always been a side project. If it has helped you, feel free to check out the [Sponsor](#sponsor) section below. We are also accepting README [ad slots](#ad) to help keep the project going.

> **Both the official Web and official desktop client are supported.** The official `dsh web` uses profile `web`; the official desktop EXE (DeepSeek Harness **0.2.1-rc.2**) uses profile `desktop`. Install them separately and click "Apply" for each one separately. The current version only adapts to dsh 0.2; for earlier versions of dsh, use the matching older plugin version. The community desktop client is not maintained.
>
> **The desktop client has only been verified on Windows.** The official macOS package is code-signed, and unpacking `Contents/Resources/app.asar`…
