# WP8F · Warthunder Port 8111 Frontend

**WP8F (Warthunder Port 8111 Frontend)** is a flight data HUD for Warthunder. It turns in-game flight data (speed, altitude, angle of attack, G-load, engine, fuel, and so on) into a transparent instrument panel overlaid on the screen. It also provides configuration, flight record replay, aircraft performance curves, and a data link.

## Open Source Notes

- This project was implemented with the assistance of LLMs such as **mimo v2.6-pro / mimo v2.6-flash / DeepSeek V4.1 Flash**. LLMs took part in everything from requirements gathering and architecture discussion to code, documentation, and tests. All output was reviewed manually and verified on real hardware before release.
