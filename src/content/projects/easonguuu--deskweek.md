# DeskWeek · Weekly Calendar & Checklist

DeskWeek is a desktop weekly calendar and to-do tool designed for Windows. It sits directly on the desktop background without replacing or disrupting the system wallpaper. All to-do and calendar data is stored by default only on your local computer.

## Download and Use

You can download it from [GitHub Releases](https://github.com/EasonGuuu/Deskweek/releases/latest):
- **Installer (Setup.exe)**: Suitable for most users. Supports an installation wizard, automatically creates desktop and Start menu shortcuts, supports launching at startup, and can be uninstalled with one click from Control Panel.
- **Portable version (Portable.zip)**: Suitable for users who prefer a green, install-free app. Extract to any folder and double-click `DeskWeek.exe` to use it.

> Tip: If you use the portable version, you only need to keep the `data/` folder when upgrading to fully migrate existing schedules and settings. The installed version automatically preserves user data when overwriting an existing installation.
