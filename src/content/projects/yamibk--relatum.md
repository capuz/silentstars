# Relatum

  Open-source, local-first Windows knowledge canvas and study notes software<br>
  Suitable for visual notes, personal knowledge management (PKM), course organization, research brainstorming, and mind maps<br>
  Interface languages: Simplified Chinese · English

## What is Relatum?

Relatum is an open-source Windows desktop app that provides four workspaces: Canvas, Notes, Research, and Career.

No account registration is required. Notes, canvases, and settings are saved on your local machine. Core features work offline, and the AI assistant connects to services you configure as needed.

## Core Features

### Canvas

- Add text, images, code, and attachments on an infinite canvas, and move and connect them freely.
- Adjust node and connector styles; supports handwriting, one-click mind map layout, and PNG export.
- Basic compatibility with the Obsidian Canvas format.

### Notes

- Real-time Markdown rendering with support for formulas, code, Callouts, images, and embedded canvases.
- Manage files with notebooks, folders, and multiple tabs; changes are saved automatically while editing.
