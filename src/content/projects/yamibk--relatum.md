# Relatum

  Open-source, local-first knowledge canvas and study notes software for Windows<br>
  Suited for visual notes, personal knowledge management (PKM), course organization, research brainstorming, and mind maps<br>
  Interface language: Simplified Chinese · English

## What is Relatum?

Relatum is an open-source local Windows application that provides four workspaces: canvas, notes, research, and career.

No account registration is required. Notes, canvases, and settings are saved on your computer. Core features work offline, and the AI assistant connects on demand to services configured by the user.

## Core Features

### Canvas

- Add text, images, code, and attachments on an infinite canvas, and move and connect them freely.
- Adjust node and connector styles; supports handwriting, one-click mind map layout, and PNG export.
- Basic compatibility with the Obsidian Canvas format.

### Notes

- Real-time Markdown rendering with support for formulas, code, Callouts, images, and embedded canvases.
- Manage files with notebooks, folders, and multiple tabs; auto-saves while editing.
- Find and browse notes via search, recent files, tags, outline, bidirectional links, and graph…
