## Project Positioning

**Naive UI Components** is a Vue 3 business component library extracted from [Robot Admin](https://github.com/ChenyCHENYU/Robot_Admin), published independently as `@robot-admin/naive-ui-components`. Built on Naive UI, it unifies common scenarios such as configuration forms, data tables, editors, workflows, and file/media into `C_*` components and accompanying composition functions, and can also be integrated independently into other Vue 3 projects.

| Design focus | Currently provided |
| -------- | ------------------------------------------------------------------------------------------------------ |
| Configuration-driven | Form fields, table columns, action buttons, and dialogs are composed through typed configuration; forms provide 8 layouts |
| End-to-end typing | Field paths, column definitions, events, and instance method types are provided; helpers such as `defineFormOptions`, `useCForm`, and `useTableQuery` are included |
| On-demand consumption | 62 standalone component entry points, an auto-import resolver, component style entry points, and base style layers for forms and tables |
