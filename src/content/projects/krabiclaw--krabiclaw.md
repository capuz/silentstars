# KrabiClaw

[KrabiClaw](https://krabiclaw.com) runs the website, bookings, payments and messaging
for restaurants, experience operators, law firms and lodging hosts, managed from
the dashboard or from ChatGPT and Claude through one MCP service. Lodging includes
homes, nightly availability and prices, direct stay bookings and guest messaging.

Open source under [AGPL-3.0](https://github.com/krabiclaw/krabiclaw/blob/HEAD/LICENSE).

- **Report a bug or request a feature:** [open an issue](https://github.com/krabiclaw/krabiclaw/issues/new/choose).
  Assistants filing for a user can prefill the form; see the field ids in
  [.github/ISSUE_TEMPLATE](https://github.com/krabiclaw/krabiclaw/blob/HEAD/.github/ISSUE_TEMPLATE).
- **Account, billing or private data:** [krabiclaw.com/help](https://krabiclaw.com/help).
- **Security:** [SECURITY.md](https://github.com/krabiclaw/krabiclaw/blob/HEAD/SECURITY.md).
- **Contributing:** [CONTRIBUTING.md](https://github.com/krabiclaw/krabiclaw/blob/HEAD/CONTRIBUTING.md).

Nuxt 5 nightly + Nitro 3 + Cloudflare Workers + D1.

**Package manager: yarn only.** Never npm or pnpm.
