## Why AgentLens

Codex, Claude Code, Pi, Hermes, OpenCode and other tools scatter sessions, tool calls, and capability configuration across JSONL, SQLite, Hooks, and configuration directories. AgentLens organizes these **observable facts** into a unified, traceable view to help you answer:

- What did the agent just do, and at which step did it fail?
- What turns, tool calls, and lifecycle events did a long task go through?
- Does a given conclusion come from history records, native tail-reading, or Runtime Hooks?
- Which Skills, MCPs, and Plugins are installed locally, and which have actually been invoked?
- Which data is complete, which has only partial coverage, and which sources are currently unavailable?

AgentLens shows only the behavior that its sources can prove. It does not claim to read hidden reasoning, and it does not present speculation as fact.
