## Why AgentLens

Codex, Claude Code, Pi, Hermes, OpenCode and other tools scatter sessions, tool calls, and capability configuration across JSONL, SQLite, Hooks, and config directories. AgentLens organizes these **observable facts** into a unified, traceable view to help you answer:

- What did the agent just do, and at which step did it fail?
- What turns, tool calls, and lifecycle events did a long task go through?
- Does a given conclusion come from historical records, native tail-reading, or a Runtime Hook?
- Which Skills, MCPs, and Plugins are installed on this machine, and which have actually been invoked?
- Which data is complete, which has only partial coverage, and which sources are currently unavailable?

AgentLens shows behavior that the sources can prove. It does not claim to read hidden reasoning, and it does not dress up speculation as fact.
