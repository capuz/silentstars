# LSF-Website Design · Basic Edition

**A web design and engineering delivery skill for AI coding assistants**: it frees AI from the cookie-cutter "default template look" and takes you from real reference-site reconnaissance, interaction and source-component reuse, to frame-by-frame animation replication and independent browser review, delivering web works that are ready for launch.

Give it a theme and it can start from scratch. Attach a reference URL and it will first break down the original site's layout rhythm, design tokens, and core motion, then redesign and implement around your theme. It can also be used on its own to find design references, reverse-engineer website-building prompts, extract `DESIGN.md` design specifications, or review existing pages.
