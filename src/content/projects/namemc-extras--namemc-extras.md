# NameMC Extras

A powerful browser extension that enhances your NameMC experience with additional features and improved functionality.

## 🚀 Installation

Install the Chromium version from the [Chrome Web Store](https://chrome.google.com/webstore/detail/cpphfojhgkppblcdhjbcploikanimgek)!

Install the Firefox version from the [Firefox Addons Store](https://addons.mozilla.org/en-US/firefox/addon/namemc-extras/)!

## ✨ Features

### Creation Dates
View the exact creation dates for Minecraft accounts. (This can be inaccurate as it is based on Ashcon's API)

### Display Ears
View deadmau5's ears on his NameMC profile.

### Elytra Preview
Quick access button to preview skins with Elytra.

### Clean Name History
Option to hide dashed-out names from name history for a cleaner view.

### Enhanced Skin Art
- Hide borders for better skin art viewing.
- One-click skin art download.

### Emoji Search Bar
Easily search for emojis in profile.

### Toggle All Names
Easily toggle all the names in your history.

### Toggle All Capes
Toggle the visibility of all of your capes in one click.

### Customizable Skin Display
Toggle individual skin layers for better viewing.
