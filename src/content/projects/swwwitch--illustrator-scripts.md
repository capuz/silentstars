# Adobe Illustrator Scripts

A collection of scripts that help with design production in Adobe Illustrator. Mainly developed with the help of ChatGPT.

## About the Published Scripts

The scripts introduced here follow a "good enough as long as it runs" approach. They are created and used for personal purposes, so from a professional standpoint there may be many points open to criticism.

They are published under the following policy, so please use them with that understanding.

- Provided without warranty.
- We are not responsible for any trouble or damage resulting from their use.
- Modification and redistribution are free.
- Suggestions and fixes such as "this should be improved like this!" are very welcome.

### Bug Reports

Please let us know the following information!

- OS (e.g., macOS Sequoia 15.5)
- Illustrator version (e.g., 29.6.1)

If an error message appears, please report it exactly. A screenshot is ideal.

If possible, sharing the relevant file would speed things up considerably (of course, it will not be published externally).
