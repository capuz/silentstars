# dsh-mpkg-wallpaper — DSH Wallpaper Engine Background Plugin

[Chinese](https://github.com/XHR666/dsh-mpkg-wallpaper/blob/HEAD/README.md) | [English](https://github.com/XHR666/dsh-mpkg-wallpaper/blob/HEAD/README.en.md)

A plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web interface (`dsh web`) to add background wallpapers: **Wallpaper Engine `.mpkg` parsing, Steam Workshop directories, video/web/image wallpapers, time-changing wallpapers with multi-time-period switching, full-screen blur system, theme colors and glass appearance, local wallpaper library, scheduled rotation, Now playing widget, one-click update**. Almost all appearance details are customizable.

> Version scope: This document describes the implementation of version **`3.8.0`** in `package.json`. The release consists of **14 files** (`lib/` with 8 runtime files + `icon.svg`, `cordis.patch.yml`, `README.md`, `README.en.md`, `THIRD-PARTY.md`, `LICENSE`); `lib/liquid-glass/**`, `lib/liquid-glass-bundle.js`, `dist/`, `tools/`, `docs/` are not included in the npm package (`package.json:8-21`).
