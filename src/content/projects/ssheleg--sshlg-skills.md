# ssheleg harness · sshlg-skills

**A working method for coding agents, with a skill family and Project Observatory.**

Route the task, preserve its intent, verify the result and leave a handoff another agent can use. The skill family supplies the instructions and checks; Project Observatory is a separately installed tool for observing projects and credential exposures. [How the harness works](https://github.com/ssheleg/sshlg-skills/blob/HEAD/docs/harness/README.md).

```bash
npx sshlg-skills install
```

Verify the resolved family: `npx --yes sshlg-skills@latest list`.
