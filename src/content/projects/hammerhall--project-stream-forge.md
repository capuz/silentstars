# ⚒️ Project Stream Forge

> **From simple Stream Pipelines to designing modern data processing systems in Java.**

> 💡 **Don't learn the Stream API. Learn to think in data streams.**

**Project Stream Forge** is a practical course on engineering thinking and modern data processing in Java.

Here, the Stream API serves as a tool rather than a learning goal. The project helps you move from using individual methods of the standard library to designing expressive data processing pipelines, algorithms, and architectural solutions. Each level consistently develops the ability to think declaratively, analyze data, and choose optimal approaches to solving problems.

Instead of a set of isolated exercises, Stream Forge offers a sequential learning path, where each new level expands not only the set of tools you use but also your way of thinking as a developer.

## 🚀 What you will learn

During the course, you will get acquainted with modern approaches to data processing in Java:

✔ Java Stream API
✔ Collectors Framework
✔ Lambda Expressions
✔ Optional
✔ Comparator API
