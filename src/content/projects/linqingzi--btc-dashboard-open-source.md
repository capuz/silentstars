[中文](https://github.com/linqingzi/btc-dashboard-open-source/blob/HEAD/README.md) · [English](https://github.com/linqingzi/btc-dashboard-open-source/blob/HEAD/README.en.md)

**[Try demo without installation / 免安装试用](https://linqingzi.github.io/btc-dashboard-open-source/)** · No download, Python, account, or API key required. Once opened, you can view the 20 indicators and 3-tier scoring, and click **English** in the top right to switch languages. Works on both mobile and desktop.

The web page requires an internet connection on first load. The data is generated by offline scripts and fixed; the browser only reads synthetic JSON from this site. There are no live quotes, trade execution, data uploads, or automatic market data updates. To modify the code or run it offline on your own machine, see [Local advanced usage](#3-分钟本机上手).

**Explore on your own machine how 20 BTC fundamentals indicators form a 3-tier rule-based score.** All inputs are reproducible synthetic data, suitable for reading the scoring code, understanding the field structure, and experimenting with the interface.
