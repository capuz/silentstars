# BTC Dashboard — 20 指标离线演示

[Chinese](https://github.com/linqingzi/btc-dashboard-open-source/blob/HEAD/README.md) · [English](https://github.com/linqingzi/btc-dashboard-open-source/blob/HEAD/README.en.md)

**Explore on your own machine how 20 BTC fundamental indicators combine into a 3-layer rule-based scoring system.** All inputs are reproducible synthetic data, suitable for reading the scoring code, understanding the field structure, and experimenting with the interface.

An offline Bitcoin fundamentals demo: 20 indicators, 3 scoring tiers, and reproducible synthetic fixtures. Python standard library + vanilla JavaScript; no API keys or package installation required.

This is a demo tool and does not provide real-time market data, profit signals, or investment advice. The values, dates, and the bullish/bearish conclusions shown on the page all come from fictional examples; “confidence” does not represent prediction accuracy.
