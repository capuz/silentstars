# Datagrok package repository

This is a public repository for the API, tools,
and [packages](https://datagrok.ai/help/develop/develop#packages)
available for [Datagrok™](https://datagrok.ai), a next-generation web-based data analytics platform.
The platform is very extensible, and almost anything could be implemented as a package:

* Support for scientific domains, such as [cheminformatics](https://github.com/datagrok-ai/public/blob/HEAD/packages/Chem/README.md)
* Applications, such as [Clinical Case](https://github.com/datagrok-ai/public/blob/HEAD/packages/ClinicalCase/README.md)
  or [Peptides](https://github.com/datagrok-ai/public/blob/HEAD/packages/Peptides/README.md)
* Connectors
  to [OpenAPI web services](https://github.com/datagrok-ai/public/tree/master/packages/Swaggers)
* Visualizations, such as [Leaflet](https://github.com/datagrok-ai/public/blob/HEAD/packages/Leaflet/README.md)
* Importing and previewing files, such as
  [SQLite](https://github.com/datagrok-ai/public/blob/HEAD/packages/SQLite),
  [PDF](https://github.com/datagrok-ai/public/blob/HEAD/packages/FileEditors/README.md), or…
