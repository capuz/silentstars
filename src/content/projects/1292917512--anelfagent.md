# AnelfAgent

**v0.3** · Unified agent framework — autonomous thinking · semantic memory · tool orchestration · multimodal generation · real-time voice · multi-channel communication

**Simplified Chinese** | [English](https://github.com/1292917512/AnelfAgent/blob/HEAD/README_EN.md)

AnelfAgent is an open-source, self-hosted AI agent runtime. Give it an LLM API key and it becomes an AI assistant that **has its own memory, learns skills on its own, takes initiative to get work done, and lives across multiple chat platforms**. It includes an autonomous decision engine, hybrid semantic memory, skill self-learning, sub-agent scheduling, resumable workflows, MCP tool bridging, and multi-platform channel adapters. It covers multimodal capabilities for text, images, voice, video, and music, and ships with a modern WebUI for all configuration, conversation, and operations.

> This repository is the **0.3 stable baseline**: the architecture and capabilities have largely settled, and it is suited to self-hosted deployment and further extension.
