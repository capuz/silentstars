# 🎴 Universal Card

  7 body modes • Grid layout • Header layouts • Badges • Footer • Lazy loading • Visual editor

---

## What it is

`Universal Card` is a flexible card for Home Assistant that can be:

- regular expandable card
- modal or fullscreen overlay
- tabs container
- carousel container
- subview launcher
- compact header-only card

The card includes:

- grid layout with `colspan` and `rowspan`
- header presets and badges
- footer with actions
- visibility and section visibility
- root actions and swipe gestures
- themes, `theme_tokens`, `state_styles`, `custom_css`
- built-in visual editor
