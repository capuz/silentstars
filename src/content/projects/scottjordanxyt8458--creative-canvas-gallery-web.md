## Project Overview

Creative Canvas Art Gallery provides a simple web presentation for creative canvas artwork. Open the project in a browser to move through the collection using a visual, gallery-oriented interface.

The site is intended for both art browsing and straightforward online presentation. Since it is built around HTML, it can be viewed from a local folder or deployed to a static web host as a lightweight gallery site.
