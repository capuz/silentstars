# Data Science Web Textbook (High School 2022 Curriculum Revision)

A web textbook for students and teachers used in the 『Data Science』 class during the Fall 2026 semester at Danggok High School. Designed as a Vibe Coding class where students leave code to AI and learn **question setting, data sensibility, result interpretation, and limitation awareness**.

**View textbook** → <https://greatsong.github.io/ds-danggok-2026/>
**Using at other schools** → [Fork and customization guide](https://greatsong.github.io/ds-danggok-2026/fork-guide.html)

No build tools. GitHub Pages serves HTML, CSS, and JavaScript files as-is. Changes reflect in 1-3 minutes after committing.

### What's Included

| Folder/File | Contents |
|---|---|

| `lessonNN-deep.html` | Detailed version of the same lesson. Main content is mostly the same with additional explanations |
| `extra-*.html` | Advanced/free practice (movie API, model catalog, hypothesis verification) |
