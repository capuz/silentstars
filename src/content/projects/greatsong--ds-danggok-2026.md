# Data Science Web Textbook (High School 2022 Revised Edition)

Danggok High School's student and teacher web textbook actually used in the 『Data Science』 class during the 2026 academic year, second semester. Designed as vibe coding classes where code is left to AI, and students learn **question formulation, data inspection, result interpretation, and awareness of limitations**.

**View Textbook** → <https://greatsong.github.io/ds-danggok-2026/>
**Using at Other Schools** → [Fork and Customization Guide](https://greatsong.github.io/ds-danggok-2026/fork-guide.html)

No build tools. HTML, CSS, and JavaScript files are served directly by GitHub Pages. Changes are reflected 1-3 minutes after committing.
