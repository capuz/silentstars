# 🔗 ParseHub

**Social Media Aggregation Parser**

Lightweight, asynchronous, out-of-the-box social media parsing and media downloading library, supporting 17+ platforms

## ✨ Features

- 🌍 **Wide Platform Support** — Covers 17+ mainstream social media platforms both domestically and internationally
- 🧹 **Link Cleaning** — Automatically extracts links from shared text and removes removable tracking parameters
- 🎬 **Multimedia Parsing** — Supports videos, images, GIFs, live photos, and rich text articles
- 📦 **Synchronous / Asynchronous API** — Provides both `async/await` and `*_sync` calling methods
- 🐚 **CLI Support** — Native command line support, lightweight and ready to use
- 🤖 **Telegram Bot** — A bot based on this project is now online → [@ParseHuBot](https://t.me/ParsehuBot)
