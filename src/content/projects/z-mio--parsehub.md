# 🔗 ParseHub

**Social Media Aggregation Parser**

A lightweight, asynchronous, ready-to-use library for parsing social media and downloading media, supporting 17+ platforms

Simplified Chinese | [English](https://github.com/z-mio/ParseHub/blob/HEAD/README.en.md)

## ✨ Features

- 🌍 **Broad platform support** — covers 17+ mainstream social media platforms at home and abroad
- 🧹 **Link cleaning** — automatically extracts links from share text and removes removable tracking parameters
- 🎬 **Multimedia parsing** — supports videos, image-text posts, animated images, live photos, and rich-text articles
- 📦 **Sync / async API** — provides both `async/await` and `*_sync` call styles
- 🐚 **CLI support** — native command-line support, lightweight and ready to use
- 🤖 **Telegram Bot** — a Bot built on this project is live → [@ParseHuBot](https://t.me/ParsehuBot)
