Manage your knowledge base with a local directory. It natively supports Markdown notes, professional Draw.io diagramming, GeoGebra math modeling, MindMap mind maps, KDBX encrypted password vaults, and professional PDF reading annotations, and uses Git for version control, sync, and recovery.<br>

## Product Positioning

MarkNotePro is a local-first structured knowledge management and multimodal authoring workbench. It builds a systematic knowledge base around a note workspace. A left-side panel organizes documents into sections, and the right side natively integrates Markdown, Draw.io architecture diagrams, GeoGebra math modeling, MindMap mind maps, and PDF professional reading annotations. It supports simple editing of common text formats such as txt and json. It includes a built-in KDBX encrypted key vault with 2FA dynamic passwords, and provides direct SSH terminal connections (you must first set up a key vault, then connect through it with automatic 2FA verification). It also links seamlessly with Git for version control, commits, and sync.

- Keeping personal notes, technical architecture diagrams, math and engineering derivations, mind maps, PDF…
