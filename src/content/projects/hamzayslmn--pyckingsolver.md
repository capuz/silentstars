# pyckingsolver

**[PackingSolver](https://github.com/fontanf/packingsolver) from Python: irregular 2D nesting (Shapely polygons welcome), 3D box packing and 1D cutting, used like upstream's own modules, every parameter included, each solve in a crash-proof child process.**

## Install

```bash
pip install pyckingsolver
```

It brings upstream's own solver module, `packingsolver` (wheels for Windows x64 and x86, Linux x86_64 and
aarch64 with glibc 2.28 or newer, macOS arm64 and x86_64), pinned to one upstream commit. Python 3.13+.
