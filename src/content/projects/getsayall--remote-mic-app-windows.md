SayAll Wireless Microphone Windows Edition has completed Windows native device adaptation for Xiaomi Bluetooth remote control 2 (RC001) and 2 Pro (RC003), covering verified scenarios including device identification, connection, key mapping, and voice bridging. The project uses Rust, Tauri 2, and Vue 3, with separate maintenance and releases for Windows and macOS.
