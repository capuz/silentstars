# Bedrock Models Explorer Monorepo

A comprehensive toolkit for working with Amazon Bedrock foundation models, providing type-safe model IDs, cross-region inference utilities, and an interactive explorer.

## 🌐 [Browse Models Online](https://mirai73.github.io/bedrock-models/)

Explore all available Bedrock models with our interactive web interface. Search by model name, filter by region, and find CRIS-enabled models.

## Repository Structure

This is a monorepo managed with `pnpm` and `turbo`.

- **[`packages/python`](https://github.com/mirai73/bedrock-models/blob/HEAD/file:///packages/python)**: Python library with model constants and CRIS utilities.
- **[`packages/typescript`](https://github.com/mirai73/bedrock-models/blob/HEAD/file:///packages/typescript)**: TypeScript/JavaScript library with parity to the Python implementation.
- **[`docs`](https://github.com/mirai73/bedrock-models/blob/HEAD/file:///docs)**: Source for the interactive Model Explorer website.
- **[`packages/shared`](https://github.com/mirai73/bedrock-models/blob/HEAD/file:///packages/shared)**: Shared data (`bedrock_models.json`) and generation scripts.
