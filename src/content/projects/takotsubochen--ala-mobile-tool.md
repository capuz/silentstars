## Demo

### Pedal Layout

| Single pedal | Dual pedal |
|---|---|
| <img src="docs/images/single-pedal.gif" width="360" alt="Single pedal demo"> | <img src="docs/images/dual-pedal.gif" width="360" alt="Dual pedal demo"> |

Single-pedal mode: swipe up and down on the screen with one finger. The upper half controls the throttle and the lower half controls the brake.

Dual-pedal mode: the left and right fingers each control a separate throttle and brake pedal.

### Overlay Controls

Icon buttons are draggable. A single tap toggles overlay control visibility. Long-pressing a module icon button enters edit mode (the screen dims and a centered instruction hint appears). In edit mode, drag to move, and use the four corner dots to resize each overlay control. Long-pressing empty space for 2 seconds resets the layout. (In edit mode, the game screen is fullscreen and cannot be operated.):
