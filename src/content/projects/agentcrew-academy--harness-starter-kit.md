# Five skills you'll use every day, plus a few small tools that keep AI honest

> **Updated 2026-10-22**: The kit is now a core set. New: **humanizer** (removes the "AI voice" from a draft) and **block-outgoing-comms** (asks you before anything sends an email, message or post). You can now install with Claude Code's plugin commands, one line each. review-loop, info-diet, phantom-pushback, asd-ste100, iso-24495 and claude-md-template moved to `retired/`: still there to read, but no longer installed or maintained. Details in [`retired/README.md`](https://github.com/agentcrew-academy/harness-starter-kit/blob/HEAD/retired/README.md).

Has this ever happened to you: you tell an AI "always run the tests before you say you're done," it does that the first three times, then forgets on the fourth, and doesn't tell you.

That's why I built these.

The problem is that a rule is just a piece of text. The AI reads it and understands it, but it's under no obligation to follow it. The longer the conversation gets, the more that text gets diluted. It's not lying on purpose. It genuinely isn't…
