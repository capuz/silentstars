# Binglan Desktop

[English](https://github.com/keros68/binglan/blob/HEAD/README_en.md) · [Download](https://github.com/keros68/binglan/releases/latest) · [Quick Start](#快速开始) · [User Guide](https://github.com/keros68/binglan/blob/HEAD/docs/USER-GUIDE.md) · [Development Guide](https://github.com/keros68/binglan/blob/HEAD/docs/DEVELOPMENT.md) · [License](#许可证)

**Manage desktop info cards, to-dos, file groups, Dock, and taskbar on Windows 11 in one app.**

Binglan Desktop is a Windows 11 desktop companion built on .NET 10 and WPF. It replaces several separate tools previously used for desktop info, file organization, Dock, and taskbar beautification. All modules share one process, one tray icon, and one settings center.
