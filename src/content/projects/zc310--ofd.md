## Introduction to OFD

OFD (Open Fixed-layout Document) is a commonly used fixed-layout document format in China's electronic document field, primarily used to preserve electronic files with fixed layouts that display consistently across devices. OFD files are typically organized as ZIP containers containing XML documents, page content, text, paths, images, fonts, attachments, and signatures and other resources; pages can contain text, vector graphics, and raster images, and retain corresponding layout and rendering information.
