# sailflow

> **Tribute to [Slickflow](https://github.com/besley/slickflow)**  
> This repository is a secondary rework of the open-source workflow engine [Slickflow](https://github.com/besley/slickflow). Thanks to Besley, Hangzhou Ligong Technology, and the community for their outstanding contributions. The upstream project is licensed under MIT; for source licensing details, see [NOTICE](https://github.com/sailuosi/SailFlow/blob/HEAD/NOTICE).

**Pluggable · Extensible · Multi-database · .NET 6 / 8 / 10**

A self-developed workflow engine, still under iteration. **Basic flow transitions have passed testing.** Compared with upstream Slickflow, the data layer, structure, and frontend have been reworked. From here on it will **continue to evolve independently** and no longer sync with upstream source code.
