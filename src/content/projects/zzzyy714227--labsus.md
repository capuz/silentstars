# 🏎️ LABSUS · Suspension Lab

**Full-vehicle chassis high-performance suspension analysis workbench — Kinematics & Compliance / 15-DOF Dynamics / Quasi-static Handling / Race-track Transient Simulation**

> A modern full-vehicle chassis and suspension engineering analysis platform for **FSAE Formula SAE race cars, GT3 touring cars, and off-road all-terrain vehicles**. From double-wishbone / push-pull rod spatial hardpoint editing, multibody kinematics and K&C sweeps, to 4-Post rig dynamics, quasi-static load transfer, and **15-DOF full-track autonomous-driving transient simulation**, everything is done in one polished, modern interactive instrument panel. It is a lightweight in-house implementation, **with architectural layering referencing** OptimumKinematics and ADAMS/Car; **the numerical values are not calibrated against real vehicles**. For internal reliability and modeling boundaries, see `LABSUS/MODEL_SCOPE.md` and `LABSUS/VERIFICATION.md`.
>
> 📁 **The engineering code is located in the [`LABSUS/`](https://github.com/ZZzyy714227/Labsus/blob/HEAD/LABSUS/) subdirectory**; all relative paths in this document are relative to that root.
