# Classic admin-side theme for Textpattern CMS

The classic admin theme that ships as standard with [Textpattern CMS](https://textpattern.com/).

## Demos

[Design patterns documentation](http://design-patterns-classic.textpattern.com/docs/).

[Flat mockup of Textpattern admin area](http://design-patterns-classic.textpattern.com/mockups/).

## Supported web browsers

* Chrome, Edge, Firefox, Safari and Opera the last two recent stable releases.

## Build setup

### Installing required tools

The project uses [Grunt](https://gruntjs.com/) to run tasks and [Sass](https://sass-lang.com/) for CSS pre-processing. First make sure you have base dependencies installed: [Node.js](https://nodejs.org/) and [Grunt](https://gruntjs.com/). You can install Node using the [installer](https://nodejs.org/) and Grunt with npm:

```ShellSession
$ npm install -g grunt-cli
```

Consult the Grunt documentation for more instructions if necessary.
