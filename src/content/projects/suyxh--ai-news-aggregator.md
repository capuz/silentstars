## ✨ Highlights

### 📡 Multi-Source Aggregation
Fetches news in real time from **14 professional platforms** + **70+ curated RSS feeds** + **52 WeChat official accounts**, covering the global AI ecosystem

### 🧠 Smart Filtering
Keyword-based AI relevance filtering that precisely extracts AI and tech content from massive volumes of information

### 🌐 Bilingual Support
English titles are automatically translated into Chinese, with three display modes: original, translation, and bilingual

### ⚡ Automatic Updates
GitHub Actions fetches data automatically every 2 hours, so the data always stays up to date

### 🎨 Web Visualization
Built-in React + TypeScript web app with multi-dimensional filtering, search, and dark mode

### 📦 Structured Data
Outputs standard JSON format for easy secondary development and data analysis…
