# YOLO Data Agent | Enterprise Intelligent Data Q&A Platform

A self-service data analysis platform for business teams: ask questions in natural language, get traceable results from data with unified definitions, and keep breaking down, comparing, and analyzing within the same session.

YOLO Data Agent connects agents, metrics and business datasets, permissions, and analysis workspaces into a manageable data Q&A workflow. Business users do not need to write SQL: they can ask questions directly, add conditions, and follow up on results; when key information is unclear, the agent asks for clarification first. Administrators are responsible for connecting data and configuring business topics and authorization scopes, so teams can perform analysis within controlled data boundaries.

The platform does not treat 'a SQL statement generated by a model' as an analysis result: query scope, metric definitions, and permissions are configured by the platform and validated at execution time; results, sessions, and analysis artifacts can be retained to support ongoing work and auditing.
