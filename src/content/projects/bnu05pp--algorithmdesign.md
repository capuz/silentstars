# 算法设计与分析

## 课程简介

### 课程概述

Computer algorithms are the main means by which computers solve practical problems, and they are one of the core skills that students majoring in fields such as big data and software engineering need to master. Building on the data structures course, the Algorithm Design and Analysis course further examines the problem descriptions, main ideas, basic principles, and application scenarios of major algorithms. This enables students not only to understand how current major algorithmic techniques work, but also to understand the background and design philosophy behind these algorithms, so they can flexibly apply these techniques and design suitable algorithms for real-world problems.
