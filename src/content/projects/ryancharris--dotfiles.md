# dotfiles

Personal configuration files for macOS, managed via symlinks.

## setup

```sh
git clone https://github.com/ryancharris/dotfiles ~/dotfiles
~/dotfiles/install.sh
```

> [!NOTE]
> Installs Homebrew (if missing), all CLI tools and GUI apps, and creates symlinks.
