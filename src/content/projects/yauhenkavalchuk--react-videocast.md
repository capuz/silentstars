# React Videocasts
Material for a series of podcasts dedicated to the **ReactJS** library. These podcasts cover new versions of the library, updated and added features, as well as functionalities that are becoming obsolete. Keep your finger on the pulse of the latest updates and subscribe to the [YouTube channel](https://youtube.com/c/YauhenKavalchuk)!

### Quick Start
- Clone the repository: `git clone https://github.com/YauhenKavalchuk/react-podcasts.git`
- Install dependencies: `yarn install` or `npm install`
- Switch to the branch corresponding to the podcast: `git checkout <branch name>`
- Run the project: `yarn start`
