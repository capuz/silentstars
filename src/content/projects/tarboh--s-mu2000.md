# S-MU2000

Yamaha MU2000 software sound source. Intended for use by inserting into a DAW.

**Current status: Runs in a DAW as VST3 and CLAP (Windows) and VST3 and Audio Unit (macOS). Includes a screen styled like the hardware's front panel and an editor to use on PC.**

Proceeding while sharing work in progress. On X: `#S_MU2000`.

> Unofficial project unrelated to Yamaha. Yamaha, MU2000, and XG are trademarks of Yamaha Corporation.

## Hardware-sourced data will not be distributed or included

**What this repository publishes is only the source code for the emulator and extraction tools.**

Yamaha's ROMs, waveform data, and firmware are not included in this repository or its distributions, and never will be. Users must extract the ROMs needed to run it from their own MU2000 themselves.

Publishing source code and publishing or sharing data extracted from the hardware are separate matters; this project does only the former. We ask users to follow these guidelines as well:

* Do not redistribute extracted waveform ROM or program ROM images anywhere, including GitHub
