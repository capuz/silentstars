# MusicConverter

A local music management, format conversion, and audio processing tool for Android.

Current official version: **v2.6**
Minimum Android version: **Android 10 (API 29)**

## v2.6 Update Content

- Optimized daytime color scheme and text contrast; fixed the issue where dark dialogs and purple controls don't follow theme changes.
- See [v2.6 Release Notes](https://github.com/YJ-Lazy/MusicConverter/blob/HEAD/release-notes/v2.6.md) for details.

## Main Features

- Home page directly lists local music on the device
- Local music displayed by source directory with pagination; directory tags support horizontal scrolling
- Local music list supports cache restoration; won't automatically rescan on every startup
- Local music uses batch loading to reduce scrolling lag with large numbers of songs
- When local music lacks album artwork, the app can search online and cache the artwork
- Built-in player and bottom mini player
- Current playlist supports adding, removing, clearing, and tap to switch songs
- Supports sequential playback, single-song loop, and shuffle playback
- Shows system notification bar prompts during playback
- Single file conversion and batch conversion…
