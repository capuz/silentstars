# <img src="https://raw.githubusercontent.com/MinatoJT/WarThunder-Camo-Translator/HEAD/assets/camo-translator.png" width="40" height="40" align="middle" alt="" /> Camo Translator

> **Warning**
>
> **This tool unpacks the local game resources of War Thunder.** It reads vehicle models, UV and material data from the game installation directory you select, to generate custom liveries.

Camo Translator lets parts that share UV coordinates be painted with different patterns. It generates independent UVs and models importable into Substance 3D Painter for the parts you place into `Reused` objects, then overlays each part's base color onto the corresponding part through the game's **Camo (camouflage) mechanism**. Camo applies to materials in the game that support camouflage.
