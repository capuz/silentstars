# Agent Native Init

Agent Native Init is a transferable Agent collaboration initialization protocol.

Its goal is not to generate an application template for a specific technology stack, but to provide any project with a layer of stable Agent collaboration capabilities: entry rules, project memory, task governance, acceptance gates, handover mechanisms, reusable workflows, and collaboration profiles.

## What This Project Solves

When developing with AI Agents over the long term, common issues are not that "Agents cannot write code," but rather:

- New sessions do not know the current state of the project;
- Agents do not have clear authorization boundaries;
- Tasks cannot be handed over halfway;
- Tests pass but acceptance is not closed;
- Important decisions are scattered in chat records;
- Context breaks when switching between multiple Agents or tools;
- Each project requires a new verbal agreement on a set of collaboration rules.
