# Growth Tree: Graph Theory

**Growth Tree: Graph Theory** is a browser strategy game centered on graph-theoretic topology and tree-like expansion. Players establish root nodes on a randomly generated regional map, expand their influence by continually growing branches, and use the tree structure between nodes to attack, defend, and fight.

The game supports local two-player matches, human-versus-computer matches, and an interactive tutorial for new players. A full match covers match setup, map deployment, turn actions, combat feedback, and result settlement. Players can review AI action analysis and combat rule breakdowns, and after a match ends, view both sides' performance and key events, or start a rematch directly. It abstracts the connections between map regions into a graph, organizes players' forces into trees, and builds a strategy gameplay centered on spatial planning, branch management, and trade-offs between offense and defense.

**Play online:** https://zshebjtzs.github.io/tree-grow-game/
