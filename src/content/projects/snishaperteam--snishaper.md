# SniShaper

[中文](https://github.com/SnishaperTeam/SniShaper/blob/HEAD/README.md) | [English](https://github.com/SnishaperTeam/SniShaper/blob/HEAD/README_EN.md) | [Русский](https://github.com/SnishaperTeam/SniShaper/blob/HEAD/README_RU.md)

**SniShaper** is a local proxy application designed for complex network environments. It uses multiple approaches, including **ECH injection**, **TLS fragmentation**, **QUIC conversion**, and **session migration**, to provide stable and flexible network access in challenging conditions.

This project supports multiple platforms. See **[Platform.md](https://github.com/SnishaperTeam/SniShaper/blob/HEAD/docs/Platform.md)** for details.
