# PiDeck

[English](https://github.com/ayuayue/PiDeck/blob/HEAD/README.en.md) · [LinuxDO 友链](https://linux.do)

**A desktop workspace for managing multiple [pi](https://pi.dev) coding Agent sessions.**

**PiDeck** is an open-source desktop workspace for unified management of pi Agent sessions in local project directories, supporting the import of Codex and Claude local sessions for unified browsing and recovery. Built on Electron + TypeScript, it provides multi-project workspaces, AI session management, Git integration, a built-in terminal, model configuration, and plugin extension capabilities, allowing local AI coding assistants to remain unified, traceable, and configurable in multi-project environments.

**Who is it for:** Developers who want to manage multiple local project AI programming assistant sessions on the desktop, need to view session history and Git status uniformly, and wish to manage pi configurations graphically.
