# PiDeck

[English](https://github.com/ayuayue/PiDeck/blob/HEAD/README.en.md) · [LinuxDO 友链](https://linux.do)

**A desktop workbench for managing multiple [pi](https://pi.dev) coding agent sessions.**

`PiDeck` **is not** a branch of pi. It is a lightweight Electron shell that integrates project management, session management, dialogue interface, configuration management, and tool orchestration into a native desktop application by launching multiple `pi --mode rpc` processes—all agent capabilities are provided natively by pi.
