# LavaAnimeLibWeb

Frontend for LavaAnimeLib (Magma Anime Library), current version V2.5.

The V2 version of this project is still a highly coupled program that cannot be deployed independently; independent deployment will be supported in the V3 version currently under development.

## Frontend Technology Stack

This project's (frontend) primarily uses the following libraries:

- [Nuxt](https://nuxt.com/): An out-of-the-box Vue development environment that provides SSR, auto-import, cross-platform deployment, TypeScript support, and more. It also includes the following frameworks:
  - [Vite](https://cn.vitejs.dev/): Next-generation frontend toolchain
  - [Vue.js](https://vuejs.org/): Progressive JavaScript framework
  - [Vue Router](https://router.vuejs.org/): Official routing for Vue.js
- [Pinia](https://pinia.vuejs.org/zh/): Intuitive Vue.js state management library
