# PrismSpace · Prism Space

**Based on Android work profile, lightweight native app dual-open solution**

<p>
</p>

</div>

PrismSpace creates truly isolated dual-open spaces at the system level—app data, accounts, and storage are completely separate, with better compatibility and no additional performance overhead. Implemented based on Android's native work profile capability, different from virtualization solutions like Parallel Space. Supports three operating modes: Normal, Shizuku, and Root.
