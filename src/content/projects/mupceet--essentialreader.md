# Legado with MD3

## 📖 Introduction

**Legado with MD3** is a Material Design 3-style refactored version developed from the open-source project [阅读 (Legado)](https://github.com/gedoor/legado).

In addition to redrawing the UI, this project adds many branch-exclusive features and is gradually migrating from traditional View to the Jetpack Compose framework, with the goal of providing a more modern, smooth, and consistent reading experience.

> [!CAUTION]
> **Notes:**
> Because the theme system was refactored using the Monet engine, the official version's themes are no longer available in this version.
>
> **Devices below Android 12:**
> Custom themes and dynamic color extraction are temporarily unavailable. This limitation will be resolved after the Jetpack Compose migration is complete (due to limited developer bandwidth, the migration will take a long time).
