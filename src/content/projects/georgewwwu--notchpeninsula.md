## Project Overview

NotchPeninsula is a "notch screen" style desktop widget for Windows 10/11, implemented using a combination of Win32 + SkiaSharp + NAudio, with the core goal of integrating system media status, notification messages, and audio visualization into an ultra-narrow floating area at the top of the screen.

It generates a lightweight transparent window at the desktop top, centralizing system media status, notification messages, and audio visualization in an ultra-narrow floating area:

- System media playback status and dynamic island lyrics (including translations and word-by-word lyrics)
- Real-time audio spectrum, time/date display, and CPU/memory usage
- Windows Toast notifications with optional notification sound
- Clipboard link recognition and custom components supporting third-party plugins
- Sleep mode: collapse the island into a small capsule with optional sleep content (time/blank/collapsed media controls)
- Auto-hide, window always on top, mouse pass-through, and auto-update detection
