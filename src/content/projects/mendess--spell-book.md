# Spell Book
 A collection of scripts and dotfiles I like to keep handy.

## [Spells](https://github.com/mendess/spell-book/blob/HEAD/spells/): Scritps to be run by hand or through a keybind.

 - [add_rune](https://github.com/mendess/spell-book/blob/HEAD/spells/add_rune.spell) - Add a new [rune](https://github.com/mendess/spell-book/blob/HEAD/runes-static-configuration-files) to the dotfiles, supports some customization options
 - [allgst](https://github.com/mendess/spell-book/blob/HEAD/spells/allgst.spell) - Performs `git status` on every folder in the `cwd`.
 - [battery_check](https://github.com/mendess/spell-book/blob/HEAD/spells/battery_check.spell) - Checks battery life and suspends if it's too low.
 - [bt-connect](https://github.com/mendess/spell-book/blob/HEAD/spells/bt-connect.spell)
 - [bulkrename](https://github.com/mendess/spell-book/blob/HEAD/spells/bulkrename.spell) - Bulk rename every file in the current directory using your default editor (Editor defined by $EDITOR or $VISUAL)
 - [changeMeWallCicle](https://github.com/mendess/spell-book/blob/HEAD/spells/changeMeWallCicle.spell) - Runs `changeMeWall` every 5 minutes
