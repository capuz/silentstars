## Quick Start (5 minutes)

```bash
# 1. Clone and install
git clone https://github.com/teachlink/backend.git
cd teachlink_backend
pnpm install

# 2. Configure environment
cp .env.example .env
# (edit .env with your settings, defaults work for local dev)

# 3. Start databases
docker compose up -d postgres redis

# 4. Start the server
pnpm start:dev

# 5. Verify it works
curl http://localhost:3000/health
```

Open http://localhost:3000/api/docs for the interactive API documentation.

> **New developer?** See the full [setup guide](https://github.com/rinafcode/teachLink_backend/blob/HEAD/docs/setup.md) for detailed instructions, prerequisites, and troubleshooting.
