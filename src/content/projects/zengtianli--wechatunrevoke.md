In the menu “Configuration & Updates…”, you can choose to use the system iCloud to remember the prompt style and automatic checks and re-apply patch preferences, and you can also export and import configuration. The WeChat path, whether this machine has previously been patched, login items, and system permissions are not migrated. Restoring a configuration does not authorize modifying WeChat on a new machine. The menu item “Check for Updates…” fetches new versions from this release channel on demand.
