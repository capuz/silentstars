## uni-admin

uni-admin is an admin backend project template based on uni-app and uniCloud.

Developers using uniCloud should use this framework for their back-office management systems.

We have set up the [uni-admin demo site](http://hellouniadmin.dcloud.net.cn/admin/). After you log in, you can quickly try out uni-admin.

uni-admin is open source and released under the MIT license. You can get the source code from [Github](https://github.com/dcloudio/uni-admin) or [Gitee](https://gitee.com/dcloud/uni-admin), or download it quickly from the [DCloud plugin marketplace](https://ext.dcloud.net.cn/plugin?id=3268).

## Framework Features

- Wide-screen adaptation based on uni-app. It automatically adapts to PC wide screens and to mobile devices on every platform. Learn about [wide-screen adaptation](https://uniapp.dcloud.io/adapt)
- Based on uniCloud, a serverless cloud development platform. Learn about [uniCloud](https://uniapp.dcloud.io/uniCloud/README)
- Based on uni-id, using uni-id's user account, role, and permission system. Learn about [uni-id](https://uniapp.dcloud.io/uniCloud/uni-id)
