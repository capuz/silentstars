# MindWord — Write documents as easily as drawing

> **Structurally expand a sentence layer by layer into a controllable, editable, and exportable finished document.**

This is a writing tool based on mind mapping, which supports bidirectional synchronization editing between a visual multi-level mind map and Markdown. It supports AI-assisted generation of nodes and descriptions, and can export documents with Word template styles.

Target user groups: writers, product managers, vibe coding enthusiasts, knowledge workers, etc.
