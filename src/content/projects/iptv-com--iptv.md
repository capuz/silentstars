# 📺 IPTV-com (Brasil)

O **IPTV-com** é um projeto de curadoria focado em organizar e manter listas de reprodução (M3U) de canais de televisão brasileiros que transmitem sinal aberto e gratuito pela internet.

---

## 🚀 Sobre o Projeto

Este projeto é uma ramificação estratégica focada na lusofonia (Brasil e países de língua portuguesa), utilizando como base a infraestrutura e dados globais do `iptv-org`. Nosso objetivo é oferecer uma lista limpa, funcional e organizada por categorias locais.

### 🎯 Diferenciais
* **Foco Regional:** Canais abertos, legislativos, universitários e locais do Brasil.
* **Organização PT-BR:** Grupos de canais nomeados em português (Notícias, Esportes, Cultura).
* **Verificação Ativa:** Links monitorados para evitar transmissões offline.
