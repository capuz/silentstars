# NAI Launcher

  Simplified Chinese · <a href="README.zh-TW.md">Traditional Chinese</a> · <a href="README.en-US.md">English</a>

> NAI Launcher is a community-developed third-party client and is not an official NovelAI product. Before using online features, prepare your own NovelAI account and comply with the relevant terms of service, content rules, and local laws.

NAI Launcher is designed for image creators who frequently use NovelAI. Generation, image editing, Prompt, characters, reference images, gallery, queue, and intelligent agents all connect within the same workflow. Windows, macOS, and Android share core capabilities, and you can use local tools without logging in.
