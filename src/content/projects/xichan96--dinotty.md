# Dinotty

---

A **multi-device synchronized** terminal server designed for **Coding Agents**. Run Claude Code, opencode, Codex, or OpenClaw on any device, with a professional and efficient desktop experience and mobile control at any time—seamless switching, sessions never lost.

## Desktop Demo

**Command Favorites** — Right-click terminal text to directly save, manage in groups, execute with one click:

**SSH Connection and File Browser** — Built-in SSH client, remote sessions consistent with local experience, full coverage of SFTP file management:
