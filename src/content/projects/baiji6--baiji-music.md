# Baiji Music · Baiji Music

A cross-platform music player client. A single Flutter/Dart codebase natively supports **iOS / macOS / Windows / Linux / Android / HarmonyOS** on six platforms. The UI uses a dark glassmorphism and neon gradient design with a modern, futuristic feel. At build time, it automatically applies **packing and obfuscation** to prevent reverse engineering.

> This project was refactored from "Baiji Music Android Native v1.1.1". All C algorithm libraries (hash33 / zzc_sign / tripledes / qrc / qimei / comm) were ported to pure Dart. The network layer supports seven music sources: **QQ Music / NetEase Cloud Music / Kuwo Music / Kugou Music / Migu Music / JOOX / Soda Music**. Feature modules cover search, playback, playlists, downloads, QR code login, and local music.
