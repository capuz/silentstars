**A theme plugin that recreates the Claude Code Desktop style and interaction experience for DeepSeek Harness.**

> **In DSH, it looks like Claude Code Desktop.**

## Preview

This plugin provides two themes. In the plugin settings, you can switch between the Claude and DeepSeek color schemes. Light and dark modes follow the system color mode.

### Claude

> The Claude brand theme, true to the original. Workspace home page (top), conversation interface (bottom), light mode (left), dark mode (right)

### DeepSeek

> The DeepSeek brand theme, featuring the signature pet, the little whale Deepy. Workspace home page (top), conversation interface (bottom), light mode (left), dark mode (right)
