# C++ Matrix Multiplication Performance Analysis and Blocked Optimization Experiments

Using C++ matrix multiplication as a vehicle, I am learning how to verify program correctness, design performance comparison experiments, and analyze the results of different implementations. The project starts from the effect of loop order on memory access and then tries blocked computation. Experimental data, analysis reports, and code are stored in the repository. Through this work, I hope to gradually understand data reuse, laying a foundation for later study of NPU architecture and dataflow.
