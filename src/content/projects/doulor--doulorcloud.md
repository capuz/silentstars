# Doulor Cloud

**An all-in-one cloud resource distribution platform** — subdomains, domain email, direct-link file hosting, personal cards (Bento space), and an AI API relay station

[cloud.doulor.cn](https://cloud.doulor.cn)
·
[<img src="https://cdn.simpleicons.org/github/8b949e" width="15" height="15" alt="GitHub" style="vertical-align:-2px" />](https://github.com/Doulor/DoulorCloud) Doulor/DoulorCloud

Pure static frontend + serverless backend: the frontend is an SPA shipped directly as build output, and the backend runs entirely on Cloudflare Workers, using D1 (SQLite) for the database and R2 for object storage. It does not depend on any always-on server.
