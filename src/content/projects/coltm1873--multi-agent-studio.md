## Quick Start

### Step 1: Prerequisite Software

1. **PostgreSQL**: Not needed if you use the SQLite sub-version of the Lite edition.

### Step 2: Download

1. Open this repository's page, click **Releases** on the right, and under the latest release click **Source code (zip)** to download it (or git clone directly).

### Step 3: Extract

1. Unzip the archive to get a `multi-agent-studio-*` folder.

### Step 4: Enter the Project Folder

1. Double-click into it and keep going until you reach the level where you can see `setup.bat` and `build_exe.bat`.
