# M350 CNC System Development Resources (Full Version)

This repository contains the comprehensive development resource package for the **M350** controller, including wiring diagrams, parameter descriptions, G/M code lists, Modbus manuals, and macro development examples.

---

## 🚀 Quick Download Guide (Highly Recommended)

**The web preview on GitHub may not display all PDF and Word documents correctly or completely.** To ensure you have all the technical data and tools, please download the entire package to your local computer:

1. Click the green **`Code`** button at the top right of this page.
2. Select **`Download ZIP`** from the menu.
3. Extract the ZIP file on your computer to access all folders and documents.

---

## 📂 Repository Structure & Contents

* **Manuals**: M350 Operation Manual (Latest Version).
* **Development**: Custom G-codes (G100-G199), Modbus RTU communication, and Macro function (#RECORD) descriptions.
* **Hardware**: MPG (Handwheel) wiring precautions, Absolute servo configuration, and Master-Slave axis (Gantry) settings.
* **Special Features**: USB Barcode scanner setup, ATC (Auto Tool Changer) customization, and Auto-centering…
