# AI Reader V2 — AI Novel Analysis Visualization Tool

> **[English Version](https://github.com/mouseart2025/AI-Reader-V2/blob/HEAD/README_EN.md)**

> **Disclaimer:** This project is currently in an intensive iteration phase for improving data analysis quality, with rapid version changes and not yet at a practical stage. The currently provided web development version and desktop installation packages are **for early experience only**, and analysis results may contain many errors. Welcome to try it out and provide feedback, but please do not use it for formal academic research or literary analysis.

**Open-source AI novel analysis tool** — Upload any TXT/Markdown novel, AI automatically extracts character relationships, location hierarchies, event timelines, and generates interactive knowledge graphs, world maps, timelines, and other multidimensional visualizations. Supports local Ollama and cloud LLMs, 100% local data storage, no internet required.

Applicable for: web novel analysis, novel worldbuilding organization, literary research, creative assistance, character relationship mapping, plot clarification, fanfiction reference.
