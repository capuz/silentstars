### External playlist API
Get QQ Music playlist list `https://music.nekocore.cn/loser1/getSongListDetail?disstid=歌单id`
Get NetEase Cloud Music playlist list `https://music.nekocore.cn/loser/playlist/track/all?id=歌单id`
