# Order of the Sinking Star · Level Workshop

**Order of the Sinking Star · Level Workshop**

A fan-made 3D level editor for the Windows version of Order of the Sinking Star. Design a puzzle from scratch, start with a template from the original game, or build an overworld connecting several levels.

An unofficial 3D level editor for the Windows version of Order of the Sinking Star. You can design a puzzle from a blank scene, import templates from the original game, or build an overworld map that links several smaller levels together.
