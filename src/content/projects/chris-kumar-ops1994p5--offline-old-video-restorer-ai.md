# AI Old Video Restoration Tool — VHS, Denoise & Detail Recovery

Offline AI old video restoration tool for Windows — restore VHS, family videos and low-resolution footage with denoise, deblur, compression cleanup, face restoration, color recovery, upscale and batch processing.

> **Local-first design:** source files are intended to be processed on the user's Windows PC; mandatory cloud upload is not part of the project concept.

## Features

- **VHS cleanup**
- **Noise reduction**
- **Compression artifact repair**
- **Deblur / sharpen**
- **Face restoration**
- **Color / contrast recovery**
- **2× / 4× upscale**
- **Before / after preview**
- **Batch queue**
- **Keep original audio**
- **Export profiles**
- **Local processing**

---

## Workflow

1. Import old video
2. Choose restoration preset
3. Tune denoise / detail
4. Preview sample frames
5. Enable optional face recovery
6. Choose upscale level
7. Process locally
8. Export restored copy
