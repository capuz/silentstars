# LYStar Code

Hand tasks to the Agent, follow its execution, read files, and review changes on the same page. You can start from a piece of code, or configure agents with different responsibilities to work on a project together through a collaboration space and a task board.

## What you can do with it

| What you want to do | Capabilities the workspace provides |
| --- | --- |
| Understand a project, fix bugs, implement features | The Agent reads and edits files, searches code, runs shell commands, and presents the process and results in the conversation |
| Make requests while checking changes | The right-side review workspace provides file browsing, Git changes and history, run records, and session branches |
| Work on multiple projects at once | Manage sessions by project, with project grouping, search, and resuming past sessions |
| Divide work among multiple agents | Configure each agent's model, Skills, and tools, and organize work through a collaboration space, member messages, and a task board |
| Use your own model service | Configure Providers, API Keys, and custom models, and switch models and thinking intensity in the input area |
