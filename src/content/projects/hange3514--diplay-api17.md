# DiPlay API 17 Compatibility Port

This repository is a wired and wireless CarPlay port for Android API 17, based on [shihabal3amri/DiPlay](https://github.com/shihabal3amri/DiPlay). The project code follows GPL-3.0. Public source code and release APKs are published on GitHub Releases.

## Automatic connection at boot, no VPN authorization needed

**This project handles the communication CarPlay requires inside the app. Neither the wired nor the wireless version needs to establish an Android system VPN, and no VPN authorization dialog appears after the head unit restarts.**
