# TabEx
Multi-tab file browser, an enhancement tool for Windows Explorer similar to Clover

## 📥 Download

**Latest version**: Download `TabExplorer.exe` from the [Releases](https://github.com/caojinyuan/TabEx/blob/HEAD/../../releases/latest) page

Ready to use after download, no need to install a Python environment!

---

## ✨ Core Features

- ✅ **Multi-tab browsing** - Chrome-style tabs with independent history and drag-to-reorder; right-click a tab to copy its path, duplicate it, move it to the other side, or close other/right-side tabs
- ✅ **Side-by-side split view** - Press `F3` or the `▫` button in the title bar to move the current tab into an independent tab group on the right. The left and right groups are fully equal: both support double-click to create, close, pin, and context menus, and tabs can be dragged freely between the two groups with a cross-group drag preview. Press `F3` again to move the right tab back to the left and close the split. Split state is saved with the session and restored automatically after a restart or unexpected close.
