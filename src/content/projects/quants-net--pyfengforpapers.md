# PyfengForPapers
A collection of Jupyter notebooks (`.ipynb`) using the [`PyFENG`](https://pypi.org/project/pyfeng) package to reproduce results from financial engineering papers. [`PyFENG`](https://pypi.org/project/pyfeng) is pre-installed on Google Colab — click any badge to run. See [PyFENG Installation](#pyfeng-installation) for local setup.
