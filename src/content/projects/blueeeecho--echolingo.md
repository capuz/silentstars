## Download and Installation

**[Download Windows 0.2.19 installer (x64)](https://github.com/Blueeeecho/EchoLingo/releases/download/0.2.19/EchoLingo_0.2.19_windows_x64-setup.exe)** · **[Download macOS 0.2.19 beta (Apple silicon)](https://github.com/Blueeeecho/EchoLingo/releases/download/0.2.19/EchoLingo_0.2.19_macos_arm64.dmg)**

Need a portable version? [0.2.18 Windows portable ZIP](https://github.com/Blueeeecho/EchoLingo/releases/download/0.2.18/EchoLingo_0.2.18_windows_x64-unpack.zip) is still available. Extract it completely, then open `Start-EchoLingo.cmd`. Windows still requires the Microsoft Edge WebView2 Runtime. Settings, history, and keys do not move with the ZIP.

Windows supports Windows 10 1809+ / Windows 11. The macOS package supports Apple silicon Macs running macOS 12+, and Apple system translation requires macOS 26+. After you open 回声译, the app stays in the system tray or menu bar. Before upgrading, fully quit the old version.
