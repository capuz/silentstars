## ok-py

[English](https://github.com/baoxin1100/ok-kes/blob/HEAD/README_en.md) | 中文

ok-py is a Python automation project template based on [ok-script](https://github.com/ok-oldking/ok-script). It provides a directly runnable GUI, task examples, configuration control examples, OCR examples, template matching examples, test cases, and packaging configurations, suitable for quickly creating your own Windows automation script projects.

This repository is not a finished automation product for a specific game, but a starting project and functional demonstration of ok-script applications.

## Main Content

- Directly launchable ok-script GUI application entry.
- `MyOneTimeTask` example task, demonstrating common task APIs and configuration controls.
- Configuration control examples: dropdowns, booleans, integers, floats, strings, multiline text, lists, multiple selections, file selection, folder selection, global configuration, and button groups.
- OCR, relative area recognition, and template matching examples.
