What is MAMEUI?
===============
MAMEUI has an inbuilt front-end allowing you to run a game from a list. It requires Windows 10 build 1607, 64-bit or later.

How to compile?
===============

You can only build MAMEUI on a Windows computer. It won't compile on Unix.

```
make OSD=messui PTR64=1 SYMBOLS=0 NO_SYMBOLS=1 DEPRECATED=0
```
