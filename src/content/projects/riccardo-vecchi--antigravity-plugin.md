# 🧩 Antigravity Plugin

**Unofficial plugin** for the Google Antigravity app on **Linux and Windows**. Requires the official Antigravity app to be installed separately.

> [!NOTE]
> Independent project, not affiliated with or endorsed by Google. Antigravity and Gemini names and logos belong to Google. See [NOTICE](https://github.com/Riccardo-Vecchi/antigravity-plugin/blob/HEAD/NOTICE.md).

## 🖥️ Platforms

| Platform | Status |
| --- | --- |
| 🐧 Linux x86-64 | Verified with Antigravity App 2.29.0 on Zorin/GNOME 46 |
| <img src="assets/logos/windows.svg" width="18" alt="Windows"> Windows 11 x64 | **Experimental**; community-verified installation on 2.28.0; desktop automation validation is pending |

## ✨ Features

- Gemini in the same window, with external links opening in your default browser, an in-page return button and a configurable shortcut (default **Ctrl+Alt+G**).
- Optional **Computer Use** (Cua Driver **0.38.0 stable**) with guided setup for the whole desktop or selected apps. [Setup guide](https://github.com/Riccardo-Vecchi/antigravity-plugin/blob/HEAD/docs/COMPUTER_USE.md).
- **Browser use** with browser detection, one-click folder copy/open, selected…
