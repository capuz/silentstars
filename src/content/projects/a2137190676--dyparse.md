# DY Parser (DYParse)

> **Author: 大爱仙尊 / 尘** | Feedback group: 995434160

A lightweight Android client for parsing content from multiple platforms. Paste a share link to parse videos, image-text posts, and animated images, with a built-in standalone player.

Currently supports **22 platforms**:
**Douyin / Kuaishou / TikTok / X (Twitter) / YouTube / Bilibili / Instagram / Xiaohongshu / WeChat Channels / WeChat Official Accounts / Weibo / Toutiao / Xigua Video / AcFun / Haokan Video / Zuiyou / Pipixia / Pipigaoxiao / Weishi / Doubao / Tencent Video / Magnet Download**.
