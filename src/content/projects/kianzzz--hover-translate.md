# 浮译 · Hover Translate

Native macOS menu bar translation tool: multilingual hover word lookup, local OCR, selection translation, and in-place translation preview and replacement within input fields.

Native macOS hover and selection translator built with SwiftUI, AppKit, Vision, Accessibility and Apple Translation. Text and image recognition run locally; no third-party translation API or API key is required.

> Currently v0.6.4 preview. Compatibility for cross-app word lookup, input-field replacement, and undo still needs to be verified app by app.
