# Primuse（猿音）

> **Try the latest version:** [Join the TestFlight public beta](https://g2.al/1)

Primuse is a native multi-source music player for the Apple ecosystem. It brings local files, NAS, media servers, cloud drives, internet radio, and Apple Music into one library and playback queue, and offers high-fidelity decoding, CUE track splitting, word-by-word lyrics, smart recommendations, cross-device sync, and full system playback controls.

The official version is now on the App Store. Search for Primuse on the App Store (the former name 猿音 also works), or use the button above to download.
