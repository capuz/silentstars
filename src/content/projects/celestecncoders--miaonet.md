# MiaoNet

A rewrite of CelesteNet, aimed at handling hundreds of Celeste multiplayer players.  
The project is called MiaoNet. To distinguish it from Miao.CelesteNet (which may also be called MiaoNet) and was built on CelesteNet earlier, MiaoNet+ can be used.  
The project is still in early development (as you can see, the branch is named `wip`). Although some external interfaces already exist, it is not recommended to depend on them too early, because it is still unstable and may receive breaking changes at any time.  

## Project

For project structure and environment setup, see [docs/project.md](https://github.com/CelesteCNCoders/MiaoNet/blob/HEAD/docs/project.md).
