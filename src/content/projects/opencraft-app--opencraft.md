# OpenCraft

Contribute through [CONTRIBUTING](https://github.com/opencraft-app/opencraft/blob/HEAD/CONTRIBUTING.md). To build a client extension, start with the [current boundary guide](https://github.com/opencraft-app/opencraft/blob/HEAD/docs/extension-development.md) and [runnable example](https://github.com/opencraft-app/opencraft/blob/HEAD/examples/extensions/README.md).

OpenCraft core is developed in this GitHub upstream. Product providers and
branding are composed downstream; see [transition status](https://github.com/opencraft-app/opencraft/blob/HEAD/docs/upstream-transition.md).
Original contributions use Apache-2.0; existing third-party notices and source
records are retained. npm publication is deferred.

OpenCraft is a maintainable TypeScript agent workbench. It has two renderer hosts over one
semantic application model and an explicit supervisor for lifecycle-scoped
runtimes: Vite/React DOM for desktop Web and Electron, and Expo Router for iOS,
Android, and Expo Web.
