# Hackintosh-EFI-Lenovo-Legion-R7000-2020-Ryzen-7-4800H

Dedicated OpenCore EFI for the Lenovo Legion R7000 2020 (AMD Ryzen 7 4800H) (OpenCore 1.0.9 dev). Based on deep tuning of SimpleKaruzi's EFI, it aims to work out of the box.

- **Supported range**: Tested on Catalina (10.15) ~ Tahoe (26). Mojave (10.14) is theoretically supported but has not been tested.
- Installation result screenshots for each version are available at [Screenshots](https://github.com/Emilelu/Hackintosh-EFI-Lenovo-Legion-R7000-2020-Ryzen-7-4800H/blob/HEAD/Screenshots).
- All external links referenced by this EFI are collected in [docs/Links.md](https://github.com/Emilelu/Hackintosh-EFI-Lenovo-Legion-R7000-2020-Ryzen-7-4800H/blob/HEAD/docs/Links.md).
