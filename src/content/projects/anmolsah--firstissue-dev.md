# FirstIssue.dev

FirstIssue.dev is a developer platform designed to help engineers start and track their open source contribution journey. It simplifies finding beginner-friendly issues, tracks contribution progress directly through GitHub integration, and aggregates merged work into verified developer portfolios.

## Documentation

Comprehensive guides are available in the `docs` directory:
- [System Architecture](https://github.com/anmolsah/firstissue.dev/blob/HEAD/docs/ARCHITECTURE.md) - Details on workflow and sync architecture.
- [Contributing Guidelines](https://github.com/anmolsah/firstissue.dev/blob/HEAD/docs/CONTRIBUTING.md) - Project standards and PR processes.
- [Student Onboarding](https://github.com/anmolsah/firstissue.dev/blob/HEAD/docs/STUDENT_GUIDE.md) - Introduction to finding your first issue.
