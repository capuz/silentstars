# ⚔️ GORE

**GORE** (Go-thic Re-make) is a vibe-coded modding and save-editing toolsuite for Gothic 1 Remake. One Rust engine, one CLI, and three Windows apps built on top of it.

[<img src="docs/images/screenshot_dark.png" alt="GORE Save Editor" width="600"/>](https://github.com/dh0er/gore/blob/HEAD/docs/images/screenshot_light.png)

## 🧰 Tools

| <div style="width:150px">Tool</div> | What it does | <div style="width:150px">Status</div> |
|---|---|---|
| **[CLI](https://github.com/dh0er/gore/blob/HEAD/docs/guide/README.md)** | All modding from the terminal: item values, text and dialogs, audio, voice, textures, DataAssets, scripts. Start here. | ⚗️ Experimental use |
| **[Mod Studio](https://github.com/dh0er/gore/blob/HEAD/apps/mod-studio/README.md)** | No-code Windows GUI over the same engine, for *authoring* one mod. | 🚧 Work in progress |
| **[Mod Manager](https://github.com/dh0er/gore/blob/HEAD/apps/mod-manager/README.md)** | Windows GUI for installing and ordering *many* mods together. | ⚗️ Experimental use |
| **[Save Editor](https://github.com/dh0er/gore/blob/HEAD/apps/save-editor/README.md)** | Windows GUI for editing your save files. Never touches the game install. | ✅…
