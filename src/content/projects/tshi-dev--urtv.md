## Install in 3 steps

### ① The TV
Settings ← About ← press OK on **Build** seven times. Then go to **Developer options** ← turn on **USB debugging**.

### ② A computer on the same Wi-Fi, with one of these

| **Codex** (OpenAI) | **Claude Code** (Anthropic) |
|---|---|
| Free with a ChatGPT account | Requires a Claude Pro subscription ($20/month) |
| Download the Codex app | Download the Claude app ← **Code** tab |
| Approvals: choose **«Approve for me»** | Approvals: **Allow** for the whole task |

> **No computer?** You can set up the TV from **the TV itself** (download both apps with the Downloader app and open «TV setup»), or from an **Android phone** (Termux) or **iPhone/iPad** (iSH). Details: [`docs/PHONE-SETUP.md`](https://github.com/tshi-dev/UrTV/blob/HEAD/docs/PHONE-SETUP.md).

### ③ Paste this

> Set up my TV from https://github.com/tshi-dev/UrTV: clone the repository and follow `docs/SETUP-PROMPT.md` step by step. You are on a computer connected to the same Wi-Fi network as the TV.
