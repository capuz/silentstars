# dsh-herta

Packages **Herta (黑塔)** as a plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): her personality, her memory, her voice, and her interface.

> ## 📌 Source Statement
>
> This project is a **third-party adaptation built on the original author's project**, not an original work.
>
> - **Original author's project**: **Herta** —— _THE SELF THAT USES THE AGENT_
> - **Original author's website**: <https://www.herta-ai.com/#research>
> - This project integrates Herta into DeepSeek Harness as a **plugin**. The four layers (personality, memory, voice, and interface) all come from the original Herta work. The plugin-side code (`src/`, `scripts/`, and the Cordis configuration) was newly written for this adaptation.
>
> This project was independently developed by a third party and has **no affiliation, partnership, or endorsement relationship with the original Herta author**.
> If the original author believes this adaptation is inappropriate, please contact me, and I will adjust or remove it immediately.
>
