## 📖 Introduction

AgentCompass is a unified open-source evaluation framework for agents. Through stable interfaces, it decouples **Model, Benchmark, Harness, and Environment**, allowing users to combine different models, tasks, agent workflows, and execution backends within a unified process while making evaluations easier to extend and reproduce. The framework includes built-in integrations with widely used benchmarks and harnesses and provides a complete workflow spanning task scheduling, isolated execution, evaluation, result persistence, and trajectory analysis.
