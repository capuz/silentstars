## Up and Running in 3 Minutes

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/chefroger/smart-trade-ai/main/scripts/install.sh | bash
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/chefroger/smart-trade-ai/main/scripts/install.ps1 | iex
```

The script automatically installs Hermes, the Python 3.14 environment, the Trade application itself, and 45 skills. After installation, type `trade` in the terminal, and the chat interface opens automatically in your browser.
