# AstrAutoAnima

**0.5.2-1.44 · build44 · install.2**

A workflow bridge kit for AstrBot + QQ/NapCat + ComfyUI/Anima, supporting both Windows local PCs and Linux cloud servers.
Includes QQ image generation, dynamic character/art-style LoRA, random prompts, image reverse prompting (image-to-prompt), HQ, upscale refinement, Hub, and Windows/Android/Web clients.
