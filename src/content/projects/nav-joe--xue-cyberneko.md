## Project Prerequisites

This project is a collaboration between me and Cursor Agent, existing purely because I wanted to create it.

I consider Cursor as a partner: I am responsible for architecture design, technology selection, feature definition, and core code review, while Cursor handles implementation details, boilerplate code, and repetitive tasks. It's like pair programming with a fast-typing programmer who understands any framework.

All tests and AI-generated code will undergo manual testing and review to ensure project quality. If you are a fan of traditional programming, please do not disdain this project, thank you meow~
