## What is this

**静观 TV** is an **unofficial cross-platform client** of [LibreSpark/LibreTV](https://github.com/LibreSpark/LibreTV).

The original is a web app that must be self-deployed with Docker. We turned it into two ready-to-use products:

- **Windows portable edition**: a green program directory plus a data directory. Extract and use, no need to install Node.js, Docker, or administrator rights.
- **Android native client**: a single APK with a native feel on both phone touchscreens and TV remotes. Supports older Android 5.0 TVs at minimum.
