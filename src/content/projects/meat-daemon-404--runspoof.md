# RunSpoof · Campus Run Location and Gait Simulation

An **LSPosed module** that provides adjustable location and gait simulation for university "campus running / sunshine morning run" apps (primarily targeting *运动世界校园* `com.zjwh.android_wh_physicalfitness`), along with a complete map point-selection interface.

The project itself is **a record of pitfalls**. Its core value lies not in the amount of code but in the "why it can't be written that way" notes in `docs/`. Each of them was settled only after something actually crashed, was judged invalid, or failed silently.
