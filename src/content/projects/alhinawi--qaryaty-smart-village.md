# 🏡 Qaryati - Smart Village App

> **Village smart services in your pocket**: a sophisticated, fast web app built with the latest technologies, React 19, TypeScript, Vite, and Zustand, to make all the services and shops of village residents easily and quickly accessible.

---

## 📖 Overview

**Qaryati** is a fully responsive, mobile-first web app for village residents. It lets them order daily services (bakery, vegetables and fruits, grilled fish, supermarket, craftsmen, school delivery, home-cooked food) with real-time order tracking, a smart shopping cart, a rewards and points system, and genuine ratings for providers.

### ✨ Key Features

1. **Mobile-First and fully responsive design:**
   - Compatible with screen sizes from the smallest mobile screens (320px, 360px, 390px, 430px) up to large screens (768px, 1024px, 1280px, 1440px+).
2. **State management using Zustand:**
   - `useCartStore`: manages the shopping cart, calculates the total, and provides the interactive shake effect (Wiggle animation).
   - `useOrderStore`: tracks order stages (received, preparing, on the way, delivered) and rates services.
