# 🐷 Xianyu Auto Customer Service Bot (Xianyu Auto Bot)

## 📑 Project Overview

Xianyu automated customer service system, developed based on open-source projects, supports **multi-user multi-account** management, with enterprise-level features such as **intelligent auto-reply**, **automatic shipment confirmation**, **scheduled product relisting**, **AI large model replies**, etc.

> ⚠️ **Important Notice: This project is for learning and research purposes only, commercial use is strictly prohibited!**

## 🎯 Core Features

| Feature Module | Description |
|---------|------|
| 🤖 **Intelligent Reply** | Keyword matching + AI large model replies, supports priority strategy |
| 👥 **Multi-user System** | Independent registration and login, complete data isolation |
| 📱 **Multi-account Management** | Each user can manage multiple Xianyu accounts, independent startup/shutdown |
| 📦 **Automatic Shipment** | Automatically match shipping rules based on product information |
| ✨ **Product Relisting** | One-click batch relisting + daily scheduled automatic relisting |
