## Key features

- **Receive translation**. Local OCR reads English, Russian, Japanese, and Korean chat, and shows Simplified Chinese below each bubble. The panel lets you view and copy the original text and the translation.
- **Send translation**. After you confirm the target language and turn it on, copy Chinese text in the game. The assistant writes a translation that passes language validation to the clipboard, and you paste and send it.
- **Local first**. It checks the glossary, translation memory, and cache first. If there is no match, it can call the translation service you configure. The provider may charge fees.
- **Personal glossary**. New installs start from zero. Qualifying Chinese translations returned by the API are added automatically. Official terms and common abbreviations are separate built-in references and do not count toward the personal glossary.
