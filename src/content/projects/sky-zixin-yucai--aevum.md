# Aevum

Aevum is an open-source runtime for 3D characters and worlds. The current repository focuses on two tracks:

- **Render engine**: WebGL2 character rendering, PMX/MMD, VRM/glTF, Live2D, plus terrain, weather, water, vegetation and LOD.
- **Kernel**: a runnable 32-bit x86 bare-metal kernel, plus a Fortuna kernel skeleton for design verification.

Code is licensed under MPL-2.0. Models, motions and textures keep their own licenses; placing them in the repository does not automatically make them MPL-2.0.
