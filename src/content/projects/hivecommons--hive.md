# Hive

You know the one. Reads every pull request. Never lets red merge. Sends it back with one line, and the line is right. Hive puts that person between your coding agents and main.

If you run CI you know the shape. The job is an AI coding agent. The gate is an AI review plus your own CI.

Everything below comes from 11,571 live pull requests in 10 repositories and 15,054 reviews (oct '26).

## Accuracy

The review agent sent 563 pull requests back. Two out of three came back fixed and approved, usually within 24 minutes.

## Security

We planted 63 texts that try to redirect an agent in issues and files. Hive caught 61 before an agent read a word. One harmless text in 12 got flagged by mistake. Agents run as a GitHub App, not on your token.

## Cost

Agents spent about $6,125 to merge 2,869 pull requests. Call it $2 a merge, our estimate (aug–oct '26).

## And the rest

Every pull request gets the same one-line review, in your style guide's voice. It adds about 15 minutes to a merge.

Humans still merge. Start with "open PRs only". When you trust it, [turn it up](https://github.com/hivecommons/hive/blob/HEAD/src/docs/acmm-policy-matrix.md) and it merges on green, like a merge…
