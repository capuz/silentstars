# Iterglow

**Open-source A/B testing and experimentation platform**

Iterglow is a platform that splits a service's features by user, delivers them, collects actual exposures and behavior, and compares the results. You can define user identifiers, events, and target metrics for each service and connect them through an SDK.

[Service](https://iterglow.pseudolab-devfactory.com) · [Docs](https://github.com/Pseudo-Lab/experiment-platform-pseudolab/blob/HEAD/docs/README.md) · [SDK](https://github.com/Pseudo-Lab/experiment-platform-pseudolab/blob/HEAD/packages/sdk/README.md) · [Contribution Guide](https://github.com/Pseudo-Lab/experiment-platform-pseudolab/blob/HEAD/docs/guides/agent_collaboration.md) · [Issues](https://github.com/Pseudo-Lab/experiment-platform-pseudolab/issues)

## Key Features

- Per-project experiments and Feature Flags, and member permission management
- Per-user variant decisions and gradual feature rollout
- Separation of decision, actual exposure, and behavior through the SDK's `decide → expose → track` flow
- Exposure and conversion aggregation, SRM and guardrail alerts, and data quality warnings
- Status history, conversion windows, late-arrival grace periods,…
