# HelixSR Decky

**Latest:** Decky **0.1.38** adds **HLX FSR 4 (AMD FSR 4.1.2 Lite)** through the reviewed HelixSR 3.2.0 prerelease. Install [HelixSR-Decky-0.1.38.zip](https://github.com/dawoodtogoo2020-code/HelixSR-Decky/releases/download/v0.1.38/HelixSR-Decky-0.1.38.zip) from the [v0.1.38 release](https://github.com/dawoodtogoo2020-code/HelixSR-Decky/releases/tag/v0.1.38). Select the HLX model explicitly; Model E / HelixSR 2.0.0 remains the default. SteamOS gameplay, image quality, performance and frame generation with HLX remain unverified. See [installation, testing and rollback](https://github.com/dawoodtogoo2020-code/HelixSR-Decky/blob/HEAD/docs/hlx-fsr.md). Desktop 0.1.21 changes are included in source; no 0.1.21 AppImage is published.

Decky **0.1.36** reuses the library list when opening dropdowns, selects **HelixSR 2.0.0** by default and offers a verified repair for missing managed files. **Refresh library and status** still rescans the library. Older releases are labeled explicitly, and package review is explained separately from game installation warnings.
