# GitHub Desktop Localization Pack · Chinese Language Pack (Simplified Chinese)

**GitHub Desktop Simplified Chinese Localization Pack (Chinese Language Pack)** provides a Chinese interface for Windows users, a local one-click generation tool, and scheduled updates via GitHub Actions. The current repository provides ready-made translation packs for **GitHub Desktop 3.7.0 Windows x64**. Generation and installation can be run separately.

It covers common interfaces such as menus, repository and branch operations, commits and diffs, settings, Copilot, and worktrees. It supports backing up the original version and restoring the English version, and shows a clickable translator homepage link under Help → About.
