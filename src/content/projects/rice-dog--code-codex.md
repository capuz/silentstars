# Code-Codex

Simplified Chinese | [English](https://github.com/Rice-dog/code-codex/blob/HEAD/README.en.md)

</p>

<em>Add local project file tree, preview tabs, and limited editing capabilities to Codex Desktop.</em>
</p>

</p>

Code-Codex is an unofficial community project that adds a local project file tree to Codex Desktop. It demonstrates a Windows local auxiliary program, a sandboxed workspace bridge, and an injected TypeScript explorer UI for file preview, editing, navigation, and file operations.

> [!IMPORTANT]
> Code-Codex is unrelated to OpenAI

## Installation Method 1: Direct EXE Download

You can download pre-built installation packages from [`releases`](https://github.com/Rice-dog/code-codex/blob/HEAD/releases/):

Requirements: Windows 10 version 2004 (build 19041) or later, x64, with the official stable version of Codex/ChatGPT Desktop installed.

- Recommended: `CodeCodex-0.2.30-x64-setup.exe`
- Alternative: `CodeCodex-0.2.30-x64.msi`
- Portable package: `CodeCodex-0.2.30-x64.zip`
- Standalone uninstaller: `Uninstall-CodeCodex.exe`
