## Project Introduction

QQNT-Patcher is an automated static bytecode patching and runtime extension tool for Android QQNT architecture. By directly performing pure in-memory streaming AST local reconstruction on target Dex files from the official package, coordinating in-situ patching of underlying Native signature verification instructions, appending independent extension Dex, and with a built-in modern dynamic Java script engine, it achieves framework-free, Root-free ultimate feature enhancement.
