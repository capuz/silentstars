# Story Maker v5.5.4 / AI物語メーカー

OpenAI story drafting and editing now offers **GPT-6.2 Sol** and **GPT-6.2 Astra**. The initial selection is **GPT-6 Luna**.

Standard input / output per million tokens: GPT-6 Luna $0.10 / $0.50, GPT-6.2 Sol $2 / $10, GPT-6.2 Astra $8 / $40 (November 18, 2026).

**Stop AI communication:** Use the upper-right “緊急停止” button while waiting for thought or receiving a response. It aborts browser requests and blocks automatic continuation, retries and fallback; late responses are discarded. Standard generation restores the previous Output, and brushup keeps its source draft. Settings and the in-memory API key remain available for another run. This does not guarantee cancellation of processing or charges at the API provider.
