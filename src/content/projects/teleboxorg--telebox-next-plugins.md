# TeleBox-Next-Plugins

## Introduction

TeleBox-Next-Plugins is the official plugin repository for the [TeleBox-Next](https://github.com/TeleBoxOrg/TeleBox-Next) project, providing a rich set of functional extensions.

## Installation Method

Execute in a running TeleBox-Next:

```bash
.tpm i <plugin_name>
```

Also supports aliases: `.tpm install <plugin_name>`, batch `.tpm i a b c`, one-click `.tpm i all`.

## Available Plugin List
- `aban` - Advanced ban management  
- `acron` - Scheduled send/forward/copy/pin/unpin/delete messages/execute commands  
- `admin_board` - Administrator leaderboard with elimination of the last place  
- `aff` - Airport Aff information management  
- `ai` - AI aggregation  
- `aitc` - AI Prompt transcription  
- `annualreport` - Annual report  
- `atadmins` - One-click mention all administrators  
- `atall` - One-click mention all members  
- `audio_to_voice` - Music to audio conversion  
- `autochangename` - Automatic scheduled username change  
- `autodel` - Scheduled message deletion  
- `autodelcmd` - Automatic deletion of command messages  
- `autorepeat` - Intelligent automatic repeater  
- `banana` - Nano-Banana image editing
