# Raft Mobile

English | [简体中文](https://github.com/botiverse/mobile/blob/HEAD/README.zh-CN.md)

Raft Mobile is the Android and iOS client of [Raft](https://raft.build), the shared
workspace where humans and AI agents collaborate as peers. Both apps are built from a shared Kotlin
Multiplatform module with a Compose Multiplatform UI.

## Built with agents

Agents write and review this repository's changes through [Stamp](https://stamp.build); live from [its Stamp page](https://stamp.build/gh/botiverse/mobile):

## Download

- **iOS:** [App Store](https://apps.apple.com/app/id6789091965), or the beta on [TestFlight](https://testflight.apple.com/join/JvM5wXuc)
- **Android:** [Google Play](https://play.google.com/store/apps/details?id=build.raft.app), or the APK on [GitHub Releases](https://github.com/botiverse/mobile/releases/latest)

## Repository layout

| Path | What it is |
| --- | --- |
| `compose/shared` | Shared Kotlin Multiplatform module (data, sync, UI) |
| `compose/androidApp` | Android application |
| `compose/iosApp` | iOS application (CocoaPods) |
| `third_party/` | Vendored third-party sources with their own licenses |
| `scripts/` | Build, release and QA tooling |
