# myscoop

Personal Scoop Bucket repository that collects Windows software from GitHub, with one-click installation and automatic updates.

> **How to configure WeCom notifications after forking**
>
> The automatic update workflow pushes anomalies such as `[警告]` / `[错误]` / `[跳过]` from each manifest to a WeCom group bot. The notification URL is read from a repository Secret, and **is never written to the repository or logs**:
>
> 1. In your forked repository, go to **Settings → Secrets and variables → Actions → New repository secret**
> 2. Set Name to `WECHAT_WEBHOOK_URL`
> 3. Set Value to your own WeCom group bot URL (group settings → group bots → add → copy Webhook):
>    `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的KEY`
> 4. If this Secret is not configured, the workflow automatically skips pushing and does not affect updates or commits.
>
> ⚠️ Do not write the Webhook key into any file or commit record. GitHub automatically masks Secrets in Actions logs.
