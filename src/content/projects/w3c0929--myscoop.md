# myscoop

Personal Scoop Bucket repository, collecting Windows software from GitHub, supporting one-click installation and automatic updates.

> **How to configure WeChat Work notifications after forking**
>
> The automatic update workflow pushes exceptions such as `[警告]` / `[错误]` / `[跳过]` from each manifest to a WeChat Work bot. The notification URL is read via a repository Secret, **and is never written into the repository or logs**:
>
> 1. In your forked repository, go to **Settings → Secrets and variables → Actions → New repository secret**
> 2. Set Name to `WECHAT_WEBHOOK_URL`
> 3. Set Value to your own WeChat Work group bot URL (Group settings → Group bots → Add → Copy Webhook):
>    `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的KEY`
> 4. If this Secret is not configured, the workflow automatically skips pushing notifications and does not affect updates or commits.
>
> ⚠️ Do not write the Webhook key into any file or commit record; GitHub automatically masks Secrets in Actions logs.
