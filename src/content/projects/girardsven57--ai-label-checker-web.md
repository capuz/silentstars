## Overview

AI Label Checker is a browser-accessible web utility for checking AI labels. It is implemented in HTML, allowing label-checking tasks to be handled from a modern browser without installing a standalone desktop program.

The small web-based format is useful for fast review tasks, local project workflows, and deployment through static hosting. Open the hosted build for immediate access, or work with a local copy of the project files.
