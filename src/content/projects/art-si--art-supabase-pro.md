## Project Positioning

亿企工场 is not a UI template that merely displays tables, forms, and charts. It is built on **Supabase Auth, PostgreSQL, RLS, Storage, Realtime, RPC and Edge Functions** as its backend foundation, and uses a model where the main platform provides a unified shared runtime while business sub-repositories evolve independently, delivering enterprise business capabilities that can be deployed and further customized.

The project currently covers:

- Enterprise base platform: login authentication, multi-tenancy, RBAC, dynamic menus, button permissions, data dictionaries, attachments, system parameters, and auditing.
- TMS end-to-end transportation: customers, carriers, drivers, cargo, contracts, sites, billing, orders, waybills, load planning, dispatch/delivery, in-transit monitoring, and financial settlement.
- Full vehicle lifecycle: vehicle records, intake review, insurance, annual inspections, maintenance, accidents, mileage, routine…
