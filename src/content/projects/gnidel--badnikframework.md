# Welcome to Badnik Framework!

This framework is designed to games inspired by 3D Sonic/Spark the Electric
Jester games in Godot 4 C#. It's mostly designed for fan games, but you can use it for any
other product, including commercial games. It's design to include everything
you need to make a game - just add more levels or expand it.

Please keep all directories free from proprietary copyrighted elements. The
only exception is SonicAssets directory which contains Sonic assets.

Our Discord community: https://discord.gg/KjDZksze7F

Youtube channel: https://www.youtube.com/@Gnidel_gamedev_channel

# Features
- 3D physics-based Sonic gameplay
- Supports boost, Adventure gameplay styles
- 3 playable characters: Sonic, Tails and Shadow
- A lot of gimmicks and actions, like grinding and skydiving
- Lost World/Mario Galaxy gravity
- Open zone/hub features: maps with optional fast travel, collectables, stage gates requiring specific items
- Extensive camera controls and camera triggers
- 2.5D and automated paths. Make a classic game if you want!
- Local split-screen multiplayer
- NPC partner characters
- Switching characters like in Sonic Heroes
- Special Stages and super forms
