# HWP Toolkit

Headless WordPress Toolkit

> A modern toolkit for building headless WordPress applications. Provides CLI tools, plugins, and best practices for decoupling WordPress into a powerful headless CMS.

## Project Organization

- [`plugins`](https://github.com/wpengine/hwptoolkit/blob/HEAD/plugins): PHP based WordPress Plugins
- [`packages`](https://github.com/wpengine/hwptoolkit/blob/HEAD/packages): Dependency packages to be published on NPM
- [`docs`](https://github.com/wpengine/hwptoolkit/blob/HEAD/docs): Documentation for the Toolkit
- [`examples`](https://github.com/wpengine/hwptoolkit/blob/HEAD/examples): Example code for HWP
