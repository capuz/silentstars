# Autolume

Autolume is a cross-platform tool for real-time visual performances using StyleGAN.

For detailed documentation and demos look at the [Metacreation Lab Website](https://www.metacreation.net/autolume).

## Installation

[➡️ Download for Windows, macOS and Linux](https://github.com/Metacreation-Lab/autolume/releases/latest)

### Brew (macOS)

Add and trust the brew tap (one time)

```
brew tap metacreation-lab/tap
brew trust metacreation-lab/tap
```

Install the app

```
brew install --cask autolume
```

Update the app

```
brew upgrade --cask autolume
```
