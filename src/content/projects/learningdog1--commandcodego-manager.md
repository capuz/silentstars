# CommandCodeGo-manager

Command Code subscription reverse proxy: Convert [Command Code](https://commandcode.ai) subscription quota (including $1/month Go tier) to **OpenAI compatible** (`/v1/chat/completions`, `/v1/responses`) and **Anthropic compatible** (`/v1/messages`) endpoints, available for any harness (Claude Code / OpenCode / ZCode / cURL / any OpenAI·Anthropic SDK); includes a beautiful Chinese Web management interface (dashboard, real-time logs, usage statistics, account usage, model pricing, key management, device fingerprints, settings).
**Provides macOS / Windows desktop versions** (native applications usable by double-click, with background service + system tray).

Protocol layer derived from [MAXeaglet/commandcode-proxy](https://github.com/MAXeaglet/commandcode-proxy) (MIT, baseline `9bdfafc`), wire behavior aligned item-by-item with it, maintaining its complete test suite passing. See [NOTICE](https://github.com/learningdog1/CommandCodeGo-manager/blob/HEAD/NOTICE) for details.
