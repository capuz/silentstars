# LokalBot

**Your personal context engine.**

A free, open-source, local-first alternative to Granola, Wispr Flow, and Rewind.<br />
Claude Code, Codex, and any MCP client can search it too.

Notes from every call with no bot. One search for everything you saw and heard.<br />
Autocomplete and dictation in any app. Local by default.

**Install on a Mac** (Apple Silicon, macOS 15+):

```bash
brew install --cask stevyhacker/tap/lokalbot
```

**Free and open source (GPLv3) · No account · No analytics or telemetry · Notarized Mac app · Built-in AI works offline once the models are downloaded**
