# akfamily.xyz

Source code of the [AKFamily](https://github.com/akfamily) homepage <https://akfamily.xyz>, published directly by GitHub Pages from the root of the `main` branch.

A pure static site with no build step:

- `index.html`: homepage
- `404.html`: 404 page
- `assets/style.css`: styles
- `assets/img/`: QR codes and screenshots
- `CNAME`: custom domain

Local preview:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.
