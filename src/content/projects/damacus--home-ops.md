# home-ops

Homelab Kubernetes using Flux.

## 📖 Project Documentation

- **[AGENTS.md](https://github.com/damacus/home-ops/blob/HEAD/AGENTS.md)**: Comprehensive project specification and AI agent instructions.
- **[GEMINI.md](https://github.com/damacus/home-ops/blob/HEAD/GEMINI.md)**: Maintenance guide and common automation tasks.
- **[.tasks/](https://github.com/damacus/home-ops/blob/HEAD/.tasks/)**: Segregated task lists for tracking development progress.

## 🚀 Getting Started

1. Install the pinned command-line tools:
   ```bash
   mise install
   ```
2. Review the task lists in `.tasks/` to see current progress and pending items.
3. List the repository automation:
   ```bash
   task --list
   ```
