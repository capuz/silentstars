# Vehicle Dynamics Performance Analysis

This tool is a data processing helper and can help with all sorts of annoying and time consuming tasks you commonly encounter when working with vehicle dynamics data. 
Whether it is asynchronous sampling or different sampling frequencies, a changed channel name which torpedoes your layouts, a format which can not be processed directly, only having raw sensor data which offer limited insights, wanting to overlay data from two different cars with different formats or reference frames, or the creation of lap based overlays from continuous data. There are just tons of time consuming tasks before vehicle dynamic data can offer valuable insights. Yes there are commercial tools out there who do some of the things and more, but they are paid and I found them inflexible. This Repository is build from practice and is designed to be modular and extendable, so feel free to tailor it to your needs. If you develop valuable features along the way, I would be happy if you contribute so others can profit as well.
