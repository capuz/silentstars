# Mirai-chan

## Introduction

A simple Bot, using [melobot](https://github.com/Meloland/melobot) as a framework

> melobot is a small, cute, and powerful robot development framework, go give *her* a star!

> The name comes from the original implementation endpoint [mirai](https://github.com/mamoe/mirai) ~~, due to not being able to name it~~,
> to be precise, it is [Ariadne](https://github.com/GraiaProject/Ariadne) and its series of ecological libraries. But that's all in the past uwu

Written/tested/running under Python 3.12, other versions have not been tested yet.
