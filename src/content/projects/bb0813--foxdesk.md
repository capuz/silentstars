# FoxDesk

A local Camoufox fingerprint browser manager — free, open source, privacy-first.

**Current version: `1.6.0` (Stable)**

## Features

- **Dual engine** — choose per profile between Camoufox (Firefox) or Chromium (Playwright/Patchright; auto prefers Patchright)
- **Profile management** — create, edit, clone, import/export, tag grouping
- **Fingerprint control** — parameter editing + random generation + running probe reports + static consistency scoring
- **Session control** — start/stop/logs, **live navigation**, concurrency limit, auto-stop on idle
- **Server mode** — capture `ws_endpoint` where possible, for external Playwright connections
- **Proxy pool** — health checks; sticky/round-robin/random health-based allocation; passwords encrypted with DPAPI
- **Cookie management** — export as SQLite cookies; import JSON / Netscape, injected on next launch
- **Scenario templates** — clean / e-commerce / automation / social media / research / mobile window, etc.
- **Proxy environment matching** — exit IP ownership detection (residential/datacenter), one-click matching of timezone/language, batch application of environment settings
- **Local backup** — password-encrypted…
