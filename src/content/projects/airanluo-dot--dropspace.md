# DropSpace

DropSpace is a local-first Windows 10 and 11 workspace for temporarily holding file references and recent clipboard content. Its main window provides full management, while a top-center Dynamic Island provides a fast file drop surface over the same Temporary Space.

Official website: https://airanluo-dot.github.io/DropSpace/

## Status

DropSpace **1.2** adds a shared music spectrum, optional Island colors from album artwork, and synchronized interlude and next-line lyrics in the independent music window.

The current release target is `v1.2.0`. The [1.2 release notes](https://github.com/airanluo-dot/DropSpace/blob/HEAD/.github/release-notes/v1.2.0.md) describe changes since [v1.1.0](https://github.com/airanluo-dot/DropSpace/releases/tag/v1.1.0).
