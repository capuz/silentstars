AutoLinker is an AI Agent support library for 易语言 (E language). Through reverse engineering, it lets AI fully automatically write code: it finds and reads the relevant code based on your requirements, then directly edits, modifies, and inserts code.

It also provides a local MCP service that connects the 易语言 IDE to tools such as Codex, Claude Code, and Gemini CLI, allowing them to call it for fully automated E language coding (see the MCP section below).
