## Project Overview

This project collects and compiles multicast and unicast source information for Zhejiang Telecom IPTV from the internet, along with lists in `.m3u`, `.txt`, and `.csv` formats and channel logos.

> ⚠️ Special notice: All content in this project is collected and compiled from the internet. It is intended only for compiling lists of programs launched on Telecom IPTV. The accuracy of all content is not guaranteed and is provided for reference only. The unicast and multicast addresses provided are for format reference only. To actually watch, you must purchase China Telecom IPTV service and play it using the included set-top box.
