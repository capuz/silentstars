# SingBox Proxy Forwarding Management System - Self-use for learning related technologies

A proxy node management and forwarding system based on sing-box, providing a simple and easy-to-use Web interface.

## 📋 Features

### Core Features
- 🚀 **Single-process architecture** - Manages all nodes with a single sing-box process, low resource usage
- 🔐 **Authentication protection** - Supports setting independent usernames and passwords for each proxy node
- 🌐 **Multi-protocol support** - Supports Direct, VLESS, VMess, Trojan, Hysteria2, TUIC, Shadowsocks, AnyTLS, WireGuard, plus SOCKS5/SOCKS5H/HTTP upstream proxies
- 🔄 **Dual-mode proxy** - A single port supports both HTTP and SOCKS5 protocols
- 📊 **IP detection** - Real-time detection of node IP, geolocation, and latency
- ⬆️ **Version update notice** - Shows an up arrow next to the panel version number when a new GitHub Release is available
