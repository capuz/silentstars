# OpenInterviewer

OpenInterviewer is an open-source platform for adaptive, AI-assisted qualitative interviews. Researchers configure a study, share an opaque participant link, and review transcripts and synthesis in a dashboard.

See the [v4.1.1 release notes](https://github.com/linxule/openinterviewer/blob/HEAD/docs/releases/v4.1.1.md) for self-hosted fonts and dependency updates, the
[v4.1.0 notes](https://github.com/linxule/openinterviewer/blob/HEAD/docs/releases/v4.1.0.md) for participant-session and link-privacy fixes and
admin-password rotation, and the [v4.0.0 notes](https://github.com/linxule/openinterviewer/blob/HEAD/docs/releases/v4.0.0.md) for the Cloudflare standalone
target, the Cloudflare AI Gateway transport, and provider fixes that also affect v3.0.0.
The [v3.0.0 notes](https://github.com/linxule/openinterviewer/blob/HEAD/docs/releases/v3.0.0.md) cover save-first completion and deferred analysis.

Contributing or working with a coding agent? Start with [`CONTRIBUTING.md`](https://github.com/linxule/openinterviewer/blob/HEAD/CONTRIBUTING.md) and the repository map in [`AGENTS.md`](https://github.com/linxule/openinterviewer/blob/HEAD/AGENTS.md).
