# PopDrop

Press `F2` to bring up a file panel at the front of the screen. Find the file, drag it away, and close it. The whole process takes less than three seconds.

PopDrop is a Windows utility that consolidates your frequently used folders, recently opened files, and pinned files into one panel for easy access, which you can close after use. The window behavior of the panel can be configured through `WindowMode`.

## Why Use It?

The Windows desktop and file manager are great, but when you frequently switch between several folders—grabbing reference images, dragging materials into Photoshop, finding documents to attach to emails—switching windows back and forth can be annoying.

PopDrop simplifies all of this into one step: **Press shortcut key → Panel appears → Find file → Drag away or use right-click menu → Press shortcut key again to make the panel disappear**.

## What It Can Do

- **One-key call**: Default `F2`. Press it in any software, and the panel opens at the front.
- **Grouped by folder**: Set up your frequently used directories, and the panel automatically displays the latest files by group, so you can see what's available at a glance.
