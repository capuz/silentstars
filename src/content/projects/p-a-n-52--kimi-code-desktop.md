<h1 align="center">Kimi Code Desktop</h1>

  源码自有的 Kimi Code Windows 与 macOS 桌面工作台。<br />
  A source-owned Kimi Code workspace for Windows &amp; macOS.
</p>

</p>

文档入口见 [文档导航](https://github.com/P-A-N-52/kimi-code-desktop/blob/HEAD/docs/README.md)，开发与提交约定见 [结构与开发规范](https://github.com/P-A-N-52/kimi-code-desktop/blob/HEAD/.github/DEVELOPMENT.md)。Source Runtime 的完成态见 [Runtime Cutover M4](https://github.com/P-A-N-52/kimi-code-desktop/blob/HEAD/docs/plans/2026-08-08-runtime-cutover-m4.md)，长期维护见 [Source Backend 维护策略](https://github.com/P-A-N-52/kimi-code-desktop/blob/HEAD/docs/plans/2026-08-07-source-backend-maintenance.md)。

Kimi Code Desktop 将 Kimi Code 的智能体能力带进一个专注、可视、可管理的桌面界面。Kimi Code 源码以 git subtree 形式收在 `runtime/kimi-code`，构建为随应用交付的唯一 Runtime：不依赖用户安装的 CLI，也不使用 ACP 或生产双 backend。
