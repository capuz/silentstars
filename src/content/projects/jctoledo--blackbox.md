# Blackbox

**Understand your drive. Own the instrument.**

Blackbox is an open-source ESP32-C3 telemetry project: GPS and inertial sensing, circuit and stage timing, optional force analysis, and a phone-friendly dashboard served directly over local Wi-Fi. Rust firmware, inspectable maths, and browser-local recordings—no cloud account required.

[Project website & USB installer](https://jctoledo.github.io/blackbox/) · [Lap timer guide](https://github.com/jctoledo/blackbox/blob/HEAD/docs/LAP_TIMER.md) · [Sensor fusion](https://github.com/jctoledo/blackbox/blob/HEAD/docs/SENSOR_FUSION.md) · [Hardware checklist](https://github.com/jctoledo/blackbox/blob/HEAD/docs/HARDWARE_VALIDATION.md) · [Try the demo](https://jctoledo.github.io/blackbox/demo.html)

Main CI validates host/browser regressions, documentation, both GPS firmware variants and artifacts on lat. Reviewed pull requests use the separate `lat/reviewed-ci` commit status; [maintainer dispatch procedure](https://github.com/jctoledo/blackbox/blob/HEAD/CONTRIBUTING.md#reviewed-pr-validation).
