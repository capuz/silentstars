# AlphaAgents

### An AI trader that changes its next decision because it lost money

**Trade · Learn · Evolve**

A-share short-term · virtual trading · no broker interface

---

Most AI trading systems end the moment they issue **Buy / Sell**.

AlphaAgents is different.

It will:

**Scan market → Write thesis → Trade → Judge where it went wrong → Form memory → Change next decision**

The goal is not to make a smarter stock picker.

> **Rather, it is to cultivate an AI trader that continuously evolves from real trading.**

And the sequence is not optional:

> **Credible trading facts → Attributable learning → Verifiable evolution.**
>
> A system that learns from results it cannot calculate clearly is learning its own bugs.
> More reports, more agents, cannot substitute for this sequence.

---

## How it works

The core loop has only six steps:

**Market scan → Write thesis → Place order / Trade → Code monitoring → Post-trade review learning → Pass gate to evolve**

Every trade leaves experience; but experience must pass the gate to become the basis for the next decision.
