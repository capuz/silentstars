# 3080 Brief

**30-second judgment, 80% in one picture**

[Chinese (Simplified)](https://github.com/BobbyYue/3080-brief/blob/HEAD/README.zh-CN.md) · [Quick start](#quick-start) · [Worked example](https://github.com/BobbyYue/3080-brief/blob/HEAD/docs/examples/claude-code-session-value.md) · [Latest release](https://github.com/BobbyYue/3080-brief/releases/latest)

An open-source **AI Agent Skill** that turns source documents into reader-first decision briefs: a 30-second executive summary, one auditable visual, a key-question table, and a clear storyline. It preserves the source and can create a new brief in Feishu/Lark, Markdown, Word/docx, or self-contained HTML when the host supports that format.

> **Real output example:** [Anthropic's five-minute article](https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions) explains token pricing, prompt caching, context growth, session length, and subagents across multiple sections.
