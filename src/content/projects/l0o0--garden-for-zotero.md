# Garden for Zotero - Release Version

Release repository for the Zotero plugin built for Chinese users.

## 📦 Installation

1. Download the latest `garden_{version}.xpi` file
2. Open Zotero and go to Tools → Add-ons
3. Click the gear icon in the upper right and select "Install Add-on From File..."
4. Select the downloaded `garden_{version}.xpi` file to install

## ✨ Key Features

- 🔐 User authentication system
- 🎁 Free large models, ready to use out of the box, usable as a free translation service
- 🤖 Integration with top global large model APIs, supporting multiple Zotero plugin ecosystems
- 📊 Token usage statistics
- 🛠️ Automatic configuration injection support
- 🎓 Quick access to Zotero Chinese community resources

**Free models**
Supports Translate for Zotero (as a free translation engine), Awesome GPT, and LLM for Zotero

**Recommended models: quickly connect to top global large models in Zotero**
You can now use Garden's recommended model list to configure leading domestic and international models in Zotero plugins with one click, without complicated manual setup.
