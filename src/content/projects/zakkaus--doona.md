# doona

**Static web interface for the [daeuniverse](https://github.com/daeuniverse) engines: manage nodes, groups, rules, and configuration in the browser.**

**[Live demo](https://demo.daeuniverse.org/)** / **[Lite demo (preview)](https://demo.daeuniverse.org/lite/)** / **[Documentation](https://daeuniverse.org/zh-TW/doona/)**

Traditional Chinese / [Simplified Chinese](https://github.com/Zakkaus/doona/blob/HEAD/README.zh-CN.md) / [English](https://github.com/Zakkaus/doona/blob/HEAD/README.en.md)

[Features](#功能) / [Two editions](#兩個版本) / [Try the demo](#體驗示範版) / [Installation](#安裝) / [Backend protocol](#後端協定) / [Documentation](#文件)

doona is a static web interface for monitoring proxy traffic and managing nodes, groups, rules, and configuration. It requires a running [honk](https://github.com/daeuniverse/honk) or [dae](https://github.com/daeuniverse/dae) backend (v2.1.2 or later) with the native API enabled. For how to configure dae, see the [native API documentation](https://github.com/daeuniverse/dae/blob/main/docs/zh/configuration/api.md).
