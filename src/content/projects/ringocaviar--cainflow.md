# CainFlow

**CainFlow** is a lightweight node-based AI orchestration tool inspired by ComfyUI. Release builds use pywebview to provide a standalone desktop window, together with a built-in Python service that provides workflows, settings, media recovery, updates, and downloads.

## Download

- Release downloads: <https://github.com/RingoCaviar/CainFlow/releases/latest>
- Regular users are recommended to download the release ZIP directly, unzip it, and launch.
- Developers are recommended to clone the source code and run it locally, for easier debugging of frontend and backend logic.

## Features

- Node-based workflow orchestration, suitable for chaining image, text, video, and other processing flows
- Native frontend implementation, lightweight startup, easy to extend by module
- Workflows and history are saved locally by default, without relying on cloud hosting
- Built-in workflow management, media recovery, download, update, and logging
- Provides a Windows release and supports building macOS release packages
