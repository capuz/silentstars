# dsh-studio

A "requirements & task workspace" for internal company use: a resident DSH plugin that packs **kanban board + role agents + internal marketplace** into the same page of DSH Web.
Source code is managed on a self-hosted GitLab and communication runs through Feishu. Agents handle the concrete work of four roles: product / architecture / development / testing.

Runtime environment: DSH `0.2.2-rc.1`, Node 22 or above, Linux/macOS (native Windows is not supported for `link:` installation + systemd hosting).

Maintenance: Supply Chain Digitalization team. For questions, open an issue in this repository or contact the "product" role on the board directly. For the release process, see [docs/publish.md](https://github.com/marsken88/dsh-studio/blob/HEAD/docs/publish.md).

## Feature map

Organized in the order of "a requirement from birth to end-of-life". For details, see the topic docs; the implementation log is in [docs/history.md](https://github.com/marsken88/dsh-studio/blob/HEAD/docs/history.md).
