# dsh-cliworker-now

**Simplified Chinese** | [English](https://github.com/SuperWheel/dsh-cliworker-now/blob/HEAD/README.en.md)

**In DeepSeek Harness, give different CLIs a shared collaboration space.**

Choose a CLI, model, and role, then dispatch named agents. View their progress in the sidebar, receive results, and continue the same task.

[Installation](#安装与更新) · [Getting Started](#使用方法) · [FAQ](#常见问题) · [Report an Issue](https://github.com/SuperWheel/dsh-cliworker-now/issues)

## What is this

dsh-cliworker-now is a **multi-CLI agent plugin** for DeepSeek Harness. It connects AI CLIs running in the terminal to Harness. The main conversation handles dispatching and receiving results, and the right sidebar uses Harness's native full conversation view to show each agent's progress, usage, and status.

You still use each CLI's own accounts, models, and native sessions. The plugin organizes them. The plugin does not include model services, subscriptions, or API quota.

- **Development collaboration**: Have Codex review code, then follow up under the same name.
- **Writing and editing**: Configure different roles for logic, style, business review, and body revision.
