# River Review

**Turn reviews into organizational judgment assets.**
**Review Judgment as Code for AI-assisted development.**
**Review Judgment as Code for AI-assisted development. Codify review judgment as repo-owned skills.**

This is the Japanese version of the README. [English README is available here.](https://github.com/s977043/river-review/blob/HEAD/README.en.md)

River Review is an OSS framework that treats review standards as **versioned / repo-owned skills**. It can run across SDLC artifacts such as plan / diff / tests / JUnit / existing review results. It currently provides the **Review Judgment Platform**, a team-owned audit layer for operating your team's review judgment. For an overview of the concept, see [Concept](https://river-review.the3396.com/explanation/concept/).

AI-assisted development (Claude Code / Codex / Cursor, etc.) has made writing code much faster. However, **review judgment remains the team's responsibility**, and it must stay explicit, reproducible, and owned by the team.

River Review is a framework for answering questions like these:

- Does this diff match the approved implementation plan?
- Do the tests meet the boundary conditions promised…
