# AgentKit 代码工坊

Welcome to the AgentKit Code Workshop (Samples) repository!

AgentKit is an enterprise-grade AI Agent development platform launched by Volcano Engine, providing developers with a complete solution for building, deploying, and operating AI agents. Through standardized development toolchains and cloud-native infrastructure, the platform significantly lowers the barrier to developing and deploying complex agent applications.

This repository contains a collection of examples and tutorials to help you understand, implement, and integrate AgentKit's features into your applications.

## ➤ Project Structure

The AgentKit Code Workshop provides examples and tutorials at different levels to help you get started with the AgentKit platform quickly:

- **Basic tutorials**: Simple Agent examples that help you quickly understand AgentKit's core concepts and basic usage
- **Use cases**: More complex Agent implementations and customization examples for developers with some experience
