# Memory System

**Local-first long-term memory that keeps every conversation connected.**

JSONL on disk · local vector retrieval · seven model tools · auto recall · hard rules · scope-based archiving · active suppression · visual management panel

[npm package](https://www.npmjs.com/package/@restregular/dsh-memory) · [Issue tracker](https://github.com/RestRegular/dsh-memory/issues) · [Changelog](https://github.com/RestRegular/dsh-memory/blob/main/CHANGELOG.md)

> **It doesn't just store a piece of text. It makes the model remember when it should, and use what it remembers when it's needed.**
> Memories stay on the local machine by default. It works without a vector service: retrieval automatically falls back to lexical matching and makes no network requests.
