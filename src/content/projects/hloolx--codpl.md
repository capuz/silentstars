# CODPL

CODPL is a static evaluation site for multi-vendor Coding Plan / Code API services. It is used for Coding Plan evaluation, Coding Plan speed testing, Code API benchmarking, multi-vendor model comparison, and long-term trend tracking. The project continuously displays TTFT, MedianTPS, composite experience scores, and historical snapshots for different platforms and models, so developers can review real probe results before integration, procurement, and selection.

If you are searching for any of the following, this project is for you:

- Coding Plan evaluation
- Coding Plan benchmark
- Coding Plan speed test
- Coding Plan vendor comparison
- Coding Plan purchase reference
- Code API response speed comparison
- TTFT / MedianTPS / composite experience ranking

## Online Addresses

- Main site: <https://codpl.15o.cc>
- Overseas node: <https://bench.codpl.com/>
- Vendor onboarding status, purchase links, and official documentation entry points: <https://bench.codpl.com/providers>

The overseas node is served by Cloudflare and is suitable for access from outside China.
