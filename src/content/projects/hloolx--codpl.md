# CODPL

CODPL is a static evaluation site for multiple Coding Plan / Code API vendors, used for Coding Plan evaluation, Coding Plan speed testing, Code API Benchmark, multi-vendor model comparison, and long-term trend tracking. The project continuously displays the TTFT, MedianTPS, overall experience scores, and historical snapshots of different platforms and models, helping developers to view real testing results before integration, procurement, and selection.

If you are searching for these contents, this project is prepared for them:

- Coding Plan evaluation
- Coding Plan benchmark
- Coding Plan speed testing
- Coding Plan vendor comparison
- Coding Plan purchase reference
- Code API response speed comparison
- TTFT / MedianTPS / overall experience ranking

## Online Address

- Main site: <https://codpl.15o.cc>
- Overseas node: <https://bench.codpl.com/>
- Vendor access status, purchase links, official documentation entry: <https://bench.codpl.com/providers>

The overseas node is provided by Cloudflare, suitable for overseas network access.
