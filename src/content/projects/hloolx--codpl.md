# CODPL

CODPL is a static evaluation site for multi-vendor Coding Plan / Code API, used for Coding Plan evaluation, Coding Plan speed testing, Code API Benchmark, cross-vendor model comparison, and long-term trend tracking. The project continuously displays TTFT, MedianTPS, comprehensive experience scores, and historical snapshots of different platforms and models, helping developers see real benchmark results before access, procurement, and model selection.

If you are searching for these contents, this project is prepared for them:

- Coding Plan evaluation
- Coding Plan benchmark
- Coding Plan speed testing
- Coding Plan vendor comparison
- Coding Plan purchase reference
- Code API response speed comparison
- TTFT / MedianTPS / comprehensive experience ranking

## Online Addresses

- Main site: <https://codpl.15o.cc>
- Overseas node: <https://bench.codpl.com/>
- Vendor access status, purchase links, official documentation entry: <https://bench.codpl.com/providers>

The overseas node is provided by Cloudflare and is suitable for overseas network access.
