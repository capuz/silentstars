> GitHub Planet is an open-source interactive project that is not affiliated with GitHub.

## What is GitHub Planet?

GitHub Planet represents a developer's GitHub activity as a 3D planet floating in space. It aggregates the language composition of owned public repositories, contributions, Stars, contributions to external repositories, and so on, and reflects the results in the planet's color, surface, size, rotation, surrounding stars, and achievements. Pinned representative works on GitHub are separated from the planet-wide language aggregation, and the languages of each work are shown individually. Language ratios represent the composition of the entire repository, not the ratio of only the code the user added.

The heart of this project is not a list of numbers. It lets you rotate a planet that reflects your own development history to observe its surface textures and per-language expression, and compare it with the planets of other developers.
