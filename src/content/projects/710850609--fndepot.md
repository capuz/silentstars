# FnDepot - 飞牛OS去中心化应用子仓库

## Overview

FnDepot is a decentralized third-party application manager that runs on FNOS (飞牛OS). It lets users discover, install, and manage third-party apps through multiple community-maintained application sources (Repositories), avoiding the limitations of a single centralized app store.

This document defines the build specification, directory structure, and metadata standard for FnDepot application sources. Developers must strictly follow this specification so that application sources can be correctly parsed, indexed, and distributed by the FnDepot client.
