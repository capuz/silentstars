# FnDepot - FNOS Decentralized App Sub-Repository

## Overview

FnDepot is a decentralized third-party app manager that runs on FNOS (FeiNiu OS). It lets users discover, install, and manage third-party apps through multiple community-maintained app sources (Repositories), avoiding the limitations of a single centralized app store.

This document defines the build specification, directory structure, and metadata standards for FnDepot app sources. Developers must strictly follow this specification so that FnDepot clients can correctly parse, index, and distribute the app source.
