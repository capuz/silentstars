# DS5 Dongle OLED Edition Configurator

The desktop app for the **[DS5 Dongle OLED Edition](https://github.com/MarcelineVPQ/DS5Dongle-OLED-Edition)**: the Raspberry Pi Pico 2 W board that connects a DualSense controller to your PC over Bluetooth while looking, to games, exactly like a wired DualSense (adaptive triggers, haptic feedback, built-in speaker and microphone included).

Made on Linux, tested on Linux, Windows 11 and macOS (the universal app, installed and run on a real Apple Silicon Mac by the [macOS smoke test](https://github.com/MarcelineVPQ/DS5Dongle-OLED-Config-Web/blob/HEAD/.github/workflows/mac-smoke.yml)). The Games page works on Linux (Steam, Heroic, Lutris) and Windows (Steam, GOG Galaxy, Epic). No drivers to install. It updates itself and the board's firmware.

- **Your controller, live:** drawn in its own colors (DualSense colorways and the Edge), moving as you use it. Click any part to set it up: light bar, adaptive…
