# 概要
データ構造やネットワークフローなど、さまざまな分野のアルゴリズムを C++20 で実装しています。  
リンクが付いていないものは、実装予定であることを意味します。  
アルゴリズム系の研究開発やプログラミングコンテストへの参加といった場面で、「実装例」「ライブラリ」として使用することを想定しています。

## 目次

|分類|内容|具体例|
|---|---|---|
|**[DATA STRUCTURE : BASIC](#dsb)**|基礎的なデータ構造|Union-Find など|
