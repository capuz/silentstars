# Self-hosted Airport

[简体中文](https://github.com/lomgzhijie/OpenProxySetup/blob/HEAD/README.md) · [English](https://github.com/lomgzhijie/OpenProxySetup/blob/HEAD/README.en.md) · [日本語](https://github.com/lomgzhijie/OpenProxySetup/blob/HEAD/README.ja.md) · [한국어](https://github.com/lomgzhijie/OpenProxySetup/blob/HEAD/README.ko.md)

[Download Windows x64 version](https://github.com/lomgzhijie/OpenProxySetup/releases/latest) · [Android APK](https://github.com/lomgzhijie/OpenProxySetup/releases/tag/v1.4.3) · [Report issue](https://github.com/lomgzhijie/OpenProxySetup/issues/new/choose) · [Contribute](https://github.com/lomgzhijie/OpenProxySetup/blob/HEAD/CONTRIBUTING.md)

OpenProxySetup provides deployment wizards for Windows and Android. Users authorize their own Cloudflare account and set a backend admin password. The app uses the [edgetunnel](https://github.com/cmliu/edgetunnel) source code included in the package to create Cloudflare KV and Pages, and provides a clickable website address. Users visit `/admin` on the website, enter the password they just set, and can view nodes and subscription links in the upstream backend.
