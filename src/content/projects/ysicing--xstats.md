# XStats

**Mac system monitoring and everyday tools, with both a main window and a menu bar experience.**

CPU, memory, network, and temperature are visible at a glance. Expand to see trends and per-app usage. AI, calendar, fan control, and other tools can be enabled as needed.

## Features

XStats is natively developed with Swift, AppKit, and SwiftUI. It is free and open source, and requires no account registration.

### Menu bar layout

Metrics can be **shown independently**, use **aggregate mode**, or be combined into a single **three-in-one icon** with freely arranged content. In icon-only mode, the Dock icon shows the same live status. Displayed items, order, and styles (text, icon, ring, progress bar, history chart) are all customizable.…
