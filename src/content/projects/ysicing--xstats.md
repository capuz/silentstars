# XStats

**Mac system monitoring and common tools, with both a main window and a menu bar experience.**

CPU, memory, network, and temperature at a glance; expand to view trends and per-app usage. AI, calendar, fan control, and other tools can be enabled as needed.

## Features

XStats is built natively with Swift, AppKit, and SwiftUI. It is free and open source, and requires no account registration.

### Menu bar layout

Metrics can be **displayed independently**, shown in **aggregated mode**, or combined into a single **three-in-one icon** with freely arranged content. In icon-only mode, the Dock icon also shows the same live status. Displayed items, order, and style (text, icons, rings, progress bars, history charts) are all customizable.…
