## 🚀 Software Introduction

> 💡 **Must-read for beginners**: If you are new to Linux server and panel operations, we strongly recommend reading our [📖 Yufeng Panel Beginner's Illustrated Guide](https://github.com/clhome/bt_simple/blob/HEAD/文档/御风面板说明书/说明书.md) first.

**Yufeng Panel (BtSimple)** is a fully open-source, lightweight Linux panel derived from the [mdserver-web](https://github.com/midoks/mdserver-web) project. It follows the **KISS (Keep It Simple, Stupid)** principle, removing redundant features and focusing on core website management, database operations, and system security hardening.

Building on the original version, this project has undergone in-depth security auditing and performance optimization, aiming to provide users with a server management tool that is both powerful and transparent.

### Core Features

- **Lightweight and efficient**: Compared with traditional panels, BtSimple uses very few resources, making it well suited to small-memory VPS instances.
