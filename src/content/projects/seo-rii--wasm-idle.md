## wasm-idle

Executes C, C++, Objective-C, Objective-C++, Fortran, COBOL, V, Python, Java, Rust, Go, D, Dart, MoonBit, C#, F#, VB.NET, Elixir, Erlang, Prolog,
Gleam, Grain, Perl, Tcl, AWK, Pascal, Forth, J, BQN, Janet, Julia, Nim, Bash, ClojureScript, ReScript, OCaml, JavaScript, CoffeeScript, TypeScript,
AssemblyScript, WAT, WASM, Lua, Fennel, Zig, Scheme, Ruby, Haskell, R, Octave, SQLite, DuckDB,
PostgreSQL, and PHP code.

Experimental LFortran execution is available separately from f2c Fortran; see
[the LFortran consumer contract and local setup](https://github.com/seo-rii/wasm-idle/blob/HEAD/docs/lfortran.md).

Lean 4 runs the upstream `lean --run` interpreter in the browser; see
[Lean 4 browser execution](https://github.com/seo-rii/wasm-idle/blob/HEAD/docs/lean4.md).

V runs the real V 0.5.2 compiler in the browser and compiles its C output with the shared
llvm-core Clang host; see [the V browser integration](https://github.com/seo-rii/wasm-idle/blob/HEAD/docs/v-browser.md).
