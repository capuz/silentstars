## 📖 Introduction

The Xianyu Management System - Koolcenter Software Center Plugin Edition is a secondary development version based on [xianyu-auto-reply-fix](https://github.com/GuDong2003/xianyu-auto-reply-fix). It is deployed to ASUS router Koolcenter Merlin firmware, making Xianyu store management more efficient and convenient.

### Prerequisite Plugins
They can be installed and mounted from the KoolCenter Software Center. Install in this order, top to bottom:
- USB2JFFS
- Virtual memory
- Proxy tool lite

### Model Support
On asuswrt-based firmware, the goofish plugin currently supports only routers with the aarch64 architecture, as follows:
- Some models are not listed. Please judge for yourself based on the CPU model and whether the software center is supported
- Using goofish is recommended with 1G or more of virtual memory, especially on routers with small memory
