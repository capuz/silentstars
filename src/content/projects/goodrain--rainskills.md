# RainSkills

> Let your AI Agent deploy the current project online and verify the page and API.

RainSkills is a set of open-source Agent Skills that enable Codex, Claude Code, Pi Agent, DeepSeek Harness, WorkBuddy, and Hermes Agent to continue with application deployment, troubleshooting, delivery verification, version management, and rollback.

It starts from the current project that the Agent already understands, and organizes the frontend, backend, database, cache, ports, and storage into a Rainbond application. Applications can run on Rainbond Cloud, your own server, or Kubernetes.

**AI generates, RainSkills delivers, Rainbond keeps it running.**
