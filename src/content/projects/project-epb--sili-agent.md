## Common Commands

You can use SILI's commands with `@SILI <command>`, `sili，<command>`, or `!<command>`. Many commands also have aliases and easy-to-remember Chinese shortcuts.

All commands and their usage instructions can be obtained with `!help`.

### `wiki <pagename>`

Returns page info and links from the MediaWiki site bound to the channel.

For example `[[Help:Content]]` → https://community.fandom.com/zh/wiki/Help:Content

Fandom's cross-domain, cross-language links also work, for example `[[w:c:zh.ngnl:初濑伊纲]]` → https://ngnl.fandom.com/zh/wiki/%E5%88%9D%E6%BF%91%E4%BC%8A%E7%BA%B2
