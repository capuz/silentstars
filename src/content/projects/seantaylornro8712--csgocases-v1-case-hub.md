## Project Overview

csgocases is a compact HTML website project with a CS:GO cases theme. It is designed for hosting situations that call for a lightweight front-end page, such as a landing page, preview website, or basic case-related showcase.

The repository keeps its structure intentionally small and avoids a complex application stack. As a result, the files are simple to review, deploy, and modify when a focused, game-themed web page is all that is required.
