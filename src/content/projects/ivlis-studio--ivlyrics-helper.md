# ivLyrics Helper

[Korean](https://github.com/ivLis-Studio/ivLyrics-helper/blob/HEAD/README.md) | [English](https://github.com/ivLis-Studio/ivLyrics-helper/blob/HEAD/README_EN.md)

A desktop helper app used to download and play video backgrounds for [PC ivLyrics](https://github.com/ivLis-Studio/ivLyrics) on your computer, or to pass the current song's lyrics and playback information to other programs.

Install only the feature you need from the two below. It is not required to view lyrics inside Spotify. If you want a separate lyrics window, use [ivLyrics Overlay](https://github.com/ivLis-Studio/ivLyrics-overlay). Overlay can be used without Helper.
