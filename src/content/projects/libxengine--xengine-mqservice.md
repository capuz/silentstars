## Introduction
C/C++ message service message middleware  
C/C++ Message Service  

## Notice
Compiled release versions will only be released on GitHub.

## Software Architecture
This software is developed based on XEngine. C/C++ is used as the development language.  
This software is a simple and high-performance service with a unified API interface, allowing users to use it directly with almost no secondary development needed.  
This software mainly provides message queue and message distribution engine, which can be used as an API server for user message operations. It supports HTTP, WEBSOCKET, MQTT and private protocols.
