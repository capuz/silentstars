# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/12AzgDQY5RIYe0M0SXoEl8iTWZ_NkXIj8

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](https://github.com/freemank1224/vibe-word-master/blob/HEAD/.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
