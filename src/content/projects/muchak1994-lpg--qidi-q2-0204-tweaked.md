# QIDI Q2 02.04 Tweaked

**English** · [Polski](https://github.com/muchak1994-lpg/qidi-q2-0204-tweaked/blob/HEAD/README.pl.md)

Community fixes and small improvements for the **QIDI Q2** 3D printer running firmware **01.01.02.04** — and only that version.

> **Unofficial project.** Not affiliated with, endorsed by or supported by QIDI Technology. You use it at your own risk. Keep the official firmware package at hand so you can always go back to stock.

> **Status: 1.2.0.** All modules build from the official packages and match a tested printer byte for byte; every module has been installed (and upgraded) with this installer on the author's printer, the installer is tested offline against a simulated printer, and a full install was done on a freshly reflashed printer (14.11.2026). See [docs/ROADMAP.md](https://github.com/muchak1994-lpg/qidi-q2-0204-tweaked/blob/HEAD/docs/ROADMAP.md).
