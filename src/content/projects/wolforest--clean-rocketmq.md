# Clean-RocketMQ

**Clean-RocketMQ is the fastest transactional message queue.**<br />
1. **Compatible with RocketMQ:** Can fully or partially replace RocketMQ.
2. **High performance:** Supports CommitLog sharding, with 5x+ RocketMQ throughput improvement.
3. **Transactional:** Supports distributed transactions (TCC), ensuring consistency of message sending and scheduling.
4. **More complete:** More complete support for delayed, expiring, periodic, cyclic and other message scheduling.
5. **Separation of storage and compute:** More reasonable splitting of the domain layer and storage layer, which is also the foundation of cloud native.
6. **CLEAN:** Introduces micro-framework and DDD thinking, easy to read and understand.

> Clean-RocketMQ is the inheritance and optimization of RocketMQ.<br />
> The RocketMQ core is less than 50,000 lines; it is not difficult to improve performance and extend features on its shoulders.<br />
> The real challenge is: &nbsp;&nbsp; **How to continuously keep the code clean and maintainable?**
