# PUJDICT

**Péh-Uē-Jī dictionary of the Teochew-Swatow dialect**

Under development; proposals and corrections are welcome.
Dictionary data is available in the [pujdict/pujbase](https://github.com/pujdict/pujbase) repository.

Dictionary sites:
- <https://pujdict.sourceforge.io/>: Hosted on SourceForge; updated daily with the latest data from this repository's Action.
- <https://pujdict.com/>: Mirror site. It may be faster, but data updates are delayed.

## Project status

- Features: Character-to-reading lookup, reading-to-character lookup, and vocabulary search are largely complete. Supports multiple accents and both the Péh-Uē-Jī and Teochew Pinyin (潮拼) romanization schemes.
- Data:
  - Character list: The character list and its readings have been proofread. Each reading is labeled with a usage frequency (preferred, common, uncommon, or rare; four tiers). Characters with multiple readings are also labeled by reading type: vernacular reading (白读), literary reading (文读), or colloquial reading (俗读). The list also records many literary readings that existing dictionaries do not include.
