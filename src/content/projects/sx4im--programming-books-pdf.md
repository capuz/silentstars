# Ultimate Programming Books

Curated programming books for **20 languages** — beginner to advanced. Pick a language, follow the skill path, and open public Drive links to read.

## Quick start

| Path | Best for |
| --- | --- |
| [**Library dashboard**](https://github.com/sx4im/programming-books-pdf/blob/HEAD/web/) (`cd web && npm run dev`) | Visual shelf — filter by language & level, click **Read book** |
| [**Language docs**](https://github.com/sx4im/programming-books-pdf/blob/HEAD/docs/) | GitHub-native Markdown guides |
| [**books.json**](https://github.com/sx4im/programming-books-pdf/blob/HEAD/web/data/books.json) | Add authors, covers, and Drive URLs for the app |

Each guide is split by level: **Beginner → Intermediate → Advanced → Specialized → References**.
