# OpenCodex

**中文** | [English](https://github.com/RyensX/OpenCodex/blob/HEAD/docs/README_EN.md)

OpenCodex is a middleware layer for Codex Desktop, compatible with both the old Codex Desktop and the new ChatGPT Desktop. It allows you to directly access and operate Codex on a target machine through a browser using a phone, tablet, or another computer, enabling AI Coding anytime and anywhere.

---
The sky has fallen 😭 Just as I was about to open source it, I woke up to find that the ChatGPT App now supports Codex.

However, compared to the official version, there are still some advantages in usage scenarios:

1. No need for magic internet access.
2. No need for foreign Google Play/Apple accounts, and supports remote use with third-party API login.
3. Supports the full functionality of Codex, such as file tree, terminal, review, etc., making AI Coding convenient anytime and anywhere.
4. Freely combine with intranet penetration/public network, without going through official relay servers, ensuring fast speed and easy protection of private data.
