# 🚀 xiaozhi-esp32-server-golang

> **Xiaozhi AI Backend for ESP32 Devices**

---

## Project Overview | 项目简介

xiaozhi-esp32-server-golang is a high-performance, fully streaming AI backend service, designed for IoT and intelligent voice scenarios. Developed in Go, it integrates core capabilities such as ASR (Automatic Speech Recognition), LLM (Large Language Model), and TTS (Text-to-Speech), supports large-scale concurrency and multi-protocol access, and enables AI voice interaction for smart terminals and edge devices.
