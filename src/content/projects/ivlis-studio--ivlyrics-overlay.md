# ivLyrics Overlay

This is a desktop app that displays lyrics on top of other windows so you can view the lyrics of the current song even outside Spotify. It receives lyrics and playback information from [ivLyrics for PC](https://github.com/ivLis-Studio/ivLyrics) running on the same computer.

Install it only when you need a separate lyrics window. It is not required to use ivLyrics inside Spotify, and you do not need to install [ivLyrics Helper](https://github.com/ivLis-Studio/ivLyrics-helper) along with it. Helper is a separate app for local video playback and lyrics integration with other programs.
