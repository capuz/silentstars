# TeleBox-Plugins

## Introduction
TeleBox-Plugins is the official plugin repository for the [TeleBox](https://github.com/TeleBoxOrg/TeleBox) project, providing a rich set of functional extensions.

## Installation Method

Execute in a running TeleBox:

```bash
.tpm i <plugin_name>
```

Aliases are also supported: `.tpm install <plugin_name>`, batch `.tpm i a b c`, one-click `.tpm i all`.

## Available Plugin List
- `aban` - Advanced ban management  
- `acron` - Scheduled sending/forwarding/copying/pinning/unpinning/deleting messages/executing commands  
- `admin_board` - Administrator leaderboard with elimination of the last place  
- `aff` - Airport Aff information management  
- `ai` - AI aggregation  
- `aitc` - AI Prompt transcription  
- `annualreport` - Annual report  
- `atadmins` - One-click mention all administrators  
- `atall` - One-click mention all members  
- `audio_to_voice` - Music to audio  
- `autochangename` - Automatically change username on a schedule  
- `autodel` - Scheduled message deletion  
- `autodelcmd` - Automatically delete command messages  
- `autorepeat` - Intelligent automatic repeater  
- `banana` - Nano-Banana image editing
