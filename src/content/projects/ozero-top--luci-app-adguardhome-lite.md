# AdGuard Home 管理中心

AdGuard Home LuCI management center for OpenWrt / ImmortalWrt / iStoreOS: integrated installation, DNS takeover, filtering and supervision, supporting three-step setup and low-intrusion DNS takeover.

> The plugin handles installation, DNS takeover, filtering and statistics; finer advanced options can still be adjusted in the AdGuard Home dashboard.
