# YR Map Editor

A map editor for *Red Alert 2: Yuri's Revenge* made for [VERA20k](https://github.com/YuriPlanet/vera20k), built with Rust, egui and wgpu.

It covers the full workflow, from terrain and object editing and mission creation to saving, playtesting and map publishing. The editor requires you to provide your own legally obtained game assets; the repository does not include any game assets.
