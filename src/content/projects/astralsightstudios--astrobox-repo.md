### 2026-8-18
Starting with AstroBox v2.1, the existing “Watch Faces, Quick Apps” category will be adjusted to “Watch Faces, Quick Apps, Modules”.

Watch faces and Quick Apps are no different from the traditional definitions.
Modules: a special resource type supported by Canopus. Modules have two types of capabilities: native app registration capability and system extension capability. A module may have only one of these capabilities, or both. This means you can build a module with purely native app capability on Canopus to create a more feature-rich app, or build a module with system extension capability on Canopus to modify some system functions. We look forward to your creativity.

At the same time, starting with this version, we will also open listings for the “Module” resource type. Because modules have very high privileges, for the security of users' devices, developers must, in addition to reasonable categorization, submit the complete module source code and build process to the reviewers.
