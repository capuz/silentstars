# 🚀 Awesome YOLO Datasets

> A curated collection of YOLO object detection datasets. High-quality datasets are continuously updated. If a dataset you need is not covered, feel free to submit an Issue; it will be added to this repository within one day.

  

---

## 📖 Project Overview

This repository curates thousands of datasets suitable for YOLO object detection, all of which provide online download addresses.

### ✨ Features

- 🎯 **Ready to use**: All datasets use the YOLO label format, so you can download and train right away
- 🔗 **Online download**: All datasets come with cloud-drive download links
- 🏷️ **Clear categories**: Organized by application domain for quick lookup of the datasets you need
- 📊 **Continuously updated**: New high-quality datasets are added regularly; Issues are welcome for dataset requests
