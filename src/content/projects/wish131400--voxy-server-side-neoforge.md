# Voxy Server Side NeoForge

[0.3.6 Changelog](https://github.com/wish131400/voxy-server-side-neoforge/blob/HEAD/CHANGELOG.md) · [Usage and Upgrade Guide](https://github.com/wish131400/voxy-server-side-neoforge/blob/HEAD/docs/release-0.3.6-player-guide.md) · [Mod Compatibility Review](https://github.com/wish131400/voxy-server-side-neoforge/blob/HEAD/docs/release-0.3.5-mod-compatibility-20261006.md)

Voxy Server Side (VSS) lets the server handle reading, generating, caching, and sending Voxy distant LOD. Clients only request missing or outdated column data, then hand it to Voxy for rendering. It suits multiplayer servers, large modpacks, and high-speed movement scenarios.
