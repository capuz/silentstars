# Xiaomu

A native multi-source player built on MyGo. Import your own TVBox configuration or IPTV playlist, or open a video link directly. [MyGo project](https://github.com/egoist/mygo)

macOS 13+ · Apple Silicon / Intel · Windows 10/11 · x64 · [Download the latest version](https://github.com/arixbit/xiaomu-desktop/releases/latest)

- **Cross-site search**  Press `⌘K` and enter a title. Multiple sources for films with the same name are shown together.
- **Episode selection**  On the details page, choose a line and episodes. You can also switch sources during playback.
- **Continue watching**  Return to the home page and pick up from the last episode and progress. You can also check for updates to series you follow.

**Quick start**  Paste your configuration URL on the home page and import it → search for a title → open the film and play an episode.
