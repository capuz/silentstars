# Markdown2Word

A small tool based on Python + Tkinter for quickly converting Markdown text into Word documents (`.docx`).

The project provides a simple graphical interface, suitable for scenarios such as organizing AI-generated Markdown answers into Word notes, and converting AI-translated papers into Word documents. The current implementation focuses on Chinese document typesetting, formula conversion, image and hyperlink handling, and paragraph output that better matches Chinese writing conventions.

**You can double-click the exe program in the ./markdown2word folder to run this program directly. Simple and fast.**
