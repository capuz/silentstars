OneLook is a mind mapping app focused on **immersive creation**. It drops cluttered UI distractions and combines the smooth input of Markdown with the high-performance rendering of SVG, giving you a WYSIWYG thinking space. All data is stored locally, so your privacy stays protected.

## ✨ Core Features

- 📝 **WYSIWYG**: Supports standard Markdown syntax and LaTeX math formulas (`$E=mc^2$`) with real-time preview.
- 🎨 **Modern Design**: Includes several polished themes (light/dark/fresh), with deep customization of rounded-corner and connector styles.
- 🌈 **Rainbow Branches**: Turn it on with one click to automatically color each main branch, so the structure of your ideas is clear at a glance.
- 🎬 **Presentation Mode**: Immersive Prize-style presentations with smart camera movement, visual focus, and a laser pointer.
- 🚀 **Infinite Canvas**: Built on D3.js layout algorithms, with infinite zooming, dragging, and smooth auto-centering.
- ⚡ **Efficient Interaction**: Driven entirely by keyboard shortcuts, with multi-select (Ctrl+Click), box selection (Shift+Drag), and batch operations.
- 📂 **Local First**: Local persistent storage based on IndexedDB, no internet connection…
