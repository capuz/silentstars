# ForgeScope

### A GitHub-connected inbox for CI failures, source evidence and reviewed changes.

**Monitor repositories in any language. Open the reported error, file and commit from your browser.**

[Evidence-backed tour](https://brunnojob.github.io/forgescope/#pipeline-1) · [Tutorial](https://brunnojob.github.io/forgescope/#how-it-works) · [Português](https://github.com/brunnojob/forgescope/blob/HEAD/README.pt-BR.md) · [Español](https://github.com/brunnojob/forgescope/blob/HEAD/README.es.md) · [Architecture](https://github.com/brunnojob/forgescope/blob/HEAD/docs/ARCHITECTURE.md) · [Migration notes](https://github.com/brunnojob/forgescope/blob/HEAD/docs/MIGRATION-0.3.md)

Changing unfamiliar code means reconstructing dependencies, reviewing patches, reading CI logs and finding maintenance work across separate tools. ForgeScope puts those evidence streams into one local investigation report.
