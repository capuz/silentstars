# Halo-Plugin-Footprint

> Footprint plugin for Halo: put the places you've been on a 3D globe, or switch to a 2D AMap map and review them by time.

## Demo and Community

- **Demo sites**: [xhhao.com/footprints](https://www.xhhao.com/footprints) (Handsome), [yunduan019.com/footprints](https://www.yunduan019.com/footprints) (Yunduan)
- **Docs**: [docs.lik.cc](https://docs.lik.cc/)
- **Source code**: [GitHub](https://github.com/acanyo/halo-plugin-footprint)
- **QQ group**: [](https://www.xhhao.com/upload/iShot_2025-03-03_16.03.00.png)

Each footprint is a location, a set of photos, an optional ticket stub, and an optional linked article. Entries are created in the admin backend and displayed on the frontend at `/footprints`:
By default it shows a Cesium 3D globe. From the bottom navigation you can switch to a 2D AMap map, browse albums by city, view ticket stubs, and flip through “The Book of the World.”
