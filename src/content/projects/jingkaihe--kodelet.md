[Kodelet](https://kodelet.com/) runs agentic loops on a server instead of your terminal session. Start a task in the terminal, pick it up in the browser or an editor that supports [ACP](https://agentclientprotocol.com/), and disconnect whenever you like. Keep everything on your laptop, or host the server remotely and send work to [runners](https://github.com/jingkaihe/kodelet/blob/HEAD/docs/MANUAL.md#workspace-bound-runners) on other machines.

Kodelet comes with a minimal core but is highly customizable through its powerful [extension system](https://github.com/jingkaihe/kodelet/blob/HEAD/docs/extension-design.md). Add custom tools and commands, intercept prompts and tool calls, build interactive terminal widgets, or plug in MCP servers, using TypeScript, Python, or any language that speaks JSON-RPC. Bring your own Claude, OpenAI, or OpenAI-compatible models, add skills for specialist know-how, and control access with sign-in through your identity provider.
