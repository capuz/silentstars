## Workbench Web Preview 1（R1，发布准备中）

The first Web preview is limited to Windows 11 x64, a same-origin loopback Web interface, and a matching NativeAOT Server. Candidate 10 has completed local R1 hands-on acceptance and preparation of four attachments, but the product is still **NOT_READY**. The P07 gate and P08 authorized release are not yet complete, so this preview has no public download yet. You can evaluate bounded SQL, relational tables, measurements, and one authorized single-row insert. The seven dedicated model workbenches, Studio, and VS Code are postponed. [Usage, limitations, upgrade/rollback and feedback](https://github.com/IoTSharp/SonnetDB/blob/HEAD/docs/design/m47-unified-management-workbench/sonnetdb-workbench-web-4.5.0-preview.1.10-notes.md) and [independent distribution status](https://github.com/IoTSharp/SonnetDB/blob/HEAD/docs/design/m47-unified-management-workbench/preview-1-p06-distribution.md) describe the actual scope.
