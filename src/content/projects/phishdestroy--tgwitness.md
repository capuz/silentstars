## Install

Python is included. Run the same command again to update.

**Linux / macOS**

```sh
curl -fsSL https://get.destroy.tools/install.sh | bash
```

**Windows · PowerShell or CMD**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://get.destroy.tools/install.ps1 | iex"
```

The installer checks package hashes and release signatures against its embedded key. Each signed build identifies its source revision.
[Verify before running](https://github.com/phishdestroy/TgWitness/blob/HEAD/docs/INSTALLATION.md#verify-before-running) · [Releases](https://github.com/phishdestroy/TgWitness/releases) · [Docker](https://github.com/phishdestroy/TgWitness/blob/HEAD/docs/DEPLOYMENT.md) · [Install from source](https://github.com/phishdestroy/TgWitness/blob/HEAD/docs/QUICKSTART.md)

**First run:** choose **Just download**, **Follow chats** or **Evidence for a case** → connect an account → choose chats. The panel shows the controls for that task. [Setup guide →](https://github.com/phishdestroy/TgWitness/blob/HEAD/docs/SETTINGS.md)
