# Carrey Fan

Carrey's personal homepage and portfolio entry, built with native HTML, CSS, and JavaScript.

Live site: [carreyf.space](https://www.carreyf.space/)

## Features

- Full-screen personal introduction and video hero section
- Project list with web thumbnail previews and collapsible expansion
- Experience, AI Coding tools, and writing content
- Floating contact panels for X, Douyin, email, and WeChat
- Music controls and a bottom galloping-horse animation
- Responsive layout, keyboard focus, and reduced-motion support

## Local Development

The project requires no build tools. Start a static server in the project directory:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000/>.
