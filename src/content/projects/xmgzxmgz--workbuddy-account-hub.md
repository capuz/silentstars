# WorkBuddy Account Hub

> 🌟 **Key highlight: instant account switching, ultra-simple operation.** Have multiple WorkBuddy accounts on your machine? Switch between them with one click—switching only changes your "login identity" without touching any of your local data, and conversations for each account remain independent and fully preserved. See the implementation details below at [How It Works](#how-it-works-why-switching-accounts-doesnt-lose-your-conversations).

> A **locally-running** cross-platform (macOS / Windows) desktop application that centralizes daily WorkBuddy account operations in one window:
> **Ultra-fast multi-account switching, multi-account billing quotas (three official APIs), daily check-in, pet adventure and energy blind boxes, login state management, AI memory profile, API model management (including global privacy data obfuscation)**.
> Built with Tauri 2 + Rust, pure local data flow, no cloud dependencies.
