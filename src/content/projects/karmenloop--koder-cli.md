# Koder CLI

**0.4.0-preview.19** · [Download](https://github.com/KarmenLoop/koder-cli/releases/tag/cli-0.4.0-preview.19) · [Installation guide](https://github.com/KarmenLoop/koder-cli/blob/HEAD/docs/INSTALLATION.md) · [Provider setup](https://github.com/KarmenLoop/koder-cli/blob/HEAD/docs/PROVIDERS.md)

Koder is a local task tool from the KARMEN LOOP team. Bring your own model API, choose a project, and work through plans, tools, approvals, and recorded results. Personal, noncommercial local use is free and does not require membership. Commercial use and organizational deployment require separate written authorization. The personal license does not permit secondary development or changes to proprietary code. A provider may charge for API requests.

The KARMEN LOOP kernel connects task planning, permission checks, tool execution, and saved results. Public descriptions cover capabilities; new application runtime source remains proprietary under the [EULA](https://github.com/KarmenLoop/koder-cli/blob/HEAD/EULA.md). Third-party components retain their own licenses and [credits](https://github.com/KarmenLoop/koder-cli/blob/HEAD/OPEN_SOURCE_CREDITS.md).
