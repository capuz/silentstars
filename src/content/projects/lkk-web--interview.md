## iOS App Maintenance

Free Apple ID signing typically expires after 7 days. When the app won't open after expiration, reconnect the iPhone and press `Cmd + R` in Xcode to reinstall and renew the signing for 7 more days:

```bash
cd /Users/max/Desktop/github/interview
source ~/.nvm/nvm.sh && nvm use 22
npx cap open ios
```

If you're only renewing the signing without changing content, you don't need to rebuild the web artifacts.
