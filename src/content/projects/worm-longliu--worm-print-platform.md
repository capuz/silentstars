## Features

- 🎨 **Zero-framework Custom Elements** — Built on native Custom Elements + Shadow DOM with zero Vue/React dependencies. Vue 3, Vue 2, React, jQuery, and vanilla JS all share the same designer.
- 🧩 **Plugin system** — 11 built-in element types and third-party plugins go through the same registry with equal extension rights. Registration happens on import, and a companion plugin marketplace CLI is provided.
- 🔗 **Isomorphic rendering pipeline** — The same template and data produce fully consistent output across three pipelines: browser preview, server-side PDF, and silent printing from the desktop client.
- ⚡ **Expression engine** — A custom-built lexer, parser, and safe evaluator that supports built-in functions such as `formatMoney` / `sum` / `concat`.
- 🧾 **Professional layout capabilities** — Table pagination, repeating headers, subtotals/summaries, merged cells, continuous paper, imposition (multiple labels tiled onto A4), and watermarks.
- 📊 **Optional ECharts** — An SVG SSR chart element package with design-time configuration for ten chart types.
