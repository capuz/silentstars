## Getting Started

Use the central
[doubtfire-deploy](https://github.com/doubtfire-lms/doubtfire-deploy)
repository for development and deployment. It includes this repository as a
submodule and provides the supported VS Code Dev Container workspace.

Opening `doubtfire-deploy` in its Dev Container automatically installs the web
and API dependencies, configures the development environment, and starts the
database and supporting services. No separate local setup for this repository
is required. See the `doubtfire-deploy` [README](https://github.com/doubtfire-lms/doubtfire-deploy#ontrack-deployment) for the current setup and usage
instructions.
