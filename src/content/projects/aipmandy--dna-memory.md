# DNA Memory

**A locally prioritized unified memory layer for Codex, Claude Code, Claude Desktop, Hermes, and Obsidian**

[English](https://github.com/AIPMAndy/dna-memory/blob/HEAD/README_EN.md) | 简体中文 | [Quick Start](https://github.com/AIPMAndy/dna-memory/blob/HEAD/QUICKSTART.md)

</div>

DNA Memory uses a Markdown/Obsidian directory as the true source of long-term memory, with SQLite as a removable and reconstructible index. Multiple AI clients can recall, write, and provide feedback through the same MCP service, no longer maintaining conflicting long-term memory copies independently.

It does not equate "saving all chat records" with "forming memory." Complete sessions are still retained by the original client; DNA Memory only saves bounded source pointers, reviewed proposals, and validated key conclusions.

## Core Concept: From Dialogue Data to Reusable Cognition

> **DNA Memory does not view "saving conversations" as "forming memory."** Inspired by the human brain's memory formation mechanisms, it treats a large amount of cross-client dialogue as raw perceptual input, continuously abstracting data into reusable cognition through signal extraction, importance and confidence…
