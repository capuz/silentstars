# 치직

**치직** is a bot that sends a Discord server notification when a [치지직(CHZZK)](https://chzzk.naver.com) streamer goes live.

It can be used by the streamer themselves or by fan server operators. Invite the bot and register a CHZZK channel, and every time the broadcast starts, a notification is sent to the Discord channel of your choice.

- **Dashboard**: [chzzk.junah.dev](https://chzzk.junah.dev)
- **Docs**: [chzzk.junah.dev/docs](https://chzzk.junah.dev/docs)
- **Troubleshooting**: [chzzk.junah.dev/docs/troubleshooting](https://chzzk.junah.dev/docs/troubleshooting/)
- **Support server**: [chzzk.junah.dev/support-server](https://chzzk.junah.dev/support-server)

## 🚀 Key Features

### Basic Features (Free)

- **Broadcast notifications**: When a broadcast starts, a notification is sent to the Discord channel within 5 minutes.
- **Web dashboard**: Log in with your Discord account to add, edit, and delete notifications, and send test notifications.
- **Message customization**: Notification messages can use mentions (@everyone, @here, specific users or roles) and Discord markdown.
