## Project Introduction

Yuanshu Ontology transforms enterprise data assets scattered across various systems into a unified, queryable, and executable semantic network. The platform provides an end-to-end workflow from **data access** to **ontology modeling** to **agent applications**, allowing teams to build intelligent scenarios based on well-governed business semantics, rather than directly manipulating raw tables and scripts.

### Core Highlights

- **Ontology-first Governance** — Aligns with W3C OWL 2 standards, supports entity/attribute/relationship modeling, versioning, publishing, and approval processes
- **Multi-source Heterogeneous Access** — Unified connector framework covering MySQL, PostgreSQL, Oracle, SQL Server, Hive, ClickHouse, S3, FTP, Kafka, REST API
