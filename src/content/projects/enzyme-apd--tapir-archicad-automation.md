# tapir-archicad-automation

This repository contains the Tapir Archicad automation package. It consists of several components:
- [Tapir Archicad Add-On](https://github.com/ENZYME-APD/tapir-archicad-automation/blob/HEAD/archicad-addon): An Add-On that registers several new JSON commands on top of the official commands provided by Graphisoft. You can see the list of new commands [here](https://enzyme-apd.github.io/tapir-archicad-automation/archicad-addon). This is ready to use, see the installation instructions below.
- [Tapir Grasshopper Plugin](https://github.com/ENZYME-APD/tapir-archicad-automation/blob/HEAD/grasshopper-plugin): A Grasshopper plugin to help using the above components even for non-programmers. This is work in progress at the moment.
