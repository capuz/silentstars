# Art Supabase Pro

Art Supabase Pro is a modern enterprise-level backend application template built on **Vue 3**, **TypeScript**, **Element Plus**, **Supabase**, and **AI SQL Assistant**. It provides a rich set of functional components, complete permission control, SQL workbench, AI SQL writing, vehicle management system, TMS transportation management system, and out-of-the-box system management modules, aimed at helping developers quickly build high-performance, deployable enterprise applications.

Online address [https://869123771.github.io/art-supabase-pro/](https://869123771.github.io/art-supabase-pro/)

## ✨ Features

- **Modern technology stack**: Built on Vue 3 + Vite + TypeScript + Pinia.
- **Backend as a service integration**: Deep integration with Supabase, providing authentication, database, and real-time subscription support.
- **AI SQL Assistant**: Built-in SQL workbench supporting PostgreSQL editing, JOIN inference, field completion, SQL formatting, error localization, AI-generated SQL, and AI SQL fixing.
