# IWM

An open-source, self-hostable all-in-one workspace for teams. It covers projects and tasks, leads, clients and a client portal, invoices and finance, chat and voice/video calls, documents and files, mail, and HR (attendance, leave, timesheets, payroll), on web, desktop and mobile.

IWM is a TypeScript monorepo: a NestJS API, a Next.js web app, an Electron desktop shell and an Expo mobile app, all sharing Zod schemas and a typed API client. See [ARCHITECTURE.md](https://github.com/The-Botss-AI/IWM/blob/HEAD/ARCHITECTURE.md) for how the pieces fit together.
