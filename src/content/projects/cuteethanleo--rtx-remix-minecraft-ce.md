# RTX Remix for Minecraft

> **RTX Remix for Minecraft Community Edition (Unofficial).** An unofficial derivative of
> [NVIDIAGameWorks/rtx-remix-minecraft](https://github.com/NVIDIAGameWorks/rtx-remix-minecraft)
> at commit `a518eff`, with lighting, weather, water, night sky, and motion blur improvements.
> Not affiliated with or endorsed by NVIDIA. See [COMMUNITY.md](https://github.com/CuteEthanLeo/rtx-remix-minecraft-ce/blob/HEAD/COMMUNITY.md) for what changed
> and how it is maintained. The rest of this README is upstream's.
>
> **RTX Remix for Minecraft 社区版（非官方）**，基于上方官方仓库的衍生版本，与 NVIDIA 无关联。
> 改动与维护方式见 [COMMUNITY.md](https://github.com/CuteEthanLeo/rtx-remix-minecraft-ce/blob/HEAD/COMMUNITY.md)。
>
> **Downloads / 下载**: each Minecraft version has its own installer package on
> [Releases](https://github.com/CuteEthanLeo/rtx-remix-minecraft-ce/releases), tagged `v<mod version>+mc<Minecraft version>`. Every Minecraft version carries the same mod version. Download the `…-win64.zip`
> whose tag ends in your Minecraft version, extract it, and run `install.bat`. A package only
> works with the Minecraft version in its tag.
>
> 每个 Minecraft 版本有独立的安装包，发布标签以 `+mc<Minecraft 版本>`…
