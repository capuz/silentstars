# NetworkAuth (Network Authorization Service)

NetworkAuth (网络授权服务) is a backend system focused on application authentication, API interface management, and dynamic logic distribution. Developed in Go, it provides core services such as application management, API interface management, variable management, and user authentication.

## Features

### 🚀 Core Features
- **Application management**: Supports create, read, update, and delete operations for applications, plus version management, status control, and key management
- **API interface management**: Supports API interface configuration with multiple encryption algorithms (RC4, RSA, 易加密, etc.)
- **Variable management**: A standalone variable system that supports create, read, update, and delete operations, as well as alias management
- **Function management**: Supports custom function code management, which can be bound to specific applications or used globally
- **User management**: A complete user authentication and permission management system
- **System settings**: Flexible system configuration and parameter management
- **System initialization**: Provides guided data table initialization and default settings injection
