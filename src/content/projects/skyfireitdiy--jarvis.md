## Moving Agents from "Working Alone" to "Working Together" 🚀

**In one sentence**: a locally run, ready-to-use, deeply customizable **collaborative AI development platform**. It fully covers four collaboration modes ("one person, one Agent", "one person, multiple Agents", "multiple people, one Agent", "multiple people, multiple Agents"), and handles code writing, review, automation, security analysis, and C→Rust migration, all from one command line.
