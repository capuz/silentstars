## About Zorara

Zorara is a free script execution tool for Roblox on Windows. It lets users run custom Lua scripts inside the Roblox client, offering a straightforward way to expand gameplay possibilities. The tool emphasizes a stable injection process without requiring complex setup or activation keys.

Built with a lightweight desktop interface, Zorara includes an integrated script hub hosting hundreds of community-contributed scripts. The application updates automatically, ensuring ongoing compatibility with current Roblox versions.
