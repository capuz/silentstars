# Lichii

> ## ✅ v31 recommended
>
> v31 includes the #874 payload-release fix and the #910/#921/#932 fixes, based on zortos `nx2` `cbb512ee`. v30, v29, v28 and v24 remain available as fallbacks.

> **Unofficial superbuild fork.** This repository is not official Lichii and is
> not affiliated with zortos293. It carries a curated set of performance and
> correctness fixes on top of `nx2`; see [SUPERBUILD.md](https://github.com/callme-sy/Lichii-Superbuild/blob/HEAD/SUPERBUILD.md) for the
> included commits, skipped fixes and build instructions. Use a stock build as
> fallback.

Lichii is an experimental, open-source Nintendo Switch and Switch 2 emulator written in C++. It builds on Eglantine, Eden, yuzu and Sudachi, preserving their contributions while developing this fork's game compatibility and renderer fixes.

This is an independent fork, not an official release of those upstream projects. Lichii is not affiliated with Nintendo.

Visit the [official Lichii website](https://lichii.zortos.me) to find games and compare community compatibility reports.
