一款功能强大的浏览器代理管理扩展，适配 Chrome/Firefox/Edge 等多款浏览器，支持多场景管理，帮助您轻松配置和切换网络代理。

</div>

## 1. ✨ 功能特性

### 1.1 🔌 多协议代理支持
- **HTTP** - 传统 HTTP 代理
- **HTTPS** - 安全 HTTPS 代理
- **SOCKS5** - 支持 TCP/UDP 的 SOCKS5 代理
- **SOCKS4** - 兼容旧版 SOCKS4 代理

### 1.2 🌐 多浏览器支持
- **Chrome** - 使用 Manifest V3 + Service Worker
- **Firefox** - 使用 Manifest V3 + `proxy.onRequest` API…
