# DLSS FrameGen Enabler & DLSS5

2026-11-14 latest version update: V1.20

2026-11-15 Beta latest version update: V1.35

A Windows desktop tool for enabling DLSS5 and Frame Generation in games.

## Features

### Frame Generation
- **RTX 40 Series**: Classic and Advanced modes
- **RTX 30 Series**: 30-series exclusive MFG patch
- **RTX 20 Series**: 20-series exclusive MFG patch
- **RE Engine Games**: RE Engine exclusive MFG
- **Cyberpunk 2077**: 2077 exclusive MFG patch
- **Older Drivers**: MFG for older drivers

### DLSS5
- **Universal DLSS5**: Supports NVIDIA and AMD (7000/9000 series) GPUs
- **RE Engine DLSS5**: RE Engine exclusive DLSS5 patch
- **DX9 32-bit DLSS5**: Supports DX9 32-bit older games
- **DX9 64-bit DLSS5**: Supports DX9 64-bit games
- **Where Winds Meet**: Exclusive DLSS5 patch
