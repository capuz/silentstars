## Two Ways to Use It

- **AstrBot users**: install the plugins under `plugins/` to get a complete character (memory, emotion, life layer, panel)
- **DSH desktop version**: use [`dsh/`](https://github.com/peterpoal134/memory-brain/blob/HEAD/dsh/README.md), with a 3D brain and a cross-session startup package
- **qqbridge**: **not adapted** in this release, and there is no test environment
