# Microcontroller Technology and Electronic Product Development

This series is mainly based on the STM32F429IGT6 platform from Positive Atom, demonstrating microcontroller-related technologies in the form of modules and comprehensive projects. The directory structure is as follows.

🧩 **modules**/: Chapter-by-chapter explanation of STM32F4 module functions.
🧩 **code**/: Verifiable code provided chapter by chapter, projects located in code/xx-STM32F429_xx

In addition, you can follow my WeChat official account: <Embedded Technology Summary> to access more technical sharing and project experience.

⚠️ **Note: This series is a summary of personal knowledge. In the current era where vibe coding is replacing embedded programming, learning hardware modules is an inefficient approach. It is better to first understand the general concepts and then start from practical applications - that is the correct method.**

To learn microcontroller applications, you can use vibe coding to replicate the following open-source projects and use this documentation to solve problems.
