## Product Overview

DisyLab organizes text, reference images, generated images, generated videos, assets, and Agent conversations on a traceable infinite canvas. Project data is stored locally in the browser by default. API keys are kept only in the current browser session, are not written to the repository, and are not hosted by DisyLab.

## Core Capabilities
