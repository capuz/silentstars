## About

This project is an associated project of [Hello-CTF](https://github.com/ProbiusOfficial/Hello-CTF), which is an automated competition information update system implemented based on Issue templates + GitHub Actions.

To view competition information, please visit: [https://hello-ctf.com/Event/](https://hello-ctf.com/Event/)

*We are testing an LLM model-based competition information extraction feature. If you encounter any issues while using it, please contact us (QQ Group: 590430891).*

## Data Sources

International competition data comes from CTFtime RSS feed - https://ctftime.org

Domestic competitions are collected and maintained by this project. To add competition information, please select the [Add Competition Template](https://github.com/ProbiusOfficial/Hello-CTFtime/issues/new/choose) in Issues.

If you have any questions, please open a blank issue or contact us in the [Competition Group](https://qm.qq.com/q/HxicU7ee2e).
