# ioBroker.pushover

[Pushover](https://pushover.net) is a service of Pushover, LLC (formerly Superblock, LLC), a private, independently financed software development company based out of Chicago, Illinois. **This ioBroker adapter is not written or supported by Pushover, LLC**.

## Documentation

[🇺🇸 Documentation](https://github.com/ioBroker/ioBroker.pushover/blob/HEAD/docs/en/README.md)

[🇩🇪 Dokumentation](https://github.com/ioBroker/ioBroker.pushover/blob/HEAD/docs/de/README.md)

## Messages for scripts and AI agents

`sendTo('pushover.0', 'help', {})` answers `{ help, commands }`: a description of all messages (`send`, `glances` ...)
with their parameters and answers for AI agents (e.g. ioBroker.pi-agent) and script authors, and the list of all
commands with `write` (whether the command has an effect, e.g. sends a message).

## Sentry

**This adapter uses Sentry libraries to automatically report exceptions and code errors to the developers.** For more details and for information how to disable the error reporting see [Sentry-Plugin Documentation](https://github.com/ioBroker/plugin-sentry#plugin-sentry)! Sentry reporting is used starting with js-controller 3.0.
