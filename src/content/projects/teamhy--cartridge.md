# cartridge

A mod preset save utility for The Binding of Isaac: Repentance.

---

## Note

This program was developed for broadcaster **Oh Heon-yeong** and may include some features that are somewhat specialized for general users.

- [YouTube Channel](https://www.youtube.com/@아이작오헌영)
- [Twitch Stream](https://www.twitch.tv/iwt2hw)
- [AfreecaTV](https://bj.afreecatv.com/iwt2hw)
- [Chzzk](https://chzzk.naver.com/f409bd9619bb9d384159a82d8892f73a)

---

## Features

- Save and load various mod combinations as **presets**
- Record feature for challenge mode (including rankings)
- **Slot machine** UI feature for streaming
