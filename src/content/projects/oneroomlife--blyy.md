# 🚢 BLYY - Azur Lane Voice Player

---

## 📖 Project Introduction

Azur Lane Voice (BLYY) is a multi-functional shipgirl app designed for Azur Lane players. Built with Kotlin 2.1 + Jetpack Compose, it covers **voice playback, a shipgirl encyclopedia, a secretary ship floating window, desktop widgets, direct reading of game resource packs, a birthday calendar, AI role-play dialogue, a guess-the-shipgirl mini-game, a Live2D skin library, and a watermark camera**. The app includes a built-in local avatar matching engine for all shipgirls (wiki encyclopedia 1004/1004 matched), supports two theme styles (classic purple / Command Center HUD), and offers smooth animations.

## ✨ Features

### 🏠 Three Main Pages in the Bottom Navigation

#### Home
- Home display page for oath shipgirls, with AGSL shader-driven dynamic oath-pink glow, rarity halo, and favorite badge
- Small screen / watch adaptation: UI scales automatically when the screen's smallest width is ≤ 360dp

#### Dock (Gallery)
- Complete shipgirl encyclopedia with multi-dimensional filtering by faction, ship type, and rarity, plus search; tap a shipgirl to go directly to her voice page
