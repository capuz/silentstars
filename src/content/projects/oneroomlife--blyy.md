# 🚢 BLYY - Azur Lane Voice Player

---

## 📖 Project Overview

Azur Voice (BLYY) is a multi-function shipgirl app designed for Azur Lane players, built with Kotlin 2.1 + Jetpack Compose. It covers **voice playback, shipgirl encyclopedia, secretary ship desktop interaction, AI role-play chat, shipgirl guessing mini-game, watermark camera** and more. The app includes a built-in local avatar matching engine for all shipgirls and supports two visual themes (Classic Purple / Command Center HUD) with smooth animations.

## ✨ Features

### 🏠 Three Main Pages in the Bottom Navigation

#### Home (后宅)
- Home display page for oath shipgirls, with AGSL shader-driven oath-pink dynamic glow, rarity halos, and favorite badges
- Adaptive for small screens and watches: automatically scales the UI when the minimum screen width is ≤ 360dp

#### Dock (Gallery)
- Full shipgirl encyclopedia with multi-dimensional filtering by faction, ship type, and rarity, plus search
- **Dual archive mode**: Ship Archive (DOCK) / Member Archive (STUDENT), switchable dynamically
- **Long-press a shipgirl avatar to make or break an oath**; after an oath, the standing portrait automatically switches to the wedding…
