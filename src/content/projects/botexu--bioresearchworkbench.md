# BioResearchWorkbench

**A biomedical research workbench focused on molecular biology dry-lab work: public retrieval, statistical and analysis design, input QC, server computing integration, review of returned results, evidence traceability, and paper delivery.**

Originally built on [Biomni](https://github.com/snap-stanford/Biomni). This project adds bridging, checks, task integration, and workflows on top of it, and combines third-party research software. Upstream algorithms, databases, models, software, and client plugins retain their own attribution; see [Origins and third-party attribution](https://github.com/BoteXu/BioResearchWorkbench/blob/HEAD/ORIGINS.md) and [Component inventory](https://github.com/BoteXu/BioResearchWorkbench/blob/HEAD/third_party_components.json). This is an independent downstream workbench.

The original foundation is Biomni. This independent downstream project adds tool adapters, QC/evidence checks and workflow orchestration, while preserving third-party attribution. The host model supplies reasoning; this tool layer needs no additional model API key or local LLM. It does not include Biomni-R0, the full E1 environment or a data lake.
