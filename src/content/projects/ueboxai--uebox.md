## Features

- **100+ engine tools**: levels, blueprints (including animation blueprints), materials (including Substrate), C++, assets, data tables, UMG, Sequencer, geometry, terrain, PCG
- **Compile and runtime verification**: automatically fixes blueprint / C++ compile errors; PIE runs capture logs and screenshots; playtest bot automated key-press testing (experimental)
- **Auditable changes**: tool calls are visible throughout; each turn lists created / modified / deleted items; one-click re-read of the engine for comparison
- **Goal mode** `/goal`: checks each item against the requirements checklist and keeps revising until it passes
- **Team mode** `/team`: multiple teammates divide the work, and each can use a different model
- **27 built-in skills** + error experience accumulated per project
- **80+ model providers**: Claude, GPT, DeepSeek, Ollama, LM Studio, etc.; supports ChatGPT Plus / Kimi membership login
- **Approvals**: risky operations require confirmation; can be set to 'Always allow from now on'
- **MCP / CLI**: for use with Codex, Claude Code, Cursor, and scripts
- **Asset management**: project library, asset library, blueprint library, material library, 3D…
