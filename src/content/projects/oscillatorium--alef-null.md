# Alef-Null (en)

A mathematical mod for Mindustry. Adds numbers as resources. The first step into mathematics.

## Version number syndrome

- 0.02–0.99: no planet
- 1.00–1.99: there is a planet
- 2.00–2.99: and another planet
- and so on, until ideas run out

## Important

The mod is actively developed. There is currently little content, but it will expand with each version.

## Installation

1. Download `Alef-Null.zip` from the [Releases section](https://github.com/oscillatorium/Alef-Null/releases) on GitHub
2. In the game: Mods -> Import mod -> Locally
3. Select the downloaded ZIP archive (do not unpack it)

Or search in the browser for the Alef-Null mod, as the mod is available in the mod browser.
