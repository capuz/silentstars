# zoo2

Compose for Android に廃止予定はなく、開発・検証・配布を継続します。動作が重く実用に耐えないため実験を中止したのは、このプロジェクトの Compose for Web のみです。Web は React で開発を継続します。[Android 版](https://github.com/Zli-UoA/zoo2/blob/HEAD/docs/android.md) を参照してください。

Slack互換Webhookでの通知連携は [Webhook設定](https://github.com/Zli-UoA/zoo2/blob/HEAD/docs/webhooks.md) を参照してください。

PWA のインストールとプッシュ通知の設定・動作は [PWA とプッシュ通知](https://github.com/Zli-UoA/zoo2/blob/HEAD/docs/pwa-and-push.md) を参照してください。

本番の配備結果と履歴は [Flux の通知](https://github.com/Zli-UoA/zoo2/blob/HEAD/docs/flux-status.md) を参照してください。

データベースの構造は [DB の ER 図](https://github.com/Zli-UoA/zoo2/blob/HEAD/docs/db-erd.md) を参照してください。

Slack のエクスポートの取り込みとアカウント連携は [Slack からの取り込みとアカウント連携](https://github.com/Zli-UoA/zoo2/blob/HEAD/docs/slack-import.md) を参照してください。

App・Botの開発、認証、イベント配信、既存Webhookの移行は [App・Bot基盤](https://github.com/Zli-UoA/zoo2/blob/HEAD/docs/apps.md) を参照してください。

投稿URLのカード展開と画像プロクシの設定は [URLカード](https://github.com/Zli-UoA/zoo2/blob/HEAD/docs/link-previews.md) を参照してください。

GitHub のコメント・状態変更を Zoo に通知する外部 Bot は [GitHub 通知 Bot](https://github.com/Zli-UoA/zoo2/blob/HEAD/apps/github-bot/README.md) を参照してください。
