# PatchEditor

A java mod providing an in-game **GUI** for DataPatcher.

This mod will help you make your own patch quickly in many ways:

* You don't need to **look up what fields are available in wiki**.
* You could **focus on mapping** instead of wandering from text editor to game.

Anyway, enjoy making wonderful patch!

## Features

- [x] Edit number, string
- [x] Edit fields in Seq, ObjectSet, ObjectMap
- [x] Add new object in Seq, ObjectSet, ObjectMap
- [x] Remove object in ObjectMap
- [x] Export easy-reading json
- [x] Override Seq, ObjectSet

- [x] Remain unsupported fields
- [ ] Errors inspector
- [x] Star fields

- [x] Edit Color
- [x] Edit Interp
- [x] Edit Consumer
- [x] Edit Attribute
- [x] Edit BuildVisibility
- [x] Edit EnumSet

- [x] Select weapon region
- [x] Select texture region
- [x] Select unit's controller, aiController and type
- [x] Select effect
- [x] Select block flag
- [x] Select sound

- [x] Export vanilla content to patch.
