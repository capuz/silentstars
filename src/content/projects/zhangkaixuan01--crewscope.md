A collaborative AI work execution platform for technical teams<br>

CrewScope turns a technical team's conversational goals into an executable, collaborative, and traceable work loop. Each member has a Personal Agent that represents them; the Team Agent provides a shared team view; Specialist Agents such as Coding and Reviewer handle professional execution; humans always own goals, authorization, Review, and final decisions.

The work packages M0–M9 for the current **Team Beta MVP** have all been delivered (the real-environment acceptance for `M9-Q02` remains pending). The [M6 MVP Release Gate](https://github.com/zhangkaixuan01/crewscope/blob/HEAD/docs/testing/M6-Q04-MVP-Release-Gate.md) has been formally closed, and the local and Linux amd64 Server RC conclusions for the [M7 Open User System Release Gate](https://github.com/zhangkaixuan01/crewscope/blob/HEAD/docs/testing/M7-Q04-Release-Gate.md) are both `PASS`. M8 delivers the Setup Center, responsibility consolidation, dependency governance, and operations observability.
