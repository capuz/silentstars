## Flowix: notes that become memory for ongoing work

Record content in Markdown, hand the context an Agent needs to it, and write the results back to the same note, so they are easy to review, edit, and reuse next time.

---

## Keep work moving forward

Keep product, development, research, and personal knowledge in one place so Agents don't have to start from scratch each time.

| Scenario | Description |
| --- | --- |
| **Product work** | Centrally manage requirements, feedback, and decisions to keep product documentation up to date. |
| **Software development** | Save project background and constraints so coding Agents can pick up where things left off. |
| **Research projects** | Keep materials, analysis, and conclusions together for easy traceability and reuse. |
| **Personal knowledge** | Make notes, plans, and personal preferences usable as context for Agents. |

---

## Let different Agents use the same memory

You can use Agents inside Flowix, or connect **Codex**, **Claude Code**, **OpenCode**, **Hermes**, and other MCP or CLI tools so they all work from the same notes and context.
