# Default SMS Forwarding Gateway-SMS Forwarder · Android

An open-source, modern default SMS client and multi-channel forwarding gateway for the Android platform.
Supports switching between <b>“Classic Daily Mode”</b> and <b>“Modern SMS Gateway Developer Workbench”</b> modes.
