Native windows, 2D graphics and audio for Node.js, built on <a href="https://www.sfml-dev.org/documentation/3.1.0/">SFML 3.1.0</a>.

**English** · [简体中文](https://github.com/XadillaX/sfml.js/blob/HEAD/README.zh-CN.md) · [日本語](https://github.com/XadillaX/sfml.js/blob/HEAD/README.ja.md) · [한국어](https://github.com/XadillaX/sfml.js/blob/HEAD/README.ko.md)

Build desktop multimedia applications in JavaScript or TypeScript: draw sprites, shapes and text, handle window events, play and record audio, and exchange data through SFML-style networking APIs.

[Website](https://sfml.js.org/) · [Quick start](https://github.com/XadillaX/sfml.js/blob/HEAD/docs/getting-started.md) · [Guides](https://github.com/XadillaX/sfml.js/blob/HEAD/docs/README.md) · [Type reference](https://sfml.js.org/reference/) · [Examples](https://github.com/XadillaX/sfml.js/blob/HEAD/examples/README.md)

## What is included

| Module | Capabilities |
| --- | --- |
| System | Typed vectors, angles, time, clocks, Unicode boundaries and seekable input streams |
| Window | Native windows, typed events, keyboard, mouse, joystick, clipboard and OpenGL contexts |
| Graphics | Sprites, shapes, Unicode text, cameras, shaders,…
