# O2DPG

This repository collects scripts and configurations to run Monte Carlo simulations and data reconstruction of the ALICE experiment within the O2 project.
Please refer to  [MC/README.md](https://github.com/AliceO2Group/O2DPG/blob/HEAD/MC/README.md) and [DATA/README.md](https://github.com/AliceO2Group/O2DPG/blob/HEAD/DATA/README.md) for details.
The content of the former [O2DataProcessing](https://github.com/AliceO2Group/O2DataProcessing) repository can be found in [DATA](https://github.com/AliceO2Group/O2DPG/blob/HEAD/DATA).
