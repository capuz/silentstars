## Voice input

When chatting, writing emails, or taking notes, press the shortcut once to start speaking and press it again to stop. MemoEcho removes filler words, tidies up sentence breaks, and then inserts the text into the current input field.

If you need to express yourself in another language, you can turn on translation. Common names and terms can be added to the dictionary, and MemoEcho also learns word choices from your edits to the output.

Speech recognition can use a local model or a cloud service. Text cleanup and translation use the AI service you configure. For setup, see the [Usage guide](https://github.com/isecret/MemoEcho/blob/HEAD/docs/USAGE.md).

## Getting started

Requires **macOS 14 or later**. Get the installer from [Releases](https://github.com/isecret/MemoEcho/releases), or install it with Homebrew:

```bash
brew install --cask isecret/tap/memoecho
```

The tap currently contains beta builds. For trust prompts, updates, and uninstall instructions, see [homebrew-tap](https://github.com/isecret/homebrew-tap).
