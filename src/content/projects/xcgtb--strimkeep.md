# 🎬 StrimKeep

---

## 🌟 Project Highlights

### ✨ Core Features

- 🔗 **115 Share Transfer** - Paste share links (supports `?password=` extraction codes) and batch-transfer them to a specified directory
- ⚡ **Offline Download** - Submit magnet / ED2K / direct links, and track progress and outputs
- 📡 **Telegram Channel Monitoring** - Monitor public channel preview pages or private channels (via user session, read-only messages); keyword filtering routes content to separate destinations on disk
- 🎬 **Media Organization & Quality Upgrades** - TMDB identification → canonical directory `剧名 (年份) {tmdb-id}/Season N/`, 7-dimension quality comparison to pick the best version, with subtitles, NFO, and posters saved alongside the video files
- 🔗 **STRM Generation & Sync** - Outputs STRM files with 302 playback addresses. **Identity is stored inside the file**, so renaming or moving between libraries requires no sync registry
- 🧹 **Dead Link Cleanup** - Checks each entry still exists on the cloud drive before deleting it, with three layers of protection and event logging
- 🖼️ **Library Mapping** - Organized by Emby media library, with 7 statuses (complete / missing episodes /…
