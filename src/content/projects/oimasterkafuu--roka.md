# Roka

Roka is a real-time grid-based territory war game, similar in gameplay to generals.io. Players expand their territory, build main bases and command posts, and in FFA or team matches, capture the enemy's main base and survive to the end.

The server is built with TypeScript, Fastify, and Socket.IO, and the frontend is mainly native JavaScript. Matches are settled by the server on a per-Tick basis, with support for reconnection after disconnection, spectating, and full replays.
