* Joomla! Content

## Features

* Push Notifications based Firebase
* OG-tags
* Schema.org
* SEO
* Service Worker
* Offline mode
* Add your site to home-screen
* Add application icons
* Add Splash background for Android and iOS 26
* Add screenshots
* Add shortcuts
* Theme color (light or dark)
* Lightning fast
* Support Android, iOS, Windows, Linux, MacOS etc.
* Support sw.js template
* Support offline template
* Support plugins integration
