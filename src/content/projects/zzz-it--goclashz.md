# <img src="docs/assets/logo.png" width="45" alt="GoclashZ Logo" style="vertical-align: middle; margin-right: 10px;"> GoclashZ

A high-performance, industrial-grade solid-color aesthetic Mihomo (Clash Meta) desktop controller built on Wails

   

---

GoclashZ was born out of resistance to the bloat of modern desktop applications. This project abandons the traditional Electron architecture and leverages Go's system-level concurrency and Wails' native rendering to compress memory footprint and system resource usage to the physical limit. Visually, it adheres to a minimalist industrial aesthetic of high contrast and solid black-and-white colors, removing all meaningless gradients and decorations. It is not just a control interface, but a network state management system that has undergone rigorous hardening.
