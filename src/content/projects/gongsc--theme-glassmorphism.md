# Glassmorphism for 极简探针

This project ports the [sanrokamlan-prog/komari-theme-Glassmorphism](https://github.com/sanrokamlan-prog/komari-theme-Glassmorphism) theme to [极简探针 Monitor](https://github.com/monitor-probe/monitor). It is based on the original v3.3.7 Vue source code, components, styles, and assets. Data is now provided by Monitor's REST and WebSocket APIs, so no Komari server deployment is required.

The current version is 1.4.6. This project keeps the original project's MIT license and retains the original author's attribution.

## Key Features

- **Glassmorphism appearance**: Provides a dynamic gradient background and five color schemes: Emerald, Soft, High Contrast, Midnight, and Custom. Supports light and dark modes, plus automatic switching based on Beijing time. The background can be an image, a video, or the Bing daily wallpaper.
- **Globe and maps**: Offers four styles: textured globe, Cobe dot-matrix globe, tiled world map, and dot-matrix tiled map. Labels the country where each node is located, with auto-rotation or hiding available. When 'Show cities on globe' is enabled, cities are identified from node names and labeled.
