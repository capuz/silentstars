# NapkinUML

NapkinUML is a UML diagram editor I created for personal use. It is meant for simple drawing, without complex, flashy, or special features.

> To commemorate the legendary story of genius developers drawing world-changing designs on napkins, the name 'NapkinUML' was chosen.

## Supported Diagrams

9 UML types:
* Class diagram
* Component diagram
* Deployment diagram
* Use Case diagram
* Sequence diagram
* State Machine diagram
* Activity diagram
* Object diagram
* Package diagram

Other 4 types:
* ER diagram
* Network diagram
* Mind map
* Timeline diagram
* Relationship diagram

## Experimental Feature: AI Assistance
You can get help creating diagrams using an AI agent installed locally.

AI agents (Claude Code, Codex CLI, Gemini CLI, Ollama, etc.) are not included in NapkinUML. You run programs you install yourself, and each program's license and terms of use apply.
