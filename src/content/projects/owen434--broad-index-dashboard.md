# 📊 broad-index-dashboard

**Quantitative analysis toolkit for A-share broad-based indices / sector funds / gold**

Each script produces a single self-contained interactive HTML file (rendered with Plotly). Double-click to open it. No browser plugins or local server are needed. A fresh version is also regenerated automatically in the early morning of every trading day.
