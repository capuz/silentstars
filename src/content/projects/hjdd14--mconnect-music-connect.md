# Mconnect

This project is developed with AI-assisted programming.

Mconnect is a Flutter Android music aggregation app that uses a unified interface to aggregate search, playback, lyrics, playlists, favorites, downloads, and local music capabilities from NetEase Cloud Music, QQ Music, and KuGou Music.

> Note: Third-party music platform APIs may change, and login status, VIP playback, and high-quality downloads are ultimately determined by the platform's backend. This project does not save any real account credentials to the repository; runtime sessions are only stored locally on user devices.

## Features Overview

- Multi-platform Search: Supports searching for songs or playlists across NetEase Cloud, QQ Music, and KuGou.
- Player: Supports playback queue, previous/next track, mini player, fullscreen player, progress memory, and audio quality selection.
- Lyrics: Supports LRC/QRC/KRC timed lyrics; when platforms provide character-by-character or translated lyrics, they are synced as much as possible.
- Music Library: Contains liked songs, listening history, platform playlists, imported playlists, local music, and download management.
