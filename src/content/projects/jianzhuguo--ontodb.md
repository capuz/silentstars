# OntoDB — Multi-Modal Semantic Database with an Ontology Kernel Embedded

**[English](https://github.com/jianzhuguo/ontodb/blob/HEAD/README.en.md)** | Chinese

**The world's first multi-modal semantic database that embeds an OWL reasoning engine in the database kernel**

Supports unified storage of 12 data types. A single INSERT automatically completes a 7-step linked write pipeline. Embedded incremental reasoning delivers 100x the performance of external solutions.

---

## Why OntoDB

**The current state at most teams**: relational data in MySQL/PostgreSQL etc., graphs in Neo4j, vectors in Milvus, time series in InfluxDB, reasoning in Jena. Answering one question spans 5 systems, writes require ETL sync afterward, and classification knowledge is hard-coded in the application. **Lots of data, little knowledge.**

OntoDB solves this with one engine:

| Dimension | Traditional approach | OntoDB |
|------|----------|--------|
| **Architecture** | MySQL + Neo4j + Milvus + InfluxDB + PostGIS + Jena, 6 systems | **1 system**, 12 data types stored uniformly |
