# AMD DLSS MU

A game management and graphics configuration tool for Windows. It manages local games, downloads and verifies the required components, configures DLSS-NR on AMD / OptiScaler, or launches a standalone scaling tool through 大力喜鹊.

[Project website](https://amd-dlss-mu.claude-api.cn/) · [Version downloads](https://github.com/xiarongwu123/AMD-DLSS-MU/releases) · [Issue tracker](https://github.com/xiarongwu123/AMD-DLSS-MU/issues) · [Contact the author](#联系作者)

## Current Version

The current stable release is `2.1.2`. It includes Smart Recommendation, one-click diagnostics, a wish pool, download resume, and an HIP 7.2 installation guide for RX 6000. The client's internal version must match the version in the official website's release manifest so that automatic update verification works.

## Key Features

### Smart Recommendation and One-Click Diagnostics

In the game library, click "Smart Recommendation" and choose "Image Quality First", "Frame Rate First", or "Custom". Image Quality First keeps the original DLSS 5 Mode 1.
