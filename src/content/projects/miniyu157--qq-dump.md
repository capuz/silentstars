# QQ DUMP + Trowel !

⛏ A full-featured, friendly all-in-one pipeline from QQNT databases to information: covering database decryption and dumping, message parsing and export, statistical analysis, friend lookup, and WebUI, plus a database and message research and analysis suite designed for reverse-engineering research and development.

Supports Android, Windows, and Linux.

> The project has been fully upgraded to Python. Runtime dependencies are all optional and installed as needed.  
> The main branch's history has been rewritten. The classic bash implementation, including the old commits, can still be viewed in the *[dbtools branch](https://github.com/miniyu157/qq-dump/tree/feat/dbtools)*.  

> The complete code of the classic message export project *[QQRootFastDecrypt](https://github.com/miniyu157/QQRootFastDecrypt)* is retained. It has been adapted to this project's architecture and can be run directly.
