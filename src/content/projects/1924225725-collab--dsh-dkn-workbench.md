# dsh-DKN-Workbench

DKN Integration Workbench is a Windows plugin for DeepSeek Harness (formerly DKN Agent). Within DSH, you can browse and continue local Codex project conversations, use CLI models from Codex, CodeBuddy, and ZCode, use local account models through Qoder ACP, and organize agent collaboration by project. The current source is `2.3.7`, compatible with DSH `0.2.2-rc.1` / `0.2.2-rc.3` / `0.2.2-rc.5`.

The interface uses a clean style by default, sharing the same scheduling layout and configuration drawer as the illustrated style. The clean version replaces artwork with icons, connector lines, and light dots, and follows DSH's light and dark themes. You can switch styles in the top-right corner. After an upgrade, it switches to the clean version once and then keeps your choice.
