# 不问凡尘 NPC Voice and Lip-Sync MOD

Adds local voice to NPC dialogue for 《不问凡尘》, so the voices convey emotion according to the character and the dialogue. Optional features include player reading, microphone input, and MuseTalk portrait lip-sync.

Current version: **Voice program 0.8.5, digital human 0.8.4**. The digital human includes the lip-sync plugin, the MuseTalk worker, and supporting resources. The repository keeps the `A1IndexTTSMod` name. It currently maintains CosyVoice3 and BreezeTTS2, and IndexTTS is a legacy route.

The public repository provides source code, scripts, necessary configuration, and documentation. **This source sync does not include model weights, reference WAV files, game assets, inference cache, runtime DLL/EXE files, or finished installation packages.** The microphone icon, the text GPU kernels, and the protocol resources required for the build are kept with the source.
