**Local-first · Encrypted storage · Open source**

Native clients are in **developer preview**. [Platform availability](#choose-your-workspace) and the [security model](https://github.com/JunWeiUp/PasswordVault/blob/HEAD/docs/SECURITY_MODEL.md) describe current limits; an independent security review is still pending.

**Release 2.4.0:** [GitHub Release](https://github.com/JunWeiUp/PasswordVault/releases/tag/v2.4.0) · [Installation and limits](https://github.com/JunWeiUp/PasswordVault/blob/HEAD/config/release/INSTALL.md). Includes current NSH Mac, Android, extension, Web and iOS Simulator packages.

**Mac client status:** [`apps/macos-nsh`](https://github.com/JunWeiUp/PasswordVault/blob/HEAD/apps/macos-nsh/README.md) is the current development and local daily client (NSH 0.4.0, macOS 14+ / Apple Silicon). [`apps/macos-legacy`](https://github.com/JunWeiUp/PasswordVault/blob/HEAD/apps/macos-legacy/README.md) is the retained legacy SwiftUI Mac client. References below to macOS 13+/Intel and older coordinated releases apply to that legacy client.
