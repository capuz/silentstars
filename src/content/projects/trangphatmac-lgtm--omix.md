## Project Introduction

Omix is a Minecraft hacked client developed based on DSJ's Remix base and Minecraft 1.21.11 / Fabric. In addition to conventional features such as functional modules, ClickGUI, HUD visuals, music player, and account management, this project is also the first AI-native client in the field.

- **In-game AI Agent**: Use the same Harness in the game panel or system browser to manage models, workspaces, sessions, and plugins.
