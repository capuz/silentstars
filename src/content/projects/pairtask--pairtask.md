# pairtask

**Your AI coding agents, working as a team.** pairtask puts Codex, Claude and
Pi in one shared workspace, lets them message each other directly, and gives
you one chat to direct them. Ask one agent to build a change and another to
review it; they coordinate without you relaying every message.

[MIT](https://github.com/pairtask/pairtask/blob/HEAD/LICENSE) or [Apache 2.0](https://github.com/pairtask/pairtask/blob/HEAD/LICENSE-APACHE) · [Get started](#set-up-a-sandbox) · [Features](#features) · [Docs](#documentation) · [Troubleshooting](https://github.com/pairtask/pairtask/blob/HEAD/docs/troubleshooting.md)

## Features

- 🤝 **Agents that pair up**: Codex, Claude and [Pi](https://github.com/pairtask/pairtask/blob/HEAD/docs/pi.md) share one workspace and talk to each other directly. Run several of each and group them in rooms.
- 💬 **One chat to lead them**: Message one agent, a group or everyone. Replies, acknowledgments, search, history, [Markdown and diagrams](https://github.com/pairtask/pairtask/blob/HEAD/docs/chat-formatting.md). [Operator chat →](https://github.com/pairtask/pairtask/blob/HEAD/docs/operator-chat.md)
