Dice!Next is a self-hosted dice bot for TRPG tabletop play. Connect your bot account to roll dice in chat, manage character sheets, and record sessions. Configure and maintain it through a web panel.

The project is currently in Beta. It provides Windows, Linux, and macOS release packages, as well as a [Docker deployment option](https://github.com/DiceZone/Dice-Next-Docker).

## Quick Start

1. Download the package for your operating system and architecture from the **Assets** section of [Releases](https://github.com/DiceZone/Dice-Next/releases). Do not choose `Source code`. Extract the whole package into a fixed directory. Do not run it from inside an archive or the system temp directory.
2. Start it as shown in the table below. The release package already includes the WebUI, so you do not need to build the frontend separately.

   | OS | Architecture / package format | How to start |
   | --- | --- | --- |
   | Windows | x64 (amd64) / ARM64 · `.zip` | Double-click `dice-next.exe` |
   | Linux | x64 (amd64) / ARM64 · `.tar.gz` | Run `./start.sh` in the extracted directory |
   | macOS | Apple Silicon (arm64) · `.tar.gz` | Run `./start.sh` in the extracted directory |
