# File & Link Actions · File Actions

**Code references travel with their source. Right-click delivered files to keep working on them.**

[English](https://github.com/jidekaixin2dian/dsh-file-actions/blob/HEAD/README.en.md) · [npm · 0.1.23](https://www.npmjs.com/package/@jidekaixin2dian/dsh-file-actions/v/0.1.23) · [Plugin Marketplace](https://awesome-dsh-plugin.com/p/jidekaixin2dian/dsh-file-actions/) · [Download](https://github.com/jidekaixin2dian/dsh-file-actions/releases/latest) · [Changelog](https://github.com/jidekaixin2dian/dsh-file-actions/blob/HEAD/CHANGELOG.md)

File Actions provides a right-click menu for file references in DeepSeek Harness (DSH). Start from a code line number, a delivery card, or an image to view context, choose an app, preview, locate, and copy directly.

| What you want to do next | What File Actions provides |
|---|---|
| See the code the Agent referenced | Read-only preview of the referenced lines and surrounding lines, highlighting the referenced range |
| Hand the reference to someone or another session | Copy the reference text, file path, and line number in one step |
