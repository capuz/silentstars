# Feiya

Feiya can share files and messages over the local network, and can also use an Android device as a Bluetooth keyboard for a computer, providing text sending and the physical key controls needed for keyboard settings.

## Requirements

- An Android 13 (API 33) or newer device with Bluetooth HID support.
- A computer that can pair with a Bluetooth keyboard.
- Bluetooth turned on, and the Bluetooth permissions Feiya requests granted.

## App Navigation and File Sharing

On phones, the bottom navigation switches between the Files, Messages, Keyboard, Security, and Settings pages; wider windows use a persistent side navigation. On large screens, selecting a shared file shows its details beside the list; on phones, use **Back to files** or the system back gesture to return to the list.

Use **Add files** to share documents. The file details provide a QR code for that file, local saving where supported, and **Remove from sharing**; removing a file from sharing does not delete the original.
