# 黑粉盒子 HyphenBox · Free AI API Radar, Model Verification & Unified Interface

**Find a suitable free AI API, test it with your own key, then connect it to common AI coding tools.**

黑粉盒子 (HyphenBox) is a desktop AI API management tool developed by 黑粉科技. It combines free resource discovery, a local key vault, model verification, local unified routing, and standalone image/video tools. DeepSeek Harness supports one-click integration for chat and free media tools; other compatible clients keep their configuration guides. Resource conditions come with official evidence and verification dates. Whether a model is usable depends on your own account and real requests.

The software is free to download and does not require a 黑粉盒子 account. Platform keys must be applied for separately, and some platforms require international network access. Free quotas, regions, and account conditions are determined by each platform.
