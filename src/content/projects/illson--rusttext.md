# RustText

**A Windows text editor with workspaces, a draft archive, and local file history. In the same window: large logs, JSON, a proxy checker, and tools for working with lists.**

**[Download for Windows x64 ↓](https://github.com/Illson/RustText/releases/latest/download/RustText.NET-win-x64.zip)** · [What's new](https://github.com/Illson/RustText/releases/latest) · Portable EXE

Looking for a **Sublime Text alternative for Windows**? RustText also lets you edit text with multiple cursors, navigate with the minimap, and open files side by side.

## Your own workspace for each project

“Production”, “Test bench” and “Notes” can be open at the same time in different windows. Each workspace has its own tabs, drafts, panel layout and theme. A workspace can be duplicated in full, and a deleted one can be restored.
