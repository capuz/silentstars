# dsh-plugins

Simplified Chinese / [English](https://github.com/klarkxy/dsh-plugins/blob/HEAD/README.en.md)

A plugin collection for klarkxy's DeepSeek Harness (DSH). Visit the [plugin site](https://klarkxy.github.io/dsh-plugins/) to browse installation commands, version updates, and detailed descriptions of each plugin.

## Plugins

| Category | Package | Description |
| --- | --- | --- |
| Work style | [`@klarkxy/dsh-git-commit`](https://github.com/klarkxy/dsh-plugins/blob/HEAD/plugins/dsh-git-commit/README.md) | Git commit: commit workspace changes within a conversation. The model groups the changes and generates Git commit messages. |
| Work style | [`@klarkxy/dsh-delegation`](https://github.com/klarkxy/dsh-plugins/blob/HEAD/plugins/dsh-delegation/README.md) | Delegation mode: enabled per session. The main agent handles decomposition, delegation, and acceptance, while sub-agents carry out specific tasks. Supports multi-agent collaboration. |
