# 🤖🍲 What is Gooey Server?

Gooey.AI is a low-code AI recipe platform and Gooey Server is our core repo.  
It allows users to discover, customize, and deploy AI "recipes" using the best of private and open-source AI,
all using a single API with a single auth token.  
Recipes are workflows that incorporate various models to accomplish a task; they are designed to be highly customizable and shareable.

## 🧑‍💻 Who is this for and why would I want to use it?

Gooey Server is open-source infrastructure for organizations that need control over where and how their AI runs. As part of our work toward recognition as a **Digital Public Good (DPG)**, Gooey Server is designed to be transparent, adaptable, and independent of any single cloud or AI provider. See our [Platform Independence](https://github.com/GooeyAI/GooeyAI/blob/HEAD/PLATFORM_INDEPENDENCE.md) documentation for the open alternatives and swap mechanisms available for each proprietary dependency.
