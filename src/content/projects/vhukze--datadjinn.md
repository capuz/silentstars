## Introduction

DataDjinn is a local database client for Windows. It combines connection management, object browsing, SQL editing, data editing, import/export, and optional AI, MCP, Git sync, and version management capabilities in one desktop workspace. Core features work out of the box, while larger or more dependency-heavy capabilities are installed on demand.

Current latest version: `v0.3.20`

## Core Capabilities

- Multi-database connections: SQLite, MySQL, PostgreSQL, Oracle, DM (Dameng), GaussDB, MongoDB, Redis, ClickHouse, Elasticsearch.
- Connection tree: groups and subgroups, drag-and-drop sorting, pinning, search and locate, SSH tunnels, connection testing, reconnecting after saving a password, silent reconnection, and multiple connection import/export formats. Group, sort, and database display preferences are kept across restarts and updates. Opening a connection expands only the connection level; databases, schemas, and table groups are expanded manually as needed. Background table size statistics preserve expanded fields and click position.
- SQL workspace: Monaco editor, multi-tab queries, SQL and stored procedure completion, keyword highlighting,…
