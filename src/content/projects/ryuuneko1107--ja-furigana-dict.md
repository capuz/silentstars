# furigana-dict

> Japanese word dictionary for the [furigana](https://github.com/RyuuNeko1107/ja-furigana) library — open, community-maintained.

A standalone repository that hosts the **vocabulary dictionary** used by [`furigana`](https://github.com/RyuuNeko1107/ja-furigana) (furigana API + library). Adding or correcting readings is done entirely by **editing TOML and submitting a PR**.

> For the latest counts / per-category breakdown / sizes, see [**STATS.md**](https://github.com/RyuuNeko1107/ja-furigana-dict/blob/HEAD/STATS.md)
> (GitHub Actions auto-commits on master push; contributors don't need to do anything).
> For the latest release, see [GitHub Releases](https://github.com/RyuuNeko1107/ja-furigana-dict/releases).
