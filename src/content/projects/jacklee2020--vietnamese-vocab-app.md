# 🇻🇳 越南语千词斩 · Vietnamese Vocabulary Trainer

一款**离线可用**的越南语词汇背诵 PWA。手机、电脑浏览器直接可用——无需注册、无需服务器、首次打开后**断网也能学**。

> 📚 **3378 个核心词汇 · 12 大分类 · 真人发音 · 间隔复习 · 三种自测**

---

## 🏫 实际使用

本应用源于**东兴还珠越南语培训中心**的课堂教学实践，已作为学员课后词汇背诵工具投入使用，覆盖 **100+ 名线下学员**，并持续根据课堂反馈迭代：

- 词库由培训中心教学团队整理、母语者校对，贴合实际教学大纲；
- 学员通过微信群链接即可打开使用，无需安装、注册、登录；
- 已根据教师与学员反馈完成多轮迭代（自定义词库、每日计划、三种自测题型、离线缓存等）。

## ✨ 功能特性

| 特性 | 说明 |
| --- | --- |
| 📚 词库规模 | 3378 词 · 12 大类（数字、时间、社交、餐饮、交通、购物、住宿、商务、金融、医疗、核心词、口语短句） |
| 🙈 自定义词库 | 隐藏不想背的单词，出题、复习、词表自动排除，随时可恢复 |
| 🃏 卡片学习 | 先听音 → 点卡片翻转看释义 → 判断「认识 / 不认识」，不会的自动进生词本 |
| 🔁 间隔复习 | 按遗忘曲线自动安排复习，巩固记忆 |
| 📝 三种自测 | ✍️ 四选一、🔊 听音选义、⌨️ 拼写，可选题数（10/20/50）与范围 |
| 🔊 越南语发音 | 点击即读，支持慢 / 正常 / 快三档语速、自动朗读 |
| ⚙️ 每日计划 | 每日新词数 10 / 20 / 50 / 100 自由调整 |
| ✈️ 完全离线 | Service Worker 缓存全部词库，飞行模式可用 |
| 💾 进度备份 | 一键导出 / 导入学习记录，换机不丢进度 |
| 🌙 深色模式 | 夜间背词护眼 |
