Building the panel from scratch on <b>Cloudflare Workers</b> and <b>Pages</b>, automatically connecting the <b>D1</b> database, and upgrading previous panels to <b>1.0.6</b> in 30 seconds without deleting users
        Publishing the latest panel versions, update announcements for the repository of country static IPs, video tutorials, and official project support
        Download the single combined <code>worker.js</code> file, version <code>1.0.6</code>, which includes the complete VLESS core, the Persian management dashboard, and the user subscription portal

        In the user creation and editing section, the country list with dedicated flags is available. By checking a country, a dedicated config is created in the user's subscription link using the static, real IP of that same country (on port <code>443</code>).
        Countries' static IPs and location lists are automatically tested and updated in the cloud every few hours, so the configs inside the panel always stay online and fast without any manual changes by the admin.
        The <code>Socks5 Proxy</code> and <code>ProxyIP</code> sections have been removed from the panel to keep the config creation environment simple…
