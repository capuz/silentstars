# Terminal

[English](https://github.com/jinpy666/dbx-plugin-ssh/blob/HEAD/README.en.md) · [Product showcase page](https://github.com/jinpy666/dbx-plugin-ssh/blob/HEAD/docs/MEDIA.zh-CN.md) · [Features and competitor comparison](https://github.com/jinpy666/dbx-plugin-ssh/blob/HEAD/docs/COMPARISON.zh-CN.md) · [Standalone repository migration notes](https://github.com/jinpy666/dbx-plugin-ssh/blob/HEAD/docs/REPOSITORY_SPLIT.zh-CN.md)

Terminal is a server terminal for modern operations teams: open one connection and you can handle terminal operations, file transfers, jump-host access, controlled privilege escalation, and MCP automation. It compresses the 'next hour after logging into a server' into one coherent, auditable, reusable workflow.

> Terminal · SFTP · Remote Operations: terminal, files, automation, and controlled operations gathered in a single DBX terminal panel.
