# SEW Multimodal AMR Dataset 2026 Documentation

This repository contains the documentation of our multimodal autonomous mobile robot (AMR) dataset. The documentation includes:

- [Intrinsic and extrinsic calibration files, sensor descriptions, and data formats](https://github.com/SEW-Eurodrive-Open-Source/Multimodal_AMR_dataset/blob/HEAD/sensors_and_calibration)
- [The ROS 1 URDF viewer for the AMR and its sensors](https://github.com/SEW-Eurodrive-Open-Source/Multimodal_AMR_dataset/blob/HEAD/utils/dataset_rosbag_viewer/ros1/urdf_viewer/README.md)
- [The safety and productivity benchmark](https://sew-eurodrive-open-source.github.io/Multimodal_AMR_dataset/)
- [Images of our documentation and a pdf version of the technical drawing of the sensor positions](https://github.com/SEW-Eurodrive-Open-Source/Multimodal_AMR_dataset/blob/HEAD/images)
