# 觅影 OmniPlay

觅影 OmniPlay is a media library player for local hard drives, external drives, NAS, and home media server setups. It scans media files, automatically scrapes TMDB / Douban metadata, generates poster walls and episode stills, and handles local and remote playback with the mpv / FFmpeg playback stack.

This repository is the multi-platform collection of OmniPlay and contains 4 client projects. Features are benchmarked against `OmniPlay开源-mac-ARM`, and the other platforms continue to align with it, but interaction is redesigned for each platform's conventions rather than copying one layout.

The `OmniPlay-docker` server, split off early from the bundle edition, is no longer in development and is not covered by this file. The directory is kept for reference, and deployment instructions are in the README inside that directory.
