# iOS_network

Rules, rewrites, and plugins for software such as Quantumultx, Loon, Stash, and Shadowrocket on the iOS platform. Rules are updated daily.

1. Once the configuration file is stable, it does not need to be updated frequently; only periodic updates to the rules and adjustments to the plugin modules are necessary.

2. Detailed resources for each app can be found in the folder of the same name. Plugins or modules are valid for the app versions specified in the documentation; if the version is updated, please test or downgrade yourself.

3. The three general basic rule lists for direct connection in China, international acceleration, and ad blocking are automatically updated daily.

(Note: The three major rule files in this repository are always updated daily, providing the cleanest and most complete rules for personal use across the internet. The configurations, rewrites, and plugins for apps like surge and loon in the repository may become outdated over time, but the corresponding versions at that time are still valid! If they become invalid, you can request an update or refresh the address to check.)
