ZUI - a modern Windows utility for running `zapret`, choosing presets, checking their functionality and managing the built-in `tg-ws`.

It is suitable for Windows users who need a convenient GUI for `zapret` without manually running `.bat` files, unnecessary windows and constantly digging through folders. Compared to Z2 GUI, the new version is rewritten in Tauri/Rust/Svelte, starts faster, manages services more carefully and can check for updates via GitHub Releases.

> [!IMPORTANT]
> ZUI is not a VPN. The application does not encrypt all traffic, does not hide the IP address, does not change the region and does not make the connection anonymous.

> [!NOTE]
> ZUI is actively developed. Bug reports and suggestions are welcome via GitHub Issues.
