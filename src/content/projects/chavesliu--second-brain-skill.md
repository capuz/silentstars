## Project Overview

**Second Brain Skill** is an open-source implementation inspired by Andrej Karpathy's [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) philosophy.

It turns scattered personal knowledge into a **structured, interconnected, continuously evolving Wiki**, enabling AI assistants to better understand and use the context you have built up over time.

The project provides a **simple, runnable, easy-to-extend foundation framework** that makes it easy for developers to quickly Fork, customize, and build their own second brain.

### From Information Retrieval to Knowledge Accumulation

**Traditional RAG is more like an interpreter; Second Brain Skill instead takes a compiler-like approach.**
