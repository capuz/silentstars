# BazaarPlusPlus

**Born out of love** · An in-game mod for [《The Bazaar》](https://www.playthebazaar.com), for Windows, macOS, and Android

[English](https://github.com/BazaarPlusPlus/BazaarPlusPlus/blob/HEAD/README_en.md) · [Official site](https://bazaarplusplus.com) · [Download](https://bazaarplusplus.com/download) · [Tutorial](https://bazaarplusplus.com/tutorial) · [Release Notes](https://github.com/BazaarPlusPlus/BazaarPlusPlus/releases) · [Ko-fi](https://ko-fi.com/cauyxy)

---

BazaarPlusPlus is an open-source project for The Bazaar that does not change game balance. It only adds information and records: a card encyclopedia, ten-win lineup recommendations, match history and battle replays, enchantment / upgrade previews, a battle status bar, and more. The desktop version (Windows, macOS) is a BepInEx mod plus a desktop installer. The Android version is a game APK with BazaarPlusPlus built in, and can be installed directly. The same repository also contains an upload backend, a data analyzer, and the official website.

Regular players should go directly to the [download page](https://bazaarplusplus.com/download) to get the installer or APK. This repository is for developers…
