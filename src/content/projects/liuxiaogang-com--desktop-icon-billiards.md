# Desktop Icon Billiards · Desktop Icon Billiards

**Set up Windows desktop icons as a game of billiards.** Aim by moving the mouse on the desktop, hold the left button to charge power, and release to strike. Icons keep their own thumbnails, roll, collide, and drop into pockets. When you quit, the desktop is restored as it was.

Windows 10 / 11 x64 · Single-file EXE · MIT
